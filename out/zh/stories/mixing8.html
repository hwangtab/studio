混音课程 - 第 8 部：为插件摆好餐桌（增益分级）

课程

2025年11月19日

返回故事列表

"插了插件之后声音怎么怪怪地失真了。" "压缩器完全不动。"（咦？怎么回事？）

不是插件坏了。 而是你给它们 喂了太多饭（输入电平）。（嗝——撑了！）

1. 什么是增益分级（Gain Staging）？

简单说，就是 “在进入下一环节之前把音量调到合适的程度。” 音频信号会经过很多阶段（一步一步来）： 话放 -> EQ -> 压缩器 -> 主总线

增益分级就是那个“门卫”，保证每一关的电平既不太大也不太小。

2. -18 dBFS 的秘密（为什么重要）

数字世界里，0 dBFS 是天花板，对吧？（小心撞头！） 那为什么那么多专业工程师都强调 -18 dBFS？

因为我们爱的 模拟建模插件。 像 LA‑2A、1176、Pultec 这些经典设备的插件，会按照老派模拟设备的特性来工作。 模拟设备的基准电平（0 VU）换算到数字大约就是 -18 dBFS。

  • 输入在 -18 dBFS 左右时：插件声音最漂亮、最温暖、最音乐性。（这就是 甜蜜点。）
  • 靠近 0 dBFS 时：插件容易过载，难听地失真，或压缩反应过度。（糟糕！）

3. 实战增益分级方法

混音前（或录音时）先检查每条轨道的电平。（仔细点！）

  1. 看表：平均电平（RMS）是否在 -18 dBFS 附近。（峰值到 -10 dB ~ -6 dB 都可以。）
  2. 调 Clip Gain：别动推子！先调波形本身的大小（Clip Gain 或 Input Gain）。
    • 过大的波形削一点，太小的波形补一点。
  3. 匹配插件输入输出：插了插件后声音变大？把插件 Output Gain 拉回去，让旁路（Bypass）前后音量一致。

“Volume in = Volume out” 做到这一点，你的混音会更干净、更从容。

4. 小声的美学

“声音小了不会没劲吗？” 不会。混音阶段就该小而干净。 变大的事情交给最后的 母带 和限制器来做。（轰！）

如果混音时就把电平塞满，母带工程师就没有任何空间可发挥了。（哭脸-） 留出 余量（Headroom）。那块空白就是之后“冲击力”和“拳头感”的位置。

给插件一顿好饭（-18 dBFS）。 它们会用最好的声音回报你。（咔嚓-！）

[初学者常见失误] 🍱

  • “只用推子做平衡”：波形本身太大，你却把推子拉到底。等于把推子的分辨率全浪费了。先把 Clip Gain 调好。
  • “插了插件就一定更好”：人耳对更大的声音天然觉得更好听。“哇，插件一上就很饱满！”不，是变大了。务必用 Bypass 对比同音量再判断。
  • “负增益分级”：录得太小导致噪声“嘶——”，再叠一堆插件。就像用沾灰的镜头拍照。合适才是关键。
