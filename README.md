# Studio NOL Website

Studio NOL is a multilingual Next.js Pages Router site for the Yeonsinnae music studio. It serves localized service pages, portfolio pages, story/guide content, contact delivery, LLM index feeds, RSS, sitemap output, and Vercel cron SEO reporting.

## Stack

- Next.js 15 Pages Router
- React 19
- TypeScript
- Tailwind CSS
- react-i18next with `ko`, `en`, `zh`, `es`, `vi`, `th`, `uz`
- Markdown story content in `content/stories`
- Vercel deployment with API routes and cron

## Commands

```bash
npm run dev
npm run type-check
npm run lint
npm test -- --watchAll=false
npm run content-check:ci
npm run audit:thin:ci
npm run build
```

`npm run build` runs the production Next.js build plus the prebuild/postbuild asset and sitemap steps. It can regenerate manifests and optimized metadata, so check the git diff after every build.

## Project Layout

- `pages/`: localized Pages Router routes and API routes
- `components/`: shared UI and page sections
- `lib/`: server helpers, i18n loading, story parsing, SEO utilities, rate limiting, email helpers
- `data/`: service, pricing, portfolio, and site configuration
- `content/stories/`: Markdown story sources and frontmatter
- `public/`: static assets, locale JSON, images, icons, generated sitemap/robots output
- `scripts/`: content, SEO, manifest, image, sitemap, and audit automation

## Operational Notes

- `public/locales/*/common.json` is sliced by `i18nSections` in `buildPageStaticProps`; pages that render dynamic components must include the sections those components need.
- Contact delivery uses `pages/api/contact/send-email.ts`, Resend REST, and Redis REST-compatible `KV_REST_API_URL` / `KV_REST_API_TOKEN` rate limiting.
- Story and portfolio manifests are generated by `npm run generate:manifests`.
- GSC/GA4 investigation starts from `docs/gsc-raw/`, `docs/ga4-raw/`, `lib/seo/`, and `pages/api/cron/gsc-audit.ts`.
