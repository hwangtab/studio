# 기타 플라멩코·라스게아도·피카도 기법 — 음악연습실 완전 가이드

플라멩코 기타(Flamenco Guitar)는 **스페인 안달루시아 지방의 열정적인 기타 전통**입니다. Paco de Lucía, Vicente Amigo, Tomatito가 현대 플라멩코 기타를 세계적으로 알렸습니다. 라스게아도(Rasgueado)의 폭풍 같은 스트로크와 피카도(Picado)의 선명한 단음이 플라멩코의 두 얼굴입니다.

---

## 플라멩코 기타의 특징

### 클래시컬 vs 플라멩코

| | 클래시컬 | 플라멩코 |
|--|---------|---------|
| 자세 | 발받침 사용 | 무릎 위에 |
| 기타 | 무거운 스프루스 탑 | 가벼운 시프레스 탑 |
| 터치 | 부드럽고 정확 | 공격적이고 퍼커시브 |
| 골페 | 없음 | 탭핑 테크닉 |
| 마음 | 클래식적 절제 | 감정의 폭발 |

### 플라멩코 리듬 (Compás)

**기본 박자:**
- **솔레아(Soleá):** 12박 (3+3+2+2+2)
- **불레리아(Bulería):** 12박 빠르게
- **알레그리아(Alegría):** 12박 가볍게
- **루가레냐(Rguarena):** 4/4 기본

**팔마스(Palmas):** 손뼉으로 리듬 표시

---

## 라스게아도 (Rasgueado)

### 라스게아도란?

**라스게아도:** 여러 손가락을 연속으로 흘려서 스트로크하는 기법.

```
기본 라스게아도:
소지(a) → 약지(r) → 중지(m) → 검지(i) → 엄지(p)
= 5손가락이 빠르게 스트로크
```

**소리:** 폭풍 같은 연속 스트로크 = 플라멩코의 화려함

### 기본 라스게아도 연습

**4손가락 라스게아도:**
```
검지(i): 위에서 아래로 스트로크
중지(m): 위에서 아래로
약지(r): 위에서 아래로
소지(a): 위에서 아래로
= i-m-r-a 연속 빠르게
```

**반대 방향 포함:**
```
내리기: i-m-r-a
올리기: 엄지(p) 위로
= i-m-r-a-p 5손가락 라스게아도
```

### 라스게아도 훈련법

**단계별:**
```
1단계: 각 손가락 개별로 연습 (4분음표로)
2단계: i-m 두 손가락 연속
3단계: i-m-r 세 손가락
4단계: i-m-r-a 네 손가락
5단계: 완전한 5손가락 라스게아도
```

## 피카도 (Picado)

### 피카도란?

**피카도:** 오른손 검지와 중지를 교번하여 치는 단음 기법.

```
i-m-i-m-i-m... (교번 반복)
빠른 16분음표 스케일
= 클래시컬 기타의 연주법과 비슷
```

**플라멩코 피카도의 특징:**
- 강한 어택
- 명확한 아티큘레이션
- 빠른 속도

### 피카도 훈련

**기본 피카도:**
```
1번 줄에서:
E4-F4-F#4-G4-G#4-A4 (반음씩 상행)
i-m-i-m-i-m (교번으로)
```

**플라멩코 스케일로 피카도:**
```
프리지안 모드 (E 프리지안): E-F-G-A-B-C-D-E
빠르게 상행·하행
= 스페인적 소리
```

---

## 골페 (Golpe)

### 골페란?

**골페:** 오른손 약지 또는 소지로 현 아래(탑) 부분을 탭핑하는 타악기 효과.

```
멜로디 연주 중에
약지로 기타 몸통 윗부분을 탭
= "탁" 소리 (타악기 효과)
```

**골페 위치:**
```
기타 탑의 현 아래 부분
손상 방지를 위해 골페 플레이트 사용
```

### 골페 패턴

**기본 골페:**
```
박1: 코드 스트로크 + 박2: 골페
= 스트로크-골페-스트로크-골페
타악기 효과로 박감 강화
```

## 아포얄도 vs 알아이레

### 아포얄도 (Apoyando)

**레스트 스트로크:**
```
손가락으로 줄을 치고
다음 줄에 손가락이 닿음
= 강하고 선명한 소리
피카도에 사용
```

### 알아이레 (Al Aire)

**프리 스트로크:**
```
손가락으로 줄을 치고
공중으로 손가락이 향함
= 부드럽고 가벼운 소리
라스게아도·아르페지오에 사용
```

---

## E 프리지안 스케일

### 스페인 음계

**E 프리지안:** E-F-G-A-B-C-D

```
특징: b2 (F 자연음 = 플라멩코의 핵심)
소리: 스페인·플라멩코 특유의 감성
```

**플라멩코 기본 코드:**
```
Am: A-C-E (I 코드)
G: G-B-D (VII)
F: F-A-C (VI)
E: E-G#-B (V = 장3화음으로 해결!)
```

**E-F-G-Am 진행:**
```
E → F → G → Am (반복)
= 플라멩코의 기본 진행
```

## 기본 플라멩코 구조

### 아라베스코 (Arabesque)

플라멩코 도입부:

```
E 프리지안 스케일 상행·하행
라스게아도 소개
= 분위기 설정
```

### 파세오 (Paseo)

플라멩코의 산책 구간:

```
규칙적인 박자
코드 반복 + 라스게아도
= 댄서가 입장하는 구간
```

### 파르티도 (Partido)

감정의 절정:

```
빠른 피카도 스케일
강한 라스게아도
골페 강조
= 감정 최고조
```

## Paco de Lucía 스타일

### 현대 플라멩코의 거장

Paco de Lucía의 특징:
- **재즈 영향:** 재즈 화성과 플라멩코 결합
- **기교:** 전례 없는 피카도 속도
- **표현:** 절제와 폭발의 완벽한 균형

**Paco 스타일 피카도:**
```
매우 빠른 속도 (♩= 200+)
각 음이 선명하게
라스게아도로 갑자기 전환
```

## 음악연습실 플라멩코 기타 연습

### 60분 루틴

**1. 라스게아도 훈련 (20분)**
   - 개별 손가락 연습
   - 2→3→4→5손가락 순차로
   - E 코드에서 라스게아도

**2. 피카도 훈련 (20분)**
   - i-m 교번 단음
   - E 프리지안 스케일 상하행
   - 속도 점진적 향상

**3. 골페 연습 (10분)**
   - 탭핑 위치 확인
   - 스트로크-골페 패턴
   - 리듬 패턴 통합

**4. 기본 플라멩코 진행 (10분)**
   - E-F-G-Am 반복
   - 라스게아도 + 피카도 조합
   - 감정 표현 연습

---

## 마무리

플라멩코 기타는 **영혼의 언어**입니다. Paco de Lucía가 "플라멩코는 배우는 것이 아니라 느끼는 것"이라고 했듯이, 기술 뒤에는 항상 감정이 있어야 합니다.

은평구 24시간 음악연습실에서 라스게아도를 익히고, 피카도를 단련하세요. 언젠가 E 프리지안 스케일 위에서 자신만의 플라멩코가 흘러나올 것입니다.
