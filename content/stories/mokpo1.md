## 전남 서남부에서 KTX로 서울까지

목포는 KTX 호남선의 종착역으로, 서울까지 약 2시간 40~50분이면 도착합니다. 전남 지역 아티스트도 연신내 스튜디오 놀에서 전문 보컬 녹음을 당일 왕복으로 이용할 수 있습니다.

---

## 목포 → 연신내 이동 경로

```
① 목포역에서 KTX(호남선) 탑승 (서울역 방면)
② 서울역 도착 (약 2시간 40~50분)
③ 1호선 서울역 → 신도림 → 2호선 합정역 → 6호선 연신내역
   또는 서울역 → 경의중앙선 → 홍대입구 → 2호선 합정 → 6호선

총 소요시간: 약 3시간 10~30분
```

---

## 당일 왕복 일정 예시 (목포 기준)

```
오전 6시 30분 목포역 출발 (KTX)
→ 오전 9시 20분 서울역 도착
→ 오전 10시 10분 연신내역 도착
→ 오전 10시 30분 세션 시작 (2~3시간)
→ 오후 1시 세션 완료
→ 오후 3시 서울역 출발 (KTX)
→ 오후 5시 50분 목포역 도착
```
