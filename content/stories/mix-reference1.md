## 믹스 레퍼런스 — 객관적인 귀를 유지하는 방법

믹싱 중 오랜 시간 같은 곡을 들으면 귀가 피로해져 객관적인 판단이 어려워집니다. 레퍼런스 트랙을 활용하면 언제든 기준으로 돌아와 객관적인 비교가 가능합니다.

---

## 레퍼런스 트랙 선택 기준

```
[선택 체크리스트]
✓ 같은 장르 또는 유사한 사운드
✓ 잘 마스터링된 상업 음원 (스트리밍 히트곡)
✓ 비슷한 악기 구성 (보컬 중심, 밴드 등)
✓ 자신이 만들고자 하는 분위기

[2~3곡 준비]
→ 주 레퍼런스 (가장 유사한 사운드)
→ 보조 레퍼런스 (다른 각도 비교용)
→ 장르 레퍼런스 (시장 표준 확인)

[피해야 할 레퍼런스]
→ 오래된 음원 (마스터링 기준 변화)
→ 불법 압축된 저품질 MP3
→ 자신의 이전 작업물 (주관적 편향)
```

---

## 레퍼런스 비교 방법

```
[볼륨 매칭 (핵심)]
Step 1: Youlean Loudness Meter 또는
        iZotope Insight로 LUFS 측정
Step 2: 현재 믹스와 레퍼런스 LUFS 동일하게
Step 3: 볼륨 차이 없이 A/B 비교

[비교 포인트]
① 저역 (80~200Hz): 킥·베이스 무게
② 중역 (500Hz~3kHz): 보컬·기타 밀도
③ 고역 (5kHz~16kHz): 에어감·밝기
④ 스테레오 폭: 좌우 악기 배치
⑤ 다이나믹: 크고 작은 소리의 차이

[청취 루틴]
→ 믹스 10초 → 레퍼런스 10초 → 다시 믹스
→ 차이점 메모
→ 보정 후 다시 비교
```

## 장르별 레퍼런스 활용 팁

```
[K팝·팝]
→ 보컬 선명도 비교
→ 킥·베이스 일관성
→ 고역 에어감

[발라드]
→ 다이나믹 보존 여부
→ 보컬 감정 표현 살아있는지
→ 현악·피아노 공간감

[R&B·힙합]
→ 저역 파워
→ 보컬 질감·컴프레서
→ 808 베이스 처리

[인디·어쿠스틱]
→ 자연스러운 공간감
→ 악기 배치 실제감
→ 다이나믹 보존
```
