## 신사·가로수길·논현·압구정에서 연신내 스튜디오 놀까지

## 지역별 이동 경로

### 신사역 출발 (3호선 직통)

```
[신사역 출발 (3호선)]
① 신사역(3호선) 탑승 (구파발 방면)
② 약수 → 동대입구 → 충무로 → 을지로3가 → 종로3가 → 안국 → 경복궁
③ 독립문 → 무악재 → 홍제 → 불광 → 연신내역

총 소요시간: 약 30~38분 (직통)
```

```
[압구정역 출발 (3호선)]

② 옥수 → 금호 → 약수 → 동대입구 → 충무로 → ... → 연신내역
```
