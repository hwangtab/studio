## 영천에서 KTX로 서울까지

영천은 경북 남부 도시로, 동대구역 KTX를 통해 서울과 약 2시간 50분대로 연결됩니다. 보현산 천문대로 유명한 영천에서 당일 서울 스튜디오 방문이 가능합니다.

---

## 영천 → 연신내 이동 경로

### KTX 동대구역 경유 (권장)

야간 녹음 세션 이용 시 막차 시간을 미리 확인해두시기 바랍니다.

1. 영천 → 동대구역 (버스 약 40~50분)
2. 동대구역 KTX 탑승 (서울역 방면, 약 1시간 40분)
3. 서울역 → 지하철 → 연신내역 (약 30~40분)

- **총 소요시간**: 약 2시간 50분~3시간 10분

---

## 당일 왕복 일정 예시 (영천 기준)

대중교통 이용이 주차 걱정 없이 편리하게 방문할 수 있는 가장 좋은 방법입니다.

오전 7시 30분 영천 출발 → 동대구역 이동
오전 8시 20분 동대구역 KTX 출발
- 오전 10시 서울역 도착
- 오전 10시 40분 연신내역 도착
- 오전 11시 세션 시작 (2시간)
- 오후 1시 세션 완료
- 오후 2시 30분 서울역 출발
- 오후 4시 10분 동대구역 도착
- 오후 5시 영천 도착

## 영천 음악 씬과 서울 스튜디오

영천은 포도와 와인으로 유명한 경북 도시로 보현산천문과학관이 있습니다. 신경주역이나 대구역 KTX를 이용해 서울까지 이동합니다.
---

## 방문 전 세션 준비 가이드

1시간 30분 이상 이동 후 최상의 컨디션으로 세션에 임하려면 철저한 사전 준비가 필요합니다.

**출발 전 챙길 것:**
- [ ] 녹음할 곡의 가사·악보·MR 파일 (USB 또는 Google Drive)
- [ ] 원하는 사운드의 레퍼런스 트랙 2~3곡
- [ ] 예약 확인 캡처 + 교통편 티켓
- [ ] 보컬: 따뜻한 차·꿀물 보온병, 간식
- [ ] 귀마개 또는 노이즈캔슬링 이어폰 (이동 중 성대 보호)

**이동 중 활용법:**
- 이어폰으로 녹음할 곡 2~3회 예습
- 가사·감정 포인트 집중 정리
- 목·어깨 스트레칭 (장시간 이동 피로 완화)
- 충분한 수분 섭취 (기차 이동 중 성대 건조 방지)

**세션 팁:**
- 도착 후 20~30분 워밍업 시간 확보 (일정 계획 시 반드시 포함)
- 가장 중요한 구간을 세션 초반(이동 피로 전)에 먼저 녹음
- 원하는 사운드를 레퍼런스 곡으로 구체적으로 설명
- 온라인 파일 의뢰 서비스 병행 시 재방문 부담 최소화 가능

## 세션 당일 체크리스트

**전날:**
- [ ] MR·가사·레퍼런스 트랙 파일 최종 확인
- [ ] 교통편 티켓 + 예약 확인 캡처
- [ ] 충분한 수면 + 성대 무리 금지

**출발 전:**
- [ ] 따뜻한 차·꿀물 지참
- [ ] 이동 중 성대 보호 (소리 지르기 금지, 수분 섭취)

**도착 후:**
- [ ] 20~30분 워밍업 확보 (일정에 미리 포함)
- [ ] 엔지니어에게 레퍼런스·사운드 방향 설명
- [ ] 가장 어려운 구간 최우선 녹음

**녹음 중:**
- [ ] 헤드폰 볼륨 확인
- [ ] 테이크마다 즉시 청취
- [ ] 막차 시간 미리 확인 (귀가 일정)

## 마치며

영천에서 동대구역 KTX를 이용하면 약 3시간 내로 서울 연신내까지 이동할 수 있습니다. KTX 이동 피로가 있을 수 있으므로 세션 전 워밍업 시간을 여유롭게 확보하시길 권장합니다.
