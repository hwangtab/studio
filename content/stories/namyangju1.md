## 남양주·구리·퇴계원에서 전문 녹음실 찾기

경기도 남양주·구리·퇴계원·다산신도시·별내 지역은 서울 도심까지 대중교통으로 1시간 내외 거리입니다. 전문 보컬 녹음과 음반 제작을 위해 스튜디오 놀을 방문하거나 온라인으로 파일을 전송해 서비스를 이용할 수 있습니다.

---

## 각 지역에서 스튜디오 놀까지

| 출발지 | 교통편 | 소요 시간 |
|--------|--------|---------|
| 구리역 (경의중앙선) | 왕십리 → 5호선 공덕 → 6호선 연신내 | 약 50~60분 |
| 도농역 | 경의중앙선 → 왕십리 → 환승 → 연신내 | 약 55분~1시간 |
| 다산역 | 경의중앙선 → 왕십리 → 환승 → 연신내 | 약 1시간~1시간 10분 |
| 별내역 (경춘선) | 상봉역 → 7호선 → 환승 → 연신내 | 약 1시간~1시간 20분 |
| 퇴계원 | 버스 → 노원·청량리 환승 → 연신내 | 약 1시간~1시간 20분 |
| 마석역 | 경춘선 → 상봉 → 환승 → 연신내 | 약 1시간 20분~1시간 40분 |

**스튜디오 주소**: 서울특별시 은평구 (연신내역 3번 출구 도보 5분)
