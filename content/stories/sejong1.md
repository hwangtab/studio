## 세종에서 KTX로 2시간이면

세종시는 KTX 오송역을 통해 서울과 1시간 30~40분대로 연결됩니다. 충청권에서 서울 스튜디오 접근성이 가장 좋은 도시 중 하나입니다.

---

## 세종 → 연신내 이동 경로

### KTX 오송역 경유 (권장)

```
① 세종 시내 → 오송역 (버스·택시 약 20~30분)
② 오송역에서 KTX 탑승 (서울역 방면, 약 40~50분)
③ 서울역 도착 → 지하철 환승 → 연신내역

총 소요시간: 약 1시간 30~40분
```

### 고속버스 경유

```
① 세종 버스터미널 출발
② 서울 강남터미널 도착 (약 1시간 20~30분)
③ 3호선 → 환승 → 연신내역 (약 30~40분)

총 소요시간: 약 2시간
```

## 당일 왕복 일정 예시 (세종 기준)

```
오전 8시 세종 출발 → 오송역
오전 8시 30분 오송역 KTX 출발
→ 오전 9시 20분 서울역 도착
→ 오전 10시 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 서울역 출발
→ 오후 2시 50분 오송역 도착
→ 오후 3시 30분 세종 도착
```

