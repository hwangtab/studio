## 라이브는 준비된 자의 무대입니다

유튜브 라이브, 인스타 라이브, 트위치 방송… 모든 라이브 방송은 실시간이라 편집이 없습니다. 방음 개인실에서 실제 방송과 동일한 조건으로 예행연습하세요.

라이브 방송 준비의 특징:
- **연속성**: 중간에 멈추지 않는 훈련
- **회복력**: 실수 후 자연스럽게 이어가기
- **소통 준비**: MC 멘트·곡 설명 준비
- **시간 관리**: 정해진 방송 길이 맞추기

---

## 라이브 방송 셋리스트 구성법

### 기본 원칙
- 첫 곡: 자신 있는 곡 (안정적 시작)
- 중반: 대표곡·하이라이트
- 마무리: 여운 있는 곡 또는 유명 커버

### 60분 라이브 구성 예시

| 순서 | 내용 | 시간 |
|-----|------|------|
| 오프닝 | 인사 + 워밍업 곡 | 5분 |
| 본 공연 | 4~6곡 | 35분 |
| 소통 시간 | 댓글 읽기·질문 답변 | 10분 |
| 마무리 곡 | 1~2곡 | 8분 |
| 엔딩 | 인사 | 2분 |

**방음 개인실 예행연습 (1회)**
- [ ] 셋리스트 전체 중단 없이 완주
- [ ] MC 멘트 자연스럽게
- [ ] 실수 후 자연스럽게 이어가는 연습 (의도적 실수)
- [ ] 전체 시간 체크

**기술 테스트 (방송 당일)**
- [ ] 인터넷 연결 안정성
- [ ] 마이크·카메라 음질 확인
- [ ] 배경·조명 세팅
- [ ] 10분 사전 라이브 테스트

## 라이브 방송 연습 루틴

1. **개인 연습 단계**: 각 곡 완성도 90% 이상
2. **연속 완주 단계**: 셋리스트 처음부터 끝 중단 없이
3. **MC 통합 단계**: 곡 사이 멘트 자연스럽게
4. **오디오 테스트**: 스마트폰 녹화 후 음질 확인
5. **최종 리허설**: D-1에 전체 예행연습 1회

### 효율적인 연습을 위한 원칙

좋은 연습 습관이 실력 향상의 핵심입니다.

1. **목표 설정** — 오늘 연습에서 달성할 구체적인 목표 1개를 정하고 시작
2. **분리 연습** — 어려운 구간은 전체 반복보다 해당 2~4마디만 집중
3. **속도 조절** — 완벽하지 않은 기법을 빠른 속도로 반복하면 잘못된 근육 기억만 강화됨

### 연습 중 자주 하는 공통 실수

1. **어려운 구간을 피해서 쉬운 곳만 반복** — 불편한 구간이 실력 향상의 지점
2. **메트로놈 없이 빠른 속도 연습** — 느린 속도의 정확성이 빠른 속도의 기반
3. **연습 시간만 늘리고 내용은 방치** — 30분 집중 연습이 2시간 멍하니 반복보다 효과적

### 연습 자가 진단

- [ ] 오늘의 목표를 시작 전에 정했는가?
- [ ] 어려운 구간을 분리해서 집중 반복했는가?
- [ ] 연습 후 무엇이 개선되었는지 구체적으로 인식하는가?



## 4주 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 점검 | 기본기 복습, 문제 구간 파악 | 40분 |
| 2주차 | 구간 집중 | 어려운 부분 느린 템포 반복 | 45분 |
| 3주차 | 전체 흐름 | 전곡 연결, 템포 단계적 올리기 | 50분 |
| 4주차 | 완성 | 목표 템포 + 표현·다이나믹 완성 | 60분 |

**주간 체크포인트:** 1주차: 약점 구간 3개 목록 작성 / 2주차: 각 구간 느린 템포 100% 달성 / 3주차: 전곡 끊김 없이 완주 / 4주차: 청중 앞 또는 녹음으로 최종 확인


## 연습실 최대한 활용하는 법

**시간별 추천 구성 (1시간 기준):**
- 0~10분: 워밍업 (스트레칭, 기본 음계 또는 개방현)
- 10~45분: 목표 구간 집중 연습 (어렵고 중요한 부분 먼저)
- 45~55분: 전곡 런스루 (흐름·감정 표현 포함)
- 55~60분: 쿨다운 + 다음 연습 목표 메모

**방음 환경에서만 가능한 연습:**
- 최대 볼륨·최대 다이나믹 표현 (집에서 불가)
- 큰 소리로 가사 암송 + 발음 교정
- 틀렸을 때 즉각 멈추고 되돌아가는 구간 반복 훈련
