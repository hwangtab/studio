在韩国生活过一段时间的华人，对首尔地铁通常都不陌生——刷一张 T-money 卡，跟着指示牌走，三换两换基本都能到。但当你第一次要去某个不熟悉的区，或者从外地带朋友、家人来首尔录音、上课的时候，"怎么去延新内"这个问题还是会让人愣一下。Studio NOL 位于首尔西北部的恩平区延新内 (Yeonsinnae, 연신내)，属于地铁 3号线沿线，从市区大多数地方都能在 40 分钟内到达，从京畿和仁川出发也都有比较省力的路线。

这篇文章就是把"从哪里出发，怎么走最省时省事"整理清楚，方便你自己第一次来，也方便你把链接转给打算来录音、上课、租练习室的朋友。如果你还没看过我们的总指南，建议先读 [在韩华人音乐人首尔录音完全攻略](/zh/stories/recording-in-seoul-for-chinese-musicians)，再回到这篇看交通。

## Studio NOL 在哪里

- **行政区**：首尔特别市 恩平区 延新内 (서울특별시 은평구 연신내)
- **最近地铁站**：延新内站 (Yeonsinnae Station, 연신내역)，3号线 (3호선) 与 6号线交汇
- **出口**：4 号出口出来步行约 5 分钟
- **邻近站**：不光站 (Bulgwang, 불광역) 也在步行可达范围内，从不光站走过来约 12-15 分钟

延新内这个区算是首尔西北部的"老牌生活区"——3号线把它串到钟路、忠武路、教大、高速终点站、再南下到一山，6号线又把它和合井、上水、梨大、孔德、首尔站后段连起来，所以无论你住在弘大附近还是江南方向，换一次车基本都能到。地铁站出来之后周边有连锁咖啡厅、便利店、几家小餐馆，所以即使你提前半小时到，也不会无处落脚。

**Naver Maps / KakaoMap 小提示**：在导航 app 里直接搜中文"Studio NOL"有时候搜不到，比较稳妥的做法是把韩文地址或英文 "Studio NOL Yeonsinnae" 复制粘贴进去。第一次预约确认后，我们一般会在 KakaoTalk 里直接发一个 Naver Maps 短链，那个最准。

## 从首尔市内出发

首尔市内大多数地方过来都不超过一小时，关键是看你怎么换车。延新内站本身是 3号线和 6号线交汇站，所以最实用的策略就是想办法换到这两条线中的任意一条。

- **弘大 / 新村 (Hongdae / Sinchon)**：2号线坐到合井 (合井站, 6号线换乘) 直接换 6号线北上一站到延新内，全程约 30-35 分钟，最省事。也可以从弘大入口坐机场铁路 (空港铁道) 到首尔数字媒体城 (DMC) 再换 6号线，时间差不多。
- **江南 (Gangnam)**：江南站本身是 2号线，3号线不经过江南站。最稳妥的路线是 2号线江南 → 教大站换 3号线 → 直接坐到延新内，约 35-45 分钟。
- **蚕室 (Jamsil)**：8号线和 3号线没有直接换乘站。推荐 2号线坐到教大或乙支路 3 街换 3号线，全程约 45-55 分钟。
- **梨泰院 (Itaewon)**：直接 6号线绕一圈到延新内（经过应岩 (응암) 循环线一段），约 35-45 分钟，全程不用换车。
- **首尔站 (Seoul Station)**：1号线或 4号线坐到忠武路 (忠武路站) 换 3号线，全程约 25-35 分钟。也可以坐 4号线 → 忠武路 → 3号线。
- **钟路 / 仁寺洞 (Jongno / Insadong)**：3号线安国站、景福宫站、独立门站附近直接坐 3号线过来，约 20-25 分钟，是市区最近的一条线之一。

如果你拖着乐器（吉他、小型键盘），建议避开早高峰 8-9 点和晚高峰 6-7 点，那两个时段 3号线和 6号线都非常挤，乐器盒会让你被人群挤得很无奈。

## 从京畿 (郊区) 出发

很多在韩华人住在京畿道——孩子在那边上学、租金便宜、或者公司在那一带。从京畿过来 Studio NOL 并不远：

- **高阳 (Goyang)、一山 (Ilsan)**：地理上离延新内最近。3号线日山线从大化、注叶、白石、马头、汀馆 (마두/정발산) 一路坐过来都不用换车，约 20-30 分钟。这条是最舒服的一条路。
- **富川 (Bucheon)**：1号线坐到新道林 (新道林站) 换 2号线 → 在乙支路 3 街换 3号线，全程约 50-70 分钟。也可以 1号线 → 富平区厅换 7号线 → 高速终点站 (高速터미널) 换 3号线，时间相近。
- **水原 (Suwon)**：1号线北上到首尔站，再走过去换 4号线 → 忠武路换 3号线，全程 60-90 分钟。带乐器的话建议从水原坐 ITX 到首尔站，比纯 1号线快 20 分钟左右。
- **城南 (Seongnam) / 盆唐 (Bundang)**：从盆唐线直接坐到水西 (수서站) 换 3号线，或者坐到道谷 (도곡站) 换 3号线，全程约 50-70 分钟。新盆唐线的话可以坐到江南后转 2号线 → 教大换 3号线。
- **议政府 (Uijeongbu)**：1号线南下到钟路 3 街换 3号线，约 50-60 分钟。也可以 1号线 → 石溪 (석계站) 换 6号线，最后到延新内，时间相近。

这些时间都是地铁 + 步行的大致估算，遇到周末或者天气恶劣时建议多预留 15-20 分钟。

## 从仁川和机场出发

如果你住在仁川，或者是从仁川机场直接过来（比如刚下飞机的华人朋友来录纪念录音、找你一起做项目），路线稍微长一点，但依然有清晰选项：

- **仁川机场 (ICN)**：最推荐 AREX (机场铁路, 공항철도) 普通列车坐到首尔数字媒体城 (DMC, 디지털미디어시티) 直接换 6号线 → 一站到延新内，全程约 70-90 分钟，是从机场过来最快的地铁组合。如果你赶时间可以坐 AREX 直达列车到首尔站，再换 4号线 → 忠武路换 3号线，时间相近但要多换一次。
- **金浦机场 (GMP)**：从金浦机场过来推荐机场铁路坐到 DMC 换 6号线 → 延新内，约 30-40 分钟。如果你是坐 5号线，可以走光化门方向到钟路 3 街换 3号线，时间略长但不用走机场铁路。如果你是从国内（北京 / 上海）直飞金浦的，这条线相当友好。
- **仁川市内 (Incheon City)**：1号线坐到新道林换 2号线 → 在乙支路 3 街或忠武路换 3号线，全程约 70-90 分钟。带大件乐器的话可以考虑直接打车到机场铁路青罗国际城 (청라국제도시) 站，再坐 AREX → DMC 换 6号线。
- **打车 / 出租车**：从仁川机场直接打车到延新内大约 ₩70,000-90,000 韩元，遇到堵车甚至更贵，所以除非是夜班航班实在没地铁，否则 AREX + 6号线 (经 DMC 换乘) 性价比更高。

## 到达后

走到延新内 4 号出口之后，请用 KakaoTalk 给我们发个消息，我们会根据你那天上课/录音/练习的房间，发具体的小巷子入口照片或者一段 30 秒的语音引导。延新内附近的小巷子有点错综复杂，但一旦走过一次就再也不会迷路。

附近有几家相对安静的咖啡厅可以让你提前到、调整一下状态，也有便利店补水、买耳塞。**停车位非常有限**——延新内是老社区，路边停车基本靠运气，建议把车停在一山或不光的公共停车场再换地铁过来。

带乐器和器材的话，电梯都是正常运作的，不用担心要扛着上楼。如果你带了重型设备（鼓、键盘、音箱），提前在 KakaoTalk 告诉我们一声，我们会帮你协调装卸位置。

## FAQ

**Q：完全不会韩文，需要装翻译 app 吗？**
A：装一个 Papago 或 Google 翻译应急当然不错，但其实并不是必需的。Studio NOL 全程支持中文和英文沟通，从预约、确认到现场对接都没问题；首尔地铁站名也都标注了汉字和英文，跟着 3号线走基本不会迷路。

**Q：几点到 studio 最合适？**
A：建议比预约时间提前 10-15 分钟到，可以稍微休息、调音、暖嗓。如果你坐 3号线过来，尽量避开早高峰 8-9 点和晚高峰 6-7 点，那两个时段地铁拥挤，带乐器的话很不舒服。

**Q：能开车过来吗？停车位有吗？**
A：可以开车，但延新内是老城区，街边停车非常有限，路也比较窄。强烈建议把车停在地铁周边大一点的换乘停车场（比如一山方向的公共停车），再地铁过来。

**Q：从机场过来要不要直接打车？**
A：仁川机场打车到延新内大约 ₩70,000 起，遇到首尔市内堵车随时可能突破 ₩90,000。AREX (机场铁路) + 6号线 (在 DMC 换乘) 虽然要换一次车，但更快也更便宜，是大多数华人音乐人推荐的方案。如果是金浦机场过来，可以走机场铁路 → DMC → 6号线 → 延新内，约 30-40 分钟。
