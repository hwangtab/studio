## 평택시 송탄·팽성·진위에서 연신내 스튜디오 놀까지

평택시 남부 송탄·팽성·진위·서정리 지역은 1호선을 이용해 수도권과 연결됩니다. 신도림역에서 2호선 합정역 경유 후 6호선으로 연신내역까지 약 80~100분에 이동할 수 있습니다.

---

## 송탄·서정리 → 연신내 이동 경로

### 1호선 급행 경유 (권장)

세션 시작 전 파일 정리와 프로젝트 백업 습관이 데이터 손실을 막아줍니다.

1. 서정리역 또는 송탄역(1호선) 탑승 — 급행 서울 방면
2. 수원역·안양역 경유 → 신도림역 하차
3. 2호선 내선순환 환승 → 합정역 하차
4. 6호선 환승 → 연신내역 도착

- **총 소요시간**: 약 80~95분 (급행 기준)

### 1호선 일반 경유

1. 서정리역 또는 진위역(1호선) 탑승
2. 수원역 이후 일반 열차로 신도림역 이동
3. 2호선 → 합정역 → 6호선 → 연신내역

- **총 소요시간**: 약 90~105분 (일반 기준)

| 출발 지점 | 경로 | 소요 시간 |
|---------|------|---------|
| 서정리역 (1호선 급행) | 신도림 → 2호선 → 합정 → 6호선 | 약 80~95분 |
| 송탄역 (1호선 급행) | 신도림 → 2호선 → 합정 → 6호선 | 약 85~100분 |
| 진위역 (1호선) | 신도림 → 2호선 → 합정 → 6호선 | 약 85~100분 |
| 평택역 (1호선 급행) | 신도림 → 2호선 → 합정 → 6호선 | 약 90~105분 |

## 당일 왕복 일정 예시 (서정리역 기준)

녹음 전 게인과 마이크 위치를 정확히 잡아두면 후반 작업이 크게 줄어듭니다.

오전 8시 30분 서정리역 출발 (1호선 급행)
- 오전 10시 연신내역 도착
- 오전 10시 10분 세션 시작 (2시간)
- 오후 12시 10분 세션 완료
- 오후 1시 30분 연신내역 출발
- 오후 3시 서정리역 도착
