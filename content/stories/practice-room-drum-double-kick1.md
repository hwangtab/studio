# 드럼 더블 킥·더블 배스 드럼 훈련 — 음악연습실 완전 가이드

더블 킥은 드러머의 발 독립성을 최고 수준으로 끌어올리는 기술입니다. **오른발 + 왼발 교대로 킥드럼을 빠르게 연주**하는 이 기법은 메탈, 프로그레시브 록, 빠른 팝에서 핵심 기술입니다. 더블 페달 또는 두 개의 킥드럼으로 구현하는 더블 킥의 체계적 훈련법을 안내합니다.

---

## 더블 킥 기초 이해

### 더블 페달 vs 더블 킥 드럼

**더블 페달 (Double Bass Pedal):**
- 하나의 킥드럼에 두 개의 페달 연결
- 이동이 편리
- 현대 드럼 셋의 일반적 선택

**더블 킥 드럼:**
- 두 개의 별도 킥드럼
- John Bonham, Neil Peart 스타일
- 더 넓은 사운드 확산

### 더블 킥의 발 메카니즘

**힐-업 (Heel-Up) 기법:**
- 발뒤꿈치를 들고 앞꿈치로 페달 조작
- 더 강한 파워
- 빠른 패턴에 적합

**힐-다운 (Heel-Down) 기법:**
- 발뒤꿈치를 페달에 고정하고 발목으로 조작
- 컨트롤이 쉽지만 파워 약함
- 느린 패턴이나 섬세한 조작에

---

## 발 독립성 기초 훈련

### 오른발 단독 훈련

먼저 오른발(주발)을 완벽히 훈련:

**패턴 1: 8분음표**
```

박 1: R(킥)
박 1-and: R(킥)
박 2: R(킥)
...

```

BPM 60에서 시작.

**패턴 2: 16분음표**
```
1-e-and-ah: 모두 R(킥) 타격
BPM 60에서 4박 동안 16개

```

### 왼발 단독 훈련

왼발(보조발)은 처음에 훨씬 약함:

**패턴 1: 천천히 4분음표**
```

박 1: L(킥)
박 2: L(킥)
...BPM 40에서 시작

```

**집중 훈련:**

왼발만으로 최소 5분씩 매일 연습. 몇 주 내에 왼발이 강해집니다.

---

## 더블 킥 핵심 패턴

### 기본 교대 패턴 (Alternating)

```

R-L-R-L-R-L-R-L (8분음표)
BPM 60에서 BPM 100까지

```

**16분음표 교대:**
```

R-L-R-L-R-L-R-L-R-L-R-L-R-L-R-L (16개)
BPM 60에서 BPM 80까지

```

### 갤로핑 더블 킥

Iron Maiden 스타일:

```

R-R-L (삼연음표 느낌)
R-R-L-R-R-L-R-R-L

```

### 더블 킥 + 손 독립성

손으로 리듬 패턴 유지하면서 발로 더블 킥:

**기본 통합 패턴:**
```

오른손(라이드): ♩ ♩ ♩ ♩ (4분음표)
왼손(스네어): 박 2, 4
오른발+왼발: R-L-R-L (8분음표)

```

---

## 속도 증가 방법

### BPM 피라미드

```
2주 훈련 사이클:
BPM 60: 1주 완전 마스터
BPM 70: 4일
BPM 80: 3일
BPM 90: 쉬어가기 후 도전

```

### 클릭 없이 vs 클릭과 함께

1. **클릭 없이**: 자신의 자연스러운 속도 파악
2. **클릭과 함께**: 정확한 타이밍 훈련
3. **드럼 루프와 함께**: 음악적 맥락에서 훈련

---

## 발 컨트롤 세팅

### 페달 세팅

**스프링 장력:**
- 느슨하게: 빠른 반동, 컨트롤 어려움
- 팽팽하게: 느린 반동, 강한 어택

**비터 앵글:**
- 위로: 더 강한 타격
- 아래로: 더 빠른 반동

### 발 위치

**발 위치에 따른 사운드:**
- 앞꿈치 중앙: 균형 잡힌 타격
- 앞꿈치 끝: 날카롭고 빠름
- 발 전체: 두텁고 강함

---

## 음악연습실 더블 킥 연습 루틴

### 1단계: 발 기초 (30분)

1. 오른발 단독 16분음표 BPM 60 (10분)
2. 왼발 단독 8분음표 BPM 40 (10분)
3. 교대 8분음표 BPM 60 (10분)

### 2단계: 패턴 통합 (30분)

1. 교대 16분음표 BPM 70 (10분)
2. 갤로핑 패턴 BPM 80 (10분)
3. 손+발 독립성 기초 (10분)

### 3단계: 음악 적용 (30분)

1. 메탈 곡 더블 킥 구간
2. 빠른 록 연주에서 더블 킥 삽입
3. 녹음 후 좌우 균형 체크

---

## 마무리

더블 킥 마스터는 몇 달의 집중 훈련이 필요합니다. 특히 왼발 강화에 많은 시간을 투자하세요. 오른발과 왼발이 균형을 이룰 때 진정한 더블 킥 그루브가 탄생합니다.

은평구 24시간 음악연습실에서 페달 앞에 충분한 시간을 투자하고 더블 킥의 파워를 완성하세요.
