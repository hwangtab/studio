# 드럼 재즈 왈츠·3박자 스윙 — 음악연습실 완전 가이드

재즈에서 3/4박자(왈츠)는 4/4박자와는 완전히 다른 음악적 감성을 지닙니다. 특히 빌 에반스 트리오, 오스카 피터슨의 왈츠 연주는 재즈의 서정성이 극대화된 아름다움을 보여줍니다. 이 가이드에서는 재즈 왈츠의 드럼 기법을 체계적으로 안내합니다.

---

## 재즈 왈츠의 특성

### 4/4 스윙 vs 3/4 왈츠

**4/4 스윙:**
- 2박, 4박 강조
- 스윙 8분음표 리듬
- 라이드 심벌에서 X .X .X .X

**3/4 왈츠:**
- 1박 강조 (대신 가볍게)
- 2박, 3박은 더 가볍게
- 라이드 패턴이 완전히 달라짐

### 왈츠의 리듬 그루브

**3박자 느낌:**
```
1 → 강 (다운비트)
2 → 약 (업비트)
3 → 중간 (또는 약)

```

느려질수록 1박이 더 명확히 느껴집니다.

---

## 기본 재즈 왈츠 패턴

### 라이드 심벌 왈츠 패턴

**기본 3/4 라이드:**
```

라이드: X . X X . X
       1 2 3 1 2 3

```

또는:

```

라이드: X . X . X .
       1   2   3

```

**하이햇 왈츠:**
```

하이햇 (발): 1박에만 닫기
또는: 1, 3박에 닫기

```

### 스네어 왈츠 배치

**기본 배치:**
```

스네어: . X . (2박 악센트)

```

**재즈 왈츠 변형:**
```

스네어: . . X (3박 악센트)
또는: . X X (2+3박)

```

---

## 브러시 왈츠

### 브러시 서클링 왈츠

4/4 브러시와 달리 3/4는 3박에 맞는 서클 패턴:

**오른손 3박 서클:**
```

박 1: 12시에서 시작
박 2: 4시 (약 1/3 회전)
박 3: 8시 (2/3 회전)
(다음 1박: 다시 12시)

```

**왼손 탭:**
```

박 2 또는 박 3에 가벼운 탭

```

### 빌 에반스 트리오 스타일

**폴 모티안(Paul Motian) 접근법:**
- 매우 자유로운 브러시 움직임
- 박자를 엄격히 지키지 않는 프리 감각
- 피아노와의 대화적 인터플레이

```

오른손: 자유로운 스윕 (3박 루프)
왼손: 응답하는 탭과 고스트 노트
발: 매우 조용한 하이햇

```

## 왈츠 대표 곡 드럼 분석

### "My Favorite Things" (John Coltrane)

**3/4박자 라이드 그루브:**
```

라이드: X . X X . X . X X
       1   2+  3   1   2+  3

```

업비트(+)에 탭이 추가되어 스윙 느낌 강화

### "Alice in Wonderland" (빌 에반스)

**매우 부드러운 브러시 왈츠:**
```

라이드: . . X . . X . . X
       1 2 3 1 2 3 1 2 3
(3박 악센트)

```

느리고 섬세한 스윙

---

## 왈츠에서의 솔로

### 3박 기반 필

왈츠에서 필은 박자 인식을 방해하지 않아야:

```
3박 기반 필:
박 3: 탐탐 런 (3박에서 다음 박 1로)

```

**트리플렛 활용:**
```

박 2-3: 6연음 (2개의 3연음) = 4개의 탐탐

```

## 음악연습실 왈츠 루틴

### 60분 루틴

**1. 3박자 카운팅 (10분)**
- BPM 60에서 '1-2-3' 소리내어 카운트
- 발로 1박 탭핑

**2. 기본 왈츠 라이드 (20분)**
- X .X .X 라이드 패턴
- 왼발 하이햇 1박 추가

**3. 브러시 왈츠 (20분)**
- 오른손 3박 서클
- 왼손 탭 추가

**4. 음원 청취 (10분)**
- 빌 에반스 "Waltz for Debby" 청취 + 드럼 집중

## 마무리

재즈 왈츠는 **4/4박자의 직선적 스윙과는 다른 둥글고 서정적 에너지**를 가집니다. 1박에서 자연스럽게 흘러내리는 느낌, 브러시로 그리는 섬세한 서클—이것이 재즈 왈츠의 본질입니다.

은평구 24시간 음악연습실에서 빌 에반스의 "Waltz for Debby"를 들으며 그 느낌을 귀에 먼저 새기세요. 그 감성을 기억하고 드럼으로 표현하는 것이 올바른 출발점입니다.

드럼 연습에서 기초 루디먼트는 절대 간과해서는 안 될 핵심 요소입니다. 싱글 스트로크, 더블 스트로크, 패러디들을 꾸준히 연습하면 양손 밸런스가 균등하게 발전합니다. 메트로놈 없이 연습하는 습관은 박자 안정성을 해치므로 항상 클릭 트랙을 활용하는 것이 좋습니다. 처음에는 느린 템포부터 시작해 정확도가 높아지면 점차 BPM을 올려가는 방식이 효과적입니다. 드럼 패드에서 충분히 익힌 뒤 실제 드럼 세트로 전환하면 습득 속도가 크게 빨라집니다. 규칙적인 연습 루틴을 만들고 꾸준히 유지하는 것이 단기간의 집중 연습보다 장기적으로 더 큰 효과를 만들어냅니다. 하루 30분씩 매일 연습하는 것이 주말에만 3시간씩 연습하는 것보다 신체 기억과 음악적 감각 형성에 훨씬 유리합니다. 연습 중 어려운 부분에 막힐 때는 천천히, 더 작은 단위로 나눠 반복하는 것이 돌파구가 됩니다. 목표 악기와 음악 스타일에 맞는 연습 방법을 지속적으로 탐구하고 실험하는 자세가 장기적인 성장의 원동력입니다.
