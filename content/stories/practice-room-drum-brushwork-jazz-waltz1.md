# 드럼 재즈 왈츠·3박자 스윙 — 음악연습실 완전 가이드

재즈에서 3/4박자(왈츠)는 4/4박자와는 완전히 다른 음악적 감성을 지닙니다. 특히 빌 에반스 트리오, 오스카 피터슨의 왈츠 연주는 재즈의 서정성이 극대화된 아름다움을 보여줍니다. 이 가이드에서는 재즈 왈츠의 드럼 기법을 체계적으로 안내합니다.

---

## 재즈 왈츠의 특성

### 4/4 스윙 vs 3/4 왈츠

**4/4 스윙:**
- 2박, 4박 강조
- 스윙 8분음표 리듬
- 라이드 심벌에서 X .X .X .X

**3/4 왈츠:**
- 1박 강조 (대신 가볍게)
- 2박, 3박은 더 가볍게
- 라이드 패턴이 완전히 달라짐

### 왈츠의 리듬 그루브

**3박자 느낌:**
```
1 → 강 (다운비트)
2 → 약 (업비트)
3 → 중간 (또는 약)
```

느려질수록 1박이 더 명확히 느껴집니다.

---

## 기본 재즈 왈츠 패턴

### 라이드 심벌 왈츠 패턴

**기본 3/4 라이드:**
```
라이드: X . X X . X
       1 2 3 1 2 3
```

또는:
```
라이드: X . X . X .
       1   2   3
```

**하이햇 왈츠:**
```
하이햇 (발): 1박에만 닫기
또는:        1, 3박에 닫기
```

### 스네어 왈츠 배치

**기본 배치:**
```
스네어: . X . (2박 악센트)
```

**재즈 왈츠 변형:**
```
스네어: . . X (3박 악센트)
또는:   . X X (2+3박)
```

---

## 브러시 왈츠

### 브러시 서클링 왈츠

4/4 브러시와 달리 3/4는 3박에 맞는 서클 패턴:

**오른손 3박 서클:**
```
박 1: 12시에서 시작
박 2: 4시 (약 1/3 회전)
박 3: 8시 (2/3 회전)
(다음 1박: 다시 12시)
```

**왼손 탭:**
```
박 2 또는 박 3에 가벼운 탭
```

### 빌 에반스 트리오 스타일

**폴 모티안(Paul Motian) 접근법:**
- 매우 자유로운 브러시 움직임
- 박자를 엄격히 지키지 않는 프리 감각
- 피아노와의 대화적 인터플레이

```
오른손: 자유로운 스윕 (3박 루프)
왼손: 응답하는 탭과 고스트 노트
발: 매우 조용한 하이햇
```

---

## 왈츠 대표 곡 드럼 분석

### "My Favorite Things" (John Coltrane)

**3/4박자 라이드 그루브:**
```
라이드: X . X X . X . X X
       1   2+  3   1   2+  3
```

업비트(+)에 탭이 추가되어 스윙 느낌 강화

### "Alice in Wonderland" (빌 에반스)

**매우 부드러운 브러시 왈츠:**
```
라이드: . . X . . X . . X
       1 2 3 1 2 3 1 2 3
(3박 악센트)
```

느리고 섬세한 스윙

---

## 왈츠에서의 솔로

### 3박 기반 필

왈츠에서 필은 박자 인식을 방해하지 않아야:

```
3박 기반 필:
박 3: 탐탐 런 (3박에서 다음 박 1로)
```

**트리플렛 활용:**
```
박 2-3: 6연음 (2개의 3연음) = 4개의 탐탐
```

---

## 음악연습실 왈츠 루틴

### 60분 루틴

**1. 3박자 카운팅 (10분)**
- BPM 60에서 '1-2-3' 소리내어 카운트
- 발로 1박 탭핑

**2. 기본 왈츠 라이드 (20분)**
- X .X .X 라이드 패턴
- 왼발 하이햇 1박 추가

**3. 브러시 왈츠 (20분)**
- 오른손 3박 서클
- 왼손 탭 추가

**4. 음원 청취 (10분)**
- 빌 에반스 "Waltz for Debby" 청취 + 드럼 집중
