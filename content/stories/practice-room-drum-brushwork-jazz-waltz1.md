# 드럼 재즈 왈츠·3박자 스윙 — 음악연습실 완전 가이드

재즈에서 3/4박자(왈츠)는 4/4박자와는 완전히 다른 음악적 감성을 지닙니다. 특히 빌 에반스 트리오, 오스카 피터슨의 왈츠 연주는 재즈의 서정성이 극대화된 아름다움을 보여줍니다. 이 가이드에서는 재즈 왈츠의 드럼 기법을 체계적으로 안내합니다.

---

## 재즈 왈츠의 특성

### 4/4 스윙 vs 3/4 왈츠

**4/4 스윙:**
- 2박, 4박 강조
- 스윙 8분음표 리듬
- 라이드 심벌에서 X .X .X .X

**3/4 왈츠:**
- 1박 강조 (대신 가볍게)
- 2박, 3박은 더 가볍게
- 라이드 패턴이 완전히 달라짐

### 왈츠의 리듬 그루브

**3박자 느낌:**
```
1 → 강 (다운비트)
2 → 약 (업비트)
3 → 중간 (또는 약)

```

느려질수록 1박이 더 명확히 느껴집니다.

---

## 기본 재즈 왈츠 패턴

### 라이드 심벌 왈츠 패턴

**기본 3/4 라이드:**
```

라이드: X . X X . X
       1 2 3 1 2 3

```

또는:

```

라이드: X . X . X .
       1   2   3

```

**하이햇 왈츠:**
```

하이햇 (발): 1박에만 닫기
또는: 1, 3박에 닫기

```

### 스네어 왈츠 배치

**기본 배치:**
```

스네어: . X . (2박 악센트)

```

**재즈 왈츠 변형:**
```

스네어: . . X (3박 악센트)
또는: . X X (2+3박)

```

---

## 브러시 왈츠

### 브러시 서클링 왈츠

4/4 브러시와 달리 3/4는 3박에 맞는 서클 패턴:

**오른손 3박 서클:**
```

박 1: 12시에서 시작
박 2: 4시 (약 1/3 회전)
박 3: 8시 (2/3 회전)
(다음 1박: 다시 12시)

```

**왼손 탭:**
```

박 2 또는 박 3에 가벼운 탭

```

### 빌 에반스 트리오 스타일

**폴 모티안(Paul Motian) 접근법:**
- 매우 자유로운 브러시 움직임
- 박자를 엄격히 지키지 않는 프리 감각
- 피아노와의 대화적 인터플레이

```

오른손: 자유로운 스윕 (3박 루프)
왼손: 응답하는 탭과 고스트 노트
발: 매우 조용한 하이햇

```

---

## 왈츠 대표 곡 드럼 분석

### "My Favorite Things" (John Coltrane)

**3/4박자 라이드 그루브:**
```

라이드: X . X X . X . X X
       1   2+  3   1   2+  3

```

업비트(+)에 탭이 추가되어 스윙 느낌 강화

### "Alice in Wonderland" (빌 에반스)

**매우 부드러운 브러시 왈츠:**
```

라이드: . . X . . X . . X
       1 2 3 1 2 3 1 2 3
(3박 악센트)

```

느리고 섬세한 스윙

---

## 왈츠에서의 솔로

### 3박 기반 필

왈츠에서 필은 박자 인식을 방해하지 않아야:

```
3박 기반 필:
박 3: 탐탐 런 (3박에서 다음 박 1로)

```

**트리플렛 활용:**
```

박 2-3: 6연음 (2개의 3연음) = 4개의 탐탐

```

## 음악연습실 왈츠 루틴

### 60분 루틴

**1. 3박자 카운팅 (10분)**
- BPM 60에서 '1-2-3' 소리내어 카운트
- 발로 1박 탭핑

**2. 기본 왈츠 라이드 (20분)**
- X .X .X 라이드 패턴
- 왼발 하이햇 1박 추가

**3. 브러시 왈츠 (20분)**
- 오른손 3박 서클
- 왼손 탭 추가

**4. 음원 청취 (10분)**
- 빌 에반스 "Waltz for Debby" 청취 + 드럼 집중

## 마무리

재즈 왈츠는 **4/4박자의 직선적 스윙과는 다른 둥글고 서정적 에너지**를 가집니다. 1박에서 자연스럽게 흘러내리는 느낌, 브러시로 그리는 섬세한 서클—이것이 재즈 왈츠의 본질입니다.

은평구 24시간 음악연습실에서 빌 에반스의 "Waltz for Debby"를 들으며 그 느낌을 귀에 먼저 새기세요. 그 감성을 기억하고 드럼으로 표현하는 것이 올바른 출발점입니다.

## 왈츠에서 자꾸 있지도 않은 네 번째 박을 기다리게 되는 이유

재즈 왈츠 곡을 편곡해서 세션에 올려본 적이 있는데, 리듬 파트에서 가장 자주 나온 사고가 마디 끝에서 반 박씩 늘어지는 현상이었습니다. 원인은 단순했습니다. 4/4에 익숙한 몸이 3박을 친 다음 무의식적으로 한 박을 더 기다리는 겁니다. 3/4는 4/4에서 한 박을 뺀 박자가 아니라 순환 주기 자체가 다른 박자인데, 머리로 아는 것과 몸이 도는 것은 별개입니다.

**두 마디를 한 덩어리로 묶어서 세보세요**

3박을 1·2·3으로만 세면 마디 경계가 매번 새로 시작되는 느낌이라 몸이 쉴 자리를 못 찾습니다. 대신 두 마디를 붙여 여섯 박으로 세면, 3/4 왈츠가 사실은 크게 도는 긴 호흡이라는 게 감각적으로 잡힙니다. 위에서 예로 든 "My Favorite Things"의 라이드 패턴도 한 마디 단위로 쪼개 보면 어색한데, 두 마디를 하나의 프레이즈로 들으면 훨씬 자연스럽게 들립니다.

**3박 서클은 한 바퀴가 아니라 3분의 1씩 끊어서 익힙니다**

4/4 서클은 12시·3시·6시·9시로 사분면이 딱 떨어져서 몸이 금방 외웁니다. 3박은 12시·4시·8시라 손목이 기억하기 어려운 각도예요. 그래서 처음에는 아예 소리를 내지 않고 브러시를 헤드에 대고 세 지점에서 잠깐씩 멈추는 연습을 권합니다. 세 지점이 몸에 박히면 그때 멈춤을 없애고 이어붙이면 됩니다. 위 루틴에서 브러시 왈츠에 20분을 배정해두었는데, 그중 처음 5분은 이 멈춤 훈련에 써도 아깝지 않습니다.

**폴 모티안을 따라 하려면 순서가 반대여야 합니다**

폴 모티안의 자유로운 왈츠 브러시를 목표로 삼는 분이 많은데, 그건 박자를 안 지키는 연주가 아니라 박자를 완전히 장악한 사람이 일부러 벗어나는 연주입니다. 순서를 지키세요. 먼저 라이드로 3박을 기계처럼 정확하게 도는 상태를 만들고, 그 위에서 왼손을 흘리기 시작하는 겁니다. "Waltz for Debby"를 들으며 발로 1박만 찍어보면, 그렇게 자유로워 보이던 연주가 사실 얼마나 단단한 기준 위에 있는지 바로 느껴집니다.

---

3박자 감각은 세트 앞에 앉아 있을 때만 훈련되는 게 아닙니다. 메트로놈을 3박마다 한 번만 울리도록 설정하고 연습 패드에서 라이드 패턴을 옮겨 쳐보는 것만으로도 마디 감각이 상당히 잡힙니다. 클릭이 마디 첫 박에만 오기 때문에 2박과 3박은 스스로 채워야 하고, 여기서 흔들리는 정도가 곧 지금의 3박 감각 수준입니다. 이 훈련은 소리가 크지 않아 개인 방음실에서 늦은 시간에도 부담 없이 반복할 수 있습니다. 어려운 구간에 막힐 때는 템포를 올리는 대신 한 마디만 떼어내 여덟 번 반복하고, 흔들림이 사라지면 앞뒤 마디를 다시 붙이는 순서가 안전합니다. 하루 30분을 매일 확보하는 편이 주말에 몰아서 세 시간을 쓰는 것보다 3박 순환을 몸에 새기는 데 훨씬 유리합니다.
