# 기타 컨트리 치킨 피킹·하이브리드 피킹 — 음악연습실 완전 가이드

치킨 피킹(Chicken Picking)은 **피크와 손가락을 동시에 사용하는 컨트리 기타의 핵심 기법**입니다. 닭 울음소리처럼 날카롭고 퍼커시브한 톤이 특징입니다. Brent Mason, Albert Lee, Vince Gill이 대표적인 마스터입니다.

---

## 치킨 피킹이란?

### 기술 원리

**하이브리드 피킹(Hybrid Picking):**
- 피크(픽)로 저음 줄 연주
- 중지(m)·약지(a)로 고음 줄 연주
- 두 가지를 동시 또는 교번으로 사용

**치킨 피킹의 특징:**
- 고음 줄을 손가락으로 당겨서 "뚝" 끊는 소리
- 머들(mute)과 어택의 조합
- 날카롭고 타악기적인 컨트리 톤

### 대표 아티스트

| 아티스트 | 스타일 |
|---------|--------|
| Brent Mason | 내슈빌 세션 마스터, 치킨 피킹의 교과서 |
| Albert Lee | 빠른 템포의 컨트리 리드 |
| Vince Gill | 서정적 컨트리 + 치킨 피킹 |
| Brad Paisley | 현대 컨트리 치킨 피킹 |
| Chet Atkins | 핑거스타일 컨트리의 원조 |

## 기본 치킨 피킹 기법

### 손 세팅

```
피크 잡는 법:
- 엄지·검지로 피크를 잡음
- 중지(m)와 약지(a)를 자유롭게 사용
- 손목을 브리지 가까이 위치 (날카로운 톤)
```

**손가락 사용:**
```
피크(p+i): 4, 5, 6번 줄 (E, A, D)
중지(m):   2번 줄 (B)
약지(a):   1번 줄 (e)
```

### 기본 패턴

**간단한 치킨 피킹 패턴:**
```
G 코드에서:
피크→6번줄(G3) 중지→2번줄(B3)
피크→4번줄(D4) 약지→1번줄(G4)
```

**뚝뚝 끊는 머들 기법:**
```
손가락으로 줄을 당겨 "팝" 소리 내기
당기면서 손바닥으로 동시에 머들
결과: 날카로운 타악기음
```

## 컨트리 스케일과 치킨 피킹

### 컨트리 스케일 (블루스 혼합)

**G 컨트리 스케일:**
```
G-A-Bb-B-D-E (메이저 + 블루스 노트)
3음과 b3음을 모두 사용
```

**핵심 개념:** 메이저 스케일에 b3(블루 노트)를 섞어 컨트리 감성.

### 더블 스톱 (Double Stops)

컨트리 기타의 상징:

**G 더블 스톱 포지션:**
```
1번 줄: B음
2번 줄: G음
동시에 연주 → 컨트리 느낌
```

**더블 스톱 치킨 피킹:**
```
중지(m) + 약지(a)로 1, 2번 줄 동시 당기기
피크로 4번 줄 베이스 음 연주
```

## 치킨 피킹 패턴 실전

### 기본 I-IV-V 패턴

**G-C-D 진행에서 치킨 피킹:**
```
G:
피크(6줄)-중지(2줄)-피크(4줄)-약지(1줄)
[G3]      [B3]    [D4]      [G4]

C:
피크(5줄)-중지(2줄)-피크(4줄)-약지(1줄)
[C3]      [C4]    [E4]      [E4]

D:
피크(4줄)-중지(3줄)-피크(2줄)-약지(1줄)
[D3]      [A3]    [D4]      [F#4]
```

### 텔레캐스터 톤 시뮬레이션

치킨 피킹은 원래 텔레캐스터로:
- 브리지 픽업 사용
- 톤 약간 높게
- 앰프 클린하게

**기타 세팅:**
```
픽업: 브리지 (날카로운 톤)
볼륨: 풀
톤: 7-8
앰프: 클린, 약간 밝게
```

## 하이브리드 피킹 고급 기법

### 롤링 아르페지오

**피크+손가락 롤링:**
```
피크 → 중지 → 약지 (순차적으로)
또는
약지 → 중지 → 피크 (역방향)
```

**G 코드 롤링:**
```
피크(6줄 G)→중지(3줄 B)→약지(1줄 G) → 빠르게
```

### 스케일 런 (하이브리드)

**G 메이저 스케일 하이브리드:**
```
피크: 5번, 4번 줄
손가락: 3번, 2번, 1번 줄
교번 적용 → 빠른 스케일 런 가능
```

### 컨트리 밴딩

**치킨 피킹 + 밴딩:**
```
3번 줄을 반음 또는 온음 벤딩하면서
2번, 1번 줄을 손가락으로 연주
동시에 → 컨트리 스타일 클라이맥스
```

## Albert Lee 스타일

### 빠른 템포 치킨 피킹

Albert Lee는 **믿을 수 없는 속도의 치킨 피킹**으로 유명:

**특징:**
- 빠른 대위법적 라인
- 피크와 손가락의 완벽한 협응
- 깔끔한 아티큘레이션

**연습법:**
```
1. BPM 80으로 시작
2. 매주 5-10 BPM 증가
3. 아티큘레이션 먼저 완벽하게
4. 속도는 자연스럽게
```

## Brent Mason 스타일

### 내슈빌 세션 치킨 피킹

**Brent Mason의 핵심:**
- 완벽한 타이밍 포켓
- 다이나믹 컨트롤 (세게-약하게-세게)
- 치킨 피킹을 리듬 플레이에도 적용

**리듬 컨트리 치킨 피킹:**
```
코드를 스트럼하면서 + 고음 줄 치킨 피킹
리듬과 리드를 동시에 연주
```

## 음악연습실 치킨 피킹 연습

### 연습 루틴 (60분)

**1. 준비 운동 (10분)**
   - 손가락 스트레칭
   - 피크+손가락 협응 운동
   - 기본 피크/손가락 교번 연습

**2. 기본 치킨 피킹 (20분)**
   - G 더블 스톱 치킨 피킹
   - 기본 I-IV-V 패턴
   - 머들 기법 집중 연습

**3. 스케일·아르페지오 (15분)**
   - 컨트리 스케일 하이브리드 피킹
   - 롤링 아르페지오
   - 밴딩+치킨 피킹 조합

**4. 곡 적용 (15분)**
   - 컨트리 스탠다드에 적용
   - 즉흥 컨트리 리드
   - 녹음하여 체크
