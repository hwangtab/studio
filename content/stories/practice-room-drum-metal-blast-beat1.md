# 드럼 메탈·블래스트 비트·더블 킥 메탈 — 음악연습실 완전 가이드

메탈 드럼은 **속도, 파워, 정밀함**의 삼위일체입니다. 블래스트 비트의 폭발적인 에너지, 더블 킥의 기관차 같은 그루브, 스래시 메탈의 리드미컬한 헤드뱅잉 패턴—이 모든 것이 메탈 드럼의 세계입니다. 은평구 24시간 음악연습실의 방음 환경에서 마음껏 폭발해보세요.

## 블래스트 비트 (Blast Beat)

### 블래스트 비트란?

블래스트 비트는 **스네어와 킥을 16분음표로 교대로 연주**하는 극도로 빠른 패턴입니다.

**기본 블래스트 비트:**
```
스네어: X - X - X - X - X - X - X - X
킥:    - X - X - X - X - X - X - X -
하이햇: X X X X X X X X X X X X X X X X (16분음표 연속)
```

**BPM:** 블래스트 비트는 BPM 180-240+ 에서 연주됩니다.

### 블래스트 비트 유형

**올드스쿨 블래스트:**
```
스네어: 모든 박에
킥: 스네어 사이마다
```

**트렘올로 블래스트:**
```
스네어: 연속적으로
킥: 1박에 하나
```

**핀케이드 블래스트:**
```
스네어: 2박에 하나 (덜 빠른 느낌)
킥: 모든 박에
```

### 블래스트 비트 훈련

**처음 시작:**
1. BPM 80에서 스네어-킥 교대로 시작
2. BPM 10씩 높이기
3. BPM 120에서 하이햇 추가
4. BPM 160 이상으로 점진적 증가

**중요:** 손목 부담을 최소화하기 위해 **버트 그립(Butt Grip)** 사용 고려.

## 메탈 더블 킥 패턴

### 더블 킥 기초

이미 `practice-room-drum-double-kick1`에서 다루었지만, 메탈 맥락에서 재정리합니다.

**기본 16분음표 더블 킥:**
```
킥킥킥킥 킥킥킥킥 (16분음표)
R L R L  R L R L
```

**갈로핑 더블 킥 (메탈의 핵심):**
```
킥킥 킥 킥킥 킥 (3련음표 갈로핑)
R L  R  L R  L
```

### 스래시 메탈 패턴

Metallica, Slayer, Megadeth 스타일.

**기본 스래시 패턴:**
```
하이햇: X - X - X - X - (8분음표)
스네어: - - X - - - X - (2, 4박)
킥:    X X - X X X - X (빠른 더블 킥)
```

**"Master of Puppets" 킥 패턴:**
```
X - X - X X - - X - X - X X - -
(2개 + 2개 갈로핑 패턴 반복)
```

### 데스 메탈 패턴

**블래스트 + 슈퍼킥:**
```
스네어: X X X X X X X X (연속 블래스트)
킥:    X X X X X X X X (스네어와 교대 또는 유니즌)
```

## 메탈 드럼 기술

### 다운 비팅 (Down Beating)

킥드럼을 **힐-토 (Heel-Toe) 기법**으로 연주하여 더 많은 킥 소리를 빠르게.

**힐-토 기법:**
1. 뒤꿈치로 킥을 치고
2. 즉시 발가락으로 두 번째 킥
3. 한 발로 16분음표 2개 연주 가능

### 스피드 메탈 손 기법

빠른 연주를 위한 **모터 기법:**

- **Wrist (손목)**: BPM 120까지
- **Arm (팔)**: BPM 120-160
- **마찰 기법 (Fulcrum)**: BPM 160 이상 - 레버리지 활용

### 다이나믹 컨트롤

메탈도 다이나믹이 있습니다.

**메탈 다이나믹 활용:**
- 인트로/아웃트로: 클린하고 조용하게
- 버스: 중간 강도
- 코러스/클라이맥스: 최대 강도
- 브리지: 갑작스러운 다이나믹 대비

## 메탈 장르별 드럼 접근

### 스래시 메탈

**BPM:** 140-200
**특징:** 16분음표 위주, 파워풀한 스네어, 갈로핑 킥

**주요 드러머:** Lars Ulrich (Metallica), Dave Lombardo (Slayer)

### 데스 메탈

**BPM:** 160-280
**특징:** 블래스트 비트, 극도의 속도, 기술적 정밀함

**주요 드러머:** George Kollias (Nile), Derek Roddy

### 블랙 메탈

**BPM:** 150-250
**특징:** 퍼커시브한 블래스트, 의도적으로 "로파이"한 느낌

**주요 드러머:** Fenriz (Darkthrone)

### 프로그레시브 메탈

**BPM:** 다양 (복합박자)
**특징:** 7/8, 5/4 등 복합박자, 기술적 폴리리듬

**주요 드러머:** Mike Portnoy (Dream Theater), Danny Carey (Tool)

## 장비와 셋업

### 메탈 드럼 셋업

**더블 킥 페달:**
- 더블 페달 또는 더블 킥드럼
- 스프링 장력 조정 (메탈은 강한 스프링 선호)
- 빔터 사이즈: 작을수록 빠른 반응

**메탈 스네어:**
- 낮고 빡빡한 튜닝
- 린넨 라이너 또는 코팅 헤드
- 림샷으로 파워풀한 소리

**심벌:**
- 두꺼운 심벌 (얇으면 메탈 사운드에 묻힘)
- China 심벌 활용
- Stack (심벌 위에 심벌) 사용

## 음악연습실 메탈 드럼 연습 루틴

### 기초 단계 (60분)

**1. 스탬프 워밍업 (15분)**
- 한 발 16분음표 BPM 100에서 100회
- 양발 교대 16분음표
- 갈로핑 패턴 BPM 80부터

**2. 블래스트 비트 (20분)**
- BPM 80 스네어-킥 교대
- BPM 120 하이햇 추가
- BPM 150 목표

**3. 스래시 패턴 적용 (25분)**
- 기본 스래시 패턴 BPM 140에서
- Metallica 스타일 킥 패턴
- 메탈 음원과 함께 연습

## 메탈 드럼 보호

메탈 드럼은 **성대 보호처럼 성대 대신 관절 보호**가 중요합니다.

**손목/팔꿈치 보호:**
- 과도한 다운 비팅 주의 (건초염 위험)
- 연습 전 충분한 스트레칭
- 고강도 연습 후 적절한 휴식

**청력 보호:**
- 이어플러그 착용 필수 (메탈 드럼은 매우 큰 소리)
- 음악연습실 방음으로 외부 피해 방지
