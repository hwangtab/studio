faq:
  - q: 기타 카포를 사용해야 하는 상황과 포지션 선택 방법은?
    a: >-
      카포 포지션 선택: ① 조성 맞추기 — 보컬 음역에 맞는 조성으로 조절 ② 개방현 활용 — 카포 후에도 개방현 코드 사용 가능 ③
      핑거링 단순화 — 어려운 코드를 쉬운 코드로 변환 ④ 음색 변화 — 카포 위치에 따라 음색이 밝아짐 ⑤ 다른 기타와 조화 — 두
      기타가 다른 포지션으로 같은 곡 연주. 카포는 단순히 조성만 바꾸는 것이 아닙니다. 카포 위치에 따라 현의 긴장도가 변해 음색도
      달라집니다. 특히 카포 5~7프렛은 브라이트하고 맑은 소리가 납니다. 보컬과 기타의 조성을 맞출 때 기장 많이 활용합니다.
  - q: 기타 카포 코드 변환 — 오픈 코드를 카포로 연주하는 방법은?
    a: >-
      카포 코드 변환: ① G형 → A키 — 카포 2프렛에 G형 코드 = A키 ② C형 → D키 — 카포 2프렛에 C형 코드 = D키 ③
      카포 도표 — 카포+코드형으로 실제 조성 계산 ④ 역계산 — 원하는 키에서 오픈 코드 형태 찾기 ⑤ 교회 음악 — Em→Dm,
      Am→Gm 등 자주 변환. 카포 코드 변환의 핵심은 '카포 위치+코드 형태=실제 코드'입니다. 카포 2프렛에 G 코드 모양 = A
      코드 소리. 이 관계를 이해하면 어떤 키든 익숙한 오픈 코드 모양으로 연주할 수 있습니다.
  - q: 파셜 카포(Partial Capo) 활용 방법과 특별한 효과는?
    a: >-
      파셜 카포 활용: ① 파셜 카포 — 모든 현이 아닌 일부 현에만 카포 적용 ② 3현 카포 — 3개 현에만 카포: 열린 드론 음 생성
      ③ 특수 튜닝 효과 — 오픈 튜닝 없이 특수 음향 ④ 고유 코드 모양 — 기존 코드와 다른 새로운 핑거링 ⑤ 포크·월드뮤직 — 독특한
      음색 특히 아름다움. 파셜 카포는 일반 카포와 달리 일부 현에만 적용해 드론 음과 일반 음을 동시에 냅니다. 이 기법으로 오픈 튜닝
      없이도 독특하고 풍부한 음향을 만들 수 있습니다. Nick Drake, Dave Matthews가 파셜 카포를 독창적으로 활용한
      것으로 유명합니다.
  - q: 기타 카포 사용 시 음정 정확도와 셋업을 유지하는 방법은?
    a: >-
      카포 음정·셋업 유지: ① 올바른 위치 — 프렛 바로 뒤에 카포 배치 ② 균등한 압력 — 모든 현에 균등하게 눌러야 ③ 버즈 방지 —
      카포가 너무 뒤에 있으면 버즈 발생 ④ 재조율 — 카포 장착 후 반드시 재조율 ⑤ 카포 품질 — 고품질 카포일수록 음정 안정성 높음.
      카포 사용 시 가장 흔한 문제는 음정이 올라가거나 버즈가 생기는 것입니다. 이는 카포 위치와 압력이 적절하지 않기 때문입니다. 카포
      장착 후 항상 조율기로 확인하고, 버즈가 있으면 카포를 프렛에 더 가깝게 이동시키세요.

## 카포 하나로 기타 연주의 가능성이 넓어집니다

카포 포지션 선택부터 파셜 카포까지. 방음 개인실에서 기타 카포 테크닉을 탐색하세요.

기타 카포 훈련의 핵심:
- **포지션 선택**: 보컬 음역·음색에 맞는 카포 위치 판단
- **코드 변환**: 카포+코드 모양으로 원하는 키 즉시 연주
- **파셜 카포**: 일부 현에만 카포를 적용해 독특한 드론 음 효과
- **음정 정확도**: 카포 장착 후 재조율·버즈 방지 세팅

## 기타 카포 활용·카포 테크닉 훈련을 극대화하는 4가지 원칙

기타 연습의 효율은 **무엇을 연습하느냐**보다 **어떻게 연습하느냐**에 달려 있습니다. 목적 있는 반복이 막연한 반복보다 10배 빠릅니다.

1. **문제 구간 집중** — 어려운 2~4마디를 전체 반복보다 10~20회 집중. 문제 구간을 건너뛰는 습관은 영원히 그 구간이 약점으로 남습니다.

2. **녹음으로 객관화** — 스마트폰으로 매 세션 일부를 녹음하고 청취. 연주 중에는 인식 못한 음정·리듬·폼 문제가 녹음에서 명확히 드러납니다.

3. **음악적 맥락 적용** — 연습한 기법을 항상 실제 곡이나 즉흥 연주에 적용. 기법 자체보다 음악 안에서의 사용이 실력으로 이어집니다.

## 기타 집중 연습 루틴

| 구간 | 내용 | 시간 |
|-----|------|------|
| 워밍업 | 크로매틱 운지·스트레칭 | 8분 |
| 기법 드릴 | 오늘의 핵심 기법 집중 반복 | 15분 |
| 스케일·아르페지오 | 목표 키에서 스케일 연습 | 10분 |
| 곡 적용 | 배운 기법을 실제 곡에 적용 | 12분 |
| 녹음 확인 | 오늘 연습 녹음 후 청취 분석 | 15분 |

### 코드 마스터를 위한 연습 곡 추천

| 난이도 | 곡명 | 핵심 코드 |
|-------|------|---------|
| 입문 | 아이유 — 밤편지 | Am·G·F·E (am키 기본) |
| 초급 | 잔나비 — 주저하는 연인들을 위해 | 전조 포함 코드 진행 |
| 중급 | Oasis — Wonderwall | 특수 튜닝·sus 코드 |
| 고급 | John Mayer — Slow Dancing | 7th·9th 재즈 코드 |

### 기타 코드 연습에서 자주 하는 실수

1. **손가락을 눕혀서 인접 현을 뮤팅** — 각 손가락 끝을 세워서 프렛 바로 뒤를 누르기
2. **코드 전환 시 손 전체를 들어올림** — 기준 손가락(1지)을 최대한 이동하지 않고 전환
3. **스트로크 없이 코드 잡기만 연습** — 코드 전환 후 즉시 스트로크해서 '연주 흐름' 익히기
4. **바레 코드를 너무 일찍 시도** — 오픈 코드를 완전히 익힌 후 바레 코드로 진행

### 기타 코드 자가 진단

- [ ] 6개 현이 모두 깨끗하게 울리는가? (왼손 뮤팅 없이)
- [ ] G → C → Am → Em 코드 전환이 1박 안에 완성되는가?
- [ ] 코드 전환 후 첫 스트로크가 끊기지 않는가?

## 4주 기타 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 코드 | Em·Am·G·C·D — 코드 전환 속도 향상 | 40분 |
| 2주차 | 스트로크·핑거 | 8비트 스트로크, 핑거피킹 기본 패턴 | 45분 |
| 3주차 | 곡 연습 | 목표 곡 섹션별 분리 연습, 코드 전환 | 50분 |
| 4주차 | 완성 | 전곡 + 노래에 맞춰 연주 실전 적용 | 60분 |

**주간 체크포인트:** 1주차: 코드 전환 2초 이내 / 2주차: 박자 흔들림 없이 8마디 연속 / 3주차: 목표 곡 코드 전환 오류 없이 / 4주차: 노래·MR과 함께 완주

카포를 활용하면 기타의 개방 코드 포지션을 유지하면서 반음씩 조옮김하여 원하는 키에서 연주할 수 있습니다. 특히 보컬과 함께 연주할 때 키를 빠르게 조정할 수 있어 편리하며, 카포 위치에 따라 음색의 밝기와 지판 울림도 달라집니다. 카포를 너무 세게 조이거나 너무 느슨하게 하면 음정이 맞지 않으므로 각 포지션에서 모든 현을 확인하는 습관이 필요합니다.
