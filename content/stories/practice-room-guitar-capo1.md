faq:
  - q: "기타 카포란 무엇이고 어떻게 사용하나요?"
    a: "기타 카포 이해: ① 정의 — 기타 넥에 끼워 개방현의 음을 높이는 도구 ② 효과 — 같은 코드 형태로 다른 키(조성) 연주 ③ 사용법 — 원하는 프렛에 끼우면 전체 음이 올라감 ④ 장점 — 어려운 바레코드 대신 오픈 코드로 연주 ⑤ 표기 — 악보에 'Capo 2' 등으로 표시. 카포 2프렛이면 모든 음이 2반음 높아집니다. C코드를 치면 D 소리가 납니다."
  - q: "기타 카포로 보컬 키에 맞게 조절하는 방법은?"
    a: "카포로 키 맞추기: ① 원곡 키 확인 — 원곡이 무슨 키인지 파악 ② 내 음역 — 편안하게 부를 수 있는 키 ③ 카포 위치 — 원하는 키에 맞는 프렛 계산 ④ 코드 변환 — 카포 후 기본 오픈 코드 사용 ⑤ 음색 변화 — 카포 위치에 따라 음색 달라짐. 예: 원곡이 C키, 내 목소리에 G가 편하면 카포 7프렛에서 C 코드 폼으로 연주하면 G 소리가 납니다."
  - q: "카포 없이 기타로 전조하는 방법과 카포 전조의 차이는?"
    a: "카포 vs 바레 전조: ① 카포 — 오픈 코드 그대로, 쉽고 자연스러운 사운드 ② 바레 코드 — 카포 없이 직접 전조, 더 어렵지만 표현 다양 ③ 음색 차이 — 카포는 밝고 오픈, 바레는 타이트한 사운드 ④ 상황 — 빠른 전조는 카포, 미세한 음색 조절은 바레 ⑤ 병행 — 카포와 바레 둘 다 배우는 것이 가장 좋음. 카포와 바레는 같은 목적이지만 음색·편의성이 다릅니다."
  - q: "카포 사용 시 음 이름이 헷갈리는 문제를 해결하는 방법은?"
    a: "카포 음 계산법: ① 기준 — 카포 위치 = 반음 수 ② 계산 — C + 카포 2 = D, C + 카포 5 = F ③ 도표 — 카포별 코드 대응표 암기 ④ 앱 활용 — 카포 계산 앱 활용 ⑤ 익숙해지기 — 자주 사용하면 자연히 암기. 처음엔 카포 코드 변환표를 프린트해서 연습실에 가져가면 편합니다."

## 카포 하나로 모든 키를 편하게 연주할 수 있습니다

보컬 키에 맞춰 쉽게 전조. 방음 개인실에서 카포 위치를 바꿔가며 자신의 목소리에 맞는 키를 찾으세요.

기타 카포 연습의 핵심:
- **내 키 찾기**: 보컬 음역에 맞는 카포 위치
- **오픈 코드**: 카포 후 익숙한 오픈 코드 그대로
- **음색 탐색**: 카포 위치에 따른 음색 차이 느끼기
- **변환표 활용**: 처음엔 카포 코드 변환표 참고

---

## 카포 위치별 음 이름 변환

| 카포 위치 | C → | G → | D → |
|---------|-----|-----|-----|
| 0 | C | G | D |
| 2 | D | A | E |
| 3 | Eb | Bb | F |
| 5 | F | C | G |
| 7 | G | D | A |

---

## 카포 활용 상황별 정리

| 상황 | 카포 활용 | 이유 |
|------|---------|------|
| 보컬 키 맞추기 | 카포 위치 조정 | 오픈 코드 유지 |
| 어려운 바레 코드 | 카포로 대체 | 쉬운 오픈 코드 |
| 밝은 음색 원할 때 | 카포 높이 | 개방현 활용 |
| 2기타 편곡 | 다른 카포 위치 | 음색 다양화 |
