# 베이스 메탈·헤비록 베이스라인 — 음악연습실 완전 가이드

메탈 베이스는 **파워, 정확성, 그루브**의 삼각형입니다. 기타와 완벽히 동기화된 리프, 킥드럼과 인터락된 갤로핑 패턴, 다운튜닝이 만드는 어두운 사운드—이것이 메탈 베이스의 세계입니다. 이 가이드에서는 헤비록과 메탈 베이스의 핵심 기법을 안내합니다.

---

## 메탈 베이스의 기초

### 피크 피킹 (Pick Picking)

메탈 베이스에서 핑거 스타일보다 **피크 사용**이 일반적:

**이유:**
- 더 명확한 어택 사운드
- 빠른 16분음표 패턴에 유리
- 기타와의 동기화 용이

**피크 기법:**
- 강한 다운-업 교대 스트로크
- 피크를 현과 약 45도 각도로
- 피크 잡는 힘: 강하게 (울리지 않게)

**손목 컨트롤:**
- 손목 위주로 움직이기 (팔 전체 사용 최소화)
- 일정한 진폭 유지

### 다운 스트로크 중심

헤비메탈은 다운 스트로크가 기본:
- 모든 음을 다운 스트로크로 — 강한 어택
- 매우 빠른 구간에서만 얼터네이트 피킹
- 각 다운 스트로크의 일관성이 핵심

## 다운튜닝 (Down Tuning)

### 일반 튜닝 vs 다운튜닝

**표준 베이스 튜닝:** E-A-D-G
**드롭 D:** D-A-D-G (6번 현만 D로)
**드롭 C:** C-G-C-F
**드롭 B:** B-F#-B-E
**4반음 내림:** Eb-Ab-Db-Gb

### 다운튜닝의 특성

- 현이 느슨해져 특유의 "flappy" 사운드
- 더 낮고 어두운 음역
- 더 강한 저음 중심의 사운드

### 드롭 D 튜닝 활용

드롭 D에서 6번 현의 D는 **파워 코드를 쉽게** 연주:

```
드롭 D 파워 코드:
6번 현: D2 (루트)
5번 현: A2 (5도)
→ 한 프렛으로 두 현 동시 눌러 파워 코드
```

## 핵심 메탈 베이스 패턴

### 갤로핑 패턴 (Galloping Pattern)

Iron Maiden 스타일의 특징적 패턴:

**2배 갤로핑:**
```
Down-Up-Down / Down-Up-Down
단-단단 / 단-단단
```

**3배 갤로핑:**
```
Down-Up-Down-Up-Down-Up
각각 16분음표
```

### 루트 루프 패턴

메탈의 가장 기본적인 패턴:

```
드롭 D, G5, 4/4박자:
G2 - G2 - G2 - G2 (단순 반복)
16분음표로 밀어붙이기
```

### 싱코페이션 메탈 패턴

```
박 1: G2 (강)
박 1-and: . (쉼)
박 2: G2 (강)
박 2-and: G2 (업비트)
박 3: . (쉼)
...
```

## 기타 리프와의 동기화

메탈 베이스의 핵심은 **기타와 완벽한 유니즌**:

**방법:**
1. 기타 리프를 먼저 완전히 암기
2. 베이스에서 동일한 리듬 패턴 구현
3. 어택 타이밍을 기타와 미세하게 맞추기

**일반적 접근:**
- 기타 리프와 1:1 동기화 (유니즌)
- 기타는 코드, 베이스는 루트 (하모니)
- 기타보다 한 박자 앞에서 또는 뒤에서 (리듬 텍스처)

## 앰프와 톤 세팅

### 메탈 베이스 앰프 세팅

**장비:**
- 베이스 앰프 + 디스토션/오버드라이브 페달 (선택)
- 하이 게인 앰프 직결 (간단하게)

**EQ 세팅:**
- 베이스: 높게 (7-8)
- 미드: 중간 또는 낮게 (4-5)
- 트레블: 약간 (5-6)

**컴프레서:**
- 어택: 중간
- 빠른 릴리즈
- 메탈의 일관된 어택 유지
