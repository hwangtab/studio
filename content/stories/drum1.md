faq:
  - q: 집에서 드럼을 녹음할 수 있나요?
    a: >-
      어쿠스틱 드럼은 소음 문제로 집에서 녹음하기 어렵습니다. 전자드럼(Electronic Drum Kit)에 오디오 인터페이스를 연결하면
      소음 없이 홈 레코딩이 가능합니다. 또는 DAW의 드럼 가상악기(VSTi)를 MIDI 패드나 키보드로 연주하는 방법도 있습니다.
  - q: 어쿠스틱 드럼 마이킹은 어떻게 하나요?
    a: >-
      기본 세팅은 킥 드럼(Kick mic), 스네어 탑(Snare top), 하이햇(Hi-hat), 오버헤드 스테레오
      2개(Overhead L/R), 룸 마이크 1~2개입니다. 최소 구성으로는 킥+스네어+오버헤드 2개로 시작합니다.
  - q: 드럼 샘플(Sample)로 실제 드럼을 대체할 수 있나요?
    a: >-
      Superior Drummer, EZdrummer, Steven Slate Drums 등 고품질 드럼 VSTi는 실제 드럼 연주자가
      녹음한 샘플로 실제에 가까운 음색을 제공합니다. 인디 밴드 레코딩에서 드럼 샘플 활용은 매우 일반적입니다.
  - q: 드럼 세션을 스튜디오에서 진행하면 어떤 과정으로 이루어지나요?
    a: >-
      드럼 튜닝 확인 → 마이크 세팅 → 사운드 체크 → 클릭 트랙 맞추기 → 녹음 시작 → 완성 테이크 선택 순서로 진행합니다. 클릭
      트랙(메트로놈)에 맞춰 연주하는 훈련이 되어 있어야 합니다.

## 드럼이 음악의 리듬을 만듭니다

드럼은 밴드 사운드의 기반입니다. 좋은 드럼 레코딩이 나머지 악기와 보컬을 살립니다.

---

## 드럼 녹음 방법 비교

| 방법 | 특징 | 추천 상황 |
|------|------|---------|
| 어쿠스틱 드럼 + 다중 마이킹 | 자연스럽고 풍성한 소리 | 전문 스튜디오 레코딩 |
| 전자드럼 + 오디오 인터페이스 | 소음 없음, 직접 녹음 | 홈 스튜디오, 전자음악 |
| 드럼 VSTi (가상악기) | 비용 절감, 유연한 편집 | 인디 제작, 데모 |
| 드럼 샘플 루프 | 빠른 제작, 전자음악 스타일 | 프로듀싱, EDM |

---

## 전자드럼 홈 녹음 방법

레이턴시 설정은 녹음과 믹싱 단계에서 각각 다르게 최적화하는 것이 좋습니다.

**장비 연결**
전자드럼 → 오디오 인터페이스 (L/R 스테레오 아웃)
- DAW에서 스테레오 오디오 트랙 생성
- 입력 모니터링 켜고 레벨 확인

**DAW 설정**
- **샘플레이트**: 44.1kHz 또는 48kHz
- **버퍼사이즈**: 64~128 샘플 (레이턴시 최소화)
- **레벨**: -18~-12dBFS (클리핑 방지)

## 어쿠스틱 드럼 기본 마이킹

신호 경로 전체를 점검해두면 녹음 중 예상치 못한 문제를 방지할 수 있습니다.

**최소 마이킹 (3~4개)**
- **Kick**: 킥 드럼 안쪽 (Shure Beta52A 등)
- **Snare**: 스네어 탑 (SM57 등)
- **Overhead**: 심벌 전체 커버하는 스테레오 페어

**풀 마이킹 (7~8개 이상)**
- Kick In + Kick Out
- Snare Top + Snare Bottom
- Hi-hat
- Tom (1~3개)
- Overhead L+R
- Room L+R (선택)

---

## 드럼 VSTi 활용 가이드


**추천 드럼 VSTi**
- **EZdrummer 3**: 입문~중급 (직관적 UI)
- **Superior Drummer 3**: 고품질, 다양한 커스터마이징
- **Steven Slate Drums**: 자연스러운 드럼 사운드
- **XO Drums**: 힙합·R&B 전용

**MIDI 입력 방법**
- MIDI 패드 (드럼 연주 느낌)
- 피아노 키보드 (세분화 배치)
- 마우스로 피아노롤 입력

### 녹음 세션 공통 체크리스트

**준비 단계**
- [ ] 세션 목표 명확히 설정 (완성할 구간·트랙 수)
- [ ] 모든 파일·장비 사전 점검 완료
- [ ] 아티스트 컨디션 확인 (보컬: 목 상태, 악기: 튜닝)

**세션 중**
- [ ] 테이크별 메모 (베스트/리테이크 표시)
- [ ] 문제 구간 즉시 인식하고 재녹음 결정
- [ ] 세션 종료 30분 전 마무리 시작

**후반 작업**
- [ ] 원본 파일 즉시 백업
- [ ] 믹싱 전 24시간 이상 청취 공백 유지

### 세션 효율을 높이는 팁

1. **가장 어려운 구간을 세션 초반에** — 에너지가 최고일 때 어려운 것 먼저
2. **구간 분리 녹음** — 전체 통으로 반복보다 구간별 완성 후 연결
3. **즉각 피드백** — 녹음 직후 헤드폰으로 바로 모니터링

## 마치며

드럼 녹음은 음악 제작에서 가장 도전적인 작업 중 하나입니다. 전자드럼이나 드럼 VSTi로도 훌륭한 결과물을 만들 수 있습니다.
