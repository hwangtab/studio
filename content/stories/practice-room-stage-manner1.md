## 무대는 연주만이 아닙니다

청중은 소리만 듣지 않습니다. 입장하는 순간부터 퇴장할 때까지 모든 것이 공연입니다. 방음 개인실에서 무대 퍼포먼스 전체를 연습하세요.

무대 매너 연습의 핵심:
- **동선 준비**: 입장→인사→연주→마무리→퇴장
- **눈 맞춤**: 청중과 소통하는 눈 맞춤 훈련
- **MC 멘트**: 자연스러운 곡 소개 준비
- **실수 대응**: 실수 후 자연스럽게 이어가기

---

## 공연 전 무대 매너 체크리스트

**동선 연습**
- [ ] 입장 경로·속도 확인
- [ ] 마이크 스탠드·악기 위치 파악
- [ ] 인사 각도·시간 (30도, 2초)
- [ ] 퇴장 경로 확인

**퍼포먼스 연습**
- [ ] 연주 중 청중 눈 맞춤 3회 이상
- [ ] MC 멘트 자연스럽게 (메모만 참고)
- [ ] 표정 자연스럽게 (긴장 표정 X)
- [ ] 실수 후 멈추지 않고 이어가기

---

## 무대 퍼포먼스 연습 루틴 (방음 개인실)

1. **입장 연습** (2분): 문에서 무대 위치까지 걸어오기
2. **인사 연습** (1분): 정면을 향해 인사
3. **MC 멘트** (3분): 오늘 연주할 곡 소개
4. **전체 공연** (연주 길이만큼): 실제 공연처럼 처음부터 끝
5. **마무리 인사** (1분): 여운 있는 마무리 인사
6. **퇴장** (1분): 자신 있는 퇴장

---

## 무대 눈 맞춤 훈련 (연습실 활용)

| 방법 | 효과 |
|-----|------|
| 벽 3곳에 스티커 붙이기 | 청중 점 설정으로 훈련 |
| 거울 보며 연주 | 자기 표정 실시간 확인 |
| 스마트폰 녹화 | 객관적 퍼포먼스 분석 |
| 가족·친구 앞 연주 | 실제 청중과 눈 맞춤 연습 |

---

### 효율적인 연습 원칙

- **목표 설정 → 연습 → 검증 루틴** — 목표를 정하고, 집중 연습하고, 녹음으로 개선을 확인하는 3단계를 매 세션에 적용
- **분리 연습 원칙** — 전체 반복보다 문제 구간만 2~4마디 앞부터 분리해서 집중하는 것이 훨씬 효과적
- **완성된 느낌의 함정 경계** — 잘 된다고 느끼는 순간이 실제로 완성된 순간과 다를 수 있음. 녹음으로 객관적 확인 필수

### 연습 중 자주 하는 실수

1. **목표 없는 반복 — 시간만 소비** — 무엇을 개선할지 모르는 반복은 잘못된 패턴만 강화. 매 세션 전 "오늘 이것만은 해결한다" 목표 1개를 설정
2. **어려운 구간 회피 — 약점 지속** — 잘 되는 부분만 반복하면 약점이 영원히 남음. 불편하고 어려운 구간이 실력 향상의 핵심 포인트
3. **자기 연주의 객관적 청취 불가** — 연주 중에는 자신의 소리를 객관적으로 듣기 어려움. 녹음 후 청취로 문제를 발견하고 수정하는 루틴이 필요

### 연습 자가 진단

- [ ] 오늘 연습의 구체적인 목표를 시작 전에 정했는가?
- [ ] 어려운 구간을 분리해서 집중적으로 반복했는가?
- [ ] 연습 후 무엇이 개선되었는지 구체적으로 인식하는가?

## 4주 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 점검 | 기본기 복습, 문제 구간 파악 | 40분 |
| 2주차 | 구간 집중 | 어려운 부분 느린 템포 반복 | 45분 |
| 3주차 | 전체 흐름 | 전곡 연결, 템포 단계적 올리기 | 50분 |
| 4주차 | 완성 | 목표 템포 + 표현·다이나믹 완성 | 60분 |

**주간 체크포인트:** 1주차: 약점 구간 3개 목록 작성 / 2주차: 각 구간 느린 템포 100% 달성 / 3주차: 전곡 끊김 없이 완주 / 4주차: 청중 앞 또는 녹음으로 최종 확인

## 연습실에서 더 효과적으로

**연습실에서만 가능한 연습:**
- 집에서 불가능한 최대 볼륨·최대 다이나믹 표현 훈련
- 방음 환경에서 집중력이 최대로 유지되는 환경
- 스스로 녹음하여 객관적으로 청취하는 피드백 루틴

## Studio NOL이 무대 매너 연습실 사용자에게 자주 권하는 3가지

스튜디오 놀(연신내, 서울 은평구) 음악연습실에서 보컬·연주자 무대 매너 연습 상담에서 반복적으로 드리는 조언입니다.

**1. 시선 방향 — 청중 골고루**

무대 매너의 핵심은 시선 처리입니다. 청중 좌·중·우를 골고루 보는 훈련을 합니다.

**2. 마이크 잡는 자세 — 손목 안정**

핸드핼드 마이크는 손목으로 잡습니다. 손가락 끝으로 잡으면 떨림이 마이크에 전달됩니다.

**3. 영상 촬영 점검 — 본인 동선 객관화**

본인 무대 동선은 본인 눈으로 보기 어렵습니다. 영상 촬영 후 점검합니다.
