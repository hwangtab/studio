## 경기 전 시·군에서 연신내 스튜디오 놀까지

경기도 31개 시·군 어디서든 지하철·광역버스 환승으로 평균 50~80분이면 은평구 연신내역에 도착합니다. 일산·고양·김포·파주·구리 같은 서울 인접 권역은 30~50분, 분당·수원·용인 같은 남부 권역은 70~90분 정도입니다.

---

## 경기 권역별 → 연신내 이동 경로

### 북부권 (고양·일산·파주·김포)

1. 일산·정발산·대화 → 3호선 직행 → 연신내
- **총 소요시간**: 약 30~40분 (가장 가까운 권역)

### 동북부권 (남양주·구리·하남·의정부)

1. 별내·구리·남양주 → 경춘선·경의중앙선 → 청량리 → 경의중앙선 → DMC → 6호선 → 연신내
- **총 소요시간**: 약 60~80분

### 동남부권 (분당·판교·성남·용인·수지)

1. 판교·서현·정자 → 신분당선 → 강남 → 환승 → 합정 → 6호선 → 연신내
- **총 소요시간**: 약 70~85분

### 남부권 (수원·평택·오산·안성)

1. 수원역 → 1호선 → 서울역 → 공항철도 → DMC → 6호선 또는 3호선 → 연신내
2. 또는 신분당선 → 강남 환승
- **총 소요시간**: 약 75~90분

### 서부권 (안양·안산·시흥·부천·광명)

1. 안양·평촌 → 4호선 → 사당 → 2호선 → 합정 → 6호선 → 연신내
2. 안산·시흥 → 4호선·서해선 → 환승
- **총 소요시간**: 약 60~80분

### 외곽권 (가평·양평·여주·이천·포천)

1. 가평·양평 → 경춘선·경의중앙선 → 청량리 → 환승
2. 여주·이천 → 경강선·고속버스 → 서울 환승
- **총 소요시간**: 약 90~120분 (사전 일정 조율 권장)

## 경기 권역별 평균 소요 시간

| 출발 권역 | 주요 환승 경로 | 소요 시간 |
|---------|------------|---------|
| 일산·고양 | 3호선 직행 | 30~40분 |
| 김포·파주 | 김포공항 → 9호선 → 6호선 | 50~70분 |
| 분당·판교 | 신분당선 → 환승 | 70~85분 |
| 수원·용인 | 1호선 또는 신분당선 | 75~90분 |
| 안양·군포 | 4호선 → 환승 | 55~70분 |
| 안산·시흥 | 4호선·서해선 → 환승 | 60~80분 |
| 부천·광명 | 1호선·7호선 → 환승 | 50~70분 |
| 남양주·구리 | 경의중앙선 → 청량리 환승 | 60~80분 |
| 가평·양평 | 경춘선 → 청량리 환승 | 90~120분 |

**스튜디오 주소**: 서울특별시 은평구 연신내역 인근 (연신내역 4번 출구 도보 5분)

## 경기도 음악 씬과 스튜디오 놀

경기도는 분당·일산·수원 같은 신도시 인디 씬과 안양·안산·부천의 실용음악과 졸업생, 평택·오산의 미군 부대 인근 라이브 씬 등 다양한 음악 인프라가 분포되어 있습니다. 자체 음향 환경 마련이 어려운 거주지에서 음원 발매·오디션 데모 제작을 위해 서울 스튜디오를 찾는 아티스트들이 꾸준히 늘고 있습니다. 연신내 스튜디오 놀은 3호선·6호선 환승역에 위치해 경기 북부에서는 30분, 남부에서는 80~90분 내외로 접근 가능합니다.

## 방문 전 세션 준비 가이드

**준비물:** MR·가사 파일, 레퍼런스 트랙, 교통편 사전 확인, 보온 음료. 외곽 권역은 도착 후 30분 워밍업 시간을 일정에 포함하세요.

## 경기도에서 자주 방문하시는 시·군·구

경기도 안에서 스튜디오 놀까지 방문하시는 분들이 자주 출발하시는 권역은 다음과 같습니다 — 가평, 경기 광주시 오포읍, 고양, 과천, 광명, 구리, 군포, 김포, 남양주, 능곡, 동두천, 동탄, 별내, 부천, 분당, 성남, 수원, 수지, 시흥, 안산, 안성, 안양, 양주, 양평, 여주, 연천, 오산, 용인, 위례, 의왕, 의정부, 이천, 일산, 장기, 파주, 평촌, 평택, 포천, 하남, 화성 등 40개 권역. 동·역 단위에서 출발하시더라도 같은 권역 안이면 동일한 환승 경로로 접근 가능합니다.

### 권역별 안내

출발 권역에 따라 환승 경로와 평균 소요 시간이 달라집니다. 본문 위 광역 동선표를 참고하시고, 정확한 출발지를 카카오톡으로 알려주시면 권장 출발 시간을 안내드립니다.

## Studio NOL이 경기도 거주 보컬리스트에게 자주 권하는 3가지

스튜디오 놀에서 경기도 31개 시·군 거주 보컬리스트의 녹음 세션 상담 때 자주 드리는 조언입니다.

**1. 권역별 환승 경로 사전 파악**

신분당선(분당·판교·용인), 수인분당선(수원·죽전), 3호선(고양·일산), 경의중앙선(파주·김포), ITX-청춘(가평) 등 자기 권역에서 가장 빠른 환승 경로를 미리 파악해두면 세션 시간을 정확히 맞출 수 있습니다.

**2. 외곽 권역(가평·양평·여주·이천) — 1박 일정 또는 온라인**

수도권 외곽 거주자는 당일 왕복이 컨디션 부담이 큽니다. 1박 일정 또는 홈 레코딩 + 온라인 의뢰가 효율적입니다.

**3. 사전 자료 공유 — 도착 직후 부스 입장**

도착 즉시 본 녹음에 들어가도록 MR·가사·레퍼런스 트랙을 카카오톡으로 미리 공유합니다. 도착 시간 + 20~30분 워밍업이 표준 일정입니다.
