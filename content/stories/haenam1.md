## 해남에서 KTX로 서울까지

해남은 한반도 땅끝 도시로, 나주역 KTX를 통해 서울과 약 3시간 30분대로 연결됩니다. 이동 거리가 길지만 당일 왕복이 가능하며, 온라인 파일 의뢰 서비스도 적극 활용할 수 있습니다.

---

## 해남 → 연신내 이동 경로

### KTX 나주역 경유 (권장)

```
① 해남 → 나주역 (버스 약 1시간 30분~2시간)
② 나주역 KTX 탑승 (서울역 방면, 약 1시간 40~50분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간 40분~4시간 30분
```

---

## 당일 왕복 일정 예시 (해남 기준)

```
오전 5시 30분 해남 출발 → 나주역 이동
오전 7시 30분 나주역 KTX 출발
→ 오전 9시 20분 서울역 도착
→ 오전 10시 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 서울역 출발
→ 오후 3시 50분 나주역 도착
→ 오후 5시 50분 해남 도착
```

## 온라인 파일 의뢰 서비스

```
해남 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
