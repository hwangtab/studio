# 기타 탭핑·라이트핸드 기법 — 음악연습실 완전 가이드

탭핑(Tapping)은 오른손(또는 왼손)으로 프렛보드를 직접 두드려 소리를 내는 기법입니다. 에디 반 헤일런이 "Eruption"으로 세상에 충격을 준 이후, 탭핑은 록·메탈·퓨전의 필수 기술이 되었습니다. 이 가이드에서는 기초 탭핑부터 고급 멀티핑거 탭핑까지 체계적으로 안내합니다.

---

## 탭핑의 기초

### 기본 원리

탭핑은 **해머온(Hammer-on)과 풀오프(Pull-off)의 확장**입니다.

```

기본 구조:
왼손 프렛 → 오른손 탭(해머온) → 왼손 풀오프

```

**표기법:**
```

T = 오른손 탭
h = 해머온
p = 풀오프

```

### 오른손 포지션

**기본 탭핑 자세:**
- 검지나 중지로 프렛보드를 수직으로 두드림
- 나머지 손가락은 바디 위에 가볍게 올려 뮤팅
- 엄지는 넥 아래나 옆에 지지대로

---

## 기본 탭핑 패턴

### 1. 3음 탭핑 (Eruption 스타일)

에디 반 헤일런의 대표적인 패턴:

```

E 현 기준:
왼손 5프렛(A) → 왼손 7프렛(B) → 오른손 12프렛(E)
T = 12프렛 탭
h = 해머온
p = 풀오프

e|--12p7h5-12p7h5-12p7h5--|
```

**연습 순서:**
1. 아주 느리게 (BPM 60) 각 음 명확하게
2. 오른손 탭의 강도와 왼손 풀오프 강도 맞추기
3. 점진적 BPM 증가

### 2. 아르페지오 탭핑

여러 현을 걸쳐 탭핑으로 아르페지오:

```

Am 아르페지오 탭핑:
e|---------12---------|
B|------12------------|
G|---9-----------------|
D|---------------------|
A|---------------------|
E|-5-------------------|
```

## 멀티핑거 탭핑

### 8핑거 탭핑

고급 기술로, 양손 모든 손가락을 사용합니다.

**기법:**
- 왼손: 검지, 중지, 약지, 소지 (4개)
- 오른손: 검지, 중지, 약지, 소지 (4개)
- 각 손가락이 독립적으로 프렛 담당

**대표 아티스트:** Stanley Jordan (기타계 유일무이한 양손 독립 탭핑)

### 라이트핸드 화음

탭핑으로 화음을 만들기:

```

Cadd9 탭핑 보이싱:
e|--T(12)--| (오른손)
B|--T(10)--| (오른손)
G|--9------| (왼손)
D|--7------| (왼손)

```

---

## 장르별 탭핑 활용

### 록·메탈 탭핑

**스케일 기반 빠른 런:**
```

마이너 스케일 탭핑 런 (Am):
e|--T12p9h5-T12p9h5-T12p9h5--|
```

**포인트:**
- 리듬의 정확성이 핵심
- 오버드라이브/디스토션으로 음 지속 시간 조절

### 재즈·퓨전 탭핑

**코드 멜로디 탭핑:**
- 멜로디음 + 화성음 동시에 탭핑
- 깨끗한 클린 톤 사용
- 섬세한 다이나믹 컨트롤

### 어쿠스틱 탭핑

**손가락 피킹과 탭핑 혼용:**
- 베이스 음은 엄지로 피킹
- 중간 음역은 검지-중지로 피킹
- 고음역 멜로디는 오른손 탭핑

---

## 음악연습실 탭핑 루틴

### 입문 단계 (60분)

**1. 해머온·풀오프 워밍업 (10분)**
- 좌손 해머온-풀오프 각 음 균등하게
- 모든 손가락 조합 연습

**2. 기본 3음 탭핑 (20분)**
- BPM 60에서 Eruption 패턴 기초
- 각 현에서 반복

**3. 아르페지오 탭핑 (20분)**
- Am, Em, Dm 아르페지오 탭핑
- BPM 80 목표

**4. 음원 카피 (10분)**
- 에디 반 헤일런 Eruption 구간 카피

## 마무리

탭핑은 기타의 표현 영역을 극적으로 확장하는 기법입니다. 처음에는 오른손이 어색하고 소리가 균등하지 않지만, 은평구 24시간 음악연습실에서 매일 꾸준히 연습하면 빠르게 향상됩니다.

핵심은 **속도보다 명확도**입니다. 각 탭이 명확하게 울릴 때까지 느린 템포에서 완성한 후 속도를 올리세요.

어쿠스틱 기타에서 핑거피킹의 오른손 독립성을 키우는 것이 핵심 과제입니다. 엄지는 저음현, 검지·중지·약지는 고음현을 담당하는 기본 배치에서 시작해 점차 복잡한 아르페지오 패턴으로 발전합니다. 손가락 끝의 각도를 일정하게 유지하면 음량 균형이 자연스럽게 맞춰집니다. 스트러밍과 핑거피킹을 한 곡 안에서 자연스럽게 전환하는 능력을 키우면 표현 범위가 크게 확장됩니다. 카포를 활용해 다양한 키에서 같은 코드 보이싱을 연습하면 응용력이 빠르게 향상됩니다. 음악을 배우는 과정에서 이론과 실기를 함께 발전시키는 것이 이상적입니다. 화성학 기초를 이해하면 코드 진행을 귀로 파악하는 능력이 향상되고, 즉흥 연주나 작곡의 기반이 됩니다. 악보를 보고 연주하는 초견 능력은 꾸준히 새로운 악보를 접하는 훈련으로만 향상됩니다. 함께 연주할 동료를 찾아 앙상블 경험을 쌓는 것도 개인 연습에서는 얻기 어려운 실전 감각을 키워주는 중요한 방법입니다.
