## 고성에서 KTX로 서울까지

경남 고성은 공룡 화석 산지로 유명한 해안 도시로, 진주역 KTX를 통해 서울과 약 3시간대로 연결됩니다. 오전 일찍 출발하면 당일 서울 스튜디오 방문이 가능합니다.

---

## 고성 → 연신내 이동 경로

### KTX 진주역 경유 (권장)

```
① 고성 → 진주역 (버스 약 40~50분)
② 진주역 KTX 탑승 (서울역 방면, 약 2시간)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간 10분~3시간 40분
```

---

## 당일 왕복 일정 예시 (고성 기준)

```
오전 7시 고성 출발 → 진주역 이동
오전 7시 50분 진주역 KTX 출발
→ 오전 10시 서울역 도착
→ 오전 10시 40분 연신내역 도착
→ 오전 11시 세션 시작 (2시간)
→ 오후 1시 세션 완료
→ 오후 3시 서울역 출발
→ 오후 5시 진주역 도착
→ 오후 5시 50분 고성 도착
```
