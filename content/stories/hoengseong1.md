## 횡성에서 KTX로 서울까지

횡성은 강원도 서부 도시로, 원주역 KTX를 통해 서울과 약 2시간으로 연결됩니다. 횡성 한우로 유명한 횡성에서 편리하게 당일 서울 스튜디오 방문이 가능합니다.

---

## 횡성 → 연신내 이동 경로

### KTX 원주역 경유 (권장)

```
① 횡성 → 원주역 (버스 약 30~40분)
② 원주역 KTX 탑승 (서울역 방면, 약 50분~1시간)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 2시간~2시간 30분
```

---

## 당일 왕복 일정 예시 (횡성 기준)

```
오전 8시 횡성 출발 → 원주역 이동
오전 8시 40분 원주역 KTX 출발
→ 오전 9시 40분 서울역 도착
→ 오전 10시 20분 연신내역 도착
→ 오전 11시 세션 시작 (2시간)
→ 오후 1시 세션 완료
→ 오후 3시 서울역 출발
→ 오후 4시 원주역 도착
→ 오후 4시 40분 횡성 도착
```

---

## 온라인 파일 의뢰 서비스

```
횡성 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
