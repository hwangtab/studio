# 베이스 재즈 콤핑·워킹 라인 고급 — 음악연습실 완전 가이드

재즈 베이스의 핵심은 **워킹 베이스 라인(Walking Bass Line)**입니다. 4/4박자에서 4분음표를 끊임없이 연주하면서 코드 진행을 안내하고, 솔로이스트를 지지하며, 드러머와 리듬 섹션을 구성합니다. Ray Brown, Paul Chambers, Ron Carter가 이 예술의 최고봉입니다.

---

## 워킹 베이스 라인이란?

### 기본 원칙

**워킹 베이스의 4대 원칙:**
1. **코드 톤 우선:** 1·3·5·7음을 강박에 배치
2. **스케일 연결:** 코드 사이를 스케일로 부드럽게 이동
3. **크로매틱 접근:** 목표 음 반음 위/아래에서 접근
4. **리듬 일관성:** 4분음표를 끊임없이 유지

### 코드 톤 기반 라인

**Dm7 → G7 → Cmaj7 워킹:**
```
Dm7: D(루트)-F(3rd)-A(5th)-C(7th)
G7: G(루트)-B(3rd)-D(5th)-F(7th)
Cmaj7: C(루트)-E(3rd)-G(5th)-B(7th)
```

---

## Ray Brown 스타일

### 풍부한 톤과 깊은 그루브

Ray Brown (Oscar Peterson Trio)의 특징:
- **깊은 저음:** 넥 가까이에서 연주 (따뜻한 톤)
- **강한 어택:** 손가락으로 강하게 플럭
- **레이드 백:** 비트보다 약간 뒤에

**Ray Brown 스타일 워킹:**
```
Dm7 (4마디):
D2-F2-A2-C3
D2-E2-F2-G2 (스케일)
A2-Ab2-G2-F#2 (크로매틱 하행)
G2-F2-E2-A2 (해결 준비)
```

### 텐스 보이싱 연결

Ray Brown은 **10도(옥타브+3도) 점프**를 자주 사용:
```
D2 → F#3 (10도 위)
강한 다이나믹 대비
```

---

## Paul Chambers 스타일

### 마일스 데이비스 쿼텟의 베이스

Paul Chambers ("Kind of Blue" 베이시스트):
- **유려한 멜로디성:** 베이스 라인이 멜로디처럼
- **활(Arco) + 핑거:** 두 기법 자유롭게 전환
- **온음계 중심:** 크로매틱보다 스케일 라인 선호

**Chambers 스타일 Dm7:**
```
D2-E2-F2-G2 (D 도리안 스케일 상행)
A2-G2-F2-E2 (스케일 하행)
```

### 솔로 베이스 라인

Chambers는 솔로도 자주 연주:
```
워킹 중 갑자기 고음으로:
D3-E3-F#3-G3 (고음역 스케일)
다시 낮게: D2-C2-B1-A1
= 큰 음역 사용
```

---

## Ron Carter 스타일

### 마일스 데이비스 퀸텟 2기

Ron Carter의 접근:
- **최소한의 음:** 필요한 것만 연주
- **공간:** 쉬는 것도 연주
- **완벽한 타이밍:** 메트로놈 같은 정확성

**Carter 스타일 미니멀 워킹:**
```
Cmaj7:
C2 - - - E2 - - - G2 - - - B2
(8분음표 하나 후 쉬기)
```

### 코드 서브스티튜션

Carter는 베이스로 **코드를 암시**:
```
악보: G7
Carter 연주: Db2-C2 (트리톤 서브)
= 실제 코드가 Db7로 느껴짐
```

---

## 코드 토널 워킹 라인 구성

### ii-V-I 진행 워킹

재즈의 핵심 진행:

**Dm7-G7-Cmaj7:**
```
Dm7 (1마디):
비트 1: D (루트 - 강박)
비트 2: F (3rd)
비트 3: A (5th)
비트 4: C (7th) 또는 B (크로매틱 접근)

G7 (1마디):
비트 1: G (루트)
비트 2: B (3rd)
비트 3: D (5th)
비트 4: F (7th)

Cmaj7 (1마디):
비트 1: C (루트 - 해결)
비트 2: E (3rd)
비트 3: G (5th)
비트 4: B (7th) 또는 Db (다음 코드 준비)
```

### 크로매틱 접근음

다음 코드의 루트로 이동할 때:

**반음 위에서 접근:**
```
G7 → Cmaj7: G7 마지막 음 = C# (반음 위)
C#에서 C로 반음 하행 → 부드러운 해결
```

**반음 아래에서 접근:**
```
G7 → Cmaj7: G7 마지막 음 = B (반음 아래)
B에서 C로 반음 상행
```

**2음 크로매틱:**
```
G7 마지막 2음: C#-C (2음 크로매틱)
또는 B-C
```

---

## 스케일 워킹 라인

### 도리안 모드 활용

**D 도리안 (Dm7용):**
```
D-E-F-G-A-B-C-D
Dm7 코드의 7음 스케일
```

**G 믹솔리디안 (G7용):**
```
G-A-B-C-D-E-F-G
G7 코드의 7음 스케일
```

### 비밥 스케일

**G7 비밥 스케일:**
```
G-A-B-C-D-E-F-F#-G
표준 G 믹솔리디안에 F#(장7음) 추가
= 8음 스케일 → 4분음표와 정확히 맞음
```

## 더블베이스(콘트라베이스) vs 일렉트릭 베이스

### 더블베이스 워킹

재즈 워킹의 원래 악기:
- **활 연주 가능:** 장음 표현
- **더 넓은 공간감:** 배음이 풍부
- **핑거보드:** 플레이어블 범위 제한적

**재즈 더블베이스 세팅:**
```
뉴 스탠다드 현 (낮은 장력)
높은 액션 (현 높이)
플랫 운드 현 (따뜻한 톤)
```

### 일렉트릭 베이스 재즈

Jaco Pastorius 이후 일렉트릭도 재즈로:
- **프렛리스(Fretless):** 더블베이스에 가까운 포르타멘토
- **플랫 운드:** 따뜻하고 부드러운 재즈 톤
- **EQ:** 고음 줄이고 중음역 강조

---

## 음악연습실 재즈 베이스 연습

### 60분 루틴

**1. 코드 톤 연습 (15분)**
   - Dm7·G7·Cmaj7 코드 톤 워킹
   - 8분음표로 천천히
   - 모든 코드 인버전 연습

**2. ii-V-I 워킹 (15분)**
   - C 메이저 ii-V-I (Dm7-G7-Cmaj7)
   - F 메이저 ii-V-I (Gm7-C7-Fmaj7)
   - Bb 메이저 ii-V-I (Cm7-F7-Bbmaj7)

**3. 크로매틱 접근 (15분)**
   - 각 코드 루트에 크로매틱 접근
   - 2음 크로매틱 연습
   - 자연스러운 라인 만들기

**4. 표준 재즈 곡 (15분)**
   - "Autumn Leaves" 워킹 베이스
   - 또는 "Summertime" 워킹
   - 녹음 후 피드백

---

## 마무리

재즈 워킹 베이스는 **밴드를 하나로 묶는 힘**입니다. Ray Brown이 "베이스 라인은 음악의 기초 공사"라고 했듯이, 좋은 워킹 베이스가 있으면 밴드 전체가 흔들리지 않습니다.

은평구 24시간 음악연습실에서 ii-V-I를 완벽히 익히고, 스탠다드 곡에 워킹 베이스를 연습하세요. 한 음 한 음이 코드 진행을 설명하는 것—그것이 재즈 베이스의 예술입니다.

---


베이스 연주에서 가장 중요한 것은 일정한 타이밍과 그루브입니다. 메트로놈에 맞춰 천천히 연습하다 보면 자연스럽게 리듬 감각이 몸에 배어들게 됩니다. 드럼 트랙과 함께 연습하면 밴드 앙상블에서 베이스의 역할을 직접 체험할 수 있어 훨씬 빠르게 실력이 향상됩니다. 오른손 두 손가락을 균등하게 사용하는 훈련을 꾸준히 하면 스피드와 다이나믹 조절 능력이 동시에 발전합니다. 연주 후 스스로 녹음을 들어보는 습관을 들이면 미처 인식하지 못했던 실수를 발견하고 빠르게 교정할 수 있습니다.
