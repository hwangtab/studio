## 장수에서 KTX로 서울까지

장수는 전북 동부 산악 도시로, 전주역 KTX를 통해 서울과 약 3시간 30분대로 연결됩니다. 한우와 오미자로 유명한 장수에서 오전 일찍 출발하면 당일 서울 스튜디오 방문이 가능합니다.

---

## 장수 → 연신내 이동 경로

### KTX 전주역 경유 (권장)

```
① 장수 → 전주역 (버스 약 1시간~1시간 10분)
② 전주역 KTX 탑승 (서울역 방면, 약 1시간 40분~2시간)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간 20분~3시간 50분
```

---

## 당일 왕복 일정 예시 (장수 기준)

```
오전 6시 30분 장수 출발 → 전주역 이동
오전 7시 40분 전주역 KTX 출발
→ 오전 9시 30분 서울역 도착
→ 오전 10시 10분 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 서울역 출발
→ 오후 3시 50분 전주역 도착
→ 오후 5시 장수 도착
```

## 온라인 파일 의뢰 서비스

```
장수 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
