## 철원에서 서울까지

철원은 강원도 북서부 도시로, 의정부역 지하철을 통해 서울과 약 2시간 40분~3시간으로 연결됩니다. DMZ와 오대쌀로 유명한 철원에서 당일 서울 스튜디오 방문이 가능합니다.

---

## 철원 → 연신내 이동 경로

### 버스 → 의정부역 경유 (권장)

```
① 철원 → 의정부역 (직행버스 약 1시간 30분~2시간)
② 의정부역 → 지하철 1호선 탑승
③ 지하철 → 연신내역 (약 1시간)

총 소요시간: 약 2시간 40분~3시간 20분
```

---

## 당일 왕복 일정 예시 (철원 기준)

```
오전 7시 철원 출발 (직행버스)
→ 오전 8시 40분 의정부역 도착
→ 오전 9시 40분 연신내역 도착
→ 오전 10시 세션 시작 (2시간)
→ 오후 12시 세션 완료
→ 오후 1시 연신내역 출발
→ 오후 2시 의정부역 도착
→ 오후 3시 40분 철원 도착
```

---

## 온라인 파일 의뢰 서비스

```
철원 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
