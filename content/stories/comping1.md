## 컴핑 — 여러 테이크에서 최고의 퍼포먼스를 만드는 기술

보컬 컴핑은 현대 음악 제작의 핵심 기술입니다. 단 한 번의 완벽한 녹음보다 여러 테이크를 정교하게 편집해 이상적인 보컬을 만드는 것이 업계 표준입니다.

---

## 컴핑 기본 워크플로우

테스트 녹음으로 먼저 소리를 확인한 뒤 본 녹음을 진행하는 것이 기본 워크플로우입니다.

### 보컬 컴핑 단계

**1. 테이크 녹음**
- 같은 파트 3~8회 반복 녹음
- 각 테이크를 별도 트랙에 저장
- 녹음 중 테이크에 간략한 메모

**2. 첫 감상**
- 모든 테이크를 한 번씩 전체 청취
- 명백히 나쁜 테이크 제거
- 좋은 구간에 마커 표시

**3. 구간 선택 (Comp)**
- 절·후렴·브릿지 단위로 최선 테이크 선택
- 특정 음절 단위로 세밀 편집
- 각 구간 경계 크로스페이드

**4. 정리 및 타임 교정**
- 컴핑된 보컬 트랙 하나로 병합
- 박자 교정 (Timing Correction)
- 피치 교정 준비

**5. 피치 교정**
- Melodyne 또는 Auto-Tune으로 교정
- 과도한 교정 방지 (자연스러움 유지)

## DAW별 컴핑 방법

반사음 문제는 후반 작업에서 제거하기 매우 어려우므로 녹음 환경 정비가 먼저입니다.

### Logic Pro X

- 트랙 헤더 클릭 → "컴핑" 활성화
- Take Folder 생성 후 자동 컴핑 모드
- 각 구간 드래그로 원하는 테이크 선택
- 노란색 선택 영역으로 시각적 편집

### Pro Tools

- 플레이리스트(Playlist) 활용
- 각 테이크를 별도 플레이리스트에 저장
- 구간 선택 후 복사·붙여넣기
- 크로스페이드 수동 적용 필요

### Cubase

- 레인(Lane) 기능 사용
- 각 테이크 레인에 쌓기
- 레인 단위 클릭으로 선택
- 선택 병합으로 최종 트랙 생성

## 좋은 테이크 선택 기준

녹음 전 게인과 마이크 위치를 정확히 잡아두면 후반 작업이 크게 줄어듭니다.

### 테이크 평가 체크리스트

**감정 표현 (최우선)**
- 곡의 감성과 일치하는가
- 보컬리스트의 의도가 느껴지는가
- 자연스러운 표현인가

**음정 (Pitch)**
- 멜로디 음정 정확도
- 피치 흔들림 정도
- 포르타멘토(슬라이드) 자연스러움

**박자 (Timing)**
- 그루브·리듬과 맞는가
- 어택 타이밍의 일관성
- 후렴 진입 타이밍

**발음·발성**
- 자음·모음 명확도
- 브레스 자연스러움
- 바이브라토 일관성

---

## 컴핑 편집 팁

클리핑은 후반에서 복구가 불가능하므로 게인을 보수적으로 설정하는 것이 안전합니다.

### 편집 품질 향상 방법

**크로스페이드 처리**
- 테이크 연결 구간에 10~30ms 크로스페이드
- 클릭 노이즈 방지
- 자연스러운 연결감 확보

**브레스 처리**
- 각 프레이즈 앞 브레스도 같은 테이크에서 선택
- 인위적인 브레스 삽입 지양
- 브레스 볼륨 오토메이션으로 조절

**다이나믹 유지**
- 같은 구간 내 음량 일관성 확인
- 너무 다른 볼륨의 테이크 연결 지양
- 보컬 오토메이션으로 레벨 보정
