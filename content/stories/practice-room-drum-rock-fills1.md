# 드럼 록 필인·트랜지션 기법 — 음악연습실 완전 가이드

드럼 필인(Fill-In)은 **섹션과 섹션 사이를 연결하는 드라마틱한 드럼 패시지**입니다. 버스-코러스 전환, 솔로 진입, 곡의 절정—이 모든 순간에 올바른 필인은 음악 전체를 살립니다. John Bonham, Neil Peart, Keith Moon의 필인 기법을 체계적으로 탐구합니다.

---

## 드럼 필인의 역할

### 필인이 하는 일

**1. 섹션 전환 신호:**
- 버스 → 코러스 예고
- 솔로 진입 또는 종료
- 곡의 중요한 전환점

**2. 에너지 구축:**
- 그루브에서 절정으로 에너지 상승
- 리스너의 기대감 자극

**3. 음악적 대화:**
- 기타리스트·보컬의 리듬 패턴에 반응
- 밴드 전체를 하나로 결속

### 필인의 타이밍

**가장 중요한 규칙:** 필인은 **그루브를 방해하지 않아야** 함.

필인이 끝나는 정확한 시점에 다음 섹션이 시작해야 합니다. 필인이 길어지거나 짧아지면 전체 밴드가 혼란.

---

## 기본 필인 패턴

### 1박 필인

**단순 스네어 4연타:**
```
박자: ..3.. ..+.. ..4.. ..+..
     SN   SN   SN   SN  (4분음표)
```

**16분음표 스네어 런:**
```
3박부터: SN SN SN SN SN SN SN SN (16분음표 8개)
마지막: 크래시 + 베이스드럼
```

### 2박 필인

**3·4박 필인 (16분음표):**
```
박자: 3e+a 4e+a
     SN SN SN SN SN SN SN SN → Crash!
```

**탐탐 하강 필인:**
```
: HiTom → MidTom → FloorTom → Snare → Crash
```

### 4박 필인

**한 마디 전체 필인:**
```
1박: 하이탐 16분음표 x4
2박: 미드탐 16분음표 x4
3박: 플로어탐 16분음표 x4
4박: 스네어+킥 콤보 → Crash
```

## John Bonham 스타일 필인

### Led Zeppelin의 드럼

John Bonham은 역사상 가장 강력한 록 드러머 중 한 명.

**특징:**
- 매우 헤비하고 근육질
- 트라이플렛 기반 필인
- 스네어 파워가 압도적

**"Good Times Bad Times" 필인:**
```
3+4박: SN-SN-SN-BD-SN-BD (트라이플렛)
각 음이 매우 강함
```

**Bonham 스타일 트라이플렛 필인:**
```
16분음표 트리플렛: RLR LRL RLR LRL
(오른-왼-오른 3연음 패턴)
```

### "Moby Dick" 솔로 기법

Bonham의 대표 드럼 솔로.

**기법:**
1. **손으로 탐탐 두드리기** (말 그대로 맨손)
2. 하이탐-스네어-플로어 롤
3. 베이스드럼 다이나믹 변화

## Neil Peart 스타일 필인

### Rush의 복잡한 드러밍

Neil Peart는 복잡한 박자와 길고 정교한 필인으로 유명.

**특징:**
- 5/4, 7/8 등 복잡 박자 위 필인
- 긴 연결 패시지 (4마디 이상 필인)
- 심벌과 탐탐의 정교한 조합

**"Tom Sawyer" 스타일 필인:**
```
4마디 빌드업 필인:
M1: 단순 스네어 패턴
M2: 탐탐 추가
M3: 전체 세트 복잡 패턴
M4: 크래시 + 절정
```

### 복잡 박자 필인

**5/4 박자 필인:**
```
1-2-3-4-5 (5박자) × 2마디 필인
마지막 박에 크래시
```

## Keith Moon 스타일 필인

### The Who의 카오틱 드러밍

Keith Moon은 전통을 무시한 자유로운 드러밍.

**특징:**
- 예측 불가능한 필인
- 강렬한 크래시 사용
- 음악을 리드하는 적극적 드럼

**Moon 스타일 필인:**
- 규칙 없이 느낌대로
- 크래시를 가장 많이 사용
- 탐탐을 모두 동시에 사용

---

## 트랜지션 기법

### 버스-코러스 트랜지션

**가장 흔한 전환:**
버스 마지막 박에 필인 → 코러스 1박에 크래시+강한 그루브

**효과적인 버스-코러스 필인:**
```
버스 마지막 마디:
1박: 그루브 유지
2박: 그루브 유지
3박: 필인 시작 (탐탐)
4박: 필인 절정 → Crash!
코러스 1박: 강한 그루브 시작
```

### 절제된 트랜지션

때로는 필인 없이 그냥 섹션 전환.

**드랍-다운 전환:**
```
버스 마지막 박: 그루브 완전 제거
코러스 1박: 강한 그루브 폭발
(대비 효과)
```

**오픈 하이햇 트랜지션:**
```
버스 마지막: 오픈 하이햇 유지 (사라지는 느낌)
코러스: 강한 클로즈 하이햇으로 시작
```

## 필인 만들기 원칙

### KISS 원칙 (Keep It Simple, Silly)

**초보자 실수:** 필인을 너무 복잡하게

**규칙:**
1. 필인은 짧을수록 효과적일 때가 많음
2. 단순한 4연타도 강력한 필인
3. 복잡한 필인 = 실수 위험 높음

### 다이나믹 고려

**필인의 에너지 호:**
```
시작: 약하게 → 끝: 매우 강하게
(절정에서의 크래시가 가장 강해야)
```

## 음악연습실 필인 연습

### 연습 루틴 (60분)

**1. 기본 필인 패턴 (20분)**
   - 1박, 2박, 4박 필인 각각
   - 메트로놈으로 정확한 타이밍

**2. Bonham 스타일 (15분)**
   - 트라이플렛 필인
   - 헤비한 어택

**3. 버스-코러스 트랜지션 (15분)**
   - 곡 구조 안에서 필인 배치
   - 전환 타이밍 연습

**4. 자유 필인 (10분)**
   - 드럼 루프에서 자유롭게 필인 삽입

## 마무리

드럼 필인은 **음악을 살리는 순간의 예술**입니다. 완벽한 타이밍에 올바른 필인이 들어올 때, 청중은 그 순간을 느낍니다. 너무 많이 채우지도, 너무 적게 채우지도 않는 균형이 핵심입니다.
