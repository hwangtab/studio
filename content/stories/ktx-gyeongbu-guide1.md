## 경부선 KTX로 서울 스튜디오 당일 방문

경부선 KTX는 천안아산·대전·대구·부산을 잇는 한국 최대 고속철도 노선입니다. 최단 50분(천안아산), 최장 2시간 30분(부산) 안에 서울역에 도착할 수 있어 서울 스튜디오를 당일 왕복으로 이용하기에 가장 편리한 교통수단입니다.

KTX 좌석에서 이어폰으로 녹음할 곡을 예습하고 가사를 점검하면 이동 시간이 곧 세션 준비 시간이 됩니다. 실제로 경부선 도시에서 방문하시는 아티스트 중 상당수가 열차 안에서 워밍업을 마치고 스튜디오에 도착하자마자 세션에 들어갑니다.

## 서울역에서 연신내 스튜디오 놀까지

서울역 도착 후 연신내까지 가장 빠른 루트는 두 가지입니다.

### 루트 A: 1호선 → 3호선 → 6호선 (약 35분)

1. 서울역 지하철 1호선 (종로3가 방면) 탑승
2. 종로3가역에서 3호선 (구파발 방면) 환승
3. 불광역에서 6호선 (응암순환 방면) 환승
4. 연신내역 하차 → 4번 출구 도보 5분

### 루트 B: 경의중앙선 직행 (약 30분)

1. 서울역 경의중앙선 (문산 방면) 탑승
2. 디지털미디어시티역 하차
3. 6호선 (응암순환 방면) 환승
4. 연신내역 하차

평일 출퇴근 시간대에는 루트 B가 좌석 확보가 수월합니다. 주말에는 루트 A가 배차 간격이 더 짧습니다.

## 거리별 추천 세션 시간표

### 근거리 (천안아산·대전) — 하루 두 세션도 가능

| 시간 | 일정 |
|------|------|
| 07:30 | KTX 출발 |
| 09:00 | 스튜디오 도착, 워밍업 |
| 09:30~12:30 | 오전 세션 (녹음 3시간) |
| 12:30~13:30 | 점심 식사 (연신내역 주변) |
| 13:30~16:30 | 오후 세션 (믹싱 디렉팅 또는 추가 녹음) |
| 17:30 | KTX 탑승, 저녁 전 귀가 |

### 중거리 (대구·울산·포항) — 알찬 반나절 세션

| 시간 | 일정 |
|------|------|
| 06:30 | KTX 출발 |
| 09:30 | 스튜디오 도착, 워밍업 |
| 10:00~14:00 | 세션 (녹음 4시간) |
| 15:00 | KTX 탑승 |
| 17:30 | 귀가 |

### 원거리 (부산·창원·거제) — 오전 집중 세션

| 시간 | 일정 |
|------|------|
| 06:00 | KTX 출발 (부산역 첫차) |
| 09:00 | 스튜디오 도착 |
| 09:30~13:30 | 세션 (녹음 4시간) |
| 14:30 | KTX 탑승 |
| 17:00 | 부산역 도착 |

세션 시간이 부족하다면 야간 세션(18:00~22:00)도 가능합니다. 야간 KTX 막차 시간(서울역 기준 약 21:00~22:00)을 반드시 확인하세요.

## KTX에서 세션 준비하기

이동 시간을 활용하면 스튜디오 도착 후 바로 녹음에 들어갈 수 있습니다.

- **가사·악보 최종 점검**: 인쇄물 또는 태블릿에 가사를 띄워두고 감정 포인트 확인
- **곡 예습**: 이어폰으로 MR을 들으며 음정·박자 체크 (소리 내지 않고 입 모양만)
- **레퍼런스 정리**: 원하는 사운드 방향의 참고곡 2~3개를 플레이리스트로 준비
- **수분 섭취**: 물이나 따뜻한 차를 충분히 마셔두면 도착 후 목 컨디션이 좋아집니다
- **목·어깨 스트레칭**: 좌석에서 가볍게 긴장을 풀어주세요
