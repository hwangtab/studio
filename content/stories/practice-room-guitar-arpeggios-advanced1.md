# 기타 아르페지오 고급·스윕 피킹 — 음악연습실 완전 가이드

스윕 피킹(Sweep Picking)은 기타의 가장 화려하고 빠른 기법 중 하나입니다. 피크가 여러 현을 쓸어내리듯(sweep) 또는 올라가듯 움직이며 아르페지오를 연주합니다. 잉위 맘스틴(Yngwie Malmsteen), 프랭크 갬베일(Frank Gambale), 제이슨 베커(Jason Becker)가 대중화한 이 기법은 현대 메탈·재즈 퓨전의 핵심 테크닉입니다.

---

## 스윕 피킹의 원리

### 일반 피킹 vs 스윕 피킹

**일반 얼터네이트 피킹:**
```
e|--D U D U D--|  (D=다운, U=업)
```

**스윕 피킹:**
```
e|--D-----------|
B|--D-----------|
G|--D-----------|  (한 방향으로 쓸어내리기)
D|--D-----------|
A|--D-----------|
```

핵심: 각 현에서 하나의 음만, 피크가 계속 같은 방향

### 손목 동작

- 피크가 현을 통과할 때 바로 다음 현으로 이어지도록
- 손목의 로킹(waving) 동작 최소화
- 피크 각도: 살짝 기울어진(angled) 포지션

---

## 3현 아르페지오 스윕

### Am 3현 스윕

```
e|--5--|
B|--5--|  ↓↓↓ (다운 스윕)
G|--5--|
(이후 탭핑 또는 상행 스윕)
```

**Full 패턴:**
```
e|----5h8p5-----|
B|---5---------5|
G|-5------------|
  ↓↓↓      ↑↑↑
```

**손가락 포지션:**
- G현 5프렛: 소지
- B현 5프렛: 중지
- E현 5프렛: 검지

### E 메이저 3현 스윕

```
e|--9--|
B|--9--|  ↓↓↓
G|--9--|
```

---

## 5현 아르페지오 스윕

### Am 5현 스윕 (클래식)

```
e|----5h8p5-------|
B|---5-----------5|
G|--5-----------5-|
D|-7-----------7--|
A|5-----------5---|
   ↓↓↓↓↓   ↑↑↑↑↑
```

**바레 프렛 기법:**
E와 B현 5프렛은 검지로 동시에 바레 — 스윕할 때 롤링(rolling) 기법으로 한 음씩

### 5현 스윕의 리듬

```
타이밍: 16분음표 5개 = 한 스윕
       BPM 120 → 한 마디에 3~4번 스윕 가능
```

---

## 6현 아르페지오 스윕

### Am 6현 완전 스윕

```
e|----5h8p5-----------|
B|---5---------------5|
G|--5---------------5-|
D|-7---------------7--|
A|7---------------7---|
E|5---------------5---|
   ↓↓↓↓↓↓     ↑↑↑↑↑↑
```

이 패턴이 잉위 맘스틴 스타일의 대표적 아르페지오

## 이코노미 피킹(Economy Picking)

스윕 피킹과 얼터네이트 피킹을 결합한 효율적 기법:

### 원리

같은 방향으로 두 현을 치면 스윕처럼, 반대 방향은 얼터네이트처럼:

```
e|--12D-10D-9D--|  (다운 3개 — 이코노미)
B|--10U---------|  (업 전환)
```

**Frank Gambale 스타일:**
스케일 런에서 3음 그룹을 이코노미로 처리

## 연습 루틴

### 입문 단계 (60분)

**1. 3현 스윕 워밍업 (15분)**
- Am 3현 다운 스윕 단독
- BPM 60에서 각 음 명확하게
- 업 스윕 추가

**2. 5현 Am 스윕 (25분)**
- 다운 스윕만 BPM 50
- 업 스윕 추가
- 다운+업 연결 BPM 60

**3. 롤링 기법 훈련 (20분)**
- 바레 구간 롤링 단독 연습
- 음이 겹치지 않게 의식

### 주의사항

- 스윕 시 음이 겹쳐(arpeggiate 아닌 chord 소리) 나오면 롤링 부족
- 각 음을 명확하게, 속도는 그 다음
