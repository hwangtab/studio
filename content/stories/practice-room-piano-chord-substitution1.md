# 피아노 코드 대리·리하모나이제이션 — 음악연습실 완전 가이드

리하모나이제이션(Reharmonization)은 **기존 멜로디에 새로운 코드를 붙이는 예술**입니다. 같은 멜로디도 다른 코드 진행으로 전혀 다른 감정을 만들어냅니다. 재즈 피아니스트가 스탠다드 곡을 매번 다르게 연주할 수 있는 이유입니다.

---

## 코드 대리의 기본 원리

### 기능별 코드 분류

화성에서 코드는 기능에 따라:

| 기능 | 코드 유형 | 예 (C 메이저) |
|-----|----------|-------------|
| 토닉 | I, IIIm, VIm | Cmaj7, Em7, Am7 |
| 서브도미넌트 | IIm, IV | Dm7, Fmaj7 |
| 도미넌트 | V, VIIdim | G7, Bdim |

**대리 원칙:** 같은 기능의 코드끼리 대리 가능.

---

## 토닉 대리

### I → IIIm 대리

**Cmaj7 → Em7 대리:**
```
Cmaj7: C-E-G-B
Em7:   E-G-B-D
공통음: E, G, B (3개!)
Em7는 Cmaj7의 3번째 음에서 시작 = 기능 비슷
```

**적용:**
```
원본: C → F → G → C
대리: Em7 → F → G → Am7
더 서정적, 재즈적 느낌
```

### I → VIm 대리

**Cmaj7 → Am7 대리:**
```
Cmaj7: C-E-G-B
Am7:   A-C-E-G
공통음: C, E, G (3개!)
```

**적용:**
```
원본: C → Am → F → G
대리: Em7 → Am7 → Fmaj7 → G7
= "쉬운 버전" 대신 재즈 버전
```

---

## 서브도미넌트 대리

### IV → IIm 대리

**Fmaj7 → Dm7 대리:**
```
Fmaj7: F-A-C-E
Dm7:   D-F-A-C
공통음: F, A, C (3개!)
```

---

## 도미넌트 대리 — 트리톤 서브스티튜션

### 트리톤이란?

**트리톤(Tritone):** 3온음 = 증4도 = 감5도

```
G와 트리톤 거리: Db (6반음 = 증4도)
G7의 트리톤 대리 = Db7
```

### 왜 트리톤 대리가 작동하는가?

```
G7:   G-B-D-F    (3음=B, 7음=F)
Db7:  Db-F-Ab-Cb (3음=F, 7음=Cb=B)

핵심 발견:
G7의 3음(B)   = Db7의 7음(B)
G7의 7음(F)   = Db7의 3음(F)
→ 두 코드의 핵심 긴장음이 같다!
```

### 트리톤 서브 적용

**ii-V-I에 트리톤 서브:**
```
원본: Dm7 - G7 - Cmaj7
트리톤 서브: Dm7 - Db7 - Cmaj7
              (G7 → Db7로 대리)
```

**효과:**
```
Db7 → Cmaj7: 베이스가 반음씩 하행 (Db → C)
= 크로매틱 베이스 라인의 부드러운 해결
```

### 트리톤 서브 확장

**전체 진행 리하모나이제이션:**
```
원본: Cmaj7 - Am7 - Dm7 - G7
트리톤: Cmaj7 - Eb7 - Dm7 - Db7
         (Am7→Eb7, G7→Db7)
크로매틱 베이스: C-Eb-D-Db-C
```

## 패스트 코드 변환 기법

### 패싱 코드 삽입

코드와 코드 사이에 경과음적 코드:

**C → F 사이에:**
```
원본: C (2마디) - F (2마디)
삽입: C (1마디) - Bb7 (1마디) - F (2마디)
      C → Bb7 (크로매틱 하행) → F
```

**B♭7의 역할:**
- F의 도미넌트처럼 기능
- 반음씩 하강하는 크로매틱 베이스

### 백사이클 (Back-cycling)

**5도권을 거슬러 올라가는 대리:**
```
목표: Cmaj7 도달
백사이클: G7 → D7 → A7 → E7 → Cmaj7
(각 코드가 다음 코드의 도미넌트)
```

**더 짧게:**
```
원본: G7 → Cmaj7
백사이클: D7 → G7 → Cmaj7
(G7 앞에 D7 삽입)
```

## 모달 인터체인지 (Modal Interchange)

### 동명 단조 코드 빌리기

**C 메이저에서 C 단조 코드 빌리기:**

```
C 메이저: C-D-E-F-G-A-B
C 단조:   C-D-Eb-F-G-Ab-Bb

빌린 코드 예:
bIII: Eb 메이저 (C 단조에서)
bVI: Ab 메이저 (C 단조에서)
bVII: Bb 메이저 (C 단조에서)
```

**적용:**
```
원본: C - F - G - C
모달 인터체인지: C - Fm - G - C
               (F 메이저 → Fm = 단조에서 빌림)
더 어두운 감성
```

### "Borrowed Chord" 효과

```
Cmaj7 → Fm7 → Cmaj7
(단조에서 빌린 Fm7)
= 순간적으로 어두워졌다 다시 밝아짐
인기 있는 대중음악 기법 (Beatles 다수 사용)
```

## 스탠다드 곡 리하모나이제이션

### "Autumn Leaves" 리하모나이제이션

**원본 진행:**
```
Em7 - Am7 - D7 - Gmaj7
Cmaj7 - F#m7b5 - B7 - Em
```

**리하모나이제이션 버전 1:**
```
Em7 - Eb7(트리톤서브Am7→Eb7) - D7 - Db7(트리톤서브Gmaj7→Db7)
```

**버전 2 (더 복잡):**
```
Em9 - Bbm7-Eb7 - Am7-D7 - Gmaj7
(Am7 앞에 Bbm7-Eb7 백사이클 삽입)
```

### "Misty" 리하모나이제이션

**원본:**
```
Ebmaj7 - Bbm7-Eb7 - Abmaj7 - ...
```

**리하모나이제이션:**
```
Ebmaj7 - E7 (트리톤서브 Bbm7→E7, 반음상행) - Abmaj7 - ...
```

## 음악연습실 리하모나이제이션 연습

### 60분 루틴

**1. 트리톤 대리 (15분)**
   - 모든 도미넌트 7th → 트리톤 대리 찾기
   - G7→Db7, C7→Gb7, F7→B7 등
   - ii-V-I에 트리톤 서브 적용

**2. 패싱 코드 삽입 (15분)**
   - 기본 I-IV-V-I에 패싱 코드
   - 백사이클 패턴 연습

**3. 모달 인터체인지 (15분)**
   - C 메이저에서 단조 코드 빌리기
   - Beatles·현대팝 스타일 적용

**4. 스탠다드 리하모나이제이션 (15분)**
   - "Autumn Leaves" 또는 선택한 곡
   - 자신만의 리하모나이제이션 버전
