# 피아노 팝 반주법·코드 보이싱 — 음악연습실 완전 가이드

팝 피아노 반주는 **보컬과 멜로디를 지지하는 음악적 기반**입니다. 단순한 코드를 아름답게 배치하고, 장르에 맞는 반주 패턴을 구사하는 것—이것이 팝 반주 피아노의 핵심입니다. K-Pop, 발라드, 팝록, 어쿠스틱 팝의 피아노 반주법을 체계적으로 정리합니다.

---

## 팝 피아노 코드 보이싱

### 기본 보이싱 유형

**클로즈 보이싱 (Close Voicing):**
- 모든 코드 음이 가까운 위치
- C 메이저: C4-E4-G4 (한 옥타브 안)
- 더 좁고 조밀한 소리

**오픈 보이싱 (Open Voicing):**
- 코드 음이 넓게 펼쳐짐
- C 메이저: C3-G4-E5 (넓은 간격)
- 더 개방적이고 풍부한 소리

### 팝에서 자주 쓰는 보이싱

**4성부 팝 보이싱:**
```
오른손: 5음(G)과 3음(E) — 코드의 색깔
왼손: 근음(C) + 옥타브(C)
```

**2-5-1 재즈 팝 보이싱:**
```
Dm7: D3 + F4-A4-C5
G7: G2 + B3-F4-A4
CMaj7: C3 + E4-G4-B4
```

## 반주 패턴 유형

### 1. 아르페지오 (Arpeggios)

팝 발라드에서 가장 많이 쓰는 패턴.

**기본 오른손 아르페지오:**
```
C 코드: C-E-G-E 반복 (8분음표)
왼손: C 단음 유지
```

**8분음표 아르페지오:**
```
박자: 1  2  3  4  5  6  7  8 (8분음표)
오른손: C  E  G  E  C  E  G  E
```

**16분음표 아르페지오 (더 빠른 발라드):**
```
C-E-G-C-E-G-C-E (16분음표)
```

### 2. 블록 코드 (Block Chords)

팝록·업비트 팝에서 사용.

**4분음표 블록 코드:**
```
박자: 1    2    3    4
     C maj G maj Am  F maj
     (코드 전체를 통째로 치기)
```

**8분음표 블록 코드 (팝록 스타일):**
```
박자: 1  +  2  +  3  +  4  +
     ●     ●     ●     ●
```

### 3. 오스티나토 (Ostinato)

같은 패턴을 반복하는 팝 패턴.

**K-Pop 오스티나토 예:**
```
오른손: C-E-G-A (반복) — 4개 음 루프
왼손: C-G-Am-F 코드 진행
```

**리듬 오스티나토:**
```
오른손: 강-약-강-약 (16분음표 리듬)
왼손: 코드 변화
```

## K-Pop 피아노 반주

### K-Pop 발라드 반주

**특징:**
- 아르페지오 위주
- 상단 멜로디 두드러짐
- 서정적이고 감성적

**전형적 K-Pop 발라드 패턴:**
```
왼손: 낮은 음 + 옥타브 베이스
오른손: 아르페지오 + 코드 상단 멜로디
```

**진행 예 (A 단조):**
```
Am - F - C - G (반복)
아르페지오: Am(A-C-E) - F(F-A-C) - C(C-E-G) - G(G-B-D)
```

### K-Pop 댄스팝 반주

**특징:**
- 블록 코드 + 리듬감
- 16분음표 오스티나토
- 퍼커시브한 어택

**댄스팝 피아노 패턴:**
```
박자: 1  e  +  a  2  e  +  a
     ●        ●     ●        ●
(싱코페이션 강조)
```

## 장르별 반주 스타일

### 어쿠스틱 팝 반주

**특징:**
- 자연스럽고 심플
- 아르페지오 중심
- 다이나믹 변화가 표현

**John Legend / Ed Sheeran 스타일:**
```
왼손: 루트+5도 (파워풀하지 않게)
오른손: 아르페지오로 코드 풀어서
```

### 팝록 피아노 반주

**특징:**
- 리듬감 있는 블록 코드
- 강한 어택
- 드럼과 락킹

**Coldplay 스타일:**
```
오른손: 코드를 통째로 (4분음표)
왼손: 베이스 워킹
```

**Elton John 스타일:**
```
왼손: 옥타브 베이스 (1·3박 강조)
오른손: 블록 코드 + 경과음
```

### 발라드 팝 반주

**특징:**
- 섬세하고 감성적
- 페달 활용
- 보컬을 돋보이게

**Adele 스타일 발라드:**
```
스타트: 피아노 (매우 조용하게)
점진: 코드가 채워지며 서서히 커짐
절정: 풀 코드 + 강한 다이나믹
```

## 코드 전환의 부드러움

### 공통음 유지 (Common Tone)

**C → Am 전환:**
```
C Maj: C-E-G
Am:    A-C-E
공통음: C와 E — 이 음들을 손가락에 남기기
```

**F → G 전환:**
```
F Maj: F-A-C
G Maj: G-B-D
공통음 없음 — 부드럽게 연결

연결 기법: F 코드에서 G로 가는 경과음 (F#) 삽입
```

### 베이스 라인 연결

**왼손 베이스 워킹:**
```
C → F 진행:
왼손: C3 - D3 - E3 - F3 (스케일 워킹업)
```

## 서스펜션과 색채 추가

### Sus4 보이싱

팝에서 긴장감을 만드는 서스펜션:

**Gsus4 → G:**
```
Gsus4: G-C-D (4음이 3음 대신)
G:     G-B-D (해결)
```

**팝 발라드에서 Sus4:**
```
Verse 끝: Gsus4 (긴장)
Chorus 시작: G (해결 + 폭발)
```

### Add9 보이싱

색채를 더하는 Add9:

**C Add9:**
```
C-E-G + D(9음) = C-D-E-G
더 밝고 풍부한 느낌
```

## 음악연습실 팝 반주 연습

### 스튜디오 놀 피아노로 연습

**반주 연습 루틴 (50분):**

**1. 아르페지오 기초 (10분)**
   - Am-F-C-G를 아르페지오로
   - 8분음표, 16분음표 각각

**2. 장르별 패턴 (20분)**
   - K-Pop 발라드 패턴
   - 어쿠스틱 팝 패턴
   - 팝록 블록 코드

**3. 보컬 반주 연습 (20분)**
   - 즐겨 부르는 곡의 피아노 반주
   - 보컬을 상상하며 반주 뒷받침
