    a: >-
      코드 멜로디 기본: ① 멜로디 최고음 — 최고 현(1·2현)에 멜로디 배치 ② 코드 아래 — 나머지 현에 코드 보이싱 ③ 멜로디 강조
      — 멜로디 음을 다른 음보다 강하게 ④ 바레 코드 — 멜로디가 1현에 있을 때 바레 코드 형태 ⑤ 오픈 현 활용 — 코드의 오픈
      현으로 코드 배치. 코드 멜로디의 핵심은 '멜로디가 들려야 한다'는 것입니다. 기술적으로는 코드와 멜로디를 동시에 치지만, 청중의

      음역 배치 설계: ① 멜로디 음역 분석 — 원곡 멜로디의 최고음·최저음 파악 ② 기타 음역 — 멜로디가 기타 음역에서 연주 가능한지
      ③ 이조 — 기타에 맞는 키로 조옮김 ④ 재배치 — 너무 높거나 낮은 음을 한 옥타브 이동 ⑤ 코드 배치 — 멜로디 아래쪽에 코드
      구성음 배치. 코드 멜로디 편곡에서 이조(조옮김)는 매우 중요합니다. 원래 키에서는 기타로 연주하기 불편할 수 있으므로 G, C,
      D, E, A 등 기타 친화적인 키로 이조하는 것이 일반적입니다.
  - q: 기타 코드 멜로디에서 보이스 리딩을 자연스럽게 하는 방법은?
    a: >-
      보이스 리딩 기법: ① 최소 이동 — 코드 전환 시 각 성부가 최소한으로 이동 ② 반진행 — 한 성부가 올라갈 때 다른 성부가
      내려가기 ③ 멜로디 연속성 — 멜로디가 끊기지 않고 이어지도록 ④ 베이스 라인 — 베이스도 멜로디처럼 자연스러운 흐름 ⑤ 내성부 연결
      — 중간 성부도 매끄럽게 이동. 보이스 리딩이 잘 된 코드 멜로디는 여러 선율이 동시에 흐르는 것처럼 들립니다. 각 성부가
      독립적이면서도 전체가 어우러지는 것이 목표입니다. 바흐의 코랄 편곡에서 최고의 보이스 리딩 예시를 찾을 수 있습니다.
  - q: 기타 코드 멜로디를 처음 배우는 사람이 시작하기 좋은 곡은?

      기타 친화 키 — G·C·D·A·E 키의 곡 ④ 예시 곡 — Autumn Leaves, Yesterday, 단순한 민요 ⑤ 점진적
      복잡화 — 멜로디만→멜로디+베이스→전체 코드. 코드 멜로디 입문의 핵심은 '이미 멜로디를 알고 있는 간단한 곡'을 선택하는 것입니다.

## 코드 멜로디로 기타 한 대가 오케스트라가 됩니다

멜로디+코드 동시 연주부터 보이스 리딩까지. 방음 개인실에서 기타 코드 멜로디를 탐색하세요.

기타 코드 멜로디 훈련의 핵심:
- **최고음 멜로디**: 1·2현에 멜로디를 배치하고 나머지 현에 코드 보이싱
- **멜로디 강조**: 코드 안에서 멜로디만 더 강하게 치는 기술
- **음역 설계**: 기타 음역에 맞게 이조하고 음을 재배치하는 편곡 전략
- **보이스 리딩**: 코드 전환 시 각 성부가 최소 이동으로 자연스럽게 흐르기

## 기타 코드 멜로디·솔로 기타 편곡 훈련의 핵심 원칙 4가지

코드는 단순히 모양을 외우는 것이 아니라 **음악적 기능을 이해하면서 익히는** 것이 장기 기억에 훨씬 유리합니다.

1. **코드 기능 이해** — 각 코드가 I(토닉)·IV(서브도미넌트)·V(도미넌트) 중 어떤 기능인지 이해하며 연습. 기능을 알면 처음 보는 곡도 빠르게 코드를 파악할 수 있습니다.

2. **최소 이동 보이싱** — 코드 전환 시 손가락 이동을 최소화하는 보이싱 탐색. 공통 음을 중심으로 나머지 손가락만 이동하면 전환 속도가 빨라집니다.

3. **장르 맞춤 코드 색채** — 팝은 개방 코드의 따뜻함, 재즈는 7th·9th·13th 텐션, 클래식은 클로즈드 보이싱의 단단함을 각각 탐색하세요.

4. **코드톤 아르페지오** — 각 코드를 아르페지오로 분해하며 내성 음의 움직임을 귀로 인식. 코드와 선율의 관계가 명확해집니다.

### 기타 코드 연습에서 자주 하는 실수

1. **손가락을 눕혀서 인접 현을 뮤팅** — 각 손가락 끝을 세워서 프렛 바로 뒤를 누르기
2. **코드 전환 시 손 전체를 들어올림** — 기준 손가락(1지)을 최대한 이동하지 않고 전환
3. **스트로크 없이 코드 잡기만 연습** — 코드 전환 후 즉시 스트로크해서 '연주 흐름' 익히기
4. **바레 코드를 너무 일찍 시도** — 오픈 코드를 완전히 익힌 후 바레 코드로 진행

### 기타 코드 자가 진단

- [ ] G → C → Am → Em 코드 전환이 1박 안에 완성되는가?
- [ ] 코드 전환 후 첫 스트로크가 끊기지 않는가?

## Studio NOL이 코드 멜로디 연습실 사용자에게 자주 권하는 3가지

스튜디오 놀(연신내, 서울 은평구) 음악연습실에서 기타 코드 멜로디·솔로 기타 편곡 연습 상담에서 반복적으로 드리는 조언입니다.

**1. 멜로디 음정 — 최상단 현에 배치**

코드 멜로디는 멜로디가 최상단 현(1번줄)에 들리도록 배치합니다. 멜로디가 묻히면 코드 멜로디가 아니라 코드 워크가 됩니다.

**2. Drop 2 보이싱 — 4성부 골격**

코드 멜로디의 골격은 Drop 2 보이싱입니다. maj7·m7·dom7 4가지 Drop 2를 4개 현 그룹별로 익힙니다.

**3. 베이스 음정 — 엄지 사용**

엄지로 6번줄 베이스 음정을 잡으면 풀 코드 멜로디가 가능해집니다. 클래식 그립으로는 어려운 표현입니다.
