## 코드 멜로디로 기타 한 대가 오케스트라가 됩니다

멜로디+코드 동시 연주부터 보이스 리딩까지. 방음 개인실에서 기타 코드 멜로디를 탐색하세요.

기타 코드 멜로디 훈련의 핵심:
- **최고음 멜로디**: 1·2현에 멜로디를 배치하고 나머지 현에 코드 보이싱
- **멜로디 강조**: 코드 안에서 멜로디만 더 강하게 치는 기술
- **음역 설계**: 기타 음역에 맞게 이조하고 음을 재배치하는 편곡 전략
- **보이스 리딩**: 코드 전환 시 각 성부가 최소 이동으로 자연스럽게 흐르기

## 코드 멜로디를 소리로 만드는 4가지 연습 기준

멜로디와 반주를 기타 한 대로 동시에 내는 코드 멜로디는 코드 이름을 아는 것만으로는 소리가 나오지 않습니다. 이 글의 구성 요소 표와 훈련 단계 표를 연습실에서 실제 손으로 옮길 때 기준이 되는 네 가지입니다.

1. **멜로디를 1·2현에 올리기** — 멜로디 음을 가장 높은 현에 두고 나머지 현에 코드 보이싱을 얹습니다. 같은 코드라도 멜로디 음이 최상단에 오도록 잡는 법을 먼저 찾아야 선율이 화음 위로 또렷이 떠오릅니다.

2. **멜로디만 더 세게 치기** — 한 번에 여러 줄을 울리더라도 멜로디 음만 다른 음보다 강하게 칩니다. 오른손 엄지로 6번 줄 베이스를 받치고 멜로디를 앞세우면 저음-화음-멜로디의 층이 나뉘어 들립니다.

3. **음역에 맞춰 이조·재배치하기** — 원곡 키에서 멜로디가 너무 높거나 낮아 잡히지 않으면 G, C, D, E, A처럼 기타 친화적인 키로 조옮김하고, 벗어나는 음은 한 옥타브 옮겨 배치합니다. 코드 구성음은 항상 멜로디 아래쪽에 둡니다.

4. **전환 때 성부 최소 이동으로 잇기** — 코드가 바뀔 때 각 성부가 가능한 한 가깝게 움직이도록 보이싱을 고릅니다. 멜로디가 끊기지 않고 이어지고, Drop 2 보이싱을 현 그룹별로 익혀 두면 이 선택지가 넓어집니다.

## 코드 멜로디는 멜로디가 코드 위로 떠올라야 완성됩니다

코드 멜로디는 반주와 멜로디를 기타 한 대로 동시에 연주하는, 솔로 기타의 꽃이에요. 여기서 가장 중요한 원칙은 멜로디가 반드시 들려야 한다는 겁니다. 멜로디 음을 가장 높은 현, 즉 1번 줄 쪽에 배치해 코드 위로 또렷이 떠오르게 해야 해요. 멜로디가 화음 속에 묻히면 그건 코드 멜로디가 아니라 그냥 코드를 친 것에 불과합니다.

그 골격이 되는 게 Drop 2 보이싱이에요. 네 성부 코드에서 위에서 두 번째 음을 한 옥타브 내려 배치하는 이 보이싱은, 멜로디를 최상단에 두면서도 손이 편하게 잡히도록 해 줍니다. maj7, m7, dom7의 Drop 2를 각 현 그룹별로 익혀 두면 코드 멜로디의 재료가 갖춰져요.

풀 사운드를 원한다면 엄지를 쓰세요. 오른손 엄지로 6번 줄 베이스를 짚어 주면 저음-화음-멜로디가 한꺼번에 울려 훨씬 두툼한 코드 멜로디가 됩니다. 코드 멜로디의 재료가 되는 재즈 보이싱은 [기타 재즈 코드·재즈 보이싱](/stories/practice-room-guitar-jazz-voicing1)에서 이어집니다.
