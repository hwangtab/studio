## 코드 멜로디로 기타 한 대가 오케스트라가 됩니다

멜로디+코드 동시 연주부터 보이스 리딩까지. 방음 개인실에서 기타 코드 멜로디를 탐색하세요.

기타 코드 멜로디 훈련의 핵심:
- **최고음 멜로디**: 1·2현에 멜로디를 배치하고 나머지 현에 코드 보이싱
- **멜로디 강조**: 코드 안에서 멜로디만 더 강하게 치는 기술
- **음역 설계**: 기타 음역에 맞게 이조하고 음을 재배치하는 편곡 전략
- **보이스 리딩**: 코드 전환 시 각 성부가 최소 이동으로 자연스럽게 흐르기
