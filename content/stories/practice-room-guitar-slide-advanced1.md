# 기타 슬라이드 고급·보틀넥 기법 — 음악연습실 완전 가이드

슬라이드 기타는 **음과 음 사이를 끊임없이 흐르는 표현의 예술**입니다. 보틀넥이나 금속 슬라이드로 현을 누르지 않고 미끄러지며, 기타가 목소리처럼 신음하고 노래합니다. Duane Allman, Ry Cooder, Derek Trucks의 고급 슬라이드 기법을 탐구합니다.

---

## 슬라이드 기타 기초 복습

### 슬라이드 선택

**슬라이드 소재별 음색:**
- **유리 (Glass):** 부드럽고 따뜻한 소리 — 블루스, 포크
- **금속 (Metal/Steel):** 밝고 날카로운 소리 — 록, 컨트리
- **세라믹:** 중간 — 다목적
- **구리 (Brass):** 따뜻하고 두터운 중저음

**손가락 위치:**
- 소지(새끼손가락): 가장 일반적 — 나머지 손가락이 자유
- 약지: Duane Allman 선호 — 더 빠른 프렛팅 가능

## 오픈 튜닝

### 오픈 E 튜닝

**표준 E에서:**
```
표준: E-A-D-G-B-E
오픈 E: E-B-E-G#-B-E
변경: 5현 A→B, 4현 D→E, 3현 G→G#
```

**장점:**
- 열린 현이 E 메이저 코드
- 슬라이드로 모든 포지션에서 메이저 코드

### 오픈 G 튜닝

**Rolling Stones 스타일 (Keith Richards):**
```
표준: E-A-D-G-B-E
오픈 G: D-G-D-G-B-D
변경: 6현 E→D, 5현 A→G, 1현 E→D
```

**슬라이드에서 오픈 G:**
```
12프렛: G 메이저 코드
7프렛: D 메이저 코드
5프렛: C 메이저 코드
```

### 오픈 D 튜닝

```
D-A-D-F#-A-D
```

블루스 슬라이드에서 자주 사용.

## Duane Allman 스타일

### Allman Brothers Band의 슬라이드

Duane Allman은 **록 슬라이드의 가장 위대한 연주자** 중 한 명.

**특징:**
- 약지에 슬라이드
- 표준 튜닝에서도 슬라이드
- 핑거스타일 + 슬라이드 혼합
- 오버톤 풍부한 인토네이션

**"Layla" 코다 슬라이드 (표준 튜닝):**
```
슬라이드 멜로디: 12-9-7-9-7-5 (고음현)
표준 튜닝에서 장조 멜로디를 슬라이드로
```

### 표준 튜닝 슬라이드

**Allman의 혁신:** 오픈 튜닝 없이 표준 튜닝으로 슬라이드.

**표준 튜닝 슬라이드 요령:**
- 슬라이드를 옆으로 기울여 특정 현만
- 뮤팅이 핵심 — 원하는 현만 울리게
- 코드 포지션 암기 필수

## Derek Trucks 스타일

### 현세대 최고의 슬라이더

Derek Trucks는 Duane Allman의 계보를 이은 **가장 표현적인 슬라이드 기타리스트**.

**특징:**
- 오픈 E 튜닝 선호
- 인도 음악 영향 (마이크로톤)
- 멜로디를 노래처럼

**Trucks 스타일 아프리카·인도 인플루언스:**
```
오픈 E 튜닝
슬라이드로 마이크로톤 (반음 사이 음)
드론 현 유지 + 고음 멜로디
```

### 슬라이드 비브라토 고급

**Trucks의 시그니처 비브라토:**
- 매우 부드럽고 느린 비브라토
- 손목 회전이 아닌 팔 전체로
- 음이 완전히 자리 잡은 후 비브라토 시작

**빠른 비브라토 vs 느린 비브라토:**
- **빠른 비브라토:** 긴급한 감정, 록 느낌
- **느린 비브라토:** 서정적, 블루스 느낌

## Ry Cooder 스타일

### 월드 뮤직 슬라이드

**Ry Cooder의 특징:**
- 하와이안·멕시칸·블루스 혼합
- 슬랙 키 (Slack Key) 영향
- 텍스처 지향

**하와이안 슬라이드 기법 (Ry Cooder 스타일):**
```
슬랙 키 튜닝에서
슬라이드가 매우 부드럽게
페달 스틸 기타 모방
```

## 슬라이드 인토네이션

### 슬라이드의 가장 큰 도전

슬라이드에서 **정확한 피치**가 가장 어려움.

**왜 어려운가:**
- 프렛이 없어 정확한 위치 없음
- 1mm 차이로 음이 달라짐
- 귀로만 위치 판단

**훈련 방법:**
1. 튜너 앱 보며 포지션 확인
2. 한 음에서 정확한 위치 반복
3. 눈을 감고 귀로만 판단
4. 느리게 시작, 정확도 우선

### 프렛 위 vs 프렛 뒤

**정확한 위치:**
- 프렛 바로 위 (표준 기타 운지와 반대)
- 슬라이드를 프렛 직상방에

## 슬라이드 뮤팅

### 왼손 뮤팅

슬라이드 뒤의 현 뮤팅:

**기법:**
- 슬라이드 뒤에 검지·중지를 가볍게 올려 뮤팅
- 원하지 않는 현이 울리지 않게

**오픈 튜닝에서 전현 슬라이드:**
- 모든 현이 슬라이드 될 수 있으므로 위아래 뮤팅 중요

### 오른손 뮤팅

**핑거피킹 뮤팅:**
- 치지 않는 저음현을 엄지로 뮤팅
- 치지 않는 고음현을 손바닥 측면으로 뮤팅

## 장르별 슬라이드

### 델타 블루스 슬라이드

**Son House·Robert Johnson 스타일:**
- 오픈 G 또는 오픈 D 튜닝
- 매우 날것의 표현
- 자연스러운 음정 부정확도가 표현의 일부

### 알라배마 록 슬라이드

**Allman Brothers 스타일:**
- 표준 또는 오픈 E 튜닝
- 더 정제된 인토네이션
- 재즈 화성 영향

### 컨트리 슬라이드

**Jerry Lee Lewis·Dobro 스타일:**
- 오픈 G 또는 오픈 D
- 컨트리 멜로디를 슬라이드로
- 레조네이터 기타(Dobro) 특유의 소리

## 음악연습실 슬라이드 연습

### 스튜디오 놀에서 슬라이드 연습

**이펙터 설정:**
```
컴프레서: 소프트 (다이나믹 유지)
리버브: 약간 (공간감)
트레몰로: 선택적 (빈티지 느낌)
앰프: 클린 또는 약한 오버드라이브
```

### 연습 루틴 (60분)

**1. 인토네이션 훈련 (15분)**
   - 12프렛, 7프렛, 5프렛 정확히
   - 튜너로 확인

**2. 비브라토 (10분)**
   - 느린 비브라토부터
   - 음이 안정된 후 비브라토 시작

**3. 블루스 스케일 슬라이드 (20분)**
   - 오픈 E에서 E 블루스 스케일
   - 각 음에서 비브라토 적용

**4. 자유 탐구 (15분)**
   - 좋아하는 슬라이더 흉내
   - 녹음하며 분석
