## 예천에서 KTX로 서울까지

예천은 경북 북부 도시로, 안동역 KTX를 통해 서울과 약 3시간대로 연결됩니다. 사과로 유명한 예천에서 당일 서울 스튜디오 방문이 가능합니다.

---

## 예천 → 연신내 이동 경로

### KTX 안동역 경유 (권장)

```
① 예천 → 안동역 (버스 약 30~40분)
② 안동역 KTX 탑승 (서울역 방면, 약 2시간)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간~3시간 30분
```

---

## 당일 왕복 일정 예시 (예천 기준)

```
오전 6시 30분 예천 출발 → 안동역 이동
오전 7시 20분 안동역 KTX 출발
→ 오전 9시 20분 서울역 도착
→ 오전 10시 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 서울역 출발
→ 오후 4시 안동역 도착
→ 오후 4시 45분 예천 도착
```

---

## 온라인 파일 의뢰 서비스

```
예천 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
