# 일렉 슬라이드 기타·보틀넥·Duane Allman 스타일 — 음악연습실 완전 가이드

일렉트릭 슬라이드 기타(Electric Slide Guitar)는 **블루스의 절규와 노래**입니다. 보틀넥(Bottleneck) 또는 유리·크롬 슬라이드로 현 위를 미끄러지며 만드는 소리는 기타가 말하는 것처럼 들립니다. Duane Allman의 "Layla" 슬라이드, Derek Trucks의 인도 음악 영향 — 이들이 일렉 슬라이드를 예술의 경지로 끌어올렸습니다.

---

## 일렉 슬라이드 기타란?

### 어쿠스틱 vs 일렉 슬라이드

| | 어쿠스틱 슬라이드 | 일렉 슬라이드 |
|--|---------------|-----------|
| 앰프 | 없음 | 필수 |
| 소리 | 투명하고 어쿠스틱 | 왜곡·오버드라이브 가능 |
| 표현 | 자연적 음량 | 다이내믹 범위 넓음 |
| 뒤틀림 | 없음 | 오버드라이브로 노래 |
| 대표 | 도브로, 어쿠스틱 랩 스틸 | 일렉 솔리드·세미 할로우 |

### 슬라이드 선택

**재질별 소리:**
```
유리 슬라이드: 부드럽고 따뜻 (Derek Trucks 애용)
크롬/스틸: 밝고 선명한 (Duane Allman)
황동: 두껍고 지속음이 긴
도자기: 중간 정도
```

**슬라이드 손가락 위치:**
```
약지 또는 중지에 슬라이드 착용
= 다른 손가락들이 자유롭게
(특히 인덱스로 뮤트)
```

## Duane Allman 스타일

### 일렉 슬라이드의 황제

Duane Allman(Allman Brothers Band, Derek and the Dominos):
- **E 오픈 튜닝:** 개방현 = E 장조 코드
- **타이트한 비브라토:** 빠르고 정확한 피치 비브라토
- **멜로디 중심:** 슬라이드로 보컬 멜로디를 노래

**"Layla" 슬라이드 세팅:**
```
E 오픈 튜닝: E-B-E-G#-B-E (낮음→높음)
앰프: Marshall + 오버드라이브
= 따뜻하고 크림 같은 슬라이드 톤
```

**Duane 비브라토:**
```
프레이즈 끝에 강한 비브라토
바를 빠르게 앞뒤로
= 목소리처럼 떨리는 슬라이드
```

## Derek Trucks 스타일

### 현대 슬라이드의 거장

Derek Trucks(Tedeschi Trucks Band, Allman Brothers):
- **유리 슬라이드:** 부드럽고 표현적인 톤
- **인도 음악 영향:** 라가(Raga) 스케일 사용
- **마이크로토날:** 반음보다 작은 음정 변화

**Derek 슬라이드 특징:**
```
클린 앰프: 오버드라이브 없이 클린
= 슬라이드 음색 자체로 표현
음악성: 블루스 + 인도 + 가스펠
```

**Derek의 클린 톤 비결:**
```
Komet 앰프: 작고 뜨거운 클린 앰프
볼륨 낮게 + 슬라이드 터치로 다이나믹
= 아름다운 클린 슬라이드 톤
```

## E 오픈 튜닝

### 슬라이드의 기본 튜닝

**E 오픈 튜닝 (EBEGsB#BE):**
```
6번 줄: E (표준과 동일)
5번 줄: B (표준과 동일)
4번 줄: E (2반음 높임, D→E)
3번 줄: G# (1반음 높임, G→G#)
2번 줄: B (표준과 동일)
1번 줄: E (표준과 동일)
```

**개방현 = E 장조 코드 (E-B-E-G#-B-E)**

**오픈 튜닝의 장점:**
```
바 하나로 모든 메이저 코드
블루스 포지션 쉽게 접근
슬라이드 라인이 자연스럽게
```

## 슬라이드 기법

### 인토네이션 정확도

**핵심: 프렛 바로 위에 슬라이드**
```
5프렛 A음: 슬라이드가 5프렛 철사 바로 위
= 정확한 피치
프렛 사이면: 음정 어긋남
```

**연습 방법:**
```
단일 음 반복하며 인토네이션 확인
드론 현과 비교 (베이스 줄 오픈)
= 정확한 위치 감각 개발
```

### 비브라토 기법

**슬라이드 비브라토:**
```
목표 프렛 위에서 슬라이드를 앞뒤로
빠르게 흔들기 (5-7번 앞뒤)
= 음정이 위아래로 진동
```

**다양한 비브라토 폭:**
```
와이드: 반음 정도 변화 (강한 표현)
나로우: 미세한 변화 (섬세한 표현)
```

### 슬라이드 뮤팅

**왼손 뮤팅 (슬라이드 착용 손):**
```
슬라이드 뒤의 손가락들로 현 가볍게 닿기
= 원하지 않는 현의 울림 방지
```

**오른손 뮤팅:**
```
치지 않는 현에 오른손 올려두기
= 개방현 잡음 방지
```

## 블루스 슬라이드 포지션

### E 오픈 튜닝에서 주요 포지션

**E 코드 (개방):**
```
전체 개방 = E 장조
```

**A 코드 (5프렛):**
```
5프렛 전체 바 = A 장조
```

**B 코드 (7프렛):**
```
7프렛 전체 바 = B 장조
```

**E7 느낌 (3프렛, 1번 줄만):**
```
3번 프렛 1번 줄 = G# → D (7도)
= E7 코드의 7도음
```

## 음악연습실 슬라이드 기타 연습

### 60분 루틴

**1. E 오픈 튜닝 + 인토네이션 (15분)**
   - 개방현 튜닝 맞추기 (E-B-E-G#-B-E)
   - 1번 줄 단일음 슬라이드 (인토네이션 중점)
   - 프렛 바로 위 위치 연습

**2. 비브라토 훈련 (15분)**
   - 하나의 음에서 비브라토 연습
   - 와이드·나로우 비브라토 구분
   - 비브라토 속도 조절

**3. 블루스 12마디 슬라이드 (20분)**
   - E-A-B 포지션 전환
   - 슬라이드 업·다운 포함 라인
   - Duane Allman 스타일 멜로디

**4. 뮤팅 + 클린 톤 (10분)**
   - 왼손/오른손 뮤팅 확인
   - 앰프 클린으로 슬라이드 톤
   - 전체 블루스 솔로 형태

## 마무리

일렉 슬라이드 기타는 **기타가 노래하는 방식**입니다. Duane Allman이 "슬라이드는 목소리와 가장 가까운 기타 기법"이라고 했듯, 슬라이드는 음정 하나하나가 살아있는 감정입니다. 인토네이션, 비브라토, 뮤팅 — 이 세 가지가 완성되면 슬라이드가 노래합니다.

은평구 24시간 음악연습실에서 E 오픈 튜닝을 맞추고, 첫 슬라이드 라인을 연습해보세요. 프렛 위에 정확히 슬라이드가 올라가는 순간, 블루스의 문이 열립니다.
