# 재즈 기타 코드 멜로디·솔로 기타·Joe Pass 스타일 — 음악연습실 완전 가이드

재즈 기타 코드 멜로디(Chord Melody)는 **멜로디와 화성을 동시에 연주하는 솔로 기타 기법**입니다. Joe Pass의 "Virtuoso" 앨범 — 완전히 혼자서 베이스, 코드, 멜로디를 모두 담당하는 기타. Wes Montgomery의 옥타브 주법, George Benson의 유연한 코드 보이싱 — 코드 멜로디는 재즈 기타의 궁극적인 목표입니다.

---

## 코드 멜로디란?

### 혼자서 풀 앙상블

**코드 멜로디의 구성:**
```

최고음(상성): 멜로디
중간음: 화성 (코드 컬러)
저음(하성): 베이스 음
= 기타 한 대 = 피아노 트리오

```

**왜 어려운가:**
```

멜로디 음이 항상 최고음에 있어야 함
코드 보이싱이 멜로디 음 위치에 맞춰야 함
= 같은 코드라도 보이싱이 달라짐

```

**Joe Pass 접근법:**
```

모든 스탠다드를 코드 멜로디로 연주
베이스, 멜로디, 코드 동시에
= 기타 하나로 피아니스트처럼

```

---

## 코드 멜로디 기초

### 멜로디를 최고음으로

**C 코드 위 멜로디 E:**
```

일반 C 코드 (E가 최고음): x-3-2-0-1-0
멜로디 E가 최고음 = 정상
멜로디 E가 낮은 위치 = 문제 → 보이싱 변경

```

**보이싱 선택의 원칙:**
```
1. 멜로디 음 최고음 위치 찾기
2. 그 음이 포함된 코드 보이싱 찾기
3. 베이스 음 추가 (최저음)
= 샌드위치: 베이스 - 코드 - 멜로디

```

**G 코드 위 멜로디 D:**
```

D가 최고음인 G 코드 보이싱: x-5-4-0-3-x
또는: 3-5-4-0-3-x
= D가 꼭대기에 있어야 함

```

---

## "Autumn Leaves" 코드 멜로디

### 가장 기본적인 스탠다드

**Autumn Leaves 코드 진행 (G 단조):**
```

Cm7 | F7 | Bbmaj7 | Ebmaj7 |
Am7b5 | D7 | Gm7 | Gm7

```

**각 코드의 멜로디 음:**
```

첫 구절: "The falling leaves..." → 멜로디 B♭
각 멜로디 음을 최고음으로 보이싱 잡기

```

**접근 순서:**
```
1. 멜로디만 (단음으로) 연주 → 완전히 외우기
2. 각 멜로디 음에 베이스 추가 (2성)
3. 중간 화성음 추가 (3~4음 코드 완성)

```

---

## 코드 멜로디 보이싱 라이브러리

### 필수 보이싱들

**멜로디 E, 코드 Am7 (A 마이너7):**
```

x-0-2-0-1-0 또는 5-7-7-0-x-x
= E가 최고음에 있는 Am7

```

**멜로디 D, 코드 G7:**
```
3-x-0-0-1-x 또는 x-x-0-0-0-3
= D가 최고음에 있는 G7

```

**멜로디 F, 코드 Cmaj7:**
```

x-3-2-0-1-x (F는 없는 보이싱이므로 다른 것)
= Cmaj7 위에 F는 #11도 → 텐션 사용

```

---

## 베이스 라인 통합

### 코드 멜로디 + 워킹 베이스

**Joe Pass 스타일 베이스:**
```

저음 현(E, A)으로 베이스 음 연주
중간 현으로 코드 화성
고음 현으로 멜로디
= 완전한 솔로 기타 편성

```

**워킹 베이스 + 코드 멜로디:**
```
1박: 베이스 음 (루트)
2박: 코드 + 멜로디 (동시에)
3박: 베이스 음 (5도 또는 패싱)
4박: 코드 + 멜로디
= 베이스와 코드 멜로디 교대

```

## 옥타브 주법 (Wes Montgomery)

### 코드 멜로디의 확장

**Wes Montgomery 옥타브:**
```

멜로디를 옥타브로 (두 현 동시에)
엄지 손가락으로 연주
= 더 풍성하고 따뜻한 소리

```

**옥타브 포지션:**
```

E 현 7 프렛 + D 현 9 프렛 = 옥타브 B
A 현 7 프렛 + G 현 9 프렛 = 옥타브 E

```

## 음악연습실 재즈 기타 코드 멜로디 연습

### 60분 루틴

**1. 멜로디 암기 (15분)**
   - "Autumn Leaves" 멜로디 단음으로
   - 포지션 2~3개로 외우기
   - 음 이름 알기 (각 음이 무슨 음인지)

**2. 베이스 + 멜로디 (15분)**
   - 각 멜로디 음에 베이스 추가 (2성부)
   - 코드 없이 베이스-멜로디만
   - 두 성부가 독립적으로 흐름

**3. 코드 보이싱 추가 (20분)**
   - 각 멜로디 음에 맞는 코드 보이싱
   - 천천히 (♩= 60)
   - 멜로디가 항상 최고음인지 확인

**4. 전체 곡 연주 (10분)**
   - "Autumn Leaves" 처음부터 끝까지
   - 자연스럽게 흐르도록
   - Joe Pass처럼 솔로 기타로

## 마무리

재즈 기타 코드 멜로디는 **기타를 오케스트라로 만드는 예술**입니다. Joe Pass가 "기타 하나면 충분하다"고 했듯, 멜로디·화성·베이스를 동시에 담을 수 있을 때 기타는 가장 완전한 악기가 됩니다. 처음에는 한 음씩, 천천히 — 수천 번의 반복이 코드 멜로디를 손에 익게 합니다.

은평구 24시간 음악연습실에서 멜로디 단음 암기부터 시작하세요. 첫 코드가 멜로디와 함께 울리는 날, 재즈 기타의 문이 활짝 열립니다.

---

## 재즈 코드 멜로디는 화음 위로 노래가 흘러야 합니다

재즈 코드 멜로디는 Joe Pass처럼 기타 한 대로 멜로디와 화음을 동시에 연주하는, 재즈 기타의 정점이에요. 절대 원칙은 멜로디가 반드시 들려야 한다는 겁니다. 멜로디 음을 가장 높은 현, 즉 1번 줄 쪽에 배치해 화음 위로 또렷이 떠오르게 해야 해요. 멜로디가 코드 속에 묻히면 그건 코드 멜로디가 아니라 그냥 코드를 짚은 것에 불과합니다.

그 골격이 드롭 2 보이싱이에요. 멜로디를 최상단에 두면서도 아래에 화음을 편하게 깔 수 있는 이 폼을, maj7·m7·dom7 네 종류로 각 현 그룹에서 익혀 두면 코드 멜로디의 재료가 갖춰집니다. 멜로디 음을 어느 보이싱의 꼭대기에 올릴지 고르는 게 편곡의 핵심이에요.

이 감각은 거장을 통해 배우는 게 가장 빠릅니다. Joe Pass와 Wes Montgomery의 코드 멜로디를 트랜스크라이브하면, 그들이 멜로디 아래에 화음을 어떻게 채우고 비우는지가 손에 들어와요. 보이싱을 고르는 기초 원리는 [기타 재즈 보이싱](/stories/practice-room-guitar-jazz-voicing1)에서 다집니다.
