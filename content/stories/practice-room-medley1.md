## 메들리는 연결의 예술입니다

여러 곡을 하나의 흐름으로 만드는 메들리는 공연의 하이라이트가 됩니다. 각 곡의 완성도와 함께, 곡 사이 전환이 자연스러워야 진짜 메들리입니다.

메들리 연습의 포인트:
- **개별 완성**: 각 곡을 먼저 완전히 익혀야
- **전환 집중**: 연결 구간이 메들리의 승부처
- **완주 훈련**: 중간에 멈추지 않는 습관
- **청중 흐름**: 에너지 곡선을 의식하며 구성

---

## 메들리 전환 유형별 연습법

### 같은 키 직접 연결

```

곡A 마지막 음 → 곡B 첫 음 (즉시)
연습: 두 곡의 연결 지점 10마디씩 반복

```

### 모듈레이션 (전조)

```

곡A 끝 → [2박 전환 화음] → 곡B (반음 또는 온음 위)
연습: 전환 화음 패턴 30회 반복

```

### 리듬 브릿지

```

곡A 끝 → 타악기·반주만 4박 → 곡B 시작
연습: 브릿지 구간 단독 반복 + 전후 연결

```

## 메들리 구성 예시 (15분 공연용)

| 곡 번호 | 성격 | 길이 | 전환 방식 |
|-------|------|------|---------|
| 1번 | 서정적·느림 | 3분 | 모듈레이션 |
| 2번 | 미디엄 템포 | 3분 | 직접 연결 |
| 3번 | 업템포 | 3분 | 리듬 브릿지 |
| 4번 | 클라이맥스 | 4분 | — |
| 마무리 | 여운 | 2분 | — |

## 메들리 연습 스케줄 (2시간)

| 시간 | 내용 |
|-----|------|
| 0~20분 | 워밍업 + 각 곡 간단 복습 |
| 20~50분 | 전환 구간 집중 연습 (각 20회) |
| 50~80분 | 전체 메들리 완주 2~3회 |
| 80~100분 | 녹음 후 전환 부분 확인 |
| 100~120분 | 수정 후 최종 완주 |

---

### 메들리 연습 원칙

| 원칙 | 내용 |
|---|---|
| 개별 곡 완성이 먼저 | 전환 연습은 각 곡이 따로 완주 가능해진 뒤에 시작 |
| 전환 구간에 시간을 몰아준다 | 전체 반복 시간의 절반 이상을 이음새 20~30회 반복에 배정 |
| 멈추지 않고 끝까지 | 실수해도 다음 곡으로 넘어가는 훈련을 완주 연습마다 포함 |

### 메들리 연습에서 자주 하는 실수

1. **개별 곡이 덜 익은 상태에서 연결부터 연습** — 곡 자체가 불안하면 전환은 더 불안해짐. 각 곡을 따로 완성한 뒤 이어야 함
2. **전환 구간을 대충 지나치기** — 곡 안에서는 안 틀리는데 이음새에서만 흔들리는 경우가 많음. 전환 전후 10마디를 따로 떼어 집중 반복
3. **한 번 끊기면 처음부터 다시** — 실전에서는 이 방식이 통하지 않음. 끊긴 지점부터 바로 이어 가는 연습이 필요

### 메들리 연습 자가 진단

- [ ] 메들리에 들어가는 곡을 각각 따로 완주할 수 있는가?
- [ ] 전환 구간만 따로 떼어 20회 이상 반복했는가?
- [ ] 중간에 실수해도 멈추지 않고 끝까지 이어 가는 훈련을 했는가?

## 메들리 완성 4주 로드맵

1주차는 메들리에 들어갈 각 곡을 개별로 완성하는 데 씁니다. 전환은 아직 신경 쓰지 말고 곡 하나하나의 완성도부터 확보합니다. 2주차는 곡과 곡 사이 전환 지점을 정하고 그 구간만 집중적으로 반복합니다. 같은 키로 이을지, 전조를 넣을지, 리듬 브릿지를 쓸지 정한 뒤 각 전환을 20~30회씩 연습합니다. 3주차는 전체 메들리를 처음부터 끝까지 이어 붙여 완주합니다. 중간에 실수해도 멈추지 않고 계속 가는 습관을 이 주차부터 들입니다. 4주차는 녹음과 실전 시뮬레이션입니다. 전체를 녹음해 전환 부분이 자연스러운지 확인하고, 필요하면 곡 순서나 전환 방식을 다시 조정합니다.

## 메들리의 승부는 곡과 곡 사이의 이음새에서 갈립니다

메들리를 준비하는 분들이 곡 하나하나는 잘 부르는데 이어 붙이면 어색해지는 경우가 많아요. 문제는 곡 자체가 아니라 곡 사이의 이음새예요. 특히 키가 뚝뚝 끊기면 듣는 사람이 덜컥거림을 느낍니다. 그래서 곡 순서를 짤 때 키를 고려하세요. 5도권에서 가까운 키끼리 이으면 전조가 자연스럽고, 필요하면 사이에 짧은 전조 구간을 넣어 부드럽게 넘어가면 됩니다.

곡 순서에도 전략이 있어요. 가장 강하고 임팩트 있는 곡을 후반에 배치해야 메들리 전체가 점점 고조되며 끝에서 터집니다. 반대로 초반에 다 써 버리면 뒤로 갈수록 김이 빠져요.

곡과 곡 사이를 잇는 방법도 미리 준비해 두세요. 짧은 멘트 한마디, 또는 다음 곡으로 흘러가는 인스트루멘탈 브리지가 있으면 이음새가 매끄러워집니다. 무대 전체를 하나의 흐름으로 설계하는 감각은 [음악 경연대회·가요제 준비](/stories/practice-room-competition1)에서 이어집니다.
