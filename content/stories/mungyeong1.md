## 문경에서 서울까지

문경은 경북 북서부 도시로, 고속버스 또는 김천구미역 KTX를 통해 서울과 연결됩니다. 문경새재의 고장 문경에서 서울 스튜디오 방문이 가능합니다.

---

## 문경 → 연신내 이동 경로

### 고속버스 이용 (권장)

```
① 문경 버스터미널 → 동서울터미널 (약 2시간 30분~3시간)
② 동서울터미널 → 지하철 2호선 → 신촌 → 연신내역 (약 40분)

총 소요시간: 약 3시간 10분~3시간 40분
```

### KTX 김천구미역 경유 (선택)

```
① 문경 → 상주 → 김천구미역 (버스 약 1시간 20분)
② 김천구미역 KTX 탑승 (서울역 방면, 약 1시간 30분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간 20분~4시간
```

## 당일 왕복 일정 예시 (문경 기준)

```
오전 6시 30분 문경 출발 (고속버스)
→ 오전 9시 30분 동서울터미널 도착
→ 오전 10시 10분 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 30분 동서울터미널 출발
→ 오후 5시 30분 문경 도착
```
