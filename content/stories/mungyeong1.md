## 문경에서 서울까지

문경은 경북 북서부 도시로, 고속버스 또는 김천구미역 KTX를 통해 서울과 연결됩니다. 문경새재의 고장 문경에서 서울 스튜디오 방문이 가능합니다.

---

## 문경 → 연신내 이동 경로

### 고속버스 이용 (권장)

처음 방문하는 분은 예약 시간 10분 전에 도착하면 여유롭게 시작할 수 있습니다.

1. 문경 버스터미널 → 동서울터미널 (약 2시간 30분~3시간)
2. 동서울터미널 → 지하철 2호선 → 신촌 → 연신내역 (약 40분)

- **총 소요시간**: 약 3시간 10분~3시간 40분

### KTX 김천구미역 경유 (선택)

1. 문경 → 상주 → 김천구미역 (버스 약 1시간 20분)
2. 김천구미역 KTX 탑승 (서울역 방면, 약 1시간 30분)
3. 서울역 → 지하철 → 연신내역 (약 30~40분)

- **총 소요시간**: 약 3시간 20분~4시간

## 당일 왕복 일정 예시 (문경 기준)

입구 위치나 주차 정보가 필요한 경우 예약 전 문의해주시면 안내드립니다.

오전 6시 30분 문경 출발 (고속버스)
- 오전 9시 30분 동서울터미널 도착
- 오전 10시 10분 연신내역 도착
- 오전 10시 30분 세션 시작 (2시간)
- 오후 12시 30분 세션 완료
- 오후 2시 30분 동서울터미널 출발
- 오후 5시 30분 문경 도착

---

## 문경 음악 씬과 서울 스튜디오

문경은 문경새재·석탄박물관 등 역사 관광지가 있는 경북 도시입니다. 점촌역에서 KTX-이음(중부내륙선)을 이용하면 서울까지 약 1시간이면 도달합니다.

## 방문 전 세션 준비 가이드

1시간 30분 이상 이동 후 최상의 컨디션으로 세션에 임하려면 철저한 사전 준비가 필요합니다.

**출발 전 챙길 것:**
- [ ] 녹음할 곡의 가사·악보·MR 파일 (USB 또는 Google Drive)
- [ ] 원하는 사운드의 레퍼런스 트랙 2~3곡
- [ ] 예약 확인 캡처 + 교통편 티켓
- [ ] 보컬: 따뜻한 차·꿀물 보온병, 간식
- [ ] 귀마개 또는 노이즈캔슬링 이어폰 (이동 중 성대 보호)

**이동 중 활용법:**
- 이어폰으로 녹음할 곡 2~3회 예습
- 가사·감정 포인트 집중 정리
- 목·어깨 스트레칭 (장시간 이동 피로 완화)
- 충분한 수분 섭취 (기차 이동 중 성대 건조 방지)

**세션 팁:**
- 도착 후 20~30분 워밍업 시간 확보 (일정 계획 시 반드시 포함)
- 가장 중요한 구간을 세션 초반(이동 피로 전)에 먼저 녹음
- 원하는 사운드를 레퍼런스 곡으로 구체적으로 설명
- 온라인 파일 의뢰 서비스 병행 시 재방문 부담 최소화 가능

## 세션 당일 체크리스트

**전날:**
- [ ] MR·가사·레퍼런스 트랙 파일 최종 확인
- [ ] 교통편 티켓 + 예약 확인 캡처
- [ ] 충분한 수면 + 성대 무리 금지

**출발 전:**
- [ ] 따뜻한 차·꿀물 지참
- [ ] 이동 중 성대 보호 (소리 지르기 금지, 수분 섭취)

**도착 후:**
- [ ] 20~30분 워밍업 확보 (일정에 미리 포함)
- [ ] 엔지니어에게 레퍼런스·사운드 방향 설명
- [ ] 가장 어려운 구간 최우선 녹음

**녹음 중:**
- [ ] 헤드폰 볼륨 확인
- [ ] 테이크마다 즉시 청취
- [ ] 막차 시간 미리 확인 (귀가 일정)
