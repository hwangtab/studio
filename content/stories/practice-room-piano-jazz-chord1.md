faq:
  - q: 재즈 피아노 보이싱이란 무엇인가요?
    a: >-
      재즈 보이싱 기초: ① 정의 — 같은 코드를 어떻게 배치하느냐의 기술 ② 팝 vs 재즈 — 팝은 루트 위 블록 코드, 재즈는 루트
      없이 색채음 강조 ③ 셸 보이싱 — 3도·7도만으로 코드 성격 표현 ④ 텐션 추가 — 9th, 11th, 13th 음으로 색채 강화
      ⑤ 보이싱 원칙 — 목소리 이동 최소화 (Voice Leading). 재즈 보이싱을 익히면 같은 코드도 훨씬 세련되고 입체적으로
      들립니다.
  - q: 셸 보이싱은 어떻게 연습하나요?
    a: >-
      셸 보이싱 연습: ① 정의 — 왼손 루트+7도, 오른손 3도+7도 (또는 반대) ② Cmaj7 셸 — 왼손 C·B, 오른손 E·B ③
      Dm7 셸 — 왼손 D·C, 오른손 F·C ④ All the Things You Are 등 스탠다드에 적용 ⑤ ii-V-I 진행에서
      셸 보이싱 연습. 처음에는 C장조 ii-V-I (Dm7→G7→Cmaj7)만 셸 보이싱으로 반복하면 됩니다.
  - q: '재즈 텐션 코드에서 9th, 11th, 13th는 어떻게 활용하나요?'
    a: >-
      텐션 노트 활용: ① 9th (2도 옥타브 위) — maj7에 자연스러운 컬러 추가 ② #11th — Lydian 느낌, 밝고 신선함
      ③ b9, #9 — 도미넌트에서 긴장감 강화 ④ 13th (6도 위) — 도미넌트 7th에 풍부함 ⑤ 피하는 음 — P11th는
      메이저 코드에 부적절. 텐션은 처음에는 하나씩 추가해서 귀로 확인하는 것이 가장 효과적입니다.
  - q: 재즈 코드 보이싱 학습을 위한 추천 학습 곡은?
    a: >-
      재즈 보이싱 입문 추천 곡: ① 'Autumn Leaves' — ii-V-I 기본 ② 'All the Things You Are' —
      다양한 조성 전환 ③ 'Fly Me to the Moon' — 단순하고 아름다운 진행 ④ 'My Funny Valentine' —
      크로매틱 베이스 ⑤ 'Blue Bossa' — 보사노바 리듬 + 재즈 화성. 방음 개인실에서 원곡을 틀면서 같이 코드를 쳐보는 것이
      귀와 손을 동시에 훈련하는 가장 좋은 방법입니다.

## 재즈 코드는 기본 코드에 색채를 더하는 것입니다

루트를 빼도 코드가 살아있는 재즈 보이싱. 방음 개인실에서 귀로 들으면서 손 아래서 코드가 피어나는 것을 느껴보세요.

재즈 피아노 보이싱 연습의 핵심:
- **셸 보이싱 우선**: 3도·7도만으로 코드 성격 표현
- **Voice Leading**: 코드 전환 시 음 이동 최소화
- **텐션 점진 추가**: 하나씩 추가하며 귀로 확인
- **ii-V-I 반복**: 재즈 진행의 기본 틀 마스터

## 재즈 보이싱 학습 단계

| 단계 | 내용 | 기간 |
|------|------|------|
| 1단계 | 블록 코드 (3·5·7) | 1주 |
| 2단계 | 셸 보이싱 (3·7) | 2~3주 |
| 3단계 | 텐션 추가 (9th) | 1~2개월 |
| 4단계 | 알터드 텐션 | 3~6개월 |
| 5단계 | 스탠다드 적용 | 지속 |

## ii-V-I 보이싱 예시 (C장조)

| 코드 | 셸 보이싱 (왼손) | 텐션 추가 (오른손) |
|------|-------------|------------|
| Dm7 | D·C | F·A·C·E(9th) |
| G7 | G·F | B·D·F·A(9th) |
| Cmaj7 | C·B | E·G·B·D(9th) |

## 재즈 피아노 보이싱·텐션 코드 — 재즈 피아노 핵심 훈련 원칙 4가지

재즈 피아노는 **코드 이론과 즉흥 능력, 스윙 필이 동시에 발전**해야 합니다. 이론 지식이 귀를 통해 손으로 연결될 때 진짜 재즈가 됩니다.

1. **4성부 보이싱 습득** — 루트·3음·7음·9음의 구성을 양손으로 분담하는 4성부 보이싱 마스터. 왼손 루트+5음(또는 루트+7음), 오른손 3음+7음+텐션이 기본 접근입니다.
2. **ii-V-I 12키 완주** — 모든 키에서 ii-V-I 진행을 즉각 반응. 재즈 스탠다드의 80%가 이 진행의 변형이므로 완전한 내재화가 필수입니다.
3. **리듬 컴핑 다양화** — 같은 코드를 다른 리듬 패턴으로 치는 연습. 스트레이트·스윙·래그비트·브러시 패턴 등 다양한 리듬 어휘가 반주 유연성을 높입니다.
4. **스탠다드 멜로디 암기** — 반주 전에 멜로디를 정확히 암기. 멜로디를 알아야 반주가 멜로디를 받쳐주는 음악적 반주가 됩니다.

### 재즈 피아노에서 자주 하는 실수

1. **보이싱이 루트 중심으로 너무 두꺼움** — 베이스가 루트를 잡아주므로 피아노는 3도·7도 중심 보이싱
2. **스윙 리듬 없이 직선적 8분음표** — 장3도/단3도의 셔플 느낌을 귀로 먼저 익히기
3. **코드 진행만 맞추고 즉흥 없음** — 알고 있는 코드 위에 5음 정도의 짧은 라인부터 시작
4. **왼손이 너무 바빠서 그루브 방해** — 왼손을 단순화하고 오른손 라인에 집중
