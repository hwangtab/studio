## 집에서 미디 작업이 어려운 이유

홈 스튜디오에서 미디 작업을 해본 분들이 공통으로 겪는 문제:

- **모니터링 부정확**: 저렴한 스피커로는 정확한 믹스 판단 불가
- **소음 문제**: 새벽에 볼륨을 높일 수 없어 헤드폰에만 의존
- **집중력 방해**: 가족·룸메이트·생활 소음
- **공간 부족**: 건반, 미디 컨트롤러, 모니터 등 장비 배치 어려움

**음악연습실 월세 입주**는 이 모든 문제를 해결합니다.

---

## 미디 작업에 음악연습실이 필요한 이유

### 1. 모니터링 환경

PA 스피커 또는 모니터 스피커가 구비된 음악연습실에서는 집보다 훨씬 정확한 소리 판단이 가능합니다. 특히 저음 대역(베이스, 킥드럼)의 판단에서 차이가 큽니다.

### 2. 야간 작업 가능

방음된 연습실에서는 새벽에도 볼륨을 높여 작업할 수 있습니다. 이웃 소음 신경 없이 창작에 몰입할 수 있습니다.

### 3. 건반 연습 통합

미디 컴포지션 중 건반(피아노, 신디) 연주를 직접 해볼 수 있는 환경입니다. 악보 없이 즉흥적으로 음악을 만들 때 실제 건반이 훨씬 유리합니다.

| 앨범 최종 믹스 | 전문 녹음실 | 스튜디오 엔지니어 필요 |

## 음악연습실 미디 작업 셋업 예시

### 기본 셋업 (개인 장비 지참)

```
노트북(DAW) → 오디오 인터페이스 → 연습실 PA 스피커
노트북 → USB → 미디 키보드/컨트롤러
```

### 연습실 내장 장비 활용

- 디지털 건반(88건반) → 미디 케이블 또는 USB → 노트북
- PA 스피커 → 모니터링 용도

### 효율적인 연습을 위한 원칙

### 효율적인 연습 원칙

- **목표 설정 → 연습 → 검증 루틴** — 목표를 정하고, 집중 연습하고, 녹음으로 개선을 확인하는 3단계를 매 세션에 적용
- **분리 연습 원칙** — 전체 반복보다 문제 구간만 2~4마디 앞부터 분리해서 집중하는 것이 훨씬 효과적
- **완성된 느낌의 함정 경계** — 잘 된다고 느끼는 순간이 실제로 완성된 순간과 다를 수 있음. 녹음으로 객관적 확인 필수

### 연습 중 자주 하는 실수

1. **목표 없는 반복 — 시간만 소비** — 무엇을 개선할지 모르는 반복은 잘못된 패턴만 강화. 매 세션 전 "오늘 이것만은 해결한다" 목표 1개를 설정
2. **어려운 구간 회피 — 약점 지속** — 잘 되는 부분만 반복하면 약점이 영원히 남음. 불편하고 어려운 구간이 실력 향상의 핵심 포인트
3. **자기 연주의 객관적 청취 불가** — 연주 중에는 자신의 소리를 객관적으로 듣기 어려움. 녹음 후 청취로 문제를 발견하고 수정하는 루틴이 필요

### 연습 자가 진단

- [ ] 오늘 연습의 구체적인 목표를 시작 전에 정했는가?
- [ ] 어려운 구간을 분리해서 집중적으로 반복했는가?
- [ ] 연습 후 무엇이 개선되었는지 구체적으로 인식하는가?

## 4주 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 점검 | 기본기 복습, 문제 구간 파악 | 40분 |
| 2주차 | 구간 집중 | 어려운 부분 느린 템포 반복 | 45분 |
| 3주차 | 전체 흐름 | 전곡 연결, 템포 단계적 올리기 | 50분 |
| 4주차 | 완성 | 목표 템포 + 표현·다이나믹 완성 | 60분 |

**주간 체크포인트:** 1주차: 약점 구간 3개 목록 작성 / 2주차: 각 구간 느린 템포 100% 달성 / 3주차: 전곡 끊김 없이 완주 / 4주차: 청중 앞 또는 녹음으로 최종 확인
