# 베이스 왼손 기법·레가토·슬라이드·비브라토 — 음악연습실 완전 가이드

베이스 왼손은 **음의 시작, 연결, 표현을 결정**합니다. 오른손이 소리를 만들어내는 엔진이라면, 왼손은 그 소리의 색깔과 느낌을 결정합니다. 레가토, 슬라이드, 비브라토, 해머온·풀오프 — 이 기법들을 마스터하면 베이스가 노래하게 됩니다.

---

## 왼손 기초

### 왼손 손가락 배치

**기본 원칙 — 한 손가락 한 프렛:**
```
검지(1): 1번 프렛
중지(2): 2번 프렛
약지(3): 3번 프렛
소지(4): 4번 프렛
```

**이 원칙의 중요성:**
```
2프렛 음 → 중지 사용 (검지 아님)
3프렛 음 → 약지 사용
이렇게 해야 손의 이동 최소화
```

### 왼손 엄지 위치

**엄지 = 손의 앵커:**
```
넥의 뒤쪽 중앙
검지 위치 뒤에
너무 위/아래 X
= 안정적인 왼손 지지
```

## 레가토 (Legato)

### 레가토란?

**레가토:** 음과 음을 끊김 없이 부드럽게 연결.

베이스에서 레가토 = **해머온·풀오프·슬라이드의 조합**

### 해머온 (Hammer-On)

**오른손 없이 왼손으로 음 추가:**
```
A2 발음 (오른손으로 연주)
B2 해머온: 중지를 빠르게 2번 프렛에 내리침
= A2 → B2 (오른손 없이)
```

**해머온 핵심:**
```
손가락을 "해머"처럼 강하게 내리침
너무 약하면 소리 안 남
손끝으로 (손가락 끝 마디로)
```

### 풀오프 (Pull-Off)

**오른손 없이 왼손으로 음 제거:**
```
B2 발음 (또는 해머온으로)
A2 풀오프: 중지를 옆으로 당기며 떼기
= B2 → A2 (오른손 없이)
```

**풀오프 핵심:**
```
손가락을 옆으로 당기며 (아래쪽으로)
그냥 떼면 안 됨 — 반드시 당겨야
= A2의 소리가 충분히 남
```

### 연속 레가토

```
해머온+풀오프 연속:
A2(오른손) → B2(해머온) → A2(풀오프) → B2(해머온)...
= 빠른 트릴 효과
```

## 슬라이드 (Slide)

### 슬라이드 업 (Slide Up)

**낮은 음에서 높은 음으로 미끄러지기:**
```
5번 프렛을 눌러서 오른손으로 연주
7번 프렛으로 손가락을 밀어 올리기 (중간에 소리 지속)
= 부드럽게 올라가는 음
```

**표기:** A2 → C2 슬라이드 (또는 /)

### 슬라이드 다운 (Slide Down)

**높은 음에서 낮은 음으로 미끄러지기:**
```
7번 프렛 연주 후
5번 프렛으로 손가락을 내리기
= 부드럽게 내려가는 음
```

### 슬라이드 기법 변형

**인 슬라이드 (In Slide):**
```
목표 음보다 낮은 곳에서 시작하여 슬라이드:
3번 프렛 → 5번 프렛 (목표)
= 목표 음에 "도달"하는 느낌
```

**아웃 슬라이드 (Out Slide):**
```
음을 연주 후 아래로 슬라이드해 나가기:
5번 프렛 연주 → 2번 프렛으로 사라지기
= 음이 "사라지는" 느낌
```

## 비브라토 (Vibrato)

### 베이스 비브라토

**비브라토:** 음정을 빠르게 위아래로 흔들어 소리에 생명감 부여.

**베이스 비브라토 방법:**
```
음을 누른 후
손가락(또는 손목)을 위아래로 빠르게 흔들기
음정이 약간 위아래로 흔들림
= 살아있는 소리
```

**비브라토 종류:**
```
와이드 비브라토: 큰 음정 변화 (반음 정도)
나로우 비브라토: 작은 음정 변화
속도 변화: 느린 → 빠른 비브라토
```

### 비브라토 연습

```
1. 음을 정확하게 발음
2. 2-3초 후 비브라토 시작 (처음에는 없다가)
3. 점점 속도 올리기
4. 음을 끝낼 때 비브라토 멈추기
```

## 왼손 포지션 이동

### 포지션 이동의 부드러움

베이스에서 포지션 이동:
```
5번 프렛 → 10번 프렛으로 이동할 때
슬라이드로 자연스럽게 연결
또는 빠르게 이동하여 포지션 바꾸기
```

**부드러운 이동:**
```
이동 중에도 현이 울리게
또는 뮤트 없이 자연스럽게
= 레가토 포지션 이동
```

### 스트레칭

**큰 인터벌 처리:**
```
1→4 손가락으로 4프렛 거리
더 큰 거리: 손 이동 필요
스트레칭보다 이동이 효율적
```

## 표현적 왼손 기법

### 다이나믹 해머온

```
강한 해머온: 큰 소리 (앰프 통해)
약한 해머온: 작은 소리
= 다이나믹 표현 가능
```

### 고스트 노트 왼손

**왼손으로 현 가볍게 닿기:**
```
완전히 눌러서 음 X
가볍게 닿아서 "뚝" 소리만
= 퍼커시브 고스트 노트
```

### 트릴 기법

**연속 해머온-풀오프:**
```
A-B-A-B-A-B (빠르게)
해머온-풀오프-해머온-풀오프...
= 클래식 트릴 효과
```

## 왼손 강화 훈련

### 크로매틱 연습 (4손가락)

**모든 줄에서:**
```
1-2-3-4 (각 프렛 순서대로)
4-3-2-1 (역방향)
빠르게 반복하면서 손가락 독립성 개발
```

### 스파이더 엑서사이즈

**손가락 교차 운동:**
```
1-3-2-4: 검지→약지→중지→소지
4-2-3-1: 소지→중지→약지→검지
여러 줄에서 반복
```

## 음악연습실 왼손 기법 연습

### 60분 루틴

**1. 해머온·풀오프 (15분)**
   - 단일 해머온 반복
   - 단일 풀오프 반복
   - 해머온+풀오프 연속

**2. 슬라이드 (15분)**
   - 업 슬라이드 (3→5프렛)
   - 다운 슬라이드 (7→5프렛)
   - 인/아웃 슬라이드

**3. 비브라토 (15분)**
   - 하나의 음에서 비브라토 연습
   - 속도 변화 연습
   - 곡에서 표현적으로 사용

**4. 통합 연습 (15분)**
   - 왼손 기법 모두 포함한 라인
   - 재즈·블루스·팝 라인에 적용
   - 녹음 후 표현력 체크

## 마무리

왼손 기법은 **베이스를 노래하게 만드는 힘**입니다. 레가토, 슬라이드, 비브라토가 없는 베이스 라인은 메커니컬합니다. 이 기법들이 있으면 베이스가 숨을 쉬기 시작합니다.

은평구 24시간 음악연습실에서 천천히 각 기법을 마스터하세요. 슬라이드 하나, 비브라토 하나가 음악 전체를 바꿀 수 있습니다.
