## 코드 분산이 기타에 섬세함을 더합니다

아르페지오로 화음을 흐름 있게 표현하세요. 방음 개인실에서 코드 분산 패턴을 탐색하세요.

기타 코드 아르페지오 훈련의 핵심:
- **음 지속**: 아르페지오 중 이전 음 손가락 유지 — 화음 쌓이는 효과
- **핑거 분배**: 엄지·검지·중지·약지 역할 고정
- **코드 전환**: 패턴 유지하며 코드 변경 — 가장 중요한 훈련
- **리듬 변형**: 단순 패턴→리듬 아르페지오로 발전

## 코드 분산 연주가 흔들릴 때 되돌아갈 4가지 원칙

아르페지오는 코드 안에 이미 들어 있던 음을 하나씩 풀어내는 연주입니다. 어떤 음을 언제 내보내느냐가 그대로 표현이 되니, 소리가 지저분할 때는 아래 네 가지부터 확인합니다.

1. **코드 모양을 먼저 안정시킵니다** — 분산하기 전에 BPM 60 안팎의 느린 템포에서 코드 모양이 손에 붙었는지 봅니다. 모양이 흔들리면 다음 음을 짚느라 박자가 끊깁니다.

2. **왼손은 코드를 통째로 누른 채 둡니다** — 음마다 손가락을 떼면 소리가 뚝뚝 끊깁니다. 앞 음이 여운으로 남아 다음 음과 겹쳐야 화음이 쌓이는 울림이 납니다.

3. **오른손은 픽킹 경로를 정해 둡니다** — 다운과 업을 아무렇게나 섞으면 현을 건너뛸 때 손이 헛돕니다. 인접한 현으로 같은 방향으로 넘어가는 이코노미 픽킹으로 경로를 고정하고, 엄지·검지·중지·약지의 담당 현도 정해 둡니다.

4. **패턴은 단순한 것부터 올립니다** — 상행으로 음이 깨끗이 지속되면 교대 패턴과 코드 전환으로, 그다음 리듬 아르페지오와 멜로디 삽입 순서로 넓힙니다. 속도를 막는 벽은 대개 코드가 바뀌는 순간이므로 전환 지점을 따로 떼어 반복합니다.

## 코드 아르페지오는 이미 아는 코드를 흩뿌리는 겁니다

코드 아르페지오라고 하면 새로운 걸 배우는 것 같지만, 사실 이미 짚을 줄 아는 코드를 한 음씩 펼쳐 내는 거예요. 그래서 출발점은 언제나 코드 모양입니다. 그 모양이 흔들리면 분산할 때 다음 음을 짚느라 박자가 끊겨요. BPM 60 정도의 느린 템포에서 코드 모양이 손에 완전히 안정된 뒤에 흩뿌리기 시작하세요. 아는 코드를 얼마나 또렷이 잡느냐가 아르페지오의 절반입니다.

핵심은 왼손을 유지하는 거예요. 음을 하나씩 눌렀다 떼는 게 아니라, 코드 모양을 통째로 누른 채 오른손만 움직여 음을 골라냅니다. 그래야 앞 음이 여운으로 남아 다음 음과 겹치며 아르페지오 특유의 울림이 생겨요. 손가락을 자꾸 떼면 소리가 뚝뚝 끊깁니다.

빠르기의 벽은 오른손 픽킹 경로에서 옵니다. 다운과 업을 아무렇게나 섞으면 현을 건너뛸 때 손이 헛돌아요. 인접한 현으로 같은 방향으로 넘어가는 이코노미 픽킹을 익히면 훨씬 효율적으로 빨라집니다. 아르페지오의 픽킹 원리를 더 파고드는 법은 [기타 아르페지오 연습](/stories/practice-room-guitar-arpeggio1)에서 이어집니다.
