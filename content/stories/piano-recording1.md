## 피아노 녹음 — 클래식에서 팝까지 범용 악기 레코딩

피아노는 가장 넓은 음역대를 가진 악기 중 하나로, 올바른 마이킹이 사운드 특성에 결정적인 영향을 미칩니다.

---

## 그랜드 피아노 마이킹

```
[마이킹 방법]
뚜껑 열기:
→ 최대 개방: 밝고 직접적인 사운드
→ 반 개방: 중간, 공간감 추가
→ 뚜껑 닫기: 소프트하고 폐쇄된 사운드

[스테레오 배치]
① 오버 스트링 스테레오 (추천)
   → 고음 현 (우) + 저음 현 (좌)
   → 뚜껑 안쪽, 현에서 30~50cm
   → 자연스러운 피아노 스테레오

② 뚜껑 엣지 XY
   → 뚜껑 개구부에서 30~50cm
   → 공간감 있는 사운드

[마이크 선택]
→ 소형 다이어프램 콘덴서 (SDC): 디테일·어택 선명
→ 대형 다이어프램 콘덴서 (LDC): 따뜻하고 풍부한 사운드
→ 두 타입 조합도 가능
```

## 업라이트 피아노 마이킹

```
[앞판 스트링 마이킹]
→ 앞판 열기
→ 스트링 위 20~30cm 거리
→ 고음·저음 영역에 각각 마이크

[뒤판 마이킹]
→ 피아노 뒤쪽 벽 사이 공간 배치
→ 더 자연스럽고 공간감 있는 사운드
→ 룸 마이크 대용으로 활용 가능

[상단 마이킹]
→ 상단 패널 열고 마이크 배치
→ 밸런스 있는 풀레인지 사운드
```

## 디지털 피아노 DI 녹음

```
[DI 체인]
디지털 피아노 라인 아웃 → 오디오 인터페이스

[주의사항]
→ 스테레오 아웃(L/R) 모두 연결
→ 볼륨을 너무 높이면 클리핑 주의
→ 인터페이스 게인은 낮게 유지
→ 피아노 내장 이펙트(리버브) 끄고 녹음

[건반 터치 감도]
→ 벨로시티 응답 설정 확인
→ 다이나믹 표현이 MIDI와 일치하는지 체크
```

## 피아노 EQ 가이드

```
[주파수 대역별 역할]
80~200Hz: 몸통감, 따뜻함 (과도하면 뭉침)
200~400Hz: 바디, 너무 많으면 탁함
800Hz~3kHz: 존재감, 명료도
4~8kHz: 밝은 어택, 건반 타격감
10kHz 이상: 에어, 공기감

[보컬 믹스에서 피아노 EQ]
→ 500~800Hz: -2~3dB (보컬 공간 확보)
→ 3~5kHz: 살짝 컷 (보컬과 겹침 방지)
→ 하이패스: 60~80Hz (저역 정리)
```
