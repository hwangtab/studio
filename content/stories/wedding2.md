## 결혼식 축가, 선물로 남기는 특별한 목소리

친구의 결혼식에서 직접 불러줄 수 없을 때, 또는 더욱 완성도 있는 선물로 남기고 싶을 때 녹음된 축가는 최고의 선물이 됩니다. 식장 스피커를 통해 울려 퍼지는 당신의 목소리로 만든 축가는 신랑신부가 평생 기억할 특별한 순간이 됩니다.

## 축가 선곡 기준

### 피로연 분위기에 맞는 곡

| 분위기 | 추천 곡 유형 |
|--------|-----------|
| 화사하고 밝은 | 팝 발라드, 러브송 |
| 감동적이고 서정적 | 클래식 발라드, 오페라 풍 |
| 신나고 경쾌한 | 댄스 팝, 업비트 장르 |
| 전통적인 느낌 | 트로트 축가, 성인가요 |

### 선곡 시 주의사항

- 가사 내용 확인: 이별·슬픔 내용의 곡은 피하세요
- 본인 음역에 맞는 곡 선택: 힘들게 고음을 쥐어짜는 곡은 결과물이 부자연스러울 수 있습니다
- 식장 BGM 시간: 보통 3~4분 내외 곡이 좋습니다

## 축가 녹음 준비 체크리스트

### 최소 2주 전

- [ ] 곡 선정 완료
- [ ] MR(반주) 파일 준비 (멜론·벅스 구매 권장, WAV 형식)
- [ ] 가사 숙지 시작

### 1주 전 (녹음일 기준)

- [ ] 가사 완전 암기
- [ ] 곡 여러 번 연습하여 자신감 확보
- [ ] 스튜디오 예약 완료

### 전날

- [ ] 음주 금지, 충분한 수면
- [ ] 찬 음식·음료 자제
- [ ] 가사 최종 확인

### 당일

- [ ] 예약 10분 전 도착
- [ ] 미지근한 물 챙기기
- [ ] MR 파일 USB 또는 카카오톡으로 미리 전달

## 스튜디오 놀 축가 완성 패키지

| 포함 내용 | 세부 사항 |
|---------|---------|
| 녹음 세션 | 2시간 (컴핑 포함) |
| 보컬 편집 | 피치 교정 + 타이밍 교정 |
| 믹싱 | MR + 보컬 밸런싱 |
| 마스터링 | 식장 PA 최적화 |
| 납품 파일 | WAV + MP3 (카카오톡/드라이브) |

## 식장 음향팀에 파일 전달 방법

1. 완성 파일(MP3 + WAV) 수령
2. 식장 담당자에게 연락: "피로연 중 재생할 축가 파일을 전달드립니다"
3. USB 또는 이메일로 파일 전달 (이메일 선호하는 식장 많음)
4. 재생 시점·볼륨 조절 방식 사전 협의 (사회자와 확인)

## 축가 키(key) 조정하기

원곡 키가 본인 음역과 맞지 않으면 반음 단위로 MR 키를 조정합니다.

### 자신에게 맞는 키 확인하는 법

예약 전 원곡 그대로 불러보며 고음부에서 무리가 있는지 확인하세요. 불편하다면 반음~1음 낮추는 것이 자연스럽습니다. 반대로 음역이 넓은 분이라면 올리는 것도 가능합니다.

### MR 키 조정 방법

- **반주 전문 사이트 구매**: 반주닷컴 등에서 원하는 키로 직접 구매 가능
- **스튜디오 내 조정**: WAV 파일을 DAW에서 피치 시프트 처리 (음질 손실 최소화)
- **스트리밍 앱 키 변경**: 간편하지만 변환 음질이 다소 부자연스러울 수 있음

카카오톡으로 "○장조에서 1반음 내려서"처럼 알려주시면 세션 전 사전 세팅해 드립니다.

## 식장 음향팀과 소통하는 법

파일 전달 시 함께 알리면 좋은 정보:

- **볼륨 기준**: 마스터링된 파일은 음압이 이미 최적화돼 있습니다. 다른 식장 BGM과 같은 음량으로 재생해 달라고 요청하면 됩니다.
- **재생 타이밍**: 사회자 안내 후 몇 초 뒤 시작인지, 신호로 즉시 시작인지 미리 협의해두세요.
- **파일 백업**: MP3로 전달하되 WAV 파일도 함께 건네면 예상치 못한 재생 오류에 대비할 수 있습니다.

## 피로연 축가는 '식장 스피커에서 어떻게 들리나'까지가 완성이에요

본식 축가와 달리 피로연 축가는 공간부터 달라요. 왁자한 식사 자리, 웅성거리는 하객, 잔 부딪히는 소리 위로 목소리가 얹히거든요. 그래서 저는 피로연용이라고 하시면 선곡부터 조금 다르게 권해요. 너무 잔잔한 발라드는 소음에 묻히기 쉬워서, 밝고 또렷한 러브송이나 경쾌한 팝 쪽이 공간을 더 잘 채워요. 다만 아무리 밝은 곡이어도 가사에 이별이나 슬픔이 섞이면 축하 자리와 어긋나니, 신랑신부를 향한 축하 메시지가 분명한 곡으로 고르시는 게 좋아요.

녹음 음원으로 준비하실 거면, 결과물이 '내 이어폰'이 아니라 '식장 PA 스피커'에서 어떻게 들리는지까지 계산해야 해요. 웨딩홀 음향 시스템은 저역이 부풀거나 고역이 날리기 쉬워서, 마스터링 단계에서 그 환경에 맞춰 음압과 밸런스를 잡아 둬야 당일 재생했을 때 목소리가 앞으로 나와요. 그래서 저희는 WAV와 MP3 두 포맷을 함께 드려요. MP3로 가볍게 전달하되, 예상치 못한 재생 오류에 대비해 WAV도 같이 건네면 식장에서 어느 쪽이든 틀 수 있거든요.

의외로 마지막에 어긋나는 게 식장 음향팀과의 소통이에요. 파일만 넘기고 끝내지 마시고, 사회자 안내 뒤 몇 초에 시작할지, 다른 BGM과 같은 음량으로 재생할지를 미리 맞춰 두세요. 이 협의 한 번이 "음악이 늦게 나와서 어색했다"는 사고를 막아요. 곡 확정부터 식장 납품까지 한 달의 준비 흐름 전체는 [축가 녹음 준비 가이드](/stories/wedding-song-guide1)에 단계별로 정리해 두었어요.
