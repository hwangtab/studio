## 분당 서부에서 연신내 스튜디오 놀까지

경기도 성남시 분당구 서부권(서현동·이매동·수내동·정자동·미금동) 지역에서 수인분당선을 이용하면 서울 연신내 스튜디오 놀까지 약 60~80분에 도달할 수 있습니다.

---

## 분당 서현·수내 → 연신내 이동 경로

### 수인분당선 + 5호선 + 6호선 (추천)

장비 자체보다 세팅 방법이 결과물 품질에 더 큰 영향을 줍니다.

### 서현역·수내역·정자역 출발 (수인분당선)

1. 서현역, 수내역 또는 정자역(수인분당선) 탑승
2. 수인분당선 왕십리 방면 이동
   (이매 → 수내 → 정자 → 미금 → 오리 → 죽전
    - 보정 → 구성 → 신갈 → ... X — 반대 방향)

**왕십리 방면**
   (서현 → 수내 → 정자 → 미금 → 오리 방향 X)

**실제 서울 방향**
   (서현 → 이매 → 야탑 → 모란 → 수진 → 신흥
    - 단대오거리 → 복정 → 가천대 → 태평 → 수서
    - 대모산입구 → 개포동 → 대청 → 학여울
    - 대치 → 한티 → 선릉 → 선정릉 → 압구정로데오
    - 강남구청 → 청담 → 뚝섬유원지 → 성수 → 왕십리)

3. 왕십리역 하차
4. 5호선 환승 → 공덕역 방면
5. 마장 → 행당 → 왕십리 → 청구 → 신금호
  - 동대문역사문화공원 → 을지로4가 → 을지로3가
  - 을지로입구 → 광화문 → 서대문 → 애오개 → 충정로 → 공덕역
6. 공덕역에서 6호선 환승
7. 효창공원 → 삼각지 → 녹사평 → 이태원
  - 한강진 → 버티고개 → 약수 → 청구
  - 신당 → 동묘앞 → 창신 → 보문 → 안암
  - 고려대 → 월곡 → 상월곡 → 돌곶이 → 석계
  - 태릉입구 → 화랑대 → 봉화산 → 신내 X

**공덕역 6호선 응암 방향**
   공덕 → 마포구청 → 망원 → 합정 → 상수
  - 광흥창 → 대흥 → 공덕 X (이미 왔음)

   올바른 경로: 공덕에서 응암 방면
   공덕 → 효창공원 → 삼각지 방향 X

   실제: 공덕(5호선 하차) → 6호선 응암 방면
  - 마포구청 → 망원 → 합정 → 홍대입구
  - 상수 → 광흥창 → 대흥 → 공덕 → 효창공원
  - 삼각지 → 이태원 방향 X

**단순 경로 요약**
서현역(수인분당선) → 왕십리역(5호선 환승)
- 공덕역(6호선 환승) → 연신내역
- **총 소요시간**: 약 65~80분
