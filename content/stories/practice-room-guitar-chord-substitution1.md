# 기타 코드 대체·리하모니제이션 기법 — 음악연습실 완전 가이드

코드 대체(Chord Substitution)는 **같은 기능을 가진 다른 코드로 교체**하는 화성 기법입니다. 흔한 코드 진행을 더 풍부하고 독창적으로 만드는 이 기법은 재즈 기타의 핵심이며, 팝과 록에서도 창의적인 편곡에 사용됩니다.

---

## 코드 대체의 기본 원리

### 왜 코드를 대체하는가?

**코드 대체의 목적:**
1. 진부한 진행을 신선하게
2. 더 풍부한 화성적 색채
3. 선율과 베이스라인에 더 많은 옵션
4. 재즈적 표현의 확장

### 기능별 코드 분류

모든 코드는 **토닉(Tonic), 도미넌트(Dominant), 서브도미넌트(Subdominant)** 중 하나에 속합니다.

**C 장조 기준:**
- **토닉 (I)**: C, Em, Am
- **서브도미넌트 (IV)**: F, Dm
- **도미넌트 (V)**: G, Bdim

같은 기능끼리 대체 가능합니다.

---

## 주요 코드 대체 기법

### 1. 트라이톤 대체 (Tritone Substitution)

재즈에서 가장 중요한 코드 대체 기법. 도미넌트 코드를 **3온음(트라이톤) 위의 도미넌트**로 교체합니다.

**원리:**
- G7의 트라이톤(3온음 위) = Db7
- G7과 Db7은 같은 텐션 음(B-F)을 공유

**예:**
```

원래 진행: Dm7 - G7 - Cmaj7
트라이톤 대체: Dm7 - Db7 - Cmaj7

```

**기타 코드 (G7 → Db7):**
```

G7: 3-2-3-4-3-3
Db7: 9-8-9-10-9-9 (바레)
또는
Db7: x-4-3-4-3-x (콤팩트)

```

### 2. 세컨더리 도미넌트 (Secondary Dominant)

어느 코드 앞에나 **그 코드의 도미넌트**를 삽입하는 기법.

**I-IV 진행에 세컨더리 도미넌트 추가:**
```

원래: C - F
세컨더리: C - C7 - F

```

**C7이 F의 도미넌트 역할** → 자연스럽게 F로 이동.

**기타 응용:**
```

Em7 - Am7 - Dm7 - G7 - C
↓
Em7 - E7 - Am7 - A7 - Dm7 - G7 - C

```

### 3. 상위 구조 트라이어드 (Upper Structure Triads)

복잡한 확장 코드를 단순한 트라이어드(3화음)로 연주하는 기법.

**G7(#11) 위에:**
```

D/G = G 베이스 + D 트라이어드
= G-D-F#-A (G7 코드 + D major triad 위에)

```

이런 접근으로 복잡한 재즈 코드를 더 쉽게 표현할 수 있습니다.

### 4. 패싱 코드 (Passing Chords)

두 코드 사이에 **경과적으로 삽입**하는 코드.

**크로매틱 패싱:**
```

Cmaj7 - - - - → Fmaj7
Cmaj7 - Dbmaj7 - Dmaj7 - Ebmaj7 → Fmaj7

```

**다이아토닉 패싱:**
```

C - F (원래)
C - Em7 - Am7 - Dm7 - G7 - F (diatonic pathway)

```

## 실전 리하모니제이션 예제

### "Happy Birthday" 리하모니제이션

단순한 곡을 재즈 코드로:

**원래:**
```

C - - - G7 - - - C - - - F - C - G7 - C

```

**재즈 리하모니제이션:**
```

Cmaj7 - Am7 - Db7 - Gbmaj7 - Dm7 - G7alt - Cmaj7 - F#7
Fmaj7 - F#dim7 - Cmaj7/G - Eb7 - Dm7 - G7alt - Cmaj7

```

### "Autumn Leaves" 리하모니제이션

재즈 스탠다드에 고급 대체 적용:

**원래 Cm 버전 Am7b5-D7-Gm:**
**리하모니제이션:**
```

Am7b5 - Abm7 - Db7 - Gm (트라이톤 대체)

```

## 기타 코드 보이싱 활용

### 코드 대체를 위한 기타 포지션

**G7 패밀리 코드:**
```

G7: 3-2-3-4-3-3
G7#5: 3-2-3-3-3-3
G7b9: 3-2-3-4-2-3
G7alt: 3-2-3-4-2-2
Db7: x-4-3-4-3-x (트라이톤 대체)

```

**Cmaj7 패밀리 코드:**
```

Cmaj7: x-3-2-4-3-x
Cmaj9: x-3-0-4-3-x
Cmaj7#11: x-3-2-0-3-x
Am7: x-0-2-0-1-0 (토닉 대체)
Em7: 0-2-2-0-3-0 (토닉 대체)

```

## 음악연습실 코드 대체 연습 루틴

### 기초 단계 (50분)

**1. 기본 코드 기능 이해 (15분)**
- C 장조 다이아토닉 7th 코드 복습
- 각 코드의 기능 (T/SD/D) 분류

**2. 트라이톤 대체 연습 (20분)**
- II-V-I에서 V를 트라이톤 대체
- Dm7 - Db7 - Cmaj7 프로그레션
- 12개 조성으로 이동

**3. 곡 적용 (15분)**
- "Fly Me to the Moon" 몇 마디에 세컨더리 도미넌트 삽입
- 또는 간단한 팝 코드 진행에 패싱 코드 추가

## 마무리

코드 대체는 **화성 언어의 어휘를 넓히는 것**입니다. 처음에는 "틀린 것 같은" 코드가 사실은 더 풍부한 음악적 표현을 만들어낸다는 것을 발견하는 순간, 화성에 대한 새로운 세계가 열립니다.

은평구 24시간 음악연습실에서 익숙한 곡에 하나씩 코드를 바꿔가며 실험해보세요. "이건 어떤 소리지?"라는 탐구심이 코드 대체 마스터의 시작입니다.
