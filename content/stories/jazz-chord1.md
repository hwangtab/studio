## 재즈 코드 진행 — 세련된 화성의 핵심

재즈 코드는 단순한 3화음을 넘어 7th·9th·11th·13th까지 확장된 화음과 복잡한 진행으로 특유의 세련미를 만들어냅니다.

---

## ii-V-I: 재즈의 핵심 진행

아래 예시는 특정 스타일 기준이며, 다른 장르에 적용할 때는 맥락 조정이 필요합니다.

### ii-V-I 기본 진행 (C 장조)

Dm7 (ii) → G7 (V) → Cmaj7 (I)
- 긴장(ii) → 강한 긴장(V) → 해소(I)

### 모든 조성의 ii-V-I

- **C장조**: Dm7 → G7 → Cmaj7
- **F장조**: Gm7 → C7 → Fmaj7
- **Bb장조**: Cm7 → F7 → Bbmaj7
- **Eb장조**: Fm7 → Bb7 → Ebmaj7

### 단조 ii-V-i

- **A단조**: Bm7b5 (ii°) → E7 (V) → Am7/Am (i)
- 단조는 V에 자연장7 대신 E7 사용
- 단조 ii = half-diminished (m7b5)

---

## 확장 코드 (Extended Chords)

가사와 멜로디의 자연스러운 강세 일치가 곡의 완성도를 크게 높입니다.

### 코드 유형과 확장음

**Cmaj7 (I)**
- **Cmaj9**: 9th(D) 추가
- **Cmaj7#11**: 리디안 모드 느낌 (F# 포함)
- **Cmaj13**: 가장 풍부한 색채

**Dm7 (ii)**
- **Dm9**: 부드러운 느낌 (+E)
- **Dm11**: 서스펜디드 느낌 (+G)

**G7 (V 도미넌트)**
- **G9**: 9th 추가 (A)
- **G7b9**: 긴장감 극대화 (Ab)
- **G13**: 화려한 도미넌트 (E 포함)
- **G7#11**: 리디안 도미넌트 (C# 포함)

### 확장음 사용 원칙

- 도미넌트(V7)에 가장 자유롭게 확장음 적용
- Imaj7에는 9th·#11·13th로 컬러 추가
- iim7에는 9th·11th로 부드러운 느낌

## 재즈 보이싱 기법

한 가지 아이디어에서 변형을 만들어가는 연습이 곡의 통일성을 높여줍니다.

### 기본 보이싱 원칙

**셸 보이싱 (Shell Voicing)**
- **왼손**: 루트 + 7th
- **오른손**: 3rd + 확장음
- 가장 기본적인 재즈 피아노 보이싱

**드롭-2 보이싱**
- 4성부 코드의 2번째 음을 한 옥타브 낮춤
- C E G B → C G B E (G 아래로 이동)
- 기타·트롬본 등에서 많이 활용

**클로즈드 vs 오픈 보이싱**
- **클로즈드**: 한 옥타브 안에 모든 음 배치 (밀도 높음)
- **오픈**: 음들이 여러 옥타브에 걸쳐 배치 (공간감)

### 실전 재즈 피아노 보이싱

**Dm7**
- **왼손**: D + C (루트+7th)
- **오른손**: F + A + E (3rd + 5th + 9th)

**G7**
- **왼손**: G + F (루트+b7th)
- **오른손**: B + D + A (3rd + 5th + 9th) 또는 B + E + A (#11 추가)

**Cmaj7**
- **왼손**: C + B (루트+7th)
- **오른손**: E + G + D (3rd + 5th + 9th)

## 재즈 터닝 (Turnaround) 진행

장르의 전통적인 코드 진행을 이해하면 기대를 충족하거나 의도적으로 배신할 수 있습니다.

### II-V-I 기반 터닝

**기본형**
I → vi → ii → V → (I)
Cmaj7 → Am7 → Dm7 → G7 → (Cmaj7)

**확장 터닝 (Coltrane Turnaround)**
I → bVII7 → bVI7 → V7 → I
Cmaj7 → Bb7 → Ab7 → G7 → Cmaj7
- 콜트레인 식 반음 하강 도미넌트

### 대리 코드 (Tritone Substitution)

G7 → Db7 (3음 위의 증4도 대리)
- 베이스 반음 하강 효과
- 같은 화성 긴장감, 다른 색채

Dm7 → G7 → Cmaj7
= Dm7 → Db7 → Cmaj7 (트리톤 서브)

## 모달 재즈 코드

완성에 집착하기보다 초안을 빠르게 완성하고 이후에 수정하는 방식이 효율적입니다.

### 모달 재즈의 핵심

마일스 데이비스 Kind of Blue에서 시작
- ii-V-I 진행 대신 하나의 스케일(모드) 유지
- 긴 시간 하나의 코드 위에서 즉흥연주

### 주요 모드와 코드

- **도리안 (D Dorian)**: Dm7 + 9th·11th·13th
- D E F G A B C D (D단조 + 장6도)
- 마이너 재즈의 가장 일반적인 모드

- **리디안 (F Lydian)**: Fmaj7#11
- F G A B C D E F (F장조 + 증4도)
- 밝고 몽환적인 장조 색채

- **믹소리디안 (G Mixolydian)**: G7
- G A B C D E F G (G장조 + 단7도)
- 블루스·팝·재즈 도미넌트의 기본
