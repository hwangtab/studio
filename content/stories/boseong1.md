## 보성에서 KTX로 서울까지

보성은 전남 남부에 위치한 녹차의 고장으로, 순천역 KTX를 통해 서울과 약 3시간 30분대로 연결됩니다.

---

## 보성 → 연신내 이동 경로

### KTX 순천역 경유 (권장)

```
① 보성 → 순천역 (버스 약 50분~1시간)
② 순천역 KTX 탑승 (서울역 방면, 약 2시간 30~40분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간 50분~4시간 20분
```

### KTX 광주송정역 경유

```
① 보성 → 광주송정역 (버스 약 1시간~1시간 20분)
② 광주송정역 KTX 탑승 (서울역 방면, 약 1시간 40~50분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간 30~50분
```

## 당일 왕복 일정 예시 (보성 기준)

```
오전 6시 보성 출발 → 순천역 이동
오전 7시 순천역 KTX 출발
→ 오전 9시 50분 서울역 도착
→ 오전 10시 30분 연신내역 도착
→ 오전 11시 세션 시작 (2시간)
→ 오후 1시 세션 완료
→ 오후 2시 30분 서울역 출발
→ 오후 5시 20분 순천역 도착
→ 오후 6시 20분 보성 도착
```

## 온라인 파일 의뢰 서비스

```
보성 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
