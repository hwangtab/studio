## 거창에서 KTX로 서울까지

거창은 경남 내륙 도시로, 진주역 KTX를 통해 서울과 약 3시간 30분~4시간으로 연결됩니다. 거창 사과와 수승대로 유명한 거창에서 오전 일찍 출발하면 당일 서울 스튜디오 방문이 가능합니다.

---

## 거창 → 연신내 이동 경로

### KTX 진주역 경유 (권장)

```
① 거창 → 진주역 (버스 약 1시간~1시간 30분)
② 진주역 KTX 탑승 (서울역 방면, 약 2시간)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간 30분~4시간
```

### 동서울터미널 직행버스 (대안)

```
① 거창 버스터미널 → 동서울터미널 (고속버스 약 3시간 30분)
② 동서울터미널 → 지하철 → 연신내역 (약 40~50분)

총 소요시간: 약 4시간~4시간 30분
```

## 당일 왕복 일정 예시 (거창 기준)

```
오전 6시 거창 출발 → 진주역 이동
오전 7시 30분 진주역 KTX 출발
→ 오전 9시 30분 서울역 도착
→ 오전 10시 10분 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 서울역 출발
→ 오후 4시 진주역 도착
→ 오후 5시 30분 거창 도착
```
