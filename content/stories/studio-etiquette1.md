## 처음이어도 당당하게 — 스튜디오는 친근한 공간입니다

녹음실이 낯설고 어색하게 느껴지는 것은 당연합니다. 몇 가지 기본 매너를 알아두면 편안한 세션이 됩니다.

---

## 예약 에티켓

| 상황 | 좋은 행동 |
|------|---------|
| 예약 전 | 녹음 목적, 곡 수, 희망 날짜를 명확히 알리기 |
| 예약 확정 후 | MR 파일 미리 공유 (세션 전날까지) |
| 변경이 필요할 때 | 최소 24시간 전 연락 |
| 당일 취소 | 부득이한 경우 가능한 빨리 연락 |

---

## 도착 에티켓

테스트 녹음으로 먼저 소리를 확인한 뒤 본 녹음을 진행하는 것이 기본 워크플로우입니다.

- **권장**: 예약 시간 10분 전 도착
- **이유**: 세팅·마이크 체크·모니터 조정에 시간 필요
     넉넉한 도착 = 첫 테이크부터 좋은 컨디션

**도착 전 준비**:
- 미지근한 물 충분히 마시기
- 가벼운 식사 후 방문 (빈속 ×)
- 면 소재 의류 (나일론 소재는 부스 내 소음 유발)
- MR 파일 스마트폰에도 백업

---

## 세션 중 소통 에티켓

### 기술 용어 없이 요청하는 방법

| 원하는 것 | 이렇게 말하세요 |
|---------|------------|
| 내 목소리 크게 | "제 목소리 모니터에서 더 크게 들으면 좋겠어요" |
| MR 소리 줄임 | "반주 소리 조금 줄여주세요" |
| 리버브 줄임 | "에코(리버브) 효과 좀 줄여주세요" |
| 다시 녹음 | "이 부분 다시 해볼게요" |
| 특정 마디 다시 | "3절 2행부터 다시 해도 될까요?" |
| 잠깐 휴식 | "잠깐 물 좀 마셔도 될까요?" |

### 적극적으로 소통하세요

| 피해야 할 것 | 이유 |
|---------|------|
| "그냥 다 좋아요" | 원하는 방향을 모르면 엔지니어도 최적화 어려움 |
| 불편해도 말 안 함 | 세션 내내 최적화 안 된 상태로 진행됨 |
| 요청을 너무 자주 바꿈 | 세팅 반복으로 세션 시간 낭비 |

---

## 장비 관련 에티켓

| 규칙 | 이유 |
|------|------|
| 마이크는 직접 만지지 않기 | 진동·충격이 마이크 손상 원인 |
| 팝 필터는 적정 거리 유지 | 15~20cm 기준 |
| 음료는 마이크 가까이 두지 않기 | 습기·음료 사고 위험 |
| 이어폰·유선 기기는 세션 전 분리 | 예상치 못한 신호 간섭 |

---

## 동반인 에티켓

동반인이 있을 경우:

모니터링 레벨과 녹음 레벨은 독립적으로 조절해야 판단 오류를 방지할 수 있습니다.

- ✅ 세션 중 조용히 관람
- ✅ 이동 자제 (부스 외부에서)
- ✅ 휴대폰 무음
- ❌ 세션 중 대화 (마이크에 잡힐 수 있음)
- ❌ 녹음 방향에 대한 과도한 개입

---

## 세션 종료 에티켓

아래 설정은 일반적인 권장 사항이며 장비 특성과 공간에 따라 조정이 필요합니다.

- ✅ 사용한 공간 정리
- ✅ 마이크 주변 물기 확인
- ✅ 파일 납품 방법·일정 확인 후 나가기
- ✅ 수고에 대한 감사 인사

## 마치며

녹음실은 여러분의 음악을 가장 잘 담아내기 위한 공간입니다. 편안한 분위기 속에서 소통하면 엔지니어도 더 좋은 결과물을 만들기 위해 집중할 수 있습니다.
