faq:
  - q: 녹음 중 엔지니어에게 어떻게 요청해야 하나요?
    a: >-
      기술 용어를 몰라도 괜찮습니다. '내 목소리가 더 크게 들리면 좋겠어요', '리버브 효과 좀 줄여주세요', '이 부분 다시 녹음해도
      될까요?' 등 원하는 것을 자연스럽게 말하면 됩니다. 엔지니어는 요청을 기술적으로 해석해 해결해줍니다.
  - q: 녹음실에 동반인을 데려와도 되나요?
    a: >-
      스튜디오마다 다르지만 일반적으로 1~2명의 동반인은 허용됩니다. 단, 동반인이 세션 중 큰 소리로 대화하거나 이동하면 마이크에 잡힐
      수 있습니다. 사전에 스튜디오에 동반인 인원을 알리고, 세션 중 조용히 있도록 부탁하세요.
  - q: 녹음 도중 화장실을 가거나 휴식을 취해도 되나요?
    a: >-
      언제든지 가능합니다. '잠깐 쉬어도 될까요?'라고 말하면 엔지니어가 세션을 일시 중단합니다. 무리하게 쉬지 않고 계속하면 오히려
      결과물이 나빠집니다. 30분~1시간마다 짧은 휴식을 취하는 것이 좋습니다.
  - q: 예약 시간보다 늦게 도착하면 어떻게 되나요?
    a: >-
      예약 시간은 세션 시작 시간이 아닌 세팅 시작 시간으로 잡혀 있는 경우가 많습니다. 늦게 도착하면 세팅 시간이 세션 시간에서
      차감됩니다. 늦을 것 같으면 반드시 사전에 연락하고, 10~15분 일찍 도착하는 것을 권장합니다.

## 처음이어도 당당하게 — 스튜디오는 친근한 공간입니다

녹음실이 낯설고 어색하게 느껴지는 것은 당연합니다. 몇 가지 기본 매너를 알아두면 편안한 세션이 됩니다.

스튜디오 에티켓의 기원은 1950~60년대 황금기 레코딩 스튜디오에서 찾을 수 있습니다. Abbey Road·Capitol Records·RCA Victor Studio 같은 레전드 스튜디오들은 시간당 요금이 현재 가치로 수백만 원에 달했기 때문에, "1분의 낭비도 없다"는 전문적 세션 문화가 자연스럽게 형성됐습니다. 마이크에 직접 손대지 않는 규칙은 Neumann U47·U67 같은 장비가 수천만 원이었던 시대에 사고 방지를 위해 굳어진 관행입니다. 현재 스튜디오 세션 문화의 국제 표준은 엔지니어가 기술을 담당하고 아티스트가 감정 표현에 집중하는 역할 분리에 기반하며, 이 분리가 세션의 효율과 결과물 품질을 동시에 높이는 구조입니다. 한국에서는 1990년대 대형 기획사 전속 스튜디오 체계가 정착되면서 세션 규범이 체계화됐고, 현재 국내 스튜디오들은 10~15분 전 도착, MR 파일 사전 공유, 세션 중 엔지니어와의 명확한 소통을 핵심 에티켓으로 공유합니다.

## 예약 에티켓

| 상황 | 좋은 행동 |
|------|---------|
| 예약 전 | 녹음 목적, 곡 수, 희망 날짜를 명확히 알리기 |
| 예약 확정 후 | MR 파일 미리 공유 (세션 전날까지) |
| 변경이 필요할 때 | 최소 24시간 전 연락 |
| 당일 취소 | 부득이한 경우 가능한 빨리 연락 |

---

## 도착 에티켓

- **권장**: 예약 시간 10분 전 도착
- **이유**: 세팅·마이크 체크·모니터 조정에 시간 필요
     넉넉한 도착 = 첫 테이크부터 좋은 컨디션

**도착 전 준비**:
- 미지근한 물 충분히 마시기
- 가벼운 식사 후 방문 (빈속 ×)
- 면 소재 의류 (나일론 소재는 부스 내 소음 유발)
- MR 파일 스마트폰에도 백업

## 세션 중 소통 에티켓

### 기술 용어 없이 요청하는 방법

| 원하는 것 | 이렇게 말하세요 |
|---------|------------|
| 내 목소리 크게 | "제 목소리 모니터에서 더 크게 들으면 좋겠어요" |
| MR 소리 줄임 | "반주 소리 조금 줄여주세요" |
| 리버브 줄임 | "에코(리버브) 효과 좀 줄여주세요" |
| 다시 녹음 | "이 부분 다시 해볼게요" |
| 특정 마디 다시 | "3절 2행부터 다시 해도 될까요?" |
| 잠깐 휴식 | "잠깐 물 좀 마셔도 될까요?" |

### 적극적으로 소통하세요

| 피해야 할 것 | 이유 |
|---------|------|
| "그냥 다 좋아요" | 원하는 방향을 모르면 엔지니어도 최적화 어려움 |
| 불편해도 말 안 함 | 세션 내내 최적화 안 된 상태로 진행됨 |
| 요청을 너무 자주 바꿈 | 세팅 반복으로 세션 시간 낭비 |

## 장비 관련 에티켓

| 규칙 | 이유 |
|------|------|
| 마이크는 직접 만지지 않기 | 진동·충격이 마이크 손상 원인 |
| 팝 필터는 적정 거리 유지 | 15~20cm 기준 |
| 음료는 마이크 가까이 두지 않기 | 습기·음료 사고 위험 |
| 이어폰·유선 기기는 세션 전 분리 | 예상치 못한 신호 간섭 |

동반인이 있을 경우:

- ✅ 세션 중 조용히 관람
- ✅ 이동 자제 (부스 외부에서)
- ✅ 휴대폰 무음
- ❌ 세션 중 대화 (마이크에 잡힐 수 있음)
- ❌ 녹음 방향에 대한 과도한 개입

- ✅ 사용한 공간 정리
- ✅ 마이크 주변 물기 확인

- ✅ 수고에 대한 감사 인사

## 마치며

녹음실은 여러분의 음악을 가장 잘 담아내기 위한 공간입니다. 편안한 분위기 속에서 소통하면 엔지니어도 더 좋은 결과물을 만들기 위해 집중할 수 있습니다.

가장 중요한 에티켓은 기술 용어를 몰라도 원하는 것을 말하는 것입니다. "목소리가 더 앞으로 나오면 좋겠어요", "이 부분 다시 해볼게요" 같은 일상 언어로 충분하며, 엔지니어는 이를 기술적으로 해석해 해결합니다. 요청을 참고 있다가 세션이 끝난 후 "좀 달랐으면 좋겠었는데..."라고 말하는 것이 가장 아쉬운 세션입니다. 적극적인 소통이 세션의 시간과 비용을 가장 효율적으로 사용하는 방법입니다.
