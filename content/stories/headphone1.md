faq:
  - q: 보컬 녹음 시 어떤 헤드폰을 써야 하나요?
    a: >-
      녹음 부스 안에서는 밀폐형(closed-back) 헤드폰을 사용해야 합니다. 소리가 바깥으로 새지 않아 마이크에 헤드폰 음이 섞이지
      않기 때문입니다. 개방형은 소리가 새나가 마이크에 피드백이 생길 수 있습니다.
  - q: 모니터 헤드폰과 일반 헤드폰(소비자용)의 차이는 무엇인가요?
    a: >-
      소비자용 헤드폰은 저음이 부스트되거나 인위적으로 소리를 좋게 만든 경우가 많습니다. 모니터 헤드폰은 최대한 평탄한(flat) 주파수
      응답을 목표로 해 녹음된 소리를 있는 그대로 들을 수 있습니다. 믹싱·모니터링에 모니터 헤드폰이 적합합니다.
  - q: 헤드폰 임피던스(ohm)가 중요한가요?
    a: >-
      저임피던스(32~64Ω) 헤드폰은 스마트폰·인터페이스에서도 충분히 구동됩니다. 고임피던스(250~600Ω)는 헤드폰 앰프가
      필요합니다. 홈 레코딩 입문용으로는 80Ω 이하를 추천합니다.
  - q: 녹음 헤드폰 예산은 얼마가 적당한가요?
    a: >-
      입문용으로 5~10만원대(소니 MDR-7506, 오디오테크니카 ATH-M20x 등), 중급으로 10~20만원대(ATH-M50x, 슈어
      SRH440 등)를 추천합니다. 믹싱용으로는 베이어다이나믹 DT770 Pro(80Ω), 젠하이저 HD600 계열이 인기 있습니다.

## 보컬 녹음에 헤드폰이 중요한 이유

녹음 중 반주(MR)를 들으면서 노래할 때 헤드폰 선택은 녹음 품질에 직접 영향을 미칩니다. 소리가 새는 헤드폰을 쓰면 MR 소리가 마이크에 섞여 믹싱 단계에서 제거할 수 없게 됩니다.

---

## 밀폐형 vs 개방형 헤드폰

| 구분 | 밀폐형 (Closed-back) | 개방형 (Open-back) |
|------|-------------------|-----------------|
| 소리 누출 | 거의 없음 | 양방향 소리 통과 |
| 녹음 시 적합성 | 필수 (MR 소리 차단) | 부적합 (마이크에 섞임) |
| 공간감 | 좁고 밀폐된 느낌 | 넓고 자연스러운 느낌 |
| 믹싱 적합성 | 보통 | 우수 |
| 주요 용도 | 녹음 모니터링 | 믹싱·마스터링 |

---

## 보컬 녹음 헤드폰 선택 기준

세션 시작 전 파일 정리와 프로젝트 백업 습관이 데이터 손실을 막아줍니다.

### 필수 조건

- 밀폐형(closed-back): 소리 누출 차단
- 임피던스 80Ω 이하: 오디오 인터페이스 직구동 가능
- 착용감: 장시간 착용에 불편하지 않아야 함
- 음압 감도: 95dB/mW 이상

### 선택 조건

- 평탄한 주파수 응답: 믹싱 겸용 시
- 착탈식 케이블: 단선 시 교체 가능
- 접이식 구조: 이동 편의

---

## 가격대별 추천 헤드폰

| 가격대 | 모델 | 특징 |
|-------|------|------|
| 5~8만원 | 소니 MDR-7506 | 방송국·스튜디오 표준, 정확한 모니터링 |
| 8~10만원 | 오디오테크니카 ATH-M40x | 평탄한 응답, 착용감 우수 |
| 10~15만원 | 오디오테크니카 ATH-M50x | 입문 모니터의 베스트셀러 |
| 15~25만원 | 슈어 SRH840A | 정확한 모니터링, 착탈식 케이블 |
| 20~35만원 | 베이어다이나믹 DT770 Pro | 독일 명품, 밀폐형 최고 선택지 |

## 녹음 시 헤드폰 볼륨 설정

마이크 위치를 조금만 바꿔도 음색이 크게 달라지므로 충분한 테스트가 필요합니다.

- ⚠️ 주의: 헤드폰 볼륨을 너무 크게 설정하면

[문제 1] 청력 손상
- 장시간 90dB 이상 노출 위험

[문제 2] 피치 인식 오류
- 소리를 크게 들으면 음정 판단이 왜곡됨
- 실제로는 낮게 부르는데 높게 들리는 착각

### 권장 설정

- 귀에서 편안하게 들릴 정도 (약 70~80dB)
- MR과 자신의 목소리가 균형 잡힌 레벨
- 3시간 이상 세션 시 중간에 헤드폰 벗고 귀 쉬기

---

### 녹음 세션 공통 체크리스트

**준비 단계**
- [ ] 세션 목표 명확히 설정 (완성할 구간·트랙 수)
- [ ] 모든 파일·장비 사전 점검 완료
- [ ] 아티스트 컨디션 확인 (보컬: 목 상태, 악기: 튜닝)

**세션 중**
- [ ] 테이크별 메모 (베스트/리테이크 표시)
- [ ] 문제 구간 즉시 인식하고 재녹음 결정
- [ ] 세션 종료 30분 전 마무리 시작

**후반 작업**
- [ ] 원본 파일 즉시 백업
- [ ] 믹싱 전 24시간 이상 청취 공백 유지

### 세션 효율을 높이는 팁

1. **가장 어려운 구간을 세션 초반에** — 에너지가 최고일 때 어려운 것 먼저
2. **구간 분리 녹음** — 전체 통으로 반복보다 구간별 완성 후 연결
3. **즉각 피드백** — 녹음 직후 헤드폰으로 바로 모니터링

## 마치며

보컬 녹음에는 밀폐형 모니터 헤드폰이 필수입니다. 5만원대 소니 MDR-7506부터 시작해도 충분히 좋은 결과물을 만들 수 있습니다.
