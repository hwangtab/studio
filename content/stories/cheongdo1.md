## 청도에서 KTX로 서울까지

청도는 경북 남부 도시로, 동대구역 KTX를 통해 서울과 약 2시간 40분대로 연결됩니다. 감으로 유명한 청도에서 당일 서울 스튜디오 방문이 가능합니다.

---

## 청도 → 연신내 이동 경로

### KTX 동대구역 경유 (권장)

```
① 청도 → 동대구역 (버스 약 40~50분)
② 동대구역 KTX 탑승 (서울역 방면, 약 1시간 40분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 2시간 50분~3시간 10분
```

---

## 당일 왕복 일정 예시 (청도 기준)

```
오전 7시 30분 청도 출발 → 동대구역 이동
오전 8시 20분 동대구역 KTX 출발
→ 오전 10시 서울역 도착
→ 오전 10시 40분 연신내역 도착
→ 오전 11시 세션 시작 (2시간)
→ 오후 1시 세션 완료
→ 오후 2시 30분 서울역 출발
→ 오후 4시 10분 동대구역 도착
→ 오후 5시 청도 도착
```
