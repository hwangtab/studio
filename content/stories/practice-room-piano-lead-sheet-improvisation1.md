# 피아노 리드시트 즉흥반주·코드 읽기 — 음악연습실 완전 가이드

리드시트(Lead Sheet)는 **멜로디와 코드 기호만 있는 악보**입니다. 어떻게 반주할지는 연주자가 즉흥으로 결정합니다. 재즈 스탠다드, 팝 곡, 찬양 반주—리드시트를 읽고 즉흥반주할 수 있으면 어떤 상황에서도 음악가로 활약할 수 있습니다.

---

## 리드시트 코드 기호 해독

### 기본 코드 기호

| 기호 | 코드명 | 예시 |
|-----|--------|------|
| C | C 메이저 | C-E-G |
| Cm | C 단조 | C-Eb-G |
| C7 | C 도미넌트 7th | C-E-G-Bb |
| Cmaj7 | C 메이저 7th | C-E-G-B |
| Cm7 | C 단7도 | C-Eb-G-Bb |
| Cdim | C 감화음 | C-Eb-Gb |
| Caug | C 증화음 | C-E-G# |

### 확장 코드

| 기호 | 뜻 | 코드 음 |
|-----|-----|--------|
| C9 | C7 + 9음(D) | C-E-G-Bb-D |
| C11 | C9 + 11음(F) | C-E-G-Bb-D-F |
| C13 | C11 + 13음(A) | 전체 7음 스택 |
| Csus4 | C Sus 4th | C-F-G |
| C/E | C over E (베이스 E) | 베이스 E, 위에 C 코드 |

### 슬래시 코드

**C/E:** C 코드를 E 베이스로 (인버전)

```
C/E: E 베이스 + C-E-G 코드
왼손: E
오른손: C-E-G
```

---

## 즉흥반주의 기본 접근

### 코드 보이싱 즉석 선택

같은 코드를 상황에 따라 다르게:

**C 메이저 보이싱 옵션:**
```
1. 근위치: C-E-G (간단)
2. 제1전위: E-G-C (부드러운 연결)
3. 제2전위: G-C-E (다음 코드에 따라)
4. 오픈: C-G-C-E (더 개방적)
```

**선택 기준:**
- 이전 코드와의 공통음 유지
- 베이스 음의 흐름
- 멜로디와의 관계

---

## 반주 패턴 즉석 적용

### 장르에 따른 패턴

**발라드 (느린 팝):**
```
왼손: 낮은 루트 + 5도
오른손: 코드를 아르페지오로
```

**스윙 재즈:**
```
왼손: 워킹 베이스 (4분음표)
오른손: 코드 콤핑 (오프비트)
```

**록:**
```
왼손: 파워 베이스 (옥타브)
오른손: 블록 코드 (8분음표)
```

**보사노바:**
```
왼손: 베이스 음 1박
오른손: 코드 2+3박, 4+박 (보사 리듬)
```

## 재즈 리드시트 반주

### "Autumn Leaves" 즉흥반주

**리드시트 코드:**
```
Em7 - Am7 - D7 - Gmaj7
Cmaj7 - F#m7b5 - B7 - Em
```

**즉흥반주 접근:**
```
Em7: 왼손 E2, 오른손 E4-G4-B4-D5
Am7: 왼손 A2, 오른손 A4-C5-E5-G5
D7: 왼손 D2, 오른손 D4-F#4-C5
Gmaj7: 왼손 G2, 오른손 G4-B4-F#5
```

**리듬 패턴 (스윙):**
```
왼손: 각 코드 1박
오른손: 2박, 4박 싱코페이션
```

### 워킹 베이스 즉흥

왼손 워킹 베이스 + 오른손 코드 콤핑:

```
Em7→Am7: E2-D2-C2-A2 (크로매틱 워킹)
```

---

## 즉흥반주 고급 기법

### 코드 대리 즉석 적용

리드시트에 없는 코드를 즉흥으로 대리:

**G7 → 트리톤 대리 Db7:**
```
리드시트: G7
즉흥 적용: Db7 (트리톤 대리)
소리가 더 부드럽게 해결
```

### 패싱 코드 즉흥 삽입

**C → Am 사이에 패싱:**
```
C → Bb7 (패싱) → Am
반음씩 하강
```

## 실전 리드시트 반주

### "The Girl from Ipanema" 즉흥반주

**기본 코드:**
```
Fmaj7 - G7 - Gm7 - C7
```

**보사노바 패턴으로:**
```
왼손: F2, G2, G2-D2, C2 (루트 + 5도)
오른손: 코드를 보사노바 리듬으로
        1박 (코드) + 2+박 (코드 반복)
```

### 코드 체인지 빠르게 처리

**리드시트 속독 훈련:**
1. 코드 이름만 먼저 빠르게 읽기
2. 조성 파악 (어떤 조인지)
3. 빈번히 나오는 진행 패턴 인식
4. 특이한 코드만 별도 확인

---

## 음악연습실 리드시트 연습

### 연습 루틴 (60분)

**1. 코드 기호 암기 (10분)**
   - 확장 코드 기호 복습
   - 슬래시 코드 연습

**2. 패턴 적용 (20분)**
   - 4가지 장르 패턴을 C-F-G-C 진행에 적용

**3. 재즈 스탠다드 (20분)**
   - "Autumn Leaves" 리드시트로 즉흥반주
   - 워킹 베이스 시도

**4. 즉석 반주 (10분)**
   - 새로운 리드시트를 처음 보고 즉석 반주
