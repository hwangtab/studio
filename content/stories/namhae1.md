## 남해에서 서울까지

남해는 경남 남쪽 섬 도시로, 진주 또는 순천을 경유해 KTX로 서울에 연결됩니다. 이동 시간이 다소 길지만 당일 왕복이 가능하며, 온라인 의뢰 서비스도 적극 활용할 수 있습니다.

---

## 남해 → 연신내 이동 경로

### KTX 진주역 경유 (권장)

대중교통 이용이 주차 걱정 없이 편리하게 방문할 수 있는 가장 좋은 방법입니다.

1. 남해 → 진주역 (버스 약 50분~1시간)
2. 진주역 KTX 탑승 (서울역 방면, 약 2시간 30~40분)
3. 서울역 → 지하철 → 연신내역 (약 30~40분)

- **총 소요시간**: 약 3시간 50분~4시간 20분

### SRT 순천역 경유

1. 남해 → 순천 (버스 약 1시간~1시간 20분)
2. 순천역 SRT/KTX 탑승 (수서역 방면, 약 2시간 20~30분)
3. 수서역 → 3호선 → 6호선 연신내역 (약 50분)

- **총 소요시간**: 약 4시간 10~40분

## 당일 왕복 일정 예시 (남해 기준)

아래 소요 시간은 평균 기준이며 혼잡 시간대에는 10~15분 추가를 권장합니다.

오전 5시 30분 남해 출발 → 진주역 이동
오전 6시 30분 진주역 KTX 출발
- 오전 9시 20분 서울역 도착
- 오전 10시 연신내역 도착
- 오전 10시 30분 세션 시작 (2시간)
- 오후 12시 30분 세션 완료
- 오후 2시 서울역 출발
- 오후 5시 진주역 도착
- 오후 6시 남해 도착

## 남해 음악 씬과 서울 스튜디오

남해는 독일마을·바래길로 유명한 경남 섬 도시입니다. 진주역 KTX를 이용하거나 남해고속버스로 서울까지 이동합니다. 자연환경 속 음악 창작 활동을 하는 아티스트들이 종종 서울 스튜디오를 찾습니다.

## 방문 전 세션 준비 가이드

1시간 30분 이상 이동 후 최상의 컨디션으로 세션에 임하려면 철저한 사전 준비가 필요합니다.

**출발 전 챙길 것:**
- [ ] 녹음할 곡의 가사·악보·MR 파일 (USB 또는 Google Drive)
- [ ] 원하는 사운드의 레퍼런스 트랙 2~3곡
- [ ] 예약 확인 캡처 + 교통편 티켓
- [ ] 보컬: 따뜻한 차·꿀물 보온병, 간식
- [ ] 귀마개 또는 노이즈캔슬링 이어폰 (이동 중 성대 보호)

**이동 중 활용법:**
- 이어폰으로 녹음할 곡 2~3회 예습
- 가사·감정 포인트 집중 정리
- 목·어깨 스트레칭 (장시간 이동 피로 완화)
- 충분한 수분 섭취 (기차 이동 중 성대 건조 방지)

**세션 팁:**
- 도착 후 20~30분 워밍업 시간 확보 (일정 계획 시 반드시 포함)
- 가장 중요한 구간을 세션 초반(이동 피로 전)에 먼저 녹음
- 원하는 사운드를 레퍼런스 곡으로 구체적으로 설명
- 온라인 파일 의뢰 서비스 병행 시 재방문 부담 최소화 가능

## 세션 당일 체크리스트

**전날:**
- [ ] MR·가사·레퍼런스 트랙 파일 최종 확인
- [ ] 교통편 티켓 + 예약 확인 캡처
- [ ] 충분한 수면 + 성대 무리 금지

**출발 전:**
- [ ] 따뜻한 차·꿀물 지참
- [ ] 이동 중 성대 보호 (소리 지르기 금지, 수분 섭취)

**도착 후:**
- [ ] 20~30분 워밍업 확보 (일정에 미리 포함)
- [ ] 엔지니어에게 레퍼런스·사운드 방향 설명
- [ ] 가장 어려운 구간 최우선 녹음

**녹음 중:**
- [ ] 헤드폰 볼륨 확인
- [ ] 테이크마다 즉시 청취
- [ ] 막차 시간 미리 확인 (귀가 일정)

## 마치며

남해에서 이동 시간이 길지만 KTX를 이용하면 당일 왕복 세션이 가능합니다. 이동이 부담된다면 온라인 파일 의뢰로 서울 스튜디오 품질의 믹싱·마스터링 서비스를 이용할 수 있습니다. 이동이 부담스럽다면 온라인 파일 의뢰를 추천합니다. 현지에서 드라이 보컬 WAV만 녹음해 보내주시면 믹싱·마스터링 후 납품합니다.
