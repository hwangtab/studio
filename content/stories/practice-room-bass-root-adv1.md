    a: "루트 너머 발전: ① 3도 — 코드의 장·단 3도로 코드 성격 표현 ② 5도 — 안정적인 코드 지지 ③ 7도 — 도미넌트7th의 긴장감 표현 ④ 코드톤 연결 — 루트에서 코드톤을 경과음으로 연결 ⑤ 리듬 조합 — 루트+코드톤의 리드미컬한 조합. 베이스는 '루트만 치는 악기'가 아닙니다. 루트를 기반으로 코드톤을 유연하게 활용하면 더욱 음악적인 베이스 파트가 됩니다. 특히 5도·7도를 사용하면 코드 진행에서 다음 화음으로의 자연스러운 흐름을 만들어냅니다."

## 코드를 읽는 베이스가 음악을 지배합니다

루트를 넘어 코드톤 전체를 활용하는 베이스. 방음 개인실에서 고급 베이스 코드 훈련을 탐색하세요.

베이스 루트·코드 읽기 고급 훈련의 핵심:
- **루트 너머**: 3·5·7도 코드톤 활용으로 음악적 베이스 라인
- **전위형 읽기**: G/B 슬래시 코드 표기 이해와 정확한 베이스 음 연주
- **5도권 자동화**: 12키 코드 진행 빠른 인식과 즉흥 연주
- **그루브 우선**: 복잡도보다 노래를 돋보이게 하는 단순 그루브
