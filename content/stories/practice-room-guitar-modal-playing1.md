# 기타 모달 연주·모드 스케일 활용 — 음악연습실 완전 가이드

모달 연주는 기타 즉흥 연주의 새로운 지평을 엽니다. **마이너 펜타토닉**만 사용하던 기타리스트가 모드를 마스터하면 훨씬 다양하고 색채감 있는 솔로를 만들어낼 수 있습니다. 이 가이드에서는 기타에서 가장 많이 사용하는 모드의 원리와 실전 활용법을 안내합니다.

---

## 모드(Mode)란?

### 기본 개념

모드는 같은 음계를 **다른 음에서 시작**하는 것입니다.

C 장조 음계: C-D-E-F-G-A-B

- **이오니안 (Ionian)**: C부터 시작 = C 장조
- **도리안 (Dorian)**: D부터 시작 = D 도리안
- **프리지안 (Phrygian)**: E부터 시작
- **리디안 (Lydian)**: F부터 시작
- **믹소리디안 (Mixolydian)**: G부터 시작
- **에올리안 (Aeolian)**: A부터 시작 = A 자연 단음계
- **로크리안 (Locrian)**: B부터 시작

---

## 기타에서 가장 많이 쓰는 모드

### 도리안 모드 (Dorian)

**특징:** 마이너 스케일이지만 장6도가 포함 — 밝은 마이너

**D 도리안:** D-E-F-G-A-B-C-D

**vs D 자연단음계:** D-E-F-G-A-Bb-C-D
차이: 6도가 B(장6도) vs Bb(단6도)

**활용:**
- 마이너 코드 진행에서 솔로
- Dm7, Am7, Em7 위에서 연주
- 펑크, 재즈-록, 퓨전에서 자주

**기타 포지션 (5번 현 5프렛 D에서 시작):**
```
5번 현: D(5)-E(7)
4번 현: F(3)-G(5)-A(7)
3번 현: B(4)-C(5)-D(7)
2번 현: E(5)-F(7)
```

### 믹소리디안 모드 (Mixolydian)

**특징:** 장조이지만 단7도 포함 — 블루지한 장조

**G 믹소리디안:** G-A-B-C-D-E-F-G

**vs G 장조:** G-A-B-C-D-E-F#-G
차이: 7도가 F(단7도) vs F#(장7도)

**활용:**
- 도미넌트 7th 코드 위에서 솔로
- G7, D7, A7 코드 진행
- 블루스, 록, 컨트리에서 핵심 모드

**기타 포지션:**
G 믹소리디안 = G 장조 스케일에서 7도만 반음 내림

### 리디안 모드 (Lydian)

**특징:** 장조이지만 증4도(♯4) 포함 — 꿈꾸는 듯한 사운드

**F 리디안:** F-G-A-B-C-D-E-F

**vs F 장조:** F-G-A-Bb-C-D-E-F
차이: 4도가 B(증4도) vs Bb(완전4도)

**활용:**
- 장조 코드 위에서 몽환적 색채 추가
- Fmaj7, Cmaj7#11 코드
- 영화 음악, 퓨전재즈에서 자주

## 모달 즉흥 연주 실전

### 도리안 즉흥 연주 연습

**백킹 코드:** Dm7 루프

**접근법:**
1. 먼저 D 자연단음계로 연주
2. 6도 음(B)을 추가해 도리안 색채
3. 도리안 특유의 밝은 느낌 의도적으로 활용

**특징음 강조:** B음(장6도)을 시작음 또는 해결음으로 사용

### 믹소리디안 즉흥 연주 연습

**백킹 코드:** G7 루프

**접근법:**
1. G 장조 스케일에서 F음(단7도) 포함
2. F음을 의도적으로 강조
3. 블루스 느낌과 혼합

**핵심 리프 예시:**
```
G-A-B-C-D-C-B-F-G
(G 믹소리디안의 F음으로 블루지함 추가)
```

## 포지션 시스템

### 5포지션 시스템

기타에서 각 모드를 5개의 포지션으로 나누어 전 지판에서 연주:

**G 믹소리디안 포지션 1 (3-6 프렛 구역):**
```
6번 현: G(3)-A(5)
5번 현: B(2)-C(3)-D(5)
4번 현: E(2)-F(3)-G(5)
3번 현: A(2)-B(4)-C(5)
2번 현: D(3)-E(5)
1번 현: F(1)-G(3)-A(5)
```

각 포지션을 마스터하면 지판 전체에서 모드 연주 가능.

## 음악연습실 모달 연주 연습 루틴

### 기초 (30분)

1. **도리안 암기**: D 도리안 1 옥타브 상행하행 (10분)
2. **믹소리디안 암기**: G 믹소리디안 (10분)
3. **백킹 트랙**: Dm7 루프에서 도리안 즉흥 (10분)

### 중급 (30분)

1. **리디안 추가**: F 리디안 학습
2. **모드 비교**: D 자연단→D 도리안 전환 느낌 비교
3. **G7 백킹**: 믹소리디안 즉흥 연주 (15분)

### 상급

1. 모드별 특징음 중심 프레이징
2. 한 곡에서 코드에 따라 모드 전환
3. 모달 재즈 스탠다드 ("So What", "Maiden Voyage")
