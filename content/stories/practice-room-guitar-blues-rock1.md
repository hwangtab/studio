# 블루스 록 기타·SRV·Eric Clapton 스타일·펜타토닉 — 음악연습실 완전 가이드

블루스 록 기타(Blues Rock Guitar)는 **블루스의 감정과 록의 에너지가 만나는 지점**입니다. Stevie Ray Vaughan(SRV)의 텍사스 블루스 파워, Eric Clapton의 영국식 우아한 블루스, B.B. King의 비브라토 — 이들이 블루스 록 기타의 기둥을 세웠습니다. 마이너 펜타토닉 스케일과 블루 노트가 이 음악의 알파벳입니다.

---

## 블루스 록이란?

### 블루스 + 록의 결합

**블루스 록의 역사:**
```
1960년대: 영국 밴드(Cream, Rolling Stones)가
미국 블루스를 록으로 재해석
Clapton: B.B. King, Freddie King 영향
SRV: Jimi Hendrix + 텍사스 블루스

```

**블루스 록의 특징:**
```

마이너 펜타토닉 중심 솔로
블루 노트 (b3, b5, b7)
오버드라이브 앰프
워밍업된 기타 톤 (표준 A442 또는 Eb)

```

---

## 마이너 펜타토닉 스케일

### 블루스의 기초

**A 마이너 펜타토닉:**
```

A-C-D-E-G-A (5음)
프렛 포지션:
E: 5-8
A: 5-7
D: 5-7
G: 5-7
B: 5-8
E: 5-8

```

**왜 5음 스케일인가:**
```

반음 없음 → 어디서 연주해도 자연스러움
블루스 느낌 = 이 5음에서 나옴
= 가장 단순하지만 강력한 음계

```

### 블루스 스케일 (6음)

**블루 노트 추가:**
```

A 블루스: A-C-D-Eb-E-G-A (6음)
Eb = "블루 노트" (#4 또는 b5)
= 마이너 펜타토닉 + Eb

```

**블루 노트의 효과:**
```

C-Eb: 반음 이동 = 강한 긴장
Eb-E: 반음 이동 = 블루스 느낌
= "슬픔"의 소리

```

---

## Stevie Ray Vaughan 스타일

### 텍사스 블루스의 번개

SRV(Stevie Ray Vaughan):
- **두꺼운 현:** .013 게이지 (두꺼운 현 = 두꺼운 톤)
- **Eb 튜닝:** 반음 낮게 (현 장력 낮춤)
- **강한 어택:** 파워풀한 피킹
- **Hendrix 영향:** 손가락 연주 기법

**SRV "Pride and Joy" 리프:**
```

E7 셔플 진행
E 블루스 스케일
강한 어택 + 빠른 벤드
= 텍사스 허리케인 블루스

```

**SRV 비브라토:**
```

넓고 강한 비브라토
음을 충분히 오래 유지
= 영혼의 절규

```

---

## Eric Clapton 스타일

### 영국 블루스의 우아함

Eric Clapton(Cream, Derek and the Dominos, 솔로):
- **마샬 앰프:** 클래식 영국 블루스 톤
- **표현적 벤딩:** 반음·온음 벤드
- **레가토:** 매끄럽고 노래하는 솔로

**Clapton "Crossroads" 솔로:**
```

A 마이너 펜타토닉 포지션 1
빠른 런 + 강한 벤드
= 크로스로드에서의 결투

```

**Clapton 벤딩:**
```

음을 반음 또는 온음 위로 구부리기
손가락 3개로 지지
= 호른처럼 울부짖는 기타

```

---

## B.B. King 스타일

### 블루스 황제의 비브라토

B.B. King:
- **비브라토만으로 노래:** 빠르고 좁은 비브라토
- "Lucille" 레스폴 + 크린 앰프
- 단음 솔로의 달인 (코드보다 단음)

**B.B. King 비브라토:**
```

음을 누른 후 바로 비브라토
매우 빠른 속도 (♩= 8~10번/초)
= 음이 떨리며 노래함

```

**B.B. King "The Thrill is Gone":**
```

Bm 블루스
단음 라인 + 강한 비브라토
= 느리고 표현적인 블루스

```

## 블루스 록 솔로 구성

### 12마디 블루스 위 솔로

**A 블루스 12마디:**
```

A7 (4마디) | D7 (2마디) | A7 (2마디) |
E7 (1마디) | D7 (1마디) | A7-E7 (2마디)

```

**각 코드 위 펜타토닉:**
```

A7: A 마이너 펜타토닉 (전체)
D7: D 마이너 펜타토닉 (또는 A 펜타토닉 유지)
E7: E 마이너 펜타토닉 (또는 A 펜타토닉 유지)
= A 펜타토닉만으로도 충분!

```

### 솔로 구성 원칙

**콜앤드리스펀스:**
```

짧은 구절 → 침묵 → 반응 구절
= 블루스 솔로의 대화법

```

**클라이맥스 구축:**
```

낮은 음역 → 높은 음역으로 상행
조용히 → 점점 강하게
= 솔로의 드라마

```

## 음악연습실 블루스 록 기타 연습

### 60분 루틴

**1. A 마이너 펜타토닉 (10분)**
   - 5포지션 전체 암기
   - 상하행 느리게 (♩= 60)
   - 각 음 벤딩 연습

**2. 벤딩·비브라토 (15분)**
   - 반음 벤딩 (각 포지션)
   - B.B. King 비브라토 흉내
   - 손가락 세 개로 지지

**3. 12마디 블루스 위 솔로 (25분)**
   - 느린 블루스 (♩= 60)
   - 콜앤드리스펀스 구조
   - SRV/Clapton 스타일 시도

**4. 블루스 록 리프 (10분)**
   - 셔플 리듬 리프
   - 오버드라이브 앰프와 함께
   - 전체 블루스 노래

## 마무리

블루스 록 기타는 **감정의 직접적인 표현**입니다. SRV가 "블루스는 느끼는 것이지 생각하는 것이 아니다"고 했듯, 펜타토닉 위의 벤딩 하나가 말보다 더 많은 것을 전합니다. 5개의 음, 하나의 벤드, 그리고 진심 — 이것이 블루스 록 기타의 전부입니다.

은평구 24시간 음악연습실에서 A 마이너 펜타토닉부터 시작하세요. 첫 벤드가 제대로 나오는 날, 블루스의 문이 활짝 열립니다.

## Studio NOL이 블루스록 기타 연습실 사용자에게 자주 권하는 3가지

스튜디오 놀(연신내, 서울 은평구) 음악연습실에서 블루스록 기타 연습 상담 때 자주 드리는 조언입니다.

**1. 12마디 블루스 + 록 다이나믹 결합**

블루스록은 블루스 12마디 진행에 록 다이나믹을 결합합니다. 두 요소를 별도 연습 후 결합합니다.

**2. 벤딩 + 비브라토 — 표현력 절반**

블루스록의 절반은 벤딩과 비브라토 표현입니다. 음정 정확도와 비브라토 폭·속도 일정성을 별도 훈련합니다.

**3. 오버드라이브 + 클린 — 톤 전환**

블루스록은 클린 톤과 오버드라이브를 교대 활용합니다. 풋스위치로 즉시 전환할 수 있도록 페달 배치를 최적화합니다.

---

기타 솔로 연주에서 벤딩의 정확도는 음악적 표현의 핵심 요소입니다. 목표 음정까지 정확히 올려야 하므로 귀로 확인하며 연습하는 것이 중요합니다. 비브라토는 처음에는 너무 빠르거나 얕게 만들기 쉬운데, 일정한 폭과 속도를 유지하는 훈련이 필요합니다. 해머온과 풀오프를 활용한 레가토 주법은 피킹 없이도 유려한 선율을 만들어주며, 프레이즈에 다양성을 더합니다. 슬라이드 기법을 자연스럽게 결합하면 블루스적 표현이 한층 풍부해집니다. 음악 연습에서 집중력을 유지하기 위해 연습 시간을 짧은 블록으로 나누는 것이 효과적입니다. 25분 집중 연습 후 5분 휴식하는 방식은 뇌의 정보 처리를 돕고 피로를 줄여줍니다. 어려운 패시지를 반복할 때 지루함을 느낀다면 약간 다른 리듬이나 다이나믹으로 변형해서 연습하면 집중력을 다시 높일 수 있습니다. 연습실을 예약하고 직접 방문하는 행위 자체가 연습 모드로 전환하는 심리적 트리거 역할을 합니다.
