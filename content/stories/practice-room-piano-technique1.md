## 테크닉은 음악 표현의 그릇입니다

아무리 좋은 음악성도 테크닉이 따라오지 않으면 표현되지 않습니다. 방음 개인실의 업라이트 피아노에서 체계적인 테크닉 훈련을 하세요.

피아노 테크닉 훈련의 핵심:
- **이완**: 힘을 빼야 속도가 나오고 테크닉이 완성됨
- **균형**: 모든 손가락에서 동일한 음량
- **느린 속도**: 완벽한 느린 연주가 빠른 연주의 기초
- **매일 꾸준히**: 테크닉은 한 번에 늘지 않음

---

## 피아노 테크닉 훈련 체계

### 손가락 기초 (하농)
```
하농 1~5번: 손가락 균등 훈련
매일 20분, 메트로놈 필수
다양한 아티큘레이션 적용
```

### 스케일·아르페지오
```
모든 장·단조 스케일 (24조성)
2옥타브 → 4옥타브 점진적 확장
양손 병행 → 반진행
```

### 트릴 훈련
```
1-2, 2-3, 3-4, 4-5 모든 조합
각 20회 × 3세트
메트로놈으로 일정한 속도 유지
```

## 테크닉 연습 루틴 (45분)

| 구간 | 내용 | 시간 |
|-----|------|------|
| 워밍업 | 손가락 스트레칭 + 5지 연습 | 5분 |
| 하농 | 1~10번 다양한 다이나믹 | 15분 |
| 스케일 | 4조성 스케일·아르페지오 | 15분 |
| 트릴 | 약한 손가락 집중 | 5분 |
| 곡 적용 | 테크닉 필요 구간 | 5분 |
