## 자세는 기술의 기반입니다

아무리 연습해도 잘못된 자세에서는 실력이 한계에 부딪힙니다. 올바른 자세가 확립되면 속도·음질·지구력 모두 향상됩니다.

올바른 자세의 효과:
- **부상 예방**: 반복 사용 손상 방지
- **음질 향상**: 불필요한 긴장이 사라져 소리 해방
- **속도 향상**: 자연스러운 움직임으로 빠른 연주 가능
- **지구력 증가**: 효율적인 근육 사용으로 피로 감소

## 악기별 자세 교정 체크리스트

### 피아노
- [ ] 의자 높이: 팔꿈치 = 건반 높이
- [ ] 손 모양: 자연스러운 아치 (달걀 쥔 형태)
- [ ] 손목: 건반면과 평행
- [ ] 어깨: 자연스럽게 내려놓기
- [ ] 등: 약간 앞으로 기울기 (척추 자연 곡선)

### 기타 (클래식)
- [ ] 발 받침 사용
- [ ] 기타 넥: 45도 위로
- [ ] 왼손 엄지: 넥 중앙 뒤
- [ ] 오른팔: 기타 바디에 자연스럽게
- [ ] 오른손 손목: 구부리지 않기

### 보컬
- [ ] 발: 어깨 너비로 벌리기
- [ ] 무릎: 약간 구부린 상태
- [ ] 가슴: 자연스럽게 들기
- [ ] 어깨: 뒤로 내리기 (귀와 거리 유지)
- [ ] 턱: 수직 (앞으로 내밀지 않기)

## 자세 교정 루틴 (매 연습 전 5분)

1. **몸 스캔**: 발→다리→허리→등→어깨→팔 순서로 긴장 확인
2. **자세 세팅**: 악기 앞에 앉아 위 체크리스트 점검
3. **거울 확인**: 가능하면 옆면도 확인
4. **3회 호흡**: 긴장 풀고 자연스러운 상태로
5. **시작**: 올바른 자세에서 워밍업

### 효율적인 연습을 위한 원칙

좋은 연습 습관이 실력 향상의 핵심입니다.

1. **목표 설정** — 오늘 연습에서 달성할 구체적인 목표 1개를 정하고 시작
2. **분리 연습** — 어려운 구간은 전체 반복보다 해당 2~4마디만 집중
3. **속도 조절** — 완벽하지 않은 기법을 빠른 속도로 반복하면 잘못된 근육 기억만 강화됨

### 연습 중 자주 하는 공통 실수

1. **어려운 구간을 피해서 쉬운 곳만 반복** — 불편한 구간이 실력 향상의 지점
2. **메트로놈 없이 빠른 속도 연습** — 느린 속도의 정확성이 빠른 속도의 기반
3. **연습 시간만 늘리고 내용은 방치** — 30분 집중 연습이 2시간 멍하니 반복보다 효과적

### 연습 자가 진단

- [ ] 오늘의 목표를 시작 전에 정했는가?
- [ ] 어려운 구간을 분리해서 집중 반복했는가?
- [ ] 연습 후 무엇이 개선되었는지 구체적으로 인식하는가?



## 4주 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 점검 | 기본기 복습, 문제 구간 파악 | 40분 |
| 2주차 | 구간 집중 | 어려운 부분 느린 템포 반복 | 45분 |
| 3주차 | 전체 흐름 | 전곡 연결, 템포 단계적 올리기 | 50분 |
| 4주차 | 완성 | 목표 템포 + 표현·다이나믹 완성 | 60분 |

**주간 체크포인트:** 1주차: 약점 구간 3개 목록 작성 / 2주차: 각 구간 느린 템포 100% 달성 / 3주차: 전곡 끊김 없이 완주 / 4주차: 청중 앞 또는 녹음으로 최종 확인


## 연습실 최대한 활용하는 법

**시간별 추천 구성 (1시간 기준):**
- 0~10분: 워밍업 (스트레칭, 기본 음계 또는 개방현)
- 10~45분: 목표 구간 집중 연습 (어렵고 중요한 부분 먼저)
- 45~55분: 전곡 런스루 (흐름·감정 표현 포함)
- 55~60분: 쿨다운 + 다음 연습 목표 메모

**방음 환경에서만 가능한 연습:**
- 최대 볼륨·최대 다이나믹 표현 (집에서 불가)
- 큰 소리로 가사 암송 + 발음 교정
- 틀렸을 때 즉각 멈추고 되돌아가는 구간 반복 훈련
