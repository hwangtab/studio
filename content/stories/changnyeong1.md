## 창녕에서 KTX로 서울까지

창녕은 경남 북부 도시로, 동대구역 KTX를 통해 서울과 약 2시간 40분대로 연결됩니다. 우포늪으로 유명한 창녕에서 당일 서울 스튜디오 방문이 가능합니다.

---

## 창녕 → 연신내 이동 경로

### KTX 동대구역 경유 (권장)

```
① 창녕 → 동대구역 (버스 약 40~50분)
② 동대구역 KTX 탑승 (서울역 방면, 약 1시간 40분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 2시간 50분~3시간 10분
```

---

## 당일 왕복 일정 예시 (창녕 기준)

```
오전 7시 30분 창녕 출발 → 동대구역 이동
오전 8시 20분 동대구역 KTX 출발
→ 오전 10시 서울역 도착
→ 오전 10시 40분 연신내역 도착
→ 오전 11시 세션 시작 (2시간)
→ 오후 1시 세션 완료
→ 오후 2시 30분 서울역 출발
→ 오후 4시 10분 동대구역 도착
→ 오후 5시 창녕 도착
```

---

## 온라인 파일 의뢰 서비스

```
창녕 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
