## 가리봉·구로역·구일·개봉에서 연신내 스튜디오 놀까지

구로구 남부(가리봉·구로역·구일·개봉)에서 1호선 또는 7호선을 이용하면 연신내 스튜디오 놀까지 약 35~48분이면 도달합니다.

---

## 지역별 이동 경로

### 구로역 출발 (1호선·2호선)

### 구로역 출발 (1호선)

1. 구로역(1호선) 탑승
2. 신도림역에서 2호선 환승 (홍대입구 방면)
3. 합정역에서 6호선 환승
4. 6호선 → 연신내역

- **총 소요시간**: 약 30~38분

### 가리봉역 출발 (7호선)

1. 가리봉역(7호선) 탑승
2. 이수역 방면 이동 (남태령 방향)
3. 이수역에서 4호선 환승
4. 동대문역사문화공원역에서 6호선 환승
5. 6호선 → 연신내역

- **총 소요시간**: 약 40~48분

### 개봉·오류동역 출발 (1호선)

1. 개봉역 또는 오류동역(1호선) 탑승
2. 신도림역에서 2호선 환승
3. 합정역에서 6호선 환승
4. 6호선 → 연신내역

- **총 소요시간**: 약 38~45분

## 구로구 남부 지역별 소요 시간

| 출발지 | 경로 | 소요 시간 |
|--------|------|---------|
| 구로역 (1호선) | 1호선 → 신도림 → 2호선 → 합정 → 6호선 | 약 30~38분 |
| 가리봉역 (7호선) | 7호선 → 이수 → 4호선 → 동대문 → 6호선 | 약 40~48분 |
| 개봉역 (1호선) | 1호선 → 신도림 → 2호선 → 합정 → 6호선 | 약 38~45분 |
| 오류동역 (1호선) | 1호선 → 신도림 → 2호선 → 합정 → 6호선 | 약 40~48분 |

**스튜디오 주소**: 서울특별시 은평구 연신내역 인근 (연신내역 3번 출구 도보 5분)
