## 게임 음악 — 인터랙티브 오디오의 세계

게임 음악은 단순 BGM이 아닌 플레이어의 상태와 행동에 반응하는 인터랙티브 오디오입니다. 루프 설계, 전환 로직, 감정 강화가 핵심입니다.

---

## 게임 음악의 종류

NFT·Web3 음악 플랫폼은 빠르게 변화하므로 최신 정보를 지속적으로 확인해야 합니다.

### 음악 유형별 역할

1. 탐험 BGM (Exploration)
  - 느리고 반복적인 루프
  - 세계관과 분위기 설정
  - 긴장감 최소화

2. 전투 BGM (Combat)
  - 빠르고 에너지 높은 루프
  - 타격감·긴박감 표현
  - 탐험 BGM과 빠른 전환 필요

3. 보스 BGM (Boss Battle)
  - 가장 강렬하고 복잡한 음악
  - 오케스트라·코러스 활용
  - 페이즈 전환에 따른 음악 변화

4. 컷씬·이벤트 (Cutscene)
  - 선형적 스코어링 (영화음악과 유사)
  - 감정 포인트에 맞춘 정밀 타이밍

5. 메뉴·UI BGM
  - 차분하고 반복에 강한 루프
  - 브랜드 아이덴티티 반영

## 루프 음악 설계

DAW 업데이트 전에는 현재 프로젝트 파일을 백업해두는 것이 안전합니다.

### 루프 포인트 설정

1. 마지막 음이 첫 음과 자연스럽게 연결
2. 루프 끝에 해결감 있는 화음 피하기
3. 드럼·베이스 라인 루프 타이밍 정확히
4. DAW에서 루프 재생 테스트

### 루프 길이

- **짧은 루프 (4~8마디)**: 메뉴·UI
- **중간 루프 (16~32마디)**: 탐험·전투
- **긴 루프 (64마디+)**: 보스 배틀

### 레이어 시스템

- 기본 레이어 (항상 재생)
- 전투 레이어 (전투 시 추가)
- 위험 레이어 (HP 낮을 때 추가)
- 미들웨어에서 실시간 제어

## 인터랙티브 오디오 미들웨어

아래 내용은 한국 기준이며, 해외 유통 시에는 각국 저작권 기관 정책을 별도 확인하세요.

### Wwise (Audiokinetic)

- 업계 표준 미들웨어
- 복잡한 게임 오디오 구현
- 무료 라이선스 (프로젝트 규모 이하)

### FMOD Studio

- 비교적 학습하기 쉬운 미들웨어
- 인디 게임 개발자에게 인기
- 무료 라이선스 (수익 기준)

### Unity Audio / Unreal Audio

- 게임 엔진 내장 오디오 시스템
- 소규모 프로젝트에 적합
- 미들웨어보다 기능 제한

### 핵심 개념

- **State**: 게임 상태 (전투/탐험/메뉴)
- **Switch**: 캐릭터·환경 변화
- **RTPC**: 실시간 파라미터 (HP, 속도)

## 게임 음악 포트폴리오 제작

아래 항목은 법적 효력에 관한 일반 정보이며, 구체적 사안은 전문가 상담을 권장합니다.

### 포트폴리오 필수 요소

1. 장르별 샘플 (JRPG, FPS, 플랫포머 등)
2. 루프 재생 데모 (반복 자연스러움 증명)
3. 인터랙티브 오디오 데모 (상태 전환 시연)
4. 사운드 디자인 샘플 (있다면)

### 납품 포맷

- WAV (44.1kHz/48kHz 24-bit)
- OGG (런타임 재생용)
- 미들웨어 프로젝트 파일
