## 딜레이 종류 — 에코로 보컬에 생동감 더하기

딜레이는 리버브와 함께 보컬 믹싱에서 공간감과 리듬감을 만드는 핵심 도구입니다.

---

## 딜레이 종류별 특성

```
① 슬랩백 딜레이 (Slapback Delay)
   - 딜레이 타임: 40~120ms
   - 1회 반복 (피드백 0%)
   - 두툼하고 친밀한 공간감
   - 적합 장르: 컨트리, 로커빌리, R&B, 레트로 팝

② 템포 싱크 딜레이 (Tempo-Sync Delay)
   - BPM에 맞게 자동 딜레이 타임 설정
   - 1/4, 1/8, 1/16 노트 등 선택
   - 리듬감 있는 에코 반복
   - 적합 장르: K-POP, 팝, 전자음악, EDM

③ 핑퐁 딜레이 (Ping-Pong Delay)
   - 좌우 채널 번갈아 에코 반복
   - 스테레오 폭 넓힘
   - 적합 장르: 일렉트로닉, 앰비언트, 신스팝

④ 테이프 딜레이 (Tape Delay)
   - 아날로그 테이프 특유의 워밍하고 흐릿한 에코
   - 자연스럽고 빈티지한 질감
   - 적합 장르: 재즈, 소울, 레트로 록

⑤ 디지털 딜레이 (Digital Delay)
   - 정확하고 깔끔한 에코 반복
   - 가장 범용적
   - 적합 장르: 전 장르
```

## 딜레이 주요 파라미터

```
[핵심 파라미터]
Delay Time (딜레이 타임)
→ 원음과 에코 사이의 시간
→ 짧을수록 슬랩백, 길수록 에코 효과
→ 템포 싱크 시 1/4 또는 1/8 노트 추천

Feedback (피드백)
→ 에코 반복 횟수 조절
→ 보컬 권장: 20~35%
→ 높을수록 더 많이 반복

Mix/Wet
→ 딜레이 양 조절
→ 보컬: 15~30% Wet

High Cut / Low Cut
→ 에코 음역대 제한
→ 고음 차단으로 자연스러운 잔향 표현
```

## 장르별 보컬 딜레이 설정

```
[K-POP·팝]
→ 템포 싱크 딜레이 (1/8 또는 1/4 노트)
→ Feedback: 20~30%
→ Mix: 15~25%

[발라드]
→ 긴 딜레이 타임 (300~500ms)
→ Feedback: 15~25%
→ Mix: 10~20%

[R&B·소울]
→ 슬랩백 딜레이 (60~100ms)
→ Feedback: 0~10%
→ Mix: 15~25%

[힙합·트랩]
→ 슬랩백 딜레이 (50~80ms)
→ 또는 딜레이 대신 숏 리버브 사용
```

## 딜레이 vs 리버브 선택 기준

```
[딜레이를 선택할 때]
→ 리드 보컬에 에너지·존재감 강조
→ 빠른 템포 곡에서 리듬감 부여
→ 공간감보다 질감 표현

[리버브를 선택할 때]
→ 자연스러운 공간감
→ 악기 사이에 보컬을 자연스럽게 녹아들게
→ 웅장함·분위기 표현

[함께 사용 시]
→ 딜레이 먼저 (원음 바로 뒤)
→ 리버브 나중 (딜레이 에코에도 공간감 추가)
→ 딜레이 → 리버브 체인 순서
```
