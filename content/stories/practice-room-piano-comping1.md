# 피아노 콤핑·리듬 반주 기법 — 음악연습실 완전 가이드

콤핑(Comping)은 "Accompanying"의 줄임말로, 솔리스트나 멜로디를 지원하는 피아노 반주 기법입니다. 재즈에서 콤핑은 단순한 코드 반주가 아닌 **솔리스트와의 대화**, 리듬적 에너지 제공, 화성적 지원의 복합적 역할을 합니다.

---

## 콤핑의 기본 원리

### 콤핑 vs 단순 코드 연주

**단순 코드 연주:**
```
박자에 맞춰 규칙적으로 코드 arpeggio
→ 배경 음악처럼 들림, 솔로 방해
```

**효과적인 콤핑:**
```
솔리스트의 프레이즈 사이에 응답
박자를 채우기보다 공간을 만들기
리듬 싱코페이션으로 에너지 조절
```

### 콤핑의 3대 원칙

1. **공간을 존중하라**: 솔리스트가 연주할 때는 콤핑을 줄이거나 멈추기
2. **대화하라**: 솔리스트의 프레이징에 응답하는 리듬과 보이싱
3. **지원하라**: 화성적 컨텍스트를 명확히 제공

---

## 재즈 콤핑 리듬 패턴

### 기본 싱코페이션 패턴

```
4/4박자 기본 콤핑:
1  e  +  a  2  e  +  a  3  e  +  a  4  e  +  a
.  .  X  .  .  X  .  X  .  .  X  .  X  .  X  .
```

X = 코드 타격, . = 쉬기

이 싱코페이션 패턴이 재즈 콤핑의 핵심 리듬

### 빠른 스윙 콤핑

**BPM 180 이상 빠른 스윙:**
```
콤핑 밀도를 줄임 → 더 많은 공간 생성
2박 또는 4박에만 콤핑 → 단순화
```

### 느린 발라드 콤핑

**BPM 60 이하 발라드:**
```
더 많은 콤핑 가능
루바토를 따라 자유로운 리듬
보이싱의 색채에 집중
```

## 보이스 리딩 콤핑

### 코드 전환 최소 이동

II-V-I에서 보이스를 최소한만 이동:

**Dm7→G7→Cmaj7 보이스 리딩:**
```
Dm7:   F-A-C  (오른손)
G7:    F-B-D  (F 유지, A→B, C→D)
Cmaj7: E-B-D  (E만 이동, B-D 유지)
```

이 방법으로 콤핑이 부드럽게 흐릅니다.

### 내성부 멜로디 콤핑

보이싱 안에 짧은 내성부 멜로디 삽입:

```
Cmaj7: E-G-B (기본)
다음: E-A-B (G→A 상행 멜로디 내성부)
다음: E-G-B (다시 G로)
```

## 팝 피아노 콤핑

### 8비트 팝 콤핑

```
8비트 콤핑:
1  +  2  +  3  +  4  +
X  .  X  X  X  .  X  X
```

**컨텍스트:**
- 버스: 적게 콤핑
- 코러스: 가득 채우기

### 팝 발라드 콤핑

```
아르페지오 콤핑:
1  e  +  a (아르페지오)
루트 - 5도 - 3도 - 7도
```

## 드럼과의 리듬 상호작용

### 드럼 히햇과 콤핑

드럼 히햇의 업비트(+)에 맞춰 콤핑 싱코페이션:

```
드럼 히햇: . X . X . X . X
피아노:    . . X . . . X .
             ↑         ↑
           업비트에 맞춤
```

### 킥 드럼 피하기

킥 드럼이 치는 박자에 콤핑을 가끔 비워두기:

```
킥: X . . . X . . .
콤핑: . X X . . X X .
(킥 박자 피해서 채우기)
```

## 음악연습실 콤핑 루틴

### 기초 단계 (60분)

**1. 리듬 패턴 암기 (15분)**
- 기본 싱코페이션 패턴 손으로 탭핑
- BPM 80

**2. II-V-I 콤핑 (20분)**
- C, F, Bb 조 II-V-I 콤핑
- 루트리스 보이싱 + 싱코페이션

**3. 솔로 대화 연습 (15분)**
- 음원 틀고 솔리스트 프레이즈에 응답 콤핑
- Miles Davis 트럼펫 솔로에 응답

**4. 녹음 분석 (10분)**
- 자신의 콤핑 녹음
- 공간이 충분한지, 솔로 방해 없는지 확인
