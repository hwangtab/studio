# 피아노 스트라이드 입문·왼손 점프 기초 — 음악연습실 완전 가이드

스트라이드 피아노(Stride Piano)는 **왼손이 베이스와 코드 사이를 빠르게 오가는 재즈 피아노 기법**입니다. James P. Johnson, Fats Waller, Willie "The Lion" Smith가 1920-30년대 할렘에서 완성했습니다. 왼손이 혼자 베이스·화음을 담당하고 오른손이 자유롭게 멜로디를 연주합니다.

---

## 스트라이드 피아노란?

### 기본 원리

**왼손 스트라이드 패턴:**
```
1박: 낮은 단음 (베이스 음)
2박: 중음역 코드
3박: 낮은 단음 (베이스 음 또는 5도)
4박: 중음역 코드

= "jump" 동작으로 왼손이 건반을 "뛰어다님"
```

**왜 스트라이드(Stride)인가:**
```
stride = 크게 걷다, 뛰어다니다
왼손이 넓은 음역을 뛰어다님
= 스트라이드 피아노
```

### 스트라이드 vs 래그타임

| | 래그타임 | 스트라이드 |
|--|--------|----------|
| 왼손 이동 | 짧게 (um-pah) | 더 넓게 (8도+) |
| 스윙 | 약함 | 강함 |
| 즉흥 | 적음 | 많음 |
| 시대 | 1890-1920 | 1920-1940 |

---

## 기본 스트라이드 왼손 패턴

### 단계 1: 기본 um-pah

**C 메이저 기본 스트라이드:**
```
1박: C2 (낮은 C)
2박: E4-G4-C5 (C 코드)
3박: G2 (5도)
4박: E4-G4-C5 (C 코드)
```

**왼손 거리:**
```
1박 C2 → 2박 E4: 약 2.5 옥타브 점프
이 점프가 스트라이드의 핵심 동작
```

### 단계 2: 점프 연습

**점프만 집중 연습:**
```
천천히: C2 → E4 (점프)
매우 천천히 (♩= 40) 시작
점프의 정확성이 먼저
```

**점프 훈련법:**
```
1. 낮은 음 누르기
2. 눈으로 높은 코드 위치 확인
3. 눈 감고 점프
4. 반복하여 근육 기억화
```

### 단계 3: 리듬에 맞추기

**메트로놈 ♩= 60:**
```
1박: C2 (정확하게)
2박: E4-G4-C5 (정확하게)
3박: G2 (정확하게)
4박: E4-G4-C5 (정확하게)
```

**핵심:** 점프가 부정확해도 **박자를 놓치지 않기**.

---

## 첫 스트라이드 진행

### C-F-G-C 진행

**왼손 스트라이드 (C 메이저):**
```
C 코드 (2마디):
1: C2, 2: C4-E4-G4, 3: G2, 4: C4-E4-G4
1: C2, 2: C4-E4-G4, 3: G2, 4: C4-E4-G4

F 코드 (1마디):
1: F2, 2: C4-F4-A4, 3: C3, 4: C4-F4-A4

G7 코드 (1마디):
1: G2, 2: B3-D4-F4, 3: D3, 4: B3-D4-F4
```

### 오른손 추가

**간단한 오른손 멜로디:**
```
C 메이저 스케일 (C4-D4-E4-F4-G4)
또는 C 코드 아르페지오 (C4-E4-G4-C5)
왼손 스트라이드와 동시에
```

## James P. Johnson 스타일

### "Carolina Shout" 입문

James P. Johnson의 대표작에서 간단한 요소:

**A 섹션 왼손 특징:**
```
C 코드에서:
1박: C2 (낮게)
2박: E4-G4-C5 (높게)
강한 대비 = 스트라이드의 핵심
```

**오른손 블루스 요소:**
```
C와 Eb(단3도)를 오가는 멜로디
블루 노트 사용
```

### 10도 점프

진보된 스트라이드는 **10도(옥타브+3도)** 점프:
```
C2 → E4 (10도)
C2에서 E4까지 = 큰 점프
Art Tatum 스타일
```

**10도 점프 연습:**
```
천천히 C2와 E4를 번갈아
왼손 엄지로 C2, 5지로 E4
손 크기가 충분해야 가능
```

## Fats Waller 스타일

### 유쾌한 스트라이드

Fats Waller의 특징:
- **경쾌함:** 무거운 래그타임보다 가볍고 빠름
- **유머:** 코믹한 요소 포함
- **기술:** Art Tatum에 필적하는 기교

**Waller 스타일 왼손:**
```
F 코드 스트라이드:
1: F2, 2: A4-C5-F5 (높은 코드)
3: C3, 4: A4-C5-F5
= 매우 넓은 점프
```

---

## 스트라이드 고급 기법

### 패싱 코드 스트라이드

코드와 코드 사이에 경과음적 코드:
```
C → F 스트라이드:
C 코드 → D7 (패싱) → G7 → C
왼손이 패싱 코드도 스트라이드로 처리
```

### 크로매틱 스트라이드

베이스 음이 반음씩 이동:
```
C2 → B1 → Bb1 → A1
각 박에 해당하는 코드를 오른손으로
= 화성적 긴장감
```

## 흔한 실수와 해결

### 점프 지연

**문제:** 점프가 늦어서 박자 이탈
**해결:**
```
연습 1: 매우 느린 템포 (♩= 40-50)
연습 2: 점프 목적지를 미리 시각화
연습 3: 점프만 따로 반복 (음악 없이)
```

### 코드 불정확

**문제:** 점프 후 코드 음이 틀림
**해결:**
```
눈 감고 코드 찾기 연습
각 코드 모양을 시각화
손가락 근육 기억 훈련
```

### 리듬 불균형

**문제:** 1박은 짧고 2박은 길거나 반대
**해결:**
```
메트로놈을 박자 사이(+박)에 맞추기
1+박, 2+박이 정확하게
```

## 음악연습실 스트라이드 연습

### 60분 루틴

**1. 점프 훈련 (15분)**
   - C2 → E4 점프 반복
   - F2 → A4 점프
   - G2 → B4 점프
   - 느리게, 정확하게

**2. 기본 스트라이드 (15분)**
   - C-F-G-C 진행 스트라이드
   - ♩= 60에서 시작
   - 점점 템포 올리기

**3. 오른손 추가 (15분)**
   - 간단한 C 메이저 스케일 오른손
   - 왼손 스트라이드 + 오른손 멜로디
   - 독립성 유지

**4. 전체 곡 (15분)**
   - 간단한 재즈 스탠다드 멜로디
   - 왼손 스트라이드 반주
   - "Ain't Misbehavin'" 멜로디 적용

## 마무리

스트라이드 피아노는 **한 사람이 밴드 전체**가 되는 기법입니다. James P. Johnson, Fats Waller는 피아노 한 대로 온 파티를 채웠습니다.
