## 스마트폰 — 언제 어디서나 녹음 가능한 포터블 스튜디오

최신 스마트폰은 고성능 마이크와 오디오 처리 능력을 갖추어, 외부 마이크와 조합하면 전문 믹싱 의뢰가 가능한 수준의 보컬을 녹음할 수 있습니다.

스마트폰 보컬 녹음이 실용적인 선택지로 자리 잡은 것은 iPhone 4 출시(2010년)와 함께입니다. 내장 마이크 품질이 비약적으로 향상된 이 시기부터 뮤지션들은 데모 녹음을 스마트폰으로 해결하기 시작했고, Lightning 어댑터를 통한 외부 마이크 연결이 가능해지면서 iRig·Apogee 같은 모바일 오디오 인터페이스 시장이 형성됐습니다. iOS GarageBand의 무료 제공은 스마트폰을 완성형 녹음 스튜디오로 만드는 결정적인 계기가 됐고, 2020~2021년 팬데믹 기간에는 스튜디오 방문이 어려운 환경에서 스마트폰 + USB 마이크 조합으로 전문 믹싱 의뢰가 가능한 드라이 보컬을 납품하는 사례가 크게 늘었습니다. 현재는 Scarlett Solo·PreSonus AudioBox 같은 소형 오디오 인터페이스를 스마트폰에 연결하는 구성이 홈 레코딩의 표준 입문 세팅으로 자리 잡았습니다.

## 스마트폰 녹음 장비 구성

| 구성 | 장비 | 특징 |
|------|------|------|
| 기본 (내장 마이크) | 스마트폰 기본 마이크 | 급할 때만 사용, 품질 한계 |
| 입문 (USB 마이크) | USB-C/Lightning 마이크 | 어댑터 없이 직접 연결 |
| 권장 (오인터 + 마이크) | 오디오 인터페이스 + 콘덴서 마이크 | 스튜디오 의뢰 가능 품질 |

## iPhone 보컬 녹음 설정

### 기본 준비

1. Lightning/USB-C → USB-A 어댑터 준비
2. 오디오 인터페이스 연결 (또는 Lightning 마이크 직접 연결)
3. GarageBand 앱 실행

### GarageBand iOS 녹음

1. 오디오 레코더 트랙 선택
2. 마이크 아이콘 탭 → 외부 마이크 선택 확인
3. 입력 레벨 조정 (-12dBFS ~ -6dBFS 목표)
4. 레코딩 버튼(빨간 원) 탭 → 노래
5. 정지 버튼 탭으로 종료

### 다이렉트 모니터링

- 오디오 인터페이스 Direct Monitoring ON
- GarageBand 소프트웨어 모니터링 OFF
- 헤드폰: 오디오 인터페이스에 연결

## Galaxy 보컬 녹음 설정

### Samsung Galaxy (Android)

1. USB-C → USB-A 어댑터로 오디오 인터페이스 연결
2. 기본 음성 녹음 앱: 음질 낮음 → DAW 앱 사용 권장

### 권장 Android 앱

- BandLab: 무료 DAW, 오디오 인터페이스 지원
- n-Track Studio: 멀티트랙 녹음 가능
- FL Studio Mobile: 비트메이킹 + 보컬 녹음

### 레벨 확인

- 입력 레벨 미터 확인
- 클리핑 방지: 피크 -12dBFS ~ -6dBFS

---

## 스마트폰 녹음 환경 세팅

### 방음 처리

1. 조용한 공간 선택 (에어컨·선풍기 OFF)
2. 구석에 마이크 세팅 — 반사음 최소화
3. 이불·커튼으로 벽면 흡음 처리
4. 스마트폰 알림음·진동 OFF 필수

### 마이크 세팅

- 거리: 마이크에서 15~20cm
- 팝 필터 설치 (없으면 양말로 대체 가능)
- 마이크 뒤: 이불·폼 배치로 반사 억제

### 녹음 시 주의

- 핸드폰 발열 방지 → 케이스 제거 권장
- 저장 공간 여유 확인 (WAV 파일은 용량 큼)

---

## 파일 내보내기 및 전달

### iOS GarageBand 내보내기

공유 버튼 → 노래 → 오디오 → Lossless

- 파일 앱 또는 iCloud Drive 저장

### Android 내보내기

- **BandLab**: 프로젝트 → Export → WAV
n-Track: 믹스다운 → WAV 24bit

### 믹싱 의뢰 전달

1. Google Drive 또는 WeTransfer 업로드
2. 카카오톡으로 링크 전송
3. 파일명: [이름]_[곡명]_vocal.wav
4. MR 파일 함께 전달 (WAV 또는 MP3 320kbps)
5. BPM·키 정보 메모 첨부

## 마치며

스마트폰도 외부 마이크와 방음 환경만 갖추면 스튜디오 믹싱 의뢰가 가능한 드라이 보컬을 얻을 수 있습니다.

스마트폰 녹음에서 품질을 결정하는 가장 중요한 요소는 방음 환경입니다. 동일한 마이크와 인터페이스를 사용해도 반사음이 많은 공간에서 녹음한 보컬은 믹싱 단계에서 교정이 어렵지만, 이불·커튼으로 간이 흡음 처리를 한 공간에서 녹음한 드라이 보컬은 스튜디오 파일과 구분하기 어려운 품질이 나옵니다. GarageBand iOS에서 Lossless(AIFF) 형식으로 내보낸 파일은 44.1kHz/16bit 품질로 대부분의 믹싱 작업에 충분하며, 더 높은 품질이 필요한 경우 오디오 인터페이스에서 직접 24bit로 녹음하는 방식을 사용합니다. 파일 전달 시 BPM·키·원본 MR 정보를 함께 첨부하면 믹싱 엔지니어가 세션을 설정하는 시간을 절약할 수 있습니다.
