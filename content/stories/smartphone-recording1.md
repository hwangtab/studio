## 스마트폰 — 언제 어디서나 녹음 가능한 포터블 스튜디오

최신 스마트폰은 고성능 마이크와 오디오 처리 능력을 갖추어, 외부 마이크와 조합하면 전문 믹싱 의뢰가 가능한 수준의 보컬을 녹음할 수 있습니다.

---

## 스마트폰 녹음 장비 구성

| 구성 | 장비 | 특징 |
|------|------|------|
| 기본 (내장 마이크) | 스마트폰 기본 마이크 | 급할 때만 사용, 품질 한계 |
| 입문 (USB 마이크) | USB-C/Lightning 마이크 | 어댑터 없이 직접 연결 |
| 권장 (오인터 + 마이크) | 오디오 인터페이스 + 콘덴서 마이크 | 스튜디오 의뢰 가능 품질 |

## iPhone 보컬 녹음 설정

레이턴시 설정은 녹음과 믹싱 단계에서 각각 다르게 최적화하는 것이 좋습니다.

### 기본 준비

1. Lightning/USB-C → USB-A 어댑터 준비
2. 오디오 인터페이스 연결 (또는 Lightning 마이크 직접 연결)
3. GarageBand 앱 실행

### GarageBand iOS 녹음

1. 오디오 레코더 트랙 선택
2. 마이크 아이콘 탭 → 외부 마이크 선택 확인
3. 입력 레벨 조정 (-12dBFS ~ -6dBFS 목표)
4. 레코딩 버튼(빨간 원) 탭 → 노래
5. 정지 버튼 탭으로 종료

### 다이렉트 모니터링

- 오디오 인터페이스 Direct Monitoring ON
- GarageBand 소프트웨어 모니터링 OFF
- 헤드폰: 오디오 인터페이스에 연결

---

## Galaxy 보컬 녹음 설정

장비 자체보다 세팅 방법이 결과물 품질에 더 큰 영향을 줍니다.

### Samsung Galaxy (Android)

1. USB-C → USB-A 어댑터로 오디오 인터페이스 연결
2. 기본 음성 녹음 앱: 음질 낮음 → DAW 앱 사용 권장

### 권장 Android 앱

- BandLab: 무료 DAW, 오디오 인터페이스 지원
- n-Track Studio: 멀티트랙 녹음 가능
- FL Studio Mobile: 비트메이킹 + 보컬 녹음

### 레벨 확인

- 입력 레벨 미터 확인
- 클리핑 방지: 피크 -12dBFS ~ -6dBFS

## 스마트폰 녹음 환경 세팅

세션 시작 전 파일 정리와 프로젝트 백업 습관이 데이터 손실을 막아줍니다.

### 방음 처리

1. 조용한 공간 선택 (에어컨·선풍기 OFF)
2. 구석에 마이크 세팅 — 반사음 최소화
3. 이불·커튼으로 벽면 흡음 처리
4. 스마트폰 알림음·진동 OFF 필수

### 마이크 세팅

- 거리: 마이크에서 15~20cm
- 팝 필터 설치 (없으면 양말로 대체 가능)
- 마이크 뒤: 이불·폼 배치로 반사 억제

### 녹음 시 주의

- 핸드폰 발열 방지 → 케이스 제거 권장
- 저장 공간 여유 확인 (WAV 파일은 용량 큼)

---

## 파일 내보내기 및 전달

팝 필터 하나로 파열음 문제의 상당 부분을 해결할 수 있습니다.

### iOS GarageBand 내보내기

공유 버튼 → 노래 → 오디오 → Lossless
- 파일 앱 또는 iCloud Drive 저장

### Android 내보내기

- **BandLab**: 프로젝트 → Export → WAV
n-Track: 믹스다운 → WAV 24bit

### 믹싱 의뢰 전달

1. Google Drive 또는 WeTransfer 업로드
2. 카카오톡으로 링크 전송
3. 파일명: [이름]_[곡명]_vocal.wav
4. MR 파일 함께 전달 (WAV 또는 MP3 320kbps)
5. BPM·키 정보 메모 첨부
