# 바리톤 기타·다운 튜닝·헤비 사운드 — 음악연습실 완전 가이드

바리톤 기타(Baritone Guitar)는 **표준 기타보다 낮게 조율된 저음역 기타**입니다. 스케일 길이가 더 길고, 표준 기타보다 4도 또는 5도 낮게 튜닝됩니다. 헤비 메탈·프로그레시브 록·컨트리에서 독특한 존재감을 보여줍니다. 또한 Drop D, Drop C 등 다운 튜닝은 파워 코드의 세계를 열어줍니다.

---

## 바리톤 기타란?

### 바리톤 기타의 특징

**물리적 특성:**
```
스케일 길이: 27~30인치 (표준 기타 25.5인치)
튜닝: B-E-A-D-F#-B (5도 낮게)
    또는 A-D-G-C-E-A (4도 낮게)
현: 더 두꺼운 현 사용 (.013-.062+)
```

**바리톤 사운드의 특징:**
```
깊고 두꺼운 저음역
표준 기타와 함께 레이어: 베이스 역할
독주: 독특한 저음 기타 사운드
= 헤비·다크·심오한 사운드
```

---

## 다운 튜닝 (Down Tuning)

### Drop D 튜닝

**Drop D:** 표준 튜닝에서 6번 줄(E)만 D로 낮추기.

```
표준: E-A-D-G-B-E
Drop D: D-A-D-G-B-E
```

**Drop D의 장점:**
```
6번 줄 D: D 파워 코드 = 하나의 손가락으로!
D5 파워 코드: 6-5-4번 줄 같은 프렛
= 빠른 파워 코드 전환
헤비 록·메탈의 표준 튜닝
```

**Drop D 파워 코드:**
```
D5: 0-0-0 (개방)
E5: 2-2-2
F5: 3-3-3
G5: 5-5-5
A5: 7-7-7
```

### Drop C 튜닝

**Drop C:** 전체를 1음 낮추고 6번 줄만 한 음 더 낮추기.

```
표준에서 전체 1음 낮춤:
D-G-C-F-A-D
그 상태에서 6번 줄만 C로:
C-G-C-F-A-D
```

**Drop C의 특징:**
```
헤비 메탈·데스 메탈에서 많이 사용
더 어둡고 무거운 사운드
= Drop D보다 반음 낮음
```

### Open G 튜닝 (E 저음형)

**오픈 G (Eb):**
```
Eb-Ab-Eb-Ab-C-Eb (슬라이드에 사용)
= 오픈 코드 슬라이드 기타에
```

## 헤비 리프 기법

### 파워 코드 리프

**파워 코드(Power Chord = 5화음):**
```
근음 + 5도만 (3도 없음)
= 장조·단조 중립 → 앰프 왜곡에 강함
G5: 3-5-5 (6-5-4번 줄)
```

**왜 파워 코드가 왜곡에 강한가:**
```
장3도 + 오버드라이브 = 불협화음
5도 + 오버드라이브 = 두꺼운 파워
= 헤비 기타의 기본 단위
```

### 팜 뮤팅 (Palm Muting)

**팜 뮤팅:**
```
오른손 손바닥 끝부분을 브릿지 근처에 대기
현이 부드럽게 뮤팅됨
= "퉁퉁" 타악기 같은 소리
```

**팜 뮤팅 + 파워 코드:**
```
리프의 기본: 팜 뮤팅 + 개방 파워 코드 교체
= 헤비 메탈 리프의 핵심
```

## 헤비 기타 앰프 세팅

### 하이 게인 사운드

**메탈 앰프 세팅:**
```
게인(Gain): 높게 (하이 게인)
베이스(Bass): 중간~높음
미들(Mid): 다소 낮게 (V자형 EQ)
트레블(Treble): 높게
= "Scooped Mids" 메탈 EQ
```

**헤비 세팅의 문제:**
```
Mid 너무 낮으면 → 밴드 믹스에서 안 들림
= 연습 때와 밴드 때 다른 EQ
```

### 튜브 앰프 vs 솔리드 스테이트

**튜브 앰프:**
```
진공관 사용 → 자연스러운 과포화 (saturation)
= 따뜻하고 다이내믹한 왜곡
헤비 록의 클래식
```

**솔리드 스테이트:**
```
반도체 → 일관적이고 선명한 왜곡
= 메탈에 깔끔한 고주파 왜곡
```

### 바리톤 기타

**바리톤 기타 사용 아티스트:**

```
Mattias IA Eklundh: 프로그레시브

= 다양한 장르에서 사용
```

### Drop D 대표 리프

**Soundgarden "Black Hole Sun":**
```
Drop D 오픈 코드 아르페지오
= 그런지의 Drop D 교과서
```

**Tool "Schism":**
```
Drop D + 폴리리듬
= 프로그 메탈 Drop D
```

## 음악연습실 바리톤·다운 튜닝 연습

### 60분 루틴

**1. Drop D 튜닝 설정 (5분)**
   - 6번 줄을 D로 낮추기
   - 전체 코드 재확인
   - Drop D 특성 느끼기

**2. 파워 코드 기초 (15분)**
   - D5·E5·F5·G5·A5 파워 코드
   - 빠른 전환 연습
   - 메트로놈으로 타이밍

**3. 팜 뮤팅 리프 (20분)**
   - 팜 뮤팅 + 파워 코드 패턴
   - 뮤팅 강도 조절 연습
   - 간단한 메탈 리프 패턴

**4. 헤비 앰프 세팅 (20분)**
   - 하이 게인 세팅으로
   - 파워 코드 리프 연주
   - 팜 뮤팅 + 오픈 코드 대비

## 마무리

바리톤·다운 튜닝 기타는 **저음역이 만드는 압도감**입니다. Tony Iommi(Black Sabbath)가 Drop 튜닝으로 헤비 메탈을 창조했듯, 낮게 조율된 기타는 음악에 중력을 줍니다. 파워 코드의 단순함 속에 무한한 표현이 있습니다.

은평구 24시간 음악연습실에서 Drop D 파워 코드부터 시작하세요. 팜 뮤팅과 함께 첫 리프가 나오는 순간, 헤비 기타의 세계가 열립니다.
