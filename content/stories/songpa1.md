## 강남권에서 전문 녹음실 찾기

잠실·강남·천호·강동 주민들이 전문 보컬 녹음과 음반 제작을 위해 스튜디오 놀을 방문합니다. 2호선 합정역 또는 5호선을 통해 강남권에서도 연신내역까지 편리하게 접근할 수 있습니다.

---

## 각 지역에서 스튜디오 놀까지

| 출발지 | 교통편 | 소요 시간 |
|--------|--------|---------|
| 잠실역 | 2호선 → 합정역 → 6호선 연신내역 | 약 40~45분 |
| 강남역 | 2호선 → 합정역 → 6호선 | 약 35~40분 |
| 선릉역 | 2호선 → 합정역 → 6호선 | 약 40~45분 |
| 삼성역 | 2호선 → 합정역 → 6호선 | 약 40~45분 |
| 천호역 | 5호선 → 공덕역 → 6호선 연신내역 | 약 45~50분 |
| 강동역 | 5호선 → 공덕역 → 6호선 | 약 50~55분 |
| 석촌역 | 8호선 → 잠실 → 2호선 합정 → 6호선 | 약 50~55분 |

**스튜디오 주소**: 서울특별시 은평구 연신내역 인근 (연신내역 3번 출구 도보 5분)

## 스튜디오 놀 서비스 요약

| 서비스 | 내용 |
|--------|------|
| 보컬 녹음 | Neumann U87 AI, 흡음 부스, 1:1 엔지니어 세션 |
| 믹싱 | 보컬 + MR 스템 통합, 2라운드 수정 포함 |
| 마스터링 | 스트리밍 기준(-14 LUFS) 음압 최적화 |
| 패키지 | 녹음+믹싱+마스터링 합산 견적 |

정확한 견적은 카카오톡으로 목적·곡 수·일정을 알려주시면 안내드립니다.

## 강남권 고객 주요 이용 목적

강남·송파·강동 지역에서 스튜디오 놀을 찾으시는 분들이 주로 이용하시는 목적:

- **인디 음원 발매**: 자작곡 디지털 싱글·EP 제작
