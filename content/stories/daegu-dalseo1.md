## 대구 달서구·서구·남구에서 스튜디오 놀 이용하기

대구 달서구(성당못·두류·월배·상인)·서구(비산·내당·평리)·남구(봉덕·이천·대명) 지역에서 스튜디오 놀의 전문 보컬 녹음 및 믹싱 서비스를 이용하는 방법을 안내합니다.

---

## 온라인 의뢰 방법 (추천)

```
[온라인 믹싱·마스터링 의뢰 순서]

1단계: 보컬 녹음
→ 대구 내 홈 레코딩 또는 대구 녹음실에서 드라이 보컬 녹음
→ WAV 파일 (48kHz/24bit 권장)
→ 노이즈·이코·공간감 없는 드라이 상태로 납품

2단계: 파일 전송
→ 카카오톡 오픈채팅으로 파일 전달
→ MR 원본 파일 + 드라이 보컬 WAV 함께 전송
→ 원하는 사운드 레퍼런스 URL 공유

3단계: 믹싱·마스터링 납품
→ 전문 엔지니어 1:1 보컬 믹싱
→ 2라운드 수정 포함
→ WAV + MP3 완성 파일 납품
```

## KTX 방문 방법

```
[대구 달서구·서구·남구 → 연신내 스튜디오 놀]

① 동대구역 또는 대구역으로 이동
   - 달서구 두류: 대구 2호선 두류역 → 반월당역 → 1호선 동대구역 (약 30분)
   - 서구 비산: 대구 2호선 비산역 → 반월당역 → 1호선 동대구역 (약 25분)
   - 남구 대명: 대구 1호선 현충로역 → 동대구역 (약 20분)

② 동대구역에서 KTX 탑승 (서울역·수서역행)
③ 서울역 도착 → 6호선 환승
④ 연신내역 하차 (3번 출구 도보 5분)

총 소요시간: 약 2.5~3시간
```
