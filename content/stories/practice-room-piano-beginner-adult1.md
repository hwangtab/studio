## 몇 살이든 피아노를 시작하기에 늦은 때는 없습니다

코드 기반 접근으로 빠르게. 방음 개인실에서 성인 피아노 입문을 탐색하세요.

성인 피아노 입문 훈련의 핵심:
- **성인용 교재**: 어린이 교재 대신 성인 맞춤 교재와 코드 접근
- **좋아하는 곡**: 처음부터 자신이 좋아하는 곡 목표로 설정
- **코드 우선**: 악보보다 기본 코드 4-5개로 즉시 연주 경험
- **짧게 집중**: 30분 집중 연습이 2시간 힘든 연습보다 효과적

---

## 성인 피아노 학습 단계

| 단계 | 내용 | 기간 |
|------|------|------|
| 1단계 | 건반·음 이름·C장조 | 1주 |
| 2단계 | 기본 코드 4개 | 2-3주 |
| 3단계 | 양손 간단한 곡 1곡 | 4-6주 |
| 4단계 | 코드 진행 응용 | 2-3개월 |

| 단계 | 내용 | 목표 |
|------|------|------|
| 기초 | 음 이름·기본 자세 | 건반 익숙화 |
| 입문 | 기본 코드·간단한 곡 | 연주 경험 |
| 중급 | 코드 진행·팝 곡 | 좋아하는 곡 연주 |
| 고급 | 악보 읽기·클래식 | 다양한 레퍼토리 |
