# 기타 펑크 리듬·치킨 피킹·클린 그루브 — 음악연습실 완전 가이드

펑크 기타는 기타의 **리듬 악기로서의 완성형**입니다. 단순히 코드를 긁는 것이 아니라, 16분음표 분할과 뮤트, 싱코페이션을 통해 베이스·드럼과 함께 완벽한 리듬 앙상블을 만들어냅니다. Nile Rodgers, Prince, John Frusciante의 펑크 리듬 기타를 분석하며 그루브를 체계적으로 익혀봅니다.

---

## 펑크 기타의 핵심 요소

### 16분음표 그리드

펑크 리듬 기타의 모든 것은 **16분음표 그리드** 위에 있습니다.

```
4/4박자 16분음표:
1 e and a 2 e and a 3 e and a 4 e and a

```

**다운-업 스트로크 기본:**
```
1 e and a 2 e and a
↓ ↑ ↓ ↑  ↓ ↑ ↓ ↑
```

중요한 것은 **뮤트 스트로크**입니다. 소리를 내지 않는 스트로크도 항상 다운-업 규칙을 지켜야 그루브가 생깁니다.

### 뮤트 스트럼 (Mute Strum)

펑크 기타의 가장 중요한 기법. 오른손 손목으로 스트럼하면서 왼손으로 코드를 살짝 눌러 뮤트합니다.

```

X = 뮤트 스트럼, / = 일반 스트럼
1 e and a 2 e and a 3 e and a 4 e and a
/ X  /  X  / X  /  X  / X  /  X  / X  / X

```

---

## 치킨 피킹 (Chicken Pickin)

### 기법 설명

치킨 피킹은 원래 컨트리 기타에서 온 기법으로, 펑크에서도 자주 사용됩니다.

**기본 동작:**
- 픽으로 다운스트로크 + 미들/링 핑거로 업스트로크
- 또는 손가락으로 줄을 튕겨서 "pop" 사운드 생성

**펑크 치킨 피킹 패턴:**
```

픽: D - D - D - D -
손가락: - U - U - U - U
결과: D U D U D U D U (16분음표)

```

### 치킨 피킹 연습

**단계별 연습:**
1. 픽 다운스트로크만 (4분음표)
2. 미들 핑거 업 추가 (8분음표)
3. 속도 높여서 16분음표
4. 뮤트 스트럼 교대로 섞기

## 핵심 펑크 기타 패턴

### Nile Rodgers 스타일

Chic의 Nile Rodgers는 **펑크 리듬 기타의 교과서**입니다.

**"Le Freak" 스타일 패턴:**
```

Am7:
1 e and a 2 e and a
/ X  / X  X  / X /
(/ = 스트럼, X = 뮤트)

```

**핵심 코드:** Am7, Dm7, Em7 등 마이너 7th 코드 활용이 많음.

**Nile Rodgers 기타 세팅:**
- 클린 톤 (컴프레서)
- 픽 포지션: 브리지 쪽
- 스탠더드 튜닝

### Prince 스타일

Prince의 펑크 기타는 더 **공격적이고 싱코페이티드**합니다.

**Prince 스타일 패턴 (E9 코드):**
```
1 e and a 2 e and a
/ - / X  - / X -
```

**클로즈드 포지션 코드 활용:**
- E9: 0-7-6-7-5-X (로우 E 뮤트)
- A9: X-0-2-0-2-0 (개방현 활용)

### John Frusciante (RHCP) 스타일

레드 핫 칠리 페퍼스의 펑크-록 리듬 기타.

**"Give It Away" 스타일:**
```

Am 베이스:
/ / X / / X / /
(더 공격적인 다운스트로크 비중)

```

## 주요 펑크 기타 코드

### 7th 코드와 9th 코드

펑크에서 가장 많이 쓰이는 코드들:

**마이너 7th 코드 (바레 포지션):**
```

Am7: X-0-2-0-1-0
Dm7: X-X-0-2-1-1
Em7: 0-2-2-0-3-0

```

**도미넌트 9th 코드 (클로즈드 포지션):**
```

E9: 0-7-6-7-5-X
A9: X-0-2-0-2-0
D9: X-X-0-2-1-2

```

**펑크 코드 진행 예:**
```

Am7 - Dm7 - G9 - Cmaj7
(마이너 2-5-1 + 1 진행)

```

## 펑크 기타 그루브 연습법

### 메트로놈 활용

펑크 기타 연습의 핵심은 **완벽한 타이밍**입니다.

**연습 순서:**
1. BPM 60 — 16분음표를 정확하게
2. BPM 80 — 뮤트 스트럼 추가
3. BPM 100 — 싱코페이션 패턴
4. BPM 120 — 실제 곡 템포

### 클릭 트랙 없이 연습

그루브를 내면화하려면 클릭 없이도 연습:

1. **드럼 트랙과 함께**: 드럼 루프 틀고 맞추기
2. **베이스와 함께**: 베이스 루프와 맞추기
3. **기록 후 청취**: 녹음하여 그루브 확인

음악연습실에서 DAW나 루프 머신을 활용하면 솔로 연습 효율이 높아집니다.

## 음악연습실 펑크 기타 연습 루틴

### 30분 집중 루틴

**1. 워밍업 (5분)**
- 16분음표 다운-업 스트로크 BPM 80
- 뮤트 스트럼 감각 익히기

**2. 패턴 연습 (15분)**
- Nile Rodgers 스타일 Am7 패턴 (5분)
- Prince 스타일 E9 패턴 (5분)
- 혼합 패턴 즉흥 (5분)

**3. 곡 적용 (10분)**
- "Le Freak" (Chic) 코러스 리듬
- "Give It Away" (RHCP) 리프
- 또는 개인 좋아하는 펑크 곡

## 마무리

펑크 리듬 기타는 **리듬 감각과 타이밍이 전부**입니다. 화려한 솔로보다 단 두 코드로 완벽한 그루브를 만드는 것이 진정한 펑크 기타리스트입니다.

은평구 24시간 음악연습실에서 메트로놈과 함께 뮤트 스트럼부터 시작하세요. 처음엔 느리게, 그루브가 손에 익으면 템포를 올리는 것이 핵심입니다. Nile Rodgers처럼—단순하게, 그러나 완벽하게.

---

기타 솔로 연주에서 벤딩의 정확도는 음악적 표현의 핵심 요소입니다. 목표 음정까지 정확히 올려야 하므로 귀로 확인하며 연습하는 것이 중요합니다. 비브라토는 처음에는 너무 빠르거나 얕게 만들기 쉬운데, 일정한 폭과 속도를 유지하는 훈련이 필요합니다. 해머온과 풀오프를 활용한 레가토 주법은 피킹 없이도 유려한 선율을 만들어주며, 프레이즈에 다양성을 더합니다. 슬라이드 기법을 자연스럽게 결합하면 블루스적 표현이 한층 풍부해집니다.
