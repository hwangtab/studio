## 고창에서 KTX로 서울까지

고창은 전북 서남부 도시로, 정읍역 KTX를 통해 서울과 약 2시간대로 연결됩니다. 유네스코 세계유산 고인돌과 복분자로 유명한 고창에서 당일 서울 스튜디오 방문이 가능합니다.

---

## 고창 → 연신내 이동 경로

### KTX 정읍역 경유 (권장)

```
① 고창 → 정읍역 (버스 약 20~30분)
② 정읍역 KTX 탑승 (서울역 방면, 약 1시간 40분~2시간)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 2시간 30분~3시간 10분
```

---

## 당일 왕복 일정 예시 (고창 기준)

```
오전 7시 30분 고창 출발 → 정읍역 이동
오전 8시 10분 정읍역 KTX 출발
→ 오전 10시 서울역 도착
→ 오전 10시 40분 연신내역 도착
→ 오전 11시 세션 시작 (2시간)
→ 오후 1시 세션 완료
→ 오후 2시 30분 서울역 출발
→ 오후 4시 20분 정읍역 도착
→ 오후 5시 고창 도착
```
