## 인천·부천에서 서울 전문 녹음실 이용하기

인천·부천 주민들이 전문 보컬 녹음과 음반 제작을 위해 서울의 스튜디오 놀을 방문합니다. 경인선·1호선·2호선을 통해 연신내역까지 접근할 수 있습니다.

## 각 지역에서 스튜디오 놀까지

| 출발지 | 교통편 | 소요 시간 |
|--------|--------|---------|
| 부천역 | 1호선 → 신도림 → 2호선 합정 → 6호선 연신내 | 약 45~55분 |
| 부평역 | 1호선 → 신도림 → 2호선 합정 → 6호선 연신내 | 약 50~60분 |
| 소사역 | 1호선 → 신도림 → 2호선 합정 → 6호선 | 약 45~50분 |
| 인천역 (구) | 1호선 → 신도림 → 2호선 합정 → 6호선 | 약 60~70분 |
| 송도국제도시 | 인천1호선 → 부평 → 1호선 → 신도림 → 합정 → 6호선 | 약 70~80분 |
| 계양역 | 1호선 부평 → 신도림 → 합정 → 6호선 | 약 60분 |

**스튜디오 주소**: 서울특별시 은평구 (연신내역 3번 출구 도보 5분)

4. **주말 예약**: 평일 직장인의 경우 주말 예약으로 여유 있게 이용
