## 군포 산본에서 연신내 스튜디오 놀까지

경기도 군포시 산본동·금정동·당동 지역에서 4호선을 이용하면 서울 연신내 스튜디오 놀까지 약 55~70분에 도달할 수 있습니다.

---

## 군포 산본 → 연신내 이동 경로

### 4호선 + 2호선 + 6호선 (추천)

모니터링 레벨과 녹음 레벨은 독립적으로 조절해야 판단 오류를 방지할 수 있습니다.

### 산본역 출발 (4호선)

1. 산본역(4호선) 탑승
2. 4호선 서울 방면 이동
   산본 → 금정 → 범계 → 평촌
  - 인덕원 → 남태령 → 사당역 하차
3. 사당역에서 2호선 환승
   (신촌 방면)
4. 낙성대 → 서울대입구 → 봉천 → 신림
  - 신대방 → 구로디지털 → 대림 → 신도림
  - 영등포구청 → 당산 → 합정역 하차
5. 합정역에서 6호선 환승
   (응암 방면)
6. 망원 → 마포구청 → 월드컵경기장
  - 디지털미디어시티 → 증산 → 새절
  - 구산 → 연신내역 하차

**단순 경로 요약**
산본역(4호선) → 사당역(2호선 환승)
- 합정역(6호선 환승) → 연신내역
- **총 소요시간**: 약 60~70분

### 금정역 경로 (1호선 이용 시)

### 금정역 출발 (1호선·4호선 환승)

1. 금정역에서 1호선 탑승
2. 1호선 서울 방면: 안양 → 석수 → 금천구청
  - 가산디지털 → 구로 → 신도림 → 영등포역
3. 영등포역에서 경의중앙선 환승 → DMC역
4. DMC역에서 6호선 환승 → 연신내역
- **소요시간**: 약 45~55분

## 군포 지역별 소요 시간

| 출발역 | 경로 | 소요 시간 |
|--------|------|---------|
| 금정역 (1호선/4호선) | 1호선 → 영등포 → 경의중앙선 → DMC → 6호선 | 약 45~55분 |
| 산본역 (4호선) | 4호선 → 사당 → 2호선 → 합정 → 6호선 | 약 60~70분 |
| 수리산역 (4호선) | 4호선 → 사당 → 2호선 → 합정 → 6호선 | 약 65~75분 |
