# 베이스 블루스·12마디 블루스 베이스라인 — 음악연습실 완전 가이드

블루스 베이스는 **모든 대중음악 베이스의 뿌리**입니다. 12마디 블루스 진행과 셔플 그루브—이 두 가지를 완전히 이해하면, 록, 팝, 재즈, 소울 어느 장르에서도 흔들리지 않는 베이스 실력의 기반이 됩니다.

---

## 12마디 블루스 진행

### 기본 12마디 블루스

블루스의 기본 구조는 **I-IV-V 코드가 12마디에 걸쳐 반복**됩니다.

**A 블루스 12마디 구조:**
```

마디 1-4: A7 (I 코드)
마디 5-6: D7 (IV 코드)
마디 7-8: A7 (I 코드)
마디 9: E7 (V 코드)
마디 10: D7 (IV 코드)
마디 11: A7 (I 코드)
마디 12: E7 (V 코드 — 턴어라운드)

```

### 퀵 체인지 블루스

마디 2에서 바로 IV 코드로 가는 변형:

```

마디 1: A7
마디 2: D7 (퀵 체인지)
마디 3-4: A7
...

```

## 블루스 베이스라인의 기본 패턴

### 루트-5도 블루스 패턴

가장 기본적인 블루스 베이스라인.

**A7 위 루트-5도 패턴:**
```

A - E - A - E (4/4박자, 각 2분음표)
또는
A - A - E - E (루트 반복 후 5도)

```

### 셔플 블루스 베이스라인

블루스의 특유한 **셔플 리듬**에 맞춘 베이스라인.

**셔플 그루브란:**
```

일반: ♩ ♩ (2개의 8분음표 동등)
셔플: ♪.♪ (점8분음표 + 16분음표, 약 2:1)

```

**A7 셔플 베이스라인:**
```

A - - E - - (루트 길게 + 5도 짧게)
또는
A - E - A - E (모두 셔플 느낌으로)

```

### 블루스 워킹 패턴

더 멜로딕한 블루스 베이스라인:

**A7 워킹:**
```

A - C - E - G (A7 코드 톤 기반)

```

**D7 워킹:**
```

D - F# - A - C

```

**E7 워킹:**
```

E - G# - B - D

```

## 블루스 필(Fill)

### 블루스 베이스 필의 역할

블루스 필은 코드 전환 직전에 배치되어 **긴장을 만들고 해결**합니다.

**기본 턴어라운드 필 (마디 11-12):**
```

A: A - F# - E - C# (하행 크로매틱)
E7으로 연결: E - G# - B - D
다시 A로: A (첫 마디 시작)

```

### 셔플 필 패턴

```

마디 11: A - C# - E - G (A7 상행)
마디 12: G - E - C# - B (하행 크로매틱 → E7 준비)

```

## 블루스 스타일별 베이스 접근

### 시카고 블루스

Muddy Waters, Howlin' Wolf 스타일.

**특징:**
- 강한 비트, 명확한 셔플
- 루트 중심의 간결한 베이스
- 드럼과 타이트하게 락인

**기본 시카고 블루스 패턴 (A):**
```

A - A - E - A (4분음표 셔플)

```

### 텍사스 블루스

SRV(Stevie Ray Vaughan) 밴드 스타일.

**특징:**
- 더 강하고 헤비
- 베이스 라인에 더 많은 움직임
- 때로는 락적인 접근

### 재즈 블루스

Miles Davis, Sonny Rollins 스타일.

**특징:**
- 8분음표 스윙 그루브
- 더 복잡한 코드 대체 (A13, D9 등)
- 워킹 베이스 지향

**재즈 블루스 코드 대체:**
```

기본: A7 - D7 - A7 - E7
재즈: Amaj7 - D13 - Bm7 - E7alt

```

## 블루스 베이스 톤 세팅

### 클래식 블루스 톤

**장비:**
- 핑거스타일 (픽보다 따뜻한 톤)
- 앰프 미드 약간 부스트

**EQ 세팅:**
```

Bass: +2dB
Mid: +3dB (400-600Hz)
Treble: 0dB

```

**이펙트:**
- 리버브 없이 (또는 극소량)
- 컴프레서 가볍게 (다이나믹 살리기)

## 음악연습실 블루스 베이스 연습 루틴

### 기초 단계 (60분)

**1. 12마디 블루스 구조 외우기 (15분)**
- A 블루스 12마디 암기
- 코드 이름과 마디 번호 연결

**2. 루트-5도 패턴 (20분)**
- A7 위 루트-5도, BPM 80 셔플
- D7, E7으로 이동하며 패턴 유지

**3. 워킹 블루스 (15분)**
- A7 위 A-C-E-G 워킹 패턴
- 전체 12마디에 적용

**4. 곡 적용 (10분)**
- "Sweet Home Chicago" 또는 "Red House" 베이스라인

## 블루스 세션에서 베이스에게 제일 자주 하게 되는 말

블루스 편성으로 합을 맞추는 자리에서 베이스 쪽에 건네게 되는 주문은 의외로 몇 가지로 좁혀집니다. 어려운 걸 요구하는 경우는 거의 없고, 대부분은 이미 치고 있는 것을 덜어내거나 자리를 옮겨달라는 이야기입니다.

**"악보 보지 말고 지금 몇 마디인지만 세어주세요"**

블루스에서 사고가 나는 자리는 어려운 필이 아니라 9마디입니다. V로 올라가는 순간을 놓치면 그 한 바퀴가 통째로 어긋나고, 기타 솔로가 몇 바퀴를 돌지 미리 정하지 않은 상태라면 더 그렇습니다. 앞에서 정리한 12마디 구조를 A 키 하나에서만 외우지 마시고, 마디 번호와 코드가 몸에 붙게 만들어두세요. 그러면 현장에서 키가 바뀌어도 손만 옮기면 됩니다. 퀵 체인지가 있는지 없는지도 첫 바퀴에서 귀로 잡아내야 합니다.

**"셔플인데 8분음이 너무 반듯해요"**

머리로는 2:1을 알아도 손은 자꾸 균등한 8분음으로 돌아갑니다. 특히 템포가 붙으면 셔플이 스트레이트 쪽으로 펴지죠. 이건 정확도의 문제가 아니라 어느 쪽으로 기울일지를 정하는 문제입니다. 앞에서 언급한 시카고 계열처럼 뒤가 짧게 튀는 셔플과, 재즈 블루스의 스윙에 가까운 셔플은 같은 표기라도 손에 붙는 느낌이 다릅니다. 두 종류의 음반을 각각 붙여놓고 따라 쳐보면서 자기 손이 어디로 기우는지를 먼저 아는 편이 좋습니다.

**"루트만 쳐도 되는 구간인데 워킹으로 채우고 계세요"**

블루스에서 가장 흔한 과잉입니다. 보컬이 들어오는 구간까지 워킹으로 돌면 노래가 앉을 자리가 없어집니다. 전통적인 부기우기 패턴과 워킹 라인을 둘 다 익혀야 하는 이유는 기술이 늘어서가 아니라, 지금 곡이 무엇을 필요로 하는지에 따라 갈아탈 수 있어야 하기 때문입니다. 보컬 절에서는 루트와 5도로 버티고 솔로가 들어오면 워킹으로 풀어주는 식으로 구간을 나눠서 연습해보세요.

---

재즈 베이스를 처음 공부할 때는 워킹 베이스라인 개념을 이해하는 것이 핵심입니다. 코드 톤을 연결하는 크로매틱 패싱 노트를 적절히 활용하면 매끄럽고 자연스러운 워킹 라인이 완성됩니다. 2박과 4박에 스윙 감을 실어주는 것이 재즈 그루브의 출발점입니다. 피아노나 기타 반주에 맞춰 실제로 연주해보는 경험이 쌓일수록 코드 진행을 귀로 읽는 능력도 함께 발전합니다. 연습실에서의 시간을 최대한 활용하려면 집에서 이미 기초 연습을 충분히 마친 상태에서 방문하는 것이 이상적입니다. 집에서는 조용히 운지나 리듬 패턴을 머릿속으로 시뮬레이션하고, 연습실에서는 실제 악기와 앰프로 이를 확인하고 정밀하게 다듬는 방식으로 역할을 나누면 효율이 높아집니다. 연습 노트를 작성해 각 세션의 목표, 성과, 다음에 집중할 부분을 기록해두면 지속적인 성장을 체계적으로 관리할 수 있습니다.
