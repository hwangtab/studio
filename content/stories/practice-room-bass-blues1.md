# 베이스 블루스·12마디 블루스 베이스라인 — 음악연습실 완전 가이드

블루스 베이스는 **모든 대중음악 베이스의 뿌리**입니다. 12마디 블루스 진행과 셔플 그루브—이 두 가지를 완전히 이해하면, 록, 팝, 재즈, 소울 어느 장르에서도 흔들리지 않는 베이스 실력의 기반이 됩니다.

---

## 12마디 블루스 진행

### 기본 12마디 블루스

블루스의 기본 구조는 **I-IV-V 코드가 12마디에 걸쳐 반복**됩니다.

**A 블루스 12마디 구조:**
```
마디 1-4:  A7 (I 코드)
마디 5-6:  D7 (IV 코드)
마디 7-8:  A7 (I 코드)
마디 9:    E7 (V 코드)
마디 10:   D7 (IV 코드)
마디 11:   A7 (I 코드)
마디 12:   E7 (V 코드 — 턴어라운드)
```

### 퀵 체인지 블루스

마디 2에서 바로 IV 코드로 가는 변형:

```
마디 1: A7
마디 2: D7 (퀵 체인지)
마디 3-4: A7
...
```

## 블루스 베이스라인의 기본 패턴

### 루트-5도 블루스 패턴

가장 기본적인 블루스 베이스라인.

**A7 위 루트-5도 패턴:**
```
A - E - A - E (4/4박자, 각 2분음표)
또는
A - A - E - E (루트 반복 후 5도)
```

### 셔플 블루스 베이스라인

블루스의 특유한 **셔플 리듬**에 맞춘 베이스라인.

**셔플 그루브란:**
```
일반: ♩ ♩ (2개의 8분음표 동등)
셔플: ♪.♪ (점8분음표 + 16분음표, 약 2:1)
```

**A7 셔플 베이스라인:**
```
A - - E - - (루트 길게 + 5도 짧게)
또는
A - E - A - E (모두 셔플 느낌으로)
```

### 블루스 워킹 패턴

더 멜로딕한 블루스 베이스라인:

**A7 워킹:**
```
A - C - E - G (A7 코드 톤 기반)
```

**D7 워킹:**
```
D - F# - A - C
```

**E7 워킹:**
```
E - G# - B - D
```

## 블루스 필(Fill)

### 블루스 베이스 필의 역할

블루스 필은 코드 전환 직전에 배치되어 **긴장을 만들고 해결**합니다.

**기본 턴어라운드 필 (마디 11-12):**
```
A: A - F# - E - C# (하행 크로매틱)
E7으로 연결: E - G# - B - D
다시 A로: A (첫 마디 시작)
```

### 셔플 필 패턴

```
마디 11: A - C# - E - G (A7 상행)
마디 12: G - E - C# - B (하행 크로매틱 → E7 준비)
```

## 블루스 스타일별 베이스 접근

### 시카고 블루스

Muddy Waters, Howlin' Wolf 스타일.

**특징:**
- 강한 비트, 명확한 셔플
- 루트 중심의 간결한 베이스
- 드럼과 타이트하게 락인

**기본 시카고 블루스 패턴 (A):**
```
A - A - E - A (4분음표 셔플)
```

### 텍사스 블루스

SRV(Stevie Ray Vaughan) 밴드 스타일.

**특징:**
- 더 강하고 헤비
- 베이스 라인에 더 많은 움직임
- 때로는 락적인 접근

### 재즈 블루스

Miles Davis, Sonny Rollins 스타일.

**특징:**
- 8분음표 스윙 그루브
- 더 복잡한 코드 대체 (A13, D9 등)
- 워킹 베이스 지향

**재즈 블루스 코드 대체:**
```
기본: A7 - D7 - A7 - E7
재즈: Amaj7 - D13 - Bm7 - E7alt
```

## 블루스 베이스 톤 세팅

### 클래식 블루스 톤

**장비:**
- 핑거스타일 (픽보다 따뜻한 톤)
- 앰프 미드 약간 부스트

**EQ 세팅:**
```
Bass: +2dB
Mid: +3dB (400-600Hz)
Treble: 0dB
```

**이펙트:**
- 리버브 없이 (또는 극소량)
- 컴프레서 가볍게 (다이나믹 살리기)

## 음악연습실 블루스 베이스 연습 루틴

### 기초 단계 (60분)

**1. 12마디 블루스 구조 외우기 (15분)**
- A 블루스 12마디 암기
- 코드 이름과 마디 번호 연결

**2. 루트-5도 패턴 (20분)**
- A7 위 루트-5도, BPM 80 셔플
- D7, E7으로 이동하며 패턴 유지

**3. 워킹 블루스 (15분)**
- A7 위 A-C-E-G 워킹 패턴
- 전체 12마디에 적용

**4. 곡 적용 (10분)**
- "Sweet Home Chicago" 또는 "Red House" 베이스라인
