## 성남·분당·판교에서 서울 전문 녹음실 이용하기

## 각 지역에서 스튜디오 놀까지

| 출발지 | 교통편 | 소요 시간 |
|--------|--------|---------|
| 판교역 | 신분당선 → 강남역 → 2호선 합정 → 6호선 연신내 | 약 45~55분 |
| 정자역 | 신분당선 → 강남 → 2호선 합정 → 6호선 연신내 | 약 50~60분 |
| 수내역 | 분당선 → 왕십리 → 5호선 공덕 → 6호선 연신내 | 약 55~65분 |
| 미금역 | 분당선·신분당선 → 강남 → 2호선 합정 → 6호선 | 약 50~60분 |
| 야탑역 | 분당선 → 왕십리 → 5호선 공덕 → 6호선 | 약 60~70분 |
| 모란역 | 8호선 → 복정 → 분당선 왕십리 → 공덕 → 6호선 | 약 65~75분 |

**스튜디오 주소**: 서울특별시 은평구 (연신내역 3번 출구 도보 5분)
