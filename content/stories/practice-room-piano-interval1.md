    a: "음정과 코드 이해: ① 코드 구성 — 장3도+단3도=장화음, 단3도+장3도=단화음 ② 7th 코드 — 3도 음정을 세 번 쌓은 구조 ③ 인터벌 = 화음 구성 — 모든 화음은 인터벌의 조합 ④ 불협화 해결 — 7도·단9도가 해결되는 방향 이해 ⑤ 성부 진행 — 각 성부의 인터벌 움직임 이해. 코드를 인터벌로 이해하면 '왜 이 코드가 이런 소리인가'를 파악하게 됩니다. 예를 들어 장화음이 밝게 들리는 이유는 장3도+단3도의 조합이고, 단화음이 어둡게 들리는 이유는 반대 순서 때문입니다."

## 음정 이해가 피아노 음악의 모든 것을 열어줍니다

3도·6도 병행부터 불협화음 해결까지. 방음 개인실에서 피아노 음정 훈련을 탐색하세요.

피아노 음정 훈련의 핵심:
- **인터벌 청음**: 각 음정 간격을 귀로 즉시 인식하는 자동화
- **3도·6도 병행**: 오른손 멜로디에 3도·6도 아래 음 동시 연주
- **코드 구성 이해**: 화음을 인터벌의 조합으로 이해
- **불협화 해결**: 긴장된 음정이 해결되는 방향과 타이밍 파악
