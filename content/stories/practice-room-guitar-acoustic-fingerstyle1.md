# 기타 어쿠스틱 핑거스타일·DADGAD 튜닝 — 음악연습실 완전 가이드

어쿠스틱 기타 핑거스타일은 피크 없이 손가락만으로 베이스, 화성, 멜로디를 동시에 연주하는 기법입니다. 클래식 기타에서 파생되었지만 팝, 포크, 켈틱, 뉴에이지 등 다양한 장르에서 활용됩니다. 특히 DADGAD 같은 오픈 튜닝은 완전히 새로운 음향 세계를 열어줍니다.

---

## 어쿠스틱 핑거스타일 기초

### 오른손 손가락 기호

클래식 기타에서 유래한 약자:
- **p (pulgar)**: 엄지 — E, A, D 현 (저음)
- **i (indice)**: 검지 — G 현
- **m (medio)**: 중지 — B 현
- **a (anular)**: 약지 — e 현

### 기본 아르페지오 패턴

**Travis Picking 기본:**
```
박자: 1  +  2  +  3  +  4  +
현:   E  G  E  B  E  G  E  B
손가락: p i  p  m  p  i  p  m
```

**오른손 엄지 교대 저음:**
```
C 코드:
박자: 1  2  3  4
저음: E  A  E  A (교대)
```

## Travis Picking

### 기원

Merle Travis와 Chet Atkins가 개발한 컨트리·팝 핑거스타일.

**핵심 원리:**
- 엄지가 저음 현에서 교대 베이스 라인
- 검지-중지가 고음 현에서 멜로디/화성
- 두 손의 독립성이 핵심

### G 코드 Travis Picking

```
e|------3-----------3--|
B|------3-----------3--|
G|------0-----------0--|
D|------0-----------0--|
A|---2-----------2-----|
E|-3-----------3-------|
   p  i m p  p  i m p
```

## DADGAD 튜닝

### DADGAD란?

표준 EADGBE 대신 DAD GAD로 조율:
```
6현: D (E에서 D로)
5현: A (변화 없음)
4현: D (변화 없음)
3현: G (변화 없음)
2현: A (B에서 A로)
1현: D (E에서 D로)
```

### DADGAD의 음향적 특성

**오픈 코드 (개방현):**
```
전체 개방 = Dsus4 (D-A-D-G-A-D)
```

이 오픈 코드 자체가 아름다운 사운드를 가집니다.

**켈틱 음악의 드론 사운드:**
D와 A 개방현을 지속하며 다른 현에서 멜로디 연주 → 특유의 켈틱 드론 사운드

### DADGAD 기본 코드

**Dm (1프렛 바레):**
```
e|--0--|
B|--1--|
G|--2--|
D|--0--|
A|--0--|
E|--X--|
```

**G (5프렛):**
```
e|--5--|
B|--5--|
G|--5--|
D|--5--|
A|--5--|
E|--5--|
```

## 첼트남(Cheltenham) 스타일

### 개요

영국 켈틱 어쿠스틱 기타 스타일. DADGAD와 카포를 결합:

```
DADGAD + 카포 2 = EBEABE (E 중심)
DADGAD + 카포 5 = GCGCGC (G 중심)
```

**특징:**
- 개방현 드론을 유지하며 멜로디 연주
- 오버톤이 풍부한 사운드
- 전통 음악에 현대적 감각 추가

---

## 어쿠스틱 핑거스타일 연습 루틴

### 입문 단계 (60분)

**1. 오른손 패턴 훈련 (15분)**
- p-i-m-a 순서 개방현에서 연습
- BPM 60에서 균일하게

**2. Travis Picking 기초 (25분)**
- G, C, D 코드에서 Travis Picking
- 엄지 교대 저음 먼저

**3. DADGAD 탐구 (20분)**
- 재조율 후 개방현 드론 감상
- 1~5프렛 간단한 멜로디 탐색
