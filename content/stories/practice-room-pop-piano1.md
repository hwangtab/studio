  - q: 팝 피아노 반주를 위한 왼손 패턴은 무엇인가요?

      팝 피아노 왼손 패턴: ① 베이스 노트만 — 루트 + 5도 단순 반복 ② 블록 코드 — 전체 코드 동시에 ③ 알베르티 베이스 —
      루트·5도·3도·5도 교대 ④ 아르페지오 — 코드를 펼쳐서 ⑤ 오옥타브 점프 — 루트 낮은 음 + 코드 중간 음. 장르·템포에 따라
      패턴을 선택하면 됩니다. 처음에는 블록 코드부터 시작하는 것이 가장 쉽습니다.

      느낌. 이 4가지 진행이 K-POP의 약 70%를 차지합니다. 전조하면서 모든 조성에서 연주할 수 있게 훈련하세요.

## 팝 피아노는 4코드로 시작합니다

클래식이나 재즈와 달리, 팝 피아노는 기본 코드 몇 개만 익혀도 바로 좋아하는 곡을 연주할 수 있습니다. 방음 개인실에서 원곡 틀고 따라 치면서 빠르게 실력을 쌓으세요.

팝 피아노 연습의 핵심:
- **4코드 마스터**: C-Am-F-G가 팝의 기초
- **멜로디 + 코드**: 오른손 멜로디와 왼손 코드 동시에
- **패턴 다양화**: 블록코드 → 아르페지오 → 패턴 반주
- **좋아하는 곡으로**: 동기부여가 있는 곡부터

---

## 팝 피아노 왼손 패턴 비교

| 패턴 | 예시 (C코드) | 느낌 |
|------|------------|------|
| 블록 코드 | C-E-G 동시 | 단순·깔끔 |
| 베이스+코드 | C·C-E-G | 가장 기본 |
| 아르페지오 | C·E·G·E | 서정적 |
| 알베르티 | C·G·E·G | 클래식 팝 |
| 팝 스타일 | C··C-E-G | 리드미컬 |

---

## K-POP 코드 진행 연습

### I-V-vi-IV 연습 (C장조)

```

C → G → Am → F (반복)
왼손: 루트 베이스
오른손: 멜로디 or 아르페지오

```

### vi-IV-I-V 연습 (C장조)

```

Am → F → C → G (반복)
단조 느낌의 감성 팝

```

## 팝 피아노 연습 루틴 (45분)

| 구간 | 내용 | 시간 |
|-----|------|------|
| 워밍업 | 4코드 블록→아르페지오 | 5분 |
| 코드 진행 | 전조 연습 (3개 조성) | 10분 |
| 커버곡 | 목표 K-POP 1곡 집중 | 20분 |
| 즉흥 | 코드 위 자유 연주 | 10분 |

### 팝 피아노 난이도별 추천 연습곡

| 난이도 | 곡명 | 핵심 기술 |
|-------|------|---------|
| 입문 | 아이유 — 좋은 날 (피아노 편곡) | 4코드 진행 |
| 초급 | BTS — Film Out | 아르페지오+멜로디 |
| 중급 | 폴킴 — 모든 날 모든 순간 | 전조+리하모니 |
| 고급 | Adele — Someone Like You | 다이나믹 폭 넓은 발라드 |

### 팝 피아노에서 자주 하는 실수

1. **화음 전환이 끊어짐** — 레가토 페달로 코드 사이 끊김 없이 이어주기
2. **반주 패턴이 단조로움** — 벌스는 단순 아르페지오, 코러스는 블록 코드로 변화주기
3. **원곡 키를 고집함** — 자신의 음역에 맞게 이조(transpose)하는 것이 음악적으로 더 효과적

### 팝 피아노 자가 진단

- [ ] 코드 전환이 끊기지 않고 매끄럽게 이어지는가?
- [ ] 벌스와 코러스의 에너지 차이가 연주에서 느껴지는가?
- [ ] 원하는 곡을 귀로 들으면서 코드를 찾아낼 수 있는가?

## 4주 피아노 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 다지기 | 하농 1~5번, 스케일 C장조·G장조 | 45분 |
| 2주차 | 곡 파악 | 곡 전체 천천히 손 분리 연습 | 45분 |
| 3주차 | 구간 집중 | 어려운 패시지 3구간 집중, BPM 70→90 | 60분 |
| 4주차 | 완성 | 전곡 연속 연주 + 다이나믹 표현 | 60분 |

**주간 체크포인트:** 1주차: 손 독립적 움직임 확인 / 2주차: 악보 암보 여부 / 3주차: 목표 구간 실수 없이 3회 연속 / 4주차: 처음부터 끝까지 감정 표현 포함

## 연습실에서 더 효과적으로

**피아노 연습실에서만 가능한 연습:**
- 포르테시모(ff) ~ 피아니시모(pp) 최대 다이나믹 폭 표현
- 페달 없이 레가토 연습 후 페달 추가 비교
- 본인 연주를 스마트폰으로 녹음 → 왼손/오른손 밸런스 객관적 확인
