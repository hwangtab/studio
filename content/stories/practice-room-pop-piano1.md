## 팝 피아노는 4코드로 시작합니다

클래식이나 재즈와 달리, 팝 피아노는 기본 코드 몇 개만 익혀도 바로 좋아하는 곡을 연주할 수 있습니다. 방음 개인실에서 원곡 틀고 따라 치면서 빠르게 실력을 쌓으세요.

팝 피아노 연습의 핵심:
- **4코드 마스터**: C-Am-F-G가 팝의 기초
- **멜로디 + 코드**: 오른손 멜로디와 왼손 코드 동시에
- **패턴 다양화**: 블록코드 → 아르페지오 → 패턴 반주
- **좋아하는 곡으로**: 동기부여가 있는 곡부터

---

## 팝 피아노 왼손 패턴 비교

| 패턴 | 예시 (C코드) | 느낌 |
|------|------------|------|
| 블록 코드 | C-E-G 동시 | 단순·깔끔 |
| 베이스+코드 | C·C-E-G | 가장 기본 |
| 아르페지오 | C·E·G·E | 서정적 |
| 알베르티 | C·G·E·G | 클래식 팝 |
| 팝 스타일 | C··C-E-G | 리드미컬 |

---

## K-POP 코드 진행 연습

### I-V-vi-IV 연습 (C장조)
```
C → G → Am → F (반복)
왼손: 루트 베이스
오른손: 멜로디 or 아르페지오
```

### vi-IV-I-V 연습 (C장조)
```
Am → F → C → G (반복)
단조 느낌의 감성 팝
```

| 구간 | 내용 | 시간 |
|-----|------|------|

| 즉흥 | 코드 위 자유 연주 | 10분 |
