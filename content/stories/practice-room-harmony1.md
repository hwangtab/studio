## 하모니는 음악의 색채입니다

하모니는 단독 선율보다 훨씬 풍부하고 감동적입니다. 하지만 각 파트가 견고해야만 아름다운 화음이 됩니다. 방음 개인실에서 내 파트를 완벽히 다진 후 합주에 나가세요.

하모니 연습의 핵심 원칙:
- **독립 파트**: 선율 없이 내 파트를 혼자 노래 가능
- **음정 유지**: 선율에 끌려가지 않는 훈련
- **균형 감각**: 전체 화음에서 내 파트의 음량
- **청음 훈련**: 전체 화음이 어떻게 들리는지 감지

---

## 하모니 파트별 연습법

### 3도 하모니 (가장 일반적)
```
선율: 도 레 미 파 솔
하모니: 미 파 솔 라 시 (3도 위)

연습: 
1. 스케일로 3도 하모니 먼저 익히기
2. 간단한 곡에 적용
3. 선율 음원과 함께 하모니 노래하기
```

### 5도·옥타브 하모니
```
선율보다 낮거나 높은 5도·옥타브
더 단순하지만 강한 힘 있음
저음부·남성 그룹에서 자주 활용
```

### 2성부·3성부 구성
```
2성부: 선율 + 3도/5도 하모니
3성부: 선율 + 3도 하모니 + 베이스라인
→ 가장 아름다운 3성부 화음은 1-3-5 트라이어드
```

## 하모니 연습 스케줄 (1시간)

| 시간 | 내용 |
|-----|------|
| 0~10분 | 발성 워밍업 |
| 10~25분 | 스케일 3도 하모니 (피아노 보조) |
| 25~40분 | 곡 하모니 파트 단독 연습 |
| 40~55분 | 음원과 함께 하모니 노래 |
| 55~60분 | 녹음 후 화음 확인 |

|-----|----------------|
