## 하모니는 음악의 색채입니다

하모니는 단독 선율보다 훨씬 풍부하고 감동적입니다. 하지만 각 파트가 견고해야만 아름다운 화음이 됩니다. 방음 개인실에서 내 파트를 완벽히 다진 후 합주에 나가세요.

하모니 연습의 핵심 원칙:
- **독립 파트**: 선율 없이 내 파트를 혼자 노래 가능
- **음정 유지**: 선율에 끌려가지 않는 훈련
- **균형 감각**: 전체 화음에서 내 파트의 음량
- **청음 훈련**: 전체 화음이 어떻게 들리는지 감지

---

## 하모니 파트별 연습법

### 3도 하모니 (가장 일반적)

```

선율: 도 레 미 파 솔
하모니: 미 파 솔 라 시 (3도 위)

연습: 
1. 스케일로 3도 하모니 먼저 익히기
2. 간단한 곡에 적용
3. 선율 음원과 함께 하모니 노래하기

```

### 5도·옥타브 하모니

```

선율보다 낮거나 높은 5도·옥타브
더 단순하지만 강한 힘 있음
저음부·남성 그룹에서 자주 활용

```

### 2성부·3성부 구성

```
2성부: 선율 + 3도/5도 하모니
3성부: 선율 + 3도 하모니 + 베이스라인
→ 가장 아름다운 3성부 화음은 1-3-5 트라이어드

```

## 하모니 연습 스케줄 (1시간)

| 시간 | 내용 |
|-----|------|
| 0~10분 | 발성 워밍업 |
| 10~25분 | 스케일 3도 하모니 (피아노 보조) |
| 25~40분 | 곡 하모니 파트 단독 연습 |
| 40~55분 | 음원과 함께 하모니 노래 |
| 55~60분 | 녹음 후 화음 확인 |

---

### 효율적인 연습 원칙

- **타이머 30분 집중 작업** — 완벽주의는 완성의 적. 타이머를 설정하고 그 안에 무조건 끝내는 훈련으로 완성 속도 향상
- **이어진 날 신선한 귀로 검토** — 작업 직후 판단은 왜곡됨. 하루 뒤에 들으면 구조적 문제가 객관적으로 들림
- **다른 사람에게 들려주기** — 청취자 반응이 가장 정직한 피드백. 음악 동료·커뮤니티 공유

### 연습 중 자주 하는 실수

1. **완성하지 않고 새 아이디어로 도망** — 미완성 프로젝트가 쌓이면 완성 능력이 발전하지 않음. 형편없는 완성곡이 완벽한 미완성보다 100배 가치 있음. 일단 끝내는 훈련
2. **레퍼런스 없이 무작정 시작** — 좋아하는 곡 3개를 분석한 후 작업 시작. 코드 진행·BPM·악기 구성을 의식적으로 참고하면 작업 시간이 단축되고 완성도가 높아짐
3. **과도한 레이어로 믹스 포화** — 레이어를 더하기 전에 지금 있는 요소를 제거해보는 테스트. 빠졌을 때 없어지는 느낌이 없으면 그 레이어는 불필요

### 연습 자가 진단

- [ ] 아이디어를 처음 들은 청자가 의도를 알아들을 수 있는가?
- [ ] 인트로-버스-코러스-아웃트로 구조가 명확한가?
- [ ] 모노 믹스에서도 각 악기가 구분되는가?

## 4주 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 점검 | 기본기 복습, 문제 구간 파악 | 40분 |
| 2주차 | 구간 집중 | 어려운 부분 느린 템포 반복 | 45분 |
| 3주차 | 전체 흐름 | 전곡 연결, 템포 단계적 올리기 | 50분 |
| 4주차 | 완성 | 목표 템포 + 표현·다이나믹 완성 | 60분 |

**주간 체크포인트:** 1주차: 약점 구간 3개 목록 작성 / 2주차: 각 구간 느린 템포 100% 달성 / 3주차: 전곡 끊김 없이 완주 / 4주차: 청중 앞 또는 녹음으로 최종 확인

## 연습실에서 더 효과적으로

**연습실에서만 가능한 연습:**
- 스튜디오 모니터로 실제 사운드 확인 (이어폰 왜곡 없이)
- 실제 악기로 아이디어 즉흥 연주 후 MIDI 녹음
- 반향음·잔향이 없는 환경에서 어레인지먼트 점검
