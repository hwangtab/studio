## 하모니는 음악의 색채입니다

하모니는 단독 선율보다 훨씬 풍부하고 감동적입니다. 하지만 각 파트가 견고해야만 아름다운 화음이 됩니다. 방음 개인실에서 내 파트를 완벽히 다진 후 합주에 나가세요.

하모니 연습의 핵심 원칙:
- **독립 파트**: 선율 없이 내 파트를 혼자 노래 가능
- **음정 유지**: 선율에 끌려가지 않는 훈련
- **균형 감각**: 전체 화음에서 내 파트의 음량
- **청음 훈련**: 전체 화음이 어떻게 들리는지 감지

## 하모니 파트별 연습법

### 3도 하모니 (가장 일반적)
```
선율: 도 레 미 파 솔
하모니: 미 파 솔 라 시 (3도 위)

연습: 
1. 스케일로 3도 하모니 먼저 익히기
2. 간단한 곡에 적용
3. 선율 음원과 함께 하모니 노래하기
```

### 5도·옥타브 하모니
```
선율보다 낮거나 높은 5도·옥타브
더 단순하지만 강한 힘 있음
저음부·남성 그룹에서 자주 활용
```

### 2성부·3성부 구성
```
2성부: 선율 + 3도/5도 하모니
3성부: 선율 + 3도 하모니 + 베이스라인
→ 가장 아름다운 3성부 화음은 1-3-5 트라이어드
```

## 하모니 연습 스케줄 (1시간)

| 시간 | 내용 |
|-----|------|
| 0~10분 | 발성 워밍업 |
| 10~25분 | 스케일 3도 하모니 (피아노 보조) |
| 25~40분 | 곡 하모니 파트 단독 연습 |
| 40~55분 | 음원과 함께 하모니 노래 |
| 55~60분 | 녹음 후 화음 확인 |

### 효율적인 연습을 위한 원칙

좋은 연습 습관이 실력 향상의 핵심입니다.

1. **목표 설정** — 오늘 연습에서 달성할 구체적인 목표 1개를 정하고 시작
2. **분리 연습** — 어려운 구간은 전체 반복보다 해당 2~4마디만 집중
3. **속도 조절** — 완벽하지 않은 기법을 빠른 속도로 반복하면 잘못된 근육 기억만 강화됨

### 연습 중 자주 하는 공통 실수

1. **어려운 구간을 피해서 쉬운 곳만 반복** — 불편한 구간이 실력 향상의 지점
2. **메트로놈 없이 빠른 속도 연습** — 느린 속도의 정확성이 빠른 속도의 기반
3. **연습 시간만 늘리고 내용은 방치** — 30분 집중 연습이 2시간 멍하니 반복보다 효과적

### 연습 자가 진단

- [ ] 오늘의 목표를 시작 전에 정했는가?
- [ ] 어려운 구간을 분리해서 집중 반복했는가?
- [ ] 연습 후 무엇이 개선되었는지 구체적으로 인식하는가?



## 4주 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 점검 | 기본기 복습, 문제 구간 파악 | 40분 |
| 2주차 | 구간 집중 | 어려운 부분 느린 템포 반복 | 45분 |
| 3주차 | 전체 흐름 | 전곡 연결, 템포 단계적 올리기 | 50분 |
| 4주차 | 완성 | 목표 템포 + 표현·다이나믹 완성 | 60분 |

**주간 체크포인트:** 1주차: 약점 구간 3개 목록 작성 / 2주차: 각 구간 느린 템포 100% 달성 / 3주차: 전곡 끊김 없이 완주 / 4주차: 청중 앞 또는 녹음으로 최종 확인


## 연습실 최대한 활용하는 법

**시간별 추천 구성 (1시간 기준):**
- 0~10분: 워밍업 (스트레칭, 기본 음계 또는 개방현)
- 10~45분: 목표 구간 집중 연습 (어렵고 중요한 부분 먼저)
- 45~55분: 전곡 런스루 (흐름·감정 표현 포함)
- 55~60분: 쿨다운 + 다음 연습 목표 메모

**방음 환경에서만 가능한 연습:**
- 최대 볼륨·최대 다이나믹 표현 (집에서 불가)
- 큰 소리로 가사 암송 + 발음 교정
- 틀렸을 때 즉각 멈추고 되돌아가는 구간 반복 훈련
