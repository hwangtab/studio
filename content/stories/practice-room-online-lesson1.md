## 레슨의 효과는 연습에서 완성됩니다

온라인 레슨이 보편화되었지만, 집에서의 연습 환경 한계로 레슨 효과가 절반에 그치는 경우가 많습니다. 방음·악기·녹음이 완비된 음악연습실이 그 격차를 채워줍니다.

온라인 레슨 + 음악연습실 조합의 장점:
- **레슨 즉시 적용**: 배운 직후 좋은 환경에서 바로 실습
- **방음 레슨 수강**: 집 소음·이웃 걱정 없이 화상 레슨
- **녹음 분석**: 레슨 내용 적용 후 자기 녹음으로 확인
- **악기 완비**: 피아노·PA가 없는 가정 환경 보완

| 요일 | 활동 | 시간 |
|-----|------|------|
| 화 | 온라인 레슨 (연습실) | 1시간 |
| 화 (레슨 후) | 레슨 내용 즉시 적용 연습 | 30분 |
| 목 | 신규 기술 집중 연습 | 1.5시간 |
| 토 | 전체 복습 + 다음 레슨 준비 | 1시간 |

## 화상 레슨 환경 최적화 체크리스트

**연습실 입실 후 레슨 전 15분:**
- [ ] 스마트폰·태블릿 거치대 세팅 (악기가 카메라에 잘 보이는 각도)
- [ ] 와이파이 연결 확인
- [ ] 이어폰/헤드셋 연결 (에코 방지)
- [ ] 레슨 메모 앱·노트 준비
- [ ] 악기 워밍업 5분

**레슨 중:**
- [ ] 중요 피드백 즉시 메모
- [ ] 선생님 시범 구간 반복 요청
- [ ] 과제 내용 정확히 확인

**레슨 후:**
- [ ] 30분 즉시 연습
- [ ] 연습 일지에 오늘 배운 핵심 기록

## 레슨 진도별 연습실 활용법

### 입문기 (0~6개월)
- 레슨 후 즉시 연습 최우선
- 짧고 자주 (30분 × 주 3~4회)
- 기본기 반복이 핵심

### 중급기 (6개월~2년)
- 레슨 내용 중 어려운 구간 집중 (50%)
- 레퍼토리 완성도 향상 (30%)
- 자기 녹음 + 분석 (20%)

### 상급기 (2년 이상)
- 독립 연습 비중 증가
- 레슨은 방향 점검·어려운 구간 해결
- 연주회·발표 준비 연계
