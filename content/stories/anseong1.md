## 안성에서 KTX로 서울까지

안성은 경기 남부 도시로, 평택역 KTX를 통해 서울과 약 1시간 30분으로 연결됩니다. 남사당 공연으로 유명한 안성에서 편리하게 당일 서울 스튜디오 방문이 가능합니다.

---

## 안성 → 연신내 이동 경로

### KTX 평택역 경유 (권장)

```
① 안성 → 평택역 (버스 약 30~40분)
② 평택역 KTX 탑승 (서울역 방면, 약 35~45분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 1시간 35분~2시간 5분
```

### 서울 고속버스 직행 (대안)

```
① 안성 터미널에서 서울고속버스터미널(강남) 직행버스
② 약 1시간 20분~1시간 40분
③ 강남터미널 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 1시간 50분~2시간 20분
```

## 당일 왕복 일정 예시 (안성 기준)

```
오전 8시 30분 안성 출발 → 평택역 이동
오전 9시 10분 평택역 KTX 출발
→ 오전 9시 55분 서울역 도착
→ 오전 10시 35분 연신내역 도착
→ 오전 11시 세션 시작 (2시간)
→ 오후 1시 세션 완료
→ 오후 3시 서울역 출발
→ 오후 3시 45분 평택역 도착
→ 오후 4시 25분 안성 도착
```

## 온라인 파일 의뢰 서비스

```
안성 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
