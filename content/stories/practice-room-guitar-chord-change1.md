## 코드 전환이 자동화될 때 음악이 흐릅니다

공통 손가락 피벗부터 메트로놈 전환까지. 방음 개인실에서 코드 전환을 탐색하세요.

기타 코드 전환 훈련의 핵심:
- **공통 손가락 피벗**: 두 코드 공통 손가락을 축으로 전환
- **최소 이동**: 손가락 이동 거리를 최소화하는 경로 설계
- **바레 코드 슬라이드**: 바레 유지하며 프렛 이동
- **메트로놈 점진적 증가**: BPM을 기록하며 목표 설정
