  - q: 기타 코드 전환을 빠르게 하는 핵심 원리는?
    a: >-
      코드 전환 속도 원리: ① 공통 손가락 유지 — 두 코드에 공통된 손가락은 그대로 유지 ② 피벗 포인트 — 공통 손가락을 축으로 다른
      손가락 이동 ③ 최소 이동 — 손가락이 이동하는 거리를 최소화 ④ 코드 예습 — 전환 전 다음 코드 모양을 머릿속에 준비 ⑤ 반복
      훈련 — 해당 코드 전환만 집중적으로 반복. 코드 전환이 느린 이유는 '다음 코드를 머릿속에서 계산하는 시간' 때문입니다. 반복을
      통해 전환이 자동화되면 생각 없이 손가락이 움직이게 됩니다.
  - q: 기타 C코드→G코드 전환을 부드럽게 하는 방법은?
    a: >-
      C→G 전환: ① 공통 손가락 없음 — C와 G는 공통 손가락이 없으므로 전체 이동 ② 빠른 모양 변환 — 왼손 전체를 새로운 G
      모양으로 즉각 이동 ③ 손목 위치 — 프렛 위치에 따라 손목 각도 조정 ④ 엄지 위치 — 코드에 따라 엄지가 넥 뒤에서 최적 위치로
      ⑤ 연속 반복 — C→G→C→G를 메트로놈에 맞춰 반복. C→G 전환은 초보자가 가장 어려워하는 전환 중 하나입니다. 두 코드의
      손가락 모양이 완전히 달라 공통 피벗이 없기 때문입니다. 천천히 시작해 속도를 점진적으로 높여야 합니다.
  - q: 기타 바레 코드 전환을 쉽게 하는 방법은?
    a: >-
      바레 코드 전환: ① 검지 고정 — 검지가 바레를 유지하면서 코드 모양만 변경 ② 루트 위치 확인 — 바레 코드는 루트 현·프렛
      위치로 코드 결정 ③ 플레이 앤 무브 — 연주하면서 바레를 새 위치로 이동 ④ 손 무게 — 검지에 적정 무게를 실어 바레 유지 ⑤
      미끄러짐 전환 — 같은 현에서 프렛만 이동하는 슬라이드 전환. 바레 코드 전환은 검지를 바레 상태로 유지하면서 이동하는 것이
      핵심입니다. 바레를 풀었다 다시 짚으면 소리가 끊기므로, 미끄러지듯 이동하는 연습이 필요합니다.
  - q: 기타 코드 전환 훈련에서 메트로놈을 활용하는 방법은?
    a: >-
      메트로놈 코드 전환: ① 4박자 체류 — 1코드에 4박 머물다 전환 ② 2박자 체류 — 숙달되면 2박마다 전환 ③ 1박자 전환 —
      완성 단계에서 매박 전환 ④ 클릭 전에 준비 — 다음 클릭이 오기 전에 이미 전환 완료 ⑤ 템포 기록 — 정확히 전환되는 최대
      BPM을 기록하며 목표 설정. 메트로놈 코드 전환 훈련에서 중요한 것은 '박자를 지키면서 전환'하는 것입니다. 박자가 늦어지면 템포를
      낮추고, 정확히 되면 BPM을 5씩 높여가세요.

## 코드 전환이 자동화될 때 음악이 흐릅니다

공통 손가락 피벗부터 메트로놈 전환까지. 방음 개인실에서 코드 전환을 탐색하세요.

기타 코드 전환 훈련의 핵심:
- **공통 손가락 피벗**: 두 코드 공통 손가락을 축으로 전환
- **최소 이동**: 손가락 이동 거리를 최소화하는 경로 설계
- **바레 코드 슬라이드**: 바레 유지하며 프렛 이동
- **메트로놈 점진적 증가**: BPM을 기록하며 목표 설정

## 기타 코드 전환 속도·스무스 체인지 훈련의 핵심 원칙 4가지

코드는 단순히 모양을 외우는 것이 아니라 **음악적 기능을 이해하면서 익히는** 것이 장기 기억에 훨씬 유리합니다.

1. **코드 기능 이해** — 각 코드가 I(토닉)·IV(서브도미넌트)·V(도미넌트) 중 어떤 기능인지 이해하며 연습. 기능을 알면 처음 보는 곡도 빠르게 코드를 파악할 수 있습니다.

2. **최소 이동 보이싱** — 코드 전환 시 손가락 이동을 최소화하는 보이싱 탐색. 공통 음을 중심으로 나머지 손가락만 이동하면 전환 속도가 빨라집니다.

3. **장르 맞춤 코드 색채** — 팝은 개방 코드의 따뜻함, 재즈는 7th·9th·13th 텐션, 클래식은 클로즈드 보이싱의 단단함을 각각 탐색하세요.

4. **코드톤 아르페지오** — 각 코드를 아르페지오로 분해하며 내성 음의 움직임을 귀로 인식. 코드와 선율의 관계가 명확해집니다.

### 기타 코드 연습에서 자주 하는 실수

1. **손가락을 눕혀서 인접 현을 뮤팅** — 각 손가락 끝을 세워서 프렛 바로 뒤를 누르기
2. **코드 전환 시 손 전체를 들어올림** — 기준 손가락(1지)을 최대한 이동하지 않고 전환
3. **스트로크 없이 코드 잡기만 연습** — 코드 전환 후 즉시 스트로크해서 '연주 흐름' 익히기
4. **바레 코드를 너무 일찍 시도** — 오픈 코드를 완전히 익힌 후 바레 코드로 진행

### 기타 코드 자가 진단

- [ ] 6개 현이 모두 깨끗하게 울리는가? (왼손 뮤팅 없이)
- [ ] G → C → Am → Em 코드 전환이 1박 안에 완성되는가?
- [ ] 코드 전환 후 첫 스트로크가 끊기지 않는가?
