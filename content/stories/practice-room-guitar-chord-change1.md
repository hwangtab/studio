    a: "C→G 전환: ① 공통 손가락 없음 — C와 G는 공통 손가락이 없으므로 전체 이동 ② 빠른 모양 변환 — 왼손 전체를 새로운 G 모양으로 즉각 이동 ③ 손목 위치 — 프렛 위치에 따라 손목 각도 조정 ④ 엄지 위치 — 코드에 따라 엄지가 넥 뒤에서 최적 위치로 ⑤ 연속 반복 — C→G→C→G를 메트로놈에 맞춰 반복. C→G 전환은 초보자가 가장 어려워하는 전환 중 하나입니다. 두 코드의 손가락 모양이 완전히 달라 공통 피벗이 없기 때문입니다. 천천히 시작해 속도를 점진적으로 높여야 합니다."
  - q: "기타 바레 코드 전환을 쉽게 하는 방법은?"
    a: "바레 코드 전환: ① 검지 고정 — 검지가 바레를 유지하면서 코드 모양만 변경 ② 루트 위치 확인 — 바레 코드는 루트 현·프렛 위치로 코드 결정 ③ 플레이 앤 무브 — 연주하면서 바레를 새 위치로 이동 ④ 손 무게 — 검지에 적정 무게를 실어 바레 유지 ⑤ 미끄러짐 전환 — 같은 현에서 프렛만 이동하는 슬라이드 전환. 바레 코드 전환은 검지를 바레 상태로 유지하면서 이동하는 것이 핵심입니다. 바레를 풀었다 다시 짚으면 소리가 끊기므로, 미끄러지듯 이동하는 연습이 필요합니다."
  - q: "기타 코드 전환 훈련에서 메트로놈을 활용하는 방법은?"

## 코드 전환이 자동화될 때 음악이 흐릅니다

공통 손가락 피벗부터 메트로놈 전환까지. 방음 개인실에서 코드 전환을 탐색하세요.

기타 코드 전환 훈련의 핵심:
- **공통 손가락 피벗**: 두 코드 공통 손가락을 축으로 전환
- **최소 이동**: 손가락 이동 거리를 최소화하는 경로 설계
- **바레 코드 슬라이드**: 바레 유지하며 프렛 이동
- **메트로놈 점진적 증가**: BPM을 기록하며 목표 설정

## 주요 코드 전환 유형

| 전환 | 공통 손가락 | 난이도 |
|------|-----------|--------|
| G→Cadd9 | 3·4지 유지 | 쉬움 |
| Am→C | 1·2지 피벗 | 보통 |
| C→G | 없음 | 어려움 |
| Bm→E | 바레 이동 | 고급 |
