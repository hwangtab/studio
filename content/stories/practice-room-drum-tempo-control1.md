# 드럼 템포 컨트롤·메트로놈 훈련법 — 음악연습실 완전 가이드

모든 드러머의 핵심 역할은 **템포를 지키는 것**입니다. 화려한 기법보다 안정적인 템포가 밴드 전체를 살립니다. 그리고 가장 훌륭한 드러머는 메트로놈 없이도 곡 내내 정확한 템포를 유지합니다. 이 가이드에서는 내면의 박자감 개발과 메트로놈 훈련법을 안내합니다.

---

## 템포 불안정의 원인

### 왜 템포가 흔들리는가?

1. **홍분**: 에너지 넘치는 구간에서 빨라짐
2. **어려운 구간**: 집중하면서 느려짐
3. **필(Fill)**: 필 후 템포 재진입 실패
4. **다이나믹 변화**: 크게 칠 때 빨라지는 경향

### 템포 드리프트 vs 템포 러시

**러시 (Rush):** 일관되게 빠른 방향으로 이탈
**드리프트 (Drift):** 불규칙하게 빠르고 느려짐
**레이드백 (Lag):** 일관되게 느린 방향으로 이탈

## 메트로놈 훈련법

### 기초: 박자에 맞추기

**1단계: 메트로놈 클릭 = 박 1**
```

BPM 80: 메트로놈 클릭마다 킥 또는 스네어
완전히 맞을 때까지 연습

```

**2단계: 클릭 = 2, 4박만**
```

BPM 80: 메트로놈이 2박과 4박에만 클릭
→ 1박과 3박은 드러머가 채워야 함
더 어렵지만 더 실용적인 훈련

```

**3단계: 클릭 = 1박만**
```

BPM 80: 4박 중 1박에만 클릭
→ 나머지 3박을 정확하게 내부에서 세기
가장 어려운 레벨

```

### 서브디비전 훈련

메트로놈을 반으로, 또는 두 배로:

**반속도 메트로놈:**
```

원하는 BPM의 절반으로 설정
→ 클릭을 2박 또는 4박으로 느끼기
예: BPM 60 클릭 = BPM 120의 2박 느낌

```

**두 배 메트로놈:**
```

원하는 BPM의 두 배 설정
→ 모든 8분음표에 클릭
정확성 극대화

```

## 내면 박자감 개발

### 메트로놈 없는 연습

메트로놈에만 의존하면 자율성이 없어짐:

**훈련 1: 눈 감고 연주**

메트로놈 켜고 → 30초 후 끄기 → 30초 연주 → 다시 켜서 체크

**훈련 2: 멈추고 재진입**

연주 중 갑자기 멈추기 → 머릿속으로 4박 세기 → 정확한 타이밍에 재진입

**훈련 3: 느리게-빠르게-느리게**

템포 변화 없이 내면으로만 빠르게 또는 느리게 느끼며 연주

### 바디 타이밍 (Body Timing)

발로 박자를 느끼며 연주:
- 발을 2박, 4박에 탭하며 상체로 연주
- 발이 내면 메트로놈 역할

---

## 필(Fill) 전후 템포 안정

### 필 중 템포 유지

필은 템포를 잃기 가장 쉬운 구간:

**원칙:**
- 필 중에도 내면 박자 유지
- 필의 마지막 음을 정확한 박자에 맞추기
- 필 후 다운비트(1박)가 완벽해야 함

**훈련:**
1. 기본 비트 4마디
2. 4마디째 마지막 박에 필
3. 필 후 즉시 기본 비트 복귀
4. 메트로놈과 비교

### 안티시파테이션 (Anticipation)

필을 실제 박자보다 약간 빨리 시작하면 자연스럽게 들리는 효과:
- 이것은 의도된 미세 조정
- 1-2개의 16분음표 먼저 시작

---

## 음악연습실 템포 훈련 루틴

### 메트로놈 정확성 (30분)

1. **1-2-3-4 클릭**: 기본 비트 BPM 80 (10분)
2. **2-4박만 클릭**: 같은 BPM (10분)
3. **1박만 클릭**: BPM 60에서 (10분)

### 내면 박자 훈련 (20분)

1. 켜고-끄기 훈련: 30초+30초 (10분)
2. 멈추고 재진입 (10분)

### 필 전후 안정 (10분)

1. 기본 비트-필-기본 비트 패턴
2. 메트로놈과 정확도 체크

## 마무리

템포 컨트롤은 드럼의 가장 기초적이고 중요한 기술입니다. 어떤 화려한 기법도 불안정한 템포 위에서는 효과가 없습니다.

은평구 24시간 음악연습실에서 매일 메트로놈과 함께 기초 훈련을 지속하고 내면의 완벽한 박자감을 완성하세요.

### 드럼 테크닉 훈련 추천 루디먼트

| 루디먼트 | 응용 | 난이도 |
|--------|------|-------|
| Single Stroke Roll | 기본 스틱킹 균등화 | 입문 |
| Paradiddle | 스네어 필인 | 초급 |
| Flam | 재즈·락 액센트 | 중급 |
| Double Stroke Roll | 고속 롤 | 고급 |

### 드럼 테크닉에서 자주 하는 실수

1. **그립이 일정하지 않음** — 매치드·트래디셔널 그립 중 하나를 완전히 익힌 후 다른 것 시도
2. **리바운드를 활용하지 않음** — 스틱이 자연스럽게 튀어 오르는 힘을 이용하면 피로도 감소
3. **양손 차이를 방치함** — 약한 손(보통 왼손) 집중 단독 연습 시간을 따로 배분
