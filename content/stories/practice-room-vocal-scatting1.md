# 보컬 스캣 싱잉·재즈 즉흥·멜로디 즉흥 — 음악연습실 완전 가이드

스캣 싱잉(Scat Singing)은 **말 없는 언어로 즉흥하는 재즈 보컬 예술**입니다. 의미 없는 음절("doo-wah", "bop-bah", "da-da-dit")로 악기처럼 즉흥 연주하는 기법입니다. Ella Fitzgerald, Louis Armstrong, Sarah Vaughan — 이들이 스캣으로 재즈 역사를 썼습니다.

---

## 스캣 싱잉이란?

### 기원과 역사

**스캣의 기원:**
```
Louis Armstrong: "Heebie Jeebies" (1926)
= 가사 잊고 즉흥 음절로 부름 → 스캣 탄생!
```

**스캣의 특징:**
```
가사 없음 → 음절로 즉흥
음절: doo, bah, bee, wah, dat, dit, shoo...
목소리 = 악기
코드 진행 위 즉흥 = 악기 솔로와 동일
```

### 스캣 vs 일반 즉흥

**스캣:** 음절로 즉흥
**멜리스마 (팝 런):** 가사 음절에 많은 음을 부름
**보컬 즉흥:** 가사 변형 + 멜로디 변주

---

## 스캣 음절 (Scat Syllables)

### 기본 음절 팔레트

**부드러운 음절:**
```
doo, do, du, da, dee
= 레가토, 부드러운 흐름에
```

**날카로운 음절:**
```
dat, dit, dut, ba, be
= 스타카토, 어택 있는 음에
```

**슬러·스윕 음절:**
```
wah, bah, dee-wah, bop-bah
= 슬러·글리산도 효과에
```

**악기 흉내:**
```
"n-ya": 와와 뮤트 느낌
"tsh": 하이햇 느낌
"boom": 킥 드럼 느낌
```

### Ella Fitzgerald 음절

Ella Fitzgerald의 특징:
```
"do-dee-ya-ya", "sh-bee-do-bah"
= 빠른 속도에도 선명한 음절
호른 라인을 목소리로 정확히 재현
```

---

## 코드 톤 중심 즉흥

### 스캣도 음악 이론이 기초

**스캣의 화성 기반:**
```
코드 톤 (1·3·5·7도): 가장 안전
스케일 패싱 톤: 연결음
크로매틱 접근: 당김·해결
```

**ii-V-I 위 스캣:**
```
Dm7 위: D-F-A-C 코드 톤 중심
G7 위: G-B-D-F 코드 톤 + Eb (b13 크로매틱)
Cmaj7 위: C-E-G-B
= 스캣이지만 코드 진행을 노래함
```

### 가이드 톤으로 스캣

**3도·7도로 ii-V-I 연결:**
```
Dm7: F(3도) → 
G7: B(3도, 반음 상행!) →
Cmaj7: E(3도)
= 스캣 라인이 가이드 톤 따라 흐름
```

## Louis Armstrong 스타일

### 스캣의 아버지

Louis Armstrong의 스캣 특징:
- **리듬 중심:** 음정보다 리듬 강조
- **짧고 강한 음절:** "ya-da-da-dat"
- **트럼펫 라인 흉내:** 자신의 트럼펫 프레이징을 목소리로

**Armstrong 리듬 패턴:**
```
타이된 8분음표: da-dat (강박-약박)
스윙 리듬: 장단 8분음표
싱코페이션 강조
```

---

## Sarah Vaughan 스타일

### 목소리의 악기화

Sarah Vaughan ("Sassy"):
- **넓은 음역:** 3옥타브 이상의 성역
- **비브라토 완벽 제어:** 느리게 시작해서 빠르게
- **화성 복잡성:** 클로즈드 보이싱의 목소리 버전

**Vaughan 화성적 스캣:**
```
단순 스케일 대신 화음 내 색채 음 강조
b9, #11 등 확장 음 자연스럽게 노래함
= 재즈 화성을 몸으로 노래함
```

---

## 스캣 리듬 패턴

### 스윙 리듬

**스윙 8분음표:**
```
악보상: 두 8분음표 = 동일
실제: 장-단 (triplet 느낌)
= 스윙의 핵심 리듬 느낌
```

**싱코페이션 스캣:**
```
"doo-wah": 약박에 강세
"ba-DIT": 뒷박 강조
= 재즈 리듬 느낌
```

### 비밥 라인 스캣

**비밥 스캣:**
```
빠른 16분음표
많은 크로매틱 음
코드 변화마다 새 라인
= Ella Fitzgerald, Charlie Parker 보컬 버전
```

---

## 스캣 연습 방법

### 단계별 학습

**1단계: 리듬 익히기**
```
단일 음으로 리듬만 스캣
"doo-doo-doo" 스윙 리듬
= 음정 없이 리듬 패턴만
```

**2단계: 코드 톤 노래**
```
Cmaj7 코드 톤만: C-E-G-B
각 코드 톤 스캣 음절로
= 화성 느낌 익히기
```

**3단계: ii-V-I 스캣**
```
Dm7-G7-Cmaj7 진행 위
코드 톤 + 패싱 톤으로 라인
느린 템포부터 (♩= 80)
```

**4단계: 녹음·비교**
```
자신의 스캣 녹음
Ella Fitzgerald 녹음과 비교
리듬·음정·표현 분석
```

---

## 음악연습실 스캣 연습

### 60분 루틴

**1. 음절 연습 (10분)**
   - doo, dat, bah, wah, bee 각 발음
   - 빠르게·느리게 변화
   - 다양한 음역대에서

**2. 리듬 스캣 (15분)**
   - 단일 음으로 스윙 리듬
   - 싱코페이션 패턴
   - 스윙 8분음표 느낌 고정

**3. ii-V-I 스캣 라인 (20분)**
   - 코드 톤 중심 라인
   - 크로매틱 접근 추가
   - 느린 템포에서 반복

**4. 자유 즉흥 스캣 (15분)**
   - 백킹 트랙 위에서 자유롭게
   - 녹음 후 자기 피드백
   - Ella Fitzgerald 음반 따라 부르기

## 마무리

스캣 싱잉은 **목소리가 완전한 악기가 되는 순간**입니다. Ella Fitzgerald가 "음악에 가사가 필요 없다는 걸 스캣이 증명한다"고 했듯, 의미 없는 음절들이 최고의 재즈 표현이 됩니다. 코드 톤을 노래하고, 리듬을 느끼고, 음절로 색칠하세요.

은평구 24시간 음악연습실에서 "doo-doo-doo" 스윙 리듬부터 시작하세요. 코드 진행이 들리기 시작하면, 스캣이 자연스럽게 흘러나옵니다.
