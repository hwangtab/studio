## 봉화에서 서울까지

봉화는 경북 북부 산악 도시로, 고속버스 또는 영주역 기차를 통해 서울과 연결됩니다. 은어와 송이버섯으로 유명한 봉화에서 서울 스튜디오 방문 또는 온라인 의뢰가 가능합니다.

---

## 봉화 → 연신내 이동 경로

### 고속버스 이용 (권장)

```
① 봉화 버스터미널 → 동서울터미널 (직행 약 3시간 30분~4시간)
② 동서울터미널 → 지하철 → 연신내역 (약 40분)

총 소요시간: 약 4시간 10분~4시간 40분
```

### 영주역 기차 경유 (선택)

```
① 봉화 → 영주역 (버스 약 30분)
② 영주역 → 청량리역 (무궁화·ITX-새마을, 약 2시간 30분~3시간)
③ 청량리역 → 지하철 → 연신내역 (약 40분)

총 소요시간: 약 3시간 40분~4시간 30분
```

---

## 당일 왕복 일정 예시 (봉화 기준)

```
오전 5시 30분 봉화 출발 (고속버스)
→ 오전 9시 30분 동서울터미널 도착
→ 오전 10시 10분 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 1시 30분 동서울터미널 출발
→ 오후 5시 30분 봉화 도착
```
