# 기타 하모닉스·인공 하모닉스 기법 — 음악연습실 완전 가이드

기타 하모닉스(Harmonics)는 **현의 배음을 독립적으로 울리게 하는 기법**입니다. 유리처럼 맑고 투명한 소리, 오케스트라 현악기 같은 음색—하모닉스는 기타에서만 가능한 신비로운 영역입니다. Steve Howe, Alex Lifeson, Kaki King의 하모닉스 기법을 탐구합니다.

---

## 하모닉스의 원리

### 배음 구조

현이 진동할 때 **기본음(Fundamental)**과 함께 **배음(Overtone)**들이 발생합니다.

**C 음의 배음:**
```

기본음: C2
배음 1: C3 (옥타브)
배음 2: G3 (5도)
배음 3: C4 (2옥타브)
배음 4: E4 (3도)

```

**하모닉스는 이 배음들을 독립적으로 울리게 하는 것**.

---

## 자연 하모닉스 (Natural Harmonics)

### 기법

**자연 하모닉스:** 열린 현 위에서 프렛을 가볍게 터치하여 배음 울리기.

**중요:** 프렛을 완전히 눌러서는 안 됨. 살짝 닿는 정도.

### 주요 하모닉스 위치

**12프렛 하모닉스:**
```
1번 현 12프렛: E5 (기본음 E4의 옥타브)
2번 현 12프렛: B5
3번 현 12프렛: G5
4번 현 12프렛: D5
5번 현 12프렛: A4
6번 현 12프렛: E4

```

**7프렛 하모닉스:**
```
1번 현 7프렛: B5 (E4의 완전5도 위 옥타브)
2번 현 7프렛: F#5

```

**5프렛 하모닉스:**
```
1번 현 5프렛: E6 (2옥타브 위)

```

**9프렛 하모닉스:**
```
1번 현 9프렛: C#6 (4도 위 + 하모닉스)

```

### 하모닉스 주법

**기법:**
1. 오른손 피킹 위치: 보통 위치 (사운드홀 또는 픽업 위)
2. 왼손: 프렛에 가볍게 닿기 (누르지 않음)
3. 치는 동시에 왼손 들기
4. 깨끗하고 투명한 소리 확인

---

## 인공 하모닉스 (Artificial Harmonics)

### 개념

**인공 하모닉스:** 왼손으로 프렛을 누른 상태에서 오른손으로 하모닉스 포인트를 터치+피킹.

**자연 하모닉스의 확장:** 12프렛 위치가 항상 기준이 아님.

**규칙:** 왼손으로 누른 프렛 + 12 = 오른손 터치 위치

**예:**
```

왼손: 5프렛 (A 음)
오른손 터치: 17프렛 (5+12=17)
결과: A의 옥타브 하모닉스

```

### 인공 하모닉스 연습

**기법 (핀치 하모닉스 아님):**
```

왼손: 코드 또는 단음 누름
오른손: 12프렛 위 위치에서
  - 검지: 하모닉스 포인트 터치
  - 엄지 또는 다른 손가락: 피킹

```

**멜로디 연주:**
```

C 스케일을 인공 하모닉스로:
왼손: 5-7-9-10-12-14-15-17 (C-D-E-F-G-A-B-C)
오른손: 각각 +12 위치에서 터치+피킹

```

---

## 태핑 하모닉스 (Tapping Harmonics)

### 개념

오른손 손가락으로 해당 위치를 강하게 탭하여 하모닉스 발음.

**기법:**
1. 왼손으로 코드 누름
2. 오른손 검지로 +12 위치를 빠르게 탭·리프트

**Eddie Van Halen 스타일:**
```

왼손: Am 코드 (또는 단음)
오른손: +12 위치를 태핑 하모닉스

```

### Kaki King 스타일

Kaki King은 태핑 하모닉스의 대가.

**기법:**
1. 기타를 수평으로 눕히거나 일반 위치
2. 양손 태핑 + 하모닉스 조합
3. 멜로디·베이스·하모닉스 동시에

---

## 핀치 하모닉스 (Pinch Harmonics)

### 록·메탈의 스크리밍 하모닉스

**기법:**
1. 픽을 매우 짧게 잡음 (엄지가 직후 현에 닿도록)
2. 현을 치면서 엄지 끝이 현을 살짝 터치
3. 날카롭고 스크리밍한 하모닉스 발음

**특징:**
- 위치에 따라 발음되는 배음이 달라짐
- 왐미바(트레몰로 암)와 함께 더 극적
- Zakk Wylde, Dimebag Darrell이 즐겨 사용

**연습 위치:**
```

픽업 근처: 더 날카로운 소리
넥 중간: 더 부드러운 소리

```

## 하모닉스 활용

### 인트로와 아웃트로

하모닉스로 시작하거나 끝내기:

**예:**
```

곡 인트로: 자연 하모닉스 아르페지오
Cmaj7 아르페지오를 12프렛 하모닉스로

```

### 코드 하모닉스

**오픈 E 코드를 자연 하모닉스로:**
```
12프렛: E5-B5-G5-E5 (4개 현 동시)
맑고 울리는 코드 소리

```

### 엔딩 하모닉스

곡의 마지막에 사용하면 드라마틱:

```

마지막 코드 후 자연 하모닉스
12프렛에서 조용히 사라짐

```

## 음악연습실 하모닉스 연습

### 연습 루틴 (50분)

**1. 자연 하모닉스 (15분)**
   - 12, 7, 5프렛 자연 하모닉스 확인
   - 모든 현에서 클린한 소리 만들기

**2. 인공 하모닉스 (15분)**
   - C 스케일을 인공 하모닉스로
   - 왼손+오른손 터치 동기화

**3. 태핑 하모닉스 (10분)**
   - 코드 위에서 태핑 하모닉스
   - 양손 독립성 훈련

**4. 창작 응용 (10분)**
   - 하모닉스로 시작하는 인트로 만들기
   - 녹음하여 소리 확인

## Studio NOL 연습실에서 기타 하모닉스 연습할 때 확인하는 3가지

스튜디오 놀 음악연습실에서 기타 하모닉스를 훈련할 때 자주 확인하는 패턴입니다.

**1. 자연 하모닉스가 클린하게 나지 않으면 손가락 위치를 점검하라**

12프렛 하모닉스가 뭉치거나 소리가 묻히는 경우 대부분 왼손 손가락이 프렛 바 정중앙에 있지 않거나 터치 압력이 너무 강한 것이 원인입니다. 프렛 와이어 정중앙을 가볍게 터치하는 것을 확인하고, 앰프를 클린 채널로 설정해 소리를 모니터하며 연습하세요.

**2. 인공 하모닉스 음정 불안정은 오른손 터치 포인트 문제다**

왼손으로 누른 프렛에서 정확히 +12 위치를 오른손이 유지해야 하는데, 빠른 멜로디 라인에서 오른손 인덱스 핑거가 조금씩 벗어나면서 음정이 흔들립니다. 느린 BPM에서 각 음의 오른손 위치를 먼저 확인하고 기준 포인트를 몸에 기억시킨 다음 속도를 올리세요.

**3. 핀치 하모닉스는 픽 깊이와 각도의 일관성 훈련이 필요하다**

핀치 하모닉스는 픽 깊이와 엄지 터치 타이밍이 매 픽마다 일치해야 안정적으로 나옵니다. 픽을 현에 대고 엄지 끝이 현에 닿는 최소 지점을 찾아 반복 연습하세요. 스마트폰으로 연주를 녹음해 재생하면 일관성 여부를 객관적으로 확인할 수 있습니다.

## 마무리

기타 하모닉스는 **기타가 가장 신비로워지는 순간**입니다. 맑고 투명한 배음의 세계는, 처음에는 어렵지만 일단 손에 익으면 가장 아름다운 기타 소리 중 하나가 됩니다.

---

기타 하모닉스는 자연 배음(Natural Harmonics)과 인공 배음(Artificial Harmonics)으로 나뉩니다. 자연 하모닉스는 12, 7, 5 프렛 위 현에 가볍게 손가락을 대고 피킹하면 피아노 종소리 같은 벨 톤이 만들어집니다. 인공 하모닉스는 원하는 음 위에 12프렛 간격으로 엄지를 대고 검지로 피킹하는 기법으로 더 많은 음역대에서 활용 가능합니다.

일렉트릭 기타에서 피킹 각도와 깊이는 톤에 직접적인 영향을 미칩니다. 픽을 줄에 대해 약간 비스듬히 잡으면 마찰음이 줄고 부드러운 톤을 얻을 수 있습니다. 얼터네이트 피킹을 정확하게 구현하기 위해 느린 BPM에서 다운·업 스트로크를 교대하는 훈련이 필수적입니다. 이펙터 조합을 다양하게 실험해보면 오버드라이브, 딜레이, 리버브 등 각 이펙트가 사운드에 미치는 영향을 직접 파악할 수 있습니다. 앰프 볼륨과 이펙터 레벨의 적절한 조화를 찾는 과정이 자신만의 톤을 만들어갑니다. 음악 연습의 질을 높이는 데 녹음은 유용한 도구입니다. 스마트폰으로 간단히 녹음한 뒤 나중에 들어보면 연주 중에는 미처 인식하지 못했던 리듬 불안정, 음정 이탈, 다이나믹 부재 등을 객관적으로 파악할 수 있습니다. 자신의 연주를 비판적으로 분석하는 능력이 쌓일수록 효율적인 자기 교정이 가능해집니다. 연습실의 앰프나 모니터 스피커를 통해 자신의 소리를 명확하게 듣는 환경을 만드는 것도 중요합니다.
