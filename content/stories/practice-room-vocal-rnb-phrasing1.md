# 보컬 R&B 프레이징·그루브·어택 포인트 — 음악연습실 완전 가이드

R&B 보컬(Rhythm & Blues Vocal)은 **리듬과 감정이 함께 흐르는 노래**입니다. Stevie Wonder의 그루비한 멜리스마, D'Angelo의 네오소울 속삭임, Alicia Keys의 파워풀한 어택 — 이들이 R&B 보컬의 아름다움을 보여줍니다. 단순히 음을 맞추는 것이 아니라, 비트 위에서 리듬과 감정을 동시에 표현하는 것이 R&B 보컬의 핵심입니다.

---

## R&B 보컬 프레이징이란?

### 프레이징과 그루브의 개념

**R&B 프레이징의 핵심:**
```
멜로디를 리듬에 맞게 "타이밍"으로 표현
박자 앞뒤로 느낌 조절
= 같은 음이지만 느낌이 달라짐
```

**그루브(Groove):**
```
박자를 정확히 맞추는 것이 아니라
"느끼는" 리듬감
= 신체적·감정적 박동감
```

**R&B vs 팝 보컬:**
```
팝: 박자 정확, 멜로디 충실
R&B: 박자 "느낌", 리듬 유연
= R&B는 노래를 "말하듯" 흐름
```

---

## 어택 포인트 (Attack Point)

### 박자 앞뒤로 타이밍 조절

**어택 포인트란:**
```
음을 시작하는 타이밍 위치
= "언제" 음을 시작하느냐
```

**비트 앞 (레이어 어헤드):**
```
박자보다 조금 일찍 시작
= 긴장감, 에너지, 적극적
Stevie Wonder 스타일
```

**비트 정확히:**
```
= 안정감, 파워, 명확함
Alicia Keys 클라이맥스
```

**비트 뒤 (레이잉 백):**
```
박자보다 조금 늦게 시작
= 여유, 섹시함, 느긋함
D'Angelo, Frank Ocean 스타일
```

### 레잉 백 연습

**레잉 백 기법:**
```
드럼 비트보다 1/16박 늦게
= 가장 그루비한 R&B 느낌
억지로 늦추지 말고 "밀리는 느낌"
```

**실습:**
```
4/4박자 메트로놈 ♩= 80
1박에 "라" 시작 → 조금 늦춰서 시작
= 비트 뒤에 얹히는 느낌
```

---

## 멜리스마 (Melisma)

### R&B 보컬의 꽃

**멜리스마:**
```
한 음절에 여러 음을 연결해서 흘려보내기
= "아~~에~~~이" 처럼
```

**Stevie Wonder 멜리스마:**
```
단순한 구절에서 갑자기 터지는 5~8음 런
감정의 폭발 표현
```

**Mariah Carey 멜리스마:**
```
고음에서의 화려한 런
5도~옥타브 도약 후 멜리스마
= 파워와 유연성의 극치
```

**멜리스마 3가지 타입:**
```
스케일 런: 도-레-미-파-솔 차례로
아르페지오 런: 화음 음들만 (1-3-5-8)
블루스 런: 블루 노트 포함 (b7-6-5 등)
```

## R&B 보컬 기법

### 그루브를 만드는 기법들

**트러캐이팅 (Truncating):**
```
음을 예상보다 일찍 끊기
= 리드미컬한 단절감
다음 음으로의 여백 만들기
```

**애드립 (Ad-lib):**
```
악보 밖의 즉흥 구절
코러스 끝에 "yeah~", "oh~" 추가
= R&B 가수의 감정 표현 도구
```

**밸렛 (Valet):**
```
메인 멜로디 위·아래에 꾸밈 구절
백그라운드 보컬처럼 자신이 하는 애드립
```

**보컬 런 (Vocal Run):**
```
빠른 음 연결 구절 (16분음표 이상)
= 기타 솔로처럼 보컬로 달리기
```

---

## 리듬 감각 훈련

### 그루브를 몸에 익히기

**박수로 비트 느끼기:**
```
1박 & 3박: 다운비트 (강)
2박 & 4박: 업비트 (약)
= R&B는 2박·4박을 강하게 느낌
```

**셔플 느낌 연습:**
```
스트레이트 8분음표 대신
장-단 느낌으로 (♩♪ → 셔플)
= 소울·R&B 특유의 스윙 느낌
```

**16분음표 분할:**
```
1 e + a 2 e + a 3 e + a 4 e + a
= R&B 멜리스마는 "e"와 "a" 위에 음들
```

## D'Angelo 네오소울 스타일

### 속삭이는 그루브

D'Angelo("Brown Sugar", "Voodoo"):
- **속삭이는 팔세토:** 가성으로 그루비하게
- **성적 긴장감:** 억제된 감정 표현
- **레잉 백:** 항상 비트보다 늦게

**D'Angelo 스타일 접근:**
```
마이크에 가까이
속삭이듯 (전체 볼륨 줄임)
= 친밀하고 그루비한 R&B
```

---

## Alicia Keys 스타일

### 피아노 R&B 어택

Alicia Keys("No One", "If I Ain't Got You"):
- **강한 어택:** 음 시작이 파워풀
- **정확한 비트:** 클래식 피아노 배경
- **감정 클라이맥스:** 클라이맥스에서 폭발

**Alicia Keys 클라이맥스 기법:**
```
조용히 시작 → 코러스에서 파워풀
마지막 클라이맥스: mf → ff (갑자기 크게)
= 극적인 R&B 감동
```

## 음악연습실 R&B 보컬 프레이징 연습

### 60분 루틴

**1. 리듬 감각 훈련 (15분)**
   - 메트로놈 ♩= 80, 2박·4박 박수 치기
   - 레잉 백 연습 (비트보다 1/16 늦게)
   - 16분음표 분할 입으로 말하기

**2. 멜리스마 기초 (15분)**
   - 스케일 런: C-D-E-F-G 5음 빠르게
   - 아르페지오 런: C-E-G-C (옥타브까지)
   - 블루스 런: b7-6-5-4 하행

**3. 어택 포인트 연습 (15분)**
   - 비트 앞 어택 vs 레잉 백 비교
   - 좋아하는 R&B 곡 따라 부르기
   - 타이밍 의도적으로 조절

**4. 애드립 & 즉흥 (15분)**
   - I-vi-IV-V 진행 위 자유로운 멜리스마
   - "yeah", "oh", "mm" 추가 애드립
   - 감정 표현에 집중

## 마무리

R&B 보컬 프레이징은 **박자를 아는 것과 느끼는 것의 차이**입니다. Stevie Wonder가 "음악은 느끼는 것이다, 생각하는 것이 아니라"고 했듯, 리듬과 멜리스마는 머리가 아니라 몸에서 나옵니다. 비트 위에 얹히는 한 음의 타이밍이 노래를 살아있게 만듭니다.

은평구 24시간 음악연습실에서 레잉 백 연습부터 시작하세요. 비트 뒤로 밀리는 그 순간, R&B의 그루브가 시작됩니다.
