  - q: 기타 곡을 악보 없이 암기하는 효과적인 방법은?
    a: >-
      기타 암보 방법: ① 청각 기억 — 먼저 귀로 완전히 기억 ② 단위 분할 — 마디 단위로 끊어서 암기 ③ 손 패턴 — 어느 프렛,
      어느 손가락인지 시각화 ④ 구조 분석 — A-B-A, 코러스-버스 등 구조 파악 ⑤ 분리 후 연결 — 각 부분 암기 후 연결. 기타
      암보의 핵심은 '귀 먼저'입니다. 머리로 선율을 노래할 수 있어야 손도 따라갈 수 있습니다. 악보를 보면서 외우는 것보다 귀로 먼저
      기억하면 훨씬 빠르고 오래 기억됩니다.
  - q: 기타 연주에서 악보 의존도를 줄이는 훈련 방법은?
    a: >-
      악보 의존도 줄이기: ① 악보 덮기 — 매 연습 일부를 악보 없이 ② 구간 암보 — 한 구간씩 악보 없이 연주 후 확인 ③ 눈 감기
      — 악보 없이 눈 감고 연주 ④ 분절 연습 — 각 마디를 악보 없이 반복 ⑤ 공연 시뮬 — 악보 없는 '공연 모드' 연습. 악보에서
      벗어나는 훈련은 처음에는 불안하지만 꼭 필요합니다. 악보를 보는 동안에는 청중과 교감하기 어렵고, 연주의 표현력도 제한됩니다. 악보
      없는 연주가 진정한 음악적 자유입니다.
  - q: 기타 코드 진행을 외워 즉흥 연주에 활용하는 방법은?
    a: >-
      코드 진행 암보·활용: ① 로마자 — C장조 기준 코드를 I·II·IV·V로 분석 ② 기능 이해 — 각 코드의 긴장·이완 기능 이해
      ③ 귀로 확인 — 코드 진행을 들으면서 인식 ④ 이조 연습 — 같은 진행을 다른 조로 ⑤ 즉흥 — 외운 코드 진행 위에 멜로디 즉흥.
      코드 진행을 외울 때 '왜 이 순서인가'를 이해하면 더 오래 기억됩니다. I-IV-V-I 진행이 자연스러운 이유, ii-V-I가
      재즈에서 많이 쓰이는 이유를 이해하면 외우지 않아도 기억에 남습니다.
  - q: 기타 솔로 라인을 악보 없이 암기하는 방법은?
    a: >-
      솔로 라인 암보: ① 프레이즈 단위 — 2~4마디 단위로 끊어서 암기 ② 루트 위치 — 각 프레이즈의 시작·끝 위치 먼저 ③ 스케일
      관계 — 어느 스케일·포지션에서 나오는 프레이즈인지 ④ 리듬 먼저 — 음정 전에 리듬 패턴 먼저 리듬창 ⑤ 느린 반복 — 정확한
      형태로 느리게 반복 후 속도. 솔로 라인 암보에서 '스케일 포지션 인식'이 핵심입니다. 각 프레이즈가 어느 포지션에서 나오는지
      파악하면, 프레이즈를 '음표 나열'이 아닌 '포지션 움직임'으로 기억할 수 있어 훨씬 쉽게 암기됩니다.

## 악보 없는 연주가 진정한 음악적 자유입니다

귀와 손의 기억으로 연주하세요. 방음 개인실에서 기타 암보를 탐색하세요.

기타 암보 훈련의 핵심:
- **귀 먼저**: 선율을 노래할 수 있어야 손도 따라간다
- **구간 분할**: 마디 단위로 끊어 암기 후 연결
- **악보 덮기**: 연습의 일부를 항상 악보 없이
- **구조 이해**: 코드 기능·스케일 포지션 이해가 암기력 향상

## 기타 뮤직 메모리·악보 없이 연주하기 훈련을 극대화하는 4가지 원칙

기타 연습의 효율은 **무엇을 연습하느냐**보다 **어떻게 연습하느냐**에 달려 있습니다. 목적 있는 반복이 막연한 반복보다 10배 빠릅니다.

1. **문제 구간 집중** — 어려운 2~4마디를 전체 반복보다 10~20회 집중. 문제 구간을 건너뛰는 습관은 영원히 그 구간이 약점으로 남습니다.
2. **녹음으로 객관화** — 스마트폰으로 매 세션 일부를 녹음하고 청취. 연주 중에는 인식 못한 음정·리듬·폼 문제가 녹음에서 명확히 드러납니다.
4. **음악적 맥락 적용** — 연습한 기법을 항상 실제 곡이나 즉흥 연주에 적용. 기법 자체보다 음악 안에서의 사용이 실력으로 이어집니다.

## 기타 집중 연습 루틴

| 구간 | 내용 | 시간 |
|-----|------|------|
| 워밍업 | 크로매틱 운지·스트레칭 | 8분 |
| 기법 드릴 | 오늘의 핵심 기법 집중 반복 | 15분 |

| 곡 적용 | 배운 기법을 실제 곡에 적용 | 12분 |
| 녹음 확인 | 오늘 연습 녹음 후 청취 분석 | 15분 |

### 효율적인 연습을 위한 원칙

### 효율적인 연습 원칙

- **선행 운지 훈련** — 다음 코드를 손가락이 먼저 준비하는 습관. 전환 속도가 2배 이상 개선됨
- **한 줄씩 확인 후 합치기** — 아르페지오나 핑거피킹은 한 줄씩 정확성 확인 후 조합
- **녹음으로 노이즈 확인** — 스마트폰 녹음으로 뮤트 실수·튜닝 이탈을 객관적으로 점검

### 연습 중 자주 하는 실수

1. **왼손 과압으로 인한 피로·부상** — 깨끗한 음이 나는 최소 압력을 찾는 연습. 피렛 가장자리에 밀착시키는 것이 핵심. 과도한 힘은 손 부상의 주원인
2. **연주하지 않는 줄을 뮤트하지 않음** — 오른손 손목 측면 또는 왼손 여분 손가락으로 불필요한 줄 차단. 특히 솔로·아르페지오 시 소음이 크게 들림
3. **시선이 왼손에 고정 → 악보·청중 불가** — 운지를 근육 기억으로 익혀서 손을 보지 않아도 되도록 훈련. 처음부터 시선을 앞에 고정하고 연주하는 습관

### 연습 자가 진단

- [ ] 코드 전환 시 다음 모양을 미리 준비하는가? (선행 운지)
- [ ] 스트로크/피킹이 메트로놈과 일치하는가?
- [ ] 연주하지 않는 줄이 뮤트되어 있는가?

## 4주 기타 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 코드 | Em·Am·G·C·D — 코드 전환 속도 향상 | 40분 |
| 2주차 | 스트로크·핑거 | 8비트 스트로크, 핑거피킹 기본 패턴 | 45분 |
