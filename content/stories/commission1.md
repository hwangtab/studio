faq:
  - q: MR(반주)을 외주로 제작하려면 어떻게 해야 하나요?
    a: >-
      음악 외주 플랫폼(크몽, 숨고, 사운드베터 등)에서 프로듀서를 찾아 의뢰하거나, 지인 소개로 진행합니다. 의뢰 시 참고 곡, 장르,
      분위기, 키(Key), BPM, 사용 목적, 납기일, 예산을 명확히 전달해야 원하는 결과를 얻을 수 있습니다.
  - q: 편곡 의뢰와 MR 제작 의뢰의 차이는 무엇인가요?
    a: >-
      MR 제작은 완전히 새로운 반주를 만드는 작업이고, 편곡은 이미 존재하는 곡의 구조·악기·리듬을 재구성하는 작업입니다. 자작곡에
      반주를 붙이고 싶다면 MR 제작, 기존 곡을 다른 스타일로 바꾸고 싶다면 편곡 의뢰를 합니다.
  - q: 의뢰한 음악의 저작권은 누구에게 있나요?
    a: >-
      계약서에 명시하지 않으면 저작권은 창작자(프로듀서·작곡가)에게 있습니다. 상업적으로 사용하거나 음원 발매를 계획한다면 반드시 '저작권
      양도' 또는 '독점 라이선스' 조건을 계약서에 명시하고, 이를 가격에 반영해야 합니다.
  - q: 음악 외주 플랫폼에서 사기를 피하는 방법은?
    a: >-
      플랫폼 내 에스크로 결제 시스템을 이용하고, 포트폴리오와 리뷰를 꼼꼼히 확인하세요. 착수금은 30~50%만 지급하고 납품 확인 후
      잔금을 지급하는 것이 안전합니다. 작업 범위·수정 횟수·납기일을 문서로 명확히 합의하세요.

## 내가 직접 만들지 않아도 됩니다

보컬은 있는데 반주가 없거나, 곡은 있는데 편곡이 필요하다면 전문 프로듀서·편곡자·작사가에게 외주를 맡길 수 있습니다.

---

## 음악 외주 의뢰 유형

| 의뢰 종류 | 설명 | 평균 금액 (참고) |
|---------|------|--------------|
| MR 제작 | 처음부터 반주 제작 | 20만원~100만원+ |
| 편곡 | 기존 곡 구조·악기 변경 | 10만원~50만원 |
| 작사 | 가사 창작 또는 수정 | 5만원~30만원 |
| 작곡 | 멜로디+가사 창작 | 20만원~100만원+ |
| 믹싱·마스터링 | 녹음 후 음질 처리 | 5만원~30만원 |

> 금액은 의뢰자·경력·작업 복잡도에 따라 크게 다릅니다.

---

## 주요 의뢰 플랫폼 비교

| 플랫폼 | 특징 | 적합한 경우 |
|--------|------|---------|
| 크몽 | 국내 최대 프리랜서 마켓 | MR 제작, 작사·작곡 |
| 숨고 | 견적 비교 가능 | 편곡, 믹싱 |
| 사운드베터 (SoundBetter) | 해외 음악인 풀 | 해외 프로듀서 의뢰 |
| Fiverr | 글로벌 플랫폼 | 영어 가사, 특수 장르 |
| SNS (인스타그램·블로그) | 직접 DM | 포트폴리오 보고 직접 접촉 |

## 의뢰 시 전달해야 할 정보

MR 제작을 의뢰할 때 반드시 전달해야 하는 정보:

유통사 선택은 수수료뿐만 아니라 지원 서비스와 플랫폼 커버리지도 함께 고려하세요.

1. 장르: 발라드, 팝, R&B, 힙합 등
2. 분위기 참고 곡: "이 곡과 비슷한 느낌으로"
3. 키(Key): 예) A 장조, Bb 단조 (모르면 "협의" 표기)
4. BPM: 빠르기 (모르면 참고 곡 제공)
5. 구성: 인트로-1절-코러스-2절-코러스-아웃트로
6. 사용 목적: 개인 연습 / 음원 발매 / SNS 공개
7. 납기일: 언제까지 필요한지
8. 예산: 명확히 제시
9. 수정 횟수: 보통 2~3회 포함 협의

## 저작권 계약 기준

| 계약 유형 | 내용 | 추천 상황 |
|---------|------|---------|
| 저작권 양도 | 모든 권리 의뢰인에게 이전 | 음원 발매, 상업 사용 |
| 독점 라이선스 | 의뢰인만 사용 가능, 저작권은 창작자 보유 | 발매·공연 |
| 비독점 라이선스 | 여러 명에게 판매 가능 | 개인 연습, SNS 비공개 |
| 무약정 | 법적 보호 없음 | ❌ 권장하지 않음 |

## MR 파일 납품 요청 사항

녹음에 사용할 MR을 받을 때 요청해야 할 파일 형식:

- **WAV 44.1kHz/24bit 이상** (압축 없는 고음질)
- **스템 파일** (악기별로 분리된 트랙): 믹싱 단계에서 보컬과 분리하기 위해
- **키 정보** 문서 (어떤 키로 제작했는지 확인)
