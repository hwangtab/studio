## 리드시트 하나로 어떤 곡이든 반주합니다

코드 읽기부터 보컬 반주까지. 방음 개인실에서 피아노 리드시트를 탐색하세요.

피아노 리드시트 훈련의 핵심:
- **코드 기호 즉독**: 리드시트 코드를 즉각 보이싱으로 변환
- **즉흥 반주 패턴**: 장르별 반주 패턴 레퍼토리 확충
- **멜로디 하모나이제이션**: 멜로디에 코드 색채 입히기
- **보컬 반주 균형**: 보컬을 빛나게 하는 반주 다이나믹

## 리드시트 반주를 손에 붙이는 4가지 순서

리드시트에는 멜로디와 코드 기호뿐이라, 나머지는 전부 연주자의 손에서 나옵니다. 그래서 연습도 곡을 통째로 반복하기보다 코드 읽기, 역할 분담, 보이싱, 보컬과의 균형을 하나씩 떼어 쌓는 쪽이 빠릅니다.

1. **열두 키의 기본 코드를 눈 감고 잡기** — 'Fmaj7' 같은 기호를 보고 구성음을 계산하는 동안 박자는 지나갑니다. 코드 기호를 보자마자 손이 가는 위치로 자동화하는 것이 가장 먼저입니다.

2. **오른손 멜로디, 왼손 코드로 역할 나누기** — 처음에는 왼손을 단순한 블록 코드로 두고 오른손 멜로디를 노래하듯 이어 갑니다. 이 분담이 안정되면 그때 왼손에 리듬을 넣습니다.

3. **한 코드를 여러 보이싱으로 바꿔 치기** — 뿌리 위치, 자리바꿈, 텐션 추가, 오픈 보이싱처럼 같은 C 코드를 다섯 가지 모양으로 번갈아 칩니다. 같은 곡을 여러 색으로 칠할 수 있어야 즉흥 반주가 단조로워지지 않습니다.

4. **보컬이 있다면 반주 밀도부터 줄이기** — 보컬 음역과 부딪히지 않게 반주를 보컬보다 작게 두고, 보컬이 쉬는 인트로·아웃트로에서만 피아노 멜로디를 앞으로 꺼냅니다. 너무 복잡하면 보컬이 묻히고 너무 단순하면 음악이 빈약해집니다.

## 리드시트 반주는 코드를 '즉시 소리로' 바꾸는 순발력이에요

리드시트 한 장을 앞에 놓고 그 자리에서 반주를 만들어 내는 건, 악보를 그대로 치는 것과는 완전히 다른 능력이에요. 첫째 조건이 코드를 보자마자 손이 나가는 거예요. 'Fmaj7'이라는 글자를 보고 이게 무슨 음인지 머릿속에서 계산하고 있으면 이미 박자가 지나가 버려요. 그래서 열두 키의 기본 코드 위치를 눈 감고도 잡을 수 있게 자동화하는 게 먼저예요. 이게 리드시트 반주의 알파벳입니다.

그다음이 오른손 멜로디와 왼손 코드를 동시에 굴리는 거예요. 리드시트는 멜로디와 코드 심볼만 적혀 있으니까, 오른손으로 멜로디를 노래하면서 왼손으로 코드를 받쳐 주는 이 역할 분담이 몸에 배야 해요. 처음엔 왼손 코드를 단순한 블록으로만 잡고 오른손 멜로디에 집중하다가, 익숙해지면 왼손에 리듬을 넣어 가세요.

진짜 재미는 보이싱 변형에서 나와요. 같은 C 코드라도 매번 똑같이 잡으면 반주가 단조로워지거든요. 저는 한 코드를 최소 다섯 가지 보이싱으로—뿌리 위치, 자리바꿈, 텐션 추가, 오픈 보이싱 등—바꿔 치는 훈련을 시켜요. 같은 곡을 여러 색으로 칠 수 있게 되면 즉흥 반주의 표현력이 확 넓어져요. 이런 훈련은 눈치 안 보고 같은 구간을 수십 번 반복할 수 있는 공간에서 빨리 늘어요. 스튜디오 놀 방음 개인실에서 리드시트 한 곡을 매번 다른 반주로 쳐 보세요. 팝 곡을 코드만 보고 반주하는 접근은 [팝 피아노 반주](/stories/practice-room-piano-pop-accompaniment1)에서 이어집니다.
