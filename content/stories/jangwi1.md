## 지역별 이동 경로

### 석계역 출발 (1호선)

### 석계역 출발 (1호선)

1. 석계역(1호선) 탑승 (서울 방면)
2. 신도림역에서 2호선 환승 (합정 방면)
3. 합정역에서 6호선 환승
4. 6호선 → 연신내역

- **총 소요시간**: 약 50~60분

### 월곡역·상월곡역 출발 (6호선)

### 월곡역 출발 (6호선)

1. 월곡역(6호선) 탑승 (합정 방면)
2. 고려대 → 안암 → 보문 → 창신 → ... → 합정역 경유
3. 망원 → 마포구청 → ... → DMC → 증산 → 새절 → 구산 → 응암 → 역촌 → 불광 → 독바위 → 연신내역

- **총 소요시간**: 약 60~70분 (6호선 직통)
