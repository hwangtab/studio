### 석계역 출발 (1호선)

### 월곡역 출발 (6호선)

2. 고려대 → 안암 → 보문 → 창신 → ... → 합정역 경유
3. 망원 → 마포구청 → ... → DMC → 증산 → 새절 → 구산 → 응암 → 역촌 → 불광 → 독바위 → 연신내역
