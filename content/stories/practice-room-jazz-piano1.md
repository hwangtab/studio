## 재즈는 규칙 안의 자유입니다

재즈 피아노는 클래식의 정확성보다 즉흥성과 리듬 감각이 핵심입니다. 방음 개인실에서 코드 진행을 탐색하고, 마음껏 즉흥 연주를 시도하세요.

재즈 피아노 연습의 특징:
- **보이싱 다양성**: 같은 코드를 여러 형태로 연주
- **리듬 탐색**: 스윙·보사노바 등 다양한 그루브
- **즉흥성**: 코드 진행 위에 자유로운 멜로디
- **재즈 언어**: 다양한 스탠다드 곡 익히기

---

## 재즈 피아노 기초 요소

### II-V-I 진행 (C장조 기준)

```

Dm7 → G7 → CMaj7
(II도 7화음 → V도 7화음 → I도 장7화음)

연습:
1. 근위치(루트 포지션)로
2. 전위(1전위, 2전위)로
3. 보이싱 변형 (3-7, 7-3 패턴)

```

### 스윙 리듬 훈련

```

악보상 8분음표 = 연주 시 3:1 비율
 ♪♪ → 𝅗𝅥+♩ 느낌
메트로놈 2박·4박에 스냅 연습

```

### 재즈 보이싱

```

CMaj7 기본: C-E-G-B
보이싱 1: 왼손 C-G, 오른손 E-B (3-7 보이싱)
보이싱 2: 텐션 추가 (9th, 11th, 13th)

```

## 재즈 피아노 연습 루틴 (1시간)

| 구간 | 내용 | 시간 |
|-----|------|------|
| 워밍업 | 스케일 + 7th 코드 연습 | 10분 |
| 코드 보이싱 | II-V-I 다양한 키 | 15분 |
| 스탠다드 | 1곡 코드+멜로디 | 20분 |
| 즉흥 탐색 | 블루스 진행 즉흥 | 10분 |
| 리듬 연습 | 스윙 리듬 감각 | 5분 |

---

### 재즈 학습 필수 스탠다드

| 레벨 | 곡명 | 포인트 |
|------|------|--------|
| 입문 | Autumn Leaves | 기본 ii-V-I 진행 |
| 중급 | All The Things You Are | 전조·코드 대리 |
| 고급 | Giant Steps | Coltrane Changes |

### 재즈 연주에서 자주 하는 실수

1. **스케일 나열에 그치는 즉흥 연주** — 짧은 모티프를 발전시키는 "motif development" 연습
2. **코드 진행 외우기에만 집중** — 귀로 코드 들으며 즉흥 연주하는 "이어 트레이닝" 병행
3. **빠른 템포에서만 멋있어 보이려 함** — 느린 블루스 BPM 60에서 표현력 먼저

### 재즈 즉흥 자가 진단

- [ ] ii-V-I 진행 위에서 짧은 모티프를 즉흥 연주할 수 있는가?
- [ ] 코드 진행을 들으면서 음이 맞는지 귀로 확인하는가?
- [ ] 쉬는 공간을 활용해서 음악에 숨을 불어넣는가?

## 4주 피아노 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 다지기 | 하농 1~5번, 스케일 C장조·G장조 | 45분 |
| 2주차 | 곡 파악 | 곡 전체 천천히 손 분리 연습 | 45분 |
| 3주차 | 구간 집중 | 어려운 패시지 3구간 집중, BPM 70→90 | 60분 |
| 4주차 | 완성 | 전곡 연속 연주 + 다이나믹 표현 | 60분 |

**주간 체크포인트:** 1주차: 손 독립적 움직임 확인 / 2주차: 악보 암보 여부 / 3주차: 목표 구간 실수 없이 3회 연속 / 4주차: 처음부터 끝까지 감정 표현 포함

## 연습실에서 더 효과적으로

**피아노 연습실에서만 가능한 연습:**
- 포르테시모(ff) ~ 피아니시모(pp) 최대 다이나믹 폭 표현
- 페달 없이 레가토 연습 후 페달 추가 비교
- 본인 연주를 스마트폰으로 녹음 → 왼손/오른손 밸런스 객관적 확인

---

피아노 스케일과 아르페지오 훈련은 손가락 기민성과 음계 감각을 동시에 향상시킵니다. 모든 장조와 단조 스케일을 양손으로 4옥타브씩 부드럽게 연주할 수 있어야 중급 이상의 곡에서 막힘없이 진행할 수 있습니다. 하논과 체르니 같은 테크닉 교재는 지루할 수 있지만 특정 기법을 집중 훈련하는 데는 여전히 가치가 있습니다. 코드 보이싱을 다양하게 변형하는 연습은 편곡과 즉흥 연주 능력을 함께 키워줍니다.

## 재즈 피아노는 ii-V-I이라는 문법에서 시작됩니다

재즈 피아노를 배우려는 분들이 처음엔 화려한 솔로에 눈이 가는데, 정작 실력의 토대는 ii-V-I 진행이에요. 재즈 스탠더드의 코드 흐름 대부분이 이 세 코드의 조합으로 굴러가거든요. 그래서 저는 이걸 12개 조성 전부에서 생각 없이 칠 수 있을 때까지 손에 붙이라고 합니다. 어느 조로 곡이 튀어도 손이 알아서 움직여야, 비로소 멜로디와 즉흥에 머리를 쓸 여유가 생겨요. 이 문법이 안 되면 아무리 좋은 프레이즈도 그 위에 얹을 수가 없습니다.

문법을 익혔으면 어휘, 즉 레퍼토리를 쌓으세요. 재즈는 스탠더드를 몇 곡이나 외우고 있느냐가 곧 실력입니다. Real Book에서 좋아하는 곡 열 곡을 정해 멜로디와 코드를 완전히 암보하면, 잼 세션에서 어떤 곡이 나와도 낄 수 있어요.

그리고 거장을 카피하세요. Bill Evans의 섬세한 보이싱, Herbie Hancock의 리듬감 같은 건 책으로 못 배웁니다. 좋아하는 연주자의 한 소절을 그대로 따라 쳐 보면 그 손맛이 내 안에 새겨져요. 텐션을 얹은 보이싱을 체계적으로 다루는 법은 [재즈 피아노 보이싱·텐션 코드 연습](/stories/practice-room-piano-jazz-chord1)에서 이어집니다.
