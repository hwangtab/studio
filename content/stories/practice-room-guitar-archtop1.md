# 아치탑 기타·재즈 기타 톤·할로우 바디 세팅 — 음악연습실 완전 가이드

아치탑 기타(Archtop Guitar)는 **재즈의 소리를 정의하는 악기**입니다. Gibson L-5, ES-175, D'Angelico — 이 기타들의 따뜻하고 둥근 톤이 Joe Pass, Wes Montgomery, Jim Hall의 음악을 만들었습니다. 플랫탑과 다른 공명 구조, 험버커 픽업의 따뜻함, 무거운 현 — 이 모든 것이 재즈 기타 톤의 비밀입니다.

---

## 아치탑 기타란?

### 구조와 특징

**아치탑의 물리적 구조:**
```
탑(Top): 아치형으로 굽은 스프루스·메이플
바디: 할로우(Hollow) 또는 세미-할로우
F홀: 양 측면의 F자 형태 사운드홀
넥: 접합(Set Neck) 방식
```

**아치탑 vs 플랫탑 기타:**

| | 아치탑 | 플랫탑 (드레드넛) |
|--|-------|---------------|
| 탑 형태 | 아치형 | 평면 |
| 사운드홀 | F홀 (측면) | 원형 (중앙) |
| 주된 음색 | 따뜻·둥근·미들 | 밝고 투명·서스테인 |
| 주 장르 | 재즈·빅밴드 | 포크·컨트리·블루그래스 |
| 픽업 | 험버커 주로 | 피에조 또는 없음 |

### 대표 아치탑 기타

**빈티지 명기:**
```
Gibson L-5 (1922년~): 가장 오래된 현대 아치탑
Gibson ES-175: 재즈 스탠더드 (Joe Pass 애용)
D'Angelico Excel: 뉴욕 장인의 명기
Epiphone Emperor: 빅밴드 시대의 상징
```

**현대 아치탑:**
```
Gibson ES-335: 세미-할로우 (클래식)
Ibanez AF/AS 시리즈: 합리적 가격
Heritage H-575: 깁슨 출신 장인
```

## 재즈 기타 톤의 비밀

### 험버커 픽업

**험버커 특징:**
```
2개의 코일 → 잡음 상쇄 (hum + buck)
더 두꺼운 톤 → 재즈의 따뜻함
싱글 코일보다 미들·베이스 강조
= 재즈 기타 톤의 핵심
```

**픽업 포지션:**
```
넥 픽업: 따뜻하고 둥근 (재즈에 주로)
브릿지 픽업: 밝고 선명 (록 리프에)
재즈: 대부분 넥 픽업 사용
```

### 무거운 현 (Heavy Strings)

**재즈 기타 현 게이지:**
```
표준 일렉: .009-.042 (얇음)
재즈 권장: .012-.052 또는 .013-.056 (두꺼움)
```

**무거운 현의 장점:**
```
더 두꺼운 톤 (더 많은 배음)
강한 어택
풍부한 서스테인
= 재즈의 풀(full) 톤
```

### 앰프 세팅

**재즈 클린 톤 세팅:**
```
게인(Gain): 낮게 (클린 유지)
베이스(Bass): 중간~높음 (따뜻함)
미들(Mid): 중간 (존재감)
트레블(Treble): 낮게 (따뜻함, 거친 음 제거)
리버브: 약간 (공간감)
```

**Fender, Roland Jazz Chorus 앰프:**
```
Jazz Chorus (JC-120): 재즈 기타리스트의 정석
= 클린하고 투명한 코러스 사운드
```

## Joe Pass 스타일

### 솔로 기타의 거장

Joe Pass(Herb Ellis 듀오, Oscar Peterson 트리오):
- **코드 멜로디(Chord Melody):** 멜로디와 코드를 동시에
- **왈킹 베이스:** 기타 혼자 베이스 라인 + 멜로디
- **선율적 단음:** 단음 솔로가 마치 노래처럼

**Joe Pass 코드 형태:**
```
7th 코드 다양한 voicing:
Dm7: X-5-7-5-6-5 (첫 역전형)
G7:  3-5-3-4-3-3 (2nd inversion + 7th)
= 전위형을 자유롭게 사용
```

## Wes Montgomery 스타일

### 엄지와 옥타브

Wes Montgomery(비블리오그래피: 엄지로만 연주!):
- **엄지 연주:** 픽 없이 엄지로만 → 따뜻하고 부드러운 톤
- **옥타브 주법:** 멜로디를 8도 간격 동시 연주
- **블록 코드:** 멜로디에 두꺼운 코드 겹치기

**Wes 옥타브 포지션:**
```
E줄 멜로디 + G줄 옥타브 (1,3번 줄):
위치 예시: 5프렛 E줄 A음 + 5프렛 G줄 A음 동시
중간 줄 (A, D줄) 뮤트 = 깨끗한 옥타브
```

## 재즈 기타 코드 보이싱

### 재즈 코드 기본 형태

**Drop 2 보이싱:**
```
클로즈드 Cmaj7: C-E-G-B (2번 음 내림)
Drop 2: C-G-B-E (2번째 음인 E를 아래 옥타브로)
= 기타 4줄에 맞는 넓은 보이싱
```

**재즈 코드 필수 형태:**
```
maj7: 루트-3도-6도-maj7 (6줄 사용)
m7:  루트-b3-5도-b7
7:   루트-3도-b7-9도 (9 추가 버전)
m7b5: 루트-b3-b5-b7
```

### 코드 멜로디 구성

**멜로디를 최고음으로:**
```
멜로디 음을 가장 높은 줄에
아래 줄들: 해당 코드 보이싱
= 코드 + 멜로디 동시 연주
```

## Jim Hall 스타일

### 미니멀한 재즈 기타

Jim Hall(Bill Evans 트리오, Sonny Rollins 듀오):
- **공간:** 빈 공간을 두려워하지 않음
- **다이나믹:** 크고 작음의 극적 대비
- **보이싱:** 3~4음의 간결한 보이싱

**Jim Hall 미니멀 보이싱:**
```
Cmaj7: X-3-2-0-0-0 (열린 현 활용)
= 3개 음만으로 코드 표현
```

## 음악연습실 아치탑 기타 연습

### 60분 루틴

**1. 재즈 코드 보이싱 (15분)**
   - Drop 2 maj7, m7, 7 형태 연습
   - ii-V-I 코드 보이싱 연결
   - 넥 픽업 클린 톤으로 (재즈 앰프 세팅)

**2. 옥타브 주법 (15분)**
   - Wes Montgomery 옥타브 기본
   - ii-V-I 위 옥타브 멜로디
   - 중간 줄 뮤트 정확히

**3. 코드 멜로디 입문 (15분)**
   - 간단한 멜로디 + 코드 동시
   - "Autumn Leaves" 앞 4마디
   - Joe Pass 스타일 전위형 활용

**4. 재즈 리듬 컴핑 (15분)**
   - 페달을 이용한 4분음표 컴핑
   - 싱코페이션 패턴
   - 피아노나 드럼과 함께 컴핑 시뮬레이션

## 마무리

아치탑 재즈 기타는 **재즈 역사의 소리**입니다. Joe Pass가 "기타는 어디서도 잘 어울리는 악기"라고 했듯, 아치탑의 따뜻한 험버커 톤은 어떤 편성에서도 황금빛으로 빛납니다. 무거운 현, 클린 앰프, 넥 픽업 — 이 세 가지가 당신의 재즈 톤을 완성합니다.
