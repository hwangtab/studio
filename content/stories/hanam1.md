      제한적입니다. 서울 연신내의 스튜디오 놀까지 약 1시간~1시간 20분 내에 이용하실 수 있습니다.

## 경기 동부에서 서울 전문 녹음실 이용하기

하남·구리·광주 주민들이 전문 보컬 녹음을 위해 서울의 스튜디오 놀을 방문합니다. 5호선·경의중앙선·경강선을 통해 연신내역까지 접근할 수 있습니다.

---

## 각 지역에서 스튜디오 놀까지

| 출발지 | 교통편 | 소요 시간 |
|--------|--------|---------|
| 하남검단산역 | 5호선 → 공덕역 → 6호선 연신내역 | 약 55~65분 |
| 미사역 | 5호선 → 공덕역 → 6호선 | 약 50~60분 |
| 구리역 | 경의중앙선 → 왕십리 → 5호선 공덕 → 6호선 | 약 50~60분 |
| 양원역 | 경의중앙선 → 왕십리 → 5호선 공덕 → 6호선 | 약 55~65분 |
| 광주역(경기) | 경강선 → 판교 → 신분당선 강남 → 2호선 합정 → 6호선 | 약 70~80분 |
| 이매역 | 분당선 → 왕십리 → 5호선 공덕 → 6호선 | 약 65~75분 |

**스튜디오 주소**: 서울특별시 은평구 (연신내역 3번 출구 도보 5분)

| 서비스 | 내용 |
|--------|------|
| 보컬 녹음 | Neumann U87 AI, 흡음 부스, 1:1 엔지니어 |
| 믹싱 | 보컬 + MR 스템 통합, 2라운드 수정 |
| 마스터링 | 스트리밍 기준 음압 최적화 |
| 패키지 | 녹음+믹싱+마스터링 합산 견적 |

## 하남에서 스튜디오 놀을 이용한다면

하남에서는 5호선 연장선 또는 버스로 약 1시간~1시간 20분 거리입니다. 위례·미사 신도시 거주 직장인 아마추어 뮤지션들의 주말 세션 이용이 꾸준합니다. 방문 전 카카오톡으로 미리 일정과 준비 자료를 공유해두시면 세션이 효율적으로 진행됩니다.

---

### 녹음 세션 공통 체크리스트

**준비 단계**
- [ ] 세션 목표 명확히 설정 (완성할 구간·트랙 수)
- [ ] 모든 파일·장비 사전 점검 완료
- [ ] 아티스트 컨디션 확인 (보컬: 목 상태, 악기: 튜닝)

**세션 중**
- [ ] 테이크별 메모 (베스트/리테이크 표시)
- [ ] 문제 구간 즉시 인식하고 재녹음 결정
- [ ] 세션 종료 30분 전 마무리 시작

**후반 작업**
- [ ] 원본 파일 즉시 백업
- [ ] 믹싱 전 24시간 이상 청취 공백 유지

### 세션 효율을 높이는 팁

1. **가장 어려운 구간을 세션 초반에** — 에너지가 최고일 때 어려운 것 먼저
2. **구간 분리 녹음** — 전체 통으로 반복보다 구간별 완성 후 연결
3. **즉각 피드백** — 녹음 직후 헤드폰으로 바로 모니터링
