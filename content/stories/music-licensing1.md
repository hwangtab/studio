faq:
  - q: 음악 라이센싱이란 무엇인가요?
    a: >-
      음악 라이센싱은 저작권자(작곡가·가수)가 제3자에게 자신의 음악을 특정 용도로 사용할 수 있는 허락을 부여하고 대가를 받는 것입니다.
      TV 광고, 영화, 게임, 유튜브 영상 등에 음악이 사용될 때 라이센스 계약이 필요합니다.
  - q: 싱크 라이센싱(Sync Licensing)이란?
    a: >-
      영상 미디어(영화, 드라마, 광고, 유튜브 영상)와 음악을 동기화(Synchronize)하여 사용하는 라이센스입니다. 싱크 권리는
      공연권(저작인접권)과 마스터 라이센스 두 가지로 구성됩니다.
  - q: 마스터 라이센스와 공연권의 차이는?
    a: >-
      마스터 라이센스는 특정 녹음본(마스터 파일)의 사용 허가입니다. 공연권(작곡·작사 저작권)은 곡 자체의 사용 허가입니다. 커버곡을
      사용할 경우 원작곡자에게 공연권, 커버 녹음 아티스트에게 마스터 라이센스를 각각 받아야 합니다.
  - q: 인디 아티스트가 싱크 라이센싱을 받으려면?
    a: >-
      싱크 대행사(Musicbed, Artlist, Epidemic Sound, Marmoset Music)에 등록하거나, 음악 감독에게
      직접 피칭하는 방법이 있습니다. 국내는 한국음악저작권협회(KOMCA) 등록 후 싱크 대행사나 음악 에이전시를 통해 진행합니다.

## 음악 라이센싱 — 내 음악으로 수익 만들기

음악 라이센싱은 스트리밍 수익 외에 아티스트가 수익을 창출할 수 있는 중요한 채널입니다.

---

## 라이센스 종류

세금 신고와 수익 정산 주기를 미리 파악해두면 현금 흐름 관리에 도움이 됩니다.

### 음악 라이센스 주요 유형

1. 싱크 라이센스 (Sync License)
   - 영상 미디어와 동기화 사용
   - TV·영화·광고·유튜브·게임
   - 일회성 선불 요금 또는 로열티

2. 마스터 라이센스 (Master License)
   - 특정 녹음 파일(마스터) 사용 허가
   - 마스터 소유자(대부분 아티스트/레이블)가 발행

3. 공연권 (Performance Right)
   - 공공장소·방송·스트리밍에서 음악 사용
   - KOMCA·RIAK을 통해 자동 징수·분배

4. 기계적 복제권 (Mechanical License)
   - 음악을 음반·디지털 파일로 복제
   - 커버곡 유통 시 필요

---

## 싱크 라이센싱 수익 구조

NFT·Web3 음악 플랫폼은 빠르게 변화하므로 최신 정보를 지속적으로 확인해야 합니다.

### 싱크 사용료 범위

- **TV 드라마 배경음악**: 수십만~수백만 원
- **TV 광고 (전국 방영)**: 수백만~수천만 원
- **영화 OST 삽입**: 수십만~수백만 원
유튜브 영상 (구독자 100만 이상): 수십만 원~

### 수익 배분

마스터 라이센스 → 아티스트(마스터 소유자)
공연권 → 작곡가·작사가 (KOMCA 분배)

---

## 싱크 대행사 등록

### 해외 주요 플랫폼

**Musicbed (musicbed.com)**
- 전문 영상 크리에이터·기업 대상
- 선별적 심사, 품질 높음

**Artlist (artlist.io)**
- 유튜브 크리에이터 많이 사용
- 연간 구독 기반

**Epidemic Sound**
- 유튜브·방송 라이센스 특화
- 월정액 구독 모델

### 국내 경로

- 음악 에이전시 또는 싱크 대행사 등록
- CF 음악 감독 직접 네트워킹
- 방송국 음악 팀 직접 피칭

---

## 직접 라이센싱 방법

### 직접 라이센싱 계약 구조

1. 요청인: 라이센스 신청 (이메일 또는 플랫폼)
2. 아티스트: 사용 조건 협의
   - 사용 매체 (TV/온라인/광고)
   - 지역 (국내/글로벌)
   - 기간 (1년/3년/영구)
   - 독점/비독점
3. 계약서 작성 및 서명
4. 사용료 수령

### 주의

저작권 등록(KOMCA) 완료 후 라이센싱
저작권 없이 계약 시 분쟁 위험

---

## KOMCA 저작권 등록과 연계

협업 시 권리 분배를 문서로 명확히 해두면 이후 갈등을 예방할 수 있습니다.

### KOMCA 등록 완료 후

- 스트리밍·방송 공연권료 자동 분배
- 싱크 사용 시 KOMCA 통해 공연권료 별도 청구 가능
- 국제 저작권 단체 (PRS, ASCAP 등)와 상호 징수

### KOMCA 등록 방법

komca.or.kr → 저작물 등록 신청
작곡·작사·편곡자 정보 입력 → 승인

---

### 시작 전 체크리스트

- [ ] 유튜브 Content ID 등록 가능한 음원 배포사를 선택하고 계약 조건 확인
- [ ] 레퍼런스 트랙 2~3개 선정 완료
- [ ] 음원 사용 허가 범위 체크리스트 준비됨
