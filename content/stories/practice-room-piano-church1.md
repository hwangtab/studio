# 교회 피아노·찬양 반주·코드 반주법·예배 피아노 — 음악연습실 완전 가이드

교회 피아노(Church Piano)는 **예배와 찬양을 음악으로 섬기는 반주법**입니다. 악보 그대로 따르는 클래식 피아노와 달리, 교회 피아노는 코드 기반의 즉흥 반주, 다양한 찬양팀 스타일 적응, 회중의 호흡에 맞추는 섬김의 음악입니다. 현대 워십 밴드부터 전통 성가대까지, 교회 피아노는 다양한 상황에 유연하게 적응해야 합니다.

---

## 교회 피아노란?

### 섬김의 반주

**교회 피아노의 역할:**
```
예배 인도 (전주·후주·간주)
찬양팀 반주 (리듬·화성 지지)
솔리스트 반주 (독창·성가대)
회중 찬송 반주 (4부 화성)
```

**교회 피아노 vs 클래식 피아노:**
```
클래식: 악보 그대로 정확하게
교회: 코드 보고 즉흥 반주
= 클래식보다 유연성이 중요
```

---

## 코드 반주 기초

### 리드 시트로 반주하기

**리드 시트(Lead Sheet):**
```
멜로디 + 코드 이름만 있는 악보
= 피아니스트가 반주를 만들어야 함
```

**기본 반주 패턴:**
```
왼손: 루트 음 또는 루트-5도
오른손: 3성부 코드 + 멜로디 (또는 코드만)
```

**C 코드 기본 반주:**
```
왼손: C (1박, 3박)
오른손: C-E-G 코드 (2박, 4박)
= 단순하지만 완전한 반주
```

**오른손 코드 보이싱:**
```
클로즈 보이싱: C-E-G (밀집)
오픈 보이싱: C-G-E (공간)
= 찬양팀 스타일에 따라 선택
```

---

## 찬양팀 스타일 반주

### 현대 워십 피아노

**현대 워십 피아노 특징:**
```
단순한 아르페지오 반주
서스테인 페달 많이 사용
리버브 이펙터로 공간감
= 뉴에이지 + 복음 느낌
```

**워십 아르페지오 패턴:**
```
G 코드: G-D-G-B-D-G (상행)
왼손: G 베이스
= 현대 찬양 특유의 공간감
```

**빌드업 반주:**
```
1절: 단순한 아르페지오 (작게)
2절: 코드 + 멜로디 (중간)
코러스: 풀 코드 + 볼륨업 (크게)
= 예배의 흐름을 음악으로
```

---

## 전통 성가 반주

### 4부 화성 반주

**전통 성가 반주:**
```
소프라노(S) - 알토(A) - 테너(T) - 베이스(B)
오른손: S + A 두 성부
왼손: T + B 두 성부
```

**SATB 피아노 반주:**
```
오른손 고음: 소프라노 멜로디
오른손 저음: 알토 하모니
왼손 고음: 테너 하모니
왼손 저음: 베이스 라인
```

**성가 반주 다이나믹:**
```
인트로: 풀 다이나믹으로 피아노 소개
1절: 중간 볼륨 (목소리 지지)
마지막 절: 크게 (클라이맥스)
```

---

## 코드 전환과 연결

### 부드러운 화음 이동

**코드 전환 기법:**
```
손 위치 최소화: 가까운 보이싱 선택
공통음 유지: 두 코드에 공통된 음 유지
= 부드러운 성부 진행
```

**C → Am 전환:**
```
C: C-E-G
Am: A-E-C (공통음 E 유지!)
= 손이 거의 안 움직임
```

**G7 → C 해결:**
```
G7: G-B-F
C: G-C-E (G 유지, B→C, F→E)
= 자연스러운 화음 해결
```

---

## 즉흥 오르나멘트

### 찬양을 풍성하게

**트릴 추가:**
```
멜로디의 중요한 음에 트릴
= 성악 장식음 같은 느낌
```

**선율 보완:**
```
보컬 쉬는 부분에 피아노 필인
= 반주가 노래를 "답"해줌
```

**간주 즉흥:**
```
절과 절 사이 피아노 간주
코드 진행 위 자유로운 멜로디
= 회중이 묵상할 시간 제공
```

---

## 음악연습실 교회 피아노 연습

### 60분 루틴

**1. 기본 코드 반주 (15분)**
   - G-D-Em-C 진행 (워십 단골)
   - 왼손 루트 + 오른손 코드
   - 페달 사용하며 연결감

**2. 아르페지오 워십 패턴 (15분)**
   - 같은 진행으로 아르페지오 반주
   - 빌드업: 조용히 → 점점 크게
   - 다이나믹 훈련

**3. SATB 성가 반주 (15분)**
   - 간단한 성가 악보 (4부 화성)
   - 오른손 S+A, 왼손 T+B
   - 균일한 4성부 다이나믹

**4. 즉흥 간주 (15분)**
   - G-D-Em-C 위 자유로운 멜로디
   - 회중이 묵상할 분위기
   - 공간과 침묵 활용

## 마무리

교회 피아노는 **음악으로 드리는 기도**입니다. 교회 피아노 반주자가 "내 연주가 회중의 마음을 열면 충분하다"고 했듯, 기술보다 섬김의 마음이 교회 피아니스트의 핵심입니다. 단순한 코드 반주 하나가 예배를 살아있게 만들 수 있습니다.

은평구 24시간 음악연습실에서 G-D-Em-C 코드 반주부터 시작하세요. 손이 코드를 자연스럽게 찾는 날, 예배 반주가 자유로워집니다.
