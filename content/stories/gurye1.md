## 구례에서 KTX로 서울까지

구례는 전남 지리산 자락의 도시로, 순천역 KTX를 통해 서울과 약 3시간 30분대로 연결됩니다.

---

## 구례 → 연신내 이동 경로

### KTX 순천역 경유 (권장)

```
① 구례 → 순천역 (버스 약 40~50분)
② 순천역 KTX 탑승 (서울역 방면, 약 2시간 30~40분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간 40분~4시간
```

---

## 당일 왕복 일정 예시 (구례 기준)

```
오전 5시 50분 구례 출발 → 순천역 이동
오전 6시 40분 순천역 KTX 출발
→ 오전 9시 30분 서울역 도착
→ 오전 10시 10분 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 서울역 출발
→ 오후 4시 50분 순천역 도착
→ 오후 5시 40분 구례 도착
```
