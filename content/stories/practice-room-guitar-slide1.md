# 기타 슬라이드·보틀넥 주법 — 음악연습실 완전 가이드

슬라이드 기타(Slide Guitar)는 유리병, 금속 튜브, 도자기 등을 손가락에 끼워 프렛을 직접 짚지 않고 연주하는 기법입니다. 미시시피 블루스에서 탄생해 록, 컨트리, 레게, 하와이안까지 폭넓게 활용됩니다. **보틀넥(Bottleneck)**이라는 이름은 초기에 실제 유리병 목 부분을 사용한 데서 유래합니다.

---

## 슬라이드 도구 선택

### 슬라이드 재질별 음색

**유리(Glass):**
- 따뜻하고 둥근 음색
- 블루스, 포크에 적합
- 대표: Dunlop #215 Coricidin Bottle

**금속(Steel):**
- 밝고 날카로운 음색
- 록, 컨트리에 적합
- 대표: Dunlop #222 Steel Slide

**브라스(Brass):**
- 풍성하고 따뜻한 중간 음색
- 다목적 사용

**도자기(Ceramic):**
- 유리와 금속의 중간
- 독특한 따뜻함

### 슬라이드 끼는 손가락

**소지(새끼손가락):** 가장 일반적
- 나머지 손가락이 자유로워 코드 연주 가능
- Duane Allman, Derek Trucks 방식

**약지(ring finger):** 유연성
- 더 강한 압력 가능
- 중지와 함께 뮤팅 용이

## 슬라이드 기본 기법

### 인토네이션

슬라이드의 가장 어려운 부분:

```
원칙:
슬라이드를 프렛 위에 정확히 놓기
프렛 바로 위 (다음 프렛 아쪽이 아닌 위)

연습:
한 현에서 5프렛에 슬라이드 → 튜너로 확인
정확하면 슬라이드가 5프렛 위에 정확히 위치
```

### 뮤팅

슬라이드 연주에서 불필요한 소리 차단:

**오른손 뮤팅:**
- 피킹 손의 손바닥으로 슬라이드 뒷부분 현 뮤팅
- 피킹 후 즉시 뮤팅

**왼손 뮤팅:**
- 슬라이드 뒷 손가락들로 슬라이드 뒤쪽 현 뮤팅

## 슬라이드 연주 기법

### 글라이드(Glide)

음에서 음으로 부드럽게 미끄러지기:

```
5프렛(A) → 7프렛(B): 슬라이드 서서히 이동
```

**업 글라이드:** 낮은 음에서 높은 음으로
**다운 글라이드:** 높은 음에서 낮은 음으로

### 비브라토 (슬라이드)

슬라이드를 작게 앞뒤로 흔들어 비브라토:

```
7프렛 위에서 슬라이드 미세하게 좌우로 흔들기
음정이 오르내리는 비브라토 효과
```

### 미끄러짐 진입

목표음으로 미끄러지며 진입:

```
2-3프렛 아래에서 슬라이드 → 목표음으로 글라이드 진입
더 표현력 있는 시작
```

## 오픈 튜닝과 슬라이드

### 오픈 G (DGDGBD)

슬라이드 기타에 가장 많이 사용되는 오픈 튜닝:
```
6현: D
5현: G
4현: D
3현: G
2현: B
1현: D
```

**오픈 G 화음:**
- 전체 개방선 = G 메이저
- 12프렛 바레 = G (높은 옥타브)

**롤링 스톤스 "Honky Tonk Women" 슬라이드 리프:**
Keith Richards의 오픈 G 슬라이드 스타일

### 오픈 D (DADF#AD)

```
6현: D, 5현: A, 4현: D, 3현: F#, 2현: A, 1현: D
전체 개방 = D 메이저
```

---

## 블루스 슬라이드 기법

### 델타 블루스 스타일

미시시피 델타 블루스의 원초적 슬라이드:

```
보컬과 기타의 대화:
보컬 프레이즈 → 슬라이드 응답
슬라이드 프레이즈 → 보컬 응답
```

**Robert Johnson 스타일:**
- 오픈 D 튜닝
- 낮은 E, A 현에서 드론 유지
- 높은 현에서 슬라이드 멜로디

---

## 음악연습실 슬라이드 루틴

### 입문 단계 (60분)

**1. 인토네이션 훈련 (15분)**
- 한 현에서 5프렛 → 7프렛 → 12프렛
- 튜너로 정확도 확인

**2. 글라이드 연습 (20분)**
- 오픈 G 튜닝에서 업/다운 글라이드
- 비브라토 추가

**3. 뮤팅 훈련 (15분)**
- 양손 뮤팅 동시 적용
- 깨끗한 단음 슬라이드 확보

**4. 블루스 리프 (10분)**
- 기본 12마디 블루스 슬라이드 적용
