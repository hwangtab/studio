## 슬라이드가 기타를 노래하게 만듭니다

인토네이션부터 블루스 표현까지. 방음 개인실에서 슬라이드 기타 주법을 탐색하세요.

기타 슬라이드 훈련의 핵심:
- **정확한 포지션**: 프렛 바 위에 슬라이드를 정확히 위치
- **뮤팅 완벽**: 슬라이드 뒤 손가락으로 불필요한 현 뮤팅
- **블루스 표현**: 포르타멘토·비브라토로 목소리 같은 표현
- **오픈 튜닝**: 오픈 G·D 튜닝으로 슬라이드 코드 연주

|------|------|------|
| 포르타멘토 | 음과 음 사이 이동 | 매끄러운 연결 |
| 비브라토 | 슬라이드 좌우 흔들기 | 음정 표현 |
| 다이나믹 | 슬라이드 압력 조절 | 음량 변화 |
| 오픈 바레 | 전체 현 동시 슬라이드 | 코드 이동 |
