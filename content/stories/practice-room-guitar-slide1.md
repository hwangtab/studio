# 기타 슬라이드·보틀넥 완전 가이드 — 연신내 음악연습실 실전 연습

슬라이드 기타(Slide Guitar)는 금속 바(Bar) 또는 보틀넥(Bottleneck)을 손가락에 끼우고 기타 줄 위를 미끄러뜨리며 연주하는 독특한 기법입니다. 피치가 연속적으로 변하는 "글리산도" 소리와 인간 목소리를 닮은 흐느끼는 느낌이 특징으로, 블루스·컨트리·록에서 빠질 수 없는 기법입니다.

## 슬라이드 기타의 역사

슬라이드 기타는 미국 남부 블루스 전통에서 기원합니다. 초기 뮤지션들은 와인 보틀이나 나이프를 줄에 대고 연주했으며, 이것이 "보틀넥 기타"의 어원입니다. 델타 블루스(Delta Blues)의 Robert Johnson, Son House, Elmore James가 슬라이드 기타를 발전시켰습니다.

## 슬라이드 바(Slide Bar) 선택

### 금속 슬라이드
- **강철(Steel)**: 밝고 선명한 소리, 단단한 어택
- **황동(Brass)**: 따뜻하고 풍부한 중역대
- **크롬**: 중간적 밸런스

### 유리 슬라이드 (보틀넥)
- 더 부드럽고 따뜻한 소리
- 블루스·록에서 선호하는 소재
- 유리 두께에 따라 중량감 차이

### 어느 손가락에 착용할까
- **소지(새끼손가락)**: 나머지 손가락으로 프렛 연주 가능 — 가장 많이 사용
- **약지(네 번째 손가락)**: 약지 힘이 필요하나 안정적
- **중지(세 번째 손가락)**: 개인 취향

## 오픈 튜닝(Open Tuning)

슬라이드 기타는 오픈 튜닝에서 진가를 발휘합니다. 오픈 튜닝은 기타를 개방현으로 쳤을 때 특정 코드(주로 E 또는 G)가 울리도록 조율하는 방식입니다.

### 오픈 E 튜닝
```
6번줄(E), 5번줄(B→), 4번줄(E), 3번줄(G#), 2번줄(B), 1번줄(E)
```
개방현을 치면 E 메이저 코드가 울립니다.

### 오픈 G 튜닝
```
6번줄(E→D), 5번줄(A→), 4번줄(D), 3번줄(G), 2번줄(B), 1번줄(E→D)
```
개방현을 치면 G 메이저 코드가 울립니다.
Rolling Stones의 Keith Richards가 즐겨 사용하는 튜닝입니다.

## 슬라이드 기본 기법

### 올바른 슬라이드 포지션
1. 슬라이드를 프렛 바로 위(정확히 프렛 금속 위)에 위치
2. 줄에 닿되 너무 세게 누르지 않기 — 줄과 프렛보드 사이에 약간 떠 있는 느낌
3. 슬라이드가 눕지 않고 줄에 수직으로 닿아야 정확한 음정

### 슬라이드 인(Slide In)
낮은 피치에서 목표 음으로 미끄러져 올라오는 어프로치입니다.
```
5프렛 → 7프렛 (슬라이드 업)
```

### 슬라이드 아웃(Slide Out)
목표 음에서 높은 피치나 낮은 피치로 빠져나가는 기법입니다.
```
7프렛에서 → 9프렛으로 슬라이드 업 아웃
7프렛에서 → 5프렛으로 슬라이드 다운 아웃
```

## 슬라이드 비브라토

슬라이드 비브라토는 슬라이드를 프렛 위에서 앞뒤로 미세하게 흔드는 기법입니다.

### 비브라토 방법
1. 목표 음에 슬라이드를 위치
2. 손목을 축으로 슬라이드를 앞뒤 1~2mm 범위로 빠르게 진동
3. 음의 끝부분에 비브라토가 시작되는 것이 자연스러움

슬라이드 비브라토는 기타 본체 비브라토보다 더 폭넓고 성악적인 느낌을 줍니다.

## 왼손 뮤트(Mute) 조절

슬라이드 연주에서 가장 중요한 기술 중 하나는 불필요한 줄 소리를 뮤트하는 것입니다.

### 오른손 손가락 뮤트
오른손 손가락(피킹하지 않는 손가락)을 줄에 살짝 얹어 슬라이드 뒤의 불필요한 진동을 막습니다.

### 슬라이드 뒤 왼손 뮤트
슬라이드가 지나간 프렛 뒤에 나머지 손가락을 가볍게 얹어 줄 진동을 차단합니다.

## 오픈 튜닝 코드 포지션

오픈 E 튜닝에서 슬라이드 위치에 따른 코드:
- **5프렛**: A 메이저
- **7프렛**: B 메이저
- **12프렛**: E 메이저 (옥타브 위)

이 세 포지션만으로 E 조성의 I(E) - IV(A) - V(B) 블루스 진행이 가능합니다.

## 연신내 음악연습실에서 슬라이드 기타 연습 루틴

| 시간 | 내용 |
|-----|------|
| 0~10분 | 오픈 E 또는 G 튜닝 확인 |
| 10~20분 | 단일 줄 슬라이드 인·아웃 기초 (5·7·12프렛) |
| 20~30분 | 슬라이드 비브라토 훈련 |
| 30~40분 | 오른손·왼손 뮤트 조합 훈련 |
| 40~55분 | 블루스 12마디 슬라이드 라인 연주 |
| 55~60분 | 오픈 코드 + 슬라이드 멜로디 통합 |

## 슬라이드 기타 흔한 실수

### 음정이 불정확한 문제
슬라이드가 프렛 위에 정확히 위치하지 않으면 음정이 흔들립니다. 처음에는 느린 템포로 각 프렛에서 멈추며 음정을 튜너로 확인하는 훈련이 필수입니다.

### 슬라이드가 너무 세게 눌리는 문제
슬라이드를 세게 누르면 프렛보드 노이즈와 과도한 마찰음이 납니다. "기대는" 것처럼 가볍게 줄에 닿는 느낌을 목표로 하세요.

## 추천 레퍼런스

- **Robert Johnson**: 델타 블루스 슬라이드의 원형
- **Elmore James**: 전기 슬라이드 기타의 선구자
- **Ry Cooder**: 다양한 오픈 튜닝 슬라이드의 현대적 표현
- **Duane Allman**: 록 슬라이드 기타의 교과서 (Allman Brothers)

## 마무리

슬라이드 기타는 처음에 음정 불안정으로 좌절하기 쉽지만, 꾸준한 뮤트·비브라토 훈련으로 슬라이드 기타만의 울부짖는 소리가 완성됩니다. 연신내 음악연습실에서 충분한 볼륨으로 슬라이드의 공명을 느끼며 연습하세요.
