## 영등포·구로에서 전문 녹음실 찾기

영등포·신도림·구로·금천 주민들이 전문 보컬 녹음과 음반 제작을 위해 스튜디오 놀을 방문합니다. 2호선 합정역을 통해 연신내까지 30분 내 접근이 가능합니다.

---

## 각 지역에서 스튜디오 놀까지

| 출발지 | 교통편 | 소요 시간 |
|--------|--------|---------|
| 영등포역 | 2호선(or 1호선) → 합정역 → 6호선 연신내역 | 약 25~30분 |
| 신도림역 | 2호선 → 합정역 → 6호선 | 약 25~30분 |
| 구로디지털단지역 | 2호선 → 합정역 → 6호선 | 약 30~35분 |
| 대림역 | 2호선 → 합정역 → 6호선 | 약 25~30분 |
| 문래역 | 2호선 → 합정역 → 6호선 | 약 20~25분 |
| 가산디지털단지역 | 1호선·7호선 → 신도림 → 2호선 합정 → 6호선 | 약 35~40분 |
| 금천구청역 | 1호선 → 신도림 → 2호선 합정 → 6호선 | 약 40~45분 |

**스튜디오 주소**: 서울특별시 은평구 (연신내역 3번 출구 도보 5분)

| 서비스 | 내용 |

| 보컬 녹음 | Neumann U87 AI, 흡음 부스, 1:1 엔지니어 |
| 믹싱 | 보컬 + MR 스템 통합, 2라운드 수정 |
