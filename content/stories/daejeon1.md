## 대전에서 KTX로 50분

대전은 KTX로 서울과 가장 가까운 지방 대도시입니다. 반나절 시간이면 서울 스튜디오 세션을 충분히 마치고 돌아올 수 있습니다.

---

## 대전 → 연신내 이동 경로

```
① 대전역에서 KTX 탑승 (서울역 방면)
② 서울역 도착 (약 50~60분)
③ 1호선 서울역 → 용산역 환승 → 경의중앙선
   또는 2호선 합정역 → 6호선 연신내역
④ 연신내역 3번 출구 → 도보 5분

총 소요시간: 약 1시간 30분~2시간
```

---

## 당일 왕복 일정 예시 (대전 기준)

```
오전 8시 대전역 출발 (KTX)
→ 오전 9시 서울역 도착
→ 오전 9시 40분 연신내역 도착
→ 오전 10시 세션 시작 (2~3시간)
→ 오후 12시~1시 세션 완료
→ 오후 1시 30분 서울역 출발
→ 오후 2시 30분 대전역 도착
```

---

## 온라인 파일 의뢰 서비스

```
대전 현지 녹음실에서 드라이 보컬 WAV 녹음
→ WeTransfer 또는 구글 드라이브 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
