## 성북구 돈암·성신여대에서 연신내 스튜디오 놀까지

성북구 돈암동·삼선동·성신여대 지역은 4호선 성신여대입구역·한성대입구역을 통해 동대문역사문화공원역에서 6호선으로 환승, 연신내역까지 약 35~45분에 이동할 수 있습니다.

---

## 돈암·성신여대 → 연신내 이동 경로

### 4호선 경유 (권장)

```
① 성신여대입구역 또는 한성대입구역(4호선) 탑승
② 동대문역사문화공원역 하차 → 6호선 환승
③ 6호선 탑승 → 연신내역 하차

총 소요시간: 약 35~45분
```

### 버스 + 지하철 경유

```
① 돈암동·삼선동에서 버스로 성신여대입구역 이동
② 이후 4호선→6호선 경유 동일
```

---

## 성북구 남부 지역별 소요 시간

| 출발 지점 | 경로 | 소요 시간 |
|---------|------|---------|
| 성신여대입구역 (4호선) | 동대문역사문화공원 → 6호선 | 약 35~45분 |
| 한성대입구역 (4호선) | 동대문역사문화공원 → 6호선 | 약 35~45분 |
| 돈암동 (버스+지하철) | 성신여대입구역 → 4호선 경유 | 약 40~50분 |

## 당일 왕복 일정 예시 (성신여대입구역 기준)

```
오전 10시 성신여대입구역 출발 (4호선)
→ 오전 10시 40분 연신내역 도착
→ 오전 10시 50분 세션 시작 (2시간)
→ 오후 12시 50분 세션 완료
→ 오후 1시 30분 연신내역 출발
→ 오후 2시 10분 성신여대입구역 도착
```
