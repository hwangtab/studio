# 기타 올터네이트 튜닝·DADGAD·오픈 코드 탐구 — 음악연습실 완전 가이드

올터네이트 튜닝(Alternate Tuning)은 **표준 EADGBE 튜닝 외에 다른 방식으로 현을 조율하는 것**입니다. 새로운 코드 보이싱, 드론 음, 독특한 음색이 탄생합니다. Pierre Bensusan(DADGAD), Jimmy Page(DADGAD), Joni Mitchell(다양한 올터네이트)이 이 세계를 탐구했습니다.

---

## 올터네이트 튜닝의 이유

### 왜 튜닝을 바꾸는가?

```

이유 1: 특정 키에서 드론 음 쉽게 사용
이유 2: 불가능한 코드 보이싱 가능하게
이유 3: 독특한 음색과 분위기
이유 4: 핑거피킹 패턴 단순화
이유 5: 새로운 창의적 아이디어

```

---

## Drop D 튜닝 (DADGBE)

### 가장 간단한 올터네이트

**변경:**
```
6번 줄만: E → D (온음 낮추기)
나머지 5줄: 그대로

```

**장점:**
```

D 파워 코드: 6, 5, 4번 줄 바레 (한 프렛에서!)
표준 튜닝에서 D 파워 코드: 두 손가락 필요
Drop D에서: 한 손가락으로

```

**Drop D D 코드:**
```
6번줄: D2 (오픈)
5번줄: A2 (오픈)
4번줄: D3 (오픈)
= 최저음 D 3개 겹침

```

### Drop D 활용

**헤비 메탈·록:**
```

Rage Against the Machine, Alice in Chains
D, C, Bb 파워 코드를 한 손가락으로
빠른 코드 전환 가능

```

**핑거피킹:**
```
6번줄 D를 베이스 드론으로
나머지 5줄로 코드 연주
Celtic, Folk 스타일에 많이 사용

```

## DADGAD 튜닝

### Celtic 기타의 표준

**변경:**
```
6번 줄: E → D
5번 줄: A → A (그대로)
4번 줄: D → D (그대로)
3번 줄: G → G (그대로)
2번 줄: B → A (온음 낮추기)
1번 줄: E → D (온음 낮추기)

```

**오픈 코드:**
```

아무 프렛도 누르지 않으면: Dsus4 코드 (D-A-D-G-A-D)
= 신비롭고 열린 사운드

```

### Pierre Bensusan 스타일

Pierre Bensusan은 DADGAD만 사용하는 기타리스트:
- **드론 현:** 낮은 D줄을 항상 울리게
- **모달 접근:** D 도리안·믹솔리디안 중심
- **화려한 핑거피킹:** 오른손 5손가락 사용

**DADGAD 기본 코드:**
```

D: 오픈 (Dsus4)
G: 5프렛 (Dsus4 포지션에서 변형)
A: 7프렛 바레
Em: 2프렛 (E-A-E-G-A-E)

```

### Jimmy Page의 DADGAD

Led Zeppelin "Kashmir"는 DADGAD:

```

오픈: D-A-D-G-A-D
반복 리프: 낮은 D 드론 + 고음 변화
= 동양적이고 웅장한 사운드

```

---

## 오픈 G 튜닝 (DGDGBD)

### 슬라이드 기타의 왕

**변경:**
```
6번: E → D
5번: A → G
4번: D → D (그대로)
3번: G → G (그대로)
2번: B → B (그대로)
1번: E → D

```

**오픈 G 코드:**
```

오픈: G 메이저
5프렛 바레: C 메이저
7프렛 바레: D 메이저

```

### Keith Richards 스타일

The Rolling Stones의 Keith Richards:
- 5번 줄 제거 (4줄 기타)
- 오픈 G에서 단순한 코드
- "Brown Sugar", "Start Me Up", "Honky Tonk Women" 모두 오픈 G

**Richards 코드 포지션:**
```

오픈: G
5프렛: C (바레)
7프렛: D (바레)
간단하고 강한 록 리프

```

---

## 오픈 D 튜닝 (DADF#AD)

### 델타 블루스 + 포크

**변경:**
```
6번: E → D
5번: A → A (그대로)
4번: D → D (그대로)
3번: G → F# (반음 낮추기)
2번: B → A (온음 낮추기)
1번: E → D (온음 낮추기)

```

**오픈 D 코드:**
```

오픈: D 메이저
5프렛: G 메이저 (바레)
7프렛: A 메이저 (바레)

```

### 솔로 포크 기타

Nick Drake 스타일:

```

오픈 D로 서정적 핑거피킹
드론 D 베이스 유지
고음 멜로디를 위로 쏘기

```

## Joni Mitchell의 다양한 튜닝

### 40개 이상의 튜닝

Joni Mitchell은 매 곡마다 다른 튜닝:

**"Big Yellow Taxi":** Open E (EBEG#BE)
**"Both Sides Now":** 오픈 G 변형
**"A Case of You":** 독특한 변형

**Mitchell의 철학:**
```
"기타를 피아노처럼 자유롭게"
튜닝이 악기의 한계를 넘어설 수 있게
각 곡에 맞는 고유한 보이싱

```

---

## 올터네이트 튜닝 탐구 방법

### 새로운 튜닝 찾는 법

**실험 방법:**
```
1. 하나 또는 두 줄만 조율 변경
2. 오픈 코드에서 시작
3. 어떤 모양이 멋진 소리인지 탐구
4. 특정 음계·코드에서 새로운 보이싱 발견

```

### 튜닝별 핵심 포지션

**DADGAD에서 D 도리안:**
```

D 도리안 스케일: D-E-F-G-A-B-C
DADGAD로: 낮은 D 드론 유지하면서
나머지 현에서 도리안 음계
= 켈틱·아이리쉬 음악의 전형적 사운드

```

## 올터네이트 튜닝 카포 사용

### 카포 + 올터네이트 조합

**Drop D + 카포 3프렛:**
```

실질 튜닝: F A D G B E (Drop F)
새로운 음색

```

**DADGAD + 카포 2프렛:**
```

실질 튜닝: E B E A B E
E 기반의 DADGAD 음색

```

## 음악연습실 올터네이트 튜닝 연습

### 60분 루틴

**1. Drop D 탐구 (15분)**
   - 파워 코드 패턴
   - 핑거피킹 패턴
   - 록 리프 연습

**2. DADGAD 탐구 (20분)**
   - 기본 코드 (오픈, 5프렛, 7프렛)
   - 드론 D 유지하며 멜로디
   - Pierre Bensusan 스타일 핑거피킹

**3. 오픈 G 탐구 (15분)**
   - Keith Richards 코드
   - 슬라이드 기타 적용
   - 간단한 블루스 진행

**4. 자유 실험 (10분)**
   - 나만의 올터네이트 튜닝 탐구
   - 오픈 코드에서 발견한 것 기록

## 마무리

올터네이트 튜닝은 **기타의 새로운 언어**입니다. 표준 튜닝에서 막혀있던 창의성이 새로운 튜닝에서 폭발할 수 있습니다. Pierre Bensusan이 DADGAD 하나로 평생 새로운 음악을 만들듯이.

은평구 24시간 음악연습실에서 Drop D부터 시작하여 DADGAD로 나아가세요. 각 튜닝이 발견하게 해줄 새로운 코드와 멜로디를 기대하세요.

---

얼터네이트 튜닝은 스탠다드 EADGBe 이외의 튜닝으로 기타를 세팅하여 새로운 코드 보이싱과 사운드 텍스처를 탐구하는 방법입니다. DADGAD 튜닝은 켈틱·포크 음악에, 오픈 G나 오픈 D는 블루스와 슬라이드 기타에 주로 활용됩니다. 처음 얼터네이트 튜닝을 시도할 때는 음정 안정화 시간이 필요하므로 충분히 스트링을 길들인 뒤 연주를 시작하세요.

일렉트릭 기타에서 피킹 각도와 깊이는 톤에 직접적인 영향을 미칩니다. 픽을 줄에 대해 약간 비스듬히 잡으면 마찰음이 줄고 부드러운 톤을 얻을 수 있습니다. 얼터네이트 피킹을 정확하게 구현하기 위해 느린 BPM에서 다운·업 스트로크를 교대하는 훈련이 필수적입니다. 이펙터 조합을 다양하게 실험해보면 오버드라이브, 딜레이, 리버브 등 각 이펙트가 사운드에 미치는 영향을 직접 파악할 수 있습니다. 앰프 볼륨과 이펙터 레벨의 적절한 조화를 찾는 과정이 자신만의 톤을 만들어갑니다. 음악 연습의 질을 높이는 데 녹음은 유용한 도구입니다. 스마트폰으로 간단히 녹음한 뒤 나중에 들어보면 연주 중에는 미처 인식하지 못했던 리듬 불안정, 음정 이탈, 다이나믹 부재 등을 객관적으로 파악할 수 있습니다. 자신의 연주를 비판적으로 분석하는 능력이 쌓일수록 효율적인 자기 교정이 가능해집니다. 연습실의 앰프나 모니터 스피커를 통해 자신의 소리를 명확하게 듣는 환경을 만드는 것도 중요합니다.

## Studio NOL이 얼터네이트 튜닝 연습자에게 자주 권하는 3가지

스튜디오 놀(연신내, 서울 은평구) 음악연습실에서 기타 얼터네이트 튜닝 상담 때 자주 드리는 조언입니다.

**1. DADGAD 우선 — 가장 활용도 높은 튜닝**

얼터네이트 튜닝 입문은 DADGAD가 가장 활용도 높음. 어쿠스틱 핑거스타일에 자주 사용.

**2. 튜닝 후 — 코드 모양 재학습 필요**

표준 튜닝 코드 모양이 통하지 않습니다. 각 튜닝에 맞춰 새 코드 모양 재학습 필요.

**3. 별도 기타 — 잦은 튜닝 변경 회피**

표준 → 얼터네이트 잦은 변경은 기타에 부담. 가능하면 얼터네이트 전용 기타 1대 분리.
