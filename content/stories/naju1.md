## 나주에서 KTX 호남선으로 서울까지

나주는 KTX 호남선이 정차하는 역이 있어 서울과 약 1시간 40~50분대로 직결됩니다. 전남 나주 혁신도시를 포함한 주변 지역에서 가장 빠른 서울 이동 경로입니다.

---

## 나주 → 연신내 이동 경로

### KTX 호남선 (직행)

```
① 나주역에서 KTX 탑승 (서울역 방면)
② 서울역 도착 (약 1시간 40~50분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 2시간 20~30분
```

---

## 당일 왕복 일정 예시 (나주 기준)

```
오전 7시 30분 나주역 KTX 출발
→ 오전 9시 20분 서울역 도착
→ 오전 10시 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 서울역 출발
→ 오후 3시 50분 나주역 도착
```

