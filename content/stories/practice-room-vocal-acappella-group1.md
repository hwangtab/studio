# 보컬 아카펠라 그룹 퍼포먼스 — 음악연습실 완전 가이드

아카펠라(A cappella)는 **악기 없이 목소리만으로 완전한 음악을 만드는 예술**입니다. 보컬 그룹이 멜로디·하모니·베이스·퍼커션을 동시에 담당하며, 그 합이 오케스트라를 능가하는 아름다움을 만들어냅니다. Pentatonix, Straight No Chaser, Home Free의 스타일을 분석합니다.

---

## 아카펠라 파트 구성

### 기본 4파트

**리드 보컬 (Lead):**
- 주선율 담당
- 그룹에서 가장 부각되는 목소리

**보컬 1 (Vocal 1 — 소프라노/테너 하이):**
- 리드보다 높거나 같은 음역
- 카운터 멜로디 또는 하모니

**보컬 2 (Vocal 2 — 알토/배리톤):**
- 중간 음역의 하모니
- 화음의 색깔 결정

**보컬 베이스 (Vocal Bass):**
- 가장 낮은 파트
- 화성의 기반과 리듬 기초

### 보컬 퍼커션 (Vocal Percussion / Beatbox)

아카펠라에서 드럼 역할.

**기본 비트박스 소리:**
- **킥드럼**: "Buh" 또는 "Puh" (입술 폭발음)
- **스네어**: "Ts" 또는 "Ka" (혀+이 마찰)
- **하이햇**: "Ts" (짧고 날카롭게)
- **베이스드럼 + 스네어 조합**: "Buh-Ka-Buh-Ka"

**4/4 기본 비트:**
```
박자: 1   2   3   4
킥:  Buh     Buh
스네어:   Ka      Ka
하이햇: Ts Ts Ts Ts (8분음표)
```

## 아카펠라 편곡법

### 편곡의 기본 원칙

**1. 파트 분배:**
- 각 파트가 독립적이면서도 조화
- 주선율이 항상 가장 잘 들려야 함

**2. 리듬 배분:**
- 퍼커션이 없으면 다른 파트에 리듬 요소 분배
- "Doo", "Bum", "Dum" 등 음절로 리듬감 표현

**3. 음역 배분:**
- 각 파트가 너무 좁거나 너무 넓지 않게
- 성부 교차가 일어날 경우 주의

### 현대 팝 아카펠라 편곡

**Pentatonix 스타일 편곡:**
```
리드: 주선율
소프라노: 리드 위 하모니 + 카운터 멜로디
알토: 코드의 3음·7음 중심
배리톤/테너: 내부 하모니
베이스: 코드 근음 + 리듬 베이스라인
퍼커션: 드럼 파트 전담
```

### 바비숍 (Barbershop) 편곡

**특징:**
- 매우 풍부한 4성부 화음
- 7th 코드를 많이 사용
- "링(Ring)" 효과 추구

**바비숍 보이싱 (G7 예):**
```
테너: F4 (7음)
리드: D4 (5음)  
배리톤: B3 (3음)
베이스: G2 (근음)
```

## 파트별 연습 방법

### 파트 러닝 (Part Learning)

**1. 파트 분리 학습:**
- 각자 자신의 파트를 먼저 완전히 외우기
- 녹음을 들으며 자신의 파트만 노래

**2. 파트 + 기준음:**
- 피아노로 자신의 파트를 확인하며 노래
- 인토네이션 정확도 훈련

**3. 파트 + 다른 파트:**
- 한 파트는 녹음으로 틀고, 다른 파트를 노래
- 실제 앙상블 느낌 훈련

### 그룹 리허설 순서

**단계 1: 개인 파트 완성**
→ **단계 2: 2파트 조합** (예: 리드+베이스)
→ **단계 3: 3파트 조합**
→ **단계 4: 전체 앙상블**

---

## 블렌딩과 인토네이션

### 그룹 블렌딩

**블렌딩의 핵심:**
- 개인 목소리를 "녹이기" — 튀지 않게
- 모음 발음 통일 (특히 "아", "이", "우")
- 다이나믹 공유 (강약을 함께)

**블렌딩 훈련:**
1. 유니즌(같은 음)으로 시작 — 완벽히 하나처럼 들릴 때까지
2. 옥타브로 블렌딩
3. 3도로 블렌딩
4. 풀 하모니

### 피치 정확도

**아카펠라에서 인토네이션이 중요한 이유:**
- 기준음이 없어 서로의 목소리만 기준
- 한 명이 벗어나면 전체 화음이 흔들림

**훈련 방법:**
- 튜너 앱으로 개인 피치 확인
- 드론 음(지속음) 위에서 하모니 연습
- 서로의 귀를 믿는 훈련

---

## 퍼포먼스 기술

### 스테이지 구성

**파트별 배치:**
- 베이스: 왼쪽 또는 중앙
- 리드 보컬: 중앙 앞
- 하모니: 리드 주변
- 퍼커션: 오른쪽 또는 중앙

**마이크 기술:**
- 핸드헬드 마이크 사용 시 거리 조절
- 강한 음에서 마이크 멀리, 약한 음에서 가까이
- 퍼커션은 컵 마이크 또는 근접 마이크

### 바디 랭귀지

**아카펠라 퍼포먼스의 시각적 요소:**
- 눈 맞춤 — 파트너와의 소통
- 몸 움직임 — 리듬을 몸으로 표현
- 표정 — 곡의 감정 전달

**Pentatonix 스타일:**
- 각자의 개성 + 그룹 통일감
- 안무 + 노래의 균형

## Pentatonix 스타일 분석

### "Daft Punk" Medley 분석

Pentatonix의 대표적 아카펠라 편곡.

**파트 구조:**
```
Avi Kaplan (베이스): 드럼 베이스 + 화성 베이스
Scott Hoying (배리톤): 내부 하모니 + 리드 교대
Kirstie Maldonado (메조): 멜로디 하모니
Mitch Grassi (테너): 카운터 멜로디
Kevin Olusola (셀로/퍼커션): 비트박스 + 첼로
```

**배울 포인트:**
- 각 파트의 명확한 역할
- 역동적인 솔로 교대
- 퍼커션과 하모니의 균형

## 음악연습실 아카펠라 그룹 연습

### 스튜디오 놀 그룹 연습

은평구 음악연습실에서 아카펠라 그룹 연습:

**방음 환경의 장점:**
- 외부 잡음 없이 순수한 목소리만 집중
- 마이크 없이도 어쿠스틱 앙상블 훈련
- 녹음하여 블렌딩 분석

**연습 루틴 (90분):**

**1. 파트 워밍업 (15분)**
   - 각자 파트 확인
   - 음역 워밍업

**2. 유니즌 블렌딩 (15분)**
   - 같은 음으로 하나의 소리 목표

**3. 파트 조합 (30분)**
   - 2파트 → 3파트 → 전체

**4. 전체 앙상블 (30분)**
