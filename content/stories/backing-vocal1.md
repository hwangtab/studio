faq:
  - q: 백보컬과 코러스는 어떻게 다른가요?
    a: >-
      코러스(Chorus)는 곡의 후렴 구간을 뜻하기도 하고, 보컬 이펙트(코러스 이펙트)를 뜻하기도 합니다. 백보컬(Backing
      Vocal)은 메인 보컬을 지원하는 보조 성부를 말합니다. 실무에서는 '코러스 녹음'과 '백보컬 녹음'을 같은 의미로 사용하는 경우가
      많습니다.
  - q: 하모니는 몇 개 레이어가 적당한가요?
    a: >-
      팝 발라드의 경우 3도·5도 위아래로 각 1~2개씩 총 3~5개 레이어가 일반적입니다. 너무 많으면 주파수가 겹쳐 흐릿해질 수
      있으므로 메인 보컬보다 레벨을 -6~-12dB 낮게 배치합니다.
  - q: 백보컬 녹음 시 메인 보컬과 다른 마이크를 써야 하나요?
    a: >-
      같은 마이크를 사용하는 것이 음색 통일성에 유리합니다. 다만 백보컬은 메인보다 마이크와 약간 더 먼 거리(30~40cm)에서 녹음해
      자연스러운 거리감을 만들기도 합니다.
  - q: 혼자서 모든 파트를 녹음할 수 있나요?
    a: >-
      가능합니다. 메인 보컬을 먼저 녹음하고 같은 가이드 트랙을 들으며 3도·5도 하모니를 차례로 레이어링합니다. 피치 수정
      툴(Auto-Tune, Melodyne)로 블렌딩을 다듬으면 전문적인 코러스 사운드를 만들 수 있습니다.

## 백보컬이 곡을 채우는 이유

메인 보컬 하나만으로는 채워지지 않는 공간을 백보컬이 채웁니다. 적절히 배치된 하모니 레이어는 곡의 감정적 밀도를 높이고, 클라이맥스 구간의 폭발감을 만들어냅니다.

백보컬 하모니 레이어링의 역사는 1960년대 모타운 레코드 히츠빌 USA 스튜디오에서 체계화됐습니다. The Supremes·Marvin Gaye 음반에서 The Andantes 같은 전문 보컬 그룹이 3성부·5성부 하모니를 정밀하게 레이어링하는 기법을 정립했고, 이것이 팝 음악 코러스 편성의 표준이 됐습니다. 1970년대 Phil Spector의 "Wall of Sound" 기법은 수십 명의 싱어를 같은 파트에 겹쳐 녹음해 거대한 사운드 밀도를 만들었으며, ABBA가 보컬 레이어링과 스테레오 패닝을 정교하게 조합해 팝 프로덕션의 기준을 높였습니다. K-POP 제작 환경에서는 1990년대 SM엔터테인먼트가 H.O.T.·S.E.S.부터 멀티 레이어 코러스 스태킹을 표준 워크플로우로 정착시켰고, 현재는 원격으로 녹음한 보컬 파일을 DAW에서 레이어링하는 비대면 코러스 제작도 보편화됐습니다.

## 백보컬 유형과 역할

| 유형 | 내용 | 주요 구간 |
|------|------|---------|
| 유니즌 더블링 | 메인 보컬을 동일 멜로디로 겹치기 | 후렴, 강조 구간 |
| 3도 하모니 | 메인 음 위/아래 3도 음정 | 후렴, 브릿지 |
| 5도 하모니 | 5도 위 음정으로 공간감 확대 | 고조 구간 |
| 앤서 보컬 | 메인 멜로디에 짧게 대답하는 성부 | 벌스, 프리코러스 |
| 패드 보컬 | 길게 유지되는 배경 성부 | 전체 구간 |

## 레이어 녹음 순서

[1단계] 메인 보컬 녹음 완료

- 피치 수정 완료된 메인 트랙 준비
- 레이어 기준선으로 사용

[2단계] 유니즌 더블링

- 메인과 동일 멜로디를 별도 테이크로 녹음
- 팬 배치: L-20%, R+20% (메인은 센터)

[3단계] 3도 하모니 (위)

- 메인 멜로디 기준 장3도 또는 단3도 위
- 레벨: 메인 -6~-8dB

[4단계] 3도 하모니 (아래)

- 메인 멜로디 기준 장3도 또는 단3도 아래
- 레벨: 메인 -8~-10dB

[5단계] 5도 하모니 (선택)

- 넓은 공간감이 필요한 클라이맥스에 추가
- 레벨: 메인 -10~-12dB

## 백보컬 믹스 배치 전략

### 주파수 분리

### 메인 보컬

- **EQ**: 200Hz 아래 롤오프, 2~4kHz 프레즌스 강조
- **레벨**: 0dB 기준 (Mix 앵커)
- **Pan**: 센터

### 더블링/유니즌

- **EQ**: 메인과 동일 + 고역대(8kHz 이상) 약간 롤오프
- **레벨**: 메인 -6~-8dB
- **Pan**: L-20 / R+20 (스테레오 넓히기)

### 3도 하모니

- **EQ**: 로우미드(300~600Hz) 약간 컷 (메인과 충돌 방지)
- **레벨**: 메인 -8~-12dB
- **Pan**: L-40 / R+40

### 5도 하모니

- **EQ**: 하이패스 600Hz 이상만 통과
- **레벨**: 메인 -12~-15dB
- **Pan**: L-60 / R+60

### 공간 이펙트

| 이펙트 | 메인 보컬 | 백보컬 |
|--------|---------|------|
| 리버브 | 짧은 룸 (0.8~1.2s) | 더 긴 홀 (1.5~2.5s) |
| 딜레이 | 짧은 슬랩백 | 8분음표·점음표 딜레이 |
| 코러스 이펙트 | 사용 안 함 | 옅게 적용 가능 |

---

## 피치 블렌딩 팁

### Auto-Tune 활용

- 메인 보컬: Retune Speed 20~40 (자연스럽게)
- 백보컬: Retune Speed 8~15 (더 빠르게 → 덜 들리게)
- 백보컬은 메인보다 피치 교정을 강하게 해
  "공기 같은" 배경 느낌을 만듦

### Melodyne 활용

- 하모니 파트에서 의도치 않은 피치 드리프트 수정
- Note 경계를 정리해 레이어 간 위화감 제거

## 마치며

백보컬은 곡의 감정적 깊이를 더하는 중요한 요소입니다. 레이어 배치에서 핵심은 메인 보컬과의 레벨 차이입니다. 유니즌 더블링은 -6~-8dB, 3도 하모니는 -8~-12dB, 5도 하모니는 -12~-15dB로 낮게 설정해야 메인 보컬이 선명하게 부각됩니다. 레벨이 너무 높으면 하모니가 메인을 잠식해 가사 전달력이 떨어지고, 반대로 너무 낮으면 하모니 효과 자체가 들리지 않습니다.

패닝 배치는 스테레오 폭을 결정합니다. 더블링을 L-20/R+20에 배치하고 3도 하모니를 L-40/R+40, 5도 하모니를 L-60/R+60에 배치하면 메인 보컬(센터)을 중심으로 하모니가 바깥쪽으로 자연스럽게 펼쳐지는 구조가 만들어집니다. 공간 이펙트는 메인 보컬보다 백보컬에 더 긴 리버브(1.5~2.5초 홀 리버브)를 적용해 거리감을 만드는 것이 기본 원칙입니다.

피치 교정에서 백보컬은 메인보다 빠른 Retune Speed(8~15)를 설정해 더 정밀하게 교정하면 "공기 같은" 배경 질감이 만들어집니다. 메인 보컬의 인간적인 피치 변동이 살아있는 상태에서 백보컬이 정밀하게 코드톤을 잡아주면, 두 요소의 대비가 오히려 입체감을 높입니다.

## 잘 깔린 코러스는 티가 안 나요

코러스를 오래 만들다 보면 역설적인 결론에 도달해요. 잘 된 백보컬일수록 "여기 코러스가 있네"라고 의식되지 않는다는 거예요. 곡이 갑자기 두툼해지고 후렴이 벅차오르는데, 정작 그게 뒤에 깔린 화음 덕분이라는 걸 청자는 눈치채지 못하죠. 앞에 나서서 존재감을 뽐내는 순간 그건 이미 백보컬이 아니라 또 하나의 메인이 돼버려요.

그 '안 들리게 잘 받치는' 감각의 핵심은 결국 음량이에요. 본문 표에 정리한 대로 유니즌은 메인보다 살짝, 3도·5도로 올라갈수록 더 낮게 깔아야 메인의 가사가 앞으로 뚫고 나와요. 레벨을 욕심내서 올리면 화음은 화려해지는데 정작 무슨 가사인지 안 들리는, 초보 믹스에서 제일 흔한 함정에 빠져요.

혼자 모든 파트를 쌓는 분들에게 제가 늘 강조하는 건 피치보다 타이밍이에요. 같은 사람이 3~4번 겹쳐 부르면 음정은 비슷하게 맞는데, 자음이 들어가는 순간이 미세하게 어긋나면 뭉개진 소리가 나요. 그래서 저는 하모니를 정밀하게 교정하고 좌우로 넓게 펼쳐서, 각 레이어가 제자리에 딱 앉게 정리해요. 이 과정이 곡 전체의 완성도를 좌우해서, 본격적인 음원이라면 [발매 프로젝트](/release-project) 단계에서 코러스 설계까지 같이 잡는 걸 권해요.
