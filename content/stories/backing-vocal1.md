faq:
  - q: 백보컬과 코러스는 어떻게 다른가요?
    a: >-
      코러스(Chorus)는 곡의 후렴 구간을 뜻하기도 하고, 보컬 이펙트(코러스 이펙트)를 뜻하기도 합니다. 백보컬(Backing
      Vocal)은 메인 보컬을 지원하는 보조 성부를 말합니다. 실무에서는 '코러스 녹음'과 '백보컬 녹음'을 같은 의미로 사용하는 경우가
      많습니다.
  - q: 하모니는 몇 개 레이어가 적당한가요?
    a: >-
      팝 발라드의 경우 3도·5도 위아래로 각 1~2개씩 총 3~5개 레이어가 일반적입니다. 너무 많으면 주파수가 겹쳐 흐릿해질 수
      있으므로 메인 보컬보다 레벨을 -6~-12dB 낮게 배치합니다.
  - q: 백보컬 녹음 시 메인 보컬과 다른 마이크를 써야 하나요?
    a: >-
      같은 마이크를 사용하는 것이 음색 통일성에 유리합니다. 다만 백보컬은 메인보다 마이크와 약간 더 먼 거리(30~40cm)에서 녹음해
      자연스러운 거리감을 만들기도 합니다.
  - q: 혼자서 모든 파트를 녹음할 수 있나요?
    a: >-
      가능합니다. 메인 보컬을 먼저 녹음하고 같은 가이드 트랙을 들으며 3도·5도 하모니를 차례로 레이어링합니다. 피치 수정
      툴(Auto-Tune, Melodyne)로 블렌딩을 다듬으면 전문적인 코러스 사운드를 만들 수 있습니다.

## 백보컬이 곡을 완성시키는 이유

메인 보컬 하나만으로는 채워지지 않는 공간을 백보컬이 채웁니다. 적절히 배치된 하모니 레이어는 곡의 감정적 밀도를 높이고, 클라이맥스 구간의 폭발감을 만들어냅니다.

---

## 백보컬 유형과 역할

| 유형 | 내용 | 주요 구간 |
|------|------|---------|
| 유니즌 더블링 | 메인 보컬을 동일 멜로디로 겹치기 | 후렴, 강조 구간 |
| 3도 하모니 | 메인 음 위/아래 3도 음정 | 후렴, 브릿지 |
| 5도 하모니 | 5도 위 음정으로 공간감 확대 | 고조 구간 |
| 앤서 보컬 | 메인 멜로디에 짧게 대답하는 성부 | 벌스, 프리코러스 |
| 패드 보컬 | 길게 유지되는 배경 성부 | 전체 구간 |

---

## 레이어 녹음 순서

레퍼런스 트랙과 A/B 비교하면서 조절하면 과보정을 방지할 수 있습니다.

[1단계] 메인 보컬 녹음 완료
- 피치 수정 완료된 메인 트랙 준비
- 레이어 기준선으로 사용

[2단계] 유니즌 더블링
- 메인과 동일 멜로디를 별도 테이크로 녹음
- 팬 배치: L-20%, R+20% (메인은 센터)

[3단계] 3도 하모니 (위)
- 메인 멜로디 기준 장3도 또는 단3도 위
- 레벨: 메인 -6~-8dB

[4단계] 3도 하모니 (아래)
- 메인 멜로디 기준 장3도 또는 단3도 아래
- 레벨: 메인 -8~-10dB

[5단계] 5도 하모니 (선택)
- 넓은 공간감이 필요한 클라이맥스에 추가
- 레벨: 메인 -10~-12dB

## 백보컬 믹스 배치 전략

### 주파수 분리

플러그인을 추가하기 전에 게인 스테이징이 올바른지 먼저 확인합니다.

### 메인 보컬

- **EQ**: 200Hz 아래 롤오프, 2~4kHz 프레즌스 강조
- **레벨**: 0dB 기준 (Mix 앵커)
- **Pan**: 센터

### 더블링/유니즌

- **EQ**: 메인과 동일 + 고역대(8kHz 이상) 약간 롤오프
- **레벨**: 메인 -6~-8dB
- **Pan**: L-20 / R+20 (스테레오 넓히기)

### 3도 하모니

- **EQ**: 로우미드(300~600Hz) 약간 컷 (메인과 충돌 방지)
- **레벨**: 메인 -8~-12dB
- **Pan**: L-40 / R+40

### 5도 하모니

- **EQ**: 하이패스 600Hz 이상만 통과
- **레벨**: 메인 -12~-15dB
- **Pan**: L-60 / R+60

### 공간 이펙트

| 이펙트 | 메인 보컬 | 백보컬 |
|--------|---------|------|
| 리버브 | 짧은 룸 (0.8~1.2s) | 더 긴 홀 (1.5~2.5s) |
| 딜레이 | 짧은 슬랩백 | 8분음표·점음표 딜레이 |
| 코러스 이펙트 | 사용 안 함 | 옅게 적용 가능 |

## 피치 블렌딩 팁

버스로 묶어 처리하면 개별 트랙 조정 없이도 전체 밸런스를 효율적으로 잡을 수 있습니다.

### Auto-Tune 활용

- 메인 보컬: Retune Speed 20~40 (자연스럽게)
- 백보컬: Retune Speed 8~15 (더 빠르게 → 덜 들리게)
- 백보컬은 메인보다 피치 교정을 강하게 해
  "공기 같은" 배경 느낌을 만듦

### Melodyne 활용

- 하모니 파트에서 의도치 않은 피치 드리프트 수정
- Note 경계를 정리해 레이어 간 위화감 제거

### 녹음 세션 공통 체크리스트

**준비 단계**
- [ ] 세션 목표 명확히 설정 (완성할 구간·트랙 수)
- [ ] 모든 파일·장비 사전 점검 완료
- [ ] 아티스트 컨디션 확인 (보컬: 목 상태, 악기: 튜닝)

**세션 중**
- [ ] 테이크별 메모 (베스트/리테이크 표시)
- [ ] 문제 구간 즉시 인식하고 재녹음 결정
- [ ] 세션 종료 30분 전 마무리 시작

**후반 작업**
- [ ] 원본 파일 즉시 백업
- [ ] 믹싱 전 24시간 이상 청취 공백 유지

### 세션 효율을 높이는 팁

1. **가장 어려운 구간을 세션 초반에** — 에너지가 최고일 때 어려운 것 먼저
2. **구간 분리 녹음** — 전체 통으로 반복보다 구간별 완성 후 연결
3. **즉각 피드백** — 녹음 직후 헤드폰으로 바로 모니터링
