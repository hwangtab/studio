# 기타 네오소울·코드 멜로디 기법 — 음악연습실 완전 가이드

네오소울 기타는 **R&B의 감성과 재즈의 화성이 만나는 지점**입니다. 단순한 코드를 풍부하게 보이싱하고, 멜로디를 코드 안에 통합하며, 레이드백된 그루브로 연주하는 것—이것이 네오소울 기타의 미학입니다. Erykah Badu, D'Angelo, Hiatus Kaiyote의 음악에서 찾을 수 있는 기타 사운드를 탐구합니다.

---

## 네오소울 코드 보이싱

### 확장 코드 기초

네오소울에서는 단순 트라이어드보다 **7th, 9th, 11th 확장 코드**를 사용합니다.

**기본 확장 코드:**
- **maj7**: C-E-G-B (달콤하고 부드러움)
- **m7**: C-Eb-G-Bb (슬프고 소울풀)
- **7#9**: 지미 헨드릭스 코드 (소울+록)
- **9**: Cmaj7 + D (밝고 넓은 느낌)

### 네오소울 특유의 보이싱

**Drop 2 보이싱:**
Cmaj7을 Drop 2로:
```
표준: E-G-B-C (모두 붙어서)
Drop 2: G-C-E-B (2번째 음을 옥타브 아래로)
```

더 개방적이고 재즈적인 소리.

**Shell Voicing (셸 보이싱):**
```
3음+7음만 사용
Cmaj7 셸: E+B (3음과 7음만)
음의 핵심 색깔만 남기기
```

## 코드-멜로디 통합

### 코드 안에 멜로디 넣기

**기법:**
- 코드를 잡은 채로 최고음부에 멜로디
- 코드 보이싱을 멜로디에 맞게 변형

**Cmaj7에서 멜로디 예:**
```
코드: x-3-2-0-0-0 (표준 Cmaj7)
멜로디 음 D가 오면: x-3-2-0-3-0으로
멜로디 음 E가 오면: x-3-2-1-0-0으로
```

### 보이스 리딩 (Voice Leading)

코드 변화 시 각 음이 최소로 이동:

**Cmaj7 → Am7 보이스 리딩:**
```
Cmaj7: E-G-B-C
Am7:   E-G-A-C
(E, G, C는 그대로, B만 A로 이동)
```

## 네오소울 리듬 기법

### 레이드백 (Laid Back) 그루브

네오소울의 핵심: **비트 뒤에 살짝 늦게** 연주.

**느낌:**
- 리듬이 "떠있는" 느낌
- 여유롭고 관능적인 그루브
- 기계적이지 않고 인간적

**연습법:**
1. 메트로놈 클릭을 "다음 비트"처럼 느끼기
2. 클릭 직전에 치지 말고, 클릭에 맞추거나 살짝 후에
3. 처음엔 드라이하게, 익숙해지면 자연스럽게

### 더블 스탑과 네오소울

**특징:**
- 3도나 6도 더블스탑으로 풍부하게
- 슬라이드로 연결

**Am7 위에서 더블스탑 멜로디:**
```
A+C → B+D → C+E (6도 더블스탑으로 상행)
```

## 핑거스타일 네오소울

### 손가락 퍼커션 활용

네오소울 기타에서 자주 쓰는 기법:

**브러시 스트럼:**
- 손가락으로 현을 위에서 아래로 살짝 쓸기
- 날카롭지 않은 부드러운 스트럼

**썸 슬랩:**
- 엄지로 저음현을 짧게 슬랩
- 퍼커시브한 베이스 효과

**핑거 탭:**
- 고음현을 손가락 끝으로 부드럽게 탭
- 멜로디와 리듬 동시 표현

### Isaiah Rashad·Syd 스타일

**특징:**
- 코드와 멜로디를 동시에
- 심플하지만 깊은 보이싱
- 깔끔하고 앰비언트한 클린 톤

**추천 이펙터 체인:**
```
기타 → 컴프레서 (소프트) → 코러스 (살짝) → 앰프 클린
```

## Hiatus Kaiyote 스타일

### Nai Palm의 기타 기법

Hiatus Kaiyote의 프론트우먼 Nai Palm은 독특한 네오소울 기타로 유명합니다.

**특징:**
- 핑거피킹 + 슬랩 혼합
- 불규칙한 박자 위 그루브 유지
- 보컬과 기타가 대화하듯

**기법:**
1. 베이스 현 슬랩 (엄지)
2. 고음현 멜로디 (검지, 중지)
3. 미드 코드 (약지)

### "Breathing Underwater" 스타일

```
코드: Cmaj9 - Am11 - Fmaj9 - Gsus2
각 코드를 핑거피킹으로 분해
비트가 부드럽게 흐르도록
```

---

## 네오소울 기타 이펙터

### 클린 톤 기반

네오소울은 **클린하거나 매우 약한 오버드라이브** 위주.

**추천 설정:**
```
앰프: 클린 채널, 약간 따뜻하게
컴프레서: 소프트 비율 (2:1~4:1)
코러스: 살짝 (공간감)
리버브: 홀 또는 플레이트 (작게)
```

**이펙터 체인:**
```
기타 → 컴프 → 오버드라이브(미세하게) → 코러스 → 딜레이(살짝) → 리버브 → 앰프
```

## 음악연습실 네오소울 기타 연습

### 연습 루틴 (50분)

**1. 코드 보이싱 워밍업 (10분)**
   - Cmaj7-Am7-Fmaj9-G7 진행
   - Drop 2, Shell, 표준 각각

**2. 코드-멜로디 통합 (15분)**
   - 코드 잡은 채로 최고음 멜로디 추가
   - 보이스 리딩 부드럽게

**3. 레이드백 그루브 (15분)**
   - 메트로놈에 맞춰 살짝 늦게
   - 더블스탑 멜로디 추가

**4. 자유 탐구 (10분)**
   - 녹음하며 자신만의 네오소울 그루브
