## 충북 동부에서 서울까지

제천·충주는 서울과 고속버스로 2~3시간 거리입니다. 전문 보컬 녹음과 음반 제작을 위해 연신내 스튜디오 놀을 이용할 수 있습니다.

---

## 제천·충주 → 연신내 이동 경로

### 제천 고속버스 경로

```
① 제천 버스터미널 출발
② 서울 강남터미널 도착 (약 2시간 30분)
③ 3호선 고속터미널역 → 충무로 → 환승 → 연신내역

총 소요시간: 약 3시간~3시간 30분
```

### 충주 고속버스 경로

```
① 충주 버스터미널 출발
② 서울 강남터미널 도착 (약 1시간 30~40분)
③ 3호선 → 환승 → 연신내역

총 소요시간: 약 2시간 10~30분
```

## 당일 왕복 일정 예시 (제천 기준)

```
오전 7시 제천터미널 출발 (고속버스)
→ 오전 9시 30분 강남터미널 도착
→ 오전 10시 20분 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 30분 강남터미널 출발 (버스)
→ 오후 5시 제천터미널 도착
```
