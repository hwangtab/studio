# 인디팝 기타·The Strokes·Vampire Weekend·코드 스타일 — 음악연습실 완전 가이드

인디팝 기타(Indie Pop Guitar)는 **클린하고 독특한 코드 보이싱과 리듬감이 특징인 현대 팝·록 기타 스타일**입니다. The Strokes의 인터로킹 기타, Vampire Weekend의 아프로팝 영향 기타, Tame Impala의 사이키델릭 클린 기타 — 인디팝 기타는 단순함 속에서 개성 있는 사운드를 만드는 예술입니다.

---

## 인디팝 기타란?

### 독립 음악의 기타 언어

**인디팝 기타의 특징:**
```
클린 또는 약한 오버드라이브
개성 있는 코드 보이싱 (서스펜드, 애드)
반복적이지만 매력적인 리프
팝 멜로디 + 록 에너지
```

**인디팝 vs 메인스트림 록:**
```
메인스트림: 헤비 디스토션, 마샬 스택
인디팝: 클린/세미클린, 개성 있는 보이싱
= 소리보다 감성이 먼저
```

---

## The Strokes 스타일

### 뉴욕 인디록의 대부

The Strokes(Nick Valensi + Albert Hammond Jr.):
- **두 기타 인터로킹:** 두 파트가 서로 보완
- **세미클린 톤:** 과하지 않은 드라이브
- **단순한 코드:** 파워 코드 + 오픈 코드

**"Last Nite" 스타일:**
```
기타 A: 반복적인 단음 리프
기타 B: 코드 지지
= 두 기타가 하나의 사운드
```

**The Strokes 리듬:**
```
16분음표 절단 스트로크
= 날카롭고 리드미컬한 사운드
업다운 교대 빠르게
```

---

## Vampire Weekend 스타일

### 아프로팝 인디팝의 화려함

Vampire Weekend:
- **아프로팝 영향:** 아프리카 기타 리듬
- **클린 톤:** 맑고 밝은 기타 소리
- **복잡한 리듬:** 인터로킹 + 폴리리듬

**"A-Punk" 스타일:**
```
빠른 클린 코드 아르페지오
Am-G-F-G 반복
= 아프로팝 느낌의 인디팝
```

**Vampire Weekend 코드 선택:**
```
Amaj7, Dmaj9, Bsus4 등
= 밝고 개방적인 코드
서스펜드와 애드 코드 많이 사용
```

---

## Tame Impala 스타일

### 사이키델릭 인디팝

Tame Impala(Kevin Parker):
- **사이키델릭 이펙터:** 페이저, 플랜저
- **레트로 느낌:** 60~70년대 팝·록 영향
- **클린 + 이펙터:** 많은 이펙터로 음색 변형

**"Feels Like We Only Go Backwards" 스타일:**
```
클린 기타 + 코러스 + 리버브
반복적인 아르페지오
= 몽환적이고 레트로한 사운드
```

**사이키델릭 이펙터:**
```
페이저: 음이 회전하는 느낌
플랜저: 제트기 소리 같은 스위프
비브라토: 피치 흔들기
= 사이키델릭 텍스처
```

## 인디팝 코드 보이싱

### 독특한 화음

**서스펜드 코드:**
```
Csus2: x-3-0-0-1-0 (D 현만 열림)
Dsus4: x-5-5-5-3-x
= 장단조 모호한 중간 색채
```

**애드 코드:**
```
Cadd9: x-3-2-0-3-0 (9도 추가)
Gadd9: 3-2-0-0-0-3 (9도 추가)
= 더 밝고 풍성한 코드
```

**오픈 코드 변형:**
```
Dsus2: x-0-0-2-3-0
= 열린 현 사용으로 공명 풍성
```

## 인터로킹 기타

### 두 기타의 대화

**기타 A와 B의 역할:**
```
기타 A: 리프 또는 단음 멜로디
기타 B: 코드 반주
= 서로 빈 자리 채우며 완성
```

**실습: G-C-D 인터로킹:**
```
기타 A: G-D-G (단음) 반복
기타 B: G코드-C코드-D코드 반복
= 합쳐져야 완전한 음악
```

## 음악연습실 인디팝 기타 연습

### 60분 루틴

**1. 인디팝 코드 연습 (15분)**
   - Csus2-Gadd9-Am-Fsus2 진행
   - 클린 톤으로
   - 자연스러운 손 이동

**2. The Strokes 스타일 (15분)**
   - 16분음표 절단 스트로크
   - 파워 코드 + 클린 리프
   - 빠른 리듬 연습

**3. Vampire Weekend 아르페지오 (15분)**
   - Amaj7-Dmaj9 아르페지오
   - 밝고 클린한 사운드
   - 리듬감 있게

**4. 즉흥 인디팝 리프 (15분)**
   - 자신만의 인디팝 리프 만들기
   - 서스펜드/애드 코드 활용
   - 독특한 보이싱 시도

## 마무리

인디팝 기타는 **개성이 기술보다 중요한 음악**입니다. Vampire Weekend의 Ezra Koenig가 "좋은 기타 리프는 단순해도 잊을 수 없어야 한다"고 했듯, 복잡한 솔로보다 기억에 남는 한 리프가 더 중요합니다. 자신만의 독특한 코드 보이싱 하나를 찾는 것이 인디팝 기타의 시작입니다.
