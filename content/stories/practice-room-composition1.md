## 작곡·편곡에 방음 연습실이 필요한 이유

작곡과 편곡 작업은 DAW(컴퓨터) 작업만으로는 한계가 있습니다.

- **멜로디 확인**: 직접 건반으로 연주해야 자연스러운 라인이 나옴
- **화성 탐구**: 피아노로 코드 보이싱을 실시간 수정
- **보컬 라인 테스트**: 직접 불러봐야 가수에게 줄 수 있는 키 확인
- **악기 조합 확인**: 실제 악기 소리로 편곡 결과 체크

집이나 카페에서는 볼륨 제약으로 이 모든 과정이 어렵습니다.

## 작곡·편곡 작업 단계별 연습실 활용법

### 아이디어 스케치

- 떠오른 멜로디를 바로 건반으로 연주
- 음성 메모 앱으로 즉시 녹음
- 코드 진행 여러 가지 탐구 (큰 소리로 실험 가능)

### 편곡 구체화

- 멜로디 + 코드 + 리듬 패턴 통합 연습
- 보컬 파트가 있다면 실제로 불러보며 키·음역 확인
- PA 스피커로 MR에 맞춰 전체 밸런스 점검

### 데모 제작 준비

- 보컬 라인 반복 연습 → 데모 녹음 준비
- 같은 건물 전문 녹음실 예약 후 데모 진행
- 연습실에서 최종 연습 → 즉시 녹음 연계

### 의뢰 프로젝트 마감

- 집중 작업 기간 월정액 입주로 전용 공간 확보
- 24시간 이용 → 마감 전 새벽 작업 가능
- 피드백 반영 후 즉시 악기로 재확인

### 효율적인 연습을 위한 원칙

좋은 연습 습관이 실력 향상의 핵심입니다.

1. **목표 설정** — 오늘 연습에서 달성할 구체적인 목표 1개를 정하고 시작
2. **분리 연습** — 어려운 구간은 전체 반복보다 해당 2~4마디만 집중
3. **속도 조절** — 완벽하지 않은 기법을 빠른 속도로 반복하면 잘못된 근육 기억만 강화됨

### 연습 중 자주 하는 공통 실수

1. **어려운 구간을 피해서 쉬운 곳만 반복** — 불편한 구간이 실력 향상의 지점
2. **메트로놈 없이 빠른 속도 연습** — 느린 속도의 정확성이 빠른 속도의 기반
3. **연습 시간만 늘리고 내용은 방치** — 30분 집중 연습이 2시간 멍하니 반복보다 효과적

### 연습 자가 진단

- [ ] 오늘의 목표를 시작 전에 정했는가?
- [ ] 어려운 구간을 분리해서 집중 반복했는가?
- [ ] 연습 후 무엇이 개선되었는지 구체적으로 인식하는가?



## 4주 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 점검 | 기본기 복습, 문제 구간 파악 | 40분 |
| 2주차 | 구간 집중 | 어려운 부분 느린 템포 반복 | 45분 |
| 3주차 | 전체 흐름 | 전곡 연결, 템포 단계적 올리기 | 50분 |
| 4주차 | 완성 | 목표 템포 + 표현·다이나믹 완성 | 60분 |

**주간 체크포인트:** 1주차: 약점 구간 3개 목록 작성 / 2주차: 각 구간 느린 템포 100% 달성 / 3주차: 전곡 끊김 없이 완주 / 4주차: 청중 앞 또는 녹음으로 최종 확인


## 연습실 최대한 활용하는 법

**시간별 추천 구성 (1시간 기준):**
- 0~10분: 워밍업 (스트레칭, 기본 음계 또는 개방현)
- 10~45분: 목표 구간 집중 연습 (어렵고 중요한 부분 먼저)
- 45~55분: 전곡 런스루 (흐름·감정 표현 포함)
- 55~60분: 쿨다운 + 다음 연습 목표 메모

**방음 환경에서만 가능한 연습:**
- 최대 볼륨·최대 다이나믹 표현 (집에서 불가)
- 큰 소리로 가사 암송 + 발음 교정
- 틀렸을 때 즉각 멈추고 되돌아가는 구간 반복 훈련
