## 음악연습실 예약, 처음이라면

음악연습실 예약은 크게 두 가지로 나뉩니다: **시간 대여 예약**과 **월세 입주 신청**. 이용 목적과 빈도에 따라 선택하세요.

| 구분 | 시간 대여 | 월세 입주 |
|-----|---------|---------|
| 대상 | 가끔 이용하는 분 | 매주 정기적으로 이용하는 분 |
| 비용 | 시간당 과금 | 월 고정 금액 |
| 계약 | 없음 (예약만) | 서면 계약 필요 |
| 전용 공간 | X (공용 스케줄) | O (내 방으로 지정) |
| 예약 방법 | 카카오톡·전화·온라인 | 현장 방문 상담 후 계약 |

---

## 시간 대여 예약 절차

### 1단계: 예약 방법 확인

연습실마다 예약 방식이 다릅니다:
- **카카오톡 오픈채팅**: 가장 빠른 소통, 실시간 공실 확인 가능
- **전화 예약**: 직접 상담 가능, 세부 문의도 동시에 해결
- **온라인 예약 시스템**: 24시간 언제든지 예약 가능

### 2단계: 원하는 조건 정하기

예약 전 미리 결정해야 할 사항:
- **날짜와 시간**: 원하는 이용 날짜와 시작·종료 시간
- **시간 수**: 최소 1시간부터 예약 가능한 곳이 대부분
- **방 종류**: 보컬 연습 / 피아노 연습 / 기타·베이스 등 목적에 맞는 방
- **악기 유무**: 피아노(업라이트·디지털), PA 스피커 필요 여부

### 3단계: 예약 요청 및 확인

예약 요청 후 확인 메시지를 받아야 예약이 완료됩니다. 확인 없이 방문하면 다른 고객이 이용 중일 수 있습니다.

### 4단계: 출입 방법 안내 받기

무인 운영 연습실은 개인 도어록 코드나 QR 코드를 예약 시 안내받습니다. 방문 전 반드시 출입 방법을 확인하세요.

## 당일 예약 가이드

### 당일 예약이 가능한 경우

- 공실이 있는 경우 이용 1~2시간 전까지 예약 가능
- 평일 낮 시간대(10:00~17:00)는 공실률이 높아 당일 예약 성공률이 높음
- 야간·주말은 사전 예약이 안전

### 당일 예약 팁

1. **아침에 미리 문의**: 당일 스케줄 확인 후 원하는 시간 확보
2. **복수 시간대 문의**: "오후 2시 또는 4시 가능한가요?" 식으로 선택지 제시
3. **캔슬 알림 요청**: 원하는 시간에 예약이 없다면 취소 발생 시 연락 요청

---

## 예약 취소·변경 정책

대부분의 연습실은 아래와 같은 원칙을 따릅니다:

| 상황 | 일반적 처리 |
|-----|-----------|
| 이용 전 2시간 이상 남은 경우 | 무료 취소 또는 변경 |
| 이용 전 1~2시간 내 취소 | 환불 불가 또는 위약금 발생 |
| 노쇼 (연락 없이 미방문) | 이후 예약 제한 또는 블랙리스트 |
| 운영자 사정으로 취소 | 전액 환불 또는 대체 시간 제공 |

예약 시 취소 정책을 반드시 확인하세요.

---

## 월세 입주 신청 절차

정기적으로 음악연습실을 이용한다면 월세 입주가 훨씬 경제적입니다.

### 입주 신청 단계

**1단계 — 온라인 문의**
- 원하는 방 타입(피아노 유무, 방 크기), 이용 목적, 희망 입주일을 알려주세요.
- 월세 가격과 현재 공실 여부를 확인합니다.

**2단계 — 현장 견학**
- 실제로 방을 보고, 방음·악기 상태·환경을 직접 확인합니다.
- 인접 방의 소음 차단 여부를 테스트하세요.

**3단계 — 계약 체결**
- 계약 기간, 월세, 해지 조건을 확인하고 서면 계약서를 작성합니다.
- 개인 도어록 코드를 발급받습니다.

**4단계 — 입주 및 이용 시작**
- 첫 달부터 24시간 자유롭게 이용합니다.


## 스튜디오 놀 예약 방법

**시간 대여 예약**
- 카카오톡 오픈채팅으로 원하는 날짜·시간·방 타입 문의
- 실시간 공실 확인 후 바로 예약 확정
- 이용 시작 1시간 전까지 취소·변경 가능

**월세 입주 문의**
- 카카오톡 또는 전화로 상담 예약
- 현장 견학 후 계약 (보증금 없음, 1개월 단위)
- 입주 즉시 개인 도어록 코드 발급

| 항목 | 조건 |
|-----|-----|
| 위치 | 연신내역 3번 출구 도보 5분 |
| 운영 시간 | 24시간 무인 운영 |
| 시간 대여 | 8,000~25,000원/시간 |
| 월세 입주 | 30만원대~, 보증금 없음 |
| 예약 방법 | 카카오톡 오픈채팅 |
| 당일 예약 | 공실 시 가능 |
