## 재즈 연습, 실험적 공간이 필요합니다

재즈는 '틀린 음'이 없는 음악입니다. 다양한 보이싱, 스케일, 리듬 아이디어를 마음껏 시도해볼 수 있는 공간이 필요합니다.

재즈 연습의 특성:
- **즉흥 연주**: 예측 불가능한 흐름 → 반복 시도 필요
- **보이싱 탐구**: 여러 코드 폼 비교 → 큰 소리로 들으며 판단
- **리듬 감각**: 스윙·보사노바·퓨전 등 다양한 리듬 훈련
- **레코딩 피드백**: 자기 연주 녹음 → 자기 점검 필수

---

## 재즈 장르별 연습 방법

### 재즈 보컬

- 재즈 스탠다드 가사·멜로디 암기
- 스캣 싱잉 기초 훈련 (도레미→ba-da-ba-da)
- iReal Pro로 MR 생성 → PA 스피커로 함께 연습
- 가이드 멜로디 vs 즉흥 애드립 전환 연습

### 재즈 피아노

- 2-5-1 진행 코드 보이싱 연습 (모든 키에서)
- 왼손 보이싱 + 오른손 멜로디/즉흥 분리 연습
- 블록 코드, 드롭2 보이싱 탐구
- 재즈 스탠다드 1곡을 여러 해석으로 연주

### 재즈 기타

- 재즈 코드 보이싱 (maj7, min7, dom7, dim7)
- 싱글 노트 라인 (비밥 스케일 기반)
- 쿼텟 반주 패턴 연습
- 솔로 기타 편곡 탐구

### 재즈 연주에서 자주 하는 실수

1. **스케일 나열에 그치는 즉흥 연주** — 짧은 모티프를 발전시키는 "motif development" 연습
2. **코드 진행 외우기에만 집중** — 귀로 코드 들으며 즉흥 연주하는 "이어 트레이닝" 병행
3. **빠른 템포에서만 멋있어 보이려 함** — 느린 블루스 BPM 60에서 표현력 먼저

### 재즈 즉흥 자가 진단

- [ ] ii-V-I 진행 위에서 짧은 모티프를 즉흥 연주할 수 있는가?
- [ ] 코드 진행을 들으면서 음이 맞는지 귀로 확인하는가?
- [ ] 쉬는 공간을 활용해서 음악에 숨을 불어넣는가?

## 4주 재즈 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 화성 | 7th·9th 코드 폼, 2-5-1 진행 | 45분 |
| 2주차 | 스윙·보사 | 스윙 8분음표 느낌, 보사노바 리듬 | 50분 |
| 3주차 | 즉흥 기초 | 블루스 스케일, 콜·앤드·리스폰스 | 55분 |
| 4주차 | 스탠다드 | 재즈 스탠다드 1곡 전체 + 솔로 | 60분 |

**주간 체크포인트:** 1주차: 2-5-1 진행 4개 조성에서 연주 / 2주차: 스윙 느낌 메트로놈 없이도 유지 / 3주차: 블루스 스케일 솔로 8마디 즉흥 / 4주차: 리얼 북 곡 1개 멤버들과 합주

## 연습실에서 더 효과적으로

**연습실에서만 가능한 연습:**
- 집에서 불가능한 최대 볼륨·최대 다이나믹 표현 훈련
- 방음 환경에서 집중력이 최대로 유지되는 환경
- 스스로 녹음하여 객관적으로 청취하는 피드백 루틴

## Studio NOL이 재즈 음악 연습실 사용자에게 자주 권하는 3가지

스튜디오 놀(연신내, 서울 은평구) 음악연습실에서 재즈 보컬·피아노·기타 연습실 상담 때 자주 드리는 조언입니다.

**1. 스탠더드 레퍼토리 — Real Book 10곡 우선**

재즈는 스탠더드 보유량이 실력. Real Book 10곡 우선 암보.

**2. 거장 카피 — 한 곡당 솔로 1코러스**

재즈 어휘는 거장 솔로 카피로 가장 빠르게 늡니다. 한 곡당 한 코러스 카피.

**3. 합주 — 혼자 연습 한계, 잼 세션 권장**

재즈는 혼자 연습에 한계. 잼 세션 경험이 필수.
