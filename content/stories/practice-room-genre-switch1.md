faq:
  - q: 클래식 피아노를 배웠는데 팝 피아노로 전환할 수 있나요?
    a: >-
      충분히 가능합니다. 클래식 기초가 있는 분이 팝 피아노를 배우면 오히려 빠르게 적응합니다. 클래식 → 팝 전환의 핵심: ① 코드 체계
      익히기 (기능화성) ② 리듬 패턴 변화 (팝 특유의 리듬) ③ 악보 없이 코드로 연주하는 감각 개발. 연습실에서 코드 연주 중심으로
      팝 곡을 따라치면서 적응하세요.
  - q: 재즈 피아노는 클래식 기초가 없어도 배울 수 있나요?
    a: >-
      가능합니다. 다만 재즈는 화성학 이론이 중요하므로 기초 화성학을 먼저 배우는 것이 도움됩니다. 클래식 기초가 있으면 더 유리하지만,
      없어도 재즈 전용 교재·레슨으로 입문 가능합니다. 재즈는 코드와 즉흥 연주가 핵심이므로 팝보다 이론 학습이 중요합니다.
  - q: 팝에서 클래식으로 전환하는 경우는 어떤가요?
    a: >-
      팝 음악인이 클래식으로 전환할 때: ① 악보 읽기 (초견) 능력 집중 강화 ② 다이나믹·아티큘레이션 정밀도 향상 ③ 음악 이론
      체계화. 클래식은 팝보다 표현의 정밀도가 높게 요구되므로 레슨을 통한 체계적 접근이 권장됩니다.
  - q: 장르 전환 시 기존 실력이 도움이 되나요?
    a: >-
      네, 많은 도움이 됩니다. 음악의 기초 (박자·음정·기본 기술)는 장르를 불문하고 공통입니다. 기존에 익힌 악기 테크닉은 새
      장르에서도 그대로 활용됩니다. 다만 각 장르 특유의 '언어' (리듬 패턴, 화성 접근, 표현 방식)는 새로 배워야 합니다.

## 음악은 장르를 넘나들며 더 풍부해집니다

클래식만 배웠던 분이 팝을 시도하거나, 팝 뮤지션이 재즈에 도전하는 것 — 장르 전환은 새로운 음악 세계를 열어주고 뮤지션으로서의 폭을 넓혀줍니다.

장르 전환의 이점:
- **음악적 폭 확장**: 더 다양한 상황에서 연주 가능
- **새로운 자극**: 익숙함에서 벗어나 성장
- **표현력 향상**: 다른 장르의 표현 기법 흡수
- **즐거움**: 좋아하는 곡 직접 연주하는 만족감

---

## 장르별 전환 포인트

### 클래식 → 팝
- 악보 → 코드 차트 전환 적응
- 정박 → 다양한 리듬 패턴
- 정확한 표현 → 자유로운 해석
- **핵심**: 코드 체계 + 팝 리듬 패턴

### 클래식 → 재즈
- 악보 기반 → 리드 시트 + 즉흥
- 장·단음계 → 모드 스케일
- 정해진 연주 → 즉흥 표현
- **핵심**: 화성학 + 스윙 리듬 + 즉흥

### 팝 → 클래식
- 코드 → 악보 읽기 능력
- 자유로운 표현 → 정밀한 다이나믹
- 현대 화성 → 기능 화성
- **핵심**: 초견 + 다이나믹 컨트롤

## 장르 전환 연습 전략

| 전환 방향 | 초기 연습 방법 | 기간 |
|---------|------------|-----|
| 클래식→팝 | 코드 교재 + 좋아하는 팝 코드 연주 | 2~3개월 |
| 클래식→재즈 | 재즈 화성학 + 리얼 북 스탠다드 | 4~6개월 |
| 팝→클래식 | 초견 연습 + 바이엘 or 체르니 재도전 | 3~6개월 |
| 팝→재즈 | 재즈 코드 + 스윙 리듬 + 즉흥 | 4~6개월 |

### 효율적인 연습을 위한 원칙

좋은 연습 습관이 실력 향상의 핵심입니다.

1. **목표 설정** — 오늘 연습에서 달성할 구체적인 목표 1개를 정하고 시작
2. **분리 연습** — 어려운 구간은 전체 반복보다 해당 2~4마디만 집중
3. **속도 조절** — 완벽하지 않은 기법을 빠른 속도로 반복하면 잘못된 근육 기억만 강화됨

### 연습 중 자주 하는 공통 실수

1. **어려운 구간을 피해서 쉬운 곳만 반복** — 불편한 구간이 실력 향상의 지점
2. **메트로놈 없이 빠른 속도 연습** — 느린 속도의 정확성이 빠른 속도의 기반
3. **연습 시간만 늘리고 내용은 방치** — 30분 집중 연습이 2시간 멍하니 반복보다 효과적

### 연습 자가 진단

- [ ] 오늘의 목표를 시작 전에 정했는가?
- [ ] 어려운 구간을 분리해서 집중 반복했는가?
- [ ] 연습 후 무엇이 개선되었는지 구체적으로 인식하는가?



## 4주 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 점검 | 기본기 복습, 문제 구간 파악 | 40분 |
| 2주차 | 구간 집중 | 어려운 부분 느린 템포 반복 | 45분 |
| 3주차 | 전체 흐름 | 전곡 연결, 템포 단계적 올리기 | 50분 |
| 4주차 | 완성 | 목표 템포 + 표현·다이나믹 완성 | 60분 |

**주간 체크포인트:** 1주차: 약점 구간 3개 목록 작성 / 2주차: 각 구간 느린 템포 100% 달성 / 3주차: 전곡 끊김 없이 완주 / 4주차: 청중 앞 또는 녹음으로 최종 확인


## 연습실 최대한 활용하는 법

**시간별 추천 구성 (1시간 기준):**
- 0~10분: 워밍업 (스트레칭, 기본 음계 또는 개방현)
- 10~45분: 목표 구간 집중 연습 (어렵고 중요한 부분 먼저)
- 45~55분: 전곡 런스루 (흐름·감정 표현 포함)
- 55~60분: 쿨다운 + 다음 연습 목표 메모

**방음 환경에서만 가능한 연습:**
- 최대 볼륨·최대 다이나믹 표현 (집에서 불가)
- 큰 소리로 가사 암송 + 발음 교정
- 틀렸을 때 즉각 멈추고 되돌아가는 구간 반복 훈련
