## 광양에서 KTX로 서울까지

광양은 전남 동부 도시로, 경전선 KTX를 통해 서울과 약 3시간대로 연결됩니다. 광양 매화마을과 광양항으로 유명한 광양에서 오전 일찍 출발하면 당일 서울 스튜디오 방문이 가능합니다.

---

## 광양 → 연신내 이동 경로

### KTX 광양역 (권장)

```
① 광양역 KTX 탑승 (서울역 방면, 약 2시간 40분~3시간)
② 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간 10분~3시간 40분
```

### KTX 순천역 경유 (대안)

```
① 광양 → 순천역 (버스 약 20~30분)
② 순천역 KTX 탑승 (서울역 방면, 약 2시간 30분~2시간 50분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간 20분~4시간
```

## 당일 왕복 일정 예시 (광양 기준)

```
오전 7시 광양역 KTX 출발
→ 오전 10시 서울역 도착
→ 오전 10시 40분 연신내역 도착
→ 오전 11시 세션 시작 (2시간)
→ 오후 1시 세션 완료
→ 오후 3시 서울역 출발
→ 오후 6시 광양역 도착
```

## 온라인 파일 의뢰 서비스

```
광양 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
