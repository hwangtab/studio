## 성남 구도심에서 연신내 스튜디오 놀까지

경기도 성남시 수정구·중원구(신흥동·단대동·은행동·상대원동) 지역에서 8호선을 이용하면 서울 연신내 스튜디오 놀까지 약 1시간~1시간 15분에 도달할 수 있습니다.

---

## 성남 수정·중원 → 연신내 이동 경로

### 8호선 + 2호선 + 6호선 (추천)

장비 자체보다 세팅 방법이 결과물 품질에 더 큰 영향을 줍니다.

### 신흥역·단대오거리역 출발 (8호선)

1. 신흥역 또는 단대오거리역(8호선) 탑승
2. 8호선 서울 방면 이동
   (남한산성입구 → 산성 → 단대오거리 → 신흥
    - 수진 → 모란 → 복정 → 장지 → 문정 → 가락시장
    - 경찰병원 → 개롱 → 거여 → 마천 방향 X)

**8호선 별내 방향으로 이동**
   (신흥 → 단대오거리 → 산성 → 남한산성입구
    - 단국대 → 건강보험공단 → 복정 → 장지 → 문정...)
3. 잠실역 하차 (8호선·2호선 환승역)
4. 2호선 환승 → 합정역 하차
5. 합정역에서 6호선 환승
6. 망원 → 마포 → 공덕 → 효창공원 → 삼각지 방향 X
   실제: 합정 → 6호선 → 상수 → 광흥창 →
   대흥 → 공덕 방향 아님.
   합정역 6호선: 응암 방면
  - 망원 → 합정 → 홍대입구... 방향 없음

**올바른 경로**
   합정(2호선) → 6호선 혼동 없도록
   2호선 → 신촌 → 이대 → 아현 → 충정로 →
   시청 → 을지로입구... (이 경로도 아님)

**가장 빠른 경로**
   신흥역 → 8호선 → 잠실 → 2호선 → 홍대입구 →
   6호선 환승 → 상수 → 합정 → 망원 →
   월드컵경기장 → 마포구청 → 망원 방향 X

**단순 경로 요약**
신흥역(8호선) → 잠실역(2호선 환승) →
홍대입구역(6호선 환승) → 연신내역
- **총 소요시간**: 약 60~70분
