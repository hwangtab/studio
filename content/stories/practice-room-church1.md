## 교회 찬양팀·성가대 개인 연습 시간이 필요한 이유

교회 단체 연습만으로는 한계가 있습니다.

| 상황 | 문제 | 해결 |
|-----|-----|-----|
| 합주 연습 | 개인 파트 불안한 채 합류 | 개인 연습 후 합주 완성도 상승 |
| 새 곡 도입 | 가사·멜로디 미숙달 | 연습실에서 혼자 반복 숙달 |
| 고음 파트 | 교회에서 큰 소리 내기 어려움 | 방음 연습실에서 충분히 연습 |
| 발성 약점 | 합주 중 지적받아도 바로 교정 어려움 | 개인 연습 때 집중 보강 |

---

## 찬양팀 단계별 연습실 활용법

### 예배 1~2주 전

- 새 곡 가사·멜로디 완전 암기
- 자신의 파트 음정·박자 확인
- MR에 맞춰 전곡 완주 연습

### 예배 전날

- 전체 세트 순서대로 논스톱 완주
- 어려운 구간 집중 보강
- 발성 워밍업 루틴 완성

### 스스로 점검하는 방법

- 스마트폰으로 녹음/녹화 → 음정 확인
- MR2(멀티트랙 제거) 활용 개인 파트 분리 연습
- 반복해도 불안한 구간은 파트장·음악감독에게 피드백 요청

---

## 악기 담당자 활용법

### 피아노·건반 담당

- 새 찬양 코드 진행 완성
- 예배 찬양 전체 셋 리스트 순서대로 연습
- 모듈레이션(조바꿈) 연결 구간 집중 연습

### 기타·베이스

- 개인 악기 지참 → PA 스피커 연결
- 리듬 패턴·솔로 구간 반복 숙달
- 드라이브 톤·이펙터 세팅 테스트

---

## 스튜디오 놀 — 찬양팀 연습 환경

| 항목 | 내용 |
|-----|-----|
| 업라이트 피아노·디지털 건반 | 찬양팀 피아니스트 개인 연습 |
| PA 스피커 | 예배 볼륨 환경 미리 체험 |
| 마이크 스탠드 | 마이크 다루기 연습 |
| STC 50+ 방음 | 고음·강한 찬양 마음껏 연습 |
| 24시간 운영 | 토요일 야간·주일 새벽 이용 가능 |
| 무인 운영 | 타인 시선 없이 집중 |
| 시간 대여 | 8,000~25,000원/시간 |
| 월정액 입주 | 30만원대~, 보증금 없음 |
