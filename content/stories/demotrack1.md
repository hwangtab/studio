## 심사위원은 데모에서 무엇을 듣는가

기획사나 레이블에 보내는 데모 트랙은 단순히 "내 노래 실력"을 보여주는 파일이 아닙니다. 심사위원은 다음을 듣습니다:

- **음색(Tone)**: 독특하고 기억에 남는가
- **감정 표현**: 가사와 멜로디에서 감정이 느껴지는가
- **음정·박자 기본기**: 프로 수준의 안정성이 있는가
- **믹싱 완성도**: 이 아티스트가 프로페셔널하게 준비하는가

마지막 항목이 중요합니다. 음질이 낮은 데모는 심사 전에 탈락하는 경우가 있습니다.

## 데모 트랙 기획 단계

### 곡 선정 기준

| 목적 | 권장 곡 구성 |
|------|------------|
| 보컬리스트 오디션 | 음색 + 감정 표현이 드러나는 곡 + 고음 역량 보여주는 곡 |
| 싱어송라이터 오디션 | 자작곡 + 선율 기억도가 높은 곡 |
| 특정 장르 기획사 | 해당 장르 레퍼런스와 유사하면서 차별화 포인트 있는 곡 |
| 배우·연기자 OST 오디션 | 드라마틱한 감정 변화가 있는 발라드 계열 |

### 2~3곡 구성 전략

- **1번 곡**: 자신의 대표 음색과 장기가 드러나는 곡
- **2번 곡**: 장르·분위기가 다른 곡으로 범용성 증명
- **3번 곡 (선택)**: 자작곡 또는 편곡 능력이 드러나는 곡

## 데모 녹음 수준 기준

### 최소 기준 (홈 레코딩 허용 여부)

소규모 인디 레이블, 지역 기획사: 홈 레코딩 데모도 검토하는 경우 있음

중형 이상 기획사, 방송국 오디션, 메이저 레이블: 전문 스튜디오 녹음 수준 요구

공통 기준:
- 배경 잡음 없을 것
- 방 울림(Room Reverb)이 없을 것
- 보컬이 MR에 묻히지 않을 것

### 전문 스튜디오 데모의 장점

- 방음 부스에서 잡음·울림 없이 녹음
- Neumann U87AI 등 레퍼런스급 마이크로 음색 최대 표현
- 엔지니어의 보컬 디렉팅으로 감정·딜리버리 최적화
- 피치 교정·컴핑으로 기본기 완성

## 데모 제출 파일 준비

### 파일 형식

- **WAV 24bit/48kHz**: 최고 품질, 마스터 파일 보존용
- **MP3 320kbps**: 이메일·드라이브 공유용 (용량 절약)

대부분의 기획사는 MP3로 수신하지만, 통과 후 계약 단계에서 WAV 원본을 요구하는 경우가 많습니다. 항상 WAV 원본을 보관해두세요.

### 파일명 형식

```
아티스트명_곡제목_데모_2026.mp3
예) 홍길동_봄날_데모_2026.mp3
```

### 제출 시 포함할 정보

- 이름, 나이, 연락처
- 장르 및 아티스트 방향성 (2~3줄)
- 레퍼런스 아티스트 (1~2명)
- SNS 또는 유튜브 링크 (있는 경우)

## 데모 녹음 — 스튜디오 놀에서 진행하는 방법

1. **카카오톡 문의**: 오디션 목적과 곡 수, MR 보유 여부 알려주기
2. **MR 사전 공유**: WAV 파일 전달 (또는 당일 USB 지참)
3. **세션 진행**: 보컬 디렉팅 + 컴핑 + 피치 교정까지
4. **믹싱·마스터링**: 데모 기준 완성 파일 납품
5. **파일 수령**: WAV + MP3 카카오톡 또는 드라이브로 전달
