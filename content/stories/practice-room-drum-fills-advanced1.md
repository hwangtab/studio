# 드럼 고급 필인·전환 기법·John Bonham — 음악연습실 완전 가이드

드럼 필인(Fill)은 **그루브 사이의 감탄사**입니다. 훌륭한 필인은 다음 섹션을 예고하고, 긴장을 해소하며, 밴드 전체를 이끕니다. John Bonham의 파워풀한 필인, Neil Peart의 복잡한 필인, Dave Grohl의 에너지 넘치는 필인—각각 다른 철학을 보여줍니다.

---

## 필인의 역할

### 왜 필인이 필요한가?

**필인의 기능:**
1. **섹션 전환 신호:** A 섹션 → B 섹션 예고
2. **에너지 빌드업:** 클라이맥스로 이끌기
3. **그루브 강화:** 반복적인 그루브에 다양성
4. **음악적 호흡:** 긴장과 해소

### 필인 타이밍

**언제 필인을 치는가:**
```
- 8마디마다 (가장 일반적)
- 4마디마다 (빠른 섹션)
- 16마디마다 (긴 섹션)
- 구조적 변화 직전
```

## John Bonham 스타일

### "Moby Dick" 솔로 필인

Led Zeppelin의 드러머 John Bonham:
- **파워:** 엄청난 강도
- **단순함:** 복잡하지 않지만 강렬
- **셔플 그루브:** "When the Levee Breaks" 스타일

**Bonham 시그니처 필인:**
```
스네어-탐-탐: S-T1-T2 (기본 하향 필인)
킥 더블: 필인 끝에 킥 2번
결과: "쿵-쿵-쿵-쿵쿵" (마지막 두 번 빠르게)
```

### "Good Times Bad Times" 필인

```
4분음표 킥: 1박, 2박, 3+박, 4+박
동시에 오른손 라이드·하이햇
= Bonham의 킥 독립성 보여주는 필인
```

### 파워 필인 구성

```
마디 7: 그루브 약간 강하게
마디 8: 필인
  박1: 스네어 강하게
  박2: 탐탐 더블
  박3: 플로어 탐
  박4: 킥+크래시 (해결)
```

## Neil Peart 스타일

### 복잡한 폴리리듬 필인

Rush의 Neil Peart:
- **복잡한 구조:** 5·7박자 필인
- **다중 탐:** 광범위한 탐 세트 활용
- **정확성:** 모든 음이 의도적

**5음 필인 예:**
```
R-L-R-L-R (5개 연타) = 5음
다음 박에 자연스럽게 이음
홀수 음으로 리듬적 서프라이즈
```

**폴리리듬 필인:**
```
3+3+2 패턴을 4/4 위에:
박1-+: 3음 (R-L-R)
박2-+: 3음 (L-R-L)
박3-4: 2음 (R-L)
= 8음표 8개 = 2마디 (홀수 느낌)
```

### 탐 투어링 (Tom Touring)

```
가장 높은 탐에서 가장 낮은 탐까지:
탐1(높음) → 탐2 → 탐3 → 플로어 탐(낮음)
각 탐에서 더블 스트로크
= 폭포수 같은 필인
```

## Dave Grohl 스타일

### 록의 에너지

Nirvana / Foo Fighters의 Dave Grohl:
- **날 것의 에너지:** 정제보다 에너지
- **단순한 필인 강하게:** 1-2타 필인
- **크래시 심벌:** 항상 강한 해결

**Grohl 시그니처 필인:**
```
박3: 스네어 (강)
박4: 플로어 탐 + 킥 (강)
박1: 크래시 심벌 + 킥 (매우 강)
= 3박에서 시작하는 짧은 필인
```

### 파워 필인 3박 패턴

```
현재 마디 박3-박4:
스네어 → 탐탐 → 킥+크래시
다음 마디 박1 = 새 섹션 시작
```

## 고급 필인 기법

### 루디먼트 기반 필인

**파라디들 필인:**
```
RLRR LRLL (파라디들)
한 마디에 2번 반복
= 복잡하게 들리는 체계적 필인
```

**더블 스트로크 롤 필인:**
```
RRLLRRLL (더블 스트로크)
속도 조절로 4분음표 → 16분음표 → 32분음표
= 가속하는 느낌의 필인
```

### 빌드업 필인 (4마디)

**4마디에 걸친 필인:**
```
마디 1: 그루브 + 마지막 박에 스네어 추가
마디 2: 그루브 + 마지막 2박 스네어 연타
마디 3: 그루브 + 마지막 1마디 절반 필인
마디 4: 풀 필인 → 섹션 전환
```

## 원 바 필인 (1마디)

### 16분음표 필인

**기본 16분음표 필인:**
```
총 16개 16분음표로 1마디
예: RLRL RLRL RLRL RLRL (기본)
또는: 스네어 연타 → 탐 → 플로어 탐
```

**반 마디 필인:**
```
박1-2: 그루브
박3-4: 필인 (8개 16분음표)
= 가장 일반적인 짧은 필인
```

### 오프비트 필인

```
박1+: 스네어 (예상치 못한 시작)
박2: 탐탐
박2+: 탐탐
박3: 플로어 탐
박3+: 킥
박4: 크래시
= 엇박에서 시작하는 필인
```

## 섹션 전환 필인

### 버스 → 코러스 전환

**에너지 최대화 필인:**
```
버스 마지막 마디 박3-4:
박3: 오픈 하이햇 연타
박4: 킥+크래시 (강)
코러스 박1: 새로운 그루브 + 크래시
```

### 코러스 → 버스 전환

**에너지 낮추기 필인:**
```
코러스 마지막 박3-4:
박3: 스네어 (보통)
박4: 하이햇 닫기
버스 박1: 조용한 그루브 시작
```

### 솔로 → 후렴 전환

**클라이맥스 필인:**
```
솔로 마지막 2마디 걸친 필인:
마디 7: 탐탐 연타 (점점 크게)
마디 8: 전 드럼셋 연타 → 크래시 해결
```

## 음악연습실 필인 연습

### 60분 루틴

**1. 루디먼트 기반 (15분)**
   - 파라디들 1마디 필인
   - 더블 스트로크 롤 속도 변화
   - 기본 16분음표 탐 필인

**2. 스타일별 필인 (15분)**
   - Bonham 파워 필인
   - Peart 폴리리듬 5음 필인
   - Grohl 에너지 3박 필인

**3. 빌드업 필인 (15분)**
   - 4마디 필인 구성
   - 섹션 전환 응용
   - 그루브 → 필인 → 그루브 연결

**4. 즉흥 필인 (15분)**
   - 메트로놈 + 그루브 연주
   - 8마디마다 즉흥 필인
   - 녹음 후 청취·개선

## 마무리

필인은 **드러머의 서명**입니다. John Bonham의 필인 하나로 Led Zeppelin임을 알 수 있듯이, 자신만의 필인 어휘를 개발하는 것이 드러머 정체성의 핵심입니다.
