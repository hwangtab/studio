## 첫인상은 커버 아트가 결정합니다

스트리밍 플랫폼에서 음원을 발견하는 순간, 청중이 제일 먼저 보는 것은 커버 아트입니다. 커버 아트는 음악의 무드와 아티스트의 브랜드를 시각으로 전달하는 첫 번째 창구입니다.

---

## 플랫폼별 커버 아트 규격

| 플랫폼 | 최소 크기 | 권장 크기 | 형식 |
|--------|---------|---------|-----|
| 멜론·카카오뮤직 | 600×600px | 3000×3000px | JPEG, PNG |
| 스포티파이 | 3000×3000px | 3000×3000px | JPEG, PNG |
| 애플뮤직 | 3000×3000px | 3000×3000px | JPEG, PNG |
| 유튜브 뮤직 | 3000×3000px | 3000×3000px | JPEG |
| 벅스·지니 | 500×500px | 3000×3000px | JPEG |

**공통 주의사항:**
- RGB 색상 모드 (CMYK 제출 시 오류 발생)
- 파일 크기: 10MB 이하
- 정사각형 비율 필수 (1:1)
- 외설·폭력적 이미지 제출 시 발매 거절

---

## 커버 아트 직접 제작 도구

### 무료 도구

| 도구 | 특징 | 사용 수준 |
|------|------|---------|
| Canva (무료) | 템플릿 기반, 직관적 | 입문 |
| Adobe Express | 포토샵 계열, 고품질 | 중급 |
| Figma | 디자이너용, 세밀한 제어 | 중~상급 |
| GIMP | 포토샵 대체, 무료 | 중급 |

### 유료 도구

| 도구 | 특징 | 월 비용 |
|------|------|--------|
| Adobe Photoshop | 업계 표준 | 약 ₩26,000~ |
| Canva Pro | 상업용 이미지 사용 가능 | 약 ₩16,900~ |
| Affinity Photo | 1회 구매 | 약 ₩70,000 |

## 저작권 없는 이미지 소스

커버 아트에 사용 가능한 무료 이미지 사이트:

| 사이트 | 라이선스 | 상업적 사용 |
|--------|---------|-----------|
| Unsplash | CCO 1.0 | ✅ 가능 |
| Pexels | CCO 유사 | ✅ 가능 |
| Pixabay | CCO 1.0 | ✅ 가능 |
| Freepik (무료) | 출처 표기 필요 | ⚠️ 조건부 |
| Canva 무료 이미지 | 플랫폼 내 사용 | ✅ 가능 |

**주의**: 무료 사이트도 이미지에 따라 상업적 사용이 제한될 수 있으니 개별 이미지의 라이선스를 확인하세요.

## 커버 아트 디자인 원칙

### 좋은 커버 아트의 조건

1. **가독성**: 스마트폰 썸네일(100px)에서도 식별 가능한 단순한 구성
2. **일관성**: 아티스트 브랜드 색상·폰트 통일
3. **장르 연관성**: 음악의 무드를 시각적으로 표현
4. **텍스트 최소화**: 아티스트명·곡명만 포함 (복잡한 텍스트 지양)

### 피해야 할 요소

- 해상도 낮은 이미지 업스케일
- 타인 사진·영화 스틸컷 무단 사용
- 저작권 있는 로고·캐릭터
- 빽빽한 텍스트

## 디자이너 의뢰 방법

직접 제작이 어렵다면 전문 디자이너에게 의뢰합니다:

| 플랫폼 | 특징 | 가격대 |
|--------|------|--------|
| 크몽 | 국내 프리랜서 | 5만~30만원 |
| 탈잉 | 디자이너 매칭 | 견적 |
| Fiverr | 해외 프리랜서 | $20~100 |
| 지인·동료 아티스트 | 협업 교환 가능 | 협의 |

의뢰 시 준비할 것:
- 음악 장르·무드 설명
- 레퍼런스 커버 아트 3~5개
- 아티스트명·곡명 (정확한 철자)
- 원하는 색상 팔레트 (있으면)
