## 확장 코드가 기타 사운드를 세련되게 만듭니다

9th·sus·재즈 코드로 기본 코드를 넘어서세요. 방음 개인실에서 확장 코드를 탐색하세요.

기타 코드 고급 훈련의 핵심:
- **음 생략**: 기타에서 확장 코드는 필수 구성음만 추려 연주
- **sus 활용**: 긴장-해결 감각으로 세련된 코드 진행 만들기
- **보이싱 변형**: 전위형·개방형·밀집형 보이싱으로 사운드 다양화
- **4현 재즈**: 3도·7도 가이드 톤 중심의 효율적 재즈 코드

## 기타 코드 고급·확장 코드 연주 훈련의 핵심 원칙 4가지

코드는 단순히 모양을 외우는 것이 아니라 **음악적 기능을 이해하면서 익히는** 것이 장기 기억에 훨씬 유리합니다.

1. **코드 기능 이해** — 각 코드가 I(토닉)·IV(서브도미넌트)·V(도미넌트) 중 어떤 기능인지 이해하며 연습. 기능을 알면 처음 보는 곡도 빠르게 코드를 파악할 수 있습니다.

2. **최소 이동 보이싱** — 코드 전환 시 손가락 이동을 최소화하는 보이싱 탐색. 공통 음을 중심으로 나머지 손가락만 이동하면 전환 속도가 빨라집니다.

3. **장르 맞춤 코드 색채** — 팝은 개방 코드의 따뜻함, 재즈는 7th·9th·13th 텐션, 클래식은 클로즈드 보이싱의 단단함을 각각 탐색하세요.

4. **코드톤 아르페지오** — 각 코드를 아르페지오로 분해하며 내성 음의 움직임을 귀로 인식. 코드와 선율의 관계가 명확해집니다.

### 기타 코드 연습에서 자주 하는 실수

1. **손가락을 눕혀서 인접 현을 뮤팅** — 각 손가락 끝을 세워서 프렛 바로 뒤를 누르기
2. **코드 전환 시 손 전체를 들어올림** — 기준 손가락(1지)을 최대한 이동하지 않고 전환
3. **스트로크 없이 코드 잡기만 연습** — 코드 전환 후 즉시 스트로크해서 '연주 흐름' 익히기
4. **바레 코드를 너무 일찍 시도** — 오픈 코드를 완전히 익힌 후 바레 코드로 진행

### 기타 코드 자가 진단

- [ ] G → C → Am → Em 코드 전환이 1박 안에 완성되는가?
- [ ] 코드 전환 후 첫 스트로크가 끊기지 않는가?

## 확장 코드는 7th라는 골격 위에 색을 입히는 겁니다

재즈나 세련된 팝에서 들리는 그 풍부하고 몽롱한 화음, 확장 코드에서 나와요. 그런데 이걸 처음부터 9도, 11도, 13도를 다 욱여넣으려 하면 손도 귀도 감당이 안 됩니다. 확장 코드에는 순서가 있어요. 먼저 7th 코드(maj7, m7, dom7)를 골격으로 확실히 잡으세요. 이 세 종류의 7th가 손에 익어야 그 위에 색을 더할 토대가 생깁니다. 골격 없이 텐션부터 쌓으면 화음이 붕 떠요.

7th가 잡혔으면 텐션을 한 단계씩 더합니다. 9도를 먼저 얹어 그 소리에 익숙해지고, 그다음 11도, 13도로 넓혀 가는 거예요. 한꺼번에 말고 하나씩 귀로 그 색깔을 느끼며 쌓아야 확장 코드가 지식이 아니라 감각으로 남습니다.

톤 세팅도 신경 쓰세요. 확장 코드의 겹겹이 쌓인 음들은 트레블이 강하면 서로 부딪혀 날카롭게 들립니다. 톤 노브를 4~6 범위로 살짝 줄이면 음들이 부드럽게 뭉쳐 그 둥근 재즈 색감이 살아나요. 재즈 코드를 실제 곡에 적용하는 법은 [기타 재즈 코드·재즈 보이싱](/stories/practice-room-guitar-jazz-voicing1)에서 이어집니다.
