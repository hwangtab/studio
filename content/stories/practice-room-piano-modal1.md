# 피아노 모달 재즈·마일스 데이비스·모드 스케일 — 음악연습실 완전 가이드

모달 재즈(Modal Jazz)는 **코드 진행 대신 모드(Mode)를 중심으로 즉흥연주하는 재즈**입니다. Miles Davis의 "Kind of Blue" (1959)가 기점. 빠른 코드 변화 대신 하나의 모드 위에서 자유롭게 멜로디를 탐구합니다. Bill Evans, John Coltrane이 이 접근을 완성했습니다.

---

## 모달 재즈란?

### 비밥 vs 모달

| | 비밥 재즈 | 모달 재즈 |
|--|---------|---------|
| 코드 | 빠르게 변함 | 느리게 변하거나 하나 |
| 즉흥 | 코드 톤 중심 | 모드 스케일 중심 |
| 느낌 | 수직적 (코드별) | 수평적 (자유롭게 흐름) |
| 대표곡 | "Cherokee" | "So What" |

### "Kind of Blue" 혁명

**"So What" 분석:**
```
A 섹션: D 도리안 모드 (16마디)
B 섹션: Eb 도리안 모드 (8마디)
A 섹션: D 도리안 (8마디)
= 단 2개의 코드로 전체 곡
```

---

## 7가지 교회 모드

### 모드 개요

C 메이저 스케일에서 각 음을 시작점으로:

```
C-D-E-F-G-A-B: C 아이오니안 (=C 메이저)
D-E-F-G-A-B-C: D 도리안
E-F-G-A-B-C-D: E 프리지안
F-G-A-B-C-D-E: F 리디안
G-A-B-C-D-E-F: G 믹솔리디안
A-B-C-D-E-F-G: A 에올리안 (=A 단조)
B-C-D-E-F-G-A: B 로크리안
```

### 각 모드의 특성

| 모드 | 특성 | 느낌 |
|-----|------|------|
| 아이오니안 | 메이저 스케일 | 밝고 안정 |
| 도리안 | 단조 + 장6음 | 재즈 단조 |
| 프리지안 | 단조 + b2 | 플라멩코, 스페인 |
| 리디안 | 메이저 + #4 | 몽환적, 밝음 |
| 믹솔리디안 | 메이저 + b7 | 블루스, 록 |
| 에올리안 | 자연 단조 | 어둡고 슬픔 |
| 로크리안 | 감소된 단조 | 불안정, 긴장 |

## 도리안 모드 (Dorian)

### 도리안의 특성

**D 도리안:** D-E-F-G-A-B-C

메이저 스케일과 비교:
```
D 메이저: D-E-F#-G-A-B-C#
D 도리안: D-E-F-G-A-B-C (b3, b7)
```

**소리:** 단조이지만 6음(B)이 장조처럼 밝음 = 재즈적 단조

### 도리안 보이싱

**"So What" 코드 보이싱:**
```
Bill Evans의 "So What" 보이싱:
왼손: D-A (5도)
오른손: G-C-F (4도 스택)
= 4도 스택 보이싱
```

**D 도리안 보이싱 옵션:**
```
1. 단순: D-F-A-C (Dm7)
2. 4도 스택: D-G-C-F (열린 보이싱)
3: 폴리코드: Dm7/Am7 (상성부 Am7)
```

### 도리안 즉흥

**D 도리안에서 즉흥 핵심 음:**
```
D, F, A, C: 코드 톤
E, G, B: 색깔 음
특히 B(장6음): 도리안의 정체성
```

---

## 믹솔리디안 모드 (Mixolydian)

### 믹솔리디안의 특성

**G 믹솔리디안:** G-A-B-C-D-E-F

```
G 메이저와 차이: F 대신 F# → F (b7)
= 블루스·록의 본질적 스케일
```

**소리:** 메이저이지만 b7으로 약간 어두움 = 블루스적

### 모달 재즈에서 믹솔리디안

**"Freddie Freeloader" (Kind of Blue) 스타일:**
```
Bb7 → Bb 믹솔리디안
Eb7 → Eb 믹솔리디안
F7 → F 믹솔리디안
= 블루스 구조를 모달로
```

---

## 리디안 모드 (Lydian)

### 리디안의 특성

**F 리디안:** F-G-A-B-C-D-E

```
F 메이저와 차이: Bb 대신 B(#4)
= 밝고 몽환적인 소리
```

### 리디안 활용

**Lydian 보이싱:**
```
Fmaj7#11 코드:
F-A-C-E-B (#11=B)
위로 빛나는 느낌
```

**John Coltrane 스타일:**
```
리디안을 임시 토닉으로
그 위에서 자유롭게 멜로디
```

## Bill Evans 모달 피아노 스타일

### 간결한 보이싱

Bill Evans (Miles Davis Quartet)의 핵심:
- **3도 없는 보이싱:** 5도와 7음 중심
- **공간:** 음표를 적게
- **투명한 텍스처:** 겹치지 않는 소리

**Evans 스타일 Dm7 보이싱:**
```
대신: D-F-A-C (풍성한 보이싱)
Evans: D-A-C (3도 생략)
또는: A-C (2음만)
= 투명하고 개방적
```

### 왼손 2성부

**Evans 왼손:**
```
루트 + 7음: D + C
루트 + 5음: D + A
= 두 음만으로 코드 암시
```

**오른손:** 도리안 스케일 위에서 자유로운 멜로디

### 레프트 핸드 보이싱

**"So What" 코드:**
```
왼손: D-A (5도)
오른손: G-C-F (4도 두 겹)
총 5음 = 넓게 펼쳐진 보이싱
```

## 모달 즉흥 방법론

### 코드 톤 vs 모드 스케일

**비밥 접근 (코드별):**
```
Am7: A-C-E-G (코드 톤 위주)
D7: D-F#-A-C (코드 톤 위주)
= 코드마다 다른 스케일
```

**모달 접근 (한 모드 위):**
```
A 도리안 전체:
A-B-C-D-E-F#-G
코드 변화 관계없이 이 스케일로 자유롭게
```

### 모달 즉흥 실전

**"So What" 스타일:**
```
D 도리안 (D-E-F-G-A-B-C)
이 음들로 8마디 자유롭게
강박: D, F, A, C (코드 톤)
약박: E, G, B (색깔)
= 선율의 흐름이 코드를 따르지 않음
```

## 음악연습실 모달 피아노 연습

### 60분 루틴

**1. 모드 스케일 (15분)**
   - D 도리안 모든 옥타브
   - G 믹솔리디안
   - F 리디안
   - 각 모드의 색깔 느끼기

**2. 모달 보이싱 (15분)**
   - "So What" 4도 스택 보이싱
   - Evans 스타일 간결한 보이싱
   - 왼손 2음 보이싱

**3. 즉흥 연습 (20분)**
   - D 도리안 8마디 즉흥
   - 코드를 신경 쓰지 않고 모드만
   - 공간을 두고 멜로디

**4. "So What" 연주 (10분)**
   - 왼손 "So What" 보이싱
   - 오른손 D 도리안 즉흥
   - Miles Davis 녹음 들으며 비교

## 마무리

모달 재즈는 **음악의 자유**입니다. 코드 변화를 쫓아가는 것이 아니라, 하나의 색깔 안에서 깊게 탐구하는 것. Miles Davis, Bill Evans가 보여준 것처럼, 단순함 속에서 무한한 깊이가 있습니다.

은평구 24시간 음악연습실에서 도리안 모드부터 시작하세요. 8마디 동안 하나의 모드만 — 그 안에서 발견하는 멜로디가 여러분의 음악이 됩니다.
