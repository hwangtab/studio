## 관악구·동작구에서 전문 녹음실 찾기

신림·봉천·상도·노량진 주민들이 전문 보컬 녹음과 음반 제작을 위해 스튜디오 놀을 방문합니다. 2호선 합정역을 통해 6호선으로 환승하면 서울 남서부에서도 접근이 가능합니다.

---

## 각 지역에서 스튜디오 놀까지

| 출발지 | 교통편 | 소요 시간 |
|--------|--------|---------|
| 신림역 | 2호선 → 합정역 → 6호선 연신내역 | 약 35~40분 |
| 서울대입구역 | 2호선 → 합정역 → 6호선 | 약 30~35분 |
| 봉천역 | 2호선 → 합정역 → 6호선 | 약 35~40분 |
| 상도역 | 7호선 → 이수역 → 4호선 → 환승 | 약 45~50분 |
| 노량진역 | 1호선·9호선 → 당산 → 2호선 합정 → 6호선 | 약 40~45분 |
| 사당역 | 4호선 → 이수 → 7호선 → 고속터미널 → 3호선 불광 → 6호선 | 약 45분 |

**스튜디오 주소**: 서울특별시 은평구 연신내역 인근 (연신내역 3번 출구 도보 5분)

## 스튜디오 놀 서비스 요약

| 서비스 | 내용 |
|--------|------|
| 보컬 녹음 | Neumann U87, 1:1 엔지니어 세션 |
| 믹싱 | 보컬 + MR 스템 통합, 2라운드 수정 |
| 마스터링 | 스트리밍 기준 음압 최적화 |
| 패키지 | 녹음+믹싱+마스터링 합산 견적 |

정확한 견적은 카카오톡으로 목적·곡 수·일정을 알려주시면 안내드립니다.
