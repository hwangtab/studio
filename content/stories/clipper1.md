## 클리퍼 — 음압을 높이는 마스터링 도구

클리퍼는 마스터링에서 리미터와 함께 사용해 더 큰 음압을 달성하는 기법입니다.

'라우드니스 전쟁(Loudness War)'은 1990년대 CD 마스터링 경쟁에서 시작됐습니다. 라디오 방송에서 더 크게 들리는 음반이 청중의 관심을 끈다는 경험칙 때문에, 마스터링 엔지니어들은 경쟁적으로 음압을 높이기 시작했습니다. 리미터를 과도하게 걸어 다이나믹을 압착하는 방식이 주류였고, 그 결과 2000년대 주류 팝 음반은 RMS 레벨이 -6~-8dBFS에 달할 정도로 음압이 높아졌습니다. 그러나 다이나믹이 소멸된 음악은 청취 피로도가 높고 음악적 표현력이 줄었습니다. Spotify가 2017년 LUFS 기반 라우드니스 노멀라이제이션을 도입하고 Apple Music, YouTube도 이를 뒤따르면서 지나치게 높은 음압의 이점이 사라졌습니다.

소프트 클리퍼는 이 환경에서 리미터의 한계를 보완하는 해결책으로 등장했습니다. 리미터만으로 음압을 높이면 짧은 트랜지언트 피크를 처리할 때 리미터가 과격하게 작동해 "펌핑(Pumping)" 현상이 발생합니다. 소프트 클리퍼를 리미터 앞에 배치하면 길이가 짧은 트랜지언트(1~5ms 이하)를 부드러운 곡선으로 잘라내어 리미터에 가해지는 부담을 줄입니다. 클리퍼는 파형을 직각으로 자르는 하드 클리핑과 달리, 사인파 형태로 라운딩하여 짝수 배음을 추가하는 방식으로 동작하기 때문에 적당한 양에서는 새추레이션과 유사한 따뜻한 음색 변화를 만들어냅니다.

## 하드 클리핑 vs 소프트 클리핑

| 구분 | 하드 클리핑 | 소프트 클리핑 |
|------|-----------|------------|
| 동작 방식 | 임계값 초과 신호 즉시 잘라냄 | 곡선으로 부드럽게 제한 |
| 음질 특성 | 거친 왜곡·하모닉 디스토션 | 자연스러운 새추레이션 |
| 사용 목적 | 의도적 왜곡 효과 (기타 등) | 마스터링 음압 최적화 |
| 트랜지언트 | 급격히 잘라냄 | 부드럽게 라운딩 |

## 마스터링 클리퍼 체인 배치

마스터링 체인에서 소프트 클리퍼의 위치는 글루 컴프레서 후단, 리미터 전단입니다. 글루 컴프레서가 믹스 전체의 결합감을 만들고 나면 소프트 클리퍼가 짧은 피크 트랜지언트를 정리합니다. 일반적으로 클리퍼로 0.5~1.5dB를 제한한 후 리미터로 최종 True Peak -1.0dBTP를 맞추는 방식을 사용합니다. 소프트 클리퍼를 과도하게 사용하면 보컬 자음과 드럼 어택의 디테일이 뭉개지므로, 클리퍼 적용량은 Ceiling을 -0.3~0dBFS로 시작해 점진적으로 확인하며 조정합니다. 납품 규격은 스트리밍 기준 True Peak -1.0dBTP, LUFS -14(Spotify·Apple Music·멜론)이며 방송 납품 시 EBU R128 기준인 -23 LUFS가 적용됩니다.

### 마스터 버스 체인 권장 순서

1. EQ (최소 개입)
2. 글루 컴프레서 (Ratio 1.5:1, GR -1~-2dB)
3. 소프트 클리퍼 (짧은 피크 제거)
4. 리미터 (Ceiling -1.0dBTP)

### 소프트 클리퍼 설정

- **Ceiling**: 0dBFS~-0.3dBFS
- **Soft Clip Amount**: 낮게 시작 (과도하면 왜곡)
- **목적**: 리미터 전에 짧은 피크 트리밍
- 과도한 사용은 음질 저하

### 리미터 설정

- **True Peak Ceiling**: -1.0dBTP (스트리밍 기준)
- ISP(인터샘플 피크) 방지
- 최종 스트리밍 납품 기준 충족

## True Peak 관리

True Peak는 디지털-아날로그 변환(DAC) 과정에서 실제로 발생하는 인터샘플 피크(ISP, Inter-Sample Peak)입니다. 디지털 오디오는 이산적인 샘플값의 연속이기 때문에, 두 샘플 사이의 실제 아날로그 파형이 샘플값보다 높게 재구성될 수 있습니다. 이를 오버샘플링(4x 이상)으로 측정하는 것이 True Peak 미터입니다. Sample Peak가 0dBFS 이하로 보여도 True Peak는 0.5~1.5dB 높게 측정되는 사례가 흔하며, 특히 고주파 콘텐츠(사이빌런트·심벌)에서 자주 발생합니다. EBU R128 표준(2011년 채택)이 방송 마스터링에 True Peak -1.0dBTP 기준을 도입한 이후, 스트리밍 플랫폼들도 동일 기준을 적용해 현재 모든 주요 플랫폼의 납품 요건이 True Peak -1.0dBTP입니다.

### True Peak 발생 원인

- Sample Peak가 0dBFS 이하여도
  DAC 과정에서 실제 ISP 발생 가능

- 특히 High-frequency 콘텐츠에서 빈번

### True Peak 측정 툴

- Youlean Loudness Meter (무료) — LUFS + True Peak
- iZotope Insight — 상세 분석
- DAW 마스터 미터 (내장 True Peak 표시)

### 플랫폼별 True Peak 기준

- **스트리밍 (스포티파이·멜론·유튜브)**: -1.0dBTP
- **방송 EBU R128**: -1.0dBTP
- **CD**: -0.3dBTP

## 클리핑과 음질

### 클리핑이 허용되는 경우

- 의도적 디스토션 효과 (록·메탈 기타)
- 소프트 클리퍼로 새추레이션 추가
- 가볍게 적용 시 음압 향상에 기여

### 클리핑이 문제가 되는 경우

- **하드 클리핑**: 거친 왜곡 소리
- **True Peak 초과**: 스트리밍 플랫폼에서 왜곡
- **과도한 클리핑**: 보컬·악기 음질 훼손

### 올바른 마스터링 흐름

믹스 납품 (-6dBFS 헤드룸 확보)

- 마스터 버스 처리 (EQ → 컴프 → 소프트 클리퍼)
- True Peak 리미터 (-1.0dBTP)
- LUFS 확인 (-14 LUFS 스트리밍 기준)
- 납품

## Studio NOL 발매 마스터링에서 클리퍼를 활용하는 3가지 케이스

스튜디오 놀 발매 마스터링에서 클리퍼(Clipper)가 결과를 바꾸는 대표적인 활용 케이스입니다.

**1. 트랜지언트 클리퍼 — 드럼·킥 어택 보존**

리미터로 피크를 줄이면 트랜지언트가 평탄해져 펀치감이 사라집니다. 트랜지언트 클리퍼를 마스터 버스 앞단에 두고 -1~2dB 클리핑하면 가청 영역에서 거의 들리지 않으면서 헤드룸이 확보돼 후단 리미터가 더 자연스럽게 작동합니다.

**2. 보컬 채널 — 강한 피크만 살짝 자르기**

보컬 채널에 클리퍼를 살짝(GR -1dB 미만) 적용하면 갑작스러운 피크만 부드럽게 잘리고 컴프 부담이 줄어듭니다. 단, 보컬에 클리퍼를 강하게 걸면 발음이 부서지므로 매우 절제적으로 사용합니다.

**3. 마스터 단계 — 리미터 직전 1차 헤드룸 확보**

마스터링 체인에서 리미터 직전에 클리퍼를 배치하면 리미터가 처리할 피크가 줄어 GR이 -2~5dB 범위에서 안정됩니다. 클리퍼 -1dB + 리미터 -3dB의 분산이 리미터 단독 -6dB보다 다이내믹·자연스러움 모두 우수합니다.

## 마치며

클리퍼는 올바르게 사용하면 음압을 높이면서 음질을 보존하는 효과적인 도구입니다. 소프트 클리퍼를 리미터 앞에 배치해 0.5~1.5dB 수준으로 트랜지언트를 정리하면, 리미터의 펌핑 현상을 줄이면서 LUFS를 더 높게 끌어올릴 수 있습니다. 중요한 원칙은 스트리밍 납품 기준인 True Peak -1.0dBTP와 -14 LUFS를 Youlean Loudness Meter 같은 도구로 반드시 확인한 뒤 납품하는 것이며, 과도한 클리핑은 오히려 플랫폼 자동 라우드니스 다운스케일로 손해가 될 수 있습니다.
