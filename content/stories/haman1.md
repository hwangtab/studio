## 함안에서 KTX로 서울까지

함안은 경남 중부 도시로, 창원중앙역 KTX를 통해 서울과 약 2시간 40분대로 연결됩니다. 아라가야의 고장 함안에서 당일 서울 스튜디오 방문이 가능합니다.

---

## 함안 → 연신내 이동 경로

### KTX 창원중앙역 경유 (권장)

```
① 함안 → 창원중앙역 (버스 약 20~30분)
② 창원중앙역 KTX 탑승 (서울역 방면, 약 2시간~2시간 20분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 2시간 50분~3시간 30분
```

---

## 당일 왕복 일정 예시 (함안 기준)

```
오전 7시 함안 출발 → 창원중앙역 이동
오전 7시 40분 창원중앙역 KTX 출발
→ 오전 10시 서울역 도착
→ 오전 10시 40분 연신내역 도착
→ 오전 11시 세션 시작 (2시간)
→ 오후 1시 세션 완료
→ 오후 2시 30분 서울역 출발
→ 오후 4시 50분 창원중앙역 도착
→ 오후 5시 30분 함안 도착
```

## 온라인 파일 의뢰 서비스

```
함안 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
