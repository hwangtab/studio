## 경산에서 동대구역 KTX로 서울까지

경산은 대구 바로 옆 위성 도시로 영남대학교·대구가톨릭대학교 등 대학 밀집 지역입니다. 대구 지하철 1호선으로 동대구역까지 접근해 KTX로 서울과 약 2시간 30분에 연결됩니다.

---

## 경산 → 연신내 이동 경로

### 지하철 + KTX 이용 (권장)

```
① 경산역(대구 1호선) 탑승
② 동대구역까지 이동 (약 20~30분)
③ 동대구역 KTX 탑승 (서울역 방면, 약 1시간 40~50분)
④ 서울역 → 연신내역 (지하철 약 30~40분)

총 소요시간: 약 2시간 30~40분
```

---

## 영천 → 연신내 이동 경로

```
[방법 1: 고속버스]
영천 → 서울 강남터미널 (고속버스 약 3시간)
강남터미널 → 연신내역 (지하철 약 30~40분)
총: 약 3시간 30~40분

[방법 2: 동대구 KTX 환승]
영천 → 동대구역 (버스 약 40~50분)
동대구역 KTX → 서울역 (약 1시간 40~50분)
서울역 → 연신내역 (약 30~40분)
총: 약 2시간 50분~3시간
```

## 당일 왕복 일정 예시 (경산 기준)

```
오전 7시 경산역 출발 (지하철)
→ 오전 7시 30분 동대구역 도착
→ 오전 8시 KTX 출발
→ 오전 9시 50분 서울역 도착
→ 오전 10시 30분 연신내역 도착
→ 오전 11시 세션 시작 (2시간)
→ 오후 1시 세션 완료
→ 오후 2시 30분 서울역 출발
→ 오후 4시 20분 동대구역 도착
→ 오후 4시 50분 경산 도착
```
