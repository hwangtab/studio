# 베이스 투핸드 탭핑·고급 솔로 기법 — 음악연습실 완전 가이드

베이스 기타는 보통 리듬 섹션의 일부로 인식되지만, 투핸드 탭핑을 마스터하면 **완전한 솔로 악기**로 변모합니다. 빅토 우튼(Victor Wooten), 마커스 밀러(Marcus Miller), 매튜 스티븐슨의 연주처럼 베이스 하나로 멜로디, 화성, 리듬을 동시에 표현할 수 있습니다.

---

## 투핸드 탭핑 기초

### 기본 원리

탭핑은 양손 손가락으로 프렛보드를 직접 해머온하는 기법입니다.

**기본 포지션:**
- 왼손: 평소 프렛팅 위치
- 오른손: 넥을 위에서 아래로 내려다보며 손가락 삽입
- 엄지는 넥 뒤에서 지지

**타격 기법:**
- 손가락 끝으로 프렛 위를 수직으로 두드림
- 해머온의 느낌 — 튕기지 않고 닿는 즉시 지속

---

## 기본 탭핑 패턴

### 3음 탭핑 패턴

```

G|--T12-9-5-T12-9-5--|
   T = 오른손 탭

왼손: 5프렛(A), 9프렛(D)
오른손: 12프렛(E)

```

**순서:**
1. 왼손 5프렛 해머온
2. 왼손 9프렛 해머온 (5프렛 유지)
3. 오른손 12프렛 탭
4. 오른손 탭 풀오프 → 왼손 9프렛 노트
5. 왼손 9프렛 풀오프 → 5프렛 노트

### 코드 탭핑

여러 현을 동시에 탭핑으로 화음 생성:

**Am 아르페지오 탭핑:**
```

G|---T9(m)--|
D|--T7(i)---|
A|-T5(왼손)--|
```

i = 검지, m = 중지 순서로 빠르게 탭

---

## 솔로 베이스 기법

### 베이스 코드 멜로디

베이스 하나로 멜로디+화성 동시 연주:

**Autumn Leaves G단조 베이스 코드 멜로디:**
```

마디 1: Am7b5 — A현 5프렛(D멜로디) + G현 탭핑 화성
마디 2: D7 — D현 루트 + G현 탭핑 멜로디

```

### 썸 슬랩 + 탭핑 결합

빅토 우튼의 핵심 기법:

```

A|--T(탭)-p-0-T(탭)-p-0--|
   오른손 탭 → 풀오프 → 오픈 → 반복
동시에 E현: 슬랩 리듬

```

이 기법으로 베이스라인과 멜로디를 동시 연주

---

## 오른손 기법 심화

### 더블 탭

오른손 검지+중지로 연속 탭핑:

```

i = 검지, m = 중지
G|--i(12)-m(14)-i(12)-m(14)--|
```

### 오른손 핑거링

1. **검지(i)**: 가장 강한 탭, 주선율에
2. **중지(m)**: 빠른 연속 탭에
3. **약지(a)**: 고급 멀티핑거 탭에
4. **소지(c)**: 최고급 — 빅토 우튼만의 영역

---

## 연습 루틴

### 입문 단계 (60분)

**1. 오른손 탭 워밍업 (10분)**
- 한 현에서 오른손 검지 단독 탭 연습
- 소리가 균등하게 날 때까지

**2. 3음 탭핑 패턴 (20분)**
- A 마이너 3음 탭핑 BPM 60
- 각 음 명확히

**3. 아르페지오 탭핑 (20분)**
- Am, Em, Dm 아르페지오 탭핑
- 현 전환 원활하게

**4. 슬랩+탭 결합 (10분)**
- E현 슬랩 + G현 탭핑 멜로디

### 중급 단계

- 코드 탭핑 보이싱
- 솔로 베이스 편곡 제작
- 더블 탭 (i+m 교대)

## 마무리

베이스 투핸드 탭핑은 **악기의 한계를 넘는 창의적 탐구**입니다. 처음에는 오른손 탭 음이 작고 명확하지 않지만, 꾸준한 훈련으로 점점 파워와 명확성이 생깁니다.

은평구 24시간 음악연습실에서 충분한 시간을 확보하고, 천천히 한 음씩 완성해가세요. 어느 순간 베이스 하나로 오케스트라를 연상시키는 풍성한 솔로 연주가 가능해집니다.

## 탭핑을 녹음해 보면 바로 드러나는 세 가지

연습실에서 들을 때는 그럴듯했는데 막상 마이크를 대거나 DI로 받아 파형을 보면 표정이 달라지는 순간이 있습니다. 탭핑은 특히 그렇습니다. 귀는 관대하지만 파형은 정직하거든요. 녹음 부스에서 베이스 탭핑 트랙을 받다 보면 거의 매번 같은 세 가지가 걸립니다.

**첫째, 오른손 탭의 어택이 왼손보다 확연히 작습니다.**

앞서 연습 루틴에서 "오른손 탭 워밍업 10분"을 따로 떼어놓은 이유가 여기 있습니다. 왼손은 평소 프렛팅으로 단련되어 있지만 오른손 검지는 프렛보드를 수직으로 때려본 경험 자체가 적습니다. 파형으로 보면 왼손 해머온 음은 큼직하게 솟는데 오른손 탭 음만 절반 높이로 눌려 있는 그림이 나옵니다. 3음 탭핑 패턴을 BPM 60에서 돌릴 때 메트로놈보다 먼저 확인할 것은 속도가 아니라 "오른손 탭 하나만 단독으로 열 번 쳤을 때 열 번 다 같은 크기인가"입니다.

**둘째, 왼손 뮤트가 빠지면 안 친 현이 같이 울립니다.**

탭핑은 손가락이 프렛보드 위를 오가는 기법이라 사용하지 않는 개방현이 계속 공진합니다. 혼자 들을 때는 "베이스니까 원래 이런 저음이 깔리지" 하고 넘어가는데, 트랙으로 분리해 놓고 들으면 코드 탭핑 구간마다 정체불명의 저음이 뭉쳐 있습니다. Am 아르페지오 탭핑처럼 여러 현을 오가는 패턴을 연습할 때 왼손 남는 손가락으로 아래 현을 덮는 습관을 같이 넣어두세요. 나중에 고치는 것보다 처음부터 붙여놓는 편이 훨씬 쌉니다.

**셋째, 컴프레서는 연주의 편차를 덮어주지 못합니다.**

탭핑 트랙에 컴프레서를 걸면 음량 차이가 줄어드는 것처럼 들리지만, 실제로는 작은 음을 끌어올리면서 그 구간의 손 소음과 개방현 울림까지 같이 끌어올립니다. 위의 두 가지가 해결되지 않은 트랙에 컴프를 세게 걸면 오히려 지저분해집니다. 믹스에서 쓰는 컴프레서는 이미 균등한 연주를 조금 더 다듬는 도구이지, 균등하지 않은 연주를 균등하게 만드는 도구가 아닙니다. 순서는 언제나 연주 → 녹음 → 처리입니다.

---

탭핑에 시간을 쏟다 보면 정작 베이스의 본업인 리듬 섹션 감각이 무뎌지는 경우가 있습니다. 탭핑 연습과 별개로 킥 드럼에 박자를 맞추는 훈련, 스네어·하이햇과의 상호작용을 확인하는 훈련은 계속 가져가세요. 루트 음만 연주하던 단계에서 코드 톤·5도·옥타브를 조합하는 단계로 넘어가면 표현 범위가 넓어지고, 그 감각이 결국 솔로 베이스 편곡의 재료가 됩니다. 피킹과 핑거스타일을 함께 연습해 두면 탭핑 구간과 일반 연주 구간을 오갈 때 톤이 튀지 않습니다.

녹음은 이 모든 과정에서 가장 값싼 피드백 도구입니다. 스마트폰으로 간단히 녹음한 뒤 나중에 들어보면 연주 중에는 인식하지 못했던 리듬 불안정, 음정 이탈, 다이나믹 부재가 그대로 드러납니다. 자기 연주를 비판적으로 들을 수 있게 될수록 혼자 하는 교정의 효율이 올라갑니다. 그러려면 우선 연습실의 앰프나 모니터를 통해 자기 소리를 정확히 듣는 환경부터 만들어야 합니다.
