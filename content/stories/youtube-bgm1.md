## 유튜브 BGM — 직접 만드는 저작권 자유 배경음악

유튜브 크리에이터에게 오리지널 BGM은 브랜드 정체성이자 저작권 걱정 없는 자산입니다. 일관된 BGM은 채널 아이덴티티를 강화하고 시청자 기억에 남습니다.

---

## 콘텐츠 유형별 BGM 장르

계약서의 세부 조항을 꼼꼼히 확인하는 습관이 장기적으로 큰 손실을 막아줍니다.

### 채널 유형별 BGM 선택 가이드

**일상 브이로그**
- 어쿠스틱 기타 + 가벼운 퍼커션
- **BPM**: 90~110
- **분위기**: 따뜻하고 편안함

**게임·테크 리뷰**
- 신디사이저 + 전자 비트
- **BPM**: 120~140
- **분위기**: 에너지 넘치고 집중력 있음

**요리·라이프스타일**
- 재즈·보사노바·로파이
- **BPM**: 80~105
- **분위기**: 여유롭고 세련됨

**뷰티·패션**
- 팝·퓨처 베이스·가벼운 EDM
- **BPM**: 110~128
- **분위기**: 트렌디하고 밝음

**교육·강의**
- 미니멀 피아노·앰비언트
- **BPM**: 60~80
- **분위기**: 집중 방해 없이 차분함

## BGM 루프 구조 제작

아래 내용은 한국 기준이며, 해외 유통 시에는 각국 저작권 기관 정책을 별도 확인하세요.

### 실용적인 BGM 루프 구조

**인트로 (4~8마디)**
- 점진적인 악기 진입
- 주제 멜로디 소개

**메인 루프 A (8~16마디)**
- 풀 편성, 에너지 유지
- 반복 가능하도록 시작과 끝이 자연스럽게 연결

**루프 B (변주 구간)**
- 약간 다른 변주 또는 브레이크
- 긴 영상에서 단조로움 방지

**아웃트로 (4~8마디)**
- 에너지 서서히 감소
- 자연스러운 페이드 아웃

### 루프 포인트 설정 팁

- 마지막 코드가 처음과 동일한 화음으로 끝나게
- 페이드 아웃 없이 자연스럽게 이어지도록 편집
- 영상 편집 소프트웨어에서 오디오 길이 조정 용이하게

---

## BGM 제작 단계별 프로세스

발매 전 마케팅 준비가 음원 초기 성과에 결정적인 영향을 줄 수 있습니다.

### BGM 제작 흐름

- **1단계**: 레퍼런스 수집
- 본인 채널 분위기와 맞는 기존 BGM 5~10개 수집
- 공통점 파악 (BPM·악기·분위기)

- **2단계**: 기본 비트 설계
- BPM 설정 → 드럼/퍼커션 패턴 제작
- 베이스라인 추가

- **3단계**: 코드·멜로디
- 간단한 코드 진행 (발전 없이 반복해도 좋게)
- 서브 멜로디 또는 주제 악절

- **4단계**: 루프 편집
- 시작-끝 연결 확인
- 인트로·아웃트로 제작

- **5단계**: 믹싱·마스터링
- **BGM 최종 목표**: -20~-18 LUFS
- VO 덮힘 없는 주파수 관리

## 유튜브 Content ID 대응

아래 항목은 법적 효력에 관한 일반 정보이며, 구체적 사안은 전문가 상담을 권장합니다.

### Content ID 분쟁 방지

**직접 제작 BGM**
- Content ID 신고 없이 자유롭게 사용 가능
- 단, 직접 음원 유통사를 통해 Content ID 등록 시
   본인 채널에서도 수익화 가능

**샘플 팩 사용 시**
- 라이센스 확인 필수 (Royalty Free, Creative Commons)
- 일부 샘플 팩은 유튜브 상업 사용 제한 있음

**외부 음악 사용 시**
- YouTube Audio Library (무료, 저작권 없음) 활용
- Epidemic Sound·Artlist 구독 서비스 이용
