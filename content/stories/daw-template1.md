## DAW 믹싱 템플릿 — 반복 설정을 없애는 효율적인 워크플로우

믹싱 템플릿 하나로 프로젝트 시작 시간을 크게 단축하고 일관된 사운드 품질을 유지할 수 있습니다.

DAW 템플릿의 개념은 1990년대 Digidesign(현 Avid)의 Pro Tools가 세션 파일(.pts) 저장 방식을 표준화하면서 시작됐습니다. Abbey Road·Capitol Records 같은 대형 스튜디오는 반복 작업을 줄이기 위해 표준 세션 파일을 내부 공유했고, 이것이 현대 DAW 템플릿 문화의 원형입니다. 2001년 Apple의 Logic Pro 인수와 2009년 Ableton Live 8의 세션 체계 개선으로 템플릿이 홈 스튜디오에도 보편화됐습니다. 한국 K-POP 스튜디오에서는 레이블별 표준 보컬 체인 템플릿이 내부 공유되며, SM·YG·JYP는 각각 자체 플러그인 체인 설정을 표준화합니다. 버스/Aux 라우팅과 플러그인 체인 미리 설정이 1시간 이상 걸리던 세션 셋업 시간을 10분 이내로 줄인 것이 템플릿 문화의 핵심 가치입니다.

## 보컬 믹싱 기본 트랙 구성

### 보컬 믹싱 템플릿 트랙 레이아웃

1. 보컬 리드 (Lead Vocal)
  - Gate → EQ → Compressor → De-esser → EQ → Limiter
  - Reverb Send / Delay Send
2. 보컬 더블 (Double)
  - EQ → Compressor (리드보다 살짝 더 압축)
  - 리드 보컬보다 -3~6dB 낮게 레벨 설정
3. 보컬 하모니 (Harmony)
  - EQ → Compressor
  - 파트별 패닝 (L/R 분리)
4. MR 트랙 (Instrumental)
  - EQ (저역 하이패스, 보컬 충돌 대역 컷)
  - 레벨 밸런스 조절
5. Reverb Aux (Send/Return)
  - 리버브 플러그인 (Wet 100%)
  - 보컬·하모니에서 Send 양 조절
6. Delay Aux (Send/Return)
  - 딜레이 플러그인 (Wet 100%)
  - 리드 보컬에서 Send 양 조절
7. 마스터 버스 (Master)
  - EQ → Compressor → Limiter
  - True Peak -1dBTP 이하

## 세션 기본 설정

### Sample Rate & Bit Depth

- **보컬 녹음**: 24bit / 44.1kHz (권장)
- **또는**: 24bit / 48kHz
- **스트리밍 마스터링 출력**: 24bit / 44.1kHz

### Buffer Size

- **녹음 시**: 64~128 samples (저지연)
- **믹싱 시**: 512~1024 samples (CPU 여유)

### 디스플레이

- **그리드**: 1/4 Note (기본)
- **스케일**: 데시벨(dBFS) 표시

## 플러그인 체인 미리 설정

### 보컬 리드 Insert Chain 예시

1. Waves Ns1 (노이즈 게이트)
2. FabFilter Pro-Q 3 (EQ 보정)
3. Waves CLA-2A (컴프레서)
4. FabFilter Pro-Q 3 (EQ 조색)
5. Waves Renaissance De-esser
6. FabFilter Pro-L 2 (리미터)

### Reverb Aux 예시

Valhalla Room (Wet 100%)

- **Decay**: 1.5초 / Pre-delay: 20ms

### Delay Aux 예시

Waves H-Delay (Wet 100%)
1/8 note 템포 싱크 / Feedback: 25%

## DAW별 템플릿 저장 방법

### Ableton Live

File → Save Live Set as Template

- User Library/Templates에 저장
- File → New Live Set에서 불러오기

### Logic Pro

File → Save as Template

- Logic Pro X/Templates에 저장
- File → New from Template에서 불러오기

### Pro Tools

프로툴즈는 별도의 템플릿 메뉴 대신, 세션 파일을 정해진 폴더에 저장해 두고 새 곡을 시작할 때 그 파일을 복사해서 쓰는 방식입니다.

## Studio NOL 보컬 믹싱 템플릿에 항상 들어가는 3가지

스튜디오 놀에서 모든 보컬 믹싱 세션을 시작할 때 사전 설정하는 템플릿 표준입니다.

**1. 보컬 트랙 — 메인/더블L/더블R/하모니/애드립 5트랙 + 폴더 그룹화**

빈 템플릿에 보컬 5트랙 + "Vocal" 폴더 그룹을 미리 만들어 둡니다. 폴더 트랙의 Bus 라우팅으로 전체 보컬 EQ·컴프를 한 번에 적용할 수 있어 작업 효율이 크게 올라갑니다.

**2. Aux 버스 — Reverb / Delay / Parallel Comp 3개**

리버브·딜레이·패러렐 컴프 3개 Aux 버스를 미리 만들어 두고 각 보컬 트랙에서 Send 라우팅. 인서트가 아닌 Aux 분리로 드라이/웻 독립 제어가 가능하고 CPU 부하도 줄어듭니다.

**3. 마스터 버스 — Loudness 미터 + 임시 리미터**

마스터 버스에 LUFS 미터(Youlean 등)와 임시 리미터(천장 -1dBTP)를 미리 걸어두면 작업 중 라우드니스를 실시간 모니터링할 수 있습니다. 최종 마스터링은 별도 단계로 진행하되, 작업 중 -14 LUFS 기준 감각을 유지하는 것이 목적입니다.

## 마치며

믹싱 템플릿은 반복 작업을 줄이고 일관된 사운드를 유지하는 기본 도구입니다.

보컬 리드 플러그인 체인에서 Gate→EQ→Compressor 순서가 중요한 이유는 게이트가 먼저 배경 소음을 제거해야 EQ·컴프레서가 노이즈를 증폭하지 않기 때문입니다. Compressor 뒤에 두 번째 EQ를 배치하는 것은 첫 번째 EQ가 음색 보정이라면 두 번째 EQ는 압축 후 변화된 주파수 특성을 미세 조정하는 역할이기 때문이며, De-esser를 컴프레서 이후에 배치하는 것은 컴프레서가 고역(4~8kHz)을 부스트하는 경향이 있어 De-esser가 이 부스트를 인식하고 제거해야 하기 때문입니다.

버퍼 사이즈 설정에서 녹음 시 64~128 samples는 직접 모니터링 레이턴시를 3~5ms 이내로 줄이는 것이고, 믹싱 시 512~1024 samples는 플러그인 처리에 충분한 CPU 시간을 주는 것입니다. 같은 프로젝트를 녹음에서 믹싱으로 전환할 때 버퍼 사이즈를 반드시 변경해야 하며, 이를 잊으면 녹음 시 CPU 과부하로 오디오가 끊기거나 믹싱 시 불필요하게 높은 레이턴시가 발생합니다.

## 템플릿에 갇히지 않는 게 더 어렵습니다

앞에서 우리 보컬 믹싱 템플릿에 뭐가 들어가는지 풀어 놨지만, 정작 오래 일하면서 더 자주 잔소리하게 되는 쪽은 "템플릿을 언제 벗어날 것인가"입니다. 템플릿은 세팅 시간을 10분으로 줄여 주는 훌륭한 출발점이지만, 모든 곡을 같은 틀에 욱여넣기 시작하면 곡마다 다른 개성이 뭉개지거든요. 발라드와 힙합 보컬을 같은 리버브·같은 컴프 세팅으로 미는 순간, 편해진 대신 곡이 다 비슷하게 들립니다.

그래서 저는 템플릿을 '기본값'이 아니라 '오늘 이 곡에 맞게 깎아 낼 원석'으로 생각하시라고 말합니다. 세션을 열면 제일 먼저 이 곡이 템플릿의 어디를 벗어나야 하는지를 봅니다. 리버브가 길어야 하는 곡인지, 오히려 드라이하게 가야 하는 곡인지. 이 판단을 매번 새로 하는 게 템플릿을 제대로 쓰는 실력이에요.

입문자라면 남이 만든 템플릿을 받아 쓰기보다 직접 하나 만들어 보길 권합니다. 트랙을 왜 이렇게 나누고 체인을 왜 이 순서로 거는지 스스로 정하는 과정에서 믹싱 감각이 붙거든요. 내 템플릿으로 뽑은 결과가 어딘가 막힌다면 그 상태 그대로 들고 오셔도 됩니다. [믹싱 의뢰 요금 안내](/pricing)를 참고해 세션을 잡으면, 어느 지점에서 세팅이 곡을 누르고 있는지 같이 찾아 드릴 수 있습니다.
