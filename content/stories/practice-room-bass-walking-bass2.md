# 베이스 워킹 베이스라인 심화편 — 연신내 음악연습실 재즈 워킹 완전 가이드

재즈 워킹 베이스라인의 기초(루트·5도·아르페지오)를 익혔다면, 이제 크로매틱 접근음·코드 대리·선율적 워킹으로 완성도를 높일 차례입니다. 연신내 음악연습실에서 중급~고급 워킹 베이스 기법을 단계적으로 익히는 방법을 소개합니다.

## 워킹 베이스라인 복습

기본 워킹 베이스는 4/4 박자에서 4분음표로 쉬지 않고 움직이는 베이스라인입니다.
- **1박**: 코드 루트 또는 코드 톤
- **2박**: 코드 톤 또는 스케일 음
- **3박**: 코드 톤 또는 접근음
- **4박**: 다음 코드로 향하는 이끔음 (Leading Tone)

4박의 이끔음이 워킹 베이스의 핵심이며, 이것을 얼마나 다양하게 변화시키느냐가 워킹의 수준을 결정합니다.

## 크로매틱 접근음 (Chromatic Approach)

크로매틱 접근음은 다음 코드 루트에서 반음 위 또는 아래 음으로 접근하는 기법입니다.

### 반음 위에서 접근
G7 → Cmaj7 진행:
```
G7: G . . Ab | Cmaj7: C . . .
```
Ab가 C의 반음 위에서 접근하는 크로매틱 어프로치입니다.

### 반음 아래에서 접근
G7 → Cmaj7 진행:
```
G7: G . . B | Cmaj7: C . . .
```
B(시)가 C의 반음 아래에서 접근합니다. 이 방식이 더 자연스럽고 재즈적입니다.

### 더블 크로매틱 (Double Chromatic)
두 반음 아래에서 두 음을 연속으로 접근하는 고급 기법입니다.
```
G7: G . Bb B | Cmaj7: C . . .
```
Bb→B→C의 반음 두 단계 접근입니다.

## 대리 코드 워킹 (Substitute Chord Walking)

재즈에서 원래 코드를 다른 코드로 대리하는 기법을 워킹 베이스에 적용합니다.

### 트라이톤 대리 (Tritone Substitution)
도미넌트 7th 코드를 3전음(감5도) 위/아래 코드로 대리합니다.
- G7의 트라이톤 대리: Db7
- G7 → Cmaj7를 Db7 → Cmaj7로 변환

**워킹 적용**:
```
원래: G7: G B D F | Cmaj7: C
대리: Db7: Db F Ab Cb | Cmaj7: C
```
Db7의 워킹이 반음씩 하행하여 C로 자연스럽게 이어집니다.

### 관련 ii 대리 (Related ii Substitution)
V7 앞에 관련 ii 코드를 삽입하는 방법입니다.
- G7 앞에 Dm7 삽입: Dm7 → G7 → Cmaj7
- 워킹이 2배 이상 풍성해집니다.

## 선율적 워킹 (Melodic Walking)

선율적 워킹은 단순한 화성 코드 음을 넘어, 악기처럼 노래하는 베이스라인을 만드는 기법입니다.

### 스케일 활용 워킹
코드 루트에서 상행·하행 스케일을 따라 자연스럽게 움직이는 방법입니다.

**Cmaj7 위에서 C 장조 스케일 워킹**:
```
C D E F | (다음 코드로)
```
단순하지만 선율적 흐름이 있어 귀에 친숙합니다.

### 멜로디 인용 워킹
연주 중인 곡의 멜로디를 베이스 워킹에 인용하는 고급 기법입니다. 주로 마지막 박이나 강박에 멜로디 음을 배치하는 방식으로 사용합니다.

## 더블타임 워킹 (Double Time Walking)

더블타임 워킹은 기본 4분음표 워킹을 8분음표로 두 배 빠르게 연주하는 기법입니다. 곡의 특정 구간에서 에너지를 올리거나 솔리스트와 반응할 때 효과적입니다.

### 더블타임 패턴
```
일반 워킹: C . G . | (4분음표)
더블타임: C D E F | G A B C | (8분음표, 두 배 빠름)
```

**주의**: 더블타임은 전체 곡에 지속하면 피로하고 과해집니다. 8마디마다 4마디 구간에 선택적으로 적용하는 것이 적절합니다.

## ii-V-I 진행에서의 고급 워킹

### ii-V-I 크로매틱 워킹 예시 (C 메이저)
```
마디1 Dm7: D . F . E . Ab (Ab = G7로의 크로매틱 접근)
마디2 G7:  G . B . D . B  (B = Cmaj7로의 반음 아래 접근)
마디3 Cmaj7: C . E . G . D (D = 9도, 선율적)
```

## 연신내 음악연습실에서 워킹 심화 연습 루틴

| 시간 | 내용 |
|-----|------|
| 0~10분 | 기본 워킹 베이스 확인 (C 장조 ii-V-I) |
| 10~20분 | 크로매틱 단음 접근 연습 (각 코드 루트 위로·아래로) |
| 20~30분 | 더블 크로매틱 적용 ii-V-I |
| 30~40분 | 트라이톤 대리 적용 워킹 |
| 40~50분 | 선율적 워킹 — 스케일 기반 상행·하행 워킹 |
| 50~60분 | 재즈 스탠다드 1곡 전체 워킹 베이스 연주 |

## 워킹 베이스 흔한 실수 (심화)

### 크로매틱 접근이 너무 많은 문제
크로매틱 접근음을 모든 코드마다 사용하면 화성 흐름이 흐려집니다. 구조적으로 중요한 코드 변화 지점에만 선택적으로 적용하세요.

### 더블타임이 전체 그루브를 흔드는 문제
더블타임 워킹 중 드러머의 그루브와 맞지 않으면 앙상블이 무너집니다. 독자 연습보다 드럼 루프와 함께 훈련하는 것이 중요합니다.

## 추천 레퍼런스

- **Paul Chambers**: 크로매틱 워킹의 표준 — Miles Davis Quintet
- **Ron Carter**: 선율적 워킹의 완성, 강한 내성 화성 감각
- **Ray Brown**: 파워풀하고 명확한 워킹, 교과서적 4분음표 그루브
- **Scott LaFaro**: 더블타임·선율적 워킹의 혁신 (Bill Evans Trio)

## 마무리

워킹 베이스라인은 베이시스트의 화성 이해와 리듬 감각이 동시에 발현되는 재즈의 핵심 기술입니다. 크로매틱 접근·코드 대리·더블타임이 자연스럽게 통합될 때까지 연신내 음악연습실에서 꾸준히 쌓아가세요. 워킹 베이스가 완성되면 어떤 재즈 앙상블에서도 신뢰받는 베이시스트가 될 수 있습니다.
