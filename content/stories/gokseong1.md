## 곡성에서 KTX로 서울까지

곡성은 전남 동부 내륙 도시로, 순천역 KTX를 통해 서울과 연결됩니다. '기차마을'로 유명한 곡성에서 실제 기차(KTX)를 타고 서울 녹음 세션을 다녀올 수 있습니다.

---

## 곡성 → 연신내 이동 경로

### KTX 순천역 경유 (권장)

```
① 곡성 → 순천역 (버스 약 40~50분)
② 순천역 KTX 탑승 (서울역 방면, 약 2시간 30~40분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간 40분~4시간
```

### KTX 광주송정역 경유

```
① 곡성 → 광주송정역 (버스 약 1시간~1시간 20분)
② 광주송정역 KTX 탑승 (서울역 방면, 약 1시간 40~50분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간 20~50분
```

---

## 당일 왕복 일정 예시 (곡성 기준)

```
오전 6시 곡성 출발 → 순천역 이동
오전 7시 순천역 KTX 출발
→ 오전 9시 40분 서울역 도착
→ 오전 10시 20분 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 서울역 출발
→ 오후 4시 40분 순천역 도착
→ 오후 5시 30분 곡성 도착
```
