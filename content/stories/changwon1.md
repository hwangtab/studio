## 경남에서 KTX로 서울까지

창원·마산·진해는 경상남도의 주요 도시로, KTX 창원중앙역을 통해 서울과 연결됩니다. 전문 보컬 녹음과 음반 제작을 위해 연신내 스튜디오 놀을 당일 왕복으로 이용할 수 있습니다.

---

## 창원 → 연신내 이동 경로

```
① 창원중앙역에서 KTX 탑승 (서울역 방면)
② 서울역 도착 (약 2시간 30~40분)
③ 1호선 서울역 → 신도림 → 2호선 합정역 → 6호선 연신내역
   또는 1호선 서울역 → 용산역 → 경의중앙선 → 홍대입구 → 환승

총 소요시간: 약 3시간~3시간 20분
```

---

## 당일 왕복 일정 예시 (창원 기준)

```
오전 6시 30분 창원중앙역 출발 (KTX)
→ 오전 9시 10분 서울역 도착
→ 오전 10시 연신내역 도착
→ 오전 10시 30분 세션 시작 (2~3시간)
→ 오후 1시 세션 완료
→ 오후 3시 서울역 출발 (KTX)
→ 오후 5시 40분 창원중앙역 도착
```

## 온라인 파일 의뢰 서비스

```

→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송

→ 완성 WAV + MP3 온라인 납품
```
