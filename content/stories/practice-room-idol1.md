## 아이돌 준비생, 개인 연습 시간이 실력을 결정합니다

기획사 연습생이든 독립 준비생이든, 개인 연습 시간의 양과 질이 오디션 결과를 좌우합니다.

공용 연습실의 한계:
- **시간 경쟁**: 인기 시간대 예약 불가
- **눈치 문화**: 남이 있으면 마음껏 못 함
- **운영 시간**: 저녁·새벽 이용 불가
- **소음 걱정**: 발성·고음 연습 제약

개인 방음 연습실은 이 모든 제약에서 자유롭습니다.

## 아이돌 준비생 단계별 연습실 활용법

### 오디션 준비 (D-30~D-7)

- 오디션 보컬 곡 전구간 완벽 숙달
- 스마트폰 녹화 → 표정·시선·손동작 점검
- PA 스피커로 실제 오디션 볼륨 체험
- 마이크 스탠드 앞 퍼포먼스 반복 연습

### 보컬 트레이닝 병행

- 레슨 내용 당일 적용 (기억 굳히기)
- 발성·호흡 훈련 → 실제 곡 적용
- 고음·폴세토 집중 연습 (방음 필수)

### 자기 점검 루틴

- 매 연습 시작 전 워밍업 (스케일 5분)
- 전 곡 논스톱 퍼포먼스 2회
- 스마트폰 녹화 → 레슨 선생님께 공유
- 쿨다운 스트레칭 + 목 관리

## 오디션 준비 체크리스트

- [ ] 오디션 지원 장르·곡 스타일 확인
- [ ] 자기소개 멘트 + 보컬 곡 2~3개 준비
- [ ] 의상·헤어까지 완성한 상태로 퍼포먼스 영상 촬영
- [ ] 심사위원 앞 상황 시뮬레이션 (서서 오디션 환경 재현)
- [ ] 실수해도 계속 이어가는 연습 (멈추지 않기)

### K-POP 보컬에서 자주 하는 실수

1. **원곡 가수 흉내를 내려 함** — 레퍼런스는 '스타일'만 참고, 자신의 목소리로 해석
2. **고음 구간 반복 연습 과다** — 목 피로 주의, 전체 곡의 흐름도 함께 연습
3. **다이나믹 없이 처음부터 끝까지 같은 강도** — 벌스(여리게) → 코러스(강하게) 대비를 의식

### K-POP 보컬 자가 진단

- [ ] 자신만의 음색과 감정으로 곡을 해석하는가?
- [ ] 벌스와 코러스의 에너지 차이가 느껴지는가?
- [ ] 반주 없이 멜로디와 가사를 정확하게 부를 수 있는가?

## 4주 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 점검 | 기본기 복습, 문제 구간 파악 | 40분 |
| 2주차 | 구간 집중 | 어려운 부분 느린 템포 반복 | 45분 |
| 3주차 | 전체 흐름 | 전곡 연결, 템포 단계적 올리기 | 50분 |
| 4주차 | 완성 | 목표 템포 + 표현·다이나믹 완성 | 60분 |

**주간 체크포인트:** 1주차: 약점 구간 3개 목록 작성 / 2주차: 각 구간 느린 템포 100% 달성 / 3주차: 전곡 끊김 없이 완주 / 4주차: 청중 앞 또는 녹음으로 최종 확인
