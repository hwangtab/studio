## 이천·여주·안성에서 전문 녹음실 찾기

경기 동남부 이천·여주·안성 지역은 서울 도심까지 거리가 있지만, 전문 보컬 녹음과 음반 제작을 위해 스튜디오 놀을 방문하는 분들이 계십니다. 방문이 부담스럽다면 온라인 파일 의뢰로도 동일한 수준의 서비스를 이용할 수 있습니다.

---

## 각 지역에서 스튜디오 놀까지

| 출발지 | 교통편 | 소요 시간 |
|--------|--------|---------|
| 이천 버스터미널 | 버스 → 동서울터미널 → 지하철 연신내역 | 약 1시간 40분~2시간 |
| 이천 (자가용) | 서울외곽순환 → 연신내 방면 | 약 1시간 20분 (교통 상황에 따라) |
| 여주역 (경강선) | 경강선 → 판교역 → 신분당선 → 강남역 → 연신내역 | 약 1시간 20분 |
| 여주 (버스) | 강남 고속터미널 → 지하철 연신내역 | 약 1시간 20~40분 |
| 안성 버스터미널 | 서울 고속버스터미널 → 지하철 연신내역 | 약 1시간 40분 |

**스튜디오 주소**: 서울특별시 은평구 (연신내역 3번 출구 도보 5분)

---

## 온라인 파일 의뢰로 방문 없이 이용하기

거리가 먼 경우 현지에서 녹음 후 파일만 전송하는 방법이 효율적입니다:

신호 경로 전체를 점검해두면 녹음 중 예상치 못한 문제를 방지할 수 있습니다.

이천·여주·안성 현지 녹음실에서 보컬 WAV 녹음
- 구글 드라이브 또는 WeTransfer 업로드
- 카카오톡으로 링크 전송
- 믹싱·마스터링 작업 (영업일 2~5일)
- 완성 WAV + MP3 파일 납품

**파일 요구사항**:
- 보컬: WAV 44.1kHz/24bit (에코·리버브 없는 드라이 파일)
- MR: WAV 44.1kHz/16bit 이상

## 이 지역 고객이 스튜디오 놀을 이용하는 이유

| 이유 | 설명 |
|------|------|
| 전문 장비 | Neumann U87 AI 마이크, 전문 흡음 부스 |
| 온라인 의뢰 가능 | 방문 없이 파일 전송만으로 믹싱 가능 |
| 음원 발매까지 | 녹음 → 믹싱 → 마스터링 → 유통 연계 안내 |
| 합리적 가격 | 홍대·강남 대비 합리적 견적 |

## 스튜디오 놀 서비스

| 서비스 | 내용 |
|--------|------|
| 보컬 녹음 | Neumann U87, 전용 흡음 부스, 실시간 엔지니어 디렉팅 |
| 믹싱 | 보컬 + MR 통합 믹스, 2라운드 수정 포함 |
| 마스터링 | 스트리밍 플랫폼 기준 음압 최적화 |
| 온라인 파일 의뢰 | 파일 전송으로 믹싱·마스터링만 의뢰 가능 |
