# 기타 핑거스타일 편곡·솔로 기타 어레인지 — 음악연습실 완전 가이드

솔로 핑거스타일 기타는 **단 하나의 악기로 밴드 전체의 음악을 표현**하는 예술입니다. 멜로디는 위에서 노래하고, 코드는 중간에서 하모니를 만들고, 베이스는 아래에서 리듬을 지탱합니다. 이 세 가지 층위를 동시에 컨트롤하는 것이 솔로 기타 어레인지의 핵심입니다.

---

## 솔로 기타 편곡의 3층 구조

### 1층: 베이스 라인

**역할:** 리듬과 화성의 토대
**현:** 주로 4, 5, 6번 현
**기법:** 엄지 손가락으로 알터네이팅 베이스 또는 루트 타격

**기본 베이스 패턴:**
```
4/4박자 G 코드:
박 1: G2 (6번 현)
박 3: D3 (4번 현)
```

### 2층: 내부 코드 보이싱

**역할:** 하모니와 음색 채우기
**현:** 3, 4번 현 (주로)
**기법:** 검지·중지·약지로 아르페지오 또는 동시 타격

### 3층: 멜로디

**역할:** 주선율, 청중이 듣는 핵심 음
**현:** 1, 2번 현 (주로)
**기법:** 엄지 외의 손가락으로 멜로디 노트 강조

---

## 편곡 프로세스

### 단계 1: 원곡 분석

편곡할 곡의 원본을 분석합니다:
- **키(Key)**: 기타에 맞는 키 선택 (개방현 활용 가능한 키 우선)
- **코드 진행**: 모든 코드 파악
- **멜로디**: 음역대와 리듬 파악
- **리듬 패턴**: 원곡의 groove 특성

### 단계 2: 포지션 결정

기타의 어떤 포지션(프렛 구역)에서 연주할지 결정:
- **개방 포지션 (0-4 fret)**: 가장 풍부한 공명, 개방현 활용
- **카포 사용**: 높은 키를 개방 포지션처럼 연주

### 단계 3: 멜로디 배치

멜로디 음을 기타 지판에 배치. 핵심 원칙:
- **멜로디는 가장 높은 음**이어야 함
- 내부 코드 음은 멜로디보다 낮게 배치
- 같은 현에서 멜로디와 베이스를 동시에 낼 수 없으므로 잘 배분

### 단계 4: 베이스 배치

베이스 라인 추가:
- 코드 루트 또는 5도
- 박 1과 3에 강박 베이스
- 알터네이팅 베이스로 리듬감 강화

---

## 실용 편곡 예시: "House of the Rising Sun"

원곡: The Animals (Am 키, 아르페지오 스타일)

**기본 아르페지오 패턴:**
```
Am:  A2 - C4 - E4 - A4 - C5 - E4 (6박자 아르페지오)
C:   C3 - E4 - G4 - C5 - E4 - G4
D:   D3 - F4 - A4 - D5 - F4 - A4
F:   F3 - A4 - C5 - F5 - A4 - C5
```

**멜로디 통합:**
- "There is a house..."의 멜로디 음을 각 아르페지오의 최고음으로 배치
- 멜로디가 없는 박자에 아르페지오 필

## 핵심 편곡 기법

### 멜로디 하모나이제이션

단선율 멜로디에 하모니를 추가하는 기법:

**3도 하모니:**
멜로디 아래 3도 음 추가 — 가장 자연스러운 하모니

**6도 하모니:**
멜로디 아래 6도 — 달콤한 사운드

**예시 (G 장조 스케일):**
```
멜로디:  G4 - A4 - B4 - C5
3도 아래: E4 - F#4 - G4 - A4
```

### 베이스 워킹

코드 전환 시 베이스에 경과음 삽입:

```
G → C 진행 (4박 이동):
G2 - A2 - B2 - C3 (반음씩 상행)
```

### 하모닉스 활용

자연 하모닉스로 벨-타운 효과:
- 12프렛: 1 옥타브 위 하모닉스
- 7프렛: 1 옥타브 + 5도 위
- 5프렛: 2 옥타브 위

## 음악연습실 편곡 연습 루틴

### 입문 (1주차)

1. 기존 솔로 기타 악보로 연주 — Tommy Emmanuel 쉬운 곡
2. 아르페지오 패턴 다양화 연습
3. 엄지 + 검지 독립성 훈련

### 중급 (2-4주차)

1. 간단한 곡(동요, 민요) 직접 편곡
2. 멜로디 + 코드만 먼저 완성
3. 베이스 라인 추가
4. 알터네이팅 베이스로 발전

### 심화

1. 팝 발라드 편곡 (4-8주)
2. 재즈 스탠다드 솔로 편곡
3. 원곡의 재해석과 창의적 변형
