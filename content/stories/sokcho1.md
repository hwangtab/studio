## 속초에서 서울까지 약 3시간

속초는 KTX가 직통으로 연결되지 않지만, 직행 고속버스로 약 2시간 30분~3시간 내에 서울에 도착할 수 있습니다. 이른 첫차를 이용하면 당일 녹음 세션 후 귀가가 가능합니다.

---

## 속초 → 연신내 이동 경로

### 고속버스 이용 (권장)

```
① 속초 고속버스터미널 출발
② 서울 강남터미널 또는 동서울터미널 도착
   (약 2시간 30분~3시간)
③ 강남터미널 → 3호선 → 환승 → 연신내역 (약 30~40분)
   또는 동서울 → 2호선 → 환승 → 연신내역 (약 40~50분)

총 소요시간: 약 3~3시간 30분
```

### KTX 강릉선 환승

```
① 속초 → 강릉역 (시외버스 약 1시간)
② 강릉역 KTX 탑승 → 청량리역 (약 2시간)
③ 청량리 → 지하철 → 연신내역 (약 40~50분)

총 소요시간: 약 3시간 50분~4시간
```

## 당일 왕복 일정 예시 (속초 기준)

```
오전 6시 속초터미널 출발 (첫 고속버스)
→ 오전 9시 강남터미널 도착
→ 오전 9시 40분 연신내역 도착
→ 오전 10시 세션 시작 (2~3시간)
→ 오후 1시 세션 완료
→ 오후 2시 30분 강남터미널 출발
→ 오후 5시~6시 속초 도착
```

## 온라인 파일 의뢰 서비스

```
속초 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
