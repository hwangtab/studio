# 재즈펑크 드럼·James Brown·The Meters·뉴올리언스 그루브 — 음악연습실 완전 가이드

재즈펑크 드럼(Jazz-Funk Drums)은 **재즈의 스윙 느낌과 펑크의 강력한 그루브가 합쳐진 스타일**입니다. Clyde Stubblefield의 "Funky Drummer", Zigaboo Modeliste(The Meters)의 뉴올리언스 세컨드라인, Bernard Purdie의 "Purdie Shuffle" — 이들이 재즈펑크 드럼의 전설을 만들었습니다.

---

## 재즈펑크란?

### 재즈 + 펑크의 결합

**재즈펑크의 역사:**
```
1960년대: James Brown이 펑크 창조
The Meters: 뉴올리언스 펑크
1970년대: Herbie Hancock 헤드헌터스
= 재즈 뮤지션들이 그루브에 눈뜸
```

**재즈펑크 드럼의 특징:**
```
재즈 스윙 필링 + 강한 1박·3박
16분음표 중심 (펑크)
라이드 심벌 스윙 + 스네어 밸런스
= 스윙과 그루브의 혼합
```

---

## Clyde Stubblefield 스타일

### "Funky Drummer"의 전설

**"Funky Drummer" (1970, James Brown):**
```
세상에서 가장 많이 샘플된 드럼
= 힙합·R&B 수천 개 곡에 사용됨
```

**"Funky Drummer" 패턴:**
```
HH: 16분음표로 일정하게
SD: 1  e  +  a  2     +
BD: 1        +     2     a
= 강한 1박 킥 + 엇박 스네어
```

**Clyde Stubblefield의 핵심:**
```
"포켓": 비트 뒤에 앉는 느낌
= 레잉 백 드럼 그루브
약하게 치는 것 같지만 강한 그루브
```

---

## Zigaboo Modeliste & The Meters

### 뉴올리언스 세컨드라인

**뉴올리언스 세컨드라인:**
```
장례 행렬 음악에서 유래
= 아프리카 리듬 + 마칭 밴드
독특한 신코페이션 스네어
```

**세컨드라인 패턴:**
```
HH: 1  +  2  +  3  +  4  +
SD: 1  e     a  2     +  a
BD: 1        a     e     a
= 예측 불가능하게 터지는 그루브
```

**Zigaboo 특징:**
```
예상치 못한 스네어 위치
히햇 엇박 강조
= "춤추고 싶어지는" 뉴올리언스 그루브
```

---

## Bernard Purdie Shuffle

### R&B 드럼의 황금 패턴

**Purdie Shuffle:**
```
하이햇 셔플 + 고스트 노트 스네어
= 스윙 느낌의 셔플 그루브
```

**Purdie Shuffle 패턴:**
```
HH: 1    +    2    +    3    +    4    +
    ↑  x  ↑  x  ↑  x  ↑  x  (x = 고스트)
SD: 2          4          (메인)
    + 고스트 노트들 사이사이에
```

**"Half-Time Shuffle" (Led Zeppelin "Fool in the Rain"):**
```
John Bonham이 Purdie Shuffle 활용
= 록의 셔플 그루브
```

## 재즈 스윙 + 펑크 통합

### 라이드 심벌 스윙

**재즈 라이드 패턴:**
```
1  +  2  +  3  +  4  +
↑     ↑  ↑  ↑     ↑  ↑  (트리플렛 느낌)
```

**재즈 스윙 + 펑크 그루브:**
```
라이드: 재즈 스윙 패턴
스네어: 펑크 2·4박 강조
킥: 펑크 싱코페이션
= 재즈펑크 하이브리드
```

---

## 재즈펑크 드럼 톤

### 빈티지 그루브 사운드

**재즈펑크 킥:**
```
짧고 둥근 킥 사운드 (오버뮤팅)
= 팡팡 튀는 느낌 아닌 둥근 느낌
```

**스네어 고스트 노트:**
```
매우 가볍게 치는 스네어
= 그루브 사이에 필인
부드럽고 섬세한 소리
```

**하이햇 다이나믹:**
```
강한 하이햇: 다운비트
약한 하이햇: 업비트
= 다이나믹 하이햇이 그루브 만듦
```

## 음악연습실 재즈펑크 드럼 연습

### 60분 루틴

**1. "Funky Drummer" 패턴 (15분)**
   - ♩= 90에서 기본 패턴
   - 레잉 백 느낌 연습
   - 포켓 안에 앉는 느낌

**2. 뉴올리언스 세컨드라인 (15분)**
   - 엇박 스네어 패턴
   - 히햇 업비트 강조
   - 춤추고 싶은 그루브 찾기

**3. Purdie Shuffle (15분)**
   - 셔플 하이햇 + 고스트 노트
   - 느린 템포에서 시작 (♩= 70)
   - 점점 빠르게

**4. 재즈 라이드 + 펑크 (15분)**
   - 라이드 스윙 패턴
   - 스네어 펑크 그루브 추가
   - 전체 재즈펑크 통합

## 마무리

재즈펑크 드럼은 **영혼과 그루브가 만나는 교차점**입니다. Clyde Stubblefield가 "그루브는 느끼는 것이지 계산하는 것이 아니다"고 했듯, 재즈펑크 드럼은 머리보다 몸이 먼저 반응해야 합니다. 포켓 안에서 레잉 백하는 그 순간, 재즈와 펑크가 하나가 됩니다.

은평구 24시간 음악연습실에서 "Funky Drummer" 패턴부터 시작하세요. 비트가 뒤로 앉는 그 순간, 재즈펑크의 그루브가 찾아옵니다.
