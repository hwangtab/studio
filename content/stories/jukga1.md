## 축가 — 결혼식에서 가장 기억에 남는 순간

축가는 결혼식장에서 직접 부르는 노래로, 신혼부부에게 평생 기억에 남는 선물입니다. 충분한 준비로 최고의 축가를 선사하세요.

---

## 축가 선곡 기준

| 기준 | 내용 |
|------|------|
| 음역대 | 자신의 편안한 음역에 맞는 곡 |
| 가사 내용 | 결혼·사랑·축복 메시지 |
| 곡 분위기 | 결혼식 전체 분위기와 어울림 |
| 신랑·신부 취향 | 신혼부부가 좋아하는 곡 우선 |
| 하객 인지도 | 하객이 아는 곡이면 호응이 좋음 |

---

## 축가 준비 단계

```
[D-30 이전]
① 곡 선정 및 신랑·신부 확인
② 원곡 키 확인 — 내 키와 맞는지 체크
③ 키 조절 필요 시 MR 준비
④ 가사 완전 암기 시작

[D-14]
⑤ MR에 맞춰 매일 연습
⑥ 스튜디오 연습 녹음 — 부족한 부분 파악
⑦ 어려운 구간 집중 훈련

[D-7]
⑧ 결혼식 회장 방문 또는 마이크 환경 파악
⑨ 결혼식 의상 입고 연습 (의상이 발성에 영향 줄 수 있음)

[D-1]
⑩ 과도한 연습 금지 — 성대 쉬기
⑪ 충분한 수분 섭취·수면

[당일]
⑫ 행사 전 워밍업 (15분)
⑬ 마이크 테스트 요청 (음량 확인)
⑭ 심호흡으로 긴장 완화
```

---

## 축가 MR 준비 가이드

```
[MR 구하기]
- 음원 앱 (멜론, 지니, 벅스) MR 다운로드
- 유튜브 검색: "[곡명] MR" 또는 "[곡명] Instrumental"
- MR 제작 의뢰 (스튜디오에서 가능)

[키 조절]
- 앱: Transpose Music, Amazing Slow Downer
- 스튜디오 의뢰: 엔지니어가 피치 시프트 처리

[파일 형식]
- WAV 또는 MP3 고음질
- USB 또는 블루투스 스피커로 전달
- 행사 담당자에게 미리 전달 및 확인
```

---

## 스튜디오 축가 녹음 활용법

```
[연습용 녹음]
- 세션 중 연습 녹음 후 듣고 수정
- 취약 구간 파악 → 집중 훈련
- 완성도 높은 연습 단계 확인

[기념 녹음]
- 결혼식 전후 스튜디오에서 완성도 있는 녹음
- WAV + MP3 납품
- 신혼부부에게 선물로 전달

[공식 녹음 (결혼식 영상 삽입용)]
- 결혼식 영상에 삽입할 완성 버전 녹음
- 믹싱·마스터링으로 전문 음원 품질 완성
```

## 축가 라이브 성공 팁

```
✓ 마이크 거리 유지
  → 평소보다 약간 멀리 (10~15cm) — 울림 있는 공간

✓ 긴장되면 호흡 먼저
  → 노래 시작 전 복식호흡 3회

✓ 하객을 보며 부르기
  → 한 곳만 보지 않고 자연스러운 시선 이동

✓ MR 볼륨 체크
  → 행사 전 결혼식장 PA 담당자에게 MR 볼륨 사전 확인

✓ 가사는 외워서
  → 가사지 없이 부르는 것이 더 자연스러운 표현
```
