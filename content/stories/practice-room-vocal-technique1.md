      개인실에서 느린 속도부터 반복 훈련하면 빠르게 완성됩니다.
  - q: 자연스러운 애드리브는 어떻게 만드나요?
    a: >-
      애드리브 훈련: ① 코드 노트 파악 — 해당 코드의 구성음 알기 ② 짧은 것부터 — 한두 음 추가에서 시작 ③ 감정으로 시작 —
      감정이 넘칠 때 자연스럽게 나오는 것 ④ 좋아하는 가수 카피 → 자신의 것으로 변형 ⑤ 반주 없이 연습 → 반주와 함께. 애드리브는
      '만드는 것'이 아니라 '감정에서 나오는 것'이므로 음악에 완전히 몰입하는 연습이 필요합니다.
  - q: 멜리스마를 연습할 때 목이 상하지 않는 방법은?
    a: >-
      성대 건강 멜리스마 연습: ① 워밍업 충분히 — 10분 이상 발성 준비 ② 과도한 힘 금지 — 부드러운 발성에서 자연스럽게 ③ 수분
      섭취 — 연습 전·중·후 물 충분히 ④ 피로하면 즉시 중단 — 성대 과부하 금지 ⑤ 쉬는 날 설정 — 매일 멜리스마 연습은 금물.
      성대를 보호하면서 점진적으로 발전시키는 것이 장기적으로 더 효과적입니다.

## 화려한 테크닉은 준비된 순간에 빛납니다

멜리스마와 런은 가장 화려하지만 가장 훈련이 많이 필요한 기술입니다. 방음 개인실에서 느린 속도부터 철저히 훈련하세요.

보컬 테크닉 연습의 핵심:
- **정확성 우선**: 빠르게 불기 전에 정확한 음정으로 천천히
- **패턴 암기**: 런의 음정 순서를 완전히 외우기
- **자연스러운 연결**: 앞뒤 구절과 유기적으로 이어지게
- **감정 기반**: 기교를 위한 기교가 아닌 감정 표현 도구

## 런 연습 기본 패턴

### 상행 런 (기초)

```

도 레 미 파 솔 라 시 도 (스케일 상행)
느린 속도 → 점진적 가속
각 음정 명확하게

```

### 하행 런 (기초)

```

도 시 라 솔 파 미 레 도 (스케일 하행)
끝음 안정적으로 착지

```

### 지그재그 런 (중급)

```

도 미 레 파 미 솔 파 라 솔 시 라 도
음 하나씩 건너뛰는 패턴

```

## 멜리스마 훈련 방법

**단계 1: 분석**
- 원곡 멜리스마 구간을 천천히 듣기
- 음정 진행 악보화 또는 음이름 파악

**단계 2: 느린 연습**
- BPM 50~60으로 한 음씩 정확하게
- 오른손으로 음정 치면서 확인

**단계 3: 속도 향상**
- BPM을 10씩 올리면서 반복
- 목표 BPM까지 단계적으로

**단계 4: 감정 연결**
- 기계적이 아닌 감정을 담아서
- 앞뒤 구절과 자연스럽게 연결

| 기법 | 추천 곡 | 포인트 |
|-----|------|--------|
| 비브라토 | 조성모 — To Heaven | 자연스러운 비브라토 |
| 멜리스마 | 백지영 — 총 맞은 것처럼 | 애드립·런 |
| 다이나믹 | 이선희 — 아름다운 강산 | 강약 폭 |
| 스타카토 | 소녀시대 — Gee | 리듬감·발음 |

### 보컬 테크닉에서 자주 하는 실수

1. **비브라토를 억지로 만들려 함** — 비브라토는 이완된 상태에서 자연스럽게 발생, 강제 금물
2. **멜리스마를 빠르기로만 평가** — 각 음이 명확히 구분되어야 멜리스마, 뭉개지면 의미 없음
3. **한 가지 다이나믹으로만 노래** — mp~ff 구간을 의식적으로 나눠서 다이나믹 폭 훈련

### 보컬 테크닉 자가 진단

- [ ] 비브라토가 목 근육이 아닌 횡격막에서 나오고 있는가?
- [ ] 멜리스마 구간에서 각 음이 명확하게 들리는가?
- [ ] 한 곡 안에서 최소 3단계 다이나믹 변화가 있는가?

## 4주 보컬 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 발성 기초 | 복식호흡 확인, 모음 발성 Ma·Me·Mi·Mo·Mu | 35분 |
| 2주차 | 음역대 | 시작음 A~C로 5음 스케일, 고음 접근법 | 40분 |
| 3주차 | 곡 연습 | 목표 곡 섹션별, 문제 음정 반복 | 45분 |
| 4주차 | 완성 | MR에 맞춰 전곡, 감정 표현·다이나믹 | 50분 |

**주간 체크포인트:** 1주차: 배에서 소리 나오는 느낌 확인 / 2주차: 고음에서 힘 빼기 성공 여부 / 3주차: 문제 음정 3회 연속 성공 / 4주차: 녹음 후 자기 모니터링

## 연습실에서 더 효과적으로

**보컬 연습실에서만 가능한 연습:**
- 실제 목소리의 최대 볼륨 발성 연습 (집에서 불가)
- 감정·다이나믹 폭이 큰 표현 훈련
- 자신의 소리를 방 울림과 함께 객관적으로 청취
