# 피아노 래그타임·Scott Joplin 스타일 — 음악연습실 완전 가이드

래그타임(Ragtime)은 **재즈와 클래식의 교차점**에서 탄생한 미국의 피아노 음악입니다. 1890년대~1920년대 Scott Joplin의 "Maple Leaf Rag", "The Entertainer"로 세계적으로 알려졌습니다. 규칙적인 왼손 베이스 위에 싱코페이션(엇박)된 오른손 멜로디가 결합합니다.

---

## 래그타임의 구조

### 기본 형식

래그타임은 보통 **16마디 섹션 여러 개**로 구성:

```
A 섹션 (16마디) × 2
B 섹션 (16마디) × 2
A 섹션 (16마디) × 1
C 섹션 (16마디) × 2
...
```

**조성:** 보통 C, G, F, Bb, Eb 메이저

### 템포

```
래그타임 표준 템포: ♩= 72-96 BPM
주의: "Not too fast" — Joplin이 직접 악보에 기재
빠르게 치면 래그타임이 아님!
```

---

## 왼손 래그타임 패턴

### 기본 um-pah 패턴

래그타임 왼손의 핵심:

```
1박: 낮은 베이스 음 (단음)
2박: 코드 (중음역)
3박: 낮은 베이스 음 (단음)
4박: 코드 (중음역)
= "um pah um pah" 패턴
```

**C 메이저 기본:**
```
1박: C2 (단음)
2박: E4-G4 (코드)
3박: C2 (단음)
4박: E4-G4 (코드)
```

### 왼손 변형 패턴

**베이스 음 이동 (Stride 연결):**
```
1박: C2
2박: E4-G4-C5
3박: G2 (5도)
4박: D4-G4-B4
C → G 코드로 자연스럽게 연결
```

**10도 점프:**
```
1박: C2 (낮은 C)
2박: E4-G4 (높은 E, 10도 위)
아트 테이텀 스타일의 와이드 스트라이드
```

## 오른손 싱코페이션

### 싱코페이션 원리

래그타임 오른손은 **박자를 엇나가게** 칩니다:

```
왼손 박자: 1 2 3 4 (규칙적)
오른손 멜로디: 1+ 2 3+ 4+ (엇박)
                   ^    ^  ^  싱코페이션
```

**효과:** 강박과 약박의 역전으로 스윙 느낌 생성.

### 기본 싱코페이션 패턴

**C 메이저 싱코페이션:**
```
왼손: C2 / E4-G4 / C2 / E4-G4
오른손: G4(1박) C5(2+박) E5(3박) G5(3+박)
        정확히       엇박      정확히    엇박
```

## "The Entertainer" 분석

Scott Joplin의 대표작:

### A 섹션 오프닝

```
도입부 (2마디):
오른손: C5-E5-D5 (옥타브 위) → 시작 모티프
왼손: 없음 (오른손만)
```

**첫 A 테마:**
```
오른손 멜로디: 엇박 8분음표 중심
왼손: um-pah um-pah 베이스
조성: C 메이저
```

### 전조 섹션

"The Entertainer"는 **F 메이저로 전조**:
```
C 메이저 A 섹션 → F 메이저 B 섹션
5도 위로 이동하여 밝은 느낌 강조
```

---

## "Maple Leaf Rag" 분석

Joplin의 첫 히트작 (1899):

### Ab 메이저의 매력

**Ab 메이저 특성:**
- 부드럽고 따뜻한 톤
- 흑건 중심 (Eb, Bb, Ab, Db, Gb)
- 초보자에게 어려운 조성

**왼손 Ab 래그타임:**
```
1박: Ab2 (낮은 Ab)
2박: Eb4-Ab4-C5 (코드)
3박: Ab2
4박: Eb4-Ab4-C5
```

### 특징적 리듬 모티프

```
3개 16분음표 + 8분음표:
Ab4-C5-Eb5 / Ab5 (길게)
이 패턴이 래그타임의 정체성
```

## 래그타임 장식음

### 그레이스 노트 (Appoggiatura)

**래그타임 장식음:**
```
주요 음 직전에 반음 또는 온음 위
빠르게 연주 (앞꾸밈음)
예: Db5 → C5 (빠르게)
```

### 트릴

```
오른손 트릴: 고음 두 음을 빠르게 교번
예: C5-D5 트릴 (8-16회 빠르게)
```

### 글리산도

```
건반을 손가락 등으로 훑어 내리기
래그타임 끝부분에 화려하게 사용
```

## James Scott & Joseph Lamb 스타일

### James Scott

Missouri 출신, Joplin과 함께 래그타임 3대 거장:

**특징:**
- 더 활기차고 빠른 템포
- 복잡한 리듬 패턴
- "Frog Legs Rag" (1906) 대표작

**Scott 스타일 오른손:**
```
더 많은 싱코페이션
연속 16분음표 패시지
기교적 요소 강조
```

### Joseph Lamb

뉴욕 출신, 백인 최초의 클래식 래그타임 작곡가:

**특징:**
- 더 서정적이고 클래식적
- 세련된 화성 진행
- "Sensation Rag" (1908) 대표작

**Lamb 스타일:**
```
부드러운 왼손 베이스
클래식 화성 어휘 사용
감정적 깊이 강조
```

## 래그타임 연주 팁

### 템포 안정성

래그타임의 가장 큰 실수: **빠르게 치는 것**

```
Joplin의 원칙: "Do not play this piece fast"
적정 템포: ♩= 72-88
메트로놈 사용 필수
```

### 왼손·오른손 독립성

**훈련법:**
1. 왼손만 (um-pah 패턴) → 완벽하게
2. 오른손만 (싱코페이션) → 완벽하게
3. 합치기 → 느린 템포에서
4. 템포 점진적으로 올리기

### 아티큘레이션

```
오른손 레가토: 멜로디 부드럽게
왼손 스타카토: 베이스 음 또렷하게
대비가 래그타임의 핵심
```
