# 슈게이징 기타·Wall of Sound·My Bloody Valentine·Slowdive 스타일 — 음악연습실 완전 가이드

슈게이징 기타(Shoegaze Guitar)는 **이펙터와 피드백으로 "소리의 벽(Wall of Sound)"을 만드는 영국 인디 록 스타일**입니다. My Bloody Valentine의 Kevin Shields의 무아지경 기타, Slowdive의 몽환적 드리밍, Cocteau Twins의 텍스처 기타 — 슈게이징은 기타가 악기가 아닌 소리 풍경(soundscape)이 되는 음악입니다.

---

## 슈게이징이란?

### 신발을 바라보는 음악

**슈게이징의 유래:**
```
1980년대 후반~1990년대 영국
"신발을 바라본다" = 이펙터 페달을 조작
= 무대에서 페달만 바라보는 연주자들
```

**슈게이징의 특징:**
```
이펙터 중심 (레이어된 텍스처)
보컬이 악기처럼 묻힘 (텍스처의 일부)
반복적인 코드·리프
감정적·몽환적 분위기
```

**슈게이징 밴드:**
```
My Bloody Valentine: "Loveless" (1991) — 슈게이징 성경
Slowdive: 꿈결 같은 슈게이징
Cocteau Twins: 텍스처 팝
Ride: 멜로딕 슈게이징
```

---

## My Bloody Valentine 스타일

### 슈게이징의 교과서

Kevin Shields:
- **스태거드 스트로킹:** 손목 비틀기로 독특한 비브라토
- **워블(Wobble):** 트레몰로 암 독특한 사용
- **이펙터 레이어:** 여러 이펙터 동시에

**"Only Shallow" 스타일:**
```
드래밍 드럼 패턴
레이어된 기타 텍스처
보컬이 기타 안에 묻힘
= 소리의 폭풍 속 아름다운 멜로디
```

**워블 기법:**
```
트레몰로 암을 손바닥으로 누르며
= 피치가 흔들리는 독특한 비브라토
독특한 MBV 사운드의 핵심
```

---

## Slowdive 스타일

### 꿈결 같은 드리밍

Slowdive:
- **리버브 기반 텍스처:** 긴 리버브로 음이 녹아듦
- **클린 코드 + 이펙터:** 기본 클린 코드 위에 이펙터
- **서정적 멜로디:** 아름다운 멜로디가 텍스처 안에

**"Alison" 스타일:**
```
클린 기타 코드 (C-G-Am-F)
긴 리버브 + 딜레이로 공간감
보컬 멜로디가 기타 텍스처 위에 떠다님
```

---

## 슈게이징 이펙터 체인

### Wall of Sound 만들기

**필수 이펙터:**
```
디스토션/퍼즈: 소리 거칠게 만들기
코러스: 여러 기타 레이어 느낌
딜레이: 반복음으로 레이어 쌓기
리버브: 큰 공간감 (홀, 스프링)
트레몰로: 볼륨 흔들기 (MBV 스타일)
```

**슈게이징 체인 순서:**
```
기타 → 퍼즈 → 코러스 → 딜레이 → 리버브 → 앰프
```

**리버브 세팅:**
```
리버브 타임: 5~10초 (매우 긴)
프리딜레이: 30~50ms
믹스: 70~100% (거의 전부 리버브)
= 소리가 공간에 녹아드는 느낌
```

## 슈게이징 코드 보이싱

### 몽환적인 화음

**오픈 드로닝 코드:**
```
Dsus2: x-0-0-2-3-0 (열린 현 드론)
Asus4: x-0-2-2-0-0
= 지속음 드론 위의 코드
```

**Capo 활용:**
```
카포를 여러 프렛에 사용
= 열린 현의 높은 음역 버전
독특한 공명과 텍스처
```

**파워 코드 + 리버브:**
```
파워 코드에 긴 리버브
= 무거움 + 공간감의 혼합
```

---

## 레이어링 기법

### 소리의 벽 만들기

**레이어 1: 드론 기타**
```
낮은 현을 개방하여 지속음 드론
= 모든 소리의 기반
```

**레이어 2: 리듬 기타**
```
코드 스트로크 + 코러스
= 두꺼운 리듬 텍스처
```

**레이어 3: 멜로디 기타**
```
단음 멜로디 + 딜레이
= 텍스처 위에 떠다니는 멜로디
```

## 음악연습실 슈게이징 기타 연습

### 60분 루틴

**1. 이펙터 세팅 (10분)**
   - 리버브 5~8초로 세팅
   - 딜레이 400ms, 피드백 60%
   - 코러스 깊게

**2. 드로닝 코드 (15분)**
   - Dsus2-Asus4 교대
   - 이펙터 풀로 열고
   - 소리가 녹아드는 느낌

**3. MBV 워블 기법 (15분)**
   - 트레몰로 암 손바닥으로 누르기
   - 코드 연주하며 워블
   - Kevin Shields 느낌

**4. 즉흥 슈게이징 (20분)**
   - 자유로운 코드 + 텍스처
   - 멜로디 레이어 추가
   - 소리의 벽 만들기

## 마무리

슈게이징 기타는 **소리가 음악이 되는 경험**입니다. Kevin Shields가 "나는 소리를 페인트처럼 칠한다"고 했듯, 슈게이징 기타는 악기를 넘어 소리 자체를 조각합니다. 코드 하나에 이펙터를 더하면, 기타가 오케스트라가 되고 그 소리가 방을 가득 채웁니다.

은평구 24시간 음악연습실에서 리버브 긴 세팅부터 시작하세요. 소리가 공간에 녹아드는 순간, 슈게이징의 세계가 펼쳐집니다.

---


슈게이징 기타 사운드는 드라이브와 리버브, 모듈레이션 이펙트를 겹쳐 만드는 두꺼운 앰비언트 월이 특징입니다. 볼륨 스웰과 피드백 노트를 활용하면 음표와 소음의 경계가 허물어지는 독특한 텍스처를 연출할 수 있습니다. 연습실에서는 각 이펙트를 하나씩 추가하면서 소리의 변화를 귀로 확인하는 실험적인 접근이 슈게이징 사운드 메이킹의 핵심입니다.
