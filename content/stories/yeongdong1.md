## 영동에서 KTX로 서울까지

영동은 충북 최남단 도시로, KTX 경부선 영동역이 시내와 가까워 서울까지 약 1시간 30분대로 연결됩니다. 와인과 포도의 고장 영동에서 당일 서울 스튜디오 방문이 가능합니다.

---

## 영동 → 연신내 이동 경로

### KTX 영동역 직접 탑승 (권장)

```
① 영동 시내 → 영동역 (버스·택시 약 10~15분)
② 영동역 KTX 탑승 (서울역 방면, 약 1시간~1시간 15분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 1시간 40분~2시간 10분
```

---

## 당일 왕복 일정 예시 (영동 기준)

```
오전 8시 30분 영동역 KTX 출발
→ 오전 9시 40분 서울역 도착
→ 오전 10시 20분 연신내역 도착
→ 오전 11시 세션 시작 (2시간)
→ 오후 1시 세션 완료
→ 오후 3시 서울역 출발
→ 오후 4시 10분 영동역 도착
→ 오후 4시 25분 영동 시내 도착
```

---

## 온라인 파일 의뢰 서비스

```
영동 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
