# 기타 비밥·재즈 기타 즉흥·Wes Montgomery — 음악연습실 완전 가이드

재즈 기타는 **피아노와 호른의 즉흥 언어를 6줄 위에 구현**하는 예술입니다. Wes Montgomery의 옥타브 주법, Joe Pass의 솔로 기타, Jim Hall의 서정적 접근—각각 재즈 기타의 다른 차원을 보여줍니다.

---

## 재즈 기타의 기초

### 재즈 기타 세팅

**클린 톤이 기본:**
```

앰프: 클린 (절대 디스토션 없음)
픽업: 넥 픽업 (따뜻한 톤)
볼륨: 풀 또는 약간 낮게
톤: 5-7 (약간 어둡게)

```

**기타 선택:**
- 아치탑(Archtop): 풀박스, 세미할로우
- 세미할로우: Gibson ES-335 타입
- 솔리드바디: Stratocaster도 가능 (장르에 따라)

### 재즈 기타 보이싱

**재즈 피아노의 보이싱을 기타로:**
```

기타로 Cmaj7 보이싱:
3-2-1번 줄: E4-G4-C5 (탑 3줄)
또는
4-3-2-1번 줄: G3-E4-G4-B4 (4줄)

```

---

## Wes Montgomery 스타일

### 옥타브 주법

Wes Montgomery의 시그니처:

**옥타브 주법 원리:**
```

두 줄을 동시에, 한 음정 차이 = 옥타브
예: 3번 줄 G4 + 1번 줄 G5 (8도 차)
손가락으로 사이 줄(2번 줄)을 뮤트

```

**기본 옥타브 폼 (G):**
```
1번 줄: 3프렛 G5
2번 줄: 뮤트 (검지 등으로)
3번 줄: 5프렛 G4

피크 없이 엄지로 연주 (Wes Montgomery 방식)

```

### 엄지 주법

Wes Montgomery는 **피크 없이 엄지로만** 연주:

```

장점: 따뜻하고 부드러운 톤
단점: 속도 제한 있음
Wes는 엄지로 놀라운 속도 달성

```

### Wes Montgomery 즉흥 구조

**3단계 즉흥 접근:**
1. **단음 라인:** 기본 비밥 라인 (1단)
2. **옥타브:** 같은 라인을 옥타브로 (2단)
3. **코드 멜로디:** 코드로 클라이맥스 (3단)

---

## Joe Pass 솔로 기타 스타일

### 코드-멜로디 동시 연주

Joe Pass의 솔로 기타 기법:

**코드 + 멜로디 동시:**
```

오른손 엄지: 베이스 음
오른손 손가락: 코드 내부 음
오른손 검지: 멜로디 음 (최상단)
= 세 레이어를 동시에

```

**"Autumn Leaves" 솔로 기타 어프로치:**
```

Em7: E2(베이스) + E4-G4-B4-D5(코드) + B4 또는 D5(멜로디)
Am7: A2(베이스) + A4-C5-E5-G5(코드) + E5(멜로디)

```

### 패스 스타일 진행

Joe Pass는 코드 사이를 **크로매틱 베이스**로 연결:

```

Cmaj7 → Am7:
C2(베이스) → B1 → Bb1 → A1(Am7 베이스)
크로매틱 하행 베이스 워킹

```

## Jim Hall 서정적 접근

### 미니멀리즘

Jim Hall (Chick Corea, Bill Evans 협연):
- **공간:** 음과 음 사이 쉬는 것
- **색깔:** 장르를 넘나드는 음색
- **대화:** 다른 악기와의 상호작용

**Hall 스타일 단음 라인:**
```

빠른 패시지 없음
각 음이 의미 있게
공간을 두고 멜로디

```

## 비밥 기타 스케일

### 비밥 스케일 활용

재즈 기타의 핵심 스케일:

**G 믹솔리디안 비밥:**
```

G-A-B-C-D-E-F-F#-G (8음)
F와 F# 사이 크로매틱 음 추가
4분음표에 맞음 (8음 = 2마디)

```

**D 도리안 비밥:**
```

D-E-F-G-A-B-C-C#-D
C와 C# 사이 크로매틱 추가

```

### 코드 톤 아르페지오

비밥 기타의 핵심 = 코드 음 사용:

**Dm7 아르페지오 위치:**
```
1 포지션: D4-F4-A4-C5 (저음 포지션)
2 포지션: A3-C4-D4-F4 (중음)
3 포지션: F3-A3-C4-D4 (고음 포지션)

```

---

## ii-V-I 재즈 기타 즉흥

### 기본 ii-V-I 라인

**Am7 - D7 - Gmaj7 라인:**
```

Am7 (1마디):
A4-C5-E5-G5 (코드 톤 상행)
또는
A4-B4-C5-D5 (도리안 스케일)

D7 (1마디):
D4-F#4-A4-C5 (코드 톤)
또는 Db4-C4-B3-A3 (트리톤 서브 어프로치)

Gmaj7 (2마디):
G4-A4-B4-C5-D5 (G 메이저 스케일)
해결감

```

### 크로매틱 접근

```

D7 → Gmaj7 해결 시:
D7 라인 끝: F#4 또는 Ab4 (반음 위)
→ G4로 해결

```

## 기타 보이싱 재즈 스타일

### 드랍 2 보이싱 (Drop 2)

```

클로즈 보이싱: G4-B4-D5-F5 (G7)
드랍 2: D4-G4-B4-F5 (2번째 음을 옥타브 아래)
기타에서 연주하기 쉬운 형태

```

**재즈 기타의 표준 보이싱:**
```
4-3-2-1번 줄 사용
5번 줄: 루트 (베이스)
4-3-2-1: 드랍 2 보이싱

```

### 텐션 추가

```

Cmaj7 기본: C-E-G-B
Cmaj9: C-E-G-B-D (9th 추가)
Cmaj7#11: C-E-G-B-F# (#11 추가)

```

## 음악연습실 재즈 기타 연습

### 60분 루틴

**1. 워밍업 + 보이싱 (10분)**
   - 기본 재즈 코드 보이싱 복습
   - ii-V-I 코드 모든 포지션
   - 드랍 2 보이싱 연습

**2. 스케일·아르페지오 (15분)**
   - 비밥 스케일 전포지션
   - 코드 톤 아르페지오 Dm7-G7-Cmaj7
   - 크로매틱 접근음

**3. Wes Montgomery 옥타브 (15분)**
   - 옥타브 폼 익히기
   - 스케일 라인을 옥타브로
   - 엄지 연주 시도

**4. ii-V-I 즉흥 (20분)**
   - Am7-D7-Gmaj7 즉흥
   - 단음 → 옥타브 → 코드 순서
   - 녹음 후 분석

## 마무리

재즈 기타는 **음악적 대화의 예술**입니다. Wes Montgomery의 옥타브, Joe Pass의 솔로 기타, Jim Hall의 서정성—각 마스터에게서 배울 것이 무궁무진합니다.

은평구 24시간 음악연습실에서 ii-V-I를 완벽히 익히고, 스탠다드 곡에 즉흥연주를 탐구하세요. 재즈 기타의 세계는 배울수록 깊어집니다.

---

재즈 비밥 기타의 핵심은 코드 보이싱과 즉흥 솔로 멜로디 라인을 유기적으로 연결하는 능력입니다. 챨리 크리스찬과 웨스 몽고메리의 솔로를 채보하고 직접 연주해보는 것이 비밥 어법을 이해하는 가장 효율적인 방법입니다. 연습실에서는 리얼 북의 스탠다드 곡들을 바탕으로 코드 멜로디 연주와 솔로를 번갈아 연습하세요.

어쿠스틱 기타에서 핑거피킹의 오른손 독립성을 키우는 것이 핵심 과제입니다. 엄지는 저음현, 검지·중지·약지는 고음현을 담당하는 기본 배치에서 시작해 점차 복잡한 아르페지오 패턴으로 발전합니다. 손가락 끝의 각도를 일정하게 유지하면 음량 균형이 자연스럽게 맞춰집니다. 스트러밍과 핑거피킹을 한 곡 안에서 자연스럽게 전환하는 능력을 키우면 표현 범위가 크게 확장됩니다. 카포를 활용해 다양한 키에서 같은 코드 보이싱을 연습하면 응용력이 빠르게 향상됩니다. 음악을 배우는 과정에서 이론과 실기를 함께 발전시키는 것이 이상적입니다. 화성학 기초를 이해하면 코드 진행을 귀로 파악하는 능력이 향상되고, 즉흥 연주나 작곡의 기반이 됩니다. 악보를 보고 연주하는 초견 능력은 꾸준히 새로운 악보를 접하는 훈련으로만 향상됩니다. 함께 연주할 동료를 찾아 앙상블 경험을 쌓는 것도 개인 연습에서는 얻기 어려운 실전 감각을 키워주는 중요한 방법입니다.
