## 성북구·동대문구에서 전문 녹음실 찾기

성신여대·길음·청량리·전농 주민들이 전문 보컬 녹음을 위해 스튜디오 놀을 이용합니다. 6호선을 통해 서울 동북부에서도 편리하게 접근할 수 있습니다.

---

## 각 지역에서 스튜디오 놀까지

| 출발지 | 교통편 | 소요 시간 |
|--------|--------|---------|
| 성신여대입구역 | 4호선 → 동대문역사문화공원 → 6호선 연신내역 | 약 30~35분 |
| 길음역 | 4호선 → 동대문역사문화공원 → 6호선 | 약 30~35분 |
| 미아사거리역 | 4호선 → 동대문역사문화공원 → 6호선 | 약 35분 |
| 청량리역 | 1호선 → 동대문역사문화공원 → 6호선 | 약 35~40분 |
| 외대앞역(동대문구) | 1호선 → 동대문역사문화공원 → 6호선 | 약 35분 |
| 회기역 | 경의중앙선 → DMC역 → 6호선 연신내역 | 약 30분 |

**스튜디오 주소**: 서울특별시 은평구 연신내역 인근 (연신내역 3번 출구 도보 5분)

## 스튜디오 놀 서비스 소개

### 전문 장비

- **마이크**: Neumann U87 AI (세계 표준 컨덴서 마이크)
- **인터페이스**: Universal Audio Apollo
- **부스**: 외부 소음 완전 차단, 흡음 처리
- **모니터**: Focal 스피커

### 제공 서비스

| 서비스 | 내용 |
|--------|------|
| 보컬 녹음 | 1:1 엔지니어, 컴핑·기본 편집 포함 |
| 믹싱 | 보컬 + MR/스템 통합 믹스 |
| 마스터링 | 스트리밍 기준 최적화 |
| 패키지 | 녹음+믹싱+마스터링 합산 |

## 성북 뮤지션들이 연신내를 선택하는 이유

성북구에는 예술인 주거·작업 공간이 많아 독립 뮤지션들의 활동이 꾸준합니다. 소규모 앨범, 자작곡 싱글 등 독립 음악 프로젝트 의뢰가 많습니다. 길음역에서 6호선으로 연신내까지 약 15~20분 직행입니다.

- [ ] 아티스트 컨디션 확인 (보컬: 목 상태, 악기: 튜닝)

**세션 중**
- [ ] 테이크별 메모 (베스트/리테이크 표시)
- [ ] 문제 구간 즉시 인식하고 재녹음 결정
- [ ] 세션 종료 30분 전 마무리 시작

**후반 작업**
- [ ] 원본 파일 즉시 백업
- [ ] 믹싱 전 24시간 이상 청취 공백 유지

### 세션 효율을 높이는 팁

1. **가장 어려운 구간을 세션 초반에** — 에너지가 최고일 때 어려운 것 먼저
2. **구간 분리 녹음** — 전체 통으로 반복보다 구간별 완성 후 연결
3. **즉각 피드백** — 녹음 직후 헤드폰으로 바로 모니터링
