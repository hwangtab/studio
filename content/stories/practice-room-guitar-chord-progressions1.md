# 기타 코드 진행·전조 기법 완전 가이드 — 연신내 음악연습실 실전 연습

코드 진행(Chord Progression)은 음악의 감성적 흐름을 만드는 뼈대입니다. 단순한 I-IV-V를 넘어 전조·코드 대리·차용 코드를 이해하면 작곡과 즉흥 연주의 폭이 비약적으로 넓어집니다. 연신내 음악연습실에서 기타를 통해 코드 진행의 세계를 체계적으로 익히는 방법을 소개합니다.

## 기능 화성의 기초

### I-IV-V 기능
- **I (토닉, Tonic)**: 안정 — 집으로 돌아온 느낌
- **IV (서브도미넌트, Subdominant)**: 이동 — 집에서 나가는 느낌
- **V (도미넌트, Dominant)**: 긴장 — 집으로 돌아가야 한다는 이끔

이 세 기능의 순환이 서양 화성의 기본 논리입니다.

### G 메이저 I-IV-V
```
I: G (솔-시-레)
IV: C (도-미-솔)
V: D (레-파#-라)
```

## 팝·록에서 자주 나오는 코드 진행

### I-V-vi-IV (현대 팝의 표준)
```
G - D - Em - C (G 메이저)
또는: C - G - Am - F (C 메이저)
```
수천 개의 팝 곡이 이 진행을 사용합니다. (Pachelbel Canon의 변형)

### I-IV-I-V (블루스·록 기본)
```
G - C - G - D (블루스 12마디 기본형)
```

### I-vi-IV-V (50년대 팝·두왑)
```
C - Am - F - G
또는: G - Em - C - D
```

### ii-V-I (재즈의 핵심 진행)
```
Dm7 - G7 - Cmaj7 (C 메이저)
```
도미넌트(V7) 앞에 ii7이 추가되어 더 자연스러운 해결감을 줍니다.

## 전조(Modulation) 기법

전조는 곡 중간에 조성(Key)을 바꾸는 기법입니다. 감성의 전환·고조·충격을 만들 때 사용합니다.

### 피벗 코드 전조 (Pivot Chord Modulation)
두 조에 모두 속하는 코드를 "피벗"으로 사용해 자연스럽게 전조합니다.

**C 메이저 → G 메이저 전조 예시**:
```
C(I) - G(V) - Em(vi) - Am(ii) - D7(V7/G) - G(I of G)
```
여기서 Em은 C 메이저의 iii이자 G 메이저의 vi입니다. 이 Em을 피벗으로 사용해 G 메이저로 전조합니다.

### 직접 전조 (Direct Modulation)
피벗 없이 갑자기 다른 조로 이동하는 방식입니다.

**효과**: 충격적이고 갑작스러운 감성 변화
**주의**: 준비 없이 전조하면 어색함 → 강조 구간(코러스)에서만 사용

**반음 상향 전조 예시** (한국 팝에서 흔함):
```
C 메이저 코러스 → C# 메이저 코러스 (마지막 코러스에서 반음 상향)
```

### 평행단조 전조 (Parallel Minor Modulation)
같은 루트의 장조→단조로 전환합니다.

**C 메이저 → C 마이너**:
```
C - F - G | C 마이너: Cm - Fm - G7 - Cm
```
밝음→어두움 감성 전환에 효과적입니다.

## 코드 대리 (Chord Substitution)

코드 대리는 원래 코드를 비슷한 기능을 가진 다른 코드로 바꾸는 기법입니다.

### vi 대리 → I
I 코드(예: C) 대신 vi(Am)를 사용합니다.
- C와 Am은 C-E-G, A-C-E로 두 음을 공유
- 더 어둡고 감성적인 느낌으로 I를 표현

### IV 대리 → ii
IV(F) 대신 ii(Dm)를 사용합니다.
- F(F-A-C)와 Dm(D-F-A)이 두 음 공유
- 더 부드럽고 재즈적인 움직임

### 트라이톤 대리 → V
V7(G7) 대신 Db7를 사용합니다.
- 크로매틱 하행으로 자연스러운 해결
- 재즈·보사노바에서 즐겨 사용

## 차용 코드 (Borrowed Chord)

같은 루트의 평행 단조에서 코드를 빌려오는 기법입니다.

### C 메이저에서 C 마이너 차용
| C 마이너 코드 | C 메이저에서의 기능 |
|------------|--------------|
| Cm (i) | I를 어둡게 대체 |
| Fm (iv) | IV의 어두운 버전 |
| Ab (bVI) | 장조 안의 어두운 색채 추가 |
| Bb (bVII) | 록·팝에서 가장 흔한 차용 |

**Bb 차용 예시** (C 메이저):
```
C - Bb - F - C (C - bVII - IV - I)
```
이 Bb(바♭)가 들어간 순간 록·팝 특유의 어두운 에너지가 생깁니다.

## 연신내 음악연습실에서 코드 진행 연습 루틴

| 시간 | 내용 |
|-----|------|
| 0~10분 | 5가지 기본 팝 진행 3키(G·C·D)에서 연습 |
| 10~25분 | 피벗 코드 전조 — C→G, G→D 전조 |
| 25~35분 | 평행단조 전조 — C→Cm 전조 |
| 35~45분 | 코드 대리 적용 (vi 대리 I, ii 대리 IV) |
| 45~55분 | 차용 코드 — Bb(bVII) 삽입 연습 |
| 55~60분 | 자유 작곡 — 전조+차용 코드 포함한 8마디 진행 완성 |

## 코드 진행 학습 시 흔한 실수

### 이론만 알고 적용을 못하는 문제
코드 이론을 외운 뒤 실제 기타로 적용하지 않으면 아무 의미가 없습니다. 모든 개념을 기타 위에서 즉시 연주하며 귀로 확인하는 것이 필수입니다.

### 한 조(Key)에서만 연습하는 문제
C 메이저에서만 코드 진행을 익히면 다른 키에서 코드 이름이 바뀔 때 혼란스럽습니다. 반드시 G·D·F·Bb 등 여러 키에서 같은 진행을 반복 연습하세요.

## 추천 레퍼런스 (코드 진행 학습)

- **The Beatles**: 다양한 전조·차용 코드의 보물창고
- **Radiohead**: 현대적이고 비전통적인 코드 진행
- **Bill Withers**: 간결하지만 완벽한 팝 코드 구조
- **Antonio Carlos Jobim**: 보사노바의 아름다운 코드 대리

## 마무리

코드 진행과 전조를 이해하면 남의 곡을 분석하는 능력이 생기고, 자신만의 작곡 아이디어가 풍부해집니다. 연신내 음악연습실에서 기타를 손에 들고, 배운 모든 진행을 직접 연주하며 귀로 체득하는 과정을 즐겨보세요.
