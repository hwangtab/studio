# 드럼 패러디들·루디먼트·스틱 컨트롤 심화 — 음악연습실 완전 가이드

패러디들(Paradiddle)은 **드럼 루디먼트의 핵심**입니다. R-L-R-R / L-R-L-L의 단순한 스트로크 조합이지만, 이것을 마스터하면 드럼의 모든 고급 기법이 열립니다. Buddy Rich, Gene Krupa, Billy Cobham — 모든 위대한 드러머는 루디먼트 위에 세워졌습니다.

---

## 루디먼트란?

### 드럼의 알파벳

**루디먼트(Rudiment):** 드럼 연주의 기본 스트로크 패턴.

**40 Essential Drum Rudiments:**
```

NARD(National Association of Rudimental Drummers)에서 정의

- 싱글 스트로크 계열
- 더블 스트로크 계열
- 패러디들 계열
- 플래드다들·드래그 계열
- 플램 계열

```

**루디먼트 학습의 중요성:**
```

손가락 독립성 개발
양손 균형 유지
복잡한 리듬 패턴의 기초
속도·다이나믹 컨트롤

```

---

## 기본 패러디들 (Single Paradiddle)

### 정의와 구조

**싱글 패러디들 (RLRR LRLL):**
```

R = 오른손 (Right)
L = 왼손 (Left)

패턴: R-L-R-R / L-R-L-L
      ↑ ↑ ↑ ↑   ↑ ↑ ↑ ↑
      1 e + a   2 e + a

```

**16분음표로 표기:**
```
1-e-+-a: R L R R
2-e-+-a: L R L L
= 8음 패턴 반복

```

**핵심 포인트:**
- 첫 번째 더블 스트로크 후 손이 전환됨
- 각 패러디들은 반대 손으로 시작
- 자연스럽게 양손이 교대됨

### 기본 연습

**느린 연습 (♩= 60):**
```
1: R (오른손 스네어)
e: L (왼손 스네어)
+: R (오른손 스네어)
a: R (오른손 스네어) ← 더블

2: L (왼손 스네어)
e: R (오른손 스네어)
+: L (왼손 스네어)
a: L (왼손 스네어) ← 더블

```

---

## 패러디들 변형

### 더블 패러디들 (Double Paradiddle)

**패턴: RLRLRR LRLRLL**
```
6음 패턴:
R-L-R-L-R-R / L-R-L-R-L-L
3박자 또는 6/8에서 자연스럽게 사용

```

**12/8 적용:**
```
12/8에서 더블 패러디들:
R-L-R-L-R-R L-R-L-R-L-L
= 폴리리듬적 느낌

```

### 트리플 패러디들 (Triple Paradiddle)

**패턴: RLRLRLRR LRLRLRLL**
```
8음 패턴:
R-L-R-L-R-L-R-R / L-R-L-R-L-R-L-L
더 많은 싱글 스트로크 전에 더블

```

### 패러디들-디들 (Paradiddle-diddle)

**패턴: RLRRLL LRLLRR**
```
6음 패턴:
R-L-R-R-L-L / L-R-L-L-R-R
마지막에 더블 더블

```

---

## 루디먼트 계열

### 싱글 스트로크 계열

**싱글 스트로크 롤:**
```

R-L-R-L-R-L-R-L (교번 반복)
= 모든 루디먼트의 기초

```

**싱글 스트로크 4:**
```

R-L-R-L / R-L-R-L (4음씩 그룹)
억양으로 4음 그룹 강조

```

### 더블 스트로크 계열

**더블 스트로크 롤:**
```

R-R-L-L-R-R-L-L
오픈 롤: 각 더블 사이 간격
클로즈 롤: 빠르게 → 버즈 롤 느낌

```

**5 스트로크 롤:**
```

R-R-L-L-R (또는 R-L-L-R-R)
5번 스트로크 후 악센트

```

### 플램 계열

**플램 (Flam):**
```

왼손 가볍게 먼저 + 오른손 강하게
= 하나의 스트로크처럼 들림
표기: lR (소문자=약한 유령 노트, 대문자=강한 메인)

```

**플램 탭:**
```

lR-R / rL-L
= 플램 + 더블 스트로크

```

## 패러디들 음악 적용

### 드럼셋에서 패러디들

**기본 패러디들 → 드럼셋:**
```

R: 스네어
L: 하이햇
R: 스네어
R: 킥 드럼 (발)
= 드럼셋 버전

```

**Buddy Rich 스타일 필인:**
```

빠른 패러디들로 탐탐을 순회
R=하이탐, L=로우탐, 더블=스네어
= 화려한 드럼 필

```

### 그루브에 패러디들 통합

**패러디들 그루브:**
```

킥: 1박, 3박
스네어: 2박, 4박 (R-R 더블 스트로크)
하이햇: 8분음표 패러디들 패턴

```

## Billy Cobham 스타일

### 퓨전의 패러디들 마스터

Billy Cobham(Mahavishnu Orchestra):
- **극도로 빠른 패러디들:** 폴리리듬과 결합
- **양손 대칭:** 왼손과 오른손이 동등하게 발달
- **오픈 핸드:** 크로스오버 없이 연주

**Cobham 스타일 필:**
```

R-L-R-R-L-R-L-L 패러디들
킥 + 패러디들 오버레이
= 퓨전의 폴리리듬 에너지

```

## 40 루디먼트 학습 순서

### 기초 루디먼트

**1단계 (첫 달):**
```
1. 싱글 스트로크 롤
2. 더블 스트로크 롤
3. 싱글 패러디들
4. 플램

```

**2단계 (2~3달):**
```
5. 파이브 스트로크 롤
6. 세이스 스트로크 롤
7. 세븐 스트로크 롤
8. 더블 패러디들
9. 트리플 패러디들
10. 플램 탭

```

**3단계 (4~6달):**
```
11-40: 드래그, 래프, 트리플, 플래드다들 등
전체 40 루디먼트 마스터

```

## 음악연습실 패러디들 루디먼트 연습

### 60분 루틴

**1. 싱글 스트로크 워밍업 (10분)**
   - R-L-R-L 느리게 (♩= 60)
   - 점진적으로 빠르게 (♩= 120)
   - 양손 균등한 다이나믹 확인

**2. 싱글 패러디들 집중 (20분)**
   - RLRR LRLL 천천히
   - 각 스트로크 균등한 볼륨
   - ♩= 60 → 120 → 160 점진적 향상

**3. 패러디들 변형 (15분)**
   - 더블 패러디들 (RLRLRR LRLRLL)
   - 트리플 패러디들
   - 패러디들-디들

**4. 드럼셋 적용 (15분)**
   - 패러디들 필인 (탐탐 순회)
   - 그루브에 패러디들 통합
   - 빠른 속도에서 필 연결

## 마무리

패러디들과 루디먼트는 **드럼의 언어**입니다. Buddy Rich가 "루디먼트를 모르면 드럼을 안다고 할 수 없다"고 했듯, 이것들은 모든 스타일의 드러밍에 기초를 제공합니다. 단순한 R-L-R-R 패턴이 당신의 손에서 음악으로 피어납니다.

은평구 24시간 음악연습실에서 매트 위에 싱글 패러디들부터 시작하세요. 속도보다 균일함이 먼저입니다. 균일함이 완성되면 속도는 저절로 따라옵니다.

---

파라디들(RLRR LRLL)은 드럼 루디먼트의 핵심 패턴으로, 양손의 균형 개발과 스틱 컨트롤에 가장 효과적인 훈련법 중 하나입니다. 느린 BPM에서 정확한 악센트 위치와 다이나믹을 유지하면서 연습한 뒤 점진적으로 템포를 높여가는 방식이 기초를 단단히 다지는 최선의 접근법입니다.

## Studio NOL이 패러디들 연습실 사용자에게 자주 권하는 3가지

스튜디오 놀(연신내, 서울 은평구) 음악연습실에서 드럼 패러디들 연습 상담 때 자주 드리는 조언입니다.

**1. 싱글 패러디들 RLRR LRLL — 양손 균등 우선**

좌우 손 한쪽이 약하면 패러디들 균형이 무너집니다. 약한 손 단독 훈련 15분을 매 세션 배정합니다.

**2. 드럼 패드 우선 — 풀 키트 전 손 컨트롤 마스터**

풀 키트로 바로 연습하면 손 컨트롤 미숙이 다른 드럼 음색에 가려집니다. 드럼 패드 단독 30분 훈련 후 키트로 옮깁니다.

**3. 메트로놈 BPM 60부터 — 더블 스트로크 명확성**

패러디들의 더블 스트로크가 메트로놈 클릭 사이에 정확히 들어가야 합니다. BPM 60에서 정확성을 잡은 뒤 속도를 올립니다.

---

드럼 연습에서 기초 루디먼트는 절대 간과해서는 안 될 핵심 요소입니다. 싱글 스트로크, 더블 스트로크, 패러디들을 꾸준히 연습하면 양손 밸런스가 균등하게 발전합니다. 메트로놈 없이 연습하는 습관은 박자 안정성을 해치므로 항상 클릭 트랙을 활용하는 것이 좋습니다. 처음에는 느린 템포부터 시작해 정확도가 높아지면 점차 BPM을 올려가는 방식이 효과적입니다. 드럼 패드에서 충분히 익힌 뒤 실제 드럼 세트로 전환하면 습득 속도가 크게 빨라집니다. 규칙적인 연습 루틴을 만들고 꾸준히 유지하는 것이 단기간의 집중 연습보다 장기적으로 더 큰 효과를 만들어냅니다. 하루 30분씩 매일 연습하는 것이 주말에만 3시간씩 연습하는 것보다 신체 기억과 음악적 감각 형성에 훨씬 유리합니다. 연습 중 어려운 부분에 막힐 때는 천천히, 더 작은 단위로 나눠 반복하는 것이 돌파구가 됩니다. 목표 악기와 음악 스타일에 맞는 연습 방법을 지속적으로 탐구하고 실험하는 자세가 장기적인 성장의 원동력입니다.
