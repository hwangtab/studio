# 드럼 포스트펑크·뉴웨이브 리듬 — 음악연습실 완전 가이드

포스트펑크 드럼은 **단순함 안에서의 절박한 에너지**입니다. 복잡한 기교 없이 일관된 비트로 어두운 분위기를 만들어냅니다. Joy Division의 Stephen Morris, The Cure의 Lol Tolhurst, Bauhaus의 Kevin Haskins—포스트펑크 드러머들은 최소한의 것으로 최대의 분위기를 만들었습니다.

---

## 포스트펑크 드럼의 특징

### 미니멀리즘

**특징:**
- 단순하지만 반복적인 패턴
- 복잡한 필인 없음
- 그루브보다 분위기 우선
- 메트로노믹 일관성

**록 드럼과의 차이:**
```
록: 다이나믹한 필인, 파워풀한 백비트
포스트펑크: 반복적, 하이폭식, 기계적 정확도
```

### 무거운 공간 활용

**공간(Rest)의 중요성:**
- 치지 않는 순간이 포스트펑크의 핵심
- 스네어 뒤의 침묵이 긴장감 생성
- 채움보다 비움

---

## Joy Division 스타일

### Stephen Morris의 드러밍

Joy Division의 Stephen Morris는 포스트펑크 드럼의 상징.

**특징:**
- 하이햇을 16분음표로 일관되게
- 킥드럼이 불규칙하고 무거움
- 스네어는 정확한 2·4박

**"She's Lost Control" 패턴:**
```
박자: 1  e  +  a  2  e  +  a  3  e  +  a  4  e  +  a
하이햇: ●  ●  ●  ●  ●  ●  ●  ●  ●  ●  ●  ●  ●  ●  ●  ●
킥드럼: ●     ●        ●        ●     ●
스네어:          ●                       ●
```

**특징:** 16분 하이햇 + 불규칙 킥 + 정확한 스네어

### "Disorder" 패턴

```
박자: 1  +  2  +  3  +  4  +
하이햇: ●  ●  ●  ●  ●  ●  ●  ●
킥:  ●     ●  ●     ●     ●
스네어:    ●        ●
(킥이 당김음 위치에서 자주 등장)
```

---

## The Cure 스타일

### 고딕·포스트펑크 드러밍

**특징:**
- 느리고 무거운 비트
- 리버브 많은 스네어 소리
- 분위기가 음악 전체

**"A Forest" 스타일 패턴:**
```
박자: 1        2        3        4
킥:  ●                 ●
스네어:       ●                 ●
하이햇: 8분음표 (깨끗하게)
```

**분위기 만들기:**
- 스네어에 리버브 많이 (홀 리버브)
- 킥에 딜레이 살짝
- 전체적으로 느린 BPM (♩=100-120)

---

## Bauhaus 스타일

### 케빈 해스킨스

Bauhaus는 포스트펑크+고딕록의 경계.

**특징:**
- 강하고 스타카토한 스네어
- 킥드럼 무겁게
- 음악 전체가 의례적인 느낌

**"Bela Lugosi's Dead" 리듬:**
```
매우 느린 BPM (♩=70-80)
킥: 1박에 강하게
스네어: 3박에 리버브 가득
심벌: 오픈 하이햇 지속
```

---

## 뉴웨이브 드럼 패턴

### 신스팝 뉴웨이브

**Depeche Mode·New Order 스타일:**
- 드럼머신과 실제 드럼 혼합
- 기계적이고 정확한 타이밍
- 댄서블한 4/4 비트

**"Blue Monday" (New Order) 드럼:**
```
킥: 1·3박 강하게
스네어: 2·4박 클래핑 느낌
하이햇: 16분음표 패턴
특징: 드럼머신의 정밀함
```

### 포스트펑크 + 댄스 혼합

**Gang of Four 스타일:**
- 당김음 강조
- 펑크의 에너지 + 댄스의 그루브

```
킥: 1박 + 2+박 (당김음)
스네어: 3박
하이햇: 8분음표
```

## 분위기 드러밍

### 감정 전달

포스트펑크 드럼의 본질: **분위기 만들기**

**어두운 분위기:**
- 느린 BPM
- 스네어 리버브 많이
- 킥 무겁고 딥
- 필인 없음

**긴장 고조:**
- 점진적으로 타이트하게
- 하이햇 16분음표로 가속감
- 절정에서 킥 강조

### 반복의 힘

포스트펑크는 **반복이 긴장감을 만든다**.

**연습법:**
1. 단순한 패턴을 4분 동안 변화 없이 유지
2. 일관성이 핵심
3. 아주 미세한 변화만 허용

---

## 음악연습실 포스트펑크 드럼 연습

### 음향 설정

**포스트펑크 드럼 소리:**
```
스네어: 리버브 가득 (홀, 4-8초 디케이)
킥: 딥하고 무거운 (60Hz 강조)
하이햇: 크리스피하게
전체: BPM 80-120
```

### 연습 루틴 (60분)

**1. 미니멀 패턴 (20분)**
   - Joy Division 스타일 16분 하이햇
   - 일관성에 집중

**2. 분위기 드러밍 (20분)**
   - The Cure 스타일 느린 비트
   - 리버브 많은 스네어로 분위기

**3. 자유 탐구 (20분)**
   - 어두운 분위기의 패턴 창작
   - 녹음하며 분위기 확인
