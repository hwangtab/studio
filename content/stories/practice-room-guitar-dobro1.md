# 도브로·레조네이터 기타·슬라이드 기법 — 음악연습실 완전 가이드

도브로(Dobro)는 **금속 공명판(Resonator)으로 소리를 증폭하는 슬라이드 기타**입니다. 블루그래스(Bluegrass)와 컨트리(Country) 음악의 핵심 악기로, Jerry Douglas, Josh Graves, Mike Auldridge가 도브로의 가능성을 극대화했습니다. 일반 기타와 달리 무릎 위에 눕혀 놓고 슬라이드(바)로 연주합니다.

---

## 도브로의 특징

### 레조네이터 구조

**도브로의 소리 원리:**
```
현 진동
→ 스파이더 브릿지 (spider bridge)
→ 알루미늄 콘 (resonator cone)
→ 소리 증폭·금속 톤
= 독특한 메탈릭 공명음
```

**도브로 vs 일반 기타:**

| | 도브로 | 어쿠스틱 기타 |
|--|-------|-------------|
| 연주 자세 | 눕혀서 (랩 스틸) | 세워서 |
| 연주 도구 | 슬라이드 바 | 손가락/픽 |
| 소리 | 금속 공명, 하울링 | 목재 따뜻함 |
| 튜닝 | G 오픈 | EADGBE |

### G 오픈 튜닝

**도브로 표준 튜닝 (높은음→낮은음):**
```
1번 줄: D
2번 줄: B
3번 줄: G
4번 줄: D
5번 줄: G
6번 줄: G (낮은 G)
= G 장조 화음 (D-B-G-D-G-G)
```

**G 오픈 이점:**
- 개방현 = G 코드
- 바 하나로 전체 코드
- 블루그래스 스케일에 완벽

## 슬라이드 바 기법

### 슬라이드 바 선택

**도브로용 바 종류:**
```
크롬 바: 밝고 선명
스틸 바: 더 따뜻한 톤
유리 바: 부드럽고 표현적
황동 바: 풍부한 공명
```

**바 잡는 방법:**
```
중지 또는 약지에 바를 끼우거나 손에 쥐기
줄과 평행하게, 프렛 위에 (not 사이)
오른손: 핑거픽 + 썸픽 사용
```

### 프렛 위치 기법

**바를 프렛 바로 위에:**
```
올바른 위치: 프렛 철사 바로 위
잘못된 위치: 프렛 사이
= 깨끗한 음정·인토네이션
```

## Jerry Douglas 스타일

### 현대 도브로의 거장

Jerry Douglas(Ricky Skaggs, Alison Krauss 세션):
- **엄청난 속도:** 블루그래스 라인을 기타처럼
- **쵸크 기법:** 현을 밀어 음정 올리기
- **롤 패턴:** 뱅조 롤을 도브로에 적용

**Jerry Douglas 롤 패턴:**
```
썸(p): 5번 줄 (G)
검지(i): 3번 줄 (G)
중지(m): 2번 줄 (B)
약지(a): 1번 줄 (D)

p-i-m-a-p-i-m-a: 포워드 롤
```

### 도브로 블루그래스 라인

**G 키 블루그래스 런:**
```
개방 G (1프렛 위) → 슬라이드 업
5프렛 (C) → 7프렛 (D) → 5프렛 (C) → 개방 (G)
= 블루그래스 정형 라인
```

## Josh Graves 스타일

### 도브로의 아버지

Josh Graves(Earl Scruggs와 협연):
- **블루그래스 도브로 발명:** 도브로를 블루그래스에 처음 통합
- **쵸크 앤 슬라이드:** 음정 변화의 극적 사용
- **시그니처 롤:** 독특한 핑거피킹 패턴

**Josh Graves 시그니처:**
```
개방현 G → 쵸크 (B♭ → B 느낌)
= 블루스적 블루그래스 표현
```

## 핵심 도브로 기법

### 슬라이드 업·다운

**슬라이드 업 (Slide Up):**
```
낮은 프렛에서 연주 시작
목표 음으로 바를 올리며 미끄러지기
= 상승하는 표현
```

**슬라이드 다운 (Slide Down):**
```
높은 프렛에서 연주
아래 음으로 바를 내리며 미끄러지기
= 하강하는 표현
```

### 쵸크 (Choke)

**현을 밀어 음정 올리기:**
```
바를 특정 프렛에 위치
왼손(또는 오른손)으로 현을 옆으로 밀기
= 반음~온음 높이기
```

**블루스 쵸크:**
```
G 오픈 → 5프렛 쵸크
실제 음정: 5프렛 음보다 반음 높게
= 블루스·컨트리 표현의 핵심
```

### 비브라토

**바 비브라토:**
```
바를 유지한 채 빠르게 앞뒤로 흔들기
= 음정이 살짝 위아래 진동
= 노래하는 표현
```

## 도브로 코드 포지션 (G 튜닝)

### 주요 코드 포지션

**G 코드 (개방현):**
```
모든 현 개방 = G-G-D-G-B-D
```

**C 코드 (5프렛):**
```
5프렛 전체 바 = C-C-G-C-E-G
```

**D 코드 (7프렛):**
```
7프렛 전체 바 = D-D-A-D-F#-A
```

**블루그래스 진행 (G-C-D):**
```
개방 (G) → 5프렛 (C) → 7프렛 (D) → 개방 (G)
```

---

## 오른손 핑거피킹

### 도브로 핑거픽

**오른손 세팅:**
```
썸픽 (엄지): 6-4번 줄 베이스
핑거픽 (검지): 3번 줄
핑거픽 (중지): 2번 줄  
핑거픽 (약지): 1번 줄
```

**포워드 롤:**
```
p(4번)-i(3번)-m(2번)-a(1번)
반복: p-i-m-a-p-i-m-a
```

**백워드 롤:**
```
a(1번)-m(2번)-i(3번)-p(4번)
반복: a-m-i-p-a-m-i-p
```

### 멜로디+롤 통합

```
멜로디 음: 바 포지션으로 1번 줄에서
베이스 롤: 썸픽으로 4-6번 줄 반복
= 솔로 어레인지
```

## 음악연습실 도브로 기타 연습

### 60분 루틴

**1. G 오픈 튜닝 + 포지션 (15분)**
   - G-C-D 코드 바 위치 확인
   - 각 포지션에서 개방현 조화 연습
   - 바 인토네이션 정확도 집중

**2. 슬라이드 기법 (15분)**
   - 슬라이드 업 (3→5→7프렛)
   - 슬라이드 다운 (7→5→3프렛)
   - 쵸크 + 비브라토 연결

**3. 핑거픽 롤 (15분)**
   - 포워드 롤 느리게 (♩= 60)
   - 백워드 롤
   - 혼합 롤 패턴

**4. 블루그래스 라인 (15분)**
   - G-C-D 진행 위 멜로디
   - Jerry Douglas 롤 패턴 적용
   - 전체 블루그래스 솔로 형태

## 마무리

도브로는 **슬라이드와 공명의 마법**입니다. Jerry Douglas가 "도브로는 기타가 꿈꾸는 소리"라고 했듯, 금속 콘의 공명은 다른 어떤 악기도 대체할 수 없습니다. G 오픈 튜닝과 바 기법이 만나는 곳에 블루그래스의 심장이 있습니다.

은평구 24시간 음악연습실에서 G 오픈 튜닝을 맞추고, 첫 슬라이드 라인을 연습해보세요. 도브로의 울음소리는 반드시 당신의 음악을 바꿀 것입니다.
