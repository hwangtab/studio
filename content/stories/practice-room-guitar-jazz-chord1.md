faq:
  - q: 기타 재즈 코드를 처음 배우는 방법은?
    a: >-
      재즈 기타 코드 입문: ① ii-V-I — Dm7-G7-Cmaj7 진행이 재즈의 기초 ② 7th 코드 — 메이저 7th, 마이너
      7th, 도미넌트 7th ③ 가이드 톤 — 3도·7도 음 중심 보이싱 ④ 위치 — 6현 루트, 5현 루트 두 포지션 ⑤ 연결 — 코드
      간 보이스 리딩. 재즈 기타 코드는 개방 코드와 다릅니다. 보통 3~4줄만 사용하는 보이싱이 많으며, 불필요한 줄은 뮤트합니다.
  - q: 기타 드롭 2 보이싱(drop 2 voicing)을 배우는 방법은?
    a: >-
      드롭 2 보이싱: ① 정의 — 4성부 코드에서 위에서 2번째 음을 한 옥타브 내리기 ② 예시 — G7의 4성부를 드롭 2로 재배치 ③
      특징 — 기타 지판에서 연주하기 좋은 형태 ④ 5·6현 루트 — 두 가지 포지션 익히기 ⑤ 이동 — 다른 포지션으로 자유롭게 이동.
      드롭 2 보이싱은 재즈 기타리스트가 자주 사용하는 보이싱입니다. 코드 모양이 독특하지만 지판에서 효율적이고 소리가 풍부합니다.
  - q: 재즈 기타 ii-V-I 진행을 연습하는 방법은?
    a: >-
      ii-V-I 진행 연습: ① 키 C — Dm7-G7-Cmaj7 완전히 익히기 ② 여러 키 — 12키에서 ii-V-I 연습 ③ 보이스
      리딩 — 코드 간 자연스러운 음 이동 ④ 컴핑 리듬 — 재즈 스윙 느낌으로 ⑤ 솔로 연결 — ii-V-I 위에 즉흥 솔로.
      ii-V-I 진행은 재즈의 가장 기본 진행입니다. 이 진행을 여러 키에서 자유롭게 연주할 수 있으면 대부분의 재즈 스탠다드를 컴핑할
      수 있습니다.
  - q: 기타 재즈 코드 알터드(altered) 코드를 배우는 방법은?
    a: >-
      알터드 코드: ① 정의 — 도미넌트 7th에 #5·b5·b9·#9 텐션 추가 ② 소리 — 긴장감 극대화, 해소를 위한 당김 ③ 활용
      — ii-V-I에서 V7 코드를 알터드로 ④ 스케일 — 알터드 스케일(7th ♭2 스케일) ⑤ 귀 훈련 — 알터드 사운드 인식.
      알터드 코드는 재즈에서 긴장감을 극대화하는 도구입니다. G7alt → Cmaj7로 해소될 때의 극적인 느낌이 재즈 사운드의
      핵심입니다.

## 재즈 코드가 기타를 다르게 합니다

ii-V-I의 흐름, 드롭 2의 풍부함. 방음 개인실에서 재즈 보이싱을 탐색하세요.

기타 재즈 코드 연습의 핵심:
- **가이드 톤**: 3도·7도 음이 재즈 코드 소리의 핵심
- **ii-V-I 우선**: 모든 키에서 자유롭게 이 진행 먼저
- **보이스 리딩**: 코드 간 인접 음으로 자연스러운 이동
- **드롭 2**: 지판에서 효율적이고 풍부한 보이싱

|------|------|---------|

| 7alt | 알터드 도미넌트 | 긴장 극대화 |

## 기타 재즈 코드·재즈 보이싱 훈련의 핵심 원칙 4가지

재즈 코드에 처음 들어서면 텐션과 보이싱의 종류에 압도되기 쉽습니다. 순서를 잡아 접근하면 훨씬 덜 막막합니다.

1. **코드 기능 이해** — 각 코드가 I(토닉)·IV(서브도미넌트)·V(도미넌트) 중 어떤 기능인지 이해하며 연습. 기능을 알면 처음 보는 곡도 빠르게 코드를 파악할 수 있습니다.

2. **최소 이동 보이싱** — 코드 전환 시 손가락 이동을 최소화하는 보이싱 탐색. 공통 음을 중심으로 나머지 손가락만 이동하면 전환 속도가 빨라집니다.

3. **장르 맞춤 코드 색채** — 팝은 개방 코드의 따뜻함, 재즈는 7th·9th·13th 텐션, 클래식은 클로즈드 보이싱의 단단함을 각각 탐색하세요.

4. **코드톤 아르페지오** — 각 코드를 아르페지오로 분해하며 내성 음의 움직임을 귀로 인식. 코드와 선율의 관계가 명확해집니다.

### 재즈 연주에서 자주 하는 실수

1. **스케일 나열에 그치는 즉흥 연주** — 짧은 모티프를 발전시키는 "motif development" 연습
2. **코드 진행 외우기에만 집중** — 귀로 코드 들으며 즉흥 연주하는 "이어 트레이닝" 병행
3. **빠른 템포에서만 멋있어 보이려 함** — 느린 블루스 BPM 60에서 표현력 먼저

## 재즈 코드는 ii-V-I 하나로 문이 열립니다

재즈 기타 코드가 끝없이 복잡해 보여 겁먹는 분이 많은데, 사실 진입로는 하나예요. ii-V-I 진행입니다. 재즈 스탠더드에 나오는 코드의 80%가 이 세 코드의 조합으로 돌아가거든요. 그래서 화려한 텐션 코드를 찾아 헤매기 전에, 이 ii-V-I을 12개 조성 어디서든 막힘없이 칠 수 있게 자동화하는 게 먼저입니다. 이게 손에 붙으면 처음 보는 스탠더드도 코드 진행이 훤히 보여요. 재즈의 문법이 이 세 코드에 다 담겨 있습니다.

이 코드들을 어떤 모양으로 잡느냐가 다음 문제예요. 재즈 기타는 드롭 2와 드롭 3라는 두 가지 보이싱이 표준입니다. 이 두 폼으로 ii-V-I을 각 조성에서 잡을 수 있게 익혀 두면, 손이 지판 위를 자연스럽게 이동하며 진행을 짚어 나가요.

어휘는 거장에게서 훔치세요. Joe Pass와 Wes Montgomery가 같은 코드를 어떻게 잡고 어떻게 잇는지 카피하면, 이론서엔 없는 실전 감각이 손에 들어옵니다. 보이싱 폼 자체를 체계적으로 익히는 법은 [기타 재즈 코드·텐션 보이싱](/stories/practice-room-guitar-jazz-chords1)에서 이어집니다.
