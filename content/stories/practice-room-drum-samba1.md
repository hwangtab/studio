# 드럼 삼바·브라질 리듬 드럼셋 — 음악연습실 완전 가이드

삼바(Samba)는 **브라질의 심장**입니다. 리우 카니발의 폭발적인 에너지, 삼바 엔호도(Samba Enredo)의 장대한 행진, 삼바 자즈(Samba Jazz)의 세련된 그루브—이 모든 삼바의 다양성을 드럼셋 하나로 표현하는 방법을 정리합니다.

---

## 삼바의 리듬적 기초

### 삼바 클라베 (Samba Clave)

삼바 리듬은 **삼바 클라베**를 기반으로 합니다.

**삼바 클라베 (2-3 형):**
```
마디 1: X - X - X - - -  (2 사이드)
마디 2: - X - - X - X - (3 사이드)
```

**16분음표로 표기:**
```
1 e and a 2 e and a  (마디 1)
X - X - X - - -

1 e and a 2 e and a  (마디 2)
- X - - X - X -
```

### 서지도 (Surdo) 리듬

서지도는 삼바의 **베이스드럼 역할**을 하는 타악기입니다. 드럼셋에서는 킥드럼으로 구현합니다.

**삼바 서지도 패턴:**
```
4/4박자:
박 1: 킥 (강하게)
박 2: 뮤트 킥 또는 쉬기
박 3: 킥 (강하게)
박 4: 쉬기
```

**더 복잡한 서지도:**
```
박 1: 킥
박 2 and: 킥 (앤티시페이션)
박 3: 킥
박 4 and: 쉬기
```

## 드럼셋 삼바 패턴

### 기본 삼바 패턴 (BPM 100-160)

```
라이드 (오른손): 삼바 클라베 패턴
스네어 (왼손): 핌파 패턴 (2박 and, 4박 and에 스네어)
킥: 서지도 패턴 (1, 3박)
하이햇 발: 2, 4박에 닫기
```

**핌파 (Pimba) 패턴 — 스네어:**
```
박 1: -
박 1 and: 스네어
박 2: -
박 2 and: 스네어
박 3: -
박 3 and: 스네어
박 4: -
박 4 and: 스네어
```

### 레구 (Repique) 패턴

레구는 리드 퍼커션 역할. 드럼셋에서는 하이 탐이나 스네어 림으로 구현.

**레구 패턴:**
```
8분음표 그리드:
X X - X X X - X
```

### 완성형 삼바 드럼셋

```
라이드/하이햇: 삼바 클라베 (오른손)
스네어: - X - X - X - X (핌파)
탐 (레구): X X - X X X - X
킥: X - - X - - X - (서지도)
하이햇 발: 2, 4박
```

---

## 삼바 장르별 드럼 접근

### 카니발 삼바 (Samba Enredo)

리우 카니발의 퍼레이드 삼바. **빠르고 강렬**합니다.

**특징:**
- BPM 180-220+
- 배터리아(Bateria) 앙상블을 드럼셋으로 재현
- 매우 강한 다이나믹
- 단순하지만 압도적인 반복

**드럼셋 카니발 삼바:**
```
라이드: X - X X X - X X (삼바 클라베)
스네어: 강한 핌파
킥: X - X - X - X - (강력하게)
```

### 삼바 자즈 (Samba Jazz)

1960년대 브라질 재즈와의 결합.

**특징:**
- BPM 120-160 (보통 빠르기)
- 더 복잡한 폴리리듬
- 재즈 브러시와의 조합
- Airto Moreira 스타일

**삼바 자즈 브러시 패턴:**
```
오른손 브러시: 라이드 시노코파도 패턴 탭
왼손 브러시: 서클링 + 스네어 탭
킥: 가볍게 서지도
```

### 삼바-레게 (Samba-Reggae)

바이아(Bahia) 지역에서 발전한 삼바-레게 스타일.

**특징:**
- BPM 90-110 (상대적으로 느림)
- 킥이 3박에 강하게
- 스네어가 2박에

**삼바-레게 패턴:**
```
킥: - - - - X - - - (3박에 강하게)
스네어: - X - - - - X - (2, 7번째 8분음표)
```

## 삼바 타악기와 드럼셋의 관계

### 브라질 타악기 이해

| 악기 | 드럼셋 대응 | 역할 |
|-----|----------|-----|
| Surdo 1 | 킥드럼 (강) | 1, 3박 베이스 |
| Surdo 2 | 킥드럼 (뮤트) | 2, 4박 응답 |
| Caixa | 스네어 | 핌파 패턴 |
| Repique | 하이 탐 또는 림 | 리드 패턴 |
| Tamborim | 하이햇 | 삼바 클라베 |
| Chocalho | 라이드 | 배경 샤케르 |

### 앙상블 개념 이해

삼바는 여러 타악기가 각각의 파트를 담당하여 **전체 그루브를 만듭니다.** 드럼셋 연주자는 이 앙상블 전체를 혼자 재현하는 것이 목표입니다.

## 음악연습실 삼바 연습 루틴

### 기초 단계 (55분)

**1. 클라베 마스터 (15분)**
- 삼바 클라베를 두 손으로 교대로 치기
- 2-3 형태와 3-2 형태 모두

**2. 서지도 킥 패턴 (15분)**
- BPM 100에서 킥드럼만 서지도 패턴
- 하이햇 발 추가

**3. 완성형 패턴 (25분)**
- 스네어 핌파 추가
- 라이드로 클라베 추가
- 탐(레구) 추가 도전

### 중급 단계

- 브러시 삼바 자즈
- BPM 180 카니발 삼바
- 삼바-레게 전환
- 브라질 퍼커션 리스닝 연습

## 마무리

삼바 드럼의 핵심은 **폴리리듬 속에서도 그루브를 잃지 않는 것**입니다. 클라베와 핌파, 서지도가 동시에 움직이면서도 하나의 흐름을 만들어야 합니다.
