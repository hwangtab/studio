## 울산에서 KTX로 서울까지

울산은 KTX로 서울과 연결되어 당일 왕복 스튜디오 세션이 가능합니다. 전문 보컬 녹음, 음원 발매용 레코딩, 믹싱·마스터링을 위해 연신내 스튜디오 놀을 이용할 수 있습니다.

---

## 울산 → 연신내 이동 경로

```
① 울산역(KTX울산역)에서 KTX 탑승 (서울역 방면)
② 서울역 도착 (약 2시간 10~20분)
③ 1호선 서울역 → 신도림 → 2호선 합정역 → 6호선 연신내역
   또는 1호선 서울역 → 용산역 → 경의중앙선 홍대입구 → 2호선 합정 → 6호선

총 소요시간: 약 2시간 50분~3시간
```

---

## 당일 왕복 일정 예시 (울산 기준)

```
오전 7시 30분 울산역 출발 (KTX)
→ 오전 9시 50분 서울역 도착
→ 오전 10시 30분 연신내역 도착
→ 오전 11시 세션 시작 (2~3시간)
→ 오후 1시~2시 세션 완료
→ 오후 3시 서울역 출발 (KTX)
→ 오후 5시 20분 울산역 도착
```

## 온라인 파일 의뢰 서비스

직접 방문이 어려울 때:

```
울산 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
