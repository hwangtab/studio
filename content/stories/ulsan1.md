## 울산에서 KTX로 서울까지

울산은 KTX로 서울과 연결되어 당일 왕복 스튜디오 세션이 가능합니다. 전문 보컬 녹음, 음원 발매용 레코딩, 믹싱·마스터링을 위해 연신내 스튜디오 놀을 이용할 수 있습니다.

---

## 울산 → 연신내 이동 경로

아래 소요 시간은 평균 기준이며 혼잡 시간대에는 10~15분 추가를 권장합니다.

1. 울산역(KTX울산역)에서 KTX 탑승 (서울역 방면)
2. 서울역 도착 (약 2시간 10~20분)
3. 1호선 서울역 → 신도림 → 2호선 합정역 → 6호선 연신내역
   또는 1호선 서울역 → 용산역 → 경의중앙선 홍대입구 → 2호선 합정 → 6호선

- **총 소요시간**: 약 2시간 50분~3시간

---

## 당일 왕복 일정 예시 (울산 기준)

주차 공간은 제한적이므로 대중교통 이용을 권장합니다.

오전 7시 30분 울산역 출발 (KTX)
- 오전 9시 50분 서울역 도착
- 오전 10시 30분 연신내역 도착
- 오전 11시 세션 시작 (2~3시간)
- 오후 1시~2시 세션 완료
- 오후 3시 서울역 출발 (KTX)
- 오후 5시 20분 울산역 도착

## 울산에서 당일 세션을 온다면

울산에서 KTX로 약 2시간 거리입니다. 왕복 일정을 고려해 세션 시간을 넉넉하게 잡아두시길 권장합니다. 방문 전 카카오톡으로 사운드 방향과 MR 파일을 미리 공유해두시면 당일 세션을 최대한 활용할 수 있습니다.

---

## 울산 음악 씬과 서울 스튜디오

울산은 현대자동차·현대중공업 등 대기업이 집중된 산업도시이지만, 울산문화예술회관·문화의거리를 중심으로 문화 활동도 활발합니다. 울산대·울산예술고 등에서 배출된 음악인들이 프로 데뷔를 위해 서울 스튜디오를 적극 활용합니다.

## 방문 전 세션 준비 가이드

1시간 30분 이상 이동 후 최상의 컨디션으로 세션에 임하려면 철저한 사전 준비가 필요합니다.

**출발 전 챙길 것:**
- [ ] 녹음할 곡의 가사·악보·MR 파일 (USB 또는 Google Drive)
- [ ] 원하는 사운드의 레퍼런스 트랙 2~3곡
- [ ] 예약 확인 캡처 + 교통편 티켓
- [ ] 보컬: 따뜻한 차·꿀물 보온병, 간식
- [ ] 귀마개 또는 노이즈캔슬링 이어폰 (이동 중 성대 보호)

**이동 중 활용법:**
- 이어폰으로 녹음할 곡 2~3회 예습
- 가사·감정 포인트 집중 정리
- 목·어깨 스트레칭 (장시간 이동 피로 완화)
- 충분한 수분 섭취 (기차 이동 중 성대 건조 방지)

**세션 팁:**
- 도착 후 20~30분 워밍업 시간 확보 (일정 계획 시 반드시 포함)
- 가장 중요한 구간을 세션 초반(이동 피로 전)에 먼저 녹음
- 원하는 사운드를 레퍼런스 곡으로 구체적으로 설명
- 온라인 파일 의뢰 서비스 병행 시 재방문 부담 최소화 가능

## 세션 당일 체크리스트

**전날:**
- [ ] MR·가사·레퍼런스 트랙 파일 최종 확인
- [ ] 교통편 티켓 + 예약 확인 캡처
- [ ] 충분한 수면 + 성대 무리 금지

**출발 전:**
- [ ] 따뜻한 차·꿀물 지참
- [ ] 이동 중 성대 보호 (소리 지르기 금지, 수분 섭취)

**도착 후:**
- [ ] 20~30분 워밍업 확보 (일정에 미리 포함)
- [ ] 엔지니어에게 레퍼런스·사운드 방향 설명
- [ ] 가장 어려운 구간 최우선 녹음

**녹음 중:**
- [ ] 헤드폰 볼륨 확인
- [ ] 테이크마다 즉시 청취
- [ ] 막차 시간 미리 확인 (귀가 일정)
