## 인디팝 보컬 — 개성과 감성이 우선

인디팝·인디음악 보컬은 상업적 완성도보다 진정성과 개성을 중시합니다. 완벽하지 않은 날것의 느낌이 오히려 장르적 매력으로 작용합니다.

## 인디 세부 장르별 보컬 특성

| 장르 | 보컬 특성 | 믹싱 특성 |
|------|---------|---------|
| 인디팝 | 자연스러운 가성, 가벼운 터치 | 공간감 있는 리버브, 자연 다이나믹스 |
| 드림팝 | 몽환적 가성, 속삭이는 느낌 | 긴 리버브, 코러스 이펙트 |
| 로우파이 인디 | 의도적 불완전함, 빈티지 느낌 | 테이프 새추레이션, 로우컷, 노이즈 |
| 포크 인디 | 진성 위주, 감정 표현 | 미니멀 처리, 공간감 |
| 슈게이징 | 기타 벽 속에 묻히는 보컬 | 딜레이·리버브 과다, 보컬 레이어 |

## 인디 보컬 녹음 접근법

```
[세팅]
마이크 거리: 20~40cm (팝보다 조금 멀리)
팝필터: 사용하되 너무 가깝지 않게
공간: 약간의 룸 어쿠스틱 허용

[녹음 태도]
→ 완벽한 테이크보다 에너지 있는 테이크 선택
→ 숨소리·성대 노이즈 삭제하지 않기
→ 가성-진성 자연스러운 전환 그대로 두기
→ 즉흥적인 애드립 살리기

[테이크 수]
→ 2~4테이크로 최선 선택
→ 지나치게 많은 테이크는 에너지 소진
→ "충분히 좋은" 느낌이 나면 멈추기
```

## 인디 보컬 믹싱 접근법

```
[EQ]
High-Pass: 100~120Hz (팝보다 조금 높게)
High Shelf 부스트: 8~12kHz (공기감)
Mid 딥: 지나친 존재감 줄이기

[다이나믹스]
컴프레서: 가볍게 (Ratio 2:1~3:1)
GR: 2~4dB 정도만
자연 다이나믹스 유지가 핵심

[공간 이펙트]
룸·플레이트 리버브: Pre-delay 20~40ms
리버브 양: 팝보다 많이 허용
스테레오 딜레이: 1/4~1/8음표

[드림팝 추가 처리]
→ 코러스 이펙트 (Aux 버스)
→ 테이프 새추레이션
→ 피치 시프트 -5~5센트 레이어
```

## 자연스러운 인디 보컬 완성 팁

```
[피치 교정]
→ Auto-Tune/Melodyne 사용 최소화
→ 교정이 필요하면 Speed를 낮게 (자연스럽게)
→ 비브라토 구간은 건드리지 말 것

[성대 노이즈 처리]
→ 숨소리: 완전히 삭제하지 말고 레벨 낮추기
→ 가사 사이 성대 소리: 장르 감성에 맞으면 유지
→ 과도한 클리핑·튐만 삭제

[레이어링]
→ 같은 파트 2~3겹 레이어 (자연스러운 불일치)
→ 퀀타이즈 없이 타이밍 살짝 어긋나게
→ 두꺼운 레이어보다 얇고 섬세한 레이어
```
