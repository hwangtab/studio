## 포항·경주에서 KTX로 서울까지

포항은 KTX로 서울과 2시간대로 연결됩니다. 경주에서도 신경주역을 이용하면 빠르게 이동할 수 있습니다. 전문 보컬 녹음과 음반 제작을 위해 연신내 스튜디오 놀을 이용할 수 있습니다.

---

## 포항·경주 → 연신내 이동 경로

### 포항역 KTX

```
① 포항역에서 KTX 탑승 (서울역 방면)
② 서울역 도착 (약 2시간 10~20분)
③ 1호선 또는 2호선 환승 → 연신내역

총 소요시간: 약 2시간 50분~3시간
```

### 경주 → 신경주역 KTX

```
① 경주 시내 → 신경주역 (택시·버스 약 15~20분)
② 신경주역에서 KTX 탑승 (서울역 방면, 약 1시간 55분)
③ 서울역 도착 → 지하철 환승 → 연신내역

총 소요시간: 약 2시간 40분~3시간
```

## 당일 왕복 일정 예시 (포항 기준)

```
오전 7시 포항역 출발 (KTX)
→ 오전 9시 15분 서울역 도착
→ 오전 10시 연신내역 도착
→ 오전 10시 30분 세션 시작 (2~3시간)
→ 오후 1시 세션 완료
→ 오후 3시 서울역 출발 (KTX)
→ 오후 5시 10분 포항역 도착
```
