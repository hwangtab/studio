## 포항·경주에서 KTX로 서울까지

포항은 KTX로 서울과 2시간대로 연결됩니다. 경주에서도 신경주역을 이용하면 빠르게 이동할 수 있습니다. 전문 보컬 녹음과 음반 제작을 위해 연신내 스튜디오 놀을 이용할 수 있습니다.

---

## 포항·경주 → 연신내 이동 경로

### 포항역 KTX

처음 방문하는 분은 예약 시간 10분 전에 도착하면 여유롭게 시작할 수 있습니다.

1. 포항역에서 KTX 탑승 (서울역 방면)
2. 서울역 도착 (약 2시간 10~20분)
3. 1호선 또는 2호선 환승 → 연신내역

- **총 소요시간**: 약 2시간 50분~3시간

### 경주 → 신경주역 KTX

1. 경주 시내 → 신경주역 (택시·버스 약 15~20분)
2. 신경주역에서 KTX 탑승 (서울역 방면, 약 1시간 55분)
3. 서울역 도착 → 지하철 환승 → 연신내역

- **총 소요시간**: 약 2시간 40분~3시간

## 당일 왕복 일정 예시 (포항 기준)

대중교통 이용이 주차 걱정 없이 편리하게 방문할 수 있는 가장 좋은 방법입니다.

오전 7시 포항역 출발 (KTX)
- 오전 9시 15분 서울역 도착
- 오전 10시 연신내역 도착
- 오전 10시 30분 세션 시작 (2~3시간)
- 오후 1시 세션 완료
- 오후 3시 서울역 출발 (KTX)
- 오후 5시 10분 포항역 도착

## 포항 음악 씬과 서울 스튜디오

포항은 포스코 철강 도시로 알려져 있지만, 포항스틸러스 응원 문화와 함께 지역 음악 씬도 성장 중입니다. 한동대·포항공대(포스텍) 등에서 다양한 배경의 학생 뮤지션이 활동하며 KTX 포항역으로 서울 직통이 가능합니다.

## 방문 전 세션 준비 가이드

1시간 30분 이상 이동 후 최상의 컨디션으로 세션에 임하려면 철저한 사전 준비가 필요합니다.

**출발 전 챙길 것:**
- [ ] 녹음할 곡의 가사·악보·MR 파일 (USB 또는 Google Drive)
- [ ] 원하는 사운드의 레퍼런스 트랙 2~3곡
- [ ] 예약 확인 캡처 + 교통편 티켓
- [ ] 보컬: 따뜻한 차·꿀물 보온병, 간식
- [ ] 귀마개 또는 노이즈캔슬링 이어폰 (이동 중 성대 보호)

**이동 중 활용법:**
- 이어폰으로 녹음할 곡 2~3회 예습
- 가사·감정 포인트 집중 정리
- 목·어깨 스트레칭 (장시간 이동 피로 완화)
- 충분한 수분 섭취 (기차 이동 중 성대 건조 방지)

**세션 팁:**
- 도착 후 20~30분 워밍업 시간 확보 (일정 계획 시 반드시 포함)
- 가장 중요한 구간을 세션 초반(이동 피로 전)에 먼저 녹음
- 원하는 사운드를 레퍼런스 곡으로 구체적으로 설명
- 온라인 파일 의뢰 서비스 병행 시 재방문 부담 최소화 가능

## 세션 당일 체크리스트

**전날:**
- [ ] MR·가사·레퍼런스 트랙 파일 최종 확인
- [ ] 교통편 티켓 + 예약 확인 캡처
- [ ] 충분한 수면 + 성대 무리 금지

**출발 전:**
- [ ] 따뜻한 차·꿀물 지참
- [ ] 이동 중 성대 보호 (소리 지르기 금지, 수분 섭취)

**도착 후:**
- [ ] 20~30분 워밍업 확보 (일정에 미리 포함)
- [ ] 엔지니어에게 레퍼런스·사운드 방향 설명
- [ ] 가장 어려운 구간 최우선 녹음

**녹음 중:**
- [ ] 헤드폰 볼륨 확인
- [ ] 테이크마다 즉시 청취
- [ ] 막차 시간 미리 확인 (귀가 일정)
