## 오픈 코드 7개면 수천 곡이 열립니다

C·G·D·Em·Am·E·A. 방음 개인실에서 이 7개를 완벽히 익히고 좋아하는 곡을 연주하세요.

기타 오픈 코드 연습의 핵심:
- **2코드 전환**: 한 번에 2개씩 반복 전환
- **느린 메트로놈**: 정확한 전환 > 빠른 전환
- **매일 연습**: 짧아도 매일이 코드 손가락 단련
- **공통 손가락**: 전환 시 공통 손가락 먼저 파악

| 우선순위 | 코드 | 이유 |
|---------|------|------|
| 1순위 | Em, Am | 가장 쉬움 |

| 4순위 | C | 팝의 핵심 |

## 오픈 코드 전환 훈련에서 지켜야 할 4가지

C·G·D·Em·Am을 하나씩 잡을 수 있게 됐다면, 그다음부터는 어떤 순서로 무엇을 반복하느냐가 속도를 가릅니다.

1. **쉬운 코드부터 순서대로** — Em·Am으로 시작해 E·A, D·G, C를 거쳐 F 바레를 마지막에 둡니다. 어려운 코드를 앞당기면 손가락 통증과 좌절만 먼저 옵니다.

2. **한 번에 두 코드만 전환** — C↔G, G↔D처럼 두 개를 정해 반복합니다. 전환 전에 두 코드에서 같은 자리를 누르는 손가락을 먼저 찾아 두면 움직여야 할 손가락이 줄어듭니다.

3. **느린 메트로놈에서 정확하게** — 빠르게 바꾸는 것보다 박자를 잃지 않고 바꾸는 것이 먼저입니다. 정확해진 뒤에 템포를 올립니다.

4. **짧아도 매일** — 한꺼번에 오래 하는 것보다 짧은 연습을 매일 이어 가는 편이 손가락을 단련합니다. 처음 몇 주의 손끝 통증은 정상 과정이니, 심하게 아프면 쉬어 가세요.

## Studio NOL 연습실에서 기타 오픈코드 연습할 때 확인하는 3가지

스튜디오 놀 연습실에서 기타 오픈코드를 처음 익힐 때 자주 막히는 패턴입니다.

**1. 코드를 잡는 것과 코드 전환이 별개의 문제다**

개별 코드 운지를 익혔더라도 코드 전환 속도가 따라오지 않으면 실제 연주에서 박자가 끊깁니다. G → C → D → Em 같은 기본 전환을 하루 10분씩 메트로놈에 맞춰 반복하는 것이 오픈코드 훈련의 핵심입니다. 코드 전환 시 왼손이 현에서 떨어지는 시간을 최소화하는 의식적 연습이 속도를 만듭니다.

**2. 특정 현이 뭉개지는 원인을 모른 채 반복한다**

코드를 잡았을 때 특정 현에서 뮤팅이 생기면 왼손가락 위치 문제입니다. 어느 손가락이 인접 현을 눌러 소리를 막는지 한 현씩 뜯어보며 확인하는 훈련이 필요합니다. 연습실에서 충분한 볼륨으로 각 현을 개별적으로 확인하는 것이 집에서 소음을 신경 쓰며 연습하는 것보다 훨씬 빠른 교정 방법입니다.

**3. 익숙해진 코드만 반복하고 어려운 코드를 피한다**

G와 Em은 잘 되는데 D나 C 코드에서 계속 막히면 어려운 코드를 집중 훈련하는 시간을 따로 잡아야 합니다. 연습의 절반을 잘 되는 코드, 절반을 막히는 코드에 배분하는 방식이 균형 있는 발전을 만듭니다.

## 오픈 코드 4주 연습 플랜

위의 30분 루틴(워밍업 5분·집중 전환 15분·스트로크 7분·곡 연습 3분)을 매일 돌린다고 보고, 주차마다 집중 전환에 쓰는 코드만 바꿉니다.

| 주차 | 목표 | 집중 전환 코드 | 이번 주의 포인트 |
|------|------|---------------|-----------------|
| 1주차 | 1~2순위 코드 | Em·Am, E·A | 가장 쉬운 코드로 손가락 모양과 눌러 잡는 힘에 익숙해지기 |
| 2주차 | 3순위 코드 | D·G, C↔G, G↔D | 공통 손가락을 먼저 찾고 두 코드씩 전환, 다운 스트로크 붙이기 |
| 3주차 | 4순위 코드 | C 추가, G→C→D→Em | 느린 메트로놈에 맞춰 네 코드를 순서대로 이어 전환 |
| 4주차 | 5순위와 곡 | F 바레 도전 | 배운 코드가 든 곡을 골라 곡 연습 시간을 늘리기 |

**주차별 체크포인트:** 1주차 — Em·Am·E·A를 막힘 없이 잡는다 / 2주차 — 두 코드 전환에서 박자가 끊기지 않는다 / 3주차 — G→C→D→Em을 메트로놈에 맞춰 이어 간다 / 4주차 — 배운 코드가 든 곡을 끝까지 연주한다
