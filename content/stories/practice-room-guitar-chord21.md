## 오픈 코드 7개면 수천 곡이 열립니다

C·G·D·Em·Am·E·A. 방음 개인실에서 이 7개를 완벽히 익히고 좋아하는 곡을 연주하세요.

기타 오픈 코드 연습의 핵심:
- **2코드 전환**: 한 번에 2개씩 반복 전환
- **느린 메트로놈**: 정확한 전환 > 빠른 전환
- **매일 연습**: 짧아도 매일이 코드 손가락 단련
- **공통 손가락**: 전환 시 공통 손가락 먼저 파악

---

## 기타 오픈 코드 학습 우선순위

| 우선순위 | 코드 | 이유 |
|---------|------|------|
| 1순위 | Em, Am | 가장 쉬움 |
| 2순위 | E, A | 록·팝 기본 |
| 3순위 | D, G | 자주 사용 |
| 4순위 | C | 팝의 핵심 |
| 5순위 | F (바레) | 최종 관문 |

| 곡 연습 | 배운 코드 포함 곡 | 3분 |
