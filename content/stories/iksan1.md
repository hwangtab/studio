## 익산에서 KTX로 2시간이면

익산역은 KTX 호남선의 주요 정차역으로 서울까지 약 1시간 40~50분입니다. 전라북도에서 서울 접근성이 가장 좋은 도시 중 하나입니다.

---

## 익산·군산 → 연신내 이동 경로

### 익산역 KTX

```
① 익산역에서 KTX(호남선) 탑승 (서울역 방면)
② 서울역 도착 (약 1시간 40~50분)
③ 1호선 또는 2호선 환승 → 연신내역

총 소요시간: 약 2시간 10~30분
```

### 군산에서 익산 경유

```
① 군산 시내 → 익산역 (버스·택시 약 25~30분)
② 익산역에서 KTX 탑승 → 서울역 도착
③ 지하철 환승 → 연신내역

총 소요시간: 약 2시간 40~3시간
```

## 당일 왕복 일정 예시 (익산 기준)

```
오전 8시 익산역 출발 (KTX)
→ 오전 9시 40분 서울역 도착
→ 오전 10시 20분 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 서울역 출발 (KTX)
→ 오후 3시 50분 익산역 도착
```
