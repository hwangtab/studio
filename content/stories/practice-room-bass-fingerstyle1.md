## 손가락 주법이 베이스의 표현력을 완성합니다

투핑거부터 레이킹·뮤팅까지. 방음 개인실에서 베이스 핑거스타일을 탐색하세요.

베이스 핑거스타일 훈련의 핵심:
- **투·쓰리핑거**: 균등한 음량과 속도의 손가락 교대 기법
- **레이킹**: 하나의 손가락으로 여러 현을 자연스럽게 연결
- **뮤팅 기술**: 불필요한 울림 제거로 깔끔한 베이스 사운드
- **음색 다양화**: 피킹 위치·압력·각도로 다양한 음색 생성

## 베이스 핑거스타일·손가락 주법 훈련을 극대화하는 4가지 원칙

기타 연습의 효율은 **무엇을 연습하느냐**보다 **어떻게 연습하느냐**에 달려 있습니다. 목적 있는 반복이 막연한 반복보다 10배 빠릅니다.

1. **문제 구간 집중** — 어려운 2~4마디를 전체 반복보다 10~20회 집중. 문제 구간을 건너뛰는 습관은 영원히 그 구간이 약점으로 남습니다.
2. **녹음으로 객관화** — 스마트폰으로 매 세션 일부를 녹음하고 청취. 연주 중에는 인식 못한 음정·리듬·폼 문제가 녹음에서 명확히 드러납니다.
3. **느린 속도의 완성** — 해당 기법을 느린 속도에서 완벽하게 연주할 수 없다면 빠른 속도는 불가능합니다. 느린 속도의 정확함이 빠른 속도의 기반입니다.
4. **음악적 맥락 적용** — 연습한 기법을 항상 실제 곡이나 즉흥 연주에 적용. 기법 자체보다 음악 안에서의 사용이 실력으로 이어집니다.

### 핑거피킹에서 자주 하는 실수

1. **손목이 현 위에 닿아서 소리가 죽음** — 오른손 손목이 기타 바디에서 떨어지도록 위치 조정
2. **엄지(P)가 1·2·3현을 건드림** — 엄지는 4·5·6현만, 나머지 손가락은 1·2·3현 담당
3. **너무 빠른 속도로 연습** — BPM 60에서 패턴을 완전히 체득 후 속도 올리기

### 핑거피킹 자가 진단

- [ ] 베이스 음(엄지)과 멜로디 음의 볼륨 균형이 맞는가?
- [ ] 오른손 각 손가락의 역할(P·I·M·A)이 일관되게 유지되는가?
- [ ] 패턴을 메트로놈 없이도 일정한 박자로 연주할 수 있는가?
