## 장흥에서 KTX로 서울까지

장흥은 전남 남부의 아름다운 도시로, 광주 또는 순천을 경유해 KTX로 서울에 연결됩니다. 이동이 길어 온라인 파일 의뢰 서비스와 병행하는 아티스트들이 많습니다.

---

## 장흥 → 연신내 이동 경로

### KTX 광주송정역 경유

```
① 장흥 → 광주송정역 (버스 약 1시간 30분~2시간)
② 광주송정역 KTX 탑승 (서울역 방면, 약 1시간 40~50분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간 40분~4시간 30분
```

### SRT 순천역 경유

```
① 장흥 → 순천역 (버스 약 1시간 10~20분)
② 순천역 SRT/KTX 탑승 (수서역 또는 서울역 방면, 약 2시간 30~40분)
③ 서울/수서 → 지하철 → 연신내역 (약 30~50분)

총 소요시간: 약 4시간 20~50분
```

## 당일 왕복 일정 예시 (장흥 기준)

```
오전 5시 30분 장흥 출발 → 광주송정역 이동
오전 7시 30분 광주송정역 KTX 출발
→ 오전 9시 20분 서울역 도착
→ 오전 10시 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 서울역 출발
→ 오후 3시 50분 광주송정역 도착
→ 오후 5시 50분 장흥 도착
```
