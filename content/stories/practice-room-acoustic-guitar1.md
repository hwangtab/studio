## 통기타 연습, 방음 공간에서 더 많이 더 자유롭게

통기타는 전기 앰프 없이도 소음이 될 수 있습니다.

| 상황 | 어려움 | 해결 |
|-----|------|-----|
| 아파트 | 저녁 9시 이후 연습 어려움 | 24시간 방음 연습실 |
| 원룸 | 이웃에게 소음 전달 | 방음 STC 50+ |
| 기타 + 보컬 | 집에서 크게 못 함 | PA 스피커 + 마이크 |
| 영상 촬영 | 배경·음질 문제 | 조용한 연습실 촬영 |

---

## 통기타 학습 단계별 연습 방법

### 입문 (코드 3~5개 배운 단계)

- 기본 코드 스트로크 패턴 반복
- 코드 전환 부드럽게 (C→G→Am→F)
- 쉬운 노래 1~2곡 완성
- 주 3~4회, 30분~1시간

### 중급 (핑거스타일 입문)

- 아르페지오 패턴 숙달
- 바레 코드 완성
- 좋아하는 곡 커버 연습
- 기타 + 보컬 동시 연습 시작

### 고급 (퍼포먼스·커버 영상 수준)

- 전곡 논스톱 퍼포먼스 완성
- 기타 솔로·인트로 아르페지오 완성
- 카포 활용 키 조절
- 버스킹·커버 영상 수준 완성도

---

## 통기타 + 보컬 동시 연습 팁

1. 먼저 기타만 완벽히 → 그다음 노래만 → 마지막에 동시
2. 처음에는 천천히 (본인이 편한 템포부터)
3. 발을 가볍게 박자 탭핑하며 연습
4. 스마트폰 녹화 → 박자·음정 양쪽 동시 점검

---

## 스튜디오 놀 — 통기타 연습 환경

| 항목 | 통기타 연습 가치 |
|-----|------------|
| STC 50+ 방음 | 기타 소음 외부 차단, 마음껏 연습 |
| PA 스피커 | 버스킹·공연 볼륨 미리 체험 |
| 마이크 스탠드 | 기타 + 보컬 동시 퍼포먼스 |
| 무인 운영 | 타인 시선 없이 편하게 |
| 24시간 운영 | 야간·주말 자유롭게 |
| 시간 대여 | 8,000~25,000원/시간 |
| 월정액 입주 | 30만원대~, 보증금 없음 |
