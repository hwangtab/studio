# 기타 재즈 코드·텐션 코드 보이싱 — 음악연습실 완전 가이드

재즈 기타리스트의 코드 어휘는 팝·록 기타리스트와 근본적으로 다릅니다. G·C·D 같은 기본 3화음으로는 재즈의 복잡한 화성을 표현할 수 없습니다. **7th 코드, 9th 코드, 11th 코드, 13th 코드**—이 확장 화음들이 재즈의 색채를 만듭니다. 이 가이드에서는 재즈 기타 코드의 원리부터 실용적인 보이싱까지 체계적으로 안내합니다.

---

## 재즈 코드의 기본 이해

### 4성부 코드 (4-Voice Chord)

재즈 기타에서 가장 기본적인 코드 형태는 4음 코드입니다. 기타는 6현을 가지지만 재즈 코드에서는 불필요한 현은 뮤트하고 핵심 4음만 사용합니다.

**기본 7th 코드 종류:**
- **메이저 세븐스(Maj7)**: C-E-G-B → 밝고 따뜻한 느낌
- **도미넌트 세븐스(7)**: C-E-G-B♭ → 긴장감, 해결을 향하는 느낌
- **마이너 세븐스(m7)**: C-E♭-G-B♭ → 부드러운 단조
- **마이너 메이저 세븐스(mMaj7)**: C-E♭-G-B → 독특하고 긴장된 느낌
- **하프 디미니쉬드(m7♭5)**: C-E♭-G♭-B♭ → 재즈 ii chord

### 텐션 노트 (Tension Notes)

9, 11, 13도 음은 코드에 색채를 더하는 "텐션" 음입니다.

- **9도**: 루트보다 2도 높은 음 (루트+옥타브+2도)
- **11도**: 루트보다 4도 높은 음 (루트+옥타브+4도)
- **13도**: 루트보다 6도 높은 음 (루트+옥타브+6도)

---

## 기타에서의 재즈 코드 보이싱

### 드롭 2 보이싱 (Drop 2 Voicing)

자주 사용되는 재즈 기타 보이싱입니다.

**드롭 2 원리:**
4성부 코드의 위에서 두 번째 성부를 한 옥타브 내려 배치합니다.

**Gmaj7 드롭 2 보이싱 예:**
```

원래 4성부: G-B-D-F# (아래서 위로)
드롭 2 적용: G-D-F#-B (두 번째 성부 B를 아래로)
기타 배치:
 1번 현: B (7프렛)
 2번 현: F# (7프렛)
 3번 현: D (7프렛)
 4번 현: G (5프렛)

```

### 실용적인 7th 코드 보이싱 (5번 현 루트 기준)

**Dm7 (D 마이너 7th):**
```
5번 현: 5프렛 (A - 뮤트)
4번 현: 7프렛 (C)
3번 현: 7프렛 (G)
2번 현: 6프렛 (E♭)
1번 현: 5프렛 (D)

```

**G7 (G 도미넌트 7th):**
```
6번 현: 3프렛 (G)
5번 현: 뮤트
4번 현: 4프렛 (B)
3번 현: 3프렛 (D)
2번 현: 3프렛 (F)
1번 현: 3프렛 (G - 옵션)

```

---

## ii-V-I 진행의 재즈 코드

재즈의 가장 기본 진행인 ii-V-I를 재즈 코드로 연주합니다.

**C 메이저 ii-V-I:**
- ii: Dm7
- V: G7 (또는 G13, G7#11 등 변형)
- I: Cmaj7 (또는 Cmaj9)

**코드 보이싱의 효율적인 이동:**

인접한 코드들이 최소한의 손 이동으로 연결되도록 보이싱을 선택합니다. 이를 "보이스 리딩(Voice Leading)"이라고 합니다.

---

## 텐션이 포함된 고급 코드

### 9th 코드

Cmaj9: C-E-G-B-D (5음)
기타에서 5음을 모두 치기 어려우므로 핵심음만 선택합니다: E-G-B-D (3,7도+9도)

### 13th 코드

G13: G-B-D-F-A-C-E (7음)
기타에서는 핵심음: G-B-F-E (루트, 3도, 7도, 13도)

### 알터드 코드 (Altered Chord)

G7alt: G-B-D♭-F-A♭ (또는 다양한 조합)
도미넌트 코드의 5도와 9도를 변형시킨 코드입니다. 재즈에서 강한 긴장감을 만들고 해결을 향합니다.

---

## 재즈 리듬 기타 (Comping)

### 콤핑(Comping)이란

콤핑은 재즈 앙상블에서 반주 기타가 솔로이스트를 지원하는 것입니다. 정박보다 오프비트(Offbeat)에 코드를 배치하여 독특한 재즈 리듬감을 만듭니다.

**기본 콤핑 리듬:**
```

박자: 1 &  2 &  3 &  4 &
코드: X        X X     (& 박자에 코드)

```

### 재즈 기타 명인의 콤핑 스타일

- **Freddie Green**: 카운트 베이시 빅밴드의 기타. 4분음표 리듬 콤핑의 대가
- **Kenny Burrell**: 블루지한 재즈 콤핑의 교과서
- **Wes Montgomery**: 옥타브 주법과 콤핑의 완벽한 균형

## 재즈 코드 연습 루틴

### 초급 (첫 달)

- Dm7-G7-Cmaj7 (ii-V-I in C) 기본 보이싱 반복
- 느린 템포(BPM 60)에서 보이싱 전환
- 코드 유지 시간 1마디씩

### 중급 (2~3개월)

- 5번 현 루트 + 4번 현 루트 보이싱 모두 익힘
- 다양한 키로 전조
- 텐션 코드 추가

### 고급 (4개월 이후)

- 알터드 코드, 대리 코드
- 재즈 스탠더드에서 콤핑 적용
- 솔리스트와의 실제 앙상블 연습

## Studio NOL이 재즈 코드 연습실 사용자에게 자주 권하는 3가지

스튜디오 놀(연신내, 서울 은평구) 음악연습실에서 기타 재즈 코드·텐션 코드 보이싱 연습 상담 때 자주 드리는 조언입니다.

**1. Drop 2·Drop 3 — 4성부 보이싱 기본**

재즈 코드 워크의 절반은 Drop 2·Drop 3 보이싱입니다. 7th 코드(maj7·m7·dom7)를 Drop 2 형태로 4개 현 그룹별로 익힙니다.

**2. 텐션 추가 단계 — 9·11·13 순서로 추가**

기본 7th를 마스터하기 전 텐션을 더하면 사운드가 흐려집니다. 9th → 11th → 13th 순서로 단계적으로 추가합니다.

**3. 톤 노브 4~6 — 재즈 음색 표준**

재즈 코드의 따뜻한 음색은 톤 노브 4~6에서 가장 잘 나옵니다. 톤 노브 10으로 두면 트레블이 과해 재즈 감성과 어긋납니다.
