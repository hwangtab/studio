## 경기 동부·강원에서 전문 녹음실까지

양평·가평·춘천 등 경기 동부와 강원도 지역에서도 연신내 스튜디오 놀에 방문할 수 있습니다.

---

## 지역별 소요 시간

| 출발지 | 경로 | 소요 시간 |
|-------|------|---------|
| 양평역 | 경의중앙선 → 환승 → 6호선 | 약 70~80분 |
| 국수역 (양평) | 경의중앙선 → 환승 | 약 60~70분 |
| 가평역 | 경춘선 → 환승 → 6호선 | 약 90~100분 |
| 춘천역 | ITX·경춘선 → 환승 | 약 90~110분 |
| 홍천 | 버스 → 춘천 → 열차 | 약 120분+ |

---

## 추천 이동 경로

### 양평 → 연신내

```
① 양평역 또는 국수역에서 경의중앙선 탑승
② 용산역 또는 왕십리역 하차
③ 2호선 탑승 → 합정역 하차
④ 6호선 탑승 → 연신내역 하차
⑤ 2번 출구 → 도보 5분

소요: 약 70~80분
```

### 가평 → 연신내

```
① 가평역에서 경춘선 탑승
② 청량리역 또는 상봉역 환승
③ 환승 → 6호선 → 연신내역

소요: 약 90~100분
```

## 당일 방문 일정 예시 (양평 기준)

```
오전 9시 30분 출발 (양평역)
→ 10시 50분 연신내역 도착
→ 11시 세션 시작 (2시간)
→ 13시 세션 완료
→ 14시 30분 양평 귀가
```

## 원격 파일 의뢰 서비스

이동이 어렵다면:

```
1. 드라이 보컬 WAV 파일 + MR 전송
2. 스튜디오 놀 엔지니어 믹싱·마스터링
3. 완성 파일 클라우드 납품
→ 카카오톡으로 문의
```
