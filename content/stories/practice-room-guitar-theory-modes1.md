# 기타 모드 이론·7가지 교회 선법 — 음악연습실 완전 가이드

"모드(Mode)는 어렵다"는 인식이 있지만, 실제로는 **C 장조 스케일의 시작 음을 달리하는 것**에서 출발합니다. 이 간단한 원리에서 7가지 다른 색채를 가진 스케일이 탄생합니다. 기타리스트에게 모드를 이해하면 즉흥연주의 팔레트가 극적으로 넓어집니다.

---

## 모드의 기본 개념

### C 메이저 스케일의 모드들

**C-D-E-F-G-A-B-C** = C 이오니안 (장조)

같은 음을 각기 다른 음에서 시작:
- C부터: **이오니안 (Ionian)** = C 장조
- D부터: **도리안 (Dorian)** = D 도리안
- E부터: **프리지안 (Phrygian)** = E 프리지안
- F부터: **리디안 (Lydian)** = F 리디안
- G부터: **믹소리디안 (Mixolydian)** = G 믹소리디안
- A부터: **에올리안 (Aeolian)** = A 자연단음
- B부터: **로크리안 (Locrian)** = B 로크리안

---

## 7가지 모드의 특성

### 1. 이오니안 (Ionian) — C 장조와 동일

**음계:** C-D-E-F-G-A-B-C
**특성:** 밝고, 행복하고, 완결된 느낌
**활용:** 팝, 클래식, 대부분의 장조 음악
**기타 포지션 (E현 8프렛 C):**
```
e|--8-10-12-13-15-|
B|--8-10-12-13----|
G|--9-10-12-------|
```

### 2. 도리안 (Dorian) — D부터

**음계:** D-E-F-G-A-B-C-D
**특성:** 마이너하지만 6도가 장음정으로 밝음
**활용:** 재즈, 록(Santana), 팝
**특징 음:** 장6도(B) — "쿨한 마이너"
```
e|--10-12-13-15-17--|
B|--10-12-13-15-----|
G|--10-12-14--------|
```

### 3. 프리지안 (Phrygian) — E부터

**음계:** E-F-G-A-B-C-D-E
**특성:** 스페인·플라멩코 느낌, 어둡고 이국적
**활용:** 플라멩코, 메탈(Metallica), 스페인 음악
**특징 음:** 단2도(F) — 스페인 특유의 반음

### 4. 리디안 (Lydian) — F부터

**음계:** F-G-A-B-C-D-E-F
**특성:** 몽환적, 공중에 뜨는 느낌
**활용:** 영화음악, 퓨전 재즈, 꿈 같은 팝
**특징 음:** 증4도(B, #4) — 리디안의 핵심

### 5. 믹소리디안 (Mixolydian) — G부터

**음계:** G-A-B-C-D-E-F-G
**특성:** 장조이지만 b7으로 블루스·펑크 느낌
**활용:** 블루스, 록, 펑크, 켈틱
**특징 음:** 단7도(F) — 이것이 블루스의 핵심

### 6. 에올리안 (Aeolian) — A부터 (자연단음)

**음계:** A-B-C-D-E-F-G-A
**특성:** 슬프고 자연스러운 단음
**활용:** 팝 단조, 록, 클래식 단조
**포지션 (A 마이너 = A 에올리안):**
```
e|--5-7-8-10-12--|
```

### 7. 로크리안 (Locrian) — B부터

**음계:** B-C-D-E-F-G-A-B
**특성:** 가장 어둡고 불안한 느낌
**활용:** 메탈, 실험적 음악, 드라마틱 효과
**특징:** 단2도 + 감5도 — 극도의 불안정감

| 마이너 7 | 도리안 또는 에올리안 |
| 도미넌트 7 | 믹소리디안 |
| 마이너 7b5 | 로크리안 |

```

D 도리안 스케일로 자유 즉흥
장6도(B)를 의식적으로 사용
```

## 음악연습실 모드 루틴

### 기초 단계 (60분)

**1. 이오니안 + 에올리안 (20분)**
- C 이오니안, A 에올리안 모두 익숙히 연주
- 이 둘이 같은 음이라는 것 이해

**2. 도리안 연습 (20분)**
- D 도리안 = C 이오니안의 D부터
- Dm7 트랙 위에서 즉흥

**3. 믹소리디안 연습 (20분)**
- G 믹소리디안 = C 이오니안의 G부터
- G7 트랙 위에서 즉흥
