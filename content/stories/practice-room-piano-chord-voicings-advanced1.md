# 피아노 코드 보이싱 고급·텐션 노트 활용 — 음악연습실 완전 가이드

재즈 피아니스트와 팝 피아니스트를 구분하는 가장 큰 요소 중 하나가 **텐션 노트의 활용**입니다. 기본 3화음이나 7화음을 넘어 9th, 11th, 13th를 추가하면 화성이 훨씬 색채롭고 정교해집니다. 이 가이드에서는 고급 보이싱 기법을 체계적으로 안내합니다.

---

## 텐션 노트의 기초

### 텐션이란?

텐션(Tension)은 **코드의 기본음(1, 3, 5, 7) 위에 추가되는 음**으로, 9th, 11th, 13th가 있습니다.

**음정 관계:**
```
루트 - 1
장2도 - 9th (루트 + 옥타브 + 2도)
완전4도 - 11th (루트 + 옥타브 + 4도)
장6도 - 13th (루트 + 옥타브 + 6도)
```

**Cmaj7 텐션:**
```
Cmaj9:   C-E-G-B-D (9th 추가)
Cmaj11:  C-E-G-B-D-F (11th 추가)
Cmaj13:  C-E-G-B-D-F-A (13th 추가)
```

### 텐션 활용 규칙

**어보이드 노트(Avoid Note):**
특정 코드에서 충돌하는 텐션. 예:
- 메이저 코드의 11th(F) = 3도(E)와 반음 충돌
- 해결책: #11(리디안 텐션) 사용

## 고급 보이싱 기법

### 쿼털 보이싱 (Quartal Voicing)

4도 간격으로 음을 쌓는 현대적 보이싱:

**Dm7 쿼털 보이싱:**
```
오른손: F-C-G (4도+4도+완전5도)
왼손: D-A (5도)
```

**Herbie Hancock 스타일 Cm7 쿼털:**
```
오른손: Eb-Bb-F-C
왼손: C-G
```

### 크러스터 보이싱 (Cluster Voicing)

반음 또는 온음 간격으로 음을 밀집시키는 보이싱:

```
Cmaj7#11 크러스터:
오른손: B-C-D-E (2도 간격 밀집)
왼손: G-C
```

현대 재즈·컨템퍼러리에서 자주 사용

### 드롭 2 보이싱

5성부 보이싱에서 위에서 두 번째 음을 한 옥타브 낮추는 기법:

**Cmaj7 드롭 2:**
```
원본: G-E-B-D (위에서 아래)
드롭 2: B-G-E-D (두 번째 음 G를 아래로)
```

## 코드별 고급 보이싱 예시

### 메이저 7th 고급 보이싱

**Cmaj9 보이싱:**
```
오른손: B-D-G (3성부)
왼손: C-E (루트+3도)
효과: 깔끔하고 현대적인 메이저 사운드
```

**Cmaj13 보이싱:**
```
오른손: B-D-A (7th-9th-13th)
왼손: C-G (루트-5도)
효과: 화려한 재즈 메이저 컬러
```

### 도미넌트 7th 고급 보이싱

**G13 보이싱:**
```
오른손: F-B-E (b7-3rd-13th)
왼손: G-D (루트-5도)
```

**G7alt 보이싱 (얼터드):**
```
오른손: F-Db-Ab (b7-b9-b13)
왼손: G-B (루트-3도)
효과: 극도로 긴장된 얼터드 도미넌트
```

### 마이너 7th 고급 보이싱

**Dm11 보이싱:**
```
오른손: C-G-A (7th-4th-5th 쿼털)
왼손: D-F (루트-b3도)
```

## 왼손 보이싱 기법

### 루트리스 보이싱 (Rootless Voicing)

재즈에서 베이시스트가 루트를 담당할 때 피아노 왼손은 루트를 생략:

**G7 루트리스 보이싱 (A형):**
```
왼손: B-F (3도-b7도)
```

**G7 루트리스 보이싱 (B형):**
```
왼손: F-B (b7도-3도)
```

이 두 보이싱이 II-V-I의 기본:

```
Dm7: F-A-C-E (A형 전위)
G7:  B-F-A-D (B형)
Cmaj7: E-B-D-G (A형)
```

## 음악연습실 고급 보이싱 루틴

### 1단계: 텐션 인식 (15분)
- Cmaj7부터 모든 텐션 음정 확인
- 각 텐션의 음색 청취

### 2단계: 보이싱 패턴 암기 (25분)
- 루트리스 A형, B형 모든 조성
- 쿼털 보이싱 5가지 코드

### 3단계: II-V-I 연결 (20분)
- C, F, Bb, Eb 조 루트리스 보이싱 연결
- 왼손 보이싱 + 오른손 멜로디

## 마무리

고급 보이싱은 단순히 음을 추가하는 것이 아니라 **화성의 색채를 통제하는 기술**입니다. 은평구 24시간 음악연습실에서 루트리스 보이싱부터 시작해 점진적으로 쿼털, 크러스터, 얼터드 텐션으로 확장하세요.

각 보이싱을 모든 12개 조성에서 익히는 것이 목표입니다. 그러면 어떤 곡에서도 유연하게 보이싱을 선택할 수 있는 진정한 재즈 피아니스트가 됩니다.
