# 피아노 코드 보이싱 고급·텐션 노트 활용 — 음악연습실 완전 가이드

재즈 피아니스트와 팝 피아니스트를 구분하는 가장 큰 요소 중 하나가 **텐션 노트의 활용**입니다. 기본 3화음이나 7화음을 넘어 9th, 11th, 13th를 추가하면 화성이 훨씬 색채롭고 정교해집니다. 이 가이드에서는 고급 보이싱 기법을 체계적으로 안내합니다.

---

## 텐션 노트의 기초

### 텐션이란?

텐션(Tension)은 **코드의 기본음(1, 3, 5, 7) 위에 추가되는 음**으로, 9th, 11th, 13th가 있습니다.

**음정 관계:**
```

루트 - 1
장2도 - 9th (루트 + 옥타브 + 2도)
완전4도 - 11th (루트 + 옥타브 + 4도)
장6도 - 13th (루트 + 옥타브 + 6도)

```

**Cmaj7 텐션:**
```

Cmaj9: C-E-G-B-D (9th 추가)
Cmaj11: C-E-G-B-D-F (11th 추가)
Cmaj13: C-E-G-B-D-F-A (13th 추가)

```

### 텐션 활용 규칙

**어보이드 노트(Avoid Note):**

특정 코드에서 충돌하는 텐션. 예:
- 메이저 코드의 11th(F) = 3도(E)와 반음 충돌
- 해결책: #11(리디안 텐션) 사용

## 고급 보이싱 기법

### 쿼털 보이싱 (Quartal Voicing)

4도 간격으로 음을 쌓는 현대적 보이싱:

**Dm7 쿼털 보이싱:**
```

오른손: F-C-G (4도+4도+완전5도)
왼손: D-A (5도)

```

**Herbie Hancock 스타일 Cm7 쿼털:**
```

오른손: Eb-Bb-F-C
왼손: C-G

```

### 크러스터 보이싱 (Cluster Voicing)

반음 또는 온음 간격으로 음을 밀집시키는 보이싱:

```

Cmaj7#11 크러스터:
오른손: B-C-D-E (2도 간격 밀집)
왼손: G-C

```

현대 재즈·컨템퍼러리에서 자주 사용

### 드롭 2 보이싱

5성부 보이싱에서 위에서 두 번째 음을 한 옥타브 낮추는 기법:

**Cmaj7 드롭 2:**
```

원본: G-E-B-D (위에서 아래)
드롭 2: B-G-E-D (두 번째 음 G를 아래로)

```

## 코드별 고급 보이싱 예시

### 메이저 7th 고급 보이싱

**Cmaj9 보이싱:**
```

오른손: B-D-G (3성부)
왼손: C-E (루트+3도)
효과: 깔끔하고 현대적인 메이저 사운드

```

**Cmaj13 보이싱:**
```

오른손: B-D-A (7th-9th-13th)
왼손: C-G (루트-5도)
효과: 화려한 재즈 메이저 컬러

```

### 도미넌트 7th 고급 보이싱

**G13 보이싱:**
```

오른손: F-B-E (b7-3rd-13th)
왼손: G-D (루트-5도)

```

**G7alt 보이싱 (얼터드):**
```

오른손: F-Db-Ab (b7-b9-b13)
왼손: G-B (루트-3도)
효과: 극도로 긴장된 얼터드 도미넌트

```

### 마이너 7th 고급 보이싱

**Dm11 보이싱:**
```

오른손: C-G-A (7th-4th-5th 쿼털)
왼손: D-F (루트-b3도)

```

## 왼손 보이싱 기법

### 루트리스 보이싱 (Rootless Voicing)

재즈에서 베이시스트가 루트를 담당할 때 피아노 왼손은 루트를 생략:

**G7 루트리스 보이싱 (A형):**
```

왼손: B-F (3도-b7도)

```

**G7 루트리스 보이싱 (B형):**
```

왼손: F-B (b7도-3도)

```

이 두 보이싱이 II-V-I의 기본:

```

Dm7: F-A-C-E (A형 전위)
G7: B-F-A-D (B형)
Cmaj7: E-B-D-G (A형)

```

## 음악연습실 고급 보이싱 루틴

### 1단계: 텐션 인식 (15분)

- Cmaj7부터 모든 텐션 음정 확인
- 각 텐션의 음색 청취

### 2단계: 보이싱 패턴 암기 (25분)

- 루트리스 A형, B형 모든 조성
- 쿼털 보이싱 5가지 코드

### 3단계: II-V-I 연결 (20분)

- C, F, Bb, Eb 조 루트리스 보이싱 연결
- 왼손 보이싱 + 오른손 멜로디

## 마무리

고급 보이싱은 단순히 음을 추가하는 것이 아니라 **화성의 색채를 통제하는 기술**입니다. 은평구 24시간 음악연습실에서 루트리스 보이싱부터 시작해 점진적으로 쿼털, 크러스터, 얼터드 텐션으로 확장하세요.

각 보이싱을 모든 12개 조성에서 익히는 것이 목표입니다. 그러면 어떤 곡에서도 유연하게 보이싱을 선택할 수 있는 진정한 재즈 피아니스트가 됩니다.

고급 코드 보이싱은 동일한 화음이라도 어떤 음을 어느 위치에 배치하느냐에 따라 음색과 긴장감이 완전히 달라지는 정교한 기술입니다. 왼손에 루트와 7th를 배치하고 오른손에 3rd와 확장음(9th, 11th, 13th)을 구성하는 쉘 보이싱은 재즈 피아노의 기본 어법입니다.

피아노 연습에서 양손 독립성을 키우는 것이 가장 중요한 과제 중 하나입니다. 처음에는 오른손과 왼손을 따로 연습한 뒤 천천히 합치는 방법이 효과적입니다. 왼손 반주 패턴을 완전히 자동화한 상태에서 오른손 선율에 집중하면 전체 연주의 완성도가 높아집니다. 페달 사용 타이밍을 의식적으로 조절하면 음의 연결과 여운을 섬세하게 표현할 수 있습니다. 어려운 구간은 반드시 분리해 반복 연습한 뒤 전체에 통합하는 방식이 효율적입니다. 규칙적인 연습 루틴을 만들고 꾸준히 유지하는 것이 단기간의 집중 연습보다 장기적으로 더 큰 효과를 만들어냅니다. 하루 30분씩 매일 연습하는 것이 주말에만 3시간씩 연습하는 것보다 신체 기억과 음악적 감각 형성에 훨씬 유리합니다. 연습 중 어려운 부분에 막힐 때는 천천히, 더 작은 단위로 나눠 반복하는 것이 돌파구가 됩니다. 목표 악기와 음악 스타일에 맞는 연습 방법을 지속적으로 탐구하고 실험하는 자세가 장기적인 성장의 원동력입니다.
