# 블루스 슬라이드 기타·Duane Allman·Derek Trucks·보틀넥 주법 — 음악연습실 완전 가이드

블루스 슬라이드 기타(Blues Slide Guitar)는 **유리병 목이나 금속 튜브를 손가락에 끼워 기타 줄을 밀어 연주하는 가장 원초적인 블루스 표현법**입니다. Duane Allman의 서던 록 슬라이드, Derek Trucks의 힌두스타니 영향 슬라이드, Robert Johnson의 미시시피 델타 슬라이드 — 슬라이드 기타는 100년 블루스 역사의 심장입니다.

---

## 슬라이드 기타란?

### 보틀넥의 기원

**슬라이드 기타의 역사:**
```
1900년대 초 미시시피 델타
유리병 목(bottleneck)으로 기타 현 밀기
= 인간 목소리처럼 우는 기타 소리
```

**슬라이드의 특징:**
```
음정이 연속적으로 변화 (포르타멘토)
비브라토 자유자재
오픈 튜닝 + 슬라이드 = 블루스의 영혼
```

---

## Duane Allman

### 서던 록 슬라이드의 전설

Duane Allman:
- **유리 보틀넥:** Coricidin 약병 사용
- **오픈 E 튜닝:** E-B-E-G#-B-E
- **서스테인 슬라이드:** 길고 노래하는 음

**"Layla" 슬라이드:**
```
Eric Clapton과 함께 녹음
Duane의 슬라이드가 아웃로 멜로디 담당
= 록 역사상 가장 감동적인 슬라이드
```

**Duane Allman 터치:**
```
슬라이드를 현에 가볍게 얹기
너무 세게 누르면 현 막힘
= 가벼운 터치로 풍부한 서스테인
```

---

## Derek Trucks

### 힌두스타니 슬라이드

Derek Trucks:
- **오픈 E 튜닝:** Duane Allman 계보
- **힌두스타니 음악:** 인도 라가 영향
- **손가락 피킹:** 픽 없이 손가락으로

**Derek Trucks 특징:**
```
마이크로토날 슬라이드 (미분음)
라가 스케일 + 블루스 혼합
= 인도 음악의 서정성 + 미국 블루스
```

**"Midnight in Harlem" 슬라이드:**
```
멜로디 라인을 슬라이드로 노래처럼
오픈 E에서 고음 현 멜로디
= 슬라이드가 제2의 보컬
```

## 오픈 튜닝 세팅

### 슬라이드 기타의 기본

**오픈 E 튜닝:**
```
E-B-E-G#-B-E
= 기본 E 메이저 코드 오픈
슬라이드 바레로 코드 이동
```

**오픈 G 튜닝:**
```
D-G-D-G-B-D
= 기본 G 메이저 코드 오픈
롤링 스톤스·로버트 존슨 사용
```

**오픈 D 튜닝:**
```
D-A-D-F#-A-D
= D 메이저 오픈
델타 블루스 전통 튜닝
```

## 슬라이드 테크닉

### 핵심 기법들

**슬라이드 기초:**
```
슬라이드 손가락: 보통 약지
현에 수직으로 얹기 (누르지 않기)
= 프렛 위에 슬라이드 위치
```

**비브라토:**
```
슬라이드를 앞뒤로 진동
좁게 빠르게 또는 넓게 느리게
= 목소리처럼 떨리는 음
```

**뮤팅:**
```
슬라이드 뒤쪽 손가락으로 뮤트
불필요한 현 소리 제거
= 깨끗한 슬라이드 톤
```

**포지션 이동:**
```
한 프렛에서 다른 프렛으로
부드럽게 글라이드 (glide)
= 음과 음이 연결되는 슬라이드
```

## 델타 블루스 슬라이드

### Robert Johnson 스타일

**Robert Johnson:**
```
1930년대 미시시피
오픈 A 또는 오픈 G 튜닝
기타 혼자 리듬 + 멜로디 + 베이스
```

**델타 블루스 패턴:**
```
베이스 현: 엄지로 반복 펌핑
멜로디 현: 슬라이드로 노래
= 혼자 모든 걸 하는 솔로 블루스
```

---

## 슬라이드 선택

### 재질별 사운드

**유리 슬라이드:**
```
부드럽고 따뜻한 톤
Duane Allman이 선호
= 블루스 전통적 따뜻한 사운드
```

**금속 슬라이드:**
```
밝고 서스테인 긴 톤
더 현대적이고 날카로운
= 록·컨트리 슬라이드에 유리
```

**도자기(세라믹) 슬라이드:**
```
유리와 금속의 중간 톤
= 고전적인 따뜻함 + 서스테인
```

## 음악연습실 슬라이드 기타 연습

### 60분 루틴

**1. 오픈 튜닝 적응 (15분)**
   - 오픈 G로 재튜닝
   - 슬라이드 없이 코드 확인
   - 슬라이드 얹어 E 포지션 (12프렛)

**2. 기초 슬라이드 이동 (15분)**
   - 5프렛 → 7프렛 → 12프렛
   - 각 포지션에서 비브라토
   - 느리게 (♩= 60)

**3. 블루스 멜로디 (15분)**
   - 오픈 G 블루스 스케일
   - 슬라이드로 멜로디 연주
   - 뮤팅 연습 병행

**4. 델타 블루스 그루브 (15분)**
   - 엄지 베이스 + 슬라이드 멜로디
   - E7 코드 위 슬라이드 즉흥
   - 노래하는 슬라이드 표현

## 마무리

블루스 슬라이드 기타는 **기타가 우는 순간**입니다. Derek Trucks가 "슬라이드는 기타가 목소리를 얻는 것"이라고 했듯, 오픈 E 튜닝에서 슬라이드를 얹으면 기타가 정말로 노래합니다. 기술보다 감정이 먼저입니다.
