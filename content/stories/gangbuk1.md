## 강북구·도봉구에서 전문 녹음실 찾기

수유·미아·방학·쌍문 등 강북구·도봉구 주민들이 전문 보컬 녹음을 위해 스튜디오 놀을 찾습니다. 4호선 또는 우이신설선을 이용하면 6호선 연신내역까지 환승 1~2회로 도달할 수 있습니다.

---

## 각 지역에서 스튜디오 놀까지

| 출발지 | 교통편 | 소요 시간 |
|--------|--------|---------|
| 수유역 | 4호선 → 성신여대입구 → 6호선 연신내역 | 약 25~30분 |
| 미아사거리역 | 4호선 → 성신여대입구 → 6호선 연신내역 | 약 20~25분 |
| 미아역 | 4호선 → 성신여대입구 → 6호선 연신내역 | 약 22~27분 |
| 길음역 | 4호선 → 성신여대입구 → 6호선 연신내역 | 약 20~25분 |
| 쌍문역 | 1호선 창동 → 4호선 → 성신여대입구 → 6호선 | 약 35~40분 |
| 방학역 | 1호선 창동 → 4호선 → 성신여대입구 → 6호선 | 약 35~40분 |
| 도봉산역 | 1호선 창동 → 4호선 → 성신여대입구 → 6호선 | 약 40분 |
| 북한산우이역 | 우이신설선 → 성신여대입구 → 6호선 | 약 35~40분 |

**스튜디오 주소**: 서울특별시 은평구 (연신내역 3번 출구 도보 5분)

| 도봉구 (쌍문·방학) | 약 35~40분 | 1호선 → 4호선 환승 |

| 성북구 (길음·정릉) | 약 20~25분 | 4호선 연결 |
