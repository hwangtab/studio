## 오산에서 1호선으로 서울까지

오산은 경기 남부 도시로, 1호선 전철을 통해 서울과 약 1시간 20분으로 연결됩니다. 수원·평택 사이에 위치해 교통이 편리하며, 오산역에서 환승 한 번으로 연신내 스튜디오 놀까지 당일 왕복이 충분히 가능합니다.

---

## 오산 → 연신내 이동 경로

### 1호선 + 6호선 경로 (추천)

1. 오산역 또는 오산대역에서 1호선 서울역 방면 탑승
2. 서울역 하차 (약 50분~1시간)
3. 서울역 → 6호선 환승 → 연신내역 하차 (약 25~30분)
4. 3번 출구 → 도보 5분

- **총 소요시간**: 약 1시간 20분~1시간 40분

| 시간 | 일정 |
|------|------|
| 오전 8:30 | 오산역 출발 (1호선) |
| 오전 10:00 | 연신내역 도착 |
| 오전 10:30 | 세션 시작 (2시간) |
| 오후 12:30 | 세션 완료 |
| 오후 1:00 | 연신내역 출발 |
| 오후 2:30 | 오산역 도착 |

세션 시간이 더 필요한 경우(3시간 등) 출발을 앞당기거나 귀가를 늦추면 됩니다. 예약 시 세션 길이를 미리 상담하세요.

---

## 스튜디오 놀 소개

스튜디오 놀은 서울 은평구 연신내역 도보 5분 거리에 위치한 전문 음악 레코딩 스튜디오입니다. 동명여고 정문 바로 옆 건물 3층에 위치해 있어 찾기 쉽습니다. (건물 1층에 카센터가 있습니다.)

### 주요 장비

- **메인 마이크**: Neumann U87AI 콘덴서 마이크 (방송·음반사 표준 장비)
- **아날로그 프로세싱**: 따뜻하고 감칠맛 있는 아날로그 사운드
- **방음 부스**: 외부 소음 완전 차단, 드라이 보컬 녹음에 최적화된 환경

### 서비스 및 요금

| 서비스 | 요금 |
|--------|------|
| 합주실 대여 | 시간당 2만원 |
| 셀프 보컬 녹음 축가 패키지 | 15만원~ |
| 성우·오디오북 녹음 | 시간당 3만원 |
| 믹싱·마스터링 | 카카오톡 견적 문의 |
| 1:1 음악 레슨 | 월 35만원 정액 |

## 오산 뮤지션에게 스튜디오 놀을 추천하는 이유

**1. 가성비 높은 전문 장비**
Neumann U87AI는 국내 방송사와 메이저 음반사에서도 쓰는 표준 콘덴서 마이크입니다. 오산 인근에서는 접하기 어려운 전문 장비를 합리적인 요금으로 이용할 수 있습니다.

**2. 엔지니어 주도 세션**
10년 이상 경력의 엔지니어가 직접 세션을 이끕니다. 마이크 포지셔닝, 프리앰프 게인, 모니터 레벨까지 최적 세팅을 잡아주기 때문에 처음 녹음하는 분도 좋은 결과물을 낼 수 있습니다.

**3. 1호선 환승 한 번으로 연결**
오산역에서 1호선 → 서울역 → 6호선 연신내. 환승 한 번으로 당일 왕복이 가능한 현실적인 거리입니다. 오전 출발하면 오후에 귀가할 수 있습니다.

**4. 원스톱 음악 제작**
보컬 녹음 → 믹싱 → 마스터링 → 음원 유통 상담까지 한 곳에서 진행할 수 있습니다. 방문 한 번으로 전체 작업을 시작할 수 있어 지방에서 오는 분에게 효율적입니다.

**5. 온라인 파일 의뢰 가능**
방문하지 않아도 드라이 보컬 WAV 파일을 카카오톡으로 전송하면 믹싱·마스터링 후 납품합니다. 녹음만 스튜디오에서 하고 이후 믹싱은 온라인으로 진행하는 방식도 가능합니다.

## 방문 당일 체크리스트

- [ ] 녹음할 곡의 MR 파일 (WAV 또는 MP3) — USB나 스마트폰에 저장
- [ ] 예약 확인 (카카오톡)
- [ ] 세션 시작 30분 전 도착 (워밍업 권장)
- [ ] 도착 전 성대 워밍업 시작 (허밍, 립 트릴 등)
- [ ] 1호선 시간표 확인 (배차 간격 고려)

주차: 스튜디오 자체 주차 공간은 협소합니다. 인근 KT은평빌딩 주차장을 유료로 이용하거나 대중교통을 이용하세요.

## 예약 방법

카카오톡 채널 '스튜디오 놀'로 원하는 날짜와 서비스 종류를 알려주시면 빠르게 일정을 잡아드립니다. 오산에서 오시는 분은 이동 시간을 고려해 세션 시작 시간을 오전 10시 이후로 잡는 것을 권장합니다.

---

## 마치며

오산에서 1호선을 이용하면 약 1시간 30분이면 연신내입니다. 방문이 어려운 날에는 온라인 믹싱 의뢰로 동일한 품질의 결과물을 받을 수 있습니다. 카카오톡으로 예약 시간을 먼저 잡아두시면 도착 즉시 바로 세션에 들어갈 수 있습니다.
