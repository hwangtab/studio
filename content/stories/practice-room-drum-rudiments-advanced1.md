# 드럼 루디멘트 고급·스트로크 조합 — 음악연습실 완전 가이드

루디멘트(Rudiment)는 드럼 테크닉의 기초 단위입니다. NARD(National Association of Rudimental Drummers)가 정의한 40가지 루디멘트를 마스터하면 어떤 드럼 스타일에서도 필요한 기술을 자유롭게 구사할 수 있습니다. 이 가이드에서는 기초 루디멘트를 넘어 고급 조합과 응용을 안내합니다.

---

## 기초 루디멘트 복습

### 4가지 기본 스트로크

**풀 스트로크 (Full Stroke):**
- 높이 올렸다가 내려친 후 다시 높이 올라옴
- 강한 타격

**다운 스트로크 (Down Stroke):**
- 높이 올렸다가 내려친 후 낮은 위치에 멈춤
- 강한 타격 후 다음 음이 약함

**업 스트로크 (Up Stroke):**
- 낮은 위치에서 올려치며 높은 위치로 이동
- 약한 타격 후 다음 음이 강함

**탭 스트로크 (Tap Stroke):**
- 낮은 위치에서 낮은 위치로
- 약한 타격

## 고급 루디멘트

### 패러디들(Paradiddle) 패밀리

**기본 패러디들:**
```
R L R R L R L L
1 + 2 + 3 + 4 +
```

**더블 패러디들:**
```
R L R L R R L R L R L L
```

**트리플 패러디들:**
```
R L R L R L R R L R L R L R L L
```

**패러디들-디들:**
```
R L R L R L R R L R L R L R L L
(패러디들 + 더블 스트로크)
```

### 루타마쿠(Ratamacue)

```
L L R L R (기본)
L L R L R L L R L R (더블)
```

드래그(Drag)를 포함한 복잡한 루디멘트

### 드래그(Drag)

```
L L R (약약강 패턴)
두 번의 약음 + 강한 스트로크
```

**드래그 패러디들:**
```
L L R L R R (드래그 + 패러디들)
```

### 플래밍(Flamming)

두 손이 거의 동시에 타격하지만 미세하게 시간 차이:

```
lR 또는 rL (소문자 = 그레이스 노트)
```

**플래밍 탭:**
```
rL l rL l (패턴)
```

## 루디멘트 드럼셋 적용

### 패러디들을 드럼셋에서

**패러디들 응용 필:**
```
R = 스네어
L = 하이탐
R = 미드탐
R = 플로어탐
```

패러디들 패턴을 탐탐에 분산시키면 화려한 필

### 루디멘트 그루브

기초 리듬에 루디멘트 삽입:

```
기본 8비트:
1  +  2  +  3  +  4  +
K  .  S  .  K  .  S  .

루디멘트 추가:
1  +  2  e+a  3  +  4  +
K  .  S  (RLRR)  K  .  S  .
       ↑패러디들 삽입
```

## 메트로놈 루디멘트 훈련법

### Slow-Fast-Slow 방법

1. BPM 40에서 완벽하게 (각 스트로크 의식)
2. BPM 80으로 증가 (느낌 유지)
3. BPM 120 시도
4. 다시 BPM 40에서 재확인 (완성도 체크)

### 모든 포지션에서 연습

루디멘트를 다양한 다이나믹으로:
- ppp에서: 가장 작게
- ff에서: 가장 크게
- 크레셴도/디미누엔도: 점진적 변화

---

## 음악연습실 루디멘트 루틴

### 45분 루틴

**1. 기본 스트로크 (10분)**
- 4가지 스트로크 교대 연습
- BPM 60 균등하게

**2. 패러디들 패밀리 (15분)**
- 기본 → 더블 → 트리플 패러디들
- BPM 70-100

**3. 드래그 + 플래밍 (10분)**
- 드래그 단독
- 플래밍 단독
- 조합

**4. 드럼셋 적용 (10분)**
- 패러디들 탐탐 필
- 플래밍 그루브

## 마무리

루디멘트는 드럼의 **알파벳**입니다. 알파벳을 완벽히 알아야 글을 쓸 수 있듯, 루디멘트를 완벽히 익혀야 음악적 드럼을 연주할 수 있습니다.
