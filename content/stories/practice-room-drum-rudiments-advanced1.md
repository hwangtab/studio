# 드럼 루디멘트 고급·스트로크 조합 — 음악연습실 완전 가이드

루디멘트(Rudiment)는 드럼 테크닉의 기초 단위입니다. NARD(National Association of Rudimental Drummers)가 정의한 40가지 루디멘트를 마스터하면 어떤 드럼 스타일에서도 필요한 기술을 자유롭게 구사할 수 있습니다. 이 가이드에서는 기초 루디멘트를 넘어 고급 조합과 응용을 안내합니다.

---

## 기초 루디멘트 복습

### 4가지 기본 스트로크

**풀 스트로크 (Full Stroke):**
- 높이 올렸다가 내려친 후 다시 높이 올라옴
- 강한 타격

**다운 스트로크 (Down Stroke):**
- 높이 올렸다가 내려친 후 낮은 위치에 멈춤
- 강한 타격 후 다음 음이 약함

**업 스트로크 (Up Stroke):**
- 낮은 위치에서 올려치며 높은 위치로 이동
- 약한 타격 후 다음 음이 강함

**탭 스트로크 (Tap Stroke):**
- 낮은 위치에서 낮은 위치로
- 약한 타격

---

## 고급 루디멘트

### 패러디들(Paradiddle) 패밀리

**기본 패러디들:**
```

R L R R L R L L
1 + 2 + 3 + 4 +
```

**더블 패러디들:**
```

R L R L R R L R L R L L

```

**트리플 패러디들:**
```

R L R L R L R R L R L R L R L L

```

**패러디들-디들:**
```

R L R L R L R R L R L R L R L L
(패러디들 + 더블 스트로크)

```

### 루타마쿠(Ratamacue)

```

L L R L R (기본)
L L R L R L L R L R (더블)

```

드래그(Drag)를 포함한 복잡한 루디멘트

### 드래그(Drag)

```

L L R (약약강 패턴)
두 번의 약음 + 강한 스트로크

```

**드래그 패러디들:**
```

L L R L R R (드래그 + 패러디들)

```

### 플래밍(Flamming)

두 손이 거의 동시에 타격하지만 미세하게 시간 차이:

```

lR 또는 rL (소문자 = 그레이스 노트)

```

**플래밍 탭:**
```

rL l rL l (패턴)

```

---

## 루디멘트 드럼셋 적용

### 패러디들을 드럼셋에서

**패러디들 응용 필:**
```

R = 스네어
L = 하이탐
R = 미드탐
R = 플로어탐

```

패러디들 패턴을 탐탐에 분산시키면 화려한 필

### 루디멘트 그루브

기초 리듬에 루디멘트 삽입:

```

기본 8비트:
1 +  2 +  3 +  4 +
K . S . K . S .

루디멘트 추가:
1 +  2 e+a 3  + 4  +
K . S (RLRR) K  . S  .
       ↑패러디들 삽입

```

---

## 메트로놈 루디멘트 훈련법

### Slow-Fast-Slow 방법

1. BPM 40에서 정확하게 (각 스트로크 의식)
2. BPM 80으로 증가 (느낌 유지)
3. BPM 120 시도
4. 다시 BPM 40에서 재확인 (완성도 체크)

### 모든 포지션에서 연습

루디멘트를 다양한 다이나믹으로:
- ppp에서: 가장 작게
- ff에서: 가장 크게
- 크레셴도/디미누엔도: 점진적 변화

---

## 음악연습실 루디멘트 루틴

### 45분 루틴

**1. 기본 스트로크 (10분)**
- 4가지 스트로크 교대 연습
- BPM 60 균등하게

**2. 패러디들 패밀리 (15분)**
- 기본 → 더블 → 트리플 패러디들
- BPM 70-100

**3. 드래그 + 플래밍 (10분)**
- 드래그 단독
- 플래밍 단독
- 조합

**4. 드럼셋 적용 (10분)**
- 패러디들 탐탐 필
- 플래밍 그루브

## 마무리

루디멘트는 드럼의 **알파벳**입니다. 알파벳을 완벽히 알아야 글을 쓸 수 있듯, 루디멘트를 완벽히 익혀야 음악적 드럼을 연주할 수 있습니다.

은평구 24시간 음악연습실에서 매일 15분이라도 루디멘트 패드 연습에 할당하세요. 1년 후 손의 컨트롤이 완전히 달라집니다.

## 고급 루디먼트는 패드 위 연습을 키트 전체로 옮기는 겁니다

루디먼트를 패드 위에서 아무리 잘 쳐도, 그 자체로는 음악이 아니에요. 고급 단계의 핵심은 이 스트로크 조합을 드럼 세트 전체에 흩뿌리는(오케스트레이션) 겁니다. 예를 들어 패드에서 단조롭던 패러디들(RLRR LRLL)도, 오른손은 하이햇, 왼손은 스네어, 강세는 톰으로 나눠 치면 순식간에 멋진 필인이나 그루브가 돼요. 같은 루디먼트가 어디에 배치되느냐에 따라 완전히 다른 음악이 되는 거죠. 그래서 고급 루디먼트 연습은 "이 패턴을 키트의 어디에 나눠 칠까"를 실험하는 과정입니다. PAS 26개 표준 루디먼트를 하나씩, 각각을 키트 여기저기에 배치해 보세요.

물론 그 전에 패드에서 손 컨트롤을 확실히 잡아야 합니다. 풀 키트로 바로 하면 서툰 컨트롤이 드럼 음색에 가려 안 보이거든요. 패드에서 30분 다진 뒤 키트로 옮기는 순서를 지키세요.

한 번에 한두 개씩, 패드에서 완성한 뒤 키트로 펼치는 이 반복이 결국 화려한 필인과 그루브의 원천이 됩니다. 기초 루디먼트 체계는 [드럼 루디먼트](/stories/practice-room-drum-rudiments1)에서 다뤘습니다.

**3. BPM 60부터 — 정확성 우선**

빠르기로 시작하면 손 컨트롤이 무너집니다. BPM 60에서 자동화 후 BPM을 올립니다.

---

드럼 연습실에서는 어쿠스틱 드럼을 충분한 볼륨으로 연주할 수 있어 다이나믹 조절 훈련에 최적입니다. 피아니시모부터 포르테까지 다양한 강도로 같은 패턴을 연주하는 훈련은 표현력 향상에 직접적으로 연결됩니다. 필인 타이밍을 곡의 섹션 전환에 맞게 배치하는 감각을 키우면 밴드 연주에서 곡의 구조를 이끄는 역할을 자신 있게 수행할 수 있습니다. 다양한 리듬 패턴을 한 박자씩 분해해 연습하는 방식이 복잡한 그루브를 익히는 데 효율적입니다. 음악을 배우는 과정에서 이론과 실기를 함께 발전시키는 것이 이상적입니다. 화성학 기초를 이해하면 코드 진행을 귀로 파악하는 능력이 향상되고, 즉흥 연주나 작곡의 기반이 됩니다. 악보를 보고 연주하는 초견 능력은 꾸준히 새로운 악보를 접하는 훈련으로만 향상됩니다. 함께 연주할 동료를 찾아 앙상블 경험을 쌓는 것도 개인 연습에서는 얻기 어려운 실전 감각을 키워주는 중요한 방법입니다.
