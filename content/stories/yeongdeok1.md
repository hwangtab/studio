## 영덕에서 KTX로 서울까지

영덕은 경북 동해안 도시로, 포항역 KTX를 통해 서울까지 약 3시간 30분~4시간이 소요됩니다. 대게로 유명한 영덕에서 오전 일찍 출발하면 당일 서울 스튜디오 방문이 가능합니다.

---

## 영덕 → 연신내 이동 경로

### KTX 포항역 경유 (권장)

```
① 영덕 → 포항역 (버스 약 1시간)
② 포항역 KTX/SRT 탑승 (서울(수서역) 방면, 약 2시간 10분~2시간 30분)
③ 수서역 → 지하철 → 연신내역 (약 50분~1시간)

총 소요시간: 약 4시간~4시간 30분
```

---

## 당일 왕복 일정 예시 (영덕 기준)

```
오전 6시 영덕 출발 → 포항역 이동
오전 7시 포항역 KTX/SRT 출발
→ 오전 9시 20분 수서역 도착
→ 오전 10시 20분 연신내역 도착
→ 오전 11시 세션 시작 (2시간)
→ 오후 1시 세션 완료
→ 오후 2시 수서역 출발
→ 오후 4시 20분 포항역 도착
→ 오후 5시 20분 영덕 도착
```

---

## 온라인 파일 의뢰 서비스

```
영덕 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
