## 양양에서 KTX 강릉역 경유 서울까지

강원도 양양은 KTX 강릉선을 통해 서울과 약 3시간으로 연결됩니다. 낙산사·서피비치·낙산해수욕장으로 유명한 양양에서 서울 연신내 스튜디오 놀까지 당일 왕복이 가능합니다.

---

## 양양 → 연신내 이동 경로

### KTX 강릉역 경유 (권장)

```
① 양양버스터미널 → 강릉역 버스 (약 40~50분)
② 강릉역 KTX 서울 방면 탑승
③ 서울역 하차 (약 2시간)
④ 지하철 6호선 경유 연신내역 (약 25분)

총 소요시간: 약 3시간~3시간 15분
```

---

## 당일 왕복 일정 예시 (양양 기준)

```
오전 7시 양양 출발 → 강릉역
오전 8시 KTX 탑승 (강릉역)
→ 오전 10시 서울역 도착
→ 오전 10시 30분 연신내역
→ 오전 11시 세션 시작 (2~3시간)
→ 오후 2시 세션 완료
→ 오후 4시 서울역 출발 KTX
→ 오후 6시 강릉역 도착
→ 오후 6시 50분 양양 도착
```

---

## 온라인 파일 의뢰 서비스

```
현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
