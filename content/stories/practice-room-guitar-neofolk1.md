# 네오포크 기타·Bon Iver·Iron and Wine·핑거피킹 스타일 — 음악연습실 완전 가이드

네오포크 기타(Neofolk Guitar)는 **전통 포크 음악의 자연스러운 어쿠스틱 사운드에 현대적 감성과 실험적 요소를 더한 기타 스타일**입니다. Bon Iver의 오픈 튜닝 아르페지오, Iron and Wine의 섬세한 핑거피킹, Fleet Foxes의 화음 풍부한 포크 기타 — 네오포크는 어쿠스틱 기타의 가장 서정적인 현대 형태입니다.

---

## 네오포크란?

### 현대 포크의 재탄생

**네오포크의 특징:**
```
어쿠스틱 기타 중심 (클린 자연음)
서정적 보컬 + 감성적 가사
실험적 편곡 (오케스트라·전자음 믹스)
자연·고독·내면의 주제
```

**네오포크 아티스트:**
```
Bon Iver: "For Emma, Forever Ago" — 오두막에서 혼자 녹음
Iron and Wine: 속삭이는 포크의 대가
Fleet Foxes: 하모니 풍부한 포크
Sufjan Stevens: 오케스트라 포크
```

## Bon Iver 스타일

### 오픈 튜닝의 마법

Justin Vernon (Bon Iver):
- **특이한 오픈 튜닝:** 표준 튜닝이 아닌 독자적 튜닝
- **팔세토 보컬 + 기타:** 몽환적인 레이어
- **오두막 녹음:** 날것의 자연스러운 사운드

**Bon Iver 오픈 튜닝 예:**
```
"Skinny Love": Eb-Bb-Eb-Gb-Bb-Eb
(표준보다 낮은 독특한 오픈 튜닝)
= 표준 코드 포지션이 새로운 화음
```

**오픈 튜닝의 장점:**
```
열린 현으로 풍부한 드론음
간단한 손 포지션으로 복잡한 화음
= 독특하고 서정적인 기타 사운드
```

## Iron and Wine 스타일

### 속삭이는 핑거피킹

Sam Beam (Iron and Wine):
- **섬세한 핑거피킹:** 매우 가볍고 조용한 터치
- **트레블리 기타 톤:** 넥 픽업보다 브릿지 쪽
- **시적 가사:** 사진 같은 이미지의 노래

**Iron and Wine 핑거피킹 패턴:**
```
엄지(p): 베이스 현 (E, A, D)
검지(i): G 현
중지(m): B 현
약지(a): e 현
= 고전 핑거피킹 PIMA 방식
```

**"The Creek Drank the Cradle" 스타일:**
```
Am-C-G-F 진행
속삭이는 핑거피킹 + 속삭이는 보컬
= 자연 속의 고독한 아름다움
```

## Fleet Foxes 스타일

### 하모니 풍부한 포크

Fleet Foxes:
- **다성부 화음:** 5~6성부 하모니
- **중세·르네상스 영향:** 고풍스러운 음악
- **포크 기타 + 하모니:** 기타가 화성 기반 제공

**Fleet Foxes 코드 진행:**
```
C-Am-F-G (I-vi-IV-V 기본)
또는 Am-G-D-Am (단조 포크)
= 단순하지만 고풍스러운 화성
```

**풍성한 코드 사용:**
```
Fmaj7, Cmaj9, G6 등
= 7도·9도 추가로 포크 색채 풍부하게
```

## 네오포크 핑거피킹 기법

### 자연스러운 어쿠스틱

**핑거피킹 기초:**
```
오른손 엄지: 4~6번 현 (베이스)
검지·중지·약지: 1~3번 현 (멜로디·화성)
= 베이스와 멜로디 동시에
```

**알테르나팅 베이스:**
```
1박: 루트 음 (엄지)
2박: 멜로디 현 (손가락)
3박: 5도 음 (엄지)
4박: 멜로디 현 (손가락)
= 베이스가 교대로 왔다 갔다
```

**아르페지오 패턴:**
```
E 현 → A 현 → D 현 → G 현 → B 현 → e 현 (상행)
= 깨끗하고 맑은 아르페지오
```

## 오픈 튜닝 탐험

### 새로운 음색 찾기

**DADGAD 튜닝:**
```
E→D, A→A, D→D, G→G, B→A, e→D
= 켈틱·중동 음악 느낌
드론음이 풍부한 포크 사운드
```

**오픈 G (DGDGBD):**
```
6번 현→D, 모든 현 G 코드
= 바레 없이 G 코드 스트럼
슬라이드 기타에도 유용
```

**오픈 D (DADF#AD):**
```
D 코드 오픈 튜닝
= 블루스·슬라이드 기반이지만 포크에도
```

## 음악연습실 네오포크 기타 연습

### 60분 루틴

**1. 핑거피킹 기초 (15분)**
   - PIMA 손가락 배치 확인
   - C-G-Am-F 핑거피킹
   - 느리고 균일하게 (♩= 60)

**2. 알테르나팅 베이스 (15분)**
   - E 코드로 베이스 교대
   - 루트-5도 베이스 교대
   - 멜로디 현 동시에

**3. 오픈 튜닝 탐험 (15분)**
   - DADGAD로 재튜닝
   - 열린 현 아르페지오
   - 새로운 코드 발견

**4. 네오포크 즉흥 (15분)**
   - Am-C-G-F 위 핑거피킹 즉흥
   - 멜로디 추가
   - 서정적이고 자연스럽게
