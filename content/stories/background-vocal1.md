  - q: 혼자서도 코러스를 만들 수 있나요?
    a: >-
      가능합니다. 같은 멜로디를 여러 번 녹음해 겹치는 '보컬 스태킹', 또는 3도·5도 위로 화음을 녹음하는 방법으로 혼자서도 풍성한
      코러스를 만들 수 있습니다.
  - q: 백 보컬 녹음 시 주요 포지션(1도·3도·5도)이란 무엇인가요?
    a: >-
      1도는 메인 보컬과 같은 음높이(유니슨), 3도는 3음 위의 화음, 5도는 5음 위의 화음입니다. 팝·K팝에서는 메인 멜로디를
      유니슨으로 한 번 더 쌓고, 3도 화음을 추가하는 것이 일반적입니다.
  - q: 백 보컬이 메인 보컬보다 커지면 어떻게 되나요?
    a: >-
      메인 보컬의 명확성이 떨어지고 음악이 산만해질 수 있습니다. 백 보컬 레벨은 메인 보컬보다 보통 -3dB~-9dB 낮게 설정해 지원
      역할을 유지하도록 합니다.

## 백 보컬이 음반을 풍성하게 만드는 이유

백 보컬은 음악의 두께감, 공간감, 감정적 깊이를 더합니다. 메인 보컬 하나만 있는 음악과 코러스가 더해진 음악의 감동 차이는 처음 들을 때부터 느껴집니다.

---

## 백 보컬 종류

| 종류 | 설명 | 주요 활용 |
|------|------|---------|
| 유니슨 더블링 | 같은 음정으로 한 번 더 녹음 | 메인 보컬 두께 강화 |
| 3도 화음 | 멜로디 3음 위로 화음 | 팝·K팝 코러스 |
| 5도 화음 | 멜로디 5음 위로 화음 | 클래식한 화음감 |
| 옥타브 화음 | 한 옥타브 위 또는 아래 | 다이나믹 대비 |
| 아멘 코러스 | 느린 화성 진행 코러스 | 가스펠·소울 |

## 보컬 스태킹(혼자 코러스 만들기)

세션 시작 전 파일 정리와 프로젝트 백업 습관이 데이터 손실을 막아줍니다.

### 단계

1. 메인 보컬 녹음 완료
2. 같은 파트를 한 번 더 녹음 (유니슨)
   - 완벽히 같으려 하지 않아도 됨
   - 자연스러운 차이가 음색 만듦
3. 3도 위 화음 녹음
   - 피아노로 화음 음정 확인 후 녹음
4. 믹스 배치
   - 메인: 센터 0%
   - 유니슨 더블: 좌우 -30/+30%
   - 화음: 좌우 -50/+50%

### 볼륨 설정

- **메인**: 0dB 기준
- **유니슨**: -3~-6dB
- **3도 화음**: -6~-9dB

## 여럿이 녹음하는 코러스 세션


### 2인 코러스

- A: 메인 멜로디 유니슨
- B: 3도 화음

### 3인 코러스

- A: 메인 멜로디
- B: 3도 화음
- C: 5도 화음 또는 베이스 라인

### 4인 이상 합창형

- 소프라노, 알토, 테너, 베이스 파트 분리
- 각 파트별 별도 녹음 후 믹스

## 백 보컬 믹싱 팁

기본값에서 출발해 한 번에 하나씩 조절하면 각 파라미터의 역할이 명확하게 들립니다.

- EQ: 메인 보컬이 차지하는 중음역(1~3kHz) 백 보컬에서 살짝 컷
  - 메인 보컬 명확성 유지

- 리버브: 백 보컬에 더 많은 리버브 적용
  - 공간감, 배경으로 자연스럽게 후퇴

- 자동화(automation): 서클러스 구간에서만 백 보컬 올리기
  - 버스 구간과의 대비 강화

- 볼륨: 백 보컬은 메인보다 항상 낮게 유지
  - 메인 보컬이 항상 앞에 있어야 함

### 코러스·백킹 보컬 체크리스트

**파트 준비**
- [ ] 하모니 파트 (3도·5도·6도 위) 정확하게 파악
- [ ] 메인 보컬보다 살짝 낮은 다이나믹으로 세팅
- [ ] 가사 발음이 메인 보컬과 정확히 맞는가?

**믹싱**
- [ ] 백킹 보컬 -6 ~ -12dB 낮게 시작
- [ ] 리버브 활용으로 공간감과 블렌딩
- [ ] EQ: 200Hz 이하 롤오프 (저역 메인에게 양보)

### 백킹 보컬 레이어 구성 예시

| 레이어 | 음정 | 패닝 | 볼륨 |
|-------|------|------|------|

| 2 (더블) | 유니즌 | ±20% | -4dB |
| 3 (상3도) | 3도 위 | ±40% | -8dB |
