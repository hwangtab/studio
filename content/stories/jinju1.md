## 진주에서 서울까지

진주는 KTX 정차역이 없어 창원 환승 또는 고속버스를 이용합니다. 전문 보컬 녹음과 음반 제작을 위해 연신내 스튜디오 놀을 이용할 수 있습니다.

---

## 진주 → 연신내 이동 경로

### 고속버스 경로 (권장)

주차 공간은 제한적이므로 대중교통 이용을 권장합니다.

1. 진주 고속버스터미널 출발
2. 서울 강남터미널 도착 (약 2시간 40분~3시간)
3. 3호선 고속터미널역 → 충무로 → 환승 → 연신내역

- **총 소요시간**: 약 3시간 10~40분

### 창원 환승 KTX 경로

1. 진주터미널 → 창원중앙역 (버스 약 30~40분)
2. 창원중앙역에서 KTX 탑승 (서울역 방면, 약 2시간 30~40분)
3. 서울역 → 연신내역 (약 30~40분)

- **총 소요시간**: 약 3시간 40분~4시간

## 당일 왕복 일정 예시 (진주 기준)

야간 녹음 세션 이용 시 막차 시간을 미리 확인해두시기 바랍니다.

오전 6시 30분 진주터미널 출발 (고속버스)
- 오전 9시 10분 강남터미널 도착
- 오전 9시 50분 연신내역 도착
- 오전 10시 세션 시작 (2시간)
- 오후 12시 세션 완료
- 오후 2시 30분 강남터미널 출발 (고속버스)
- 오후 5시 10분 진주터미널 도착

## 진주 음악 씬과 서울 스튜디오

진주는 개천예술제, 진주남강유등축제 등 문화 전통이 강한 도시입니다. 경상국립대·진주교대 등이 있으며 지역 문화재단의 음악 지원 사업도 활발합니다. KTX 진주역(경전선)으로 서울까지 약 2시간 40분 소요됩니다.

## 방문 전 세션 준비 가이드

1시간 30분 이상 이동 후 최상의 컨디션으로 세션에 임하려면 철저한 사전 준비가 필요합니다.

**출발 전 챙길 것:**
- [ ] 녹음할 곡의 가사·악보·MR 파일 (USB 또는 Google Drive)
- [ ] 원하는 사운드의 레퍼런스 트랙 2~3곡
- [ ] 예약 확인 캡처 + 교통편 티켓
- [ ] 보컬: 따뜻한 차·꿀물 보온병, 간식
- [ ] 귀마개 또는 노이즈캔슬링 이어폰 (이동 중 성대 보호)

**이동 중 활용법:**
- 이어폰으로 녹음할 곡 2~3회 예습
- 가사·감정 포인트 집중 정리
- 목·어깨 스트레칭 (장시간 이동 피로 완화)
- 충분한 수분 섭취 (기차 이동 중 성대 건조 방지)

**세션 팁:**
- 도착 후 20~30분 워밍업 시간 확보 (일정 계획 시 반드시 포함)
- 가장 중요한 구간을 세션 초반(이동 피로 전)에 먼저 녹음
- 원하는 사운드를 레퍼런스 곡으로 구체적으로 설명
- 온라인 파일 의뢰 서비스 병행 시 재방문 부담 최소화 가능

## 세션 당일 체크리스트

**전날:**
- [ ] MR·가사·레퍼런스 트랙 파일 최종 확인
- [ ] 교통편 티켓 + 예약 확인 캡처
- [ ] 충분한 수면 + 성대 무리 금지

**출발 전:**
- [ ] 따뜻한 차·꿀물 지참
- [ ] 이동 중 성대 보호 (소리 지르기 금지, 수분 섭취)

**도착 후:**
- [ ] 20~30분 워밍업 확보 (일정에 미리 포함)
- [ ] 엔지니어에게 레퍼런스·사운드 방향 설명
- [ ] 가장 어려운 구간 최우선 녹음

**녹음 중:**
- [ ] 헤드폰 볼륨 확인
- [ ] 테이크마다 즉시 청취
- [ ] 막차 시간 미리 확인 (귀가 일정)

## 마치며

진주에서 고속버스로 3시간이면 서울 연신내. 이동이 부담스럽다면 온라인 파일 의뢰를 추천합니다. 현지에서 드라이 보컬 WAV만 녹음해 보내주시면 믹싱·마스터링 후 납품합니다.
