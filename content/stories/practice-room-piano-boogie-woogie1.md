# 피아노 부기우기·블루스 피아노 기초 — 음악연습실 완전 가이드

부기우기 피아노는 1920-30년대 미국 블루스에서 탄생한 **폭발적인 에너지의 피아노 스타일**입니다. 왼손이 만들어내는 끊임없는 베이스 패턴과 오른손의 날카로운 블루스 리프—이 두 요소가 만나 누구나 몸을 흔들고 싶게 만드는 그루브가 됩니다.

---

## 부기우기의 핵심: 왼손 베이스 패턴

### 기본 "웨킹 베이스" 패턴

부기우기의 왼손은 **쉬지 않고 움직이는 베이스**를 담당합니다.

**C 장조 기본 패턴 (8분음표):**
```
C - G - A - G - C - G - A - G
(1  2   3   4   5   6   7   8)
```

**실제 음표:**
```
C3-G3-A3-G3-C3-G3-A3-G3
```

이것이 1마디 왼손 패턴입니다. 끊임없이 반복되며 전체 곡의 그루브를 만듭니다.

### 쉐이크 베이스 패턴

**더 역동적인 "쉐이크" 패턴:**
```
C3 - E3 - G3 - A3 - Bb3 - A3 - G3 - E3
```

이 상행-하행 패턴이 전형적인 부기우기 왼손입니다.

### 블루스 코드 진행 (12마디)

부기우기는 **12마디 블루스 진행**을 기반으로 합니다.

```
I  - I  - I  - I    (1-4마디: C7)
IV - IV - I  - I    (5-8마디: F7-C7)
V  - IV - I  - V    (9-12마디: G7-F7-C7-G7)
```

---

## 오른손 블루스 리프

### 블루스 스케일 활용

부기우기 오른손은 **블루스 스케일**을 기반으로 합니다.

**C 블루스 스케일:**
```
C - Eb - F - F# - G - Bb - C
```

**기본 오른손 패턴:**
```
C5 - Eb5 - E5 - G5 - Bb5 (상행)
Bb5 - G5 - E5 - Eb5 - C5 (하행)
```

### 트리플렛 리프

부기우기에서 자주 사용되는 **3련음표(Triplet) 리프:**

```
C-E-G (한 박에 3개) × 반복
또는
G-E-C (하행 트리플렛)
```

### 옥타브 플레이

강렬한 효과를 위한 **옥타브 리프:**
```
C4-C5 (옥타브)를 반복하며 상행
C4-C5 → D4-D5 → E4-E5
```

## 기본 부기우기 곡 구조

### 양손 결합 첫 단계

처음 배울 때는 단계적으로 접근합니다.

**1단계: 왼손만 (5분)**
- C 장조 쉐이크 베이스 패턴 반복
- BPM 80에서 안정적으로 연주

**2단계: 오른손만 (5분)**
- 블루스 스케일 상행/하행
- 트리플렛 리프 연습

**3단계: 양손 합치기 (10분)**
- 왼손 패턴 먼저 안정시키고
- 오른손을 서서히 추가
- 처음에는 BPM 60으로 시작

### 기본 부기우기 패턴 (C 장조)

```
왼손: C-E-G-A-Bb-A-G-E (반복)
오른손: C5-Eb5-E5-G5 (2박에 맞춰)
```

## 대표 부기우기 스타일 분석

### 제리 리 루이스 스타일

**"Great Balls of Fire"**, **"Whole Lotta Shakin' Goin' On"** - 로큰롤 피아노의 교과서.

**특징:**
- 공격적인 오른손 리프
- 빠른 템포 (BPM 160+)
- 글리산도 (건반을 손가락으로 쭉 긁기) 활용
- 강력한 왼손 베이스

**글리산도 연습:**
- 검지 손등으로 건반을 빠르게 위에서 아래로 또는 아래에서 위로 쓸기
- 처음에는 천천히, 건반 끝을 부드럽게

### 패츠 도미노 스타일

**"Blueberry Hill"**, **"Ain't That a Shame"** - 부드러운 뉴올리언스 스타일.

**특징:**
- 라이드백된 템포 (BPM 110-130)
- 더 멜로딕한 오른손
- 싱코페이션된 리프
- 뉴올리언스 R&B 그루브

### 루이 조던 스타일

점프 블루스의 대가. 더 스윙이 강한 스타일.

**특징:**
- 재즈와 블루스의 결합
- 스윙 8분음표 사용
- 음악이 "점프"하는 느낌

## 부기우기 즉흥 연주

### 블루스 콜 앤 리스폰스

오른손이 **질문(콜)**을 하면 왼손이 **답변(리스폰스)**을 하는 구조.

```
오른손 콜 (1-2박): G5-E5-C5 (하행)
오른손 리스폰스 (3-4박): C5-E5-G5 (상행)
```

### 12마디 즉흥 구조

12마디 블루스 위에서 즉흥:
- **1-4마디**: 주제 제시 (C7)
- **5-6마디**: 발전 (F7)
- **7-8마디**: 주제 반복 (C7)
- **9마디**: 클라이맥스 (G7)
- **10마디**: 해결 (F7)
- **11-12마디**: 마무리 + 턴어라운드 (C7-G7)

## 음악연습실 부기우기 연습 루틴

### 초급 45분 루틴

**1. 왼손 워밍업 (10분)**
- C 장조 쉐이크 베이스 패턴 × 100회
- F 장조로 이동, G 장조로 이동

**2. 오른손 블루스 스케일 (10분)**
- C 블루스 스케일 상행/하행 × 20회
- 트리플렛 리프 연습

**3. 양손 합치기 (15분)**
- BPM 70부터 시작
- 안정되면 BPM 10씩 올리기

**4. 곡 적용 (10분)**
- "Great Balls of Fire" 간단 버전 연습
