# 보사노바 기타·삼바 리듬·João Gilberto 스타일 — 음악연습실 완전 가이드

보사노바(Bossa Nova)는 **삼바 리듬과 쿨 재즈가 만나 탄생한 브라질 음악**입니다. João Gilberto가 기타 하나로 노래하는 방식 — 조용하고 섬세하게, 리듬과 코드와 멜로디를 동시에 — 이것이 보사노바 기타의 혁명이었습니다. Tom Jobim의 화성과 João의 기타 리듬이 "Girl from Ipanema", "Garota de Ipanema"를 만들었습니다.

---

## 보사노바란?

### 역사와 기원

**보사노바의 탄생 (1950년대 후반):**
```
장소: 브라질 리우 데 자네이루, 이파네마 해변
João Gilberto: 기타·보컬 혁신
Tom Jobim: 작곡·편곡
= 삼바 + 쿨 재즈 = 보사노바
```

**보사노바의 특징:**
```
조용하고 친밀한 음악 (삼바보다 훨씬 조용)
재즈 화성 (확장 코드)
싱코페이션 기타 리듬
포르투갈어 가사 + 재즈적 보컬
```

### 보사노바 vs 삼바

| | 삼바 | 보사노바 |
|--|-----|--------|
| 에너지 | 강렬·열정적 | 조용·섬세 |
| 리듬 | 강한 타악기 | 기타 단독 리듬 |
| 화성 | 단순 | 재즈 확장 코드 |
| 편성 | 대규모 | 기타·보컬 듀오 |

## João Gilberto 기타 리듬

### 보사노바의 핵심 리듬 패턴

**기본 보사노바 리듬:**
```
4/4박자로 카운트:
박 1: 썸으로 베이스 음
박 1의 "+"': 손가락 업스트로크
박 2: 손가락 다운스트로크
박 2의 "a": 손가락 업스트로크
박 3: 썸 베이스
박 3의 "+": 업스트로크
박 4: 다운스트로크
박 4의 "a": 업스트로크
```

**간략 표기:**
```
D = 다운 스트로크 (현 아래로)
U = 업 스트로크 (현 위로)
B = 베이스 (엄지 단음)

B-U-D-U-B-U-D-U (기본 8음 패턴)
```

### 실제 João Gilberto 패턴

**"Girl from Ipanema" 리듬:**
```
박1: B(베이스) + DU (스트로크)
박2: DU
박3: B + DU  
박4: DU
= 베이스가 1·3박에, 스트로크가 사이사이
```

**리듬 싱코페이션:**
```
보사노바의 느낌: 박자가 살짝 앞당겨짐
= 삼바의 싱코페이션을 조용하게
```

## Tom Jobim 화성

### 보사노바 코드 언어

Tom Jobim의 화성 특징:
- **Major7 코드:** 부드럽고 꿈같은
- **Minor7 코드:** 달콤한 슬픔
- **Major7#11 (리디안):** 신비롭고 빛나는
- **Dominant 9:** 달콤한 긴장

**"Girl from Ipanema" 코드:**
```
Fmaj7 - G7 - Gm7 - Gb7
Fmaj7 - Gb7 - B7 - Gbmaj7...
= 반음씩 이동하는 특유의 진행
```

### 보사노바 필수 코드 형태

**Fmaj7 (보사노바 클래식):**
```
X-8-10-9-10-8 (바레)
또는 X-X-3-2-1-0
```

**Dm7 (보사노바 스타일):**
```
X-X-0-2-1-1 (오픈 포지션)
```

**Bbmaj7:**
```
X-1-3-2-3-1 (바레)
```

## 오른손 기법

### 엄지·손가락 분리

**오른손 세팅:**
```
엄지(p): 4-6번 줄 (베이스 라인)
검지(i): 3번 줄
중지(m): 2번 줄
약지(a): 1번 줄
```

**베이스+코드 동시 연주:**
```
엄지: 루트 베이스 음 (단음)
손가락들: 위 3개 줄 스트로크
= 기타 혼자서 베이스 + 코드 역할
```

### 라이트 터치

**보사노바 터치의 특징:**
```
매우 가벼운 터치 (부드럽게)
클런킹 없이 깨끗한 코드
조용한 다이나믹 (pp~mp)
= 친밀하고 내밀한 소리
```

## 보사노바 코드 진행

### 기본 진행

**I - IV - ii - V (보사노바 버전):**
```
Cmaj7 - Fmaj7 - Dm7 - G7
(클래식 진행을 확장 코드로)
```

**보사노바의 특이한 진행:**
```
반음 아래 도미넌트:
Fmaj7 - E7(→ Am7)
= 반음 아래서 도미넌트 접근
```

### "Garota de Ipanema" 진행

```
F - G7 - Gm7 - Gb7
F - Gb7 - B7(트리톤) - Gbmaj7 - B7
Gb7 - Cbmaj7 - D7 - Gm7 - Eb7
Am7 - D7 - Gm7 - Eb7 - Am7 - D7
Gm7 - C7 - Fmaj7
```

## 음악연습실 보사노바 기타 연습

### 60분 루틴

**1. 리듬 패턴 (15분)**
   - B-D-U 기본 패턴 (단일 코드에서)
   - Cmaj7 코드로 8분 반복
   - 메트로놈 (♩= 80~100)

**2. 보사노바 코드 전환 (15분)**
   - Cmaj7 - Fmaj7 전환
   - Dm7 - G7 전환
   - 리듬 유지하면서 코드 변환

**3. "Girl from Ipanema" 입문 (20분)**
   - 앞 8마디 코드 진행
   - 리듬 + 코드 동시
   - 보컬 없이 기타만으로 노래처럼

**4. 자유 보사노바 컴핑 (10분)**
   - ii-V-I 보사노바 리듬으로
   - 다양한 코드 전위형 시도
   - 음반 들으며 리듬 느낌 비교
