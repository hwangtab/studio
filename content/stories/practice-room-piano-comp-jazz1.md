# 재즈 피아노 컴핑·밴드 앙상블·Red Garland 스타일 — 음악연습실 완전 가이드

재즈 피아노 컴핑(Comping)은 **반주하면서 동시에 즉흥적으로 대화하는 기술**입니다. 독주 피아노와 달리, 밴드 안의 피아노는 솔로이스트를 지지하고, 드러머와 대화하고, 베이시스트의 워킹 라인에 화답합니다. Red Garland, Wynton Kelly, Herbie Hancock이 밴드 컴핑의 예술을 극한까지 끌어올렸습니다.

---

## 컴핑이란?

### 컴핑의 역할

**컴핑(Comping = Accompanying):**
```
솔로이스트 지지 (화성 제공)
리듬 드라이브 (그루브 기여)
대화 (솔로와 교감)
공간 남기기 (솔로가 숨 쉬도록)
```

**컴핑 = 대화:**
```
솔로이스트가 긴 구절 → 피아노 공간 줌
솔로이스트가 멈추면 → 피아노가 반응
= 테니스처럼 주고받기
```

---

## Red Garland 스타일

### Miles Davis 퀸텟의 피아노

Red Garland(Miles Davis 퀸텟 1955-58):
- **블록 코드:** 두꺼운 밀집 보이싱으로 강한 스윙
- **스윙감:** 재즈 스윙의 교과서
- **단순함의 파워:** 복잡한 화성보다 타이밍

**Garland 블록 코드 컴핑:**
```
ii-V-I 위 블록 코드:
Dm7: 풀 Dm7 보이싱 (왼손+오른손)
G7: G7 블록 코드
Cmaj7: Cmaj7 블록 코드
= 굵직하고 스윙하는 컴핑
```

**Garland 리듬 컴핑:**
```
대부분 2박·4박에 집중
가끔 1·3박 어택
= 예측 가능하지만 스윙하는 리듬
```

---

## Wynton Kelly 스타일

### Miles Davis의 두 번째 피아니스트

Wynton Kelly(Miles Davis 퀸텟 1959-63, "Kind of Blue"):
- **블루스 감성:** 가스펠·블루스의 온기
- **경제적 보이싱:** 필요한 음만
- **솔로이스트와 완벽한 호흡**

**Kelly 블루스 컴핑:**
```
Blues feel: 블루 노트 보이싱 포함
왼손: 5도 + 비트
오른손: 7th 또는 확장 코드 싱코페이션
= 따뜻하고 블루스적인 컴핑
```

---

## 컴핑 리듬 패턴

### 기본 컴핑 리듬

**2박·4박 컴핑:**
```
4/4박자:
박 2·4에 코드 어택
= 스네어 드럼처럼 강박 강조
```

**싱코페이션 컴핑:**
```
박 2의 "a", 박 4의 "e"에 코드
= 오프비트 강조로 더 스윙감
```

**랜덤 컴핑:**
```
고급 기법: 어느 위치에서든 자유롭게
솔로이스트의 리듬에 반응
= 대화하는 컴핑
```

---

## 왼손 vs 오른손 역할

### 왼손 컴핑

**재즈 왼손 기본:**
```
루트 + 7도 보이싱 (2음)
또는 루트 + 3도 + 7도 (3음)
= 화성 기반 제공
```

**왼손 Stride (1930s 스타일):**
```
낮은 음 → 높은 코드 → 낮은 음 → 높은 코드
(스트라이드 피아노)
= 독립적 왼손 컴핑
```

### 오른손 컴핑

**오른손 역할:**
```
상위 보이싱 (3도·7도 중심)
싱코페이션 리듬
솔로와 대화하는 반응
```

**2음 오른손 보이싱:**
```
G7: B-F (3도+7도)
= 간결하면서 화성 명확
```

## 밴드 앙상블 컴핑

### 드러머와 협력

**피아노-드럼 대화:**
```
드러머 필인 → 피아노 공간 줌
드러머 4박자 스윙 → 피아노 싱코페이션
= 서로 보완·대화
```

**드럼 레이어링:**
```
드럼: 2·4박 스네어
피아노: 2·4박 사이에 코드
= 드럼과 엇갈리는 피아노
```

### 베이시스트와 협력

**워킹 베이스 + 피아노:**
```
베이시스트가 루트 담당
→ 피아노 왼손은 루트 필요 없음!
왼손: 가이드 톤만 (3도·7도)
오른손: 상위 보이싱 컴핑
```

**조율 방법:**
```
피아노·베이스 사이 공간 유지
피아노가 너무 낮으면 → 베이스와 충돌
최적: 피아노 최저음을 중음역 이상으로
```

---

## 공간 만들기 (Leaving Space)

### 솔로이스트를 위한 공간

**컴핑의 핵심 원칙:**
```
적게 연주하는 것이 더 좋을 수 있다
솔로이스트가 말할 때 듣기
= 침묵도 컴핑이다
```

**Miles Davis의 요구:**
```
"Don't play so much" (너무 많이 치지 마라)
→ 피아니스트들에게 경고
공간이 음악을 숨 쉬게 한다
```

## 음악연습실 재즈 컴핑 연습

### 60분 루틴

**1. 기본 보이싱 복습 (10분)**
   - ii-V-I 가이드 톤 보이싱
   - 왼손 루트+7도 / 오른손 3도+9도
   - 모든 12키로 전조

**2. 리듬 컴핑 패턴 (15분)**
   - 2박·4박 컴핑 (Red Garland 스타일)
   - 싱코페이션 컴핑 (오프비트)
   - 메트로놈과 함께

**3. 드럼·베이스 백킹과 함께 (25분)**
   - 백킹 트랙 위에 컴핑
   - 베이스 없을 때 vs 있을 때 차이
   - 공간 만들기 연습

**4. 솔로이스트 지원 연습 (10분)**
   - 자신의 오른손 솔로 + 왼손 컴핑
   - 또는 파트너와 솔로·컴핑 교환
   - 대화하는 컴핑 느낌

## 마무리

재즈 피아노 컴핑은 **함께 하는 음악의 정수**입니다. Red Garland가 "좋은 컴핑은 솔로이스트가 날아오르게 한다"고 했듯, 컴핑은 자신을 드러내지 않으면서 음악 전체를 끌어올립니다. 많이 치는 것보다 제대로 치는 것, 공간을 채우는 것보다 공간을 만드는 것 — 이것이 컴핑의 예술입니다.

은평구 24시간 음악연습실에서 2박·4박 가이드 톤 컴핑부터 시작하세요. 밴드와 함께 연주할 때 소리가 하나로 합쳐지는 순간, 컴핑의 기쁨을 알게 됩니다.
