## 춘천에서 ITX로 서울까지

춘천은 ITX-청춘 열차로 서울 청량리역과 연결됩니다. 강원도 북서부에서 전문 보컬 녹음과 음반 제작을 위해 연신내 스튜디오 놀을 이용할 수 있습니다.

---

## 춘천 → 연신내 이동 경로

### ITX-청춘 경로

```
① 춘천역에서 ITX-청춘 탑승 (청량리역 방면)
② 청량리역 도착 (약 1시간 30~40분)
③ 경의중앙선 청량리역 → 홍대입구역 → 2호선 합정역 → 6호선 연신내역

총 소요시간: 약 2시간 20분~3시간
```

### 버스 경로

```
① 춘천터미널 → 서울 동서울터미널 (버스 약 1시간 10~30분)
② 동서울터미널역 → 2호선 합정역 → 6호선 연신내역

총 소요시간: 약 2시간
```

## 당일 왕복 일정 예시 (춘천 기준)

```
오전 7시 30분 춘천역 출발 (ITX-청춘)
→ 오전 9시 10분 청량리역 도착
→ 오전 10시 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 30분 청량리역 출발 (ITX)
→ 오후 4시 10분 춘천역 도착
```
