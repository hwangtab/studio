## 영암에서 KTX로 서울까지

영암은 전남 서부에 위치한 도시로, 나주역 KTX를 통해 서울과 약 2시간 10~30분대로 연결됩니다. 전라남도 내 비교적 접근이 편리한 지역입니다.

---

## 영암 → 연신내 이동 경로

### KTX 나주역 경유 (권장)

```
① 영암 → 나주역 (버스 약 20~30분)
② 나주역 KTX 탑승 (서울역 방면, 약 1시간 40~50분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 2시간 30~40분
```

---

## 당일 왕복 일정 예시 (영암 기준)

```
오전 8시 영암 출발 → 나주역 이동
오전 8시 30분 나주역 KTX 출발
→ 오전 10시 20분 서울역 도착
→ 오전 11시 연신내역 도착
→ 오전 11시 30분 세션 시작 (2시간)
→ 오후 1시 30분 세션 완료
→ 오후 3시 서울역 출발
→ 오후 4시 50분 나주역 도착
→ 오후 5시 20분 영암 도착
```

---

온라인 파일 의뢰도 가능합니다. 현지에서 드라이 보컬 WAV를 녹음해 파일로 보내주시면 믹싱·마스터링 후 납품합니다. [자세한 안내](/stories/onlinemix1)
