faq:
  - q: PA 시스템이란 무엇인가요?
    a: >-
      PA(Public Address) 시스템은 마이크 → 믹서 → 앰프 → 스피커로 이어지는 공연 음향 증폭 시스템입니다. 보컬, 악기
      소리를 관객에게 전달하는 메인 스피커 시스템과 연주자가 자신의 소리를 듣기 위한 모니터 시스템으로 나뉩니다.
  - q: 사운드 체크는 어떻게 하나요?
    a: >-
      공연 전 30분~1시간 전에 진행합니다. 마이크 레벨 확인 → 모니터 볼륨 조정 → EQ 설정 → 전체 밸런스 확인 순서로
      진행합니다. 사운드 엔지니어에게 '모니터에 보컬 더 올려주세요', '베이스 좀 줄여주세요' 등 명확하게 요청하세요.
  - q: 인이어 모니터와 웨지 모니터의 차이는 무엇인가요?
    a: >-
      웨지(Wedge) 모니터는 무대 앞에 놓는 스피커이고, 인이어 모니터(IEM)는 귀에 꽂는 이어폰 형태입니다. 인이어는 소음 차단이
      좋고 일관된 사운드를 제공하지만 귀 건강 주의가 필요합니다. 소규모 공연에서는 웨지 모니터가 일반적입니다.
  - q: 마이크 피드백(하울링)은 왜 생기고 어떻게 막나요?
    a: >-
      마이크가 스피커 앞에 있을 때 소리가 마이크→스피커→마이크로 무한 루프되어 발생합니다. 마이크를 스피커 뒤에 위치시키고, 볼륨을 적정
      수준 이하로 유지하면 대부분 해결됩니다. 사운드 엔지니어가 EQ로 공진 주파수를 줄이기도 합니다.

## 라이브는 스튜디오와 다릅니다

라이브 공연에서 보컬리스트는 자신의 소리를 직접 제어할 수 없습니다. 사운드 엔지니어와 효과적으로 소통하고, 음향 시스템을 이해하는 것이 좋은 퍼포먼스의 기반입니다.

---

## 라이브 음향 신호 흐름

각 파라미터가 사운드에 미치는 영향을 이해하면 설정값을 외우지 않아도 귀로 판단할 수 있습니다.

마이크 → 믹서(콘솔) → 앰프 → 스피커

           ↓
      모니터 믹서
           ↓
      웨지 스피커 또는 인이어 모니터
      (연주자 자신이 듣는 소리)

---

## 모니터 시스템 종류 비교

| 종류 | 특징 | 장점 | 단점 |
|------|------|------|------|
| 웨지 모니터 | 무대 바닥 스피커 | 설치 간단, 자연스러운 소리 | 소음 섞임, 피드백 위험 |
| 인이어 모니터 (유선) | 귀에 꽂는 이어폰 | 깨끗한 소리, 귀 보호 가능 | 착용 불편 |
| 무선 인이어 (IEM) | 무선 이어폰 시스템 | 이동 자유, 전문 퍼포먼스 | 비용 높음 |
| 사이드필 스피커 | 무대 측면 스피커 | 넓은 음역 커버 | 피드백 주의 |

## 사운드 체크 체크리스트

귀가 피로해지기 전에 중요한 판단을 먼저 내리는 것이 좋습니다.

**공연 1시간 전**
- 마이크 작동 확인 (소리 발생·레벨 확인)
- 모니터 스피커에서 본인 보컬 들리는지 확인
- 모니터 볼륨 요청 (부족하면 올려 달라고)
- 드럼·베이스 밸런스 조정 요청
- 피드백 없는지 테스트 발성

**공연 직전**
- 마이크 그립 방식 확인
- 마이크 위치 (입과 5~10cm)
- 피드백 방지: 마이크를 스피커 앞에 두지 않기
- 몸 상태 확인 (물 한 컵)

## 사운드 엔지니어에게 효과적으로 소통하기

고음역 컷이 전체 믹스에 투명감을 더해주는 경우가 많으므로 저역부터 정리하세요.

- ✅ 구체적으로 요청:
"제 보컬 모니터에서 더 크게 들리게 해주세요"
"베이스가 너무 크게 들려서 작게 해주세요"

- ❌ 막연하게 요청:
"소리가 이상해요"
"뭔가 잘 안 들려요"

**요청 가능한 사항**
- 모니터 보컬 레벨 조정
- 특정 악기 크기 조정
- EQ (너무 날카롭게/부드럽게)
- 리버브 양 조정

### 녹음 세션 공통 체크리스트

**준비 단계**
- [ ] 세션 목표 명확히 설정 (완성할 구간·트랙 수)
- [ ] 모든 파일·장비 사전 점검 완료
- [ ] 아티스트 컨디션 확인 (보컬: 목 상태, 악기: 튜닝)

**세션 중**
- [ ] 테이크별 메모 (베스트/리테이크 표시)
- [ ] 문제 구간 즉시 인식하고 재녹음 결정
- [ ] 세션 종료 30분 전 마무리 시작

**후반 작업**
- [ ] 원본 파일 즉시 백업
- [ ] 믹싱 전 24시간 이상 청취 공백 유지

### 세션 효율을 높이는 팁

1. **가장 어려운 구간을 세션 초반에** — 에너지가 최고일 때 어려운 것 먼저
2. **구간 분리 녹음** — 전체 통으로 반복보다 구간별 완성 후 연결
3. **즉각 피드백** — 녹음 직후 헤드폰으로 바로 모니터링

## 마치며

라이브 경험을 쌓는 가장 빠른 방법은 자주 무대에 서는 것입니다. 스튜디오 녹음으로 자신의 목소리를 객관적으로 파악하면 라이브에서 더 자신 있게 퍼포먼스할 수 있습니다.
