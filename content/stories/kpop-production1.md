faq:
  - q: K-POP 음반 제작 흐름은 어떻게 되나요?
    a: >-
      작곡·작사 → 편곡(프로듀싱) → 데모 녹음 → 보컬 디렉팅·레코딩 → 믹싱 → 마스터링 → 유통/발매 순서입니다. 인디 아티스트나
      솔로는 작곡부터 발매까지 스튜디오 1~2곳에서 진행할 수 있습니다.
  - q: K-POP 보컬 사운드의 특징은 무엇인가요?
    a: >-
      선명하고 밝은 중고음역(3~8kHz 강조), 오토튠으로 완성된 정확한 피치, 레이어드 하모니, 깔끔한 디에서 처리, 짧은
      리버브(홀·플레이트)로 공간감을 주면서도 드라이한 느낌이 K-POP 보컬의 특징입니다.
  - q: K-POP 믹싱에서 가장 중요한 것은?
    a: >-
      보컬이 가장 선명하게 들리는 믹스 밸런스입니다. 배경 악기를 억제하고 보컬을 전면 배치합니다. 저음 킥·베이스의 펀치감, 선명한 보컬
      존재감, 넓은 스테레오 이미지가 K-POP 사운드의 핵심입니다.
  - q: K-POP 오토튠은 어떻게 사용하나요?
    a: >-
      Auto-Tune(Melodyne) Retune Speed를 빠르게 설정하면 'T-Pain 스타일' 강한 오토튠, 느리게 설정하면
      자연스러운 피치 보정이 됩니다. K-POP 메인스트림은 자연스러운 피치 보정에 가까운 설정을 주로 사용하며, 후렴에서는 더 선명하게
      처리합니다.

## K-POP 프로덕션 — 완성도 높은 케이팝 음반 만들기

K-POP은 세계적으로 인정받는 프로덕션 수준을 자랑합니다. 인디 아티스트도 전문 스튜디오를 활용하면 K-POP 사운드에 가까운 결과물을 만들 수 있습니다.

---

## K-POP 음반 제작 흐름

| 단계 | 내용 | 담당 |
|------|------|------|
| 1. 작곡·작사 | 멜로디·가사 창작 | 작사·작곡가 |
| 2. 편곡·프로듀싱 | 비트·악기 편성 | 프로듀서 |
| 3. 데모 녹음 | 파일럿 보컬 제작 | 아티스트 |
| 4. 보컬 레코딩 | 전문 스튜디오 녹음 | 엔지니어·아티스트 |
| 5. 보컬 편집 | 컴핑·피치 편집 | 엔지니어 |
| 6. 믹싱 | 트랙 통합·처리 | 믹싱 엔지니어 |
| 7. 마스터링 | 최종 음압·출력 | 마스터링 엔지니어 |
| 8. 유통·발매 | 스트리밍 플랫폼 | 유통사 |

## K-POP 보컬 프로세싱

장르의 정체성을 결정하는 핵심 요소를 먼저 파악한 뒤 세부 사운드를 쌓아가세요.

### K-POP 보컬 신호 체인

1. HPF (80~100Hz): 저역 노이즈 제거
2. 컴프레서 (1단): Ratio 3:1~4:1, GR -3~-5dB
3. EQ (서지컬): 200~400Hz 탁함 컷
4. EQ (음색): 3~5kHz 존재감 부스트, 12kHz 에어
5. 오토튠/Melodyne: 자연스러운 피치 보정
6. 디에서: 시빌런스 제거
7. 컴프레서 (2단, 선택): 캐릭터 추가
8. 리버브 (센드): 홀 또는 플레이트 (Pre-delay 15ms)
9. 딜레이 (센드): 1/8~1/4박 스테레오 딜레이

### 보컬 레이어링

- 리드 보컬 (중앙)
- 더블 (좌우 ±10~20ms 스프레드)
- 하모니 (3도·5도 위)
- 배킹 보컬

## K-POP 믹싱 사운드 특징

장르별 믹싱 관행은 해당 음악을 가장 많이 듣는 청중의 기대치를 반영합니다.

### K-POP 믹스 특징

1. 보컬 전면 배치
  - 악기 EQ 카빙으로 보컬 공간 확보
  - 보컬 +3~+5dB 우위

2. 선명한 드럼 킥
  - 60~80Hz 서브 펀치 강조
  - 2~4kHz 어택감

3. 넓은 스테레오 이미지
  - 배킹 트랙 좌우 넓게 패닝
  - 마스터버스 스테레오 이미지 처리

4. 높은 음압 (트랜디 K-POP)
  - **마스터링**: -8~-10 LUFS
  - 리미터 강하게 처리
  - 스트리밍 정규화 고려

5. 오토튠 질감
  - 자연스러운 피치 보정 (Retune 속도: 중간)
  - **후렴·하이노트**: 더 선명한 튜닝

## 인디 아티스트의 K-POP 스타일 제작

샘플과 합성 사운드를 레이어하면 독창적이면서도 장르에 충실한 사운드를 만들 수 있습니다.

### 소규모 K-POP 프로덕션 가이드

1. 비트 구매 또는 DAW 제작
  - BeatStars·Airbit에서 K-POP 스타일 트랙 구매
  - FL Studio·Logic으로 직접 제작

2. 홈 데모 제작
  - 가이드 보컬 녹음 (피치 보정 후 확인)

3. 전문 스튜디오 보컬 녹음
  - Neumann 마이크·전문 부스에서 진행
  - 스튜디오 놀에서 K-POP 보컬 세션 가능

4. 온라인 믹싱 의뢰
  - 드라이 보컬 + MR 전송
  - K-POP 레퍼런스 트랙 제공
  - 믹싱·마스터링 후 발매
