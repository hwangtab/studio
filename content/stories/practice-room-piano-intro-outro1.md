# 피아노 인트로·아웃트로 작곡법 — 음악연습실 완전 가이드

피아노 인트로는 **청중을 음악 세계로 초대하는 문**입니다. 첫 몇 초에 곡의 분위기, 장르, 감정을 모두 전달해야 합니다. 아웃트로는 **음악이 사라지며 청중을 일상으로 돌려보내는 의식**입니다. 두 가지 모두 피아노 작곡에서 핵심 스킬입니다.

---

## 피아노 인트로 유형

### 1. 멜로디 인트로

주선율이나 주선율의 일부를 인트로로 사용.

**장점:** 청중이 바로 곡을 인식
**예:** 팝 발라드의 피아노가 멜로디를 먼저 제시

**기법:**
```
코드 진행 (Am-F-C-G) 반주 위에
주선율 첫 4마디를 피아노로 연주
```

### 2. 하모니 인트로

코드 보이싱이나 아르페지오로 화성을 제시.

**장점:** 분위기 설정에 효과적
**예:** Coldplay "The Scientist" 인트로 아르페지오

**기법:**
```
Am - F - C - G
각 코드를 아르페지오로 (8분음표)
단순하지만 아름다운 개방감
```

### 3. 모티프 인트로

짧은 리듬·멜로디 모티프를 반복.

**장점:** 기억에 남는 훅
**예:** "Für Elise"의 첫 4음이 전체 곡의 모티프

**기법:**
```
2-4음의 짧은 패턴을 반복
점점 발전시키며 본 멜로디로 연결
```

### 4. 분위기 인트로 (Atmospheric)

특정 음색이나 텍스처로 분위기만 설정.

**장점:** 미스터리한 개방감
**예:** 클래식 음악의 긴 서주

**기법:**
```
페달 + 낮은 드론 음
고음에서 자유로운 필인
박자 없이 자유롭게 (Rubato)
```

## 인트로 길이 결정

### 장르별 인트로 길이

| 장르 | 일반적 인트로 길이 |
|-----|----------------|
| 팝  | 4-8마디 |
| 발라드 | 4-16마디 |
| 재즈 | 2-8마디 (또는 없음) |
| 클래식 소나타 | 수십 마디 가능 |

### 인트로 너무 길면?

- 청중이 지루해짐
- 본 멜로디가 늦게 등장

**해결:** 4-8마디 내에서 핵심 분위기 전달

## 피아노 아웃트로 기법

### 1. 페이드아웃

점점 조용해지며 사라지는 아웃트로.

**기법:**
```
마지막 코드 진행을 반복
점점 피아니시모(pp)로
마지막은 거의 들릴 듯 말 듯
페달로 소리가 서서히 사라지게
```

**주의:** 너무 갑자기 끝나지 않도록

### 2. 리타르단도 (Ritardando)

점점 느려지며 마무리.

**기법:**
```
마지막 2-4마디를 점점 느리게
마지막 코드에서 페르마타 (늘이기)
서서히 건반에서 손 들기
```

### 3. 아르페지오 아웃트로

마지막 코드를 아르페지오로 분해하며 마무리.

**기법:**
```
마지막 코드: CMaj7
아르페지오: C-E-G-B (아래에서 위로)
각 음이 사라지며 고음이 마지막에 남음
```

### 4. 코다 (Coda)

별도의 종결부를 작성.

**기법:**
```
주요 주제 후 새로운 종결 섹션
피날레 방향으로 에너지 상승
최종 해결 코드로 강하게 종결
```

## 브리지 (Bridge) 작곡법

### 브리지의 역할

**브리지:** 버스와 코러스 사이, 또는 반복 후 중간에 오는 대조적 섹션.

**기능:**
- 반복에서 벗어나 신선함 제공
- 감정 전환점
- 최종 코러스로의 준비

### 브리지 화성

**규칙:** 이전 섹션과 다른 화성 지역으로

**팝 발라드 브리지 (C 장조):**
```
버스/코러스: C - Am - F - G
브리지: Dm - Em - F - G (2도에서 출발)
또는: Ab - Bb - C (장2도로 전조)
```

### 브리지 분위기

**화성만 아니라 분위기도 바꾸기:**
- 밝은 곡의 브리지: 단조로 전환
- 조용한 곡의 브리지: 갑자기 강하게

## 실전 인트로 작곡

### 팝 발라드 인트로 만들기

**코드 진행:** Am - F - C - G

**단계:**
1. **코드 선택:** Am-F-C-G 확정
2. **패턴 선택:** 아르페지오 (8분음표)
3. **길이:** 4마디
4. **음색:** 부드럽고 서정적

**아르페지오 인트로 예:**
```
Am: A-C-E-A-C-E-C-A (8분음표)
F: F-A-C-F-A-C-A-F
C: C-E-G-C-E-G-E-C
G: G-B-D-G-B-D-B-G
```

### 재즈 피아노 인트로

**"Autumn Leaves" 스타일:**
```
Em7 - Am7 - D7 - Gmaj7
아르페지오 + 경과음 자유롭게
루바토 (자유 박자)
```

## 음악연습실 인트로·아웃트로 연습

### 연습 루틴 (60분)

**1. 기존 곡 인트로 분석 (15분)**
   - 좋아하는 피아노 곡의 인트로 듣기
   - 어떤 유형인지 분석

**2. 인트로 유형 연습 (20분)**
   - 멜로디 인트로, 하모니 인트로, 모티프 인트로 각각 4마디 만들기

**3. 아웃트로 연습 (15분)**
   - 페이드아웃, 리타르단도, 아르페지오 아웃트로 각각 연습

**4. 자신의 곡에 적용 (10분)**
   - 연습하던 곡에 인트로·아웃트로 추가

## 마무리

피아노 인트로와 아웃트로는 **곡의 첫인상과 마지막 기억**입니다. 8마디의 인트로가 청중을 결정하고, 마지막 음이 사라지는 방식이 곡 전체를 기억하게 합니다.

은평구 24시간 음악연습실에서 다양한 인트로 유형을 실험하세요. 처음 시작과 마지막 마무리가 완성되면, 곡 전체가 살아납니다.
