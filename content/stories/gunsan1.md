## 군산에서 KTX 익산역 경유 서울까지

전라북도 군산은 익산역을 경유한 KTX를 통해 서울과 약 2시간 30분으로 연결됩니다. 근대역사 시간여행마을·진포해양테마공원으로 유명한 군산에서 서울 연신내 스튜디오 놀까지 당일 왕복이 가능합니다.

---

## 군산 → 연신내 이동 경로

### KTX 익산역 경유 (권장)

```
① 군산 → 익산역 (버스 약 30분 또는 기차 약 20분)
② 익산역에서 KTX 서울 방면 탑승
③ 서울역 하차 (약 1시간 50분~2시간)
④ 지하철 6호선 경유 연신내역 (약 25분)

총 소요시간: 약 2시간 30분~3시간
```

### 버스 직행 (대안)

```
① 군산버스터미널 → 서울 센트럴시티(강남) 버스
② 약 2시간 40분~3시간 소요
③ 강남에서 지하철 → 연신내역 약 30~40분

총 소요시간: 약 3시간 10분~3시간 40분
```

## 당일 왕복 일정 예시 (군산 기준)

```
오전 7시 30분 군산 출발 → 익산역
오전 8시 KTX 탑승 (익산역)
→ 오전 10시 서울역 도착
→ 오전 10시 30분 연신내역
→ 오전 11시 세션 시작 (2시간)
→ 오후 1시 세션 완료
→ 오후 3시 서울역 출발 KTX
→ 오후 5시 익산역 도착
→ 오후 5시 30분 군산 도착
```

## 온라인 파일 의뢰 서비스

```
현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
