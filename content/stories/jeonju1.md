## 전주에서 KTX로 두 시간이면

전주는 KTX 전라선으로 서울과 연결됩니다. 전문 보컬 녹음, 음원 발매용 레코딩, 오디션 데모 제작을 위해 연신내 스튜디오 놀을 당일 왕복으로 이용할 수 있습니다.

---

## 전주 → 연신내 이동 경로

### KTX 전라선 → 서울역

아래 정보는 작성 시점 기준이며, 교통 상황이나 노선 변경으로 달라질 수 있습니다.

1. 전주역에서 KTX 탑승 (서울역 방면)
2. 서울역 도착 (약 1시간 40~50분)
3. 1호선 → 용산역 → 경의중앙선
   또는 2호선 합정역 → 6호선 연신내역
4. 연신내역 3번 출구 → 도보 5분

### SRT → 수서역 경로

1. 전주역 → SRT (수서역 방면)
2. 수서역 도착 → 3호선 탑승
3. 3호선 충무로 → 환승 → 6호선 연신내역

- **총 소요시간**: 약 2시간 30분~3시간

## 당일 왕복 일정 예시 (전주 기준)

입구 위치나 주차 정보가 필요한 경우 예약 전 문의해주시면 안내드립니다.

오전 7시 전주역 출발 (KTX/SRT)
- 오전 9시 30분 서울 도착
- 오전 10시 20분 연신내역 도착
- 오전 10시 30분 세션 시작 (2시간)
- 오후 12시 30분 세션 완료
- 오후 2시 서울역 출발 (KTX)
- 오후 4시 전주역 도착

## 전주 음악 씬과 서울 스튜디오

전주세계소리축제·한국소리문화의전당. 전북대 음악대학. 국악·크로스오버 허브. 서울 연신내 스튜디오 놀까지 KTX 이용 시 약 90분 소요됩니다.

KTX 전주역 → 서울역 1시간 10분, 지하철 연신내 총 90분.

## 방문 전 세션 준비 가이드

약 90분 이동 후 최상의 컨디션으로 세션에 임하기 위한 준비 사항입니다.

**출발 전 챙길 것:**
- 녹음할 곡의 가사·악보·MR 파일 (USB 또는 Google Drive)
- 원하는 사운드의 레퍼런스 트랙 2~3곡
- 예약 확인 문자 캡처
- 충분한 수분 + 보컬이라면 따뜻한 차·꿀물 보온병
- 간식 또는 간단한 식사 (긴 이동 후 빈속 녹음 금지)

**이동 중 활용법:**
- 녹음할 곡 이어폰으로 2~3회 예습
- 가사·감정 포인트 머릿속으로 정리
- 목·어깨 스트레칭으로 이동 피로 완화
- KTX 이동 중 수분 섭취로 성대 건조 방지

**세션 팁:**
- 도착 후 30분은 워밍업 시간 확보 (출발 시간 고려해 일정 계획)
- 가장 중요한 구간을 세션 초반에 먼저 녹음 (이동 피로 전)
- 원하는 사운드를 엔지니어에게 레퍼런스 곡으로 구체적으로 설명
- 온라인 파일 의뢰 서비스 병행 고려 (재방문 부담 완화)



## 세션 당일 체크리스트

세션에서 최상의 결과를 얻기 위한 확인 사항입니다.

**출발 전:**
- [ ] 녹음할 곡의 가사·악보·MR 파일 준비 (USB 또는 Google Drive)
- [ ] 원하는 사운드의 레퍼런스 트랙 2~3곡 선정
- [ ] 예약 확인 메시지 캡처
- [ ] 보컬이라면 전날 무리한 발성 금지, 충분한 수면

**도착 후:**
- [ ] 도착 후 5~10분 워밍업 발성
- [ ] 엔지니어에게 레퍼런스 트랙·원하는 사운드 설명
- [ ] 중요한 구간을 세션 초반에 먼저 녹음

**녹음 중:**
- [ ] 모니터 헤드폰 볼륨이 편안한지 확인
- [ ] 이어폰 한쪽 빼고 자신의 실제 목소리 확인
- [ ] 만족스러운 테이크가 나오면 바로 확인


## 마치며

전주에서 KTX로 2~3시간이면 서울 전문 스튜디오 세션이 가능합니다. 전라북도 지역 아티스트도 연신내 스튜디오 놀의. KTX 이동 피로가 있을 수 있으므로 세션 전 워밍업 시간을 여유롭게 확보하시길 권장합니다.
