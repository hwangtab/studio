## 평창에서 KTX로 2시간

평창은 2018년 동계올림픽 개최와 함께 KTX 강릉선이 개통되어 서울과의 접근성이 크게 향상되었습니다. 청량리역까지 약 1시간 10~20분으로 강원도 내 서울 접근성이 우수한 도시입니다.

---

## 평창 → 연신내 이동 경로

### KTX 강릉선 이용 (권장)

```
① 평창역에서 KTX 탑승 (청량리 방면)
② 청량리역 도착 (약 1시간 10~20분)
③ 청량리역 → 지하철 1호선 또는 2호선 환승
   → 합정역 6호선 환승 → 연신내역

총 소요시간: 약 2시간~2시간 10분
```

### 고속버스 이용 (대안)

```
① 평창 시외버스터미널 출발
② 서울 동서울터미널 또는 강남터미널 도착
   (약 2시간 30분~3시간)
③ 지하철 이용 → 연신내역

총 소요시간: 약 3시간~3시간 30분
```

## 당일 왕복 일정 예시 (평창 기준)

```
오전 7시 평창역 출발 (KTX)
→ 오전 8시 20분 청량리역 도착
→ 오전 9시 10분 연신내역 도착
→ 오전 9시 30분 세션 시작 (2~3시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 청량리역 출발
→ 오후 3시 20분 평창역 도착
```

## 온라인 파일 의뢰 서비스

```
평창 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
