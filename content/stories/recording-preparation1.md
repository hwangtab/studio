## 준비된 보컬이 최고의 결과를 만든다

스튜디오 세션은 시간이 한정되어 있습니다. 사전 준비가 충분할수록 녹음에 집중할 수 있고, 결과물의 품질도 높아집니다.

---

## 세션 D-1 (전날) 체크리스트

마이크 위치를 조금만 바꿔도 음색이 크게 달라지므로 충분한 테스트가 필요합니다.

### 보컬 컨디션 관리

☐ 충분한 수면 (7~8시간)
☐ 수분 섭취 (물 1.5~2L)
☐ 과도한 연습 금지 (가볍게 확인만)
☐ 카페인·알코올 자제
☐ 유제품(우유·치즈) 자제 — 점액 증가

### 파일·자료 준비

☐ MR 파일 준비 (WAV 권장)
☐ 가사 출력 또는 스마트폰 저장
☐ 악보 준비 (필요 시)
☐ 참고 레퍼런스 음원 저장
☐ 스튜디오 위치·주차 확인

---

## 세션 당일 아침 체크리스트

클리핑은 후반에서 복구가 불가능하므로 게인을 보수적으로 설정하는 것이 안전합니다.

### 기상 후

☐ 따뜻한 물 마시기 (성대 보호)
☐ 과격한 운동 금지 (체력 소모)
☐ 식사: 세션 1~2시간 전에 가볍게
  - 과식 금지 (횡격막 압박)
  - 기름진 음식 금지 (점액 증가)

### 이동 중

☐ 찬 음료·아이스크림 금지
☐ 이동 중 불필요한 발성 자제
☐ 시간에 여유 있게 출발 (긴장 방지)

---

## 스튜디오 도착 후 체크리스트

### 도착 즉시

☐ MR 파일·가사 제출 또는 클라우드 링크 공유
☐ 상온 물 준비
☐ 세션 목적·희망 사항 엔지니어에게 전달
  예: "이 곡은 감성적으로 부드럽게, 코러스는 힘 있게"

### 워밍업 (세션 시작 15~20분 전)

☐ 가볍게 허밍
☐ 립 트릴 (혀 트릴)
☐ 스케일 — 낮은 음역부터 편안하게
☐ 녹음 곡 중 가장 어려운 구간 가볍게 확인

### 모니터 세팅

☐ 헤드폰 모니터 레벨 확인
☐ 자신의 목소리 레벨 조절 (너무 크면 음정 오버보상)
☐ MR과 보컬 밸런스 설정

## MR 파일 준비 가이드

| 항목 | 권장 | 가능 |
|------|------|------|
| 포맷 | WAV 44.1kHz/24bit | MP3 320kbps |
| 파일명 | 곡명_키_BPM.wav | 곡명.mp3 |
| 멜로디 가이드 | 없는 버전 권장 | 있어도 가능 |
| 전달 방법 | USB, 구글 드라이브 | 카카오톡 전송 |

## 세션 에티켓

불필요한 배경 소음을 차단하는 것이 노이즈 제거 플러그인보다 효과적입니다.

- 예약 시간 5~10분 전 도착
  - 워밍업 시간 확보

- 목소리 외에 신체 소음 주의
  - 의류 마찰음, 악세서리 소리

- 엔지니어·디렉터 피드백 수용
  - 열린 마음으로 협업

- 녹음 중 불필요한 대화 최소화
  - 집중력 유지

- 세션 시간 내 효율적으로 진행
  - 쉬운 구간 먼저, 어려운 구간 나중에

### 녹음 전 준비 체크리스트

**장비 점검**
- [ ] 마이크·케이블·인터페이스 연결 상태 확인
- [ ] 헤드폰 모니터링 레벨 적절히 설정
- [ ] DAW 샘플레이트 설정: 44.1kHz 또는 48kHz

**공간 준비**
- [ ] 불필요한 소음원 제거 (에어컨, 팬 소리 등)
- [ ] 방음·흡음 처리 여부 확인
- [ ] 리플렉션 필터 또는 보컬 부스 활용

**아티스트 준비**
- [ ] MR 파일 최종 확인 (키·BPM·시작점)
- [ ] 가사 인쇄 또는 화면 준비
- [ ] 보컬 워밍업 10~15분 확보

### 녹음 세션 타임라인 예시

| 시간 | 내용 |
|------|------|
| 0~15분 | 장비 세팅·사운드 체크 |
| 15~30분 | 아티스트 워밍업·테스트 녹음 |
| 30~90분 | 본 녹음 (구간별 집중) |
| 90~100분 | 마무리·베스트 테이크 선택 |
