# 기타 메탈·디스토션 완벽 세팅 가이드 — 연신내 음악연습실 실전 연습

메탈 기타는 단순히 디스토션 페달을 켜는 것 이상입니다. 픽업, 앰프 게인 구조, 피킹 각도, 팜뮤트까지 유기적으로 결합되어야 진짜 메탈 사운드가 완성됩니다. 연신내 음악연습실에서 메탈 기타의 본질을 체계적으로 익히는 방법을 소개합니다.

## 메탈 기타 사운드의 구조

메탈 사운드는 게인 스테이지(Gain Stage)가 겹쳐져 만들어집니다.

### 게인 체인 구조
```
기타 → 디스토션/오버드라이브 → 앰프 드라이브 채널 → 캐비넷
```

각 단계에서 게인(이득)이 더해지며 파형이 클리핑됩니다. 과도한 게인은 음정을 뭉치게 하고, 적절한 게인은 타이트한 메탈 사운드를 만듭니다.

### 메탈 장르별 게인 수준
| 장르 | 게인 수준 | 특징 |
|-----|---------|------|
| 헤비메탈 | 중 (6~7) | 선명한 음정, 파워 코드 강조 |
| 스래쉬메탈 | 높음 (7~8) | 빠른 리프, 공격적인 어택 |
| 데스메탈 | 매우 높음 (8~10) | 고밀도 디스토션, 리프 텍스처 |
| 둠메탈 | 중~높음 (6~8) | 느리고 무거운 리프, 저음 강조 |

## 디스토션 페달 종류와 특성

### 오버드라이브(Overdrive)
- 게인이 낮은 자연스러운 왜곡
- 앰프 드라이브 채널과 조합해 메탈 사운드 베이스 형성
- 대표 페달: Boss BD-2, Ibanez Tube Screamer

### 디스토션(Distortion)
- 더 강한 클리핑으로 공격적인 메탈 사운드
- 단독으로 메탈 사운드 완성 가능
- 대표 페달: Boss DS-1, MXR M75

### 하이게인 프리앰프 페달
- 앰프 프리앰프 단계를 시뮬레이션
- 현대 메탈의 타이트한 게인 제어에 유리
- 대표 페달: Amptweaker Tight Drive, Friedman BE-OD

## 팜뮤트(Palm Mute): 메탈 리프의 핵심

팜뮤트는 오른손 손바닥 측면을 줄에 살짝 얹어 진동을 제한하는 기법으로, 메탈 리프의 '척' 하는 타이트한 소리를 만듭니다.

### 팜뮤트 기본 포지션
1. 오른손 소지구 근처(손바닥 아랫부분)를 브릿지 직전 줄 위에 얹기
2. 브릿지에 가까울수록 짧고 타이트한 뮤트
3. 브릿지에서 멀어질수록 더 많이 뮤트되어 피치 불분명

**팁**: 팜뮤트 연습은 먼저 E 저음 줄 한 줄만으로 시작합니다. 뮤트 위치를 앞뒤로 조금씩 이동하며 원하는 타이트감을 찾으세요.

### 팜뮤트 리프 패턴 (기본)
```
BPM: 120, 4/4박자
E |: 0 0 0 0 0 0 0 0 :|  (팜뮤트, 다운 피킹)
```

### 팜뮤트와 오픈 코드의 대비
```
PM: 0 0 0 0  오픈: 5(파워코드)
E |: PM PM PM PM   5 5 5 5 :|
```
팜뮤트 리프 위에 갑자기 오픈 파워코드가 터질 때 메탈 특유의 폭발감이 생깁니다.

## 다운 피킹 vs 얼터네이트 피킹

메탈에서는 피킹 방향이 그루브 캐릭터를 결정합니다.

### 다운 피킹(Down Picking)
- 모든 음을 다운스트로크로만 연주
- 묵직하고 타이트한 스래쉬메탈 특유의 어택
- 한계: 빠른 템포에서 체력 소모 큼
- 레퍼런스: James Hetfield (Metallica)

### 얼터네이트 피킹(Alternate Picking)
- 다운-업 교대로 연주
- 더 빠른 템포에서 유리
- 음색이 다운 피킹보다 살짝 가볍고 일정함
- 레퍼런스: John Petrucci (Dream Theater)

### 피킹 각도
픽이 줄과 이루는 각도도 음색에 영향을 줍니다.
- **수직(90°)**: 밝고 선명한 어택
- **사선(45°)**: 부드럽고 두터운 어택
- 메탈에서는 대부분 사선 피킹으로 두텁고 공격적인 음색 선호

## 앰프 EQ: 메탈 사운드 세팅

### 기본 메탈 EQ 세팅
```
Bass: 6~7 (묵직한 저음)
Mid: 3~4 (중역대 스쿱 — 일반 메탈)
Treble: 6~7 (선명한 고역, 리프 명료성)
Presence: 7~8 (응답성·어택감 강화)
```

### 중역대 스쿱(Mid Scoop)과 예외
전통 메탈은 미드를 줄여 "V 모양" EQ를 사용합니다. 그러나 스래쉬메탈·둠메탈에서는 미드를 높여 두텁고 펀치감 있는 사운드를 선호합니다.

### 장르별 EQ 비교
| 장르 | Bass | Mid | Treble |
|-----|------|-----|--------|
| 클래식 헤비메탈 | 7 | 3 | 7 |
| 스래쉬 | 6 | 6 | 6 |
| 둠/스토너 | 8 | 6 | 4 |
| 프로그레시브 | 5 | 6 | 6 |

## 메탈 리프 연습 루틴

### 1시간 메탈 집중 연습 루틴
| 시간 | 내용 |
|-----|------|
| 0~10분 | 팜뮤트 E 줄 단음 피킹 웜업 (BPM 60→100 점진적 증가) |
| 10~25분 | 파워 코드 + 팜뮤트 조합 리프 연습 |
| 25~35분 | 다운 피킹으로 짧은 리프 반복 (BPM 100→140) |
| 35~50분 | 얼터네이트 피킹으로 빠른 리프 훈련 (BPM 140→180) |
| 50~60분 | EQ 세팅 실험 + 팜뮤트-오픈 대비 사운드 확인 |

## 메탈 기타 흔한 실수와 교정

### 게인을 최대로만 올리는 문제
게인이 너무 높으면 리프의 음정이 뭉개지고 팜뮤트의 타이트감이 사라집니다. 게인을 6~7 수준에서 팜뮤트 선명도를 먼저 확인한 뒤 장르에 맞게 조정하세요.

### 팜뮤트 위치가 일정하지 않은 문제
리프 연주 중 손의 위치가 흔들리면 음색이 변합니다. 오른손 앵커 포인트(손목 브릿지 접촉)를 고정하는 연습을 꾸준히 하세요.

## 추천 레퍼런스

- **Tony Iommi** (Black Sabbath): 헤비메탈 팜뮤트의 원조
- **James Hetfield** (Metallica): 다운 피킹의 교과서, 스래쉬 리프
- **Dimebag Darrell** (Pantera): 파워풀한 디스토션 + 독창적 리프 구성
- **John Petrucci** (Dream Theater): 프로그레시브 메탈 얼터네이트 피킹의 정점

## 마무리

메탈 기타의 본질은 통제된 게인, 정확한 팜뮤트, 일관된 피킹입니다. 연신내 음악연습실의 충분한 볼륨 환경에서 앰프를 제대로 울리며 자신만의 메탈 사운드를 만들어가는 과정 자체가 최고의 훈련입니다.
