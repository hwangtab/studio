faq:
  - q: 기타에서 코드 진행을 이해하는 방법은?
    a: >-
      기타 코드 진행 이해: ① 스케일 도수 — I·IV·V 등 스케일 내 코드 위치 ② 기본 진행 — I-IV-V-I (C-F-G-C)
      ③ 마이너 — Im-IVm-Vm (Am-Dm-Em) ④ 역할 — 토닉(I)·서브도미넌트(IV)·도미넌트(V) ⑤ 해결 — V→I의
      긴장-해결이 화성의 기본. 코드 진행을 이해하면 어떤 곡이든 코드를 유추할 수 있습니다. 음악은 긴장(도미넌트)과 해결(토닉)의
      반복으로 이루어집니다.
  - q: 팝·록 기타에서 자주 쓰이는 코드 진행은?
    a: >-
      기타 코드 진행 패턴: ① I-V-vi-IV — 팝의 가장 기본 (C-G-Am-F) ② I-IV-V — 블루스·록 기본 ③
      ii-V-I — 재즈 기본 ④ I-vi-IV-V — 50년대 팝·R&B ⑤ vi-IV-I-V — 현대 팝 변형. 팝과 록의 90%는
      I-V-vi-IV 진행으로 이루어져 있습니다. 이 네 코드를 익히면 수백 곡을 연주할 수 있습니다.
  - q: 기타 차용 화음(borrowed chord)이란 무엇인가요?
    a: >-
      기타 차용 화음: ① 정의 — 같은 으뜸음의 장조·단조에서 코드 빌려 쓰기 ② 예시 — C 장조에서 Ab 코드 (C 단조에서 차용)
      ③ 효과 — 예상치 못한 색깔 변화 ④ 흔한 차용 — ♭VII·♭VI·iv (단조 4도) ⑤ 활용 — Let It Be의
      ♭VII(B♭) 등. 차용 화음은 평범한 진행에 극적인 색깔을 더해줍니다. 록 발라드에서 자주 들리는 그 '뭔가 다른' 느낌이 차용
      화음입니다.
  - q: 기타 피벗 코드 전조(modulation)란 무엇인가요?
    a: >-
      기타 전조 이해: ① 피벗 코드 — 두 조에 모두 속하는 코드로 전조 연결 ② 반음 전조 — 반음 위아래로 올라가는 극적 전조 ③
      평행 전조 — C 장조→C 단조 같은 동일 으뜸음 ④ 5도권 전조 — 5도 위나 아래로 자연스럽게 ⑤ 팝 전조 — 클라이맥스에서 반음
      위로 올리기. 전조는 음악에 새로운 에너지를 불어넣습니다. 많은 팝 발라드가 마지막 코러스에서 반음 위로 전조해 감동의 클라이맥스를
      만듭니다.

## 코드 진행을 알면 모든 음악이 달라 보입니다

왜 이 코드가 여기 있는지 이해하는 순간 음악이 보입니다. 방음 개인실에서 다양한 코드 진행을 자유롭게 탐색하세요.

기타 코드 진행 연습의 핵심:
- **도수 이해**: I-IV-V가 음악의 기본 뼈대
- **귀로 익히기**: 진행을 이론이 아닌 귀로 느끼기
- **많은 곡 분석**: 좋아하는 곡 코드 분석 습관
- **즉흥 활용**: 배운 진행 즉흥 연주에 적용

| 코드 | 기능 | 느낌 |
|------|------|------|
| I (토닉) | 안정·귀결 | 편안함 |
| IV (서브도미넌트) | 중간 | 출발·움직임 |
| V (도미넌트) | 긴장 | 해결 요구 |
| vi (서브토닉) | 상대단조 | 감성·우울 |

## 기타 코드 진행·화성 이해 훈련의 핵심 원칙 4가지

코드는 단순히 모양을 외우는 것이 아니라 **음악적 기능을 이해하면서 익히는** 것이 장기 기억에 훨씬 유리합니다.

1. **코드 기능 이해** — 각 코드가 I(토닉)·IV(서브도미넌트)·V(도미넌트) 중 어떤 기능인지 이해하며 연습. 기능을 알면 처음 보는 곡도 빠르게 코드를 파악할 수 있습니다.

2. **최소 이동 보이싱** — 코드 전환 시 손가락 이동을 최소화하는 보이싱 탐색. 공통 음을 중심으로 나머지 손가락만 이동하면 전환 속도가 빨라집니다.

3. **장르 맞춤 코드 색채** — 팝은 개방 코드의 따뜻함, 재즈는 7th·9th·13th 텐션, 클래식은 클로즈드 보이싱의 단단함을 각각 탐색하세요.

4. **코드톤 아르페지오** — 각 코드를 아르페지오로 분해하며 내성 음의 움직임을 귀로 인식. 코드와 선율의 관계가 명확해집니다.

### 코드 마스터를 위한 연습 곡 추천

| 난이도 | 곡명 | 핵심 코드 |

### 기타 코드 연습에서 자주 하는 실수

1. **손가락을 눕혀서 인접 현을 뮤팅** — 각 손가락 끝을 세워서 프렛 바로 뒤를 누르기
2. **코드 전환 시 손 전체를 들어올림** — 기준 손가락(1지)을 최대한 이동하지 않고 전환
3. **스트로크 없이 코드 잡기만 연습** — 코드 전환 후 즉시 스트로크해서 '연주 흐름' 익히기
4. **바레 코드를 너무 일찍 시도** — 오픈 코드를 완전히 익힌 후 바레 코드로 진행

### 기타 코드 자가 진단

- [ ] 6개 현이 모두 깨끗하게 울리는가? (왼손 뮤팅 없이)
- [ ] G → C → Am → Em 코드 전환이 1박 안에 완성되는가?
- [ ] 코드 전환 후 첫 스트로크가 끊기지 않는가?

## 4주 기타 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 코드 | Em·Am·G·C·D — 코드 전환 속도 향상 | 40분 |
| 2주차 | 스트로크·핑거 | 8비트 스트로크, 핑거피킹 기본 패턴 | 45분 |
| 3주차 | 곡 연습 | 목표 곡 섹션별 분리 연습, 코드 전환 | 50분 |
| 4주차 | 완성 | 전곡 + 노래에 맞춰 연주 실전 적용 | 60분 |

**주간 체크포인트:** 1주차: 코드 전환 2초 이내 / 2주차: 박자 흔들림 없이 8마디 연속 / 3주차: 목표 곡 코드 전환 오류 없이 / 4주차: 노래·MR과 함께 완주
