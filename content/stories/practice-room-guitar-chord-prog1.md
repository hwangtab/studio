    a: >-
      기타 차용 화음: ① 정의 — 같은 으뜸음의 장조·단조에서 코드 빌려 쓰기 ② 예시 — C 장조에서 Ab 코드 (C 단조에서 차용)

      화음입니다.

      평행 전조 — C 장조→C 단조 같은 동일 으뜸음 ④ 5도권 전조 — 5도 위나 아래로 자연스럽게 ⑤ 팝 전조 — 클라이맥스에서 반음
      위로 올리기. 전조는 음악에 새로운 에너지를 불어넣습니다. 많은 팝 발라드가 마지막 코러스에서 반음 위로 전조해 감동의 클라이맥스를
      만듭니다.

## 코드 진행을 알면 모든 음악이 달라 보입니다

왜 이 코드가 여기 있는지 이해하는 순간 음악이 보입니다. 방음 개인실에서 다양한 코드 진행을 자유롭게 탐색하세요.

기타 코드 진행 연습의 핵심:
- **도수 이해**: I-IV-V가 음악의 기본 뼈대
- **귀로 익히기**: 진행을 이론이 아닌 귀로 느끼기
- **많은 곡 분석**: 좋아하는 곡 코드 분석 습관
- **즉흥 활용**: 배운 진행 즉흥 연주에 적용

|------|------|------|

## 기타 코드 진행·화성 이해 훈련의 핵심 원칙 4가지

I-IV-V든 ii-V-I든, 진행을 외운다고 화성이 이해되지는 않습니다. 코드 이름 뒤에 있는 역할을 봐야 비로소 응용이 시작됩니다.

1. **코드 기능 이해** — 각 코드가 I(토닉)·IV(서브도미넌트)·V(도미넌트) 중 어떤 기능인지 이해하며 연습. 기능을 알면 처음 보는 곡도 빠르게 코드를 파악할 수 있습니다.

2. **최소 이동 보이싱** — 코드 전환 시 손가락 이동을 최소화하는 보이싱 탐색. 공통 음을 중심으로 나머지 손가락만 이동하면 전환 속도가 빨라집니다.

3. **장르 맞춤 코드 색채** — 팝은 개방 코드의 따뜻함, 재즈는 7th·9th·13th 텐션, 클래식은 클로즈드 보이싱의 단단함을 각각 탐색하세요.

4. **코드톤 아르페지오** — 각 코드를 아르페지오로 분해하며 내성 음의 움직임을 귀로 인식. 코드와 선율의 관계가 명확해집니다.

## 대중가요의 대부분은 네 개의 코드로 되어 있습니다

기타로 아는 노래를 치고 싶은데 곡마다 코드를 새로 외우려니 막막하다면, 반가운 사실이 하나 있어요. 대중음악의 95%가 1·4·5·6, 이 네 개 코드의 변형으로 만들어진다는 겁니다. C 키로 치면 C-F-G-Am이죠. 이 네 코드의 조합인 1·4·5나 1·6·4·5 진행을 여러 키에서 익혀 두면, 처음 듣는 노래도 '아, 그 진행이네' 하고 금방 따라 칠 수 있어요. 곡을 하나씩 외우는 게 아니라 진행의 공식을 익히는 겁니다.

이 진행이 왜 그렇게 자연스러운지는 다이아토닉을 알면 보여요. 한 조성 안의 일곱 개 코드가 어떻게 어울리는지 이해하면, 1·4·5·6이 그 가족의 핵심 멤버라는 게 눈에 들어옵니다.

진행을 이해했어도 실전엔 한 단계가 더 있어요. 노래하는 사람의 키에 맞추는 겁니다. 코드 모양은 그대로 두고 카포로 키를 즉시 옮기는 훈련을 함께하면, 어떤 보컬과도 바로 맞출 수 있어요. 진행의 이론적 뿌리를 더 파고드는 법은 [기타 코드 진행 연습](/stories/practice-room-guitar-chord-progressions1)에서 이어집니다.
