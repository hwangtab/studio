## 의령에서 KTX로 서울까지

의령은 경남 내륙 도시로, 창원중앙역 KTX를 통해 서울과 약 3시간 10분대로 연결됩니다. 홍의장군 곽재우의 고장 의령에서 오전 일찍 출발하면 당일 서울 스튜디오 방문이 가능합니다.

---

## 의령 → 연신내 이동 경로

### KTX 창원중앙역 경유 (권장)

```
① 의령 → 창원중앙역 (버스 약 40~50분)
② 창원중앙역 KTX 탑승 (서울역 방면, 약 2시간~2시간 20분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간 10분~3시간 50분
```

---

## 당일 왕복 일정 예시 (의령 기준)

```
오전 7시 의령 출발 → 창원중앙역 이동
오전 8시 창원중앙역 KTX 출발
→ 오전 10시 20분 서울역 도착
→ 오전 11시 연신내역 도착
→ 오전 11시 30분 세션 시작 (2시간)
→ 오후 1시 30분 세션 완료
→ 오후 3시 서울역 출발
→ 오후 5시 20분 창원중앙역 도착
→ 오후 6시 20분 의령 도착
```

## 온라인 파일 의뢰 서비스

```
의령 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
