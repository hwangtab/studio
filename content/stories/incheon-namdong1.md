## 인천 남동구에서 연신내 스튜디오 놀까지

인천시 남동구(구월동·만수동·논현동·소래포구) 지역에서 인천1호선 또는 수인분당선을 이용하면 서울 연신내 스튜디오 놀까지 약 70~90분에 도달할 수 있습니다.

---

## 남동구 → 연신내 이동 경로

### 구월·만수동 출발 (인천1호선)

```
① 구월역 또는 인천시청역(인천1호선) 탑승
② 부평역 하차 → 1호선 서울 방향 환승
③ 영등포역 하차 → 경의중앙선 환승
④ DMC역(디지털미디어시티) 하차 → 6호선 환승
⑤ 연신내역 하차 → 3번 출구 도보 5분

소요: 약 70~80분
```

### 소래포구·논현동 출발 (수인분당선)

```
① 소래포구역(수인분당선) 탑승
② 수인분당선 왕십리 방면 탑승
③ 왕십리역 하차 → 5호선 환승
④ 공덕역 하차 → 6호선 환승
⑤ 연신내역 하차 → 3번 출구 도보 5분

소요: 약 75~90분
```

| 인천시청역 (인천1호선) | 부평 → 1호선 → 영등포 → 경의중앙선 → DMC → 6호선 | 약 75~85분 |
| 소래포구역 (수인분당선) | 수인분당선 → 왕십리 → 5호선 → 공덕 → 6호선 | 약 75~90분 |
| 논현역 (수인분당선) | 수인분당선 → 왕십리 → 5호선 → 공덕 → 6호선 | 약 80~90분 |
