## 제주에서 비행기로 서울까지

제주도는 유일하게 항공 이동이 필요한 지역입니다. 그러나 비행 시간 자체는 55~65분으로 짧아 당일 왕복 세션이 충분히 가능합니다.

---

## 제주 → 연신내 이동 경로

```
① 제주국제공항 출발 → 김포국제공항 도착 (약 55~65분)
② 김포공항 5호선 또는 9호선 탑승
③ 5호선: 방화 방면 → 공덕역 → 환승 → 6호선 연신내역
   또는 9호선: 공항시장역 → 5호선 환승 → 6호선 연신내역
④ 연신내역 3번 출구 → 도보 5분

총 소요시간: 공항 대기 포함 약 2시간 30분~3시간
```

---

## 당일 왕복 일정 예시 (제주 기준)

```
오전 7시 제주공항 출발 (첫 항공편)
→ 오전 8시 5분 김포공항 도착
→ 오전 9시 연신내역 도착
→ 오전 9시 30분~10시 세션 시작 (2~3시간)
→ 오후 12시~1시 세션 완료
→ 오후 3시~4시 김포공항 출발
→ 오후 4시~5시 제주공항 도착
```

## 온라인 파일 의뢰 서비스

이동이 부담스러울 때 가장 편리한 방법:

```
제주 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```

**파일 요구사항**
- 보컬: WAV 44.1kHz/24bit (에코·리버브 없는 드라이 파일)
- MR: WAV 44.1kHz/16bit 이상
