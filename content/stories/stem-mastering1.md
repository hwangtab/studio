faq:
  - q: 스템 마스터링이란 무엇인가요?

  - q: 스템 파일은 어떻게 구성하나요?
    a: >-
      일반적으로 드럼, 베이스, 키보드/신스, 기타, 보컬(메인+백보컬), FX/패드 등 6~8개 그룹으로 분리합니다. 각 스템은 이펙트
      없이(드라이) 또는 믹스 내 이펙트 포함 버전으로 렌더링합니다.
  - q: 스템 마스터링이 일반 마스터링보다 항상 좋은가요?
    a: >-
      반드시 그렇지는 않습니다. 잘 완성된 풀 믹스라면 일반 마스터링으로 충분합니다. 스템 마스터링은 믹스에서 특정 파트(예: 드럼 음압,
      보컬 위치)를 수정하고 싶을 때 유용합니다. 믹스를 다시 열 수 없는 상황에서도 활용합니다.

    a: >-
      각 스템 WAV 파일(24bit 44.1kHz 또는 48kHz)과 함께 마스터 버전(스테레오 2-mix) WAV를 함께 납품합니다.

## 스템 마스터링이 필요한 순간

믹스가 완성됐지만 특정 파트의 음압이나 음색을 미세하게 조정하고 싶을 때, 또는 방송·광고 등 납품처에서 스템 파일을 요구할 때 스템 마스터링이 필요합니다.

스템 마스터링의 관행은 1990년대 DAW의 멀티트랙 버스 라우팅이 일반화되면서 형성됐습니다. 이전에는 완성된 스테레오 믹스 파일만 마스터링 엔지니어에게 전달하는 것이 표준이었지만, 마스터링 과정에서 드럼 저역이 너무 강하거나 보컬 레벨이 낮은 문제를 발견해도 전체 믹스를 다시 열어야 하는 한계가 있었습니다. 밥 클리어마운틴(Bob Clearmountain)·밥 루드위그(Bob Ludwig) 같은 마스터링 엔지니어들이 스템 파일을 요청해 개별 조정하는 방식을 도입하면서 스템 마스터링이 확산됐습니다. 방송·광고 업계에서는 음악의 악기별 분리 납품이 오래전부터 필수였으며, 특히 드라마·광고 음악 제작에서는 보컬·반주 분리 버전, 효과음 제거 버전 등 다양한 스템 조합이 계약 납품 요건에 포함됩니다. 현재 K-POP 대형 기획사들은 향후 리믹스·컴필레이션·다국어 버전 제작을 대비해 마스터 믹스와 함께 스템 파일을 아카이브하는 것이 표준입니다.

## 스템 구성 기준

| 스템 이름 | 포함 트랙 | 비고 |
|---------|---------|------|
| Drums | 킥·스네어·하이햇·심벌·퍼커션 | 모든 드럼 트랙 합산 |
| Bass | 베이스 기타·신스 베이스 | 저역대 기준 |
| Keys/Synth | 피아노·패드·신스리드·스트링 | 하모닉 파트 |
| Guitar | 일렉·어쿠스틱 기타 | 별도 분리도 가능 |
| Vocals | 메인 보컬 + 백보컬 | 메인·백보컬 분리 권장 |
| FX/Amb | 리버브 테일·환경음·특수 이펙트 | 공간감 파트 |

## 스템 렌더링 방법

### DAW에서 스템 렌더링 절차

1. 각 버스(Bus) 채널에 스템 그룹 배정
   - 드럼 트랙 전체 → Drum Bus
   - 보컬 트랙 전체 → Vocal Bus

2. 마스터 채널 이펙트 바이패스
   - 마스터 리미터·컴프레서 OFF
   - 마스터 EQ OFF
   (마스터링 엔지니어가 별도 처리)

3. 각 버스를 솔로(Solo)로 렌더링
   - 포맷: WAV 24bit 44.1kHz 또는 48kHz
   - 길이: 모든 스템 동일한 길이로 렌더링
   - 오프셋: 프로젝트 0:00 시작점 통일

4. 파일명 규칙
   아티스트명_곡명_Drums.wav
   아티스트명_곡명_Bass.wav
   아티스트명_곡명_Vocals.wav
   ...

## 풀 믹스 마스터링 vs 스템 마스터링

| 항목 | 풀 믹스 마스터링 | 스템 마스터링 |
|------|--------------|------------|
| 비용 | 낮음 | 높음 |
| 수정 범위 | 전체 음색·음압 조정 | 파트별 독립 조정 가능 |
| 믹스 수정 | 불가 | 제한적으로 가능 |
| 납품 요구 | 일반 상업 음원 발매 | 방송·광고·라이브 리믹스 |
| 파일 수 | 1개 (스테레오 WAV) | 6~10개 + 마스터 |

## 스템 마스터링 처리 순서

### 각 스템별 처리

1. 하이패스/로우패스 EQ (스펙트럼 충돌 방지)
2. 멀티밴드 컴프레서 (파트별 다이나믹)
3. 스테레오 이미저 (공간 배치 확인)

### 마스터 버스 처리

4. 마스터 EQ (전체 음색 균형)
5. 마스터 컴프레서 (글루 컴프레싱)
6. 리미터 (음압 확보, True Peak -1dBFS)

### 스트리밍 납품 기준

- **LUFS**: -14 LUFS (스포티파이·유튜브 표준)
- **True Peak**: -1dBFS 이하
- **포맷**: WAV 24bit 44.1kHz

## 마치며

스템 마스터링은 믹스에 대한 추가 컨트롤이 필요한 프로젝트에 효과적입니다. 스템 렌더링에서 가장 흔한 실수는 각 스템의 시작 오프셋이 서로 다른 것입니다. 모든 스템은 반드시 프로젝트 0:00 지점에서 시작해 동일한 길이로 렌더링해야 합니다. 그래야 마스터링 엔지니어가 모든 스템을 DAW에 불러왔을 때 자동으로 정렬되어 즉시 작업을 시작할 수 있습니다. 또한 마스터 채널의 리미터와 컴프레서를 모두 바이패스한 상태에서 렌더링해야 마스터링 엔지니어의 처리 공간이 확보됩니다.

드라이(이펙트 없는) 스템과 웻(이펙트 포함) 스템 중 어떤 것을 납품할지는 의뢰 목적에 따라 다릅니다. 방송·광고처럼 자체 리믹스가 필요한 경우에는 드라이 스템이 필요하고, 단순 음압 조정이 목적이라면 웻 스템으로 충분합니다. 납품 전 마스터링 엔지니어와 스템 구성·포맷·이펙트 포함 여부를 사전에 확인하면 불필요한 재납품을 방지할 수 있습니다.
