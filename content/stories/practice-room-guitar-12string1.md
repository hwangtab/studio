# 12현 기타·코러스 효과·Roger McGuinn 스타일 — 음악연습실 완전 가이드

12현 기타(12-String Guitar)는 **6현 기타의 모든 현에 옥타브 또는 유니즌 현을 더한 악기**입니다. 두 배의 현이 만드는 자연적인 코러스(chorus) 효과와 풍부한 배음은 The Byrds의 Roger McGuinn, Led Zeppelin의 Jimmy Page가 록 역사에 刻印했습니다. 하나의 현 대신 두 개의 현이 동시에 울릴 때 생기는 미세한 음정 차이가 코러스의 마법을 만듭니다.

---

## 12현 기타의 구조

### 6현과의 차이

**12현 기타 현 배치:**
```
1번 현 쌍: E + E (유니즌: 같은 음높이)
2번 현 쌍: B + B (유니즌)
3번 현 쌍: G + G (유니즌)
4번 현 쌍: D + D 옥타브 위 (옥타브 쌍)
5번 현 쌍: A + A 옥타브 위 (옥타브 쌍)
6번 현 쌍: E + E 옥타브 위 (옥타브 쌍)
```

**코러스 효과의 원리:**
```
유니즌/옥타브 현들 사이의 미세한 음정 차이
= 자연적인 코러스/플랜저 효과
= 풍부하고 반짝이는 음색
```

### 어쿠스틱 vs 일렉 12현

**어쿠스틱 12현:**
```
기타 보디가 더 강하게 제작 (현 장력 두 배)
자연적 공명 풍부
포크·컨트리·록에 사용
```

**일렉 12현:**
```
Roger McGuinn의 Rickenbacker 12현
= Byrds의 "jangly" 사운드
```

## Roger McGuinn 스타일

### The Byrds의 종 소리

Roger McGuinn(The Byrds):
- **Rickenbacker 360/12:** 12현 일렉기타
- **픽 연주:** 강한 어택으로 종 소리
- **5현 밴조 핑거픽 스타일 통합**

**"Turn! Turn! Turn!" 인트로:**
```
G-D-Em-C 진행 위
12현의 링잉 톤
픽으로 강하게 스트로크
= The Byrds의 시그니처 사운드
```

**"Mr. Tambourine Man":**
```
D 튜닝의 12현
아르페지오 + 스트로크 혼합
= 미국 포크 록의 원형
```

---

## Jimmy Page 스타일

### Led Zeppelin의 12현

Jimmy Page(Led Zeppelin):
- **"Stairway to Heaven" 인트로:** 어쿠스틱 12현
- **핑거피킹:** 섬세한 핑거피킹 + 12현의 풍부함
- **라이브 확장:** 12현 파트가 밴드 사운드를 완성

**"Stairway to Heaven" 인트로 포지션:**
```
Am 자리 핑거피킹 (카포 없이)
오르내리는 베이스 라인
12현이 만드는 신비로운 배음
= 록 기타 역사 최고의 인트로
```

## 12현 기타 연주 기법

### 튜닝과 스트링 장력

**12현 튜닝의 어려움:**
```
12개의 현 모두 정확히 튜닝
유니즌 현: 정확히 같게
옥타브 현: 정확히 1옥타브 위
= 튜닝이 6현보다 3배 어려움
```

**스트레칭:**
```
새 현은 항상 늘어남 (스트레치)
12현 기타는 시간이 더 걸림
= 연주 전 충분히 스트레칭
```

### 코드 연주

**12현 기타 코드:**
```
6현과 동일한 코드 폼 사용
하지만 넥 폭이 더 넓음
= 손가락 바레가 더 어려움
```

**파워 코드 12현:**
```
5도 파워 코드만으로도 12현의 웅장함
오픈 코드: G·D·Em·C = 최적
= 개방현이 많을수록 12현 효과 극대화
```

### 피킹 기법

**강한 픽 어택:**
```
12현은 강하게 쳐야 모든 현이 발음
너무 약하면 일부 현만 울림
= 일관된 강한 어택 필요
```

**핑거피킹:**
```
엄지: 6·5번 현 쌍 (베이스)
검지: 4번 현 쌍
중지: 3번 현 쌍
약지: 2번·1번 현 쌍
= 아르페지오로 각 현 쌍 독립적으로
```

## 대표 12현 기타 사운드

### 포크 록 사운드

**The Byrds 사운드:**
```
Rickenbacker 12현 + 클린 앰프
= "Jangle" 팝 사운드
```

**폴크 복고 12현:**
```
Martin D12-20 어쿠스틱
= 포크·컨트리의 풍성한 배음
```

### 록 12현 사운드

**Led Zeppelin:**
```
어쿠스틱 12현 + 클로즈업 마이킹
= 따뜻하고 풍성한 어쿠스틱 사운드
```

**The Eagles "Hotel California" (어쿠스틱 12현):**
```
인트로 어쿠스틱 12현 아르페지오
= 웅장한 배음의 호텔 캘리포니아
```

## 음악연습실 12현 기타 연습

### 60분 루틴

**1. 튜닝 + 현 점검 (10분)**
   - 12현 정확한 튜닝
   - 유니즌·옥타브 현 비교 확인
   - 현 스트레칭

**2. 오픈 코드 연습 (15분)**
   - G-D-Em-C 기본 코드
   - 스트로크로 12현 사운드 확인
   - 코러스 효과 느끼기

**3. 아르페지오 연습 (20분)**
   - Am-G-F-E 아르페지오 (Stairway 참고)
   - 핑거피킹으로 부드럽게
   - 12현의 배음 음색 표현

**4. 간단한 곡 연습 (15분)**
   - "Turn! Turn! Turn!" 진행
   - 스트로크 + 아르페지오 혼합
   - 12현 사운드의 전체적 표현

## 마무리

12현 기타는 **혼자서 코러스가 되는 악기**입니다. Roger McGuinn이 "12현은 종 소리와 기타가 하나 된 것"이라고 했듯, 두 배의 현이 만드는 자연 코러스는 어떤 이펙터도 흉내 내기 어렵습니다. G 코드 하나만으로도 왕관을 쓴 느낌의 풍성한 사운드가 나옵니다.
