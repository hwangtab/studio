## 하동에서 KTX로 서울까지

하동은 경남 서부 섬진강 변의 도시로, 순천 또는 진주를 경유해 KTX로 서울에 연결됩니다. 이동 시간이 길지만 당일 왕복이 가능합니다.

---

## 하동 → 연신내 이동 경로

### KTX 순천역 경유

입구 위치나 주차 정보가 필요한 경우 예약 전 문의해주시면 안내드립니다.

1. 하동 → 순천역 (버스 약 40~50분)
2. 순천역 KTX/SRT 탑승 (서울역 또는 수서역 방면, 약 2시간 30~40분)
3. 서울역/수서역 → 지하철 → 연신내역 (약 30~50분)

- **총 소요시간**: 약 3시간 40분~4시간 20분

### KTX 진주역 경유

1. 하동 → 진주역 (버스 약 40~50분)
2. 진주역 KTX 탑승 (서울역 방면, 약 2시간 30~40분)
3. 서울역 → 지하철 → 연신내역 (약 30~40분)

- **총 소요시간**: 약 3시간 40분~4시간 10분

---

## 당일 왕복 일정 예시 (하동 기준)

사전에 이동 경로를 확인해두면 첫 방문 시 헤매는 시간을 줄일 수 있습니다.

오전 5시 30분 하동 출발 → 순천역 이동
오전 6시 30분 순천역 KTX/SRT 출발
- 오전 9시 20분 서울 도착
- 오전 10시 연신내역 도착
- 오전 10시 30분 세션 시작 (2시간)
- 오후 12시 30분 세션 완료
- 오후 2시 서울 출발
- 오후 5시 10분 순천역 도착
- 오후 6시 하동 도착

## 하동 음악 씬과 서울 스튜디오

하동은 지리산·화개장터·섬진강으로 유명한 경남 소도시입니다. 진주역 KTX를 이용하거나 고속버스로 서울까지 이동합니다. 자연환경 속에서 음악 작업을 하는 싱어송라이터들이 서울 스튜디오를 활용합니다.

## 방문 전 세션 준비 가이드

1시간 30분 이상 이동 후 최상의 컨디션으로 세션에 임하려면 철저한 사전 준비가 필요합니다.

**출발 전 챙길 것:**
- [ ] 녹음할 곡의 가사·악보·MR 파일 (USB 또는 Google Drive)
- [ ] 원하는 사운드의 레퍼런스 트랙 2~3곡
- [ ] 예약 확인 캡처 + 교통편 티켓
- [ ] 보컬: 따뜻한 차·꿀물 보온병, 간식
- [ ] 귀마개 또는 노이즈캔슬링 이어폰 (이동 중 성대 보호)

**이동 중 활용법:**
- 이어폰으로 녹음할 곡 2~3회 예습
- 가사·감정 포인트 집중 정리
- 목·어깨 스트레칭 (장시간 이동 피로 완화)
- 충분한 수분 섭취 (기차 이동 중 성대 건조 방지)

**세션 팁:**
- 도착 후 20~30분 워밍업 시간 확보 (일정 계획 시 반드시 포함)
- 가장 중요한 구간을 세션 초반(이동 피로 전)에 먼저 녹음
- 원하는 사운드를 레퍼런스 곡으로 구체적으로 설명
- 온라인 파일 의뢰 서비스 병행 시 재방문 부담 최소화 가능

## 세션 당일 체크리스트

**전날:**
- [ ] MR·가사·레퍼런스 트랙 파일 최종 확인
- [ ] 교통편 티켓 + 예약 확인 캡처
- [ ] 충분한 수면 + 성대 무리 금지

**출발 전:**
- [ ] 따뜻한 차·꿀물 지참
- [ ] 이동 중 성대 보호 (소리 지르기 금지, 수분 섭취)

**도착 후:**
- [ ] 20~30분 워밍업 확보 (일정에 미리 포함)
- [ ] 엔지니어에게 레퍼런스·사운드 방향 설명
- [ ] 가장 어려운 구간 최우선 녹음

**녹음 중:**
- [ ] 헤드폰 볼륨 확인
- [ ] 테이크마다 즉시 청취
- [ ] 막차 시간 미리 확인 (귀가 일정)
