## 음악은 마음을 회복시키는 힘이 있습니다

현대인의 일상은 끊임없는 자극과 스트레스로 가득합니다. 음악은 그 안에서 마음을 회복하고 정서적 균형을 찾는 강력한 도구입니다.

음악이 마음을 치유하는 원리:
- **집중 전환**: 연주·노래에 집중하는 동안 걱정·불안에서 이탈
- **호흡 조절**: 노래의 복식 호흡 → 자율신경계 안정
- **감정 표현**: 음악을 통한 억압된 감정 해방
- **성취·즐거움**: 좋아하는 노래 연주 → 도파민·엔도르핀 분비

---

## 음악 힐링 유형별 연습 방법

### 감정 해방이 필요할 때
- 현재 감정과 일치하는 곡 선택 (슬픔·분노·우울)
- 감정을 담아 크게 노래하기
- 악기로 감정을 소리로 표현하기
- 완성도보다 표현 자체에 집중

### 마음을 안정시키고 싶을 때
- 느린 템포의 발라드·클래식 연주
- 깊은 복식 호흡을 의식하며 노래
- 반복적인 아르페지오·선율 연주
- 눈을 감고 음악에 집중

### 활력이 필요할 때
- 좋아하는 신나는 곡으로 시작
- 몸을 움직이며 리듬감 있게
- 좋아하는 아티스트 노래 커버
- 에너지 있는 연주로 무기력 극복

---

## 음악 힐링 공간의 조건

| 조건 | 필요한 이유 |
|-----|----------|
| 방음 | 타인의 시선·청취 없이 마음껏 표현 |
| 개인 공간 | 눈치 없이 감정을 자유롭게 드러냄 |
| 악기 구비 | 즉시 시작, 준비 불필요 |
| 언제든 접근 | 필요할 때 즉시 방문 가능 |
| 쾌적한 환경 | 냉난방·청결한 공간이 심리 안정 도움 |

---

## 스튜디오 놀 — 음악 치유·힐링 환경

| 항목 | 힐링 이용 가치 |
|-----|------------|
| STC 50+ 방음 | 완벽한 개인 공간, 외부 노출 없음 |
| 무인 운영 | 누군가의 시선 없이 감정 표현 자유 |
| 24시간 운영 | 힘든 순간 즉시 방문 가능 |
| 업라이트 피아노 | 터치로 감정을 표현할 수 있는 악기 |
| PA 스피커 | 좋아하는 노래 크게 틀고 함께 |
| 시간 대여 | 8,000~25,000원/시간 |
