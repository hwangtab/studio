# 기타 펜타토닉 고급·포지션 연결 — 음악연습실 완전 가이드

펜타토닉 스케일은 모든 장르에서 기타 즉흥연주의 기초입니다. 그러나 많은 기타리스트가 하나의 포지션에만 갇혀 "박스 패턴"만 반복합니다. 이 가이드에서는 5개 펜타토닉 포지션을 연결하고, 블루스 필과 벤딩으로 표현력을 극대화하는 방법을 안내합니다.

---

## 마이너 펜타토닉 5포지션

### A 마이너 펜타토닉 5포지션

**포지션 1 (박스 패턴 — 5프렛):**
```
e|--5--8--|
B|--5--8--|
G|--5--7--|
D|--5--7--|
A|--5--7--|
E|--5--8--|
```

**포지션 2 (7프렛):**
```
e|--8--10-|
B|--8--10-|
G|--7--9--|
D|--7--10-|
A|--7--10-|
E|--8--10-|
```

**포지션 3 (10프렛):**
```
e|--10-12-|
B|--10-13-|
G|--9--12-|
D|--10-12-|
A|--10-12-|
E|--10-12-|
```

**포지션 4 (12프렛):**

A|--12-14-|
E|--12-15-|

**포지션 5 (15프렛):**

A|--14-17-|

## 포지션 연결

### 가로 이동 기법

한 현 위에서 포지션을 가로로 이동:

```
E 현 기준 Am 펜타토닉:
5 - 8 - 10 - 12 - 15 - 17(같은 E)
(포지션 1)(2)(3)(4)(5)(옥타브)
```

**연습:**
```
E|--5-8-10-12-15-17--|  (상행 이동)
E|--17-15-12-10-8-5--|  (하행 이동)
```

### 대각선 이동

넥을 가로지르며 포지션 전환:

```
포지션 1→2 연결:
G|--5--7--9--7--|  (G현에서 7→9로 포지션 2 진입)
```

## 블루스 필 기법

### 블루스 노트(♭5) 추가

마이너 펜타토닉 + ♭5 = 블루스 스케일:

**Am 블루스 스케일 (포지션 1):**
```
e|--5--6--8--|  (6은 ♭5=Eb)
B|--5--6--8--|
G|--5--7-----|
D|--5--7-----|
A|--5--7-----|
E|--5--6--8--|
```

### 벤딩(Bending)

**기본 벤딩:**
- G현 7프렛(G)을 1음 위(A)까지 벤딩
- 오른쪽(넥 방향)으로 밀거나 왼쪽(바디 방향)으로 당김

**블루스 벤딩 패턴:**
```
1/4 벤딩: 살짝 올려 블루스 색채
1/2 벤딩: 반음 올림
1 벤딩: 온음 올림
오버벤딩: 1.5음 (고급)
```

### 비브라토

벤딩 후 손가락을 앞뒤로 흔들어 음을 떨리게:
```
음 → 벤딩 → 비브라토 (B.V.)
```

## 포지션 전환 프레이징

### 포지션 1→2 슬라이드

```
e|--5--8--sl10-12--|
    ↑     슬라이드
포지션1   포지션2로 이동
```

**슬라이드 기법:**
- 마지막 음에서 손가락 힘을 유지하며 미끄러짐

### 포지션 2→3 해머온

```
G|--9-h12--|
  포지션2→3 해머온으로 전환
```

## 음악연습실 펜타토닉 루틴

### 입문~중급 (60분)

**1. 5포지션 암기 (20분)**
- A 마이너 5포지션 각각 상하행
- BPM 70에서 안정화

**2. 가로 이동 훈련 (20분)**
- 한 현에서 5→17 전 포지션 이동
- BPM 80

**3. 블루스 느낌 즉흥 (20분)**
- Am 블루스 트랙에 맞춰 즉흥
- 포지션 1 + 블루스 노트 + 벤딩
