## 영월에서 KTX로 서울까지

영월은 강원도 남부 산간 도시로, 원주역 KTX를 통해 서울과 약 3시간대로 연결됩니다. 동강 래프팅과 단종 장릉으로 유명한 영월에서 오전 일찍 출발하면 당일 서울 스튜디오 방문이 가능합니다.

---

## 영월 → 연신내 이동 경로

### KTX 원주역 경유 (권장)

```
① 영월 → 원주역 (버스 약 1시간 30분)
② 원주역 KTX 탑승 (서울역 방면, 약 50분~1시간)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 3시간~3시간 40분
```

### 제천역 기차 경유 (선택)

```
① 영월 → 제천역 (버스 약 40~50분)
② 제천역 → 청량리역 (무궁화·ITX, 약 2시간~2시간 30분)
③ 청량리역 → 연신내역 (지하철 약 40분)

총 소요시간: 약 3시간 40분~4시간
```

## 당일 왕복 일정 예시 (영월 기준)

```
오전 6시 30분 영월 출발 → 원주역 이동
오전 8시 원주역 KTX 출발
→ 오전 9시 서울역 도착
→ 오전 9시 40분 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 서울역 출발
→ 오후 3시 원주역 도착
→ 오후 4시 30분 영월 도착
```
