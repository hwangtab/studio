## 담양에서 KTX로 서울까지

담양은 광주와 인접한 전남 북부 도시로, 광주송정역 KTX를 통해 서울과 약 2시간 20분대로 연결됩니다.

---

## 담양 → 연신내 이동 경로

### KTX 광주송정역 경유 (권장)

```
① 담양 → 광주송정역 (버스 약 30~40분)
② 광주송정역 KTX 탑승 (서울역 방면, 약 1시간 40~50분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 2시간 40~50분
```

---

## 당일 왕복 일정 예시 (담양 기준)

```
오전 7시 30분 담양 출발 → 광주송정역 이동
오전 8시 10분 광주송정역 KTX 출발
→ 오전 10시 서울역 도착
→ 오전 10시 40분 연신내역 도착
→ 오전 11시 세션 시작 (2시간)
→ 오후 1시 세션 완료
→ 오후 2시 30분 서울역 출발
→ 오후 4시 20분 광주송정역 도착
→ 오후 5시 담양 도착
```
