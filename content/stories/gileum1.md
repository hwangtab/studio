## 길음·정릉·삼선·성북에서 연신내 스튜디오 놀까지

서울 성북구(길음·정릉·삼선·성북)에서 4호선을 이용하면 연신내 스튜디오 놀까지 약 25~40분이면 도달합니다.

---

## 지역별 이동 경로

### 길음역 출발 (4호선)

```
[길음역 출발 (4호선)]
① 길음역(4호선) 탑승 (당고개 방면 → 남쪽)
② 성신여대입구역에서 6호선 환승
③ 6호선 → 연신내역

총 소요시간: 약 25~32분
```

### 성신여대입구역 출발 (6호선)

```
[성신여대입구역 출발 (6호선)]
① 성신여대입구역(4호선/6호선) 6호선 탑승
② 응암 방면으로 연신내역 도착

총 소요시간: 약 18~25분
```

### 한성대입구역 출발 (4호선)

```
[한성대입구역 출발 (삼선동 인근)]
① 한성대입구역(4호선) 탑승
② 성신여대입구역에서 6호선 환승
③ 6호선 → 연신내역

총 소요시간: 약 22~30분
```

## 성북구 지역별 소요 시간

| 출발지 | 경로 | 소요 시간 |
|--------|------|---------|
| 길음역 (4호선) | 4호선 → 성신여대 → 6호선 | 약 25~32분 |
| 성신여대입구역 (6호선) | 6호선 직통 | 약 18~25분 |
| 한성대입구역 (4호선) | 4호선 → 성신여대 → 6호선 | 약 22~30분 |
| 돈암역 (4호선) | 4호선 → 성신여대 → 6호선 | 약 22~28분 |
| 정릉동 | 마을버스 → 길음역 → 위 경로 | 약 35~45분 |

**스튜디오 주소**: 서울특별시 은평구 (연신내역 3번 출구 도보 5분)
