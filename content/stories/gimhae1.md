## 김해에서 부산역 KTX로 서울까지

김해는 부산과 인접한 경남 도시로, 부산역 KTX를 이용해 서울과 약 2시간 30분대로 연결됩니다. 부산-김해 경전철(BGL)을 활용하면 부산역까지 환승 없이 접근할 수 있습니다.

---

## 김해 → 연신내 이동 경로

### KTX 부산역 경유 (권장)

입구 위치나 주차 정보가 필요한 경우 예약 전 문의해주시면 안내드립니다.

1. 김해 시내 → 부산역 (BGL·버스·지하철 약 40~50분)
2. 부산역 KTX 탑승 (서울역 방면, 약 2시간 20~30분)
3. 서울역 → 지하철 → 연신내역 (약 30~40분)

- **총 소요시간**: 약 3시간 30~40분

### SRT 부산 수서역 경유

1. 김해 → 부산 부전역 또는 동부산 방면 이동
2. KTX-이음 또는 무궁화호로 환승
3. 수서역 도착 → 3호선 → 6호선 연신내역

※ KTX 부산역 경유가 더 빠르고 편리합니다

## 당일 왕복 일정 예시 (김해 기준)

네이버 지도 또는 카카오맵에서 '스튜디오 놀'을 검색하면 실시간 길 안내를 받을 수 있습니다.

오전 6시 김해 출발 → 부산역 이동
오전 7시 부산역 KTX 출발
- 오전 9시 30분 서울역 도착
- 오전 10시 10분 연신내역 도착
- 오전 10시 30분 세션 시작 (2시간)
- 오후 12시 30분 세션 완료
- 오후 2시 서울역 출발
- 오후 4시 30분 부산역 도착
- 오후 5시 20분 김해 도착

## 김해 음악 씬과 서울 스튜디오

김해는 가야왕도의 역사와 함께 부산 인근 위성 도시로 성장했습니다. 부산 동래·공항 인근에 위치해 KTX 부산역이나 김해공항을 이용해 서울까지 접근합니다.

## 방문 전 세션 준비 가이드

1시간 30분 이상 이동 후 최상의 컨디션으로 세션에 임하려면 철저한 사전 준비가 필요합니다.

**출발 전 챙길 것:**
- [ ] 녹음할 곡의 가사·악보·MR 파일 (USB 또는 Google Drive)
- [ ] 원하는 사운드의 레퍼런스 트랙 2~3곡
- [ ] 예약 확인 캡처 + 교통편 티켓
- [ ] 보컬: 따뜻한 차·꿀물 보온병, 간식
- [ ] 귀마개 또는 노이즈캔슬링 이어폰 (이동 중 성대 보호)

**이동 중 활용법:**
- 이어폰으로 녹음할 곡 2~3회 예습
- 가사·감정 포인트 집중 정리
- 목·어깨 스트레칭 (장시간 이동 피로 완화)
- 충분한 수분 섭취 (기차 이동 중 성대 건조 방지)

**세션 팁:**
- 도착 후 20~30분 워밍업 시간 확보 (일정 계획 시 반드시 포함)
- 가장 중요한 구간을 세션 초반(이동 피로 전)에 먼저 녹음
- 원하는 사운드를 레퍼런스 곡으로 구체적으로 설명
- 온라인 파일 의뢰 서비스 병행 시 재방문 부담 최소화 가능

## 세션 당일 체크리스트

**전날:**
- [ ] MR·가사·레퍼런스 트랙 파일 최종 확인
- [ ] 교통편 티켓 + 예약 확인 캡처
- [ ] 충분한 수면 + 성대 무리 금지

**출발 전:**
- [ ] 따뜻한 차·꿀물 지참
- [ ] 이동 중 성대 보호 (소리 지르기 금지, 수분 섭취)

**도착 후:**
- [ ] 20~30분 워밍업 확보 (일정에 미리 포함)
- [ ] 엔지니어에게 레퍼런스·사운드 방향 설명
- [ ] 가장 어려운 구간 최우선 녹음

**녹음 중:**
- [ ] 헤드폰 볼륨 확인
- [ ] 테이크마다 즉시 청취
- [ ] 막차 시간 미리 확인 (귀가 일정)

## 마치며

김해에서 부산역 KTX를 이용하면 약 3시간 30분대로 서울 연신내. 이동이 부담스럽다면 온라인 파일 의뢰를 추천합니다. 현지에서 드라이 보컬 WAV만 녹음해 보내주시면 믹싱·마스터링 후 납품합니다.
