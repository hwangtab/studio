## 평택에서 연신내 스튜디오 놀까지

경기도 평택시 지산동·서정동·안중읍·고덕면 지역에서 KTX·SRT 또는 1호선을 이용하면 서울 연신내 스튜디오 놀까지 약 1~1.5시간에 도달할 수 있습니다.

---

## 평택 → 연신내 이동 경로

### KTX·SRT 이용 (가장 빠른 경로)

```
[평택역·지제역 출발 (KTX·SRT)]
① 평택역(KTX) 또는 지제역(SRT) 탑승
② 서울역 또는 수서역 하차
③-A 서울역 → 경의중앙선 → DMC역 → 6호선 연신내역
③-B 수서역(SRT) → 3호선 환승 → 연신내역

서울역 경유: 총 약 1시간~1시간 10분
수서역 경유: 총 약 1시간 10분~1시간 20분
```

### 1호선 이용 (시간 여유 있을 때)

```
[평택역 출발 (1호선)]
① 평택역(1호선) 탑승
② 수원역 → 영등포역 방향 이동
③ 영등포역에서 경의중앙선 환승
   → 공덕 → 서강대 → DMC역
④ DMC역에서 6호선 환승
⑤ 수색 → 증산 → 새절 → 연신내역

총 소요시간: 약 1시간 30분~2시간
```

## 평택 지역별 소요 시간

| 출발지 | 경로 | 소요 시간 |
|--------|------|---------|
| 평택역 (KTX) | KTX → 서울역 → 경의중앙선 → DMC → 6호선 | 약 1시간~1시간 10분 |
| 지제역 (SRT) | SRT → 수서역 → 3호선 → 연신내역 | 약 1시간 10분~1시간 20분 |

| 안중·고덕 | 버스 → 평택역 → 상기 경로 | 약 1.5~2시간+ |
