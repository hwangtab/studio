## 뮤직비디오 — 음악을 시각으로 확장하는 콘텐츠

뮤직비디오는 음악에 시각적 스토리텔링을 더해 팬과의 접점을 넓히는 핵심 콘텐츠입니다. 스트리밍 시대에 유튜브·SNS 배포 가능한 MV는 아티스트 노출을 크게 높입니다.

---

## 뮤직비디오 유형별 특성

| 유형 | 특징 | 예산 |
|------|------|------|
| 퍼포먼스형 | 아티스트 노래·댄스 중심 | 저예산 가능 |
| 스토리형 | 서사·연기·장면 전환 | 중~고예산 |
| 라이릭 비디오 | 가사 자막 + 배경 이미지 | 최저예산 |
| 애니메이션 | 그래픽·일러스트 기반 | 제작비 별도 |
| 콘셉트형 | 색감·분위기 중심 비주얼 | 저~중예산 |

---

## 뮤직비디오 제작 단계

```
[1단계: 프리 프로덕션 (기획)]
① 곡 분석 — 주제, 감정, 분위기 키워드 추출
② 레퍼런스 MV 3~5개 수집 및 방향성 정의
③ 스토리보드 작성 — 장면별 구도·동선 스케치
④ 촬영 장소 섭외 (야외·스튜디오·카페·공원 등)
⑤ 출연자·스태프 섭외 및 일정 조율
⑥ 소품·의상 리스트 작성 및 준비
⑦ 음원 최종 마스터 파일 확보 (필수)

[2단계: 프로덕션 (촬영)]
① 촬영 당일 장소 셋업 (조명·배경·소품)
② 음원 재생 장비 확인 (블루투스 스피커·핀 마이크)
③ 카메라 세팅 (노출·초점·프레임 레이트)
④ 퍼포먼스 리허설 후 본촬영
⑤ 각 장면 다각도 촬영 (마스터샷·클로즈업·인서트)
⑥ 립싱크 정확도 확인하며 OK컷 선별

[3단계: 포스트 프로덕션 (편집)]
① 영상 소재 정리 및 컬러 그레이딩 (보정)
② 음원 싱크 맞추기
③ 컷 편집 — 음악 비트에 맞춰 장면 전환
④ 자막·그래픽 삽입 (라이릭 비디오 등)
⑤ 색보정 최종 확인
⑥ 마스터 파일 렌더링 (4K 또는 1080p)
```

## 저예산 MV 촬영 장비 가이드

```
[카메라]
- 스마트폰 최신 기종 (아이폰 Pro, 갤럭시 S Ultra)
  → 4K 촬영 가능, 짐벌 사용 시 흔들림 방지
- 미러리스 카메라 (Sony ZV-E10, Canon M50)
  → 얕은 피사계심도(보케) 효과

[조명]
- 자연광 활용 (골든 아워: 일출 후·일몰 전 1시간)
- LED 패널 조명 1~2개 (실내 보조 조명)
- 반사판으로 그림자 채우기

[안정화]
- 짐벌 (DJI OM6 또는 Ronin)
- 삼각대 (정적 장면)

[음원 재생]
- 블루투스 포터블 스피커
- 모니터 이어폰으로 싱크 확인
```

## 편집 소프트웨어

```
[무료]
- DaVinci Resolve — 전문급 컬러 그레이딩 가능
- CapCut — 모바일·PC, SNS 클립 편집에 적합

[유료]
- Adobe Premiere Pro — 업계 표준
- Final Cut Pro (Mac) — 빠른 렌더링
```

## 유튜브·SNS 배포 최적화

```
[유튜브 업로드]
- 해상도: 1080p (최소) / 4K (권장)
- 썸네일: 얼굴 클로즈업 + 곡명 텍스트 (CTR 높임)
- 제목: "[아티스트명] - [곡명] MV (Official Music Video)"
- 설명란: 가사, 크레딧, SNS 링크, 음원 링크 삽입
- 태그: 아티스트명 + 곡명 + "뮤직비디오" + 장르

[SNS 클립 편집]
- 인스타그램 릴스: 15~30초 하이라이트
- 틱톡: 훅(도입부) 15초 집중
- 유튜브 쇼츠: 세로형 편집 (9:16)
```
