## Logic Pro에서는 순서가 반이에요

Logic Pro는 기능이 많아서 처음엔 뭘 눌러야 할지부터 막막해질 수 있어요. 그런데 실제로는 복잡한 기술보다 순서가 더 중요합니다. 입력 장치가 제대로 잡혔는지, 버퍼를 지금 상황에 맞게 두었는지, 녹음 전에 레벨을 확인했는지 같은 기본 흐름이 흔들리면 뒤에서 EQ를 아무리 만져도 결과가 불안정해지거든요.

저도 처음엔 플러그인을 먼저 열어보곤 했어요. 그런데 그렇게 하면 오히려 중요한 걸 놓치더라고요. 녹음 준비 단계가 안정적이면 기본 플러그인만으로도 충분히 정돈된 결과를 만들 수 있습니다.

## 1. 오디오 설정부터 안정적으로 잡기

먼저 오디오 인터페이스가 Logic Pro에 제대로 연결됐는지 확인하세요.

1. 오디오 인터페이스를 Mac에 연결하기
2. `Logic Pro > Settings > Audio`에서 입력과 출력을 인터페이스로 지정하기
3. 마이크 입력이 어느 채널로 들어오는지 확인하기

샘플레이트는 보통 44.1kHz나 48kHz면 충분해요. 더 중요한 건 버퍼 설정입니다.

- 녹음 단계: 64~128 samples
- 편집이나 믹싱 단계: 256~512 samples

녹음 중 레이턴시가 거슬리면 버퍼를 낮추고, 플러그인이 많아져서 재생이 버벅이면 다시 올리는 식으로 생각하면 됩니다.

## 2. 트랙을 만들고 레벨을 먼저 보기

새 오디오 트랙을 만든 뒤에는 바로 녹음 버튼을 누르기보다 입력 레벨을 먼저 확인하는 편이 좋아요. 보컬 피크가 너무 높으면 금방 클리핑이 나고, 너무 낮으면 나중에 올릴 때 노이즈가 같이 따라옵니다.

보통은 피크가 `-12dBFS`에서 `-6dBFS` 사이에 들어오도록 잡으면 무난해요. 여기서 중요한 건, 잘 들어온 소리가 좋은 출발점이라는 점입니다. EQ나 컴프레서는 나중 이야기예요.

다이렉트 모니터링이 가능한 인터페이스라면 그 기능을 먼저 써보세요. 소프트웨어 모니터링만으로 듣다가 레이턴시 때문에 박자가 흔들리는 경우가 의외로 많거든요.

## 3. 기본 EQ는 많이 더하기보다 덜어내기

Logic Pro의 Channel EQ는 충분히 강력해요. 다만 처음부터 큰 폭으로 올리기보다, 먼저 거슬리는 부분을 덜어낸다는 느낌으로 접근하는 편이 자연스럽습니다.

출발점으로는 이런 정도면 충분해요.

- 80~100Hz 아래를 가볍게 정리하기
- 200~300Hz 부근이 탁하면 조금만 깎아보기
- 1~3kHz에서 말소리 명료도가 필요한지 들어보기
- 10kHz 근처는 공기감을 더할 때만 소폭 조정하기

EQ는 정답보다 비교가 중요해요. 켰을 때보다 껐을 때가 더 자연스러우면, 이미 많이 건드린 것일 수도 있습니다.

## 4. 컴프레서는 소리를 누르기보다 정리한다고 생각하기

컴프레서를 처음 쓰면 "얼마나 세게 걸어야 하지?"부터 궁금해지죠. 그런데 보컬에서는 크게 눌러서 단단하게 만드는 것보다, 튀는 부분을 정리해서 듣기 편하게 만드는 쪽이 더 중요해요.

시작값으로는 아래처럼 가볍게 잡아보세요.

- Ratio: 3:1 안팎
- Attack: 10~20ms
- Release: 80~120ms
- Gain Reduction: 대체로 -3~-6dB 안팎

압축이 많이 걸릴수록 안정감은 생기지만, 동시에 답답함도 같이 생깁니다. 그래서 수치보다도 "숨이 너무 앞으로 튀지 않는가", "후렴이 눌려서 납작해지지 않는가"를 귀로 확인하는 편이 더 중요합니다.

## 5. Flex Pitch는 교정보다 정리에 가깝게 쓰기

Flex Pitch는 아주 편리하지만, 많이 쓸수록 자연스러움이 줄어들기도 해요. 특히 처음엔 모든 음을 정가운데로 끌고 가고 싶어지는데, 그렇게 하면 목소리의 표정까지 같이 사라지는 경우가 있습니다.

그래서 보통은 이런 기준으로 접근하면 무난해요.

- 분명하게 흔들린 음부터 먼저 보기
- 길게 유지되는 음의 끝부분이 밀리는지 확인하기
- 교정 강도를 한 번에 끝까지 올리지 않기
- 수정 전후를 반복해서 들어보기

완벽하게 맞추는 것보다, 어색하지 않게 정리하는 것이 훨씬 오래 들어도 편합니다.

## 6. 파일 내보내기는 다음 작업자를 생각하면서

혼자 끝낼 작업이 아니라면 Bounce 단계가 꽤 중요해요. 믹싱 의뢰용 파일이라면 플러그인을 많이 얹은 버전보다, 정리되지 않은 드라이 파일이 오히려 더 안전한 경우가 많습니다.

보통은 이렇게 준비하면 충분해요.

- WAV 형식
- 24bit
- 44.1kHz 또는 48kHz
- 반주 파일도 같이 정리하기
- 파일 이름을 곡명과 버전 기준으로 분명하게 적기

나중에 다시 열었을 때도 바로 알 수 있게 정리해두면, 수정 과정이 훨씬 덜 꼬입니다.
