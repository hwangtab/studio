# 베이스 재즈 베이스·스윙 그루브 — 음악연습실 완전 가이드

재즈 베이스는 단순한 리듬 악기가 아닙니다. 재즈 베이시스트는 **화성을 이끌고, 스윙을 만들고, 솔리스트와 대화**합니다. 팝·록 베이스가 루트 중심의 패턴을 반복한다면, 재즈 베이스는 매 마디마다 새로운 선율을 즉흥으로 만들어냅니다. 이 가이드에서는 재즈 베이스의 핵심—워킹 베이스라인과 스윙 그루브—을 체계적으로 안내합니다.

---

## 스윙 필의 이해

### 스윙 8분음표

재즈의 핵심은 **스윙 필**입니다. 악보에 적힌 두 개의 8분음표는 실제로는 점8분음표+16분음표(약 2:1 비율)로 연주됩니다.

**스윙 느낌의 핵심 요소:**
- **긴-짧음 패턴**: 박의 앞부분을 길게, 뒷부분을 짧게
- **업비트 강조**: 4박 계열보다 2박·4박 업비트에 중점
- **릴랙스된 타이밍**: 정확한 박보다 약간 뒤에서 끌어당기는 느낌

**연습 방법:**
```
4/4박자 스윙 카운트:
1 -  and -  2 -  and -  3 -  and -  4 -  and
긴 짧   긴 짧   긴 짧   긴 짧

```

음악연습실 메트로놈으로 스윙 필을 몸에 익힐 때는 BPM 60부터 시작해 3박, 4박의 업비트를 발로 가볍게 탭하며 연습합니다.

### 고스트 노트와 타이밍

재즈 베이스의 스윙감은 **고스트 노트**에서도 나옵니다. 완전히 들리지 않는 짧고 가벼운 터치—이 노트들이 그루브에 숨결을 불어넣습니다.

---

## 워킹 베이스라인 구축

### 기본 원칙

워킹 베이스라인은 **코드 진행 위에서 매 박을 걸으며(walking) 진행**하는 선율입니다.

**4가지 음표 유형:**
1. **코드 톤**: 루트, 3도, 5도, 7도 (가장 안전한 선택)
2. **스케일 패싱 톤**: 코드 톤 사이를 연결하는 음
3. **크로매틱 어프로치**: 목표음 반음 위·아래에서 진입
4. **텐션 노트**: 9th, 11th, 13th (조심스럽게 사용)

### C 장조 II-V-I 워킹 베이스라인

재즈에서 가장 중요한 진행은 **투파이브원(II-V-I)**입니다.

**Dm7 - G7 - Cmaj7 예시 (4/4박자):**

```

Dm7: D - F - A - C
G7: G - B - D - F
Cmaj7: C - E - G - E

```

**크로매틱 버전:**
```

Dm7: D - F - Ab - A (크로매틱 어프로치)
G7: G - F# - F - E (크로매틱 하강)
Cmaj7: C - B - Bb - A (계속 하강)

```

---

## 핵심 재즈 스탠다드 패턴

### Autumn Leaves (오텀 리브스)

재즈 베이시스트의 필수 레퍼토리. G 단조 버전:

**Am7♭5 - D7 - Gm:**
```

Am7b5: A - C - Eb - G
D7: D - F# - A - C
Gm: G - Bb - D - F

```

음악연습실에서 이 곡을 연습할 때 핵심은 **코드 변화를 미리 예측**하는 것입니다. 현재 코드의 마지막 박에서 다음 코드의 루트로 크로매틱 어프로치하면 자연스러운 흐름이 생깁니다.

### Fly Me to the Moon

C 장조의 II-V-I 연속:

```

Am7 → Dm7 → G7 → Cmaj7 → ...

```

**워킹 베이스 접근:**
- 각 코드의 루트에서 시작
- 3도, 5도, 7도로 상행
- 다음 코드 루트로 크로매틱 접근

---

## 투파이브원 심화

### 메이저 II-V-I

**Dm7 - G7 - Cmaj7:**
```

D 도리안 → G 믹소리디안 → C 이오니안

```

**베이스 라인 선택 원칙:**
- Dm7에서 D-F-A-C (도리안 코드 톤)
- G7에서 G-B-D-F (도미넌트 7th)
- Cmaj7에서 C-E-G-B (메이저 7th)

### 마이너 II-V-I

**Dm7♭5 - G7alt - Cm:**
```

D 로크리안 → G 얼터드 → C 하모닉 마이너

```

G7alt에서 베이스는 ♭9, ♯9, ♭5(=♯11), ♭13 텐션을 활용합니다. 음악연습실에서 피아노와 함께 연습하면 얼터드 사운드를 귀로 익히기 훨씬 쉽습니다.

## 재즈 스타일별 베이스 접근

### 스윙 재즈 (Swing Jazz)

**특징:**
- 4비트 워킹 베이스가 기본
- 스윙 8분음표 강조
- 더블베이스의 아르코(활) 사운드 참고

**연습 패턴:**
```
♩ ♩ ♩ ♩ (매 박 걷기)
스윙 필로 연주

```

### 쿨 재즈 (Cool Jazz)

**특징:**
- 박을 살짝 뒤에서 끌어당김 (laid-back)
- 더 적은 음표, 더 많은 공간
- 고스트 노트 활용

### 보사노바

**특징:**
- 8분음표 기반의 시노코파도 리듬
- 루트-5도 패턴 중심
- 라틴 퍼커션과 맞추는 2박자 감각

**기본 보사노바 베이스 패턴:**
```

Cmaj7: C - - - G - - -
       1   2   3   4

```

## 음악연습실 재즈 베이스 연습 루틴

### 기초 단계 (60분)

**1. 워밍업 - 스케일 & 아르페지오 (10분)**
- 모든 조성의 메이저/마이너 스케일
- 7th 코드 아르페지오 (루트 포지션, 전위형)

**2. 워킹 베이스 기초 (20분)**
- C 장조 II-V-I 워킹 라인
- BPM 60-80 메트로놈과 함께

**3. 스탠다드 곡 연습 (20분)**
- Autumn Leaves 또는 All the Things You Are
- 리드 시트 보며 코드 따라가기

**4. 음원 따라 연주 (10분)**
- Ray Brown, Paul Chambers, Scott LaFaro 음원 참고

### 중급 단계

- 전조(모달 II-V-I)
- 솔로 베이스 편곡
- 얼터드 스케일 활용
- 리듬 섹션 연동 (피아노·드럼 합주)

## 마무리

재즈 베이스의 핵심은 **듣기**입니다. 코드 변화를 듣고, 솔리스트의 프레이징을 듣고, 드럼의 스윙을 들으며 대화하는 것—이것이 재즈 베이스의 본질입니다.

워킹 베이스라인은 악보를 외우는 것이 아닙니다. 화성의 논리를 이해하고 그 안에서 즉흥적으로 선율을 만드는 능력입니다. 은평구 24시간 음악연습실에서 충분한 시간을 들여 귀와 손을 동시에 훈련하세요.
