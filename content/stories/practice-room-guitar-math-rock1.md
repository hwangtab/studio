# 수학록 기타·폴리리듬·Animals as Leaders·Don Caballero 스타일 — 음악연습실 완전 가이드

수학록 기타(Math Rock Guitar)는 **복잡한 박자 변형, 폴리리듬, 비정규 박자를 사용하는 현대 기타 스타일**입니다. Tosin Abasi(Animals as Leaders)의 8현 기타 타핑, Don Caballero의 복잡한 인터로킹 기타, Polyphia의 테크니컬 팝 기타 — 이들이 수학록의 지적 아름다움을 보여줍니다.

---

## 수학록이란?

### 음악과 수학의 만남

**수학록의 특징:**
```
비정규 박자 (5/4, 7/8, 11/8 등)
폴리리듬: 여러 리듬이 동시에
복잡한 리프 인터로킹
감성보다 구조적 복잡함 추구
```

**수학록 밴드:**
```
Animals as Leaders: 8현 기타 폴리리듬
Polyphia: 테크니컬 팝 + 수학록
Don Caballero: 포스트록 수학 선구자
Tera Melos: 익스페리멘탈 수학록
```

---

## 비정규 박자 (Odd Time Signatures)

### 수학록의 기초

**5/4 박자:**
```
"1-2-3-4-5" = 5박자
= 왈츠(3/4) + 2/4 박자
Dave Brubeck "Take Five" 유명
```

**7/8 박자:**
```
"1-2-3-4-5-6-7" (8분음표)
= 3+2+2 또는 2+2+3 분할
= 조금 이상하게 느껴지는 박자
```

**11/8 박자:**
```
= 3+2+3+3 또는 4+3+4 분할
= 극단적으로 불규칙한 느낌
```

**말로 외우기:**
```
5/4: "이게 뭔지 알-겠-어" (5음절)
7/8: "이게 뭔지 알-겠-니" (7음절)
```

---

## 폴리리듬 기타

### 두 가지 리듬 동시에

**3:2 폴리리듬 기타:**
```
상현(고음): 3분할 패턴
하현(저음): 2분할 패턴
= 동시에 다른 리듬
```

**4:3 폴리리듬 리프:**
```
상현: 4분할 반복 리프
하현: 3분할 반복 리프
= 두 리프가 다른 속도로
```

**Tosin Abasi 스타일:**
```
8현 기타 저음으로 리듬 패턴
상현으로 멜로디 또는 타핑
= 한 기타로 두 가지 폴리리듬
```

---

## Animals as Leaders 스타일

### 8현 기타의 폴리리듬

**Tosin Abasi 기법:**
```
섬핑(Thumping): 엄지로 저음 현 두드리기
타핑: 두 손으로 지판 두드리기
폴리리듬: 두 손이 다른 리듬
= 완전히 새로운 기타 패러다임
```

**"CAFO" 스타일 리프:**
```
저음 현: 싱코페이션 섬핑
고음 현: 빠른 타핑 멜로디
= 드럼 + 멜로디를 한 기타로
```

**8현 기타 활용:**
```
7현, 8현: 더 낮은 음역 (B, F#)
다운 튜닝: 더 무거운 사운드
= 기타 + 베이스의 역할 동시에
```

## 인터로킹 기타 (Interlocking Guitar)

### 두 기타가 퍼즐처럼

**인터로킹 패턴:**
```
기타 A: 1박에 음
기타 B: 기타 A가 쉬는 곳에 음
= 두 파트가 합쳐져야 완성
```

**Don Caballero 인터로킹:**
```
두 기타가 서로 빈 자리를 채움
= 마치 하나의 드럼 패턴처럼
```

**연습 방법:**
```
기타 A 파트 혼자 연습 → 이상하게 들림
기타 B 파트 혼자 연습 → 이상하게 들림
합치면 완성 → 아하!
```

## Polyphia 스타일

### 테크니컬 팝 수학록

Polyphia:
- **팝 멜로디 + 복잡한 박자**
- **깨끗한 기타 톤**: 일렉 기타 클린
- **핑거스타일**: 픽 없이 손가락 + 타핑

**"G.O.A.T." 스타일:**
```
7/8 박자 기반
클린 아르페지오 + 타핑 멜로디
= 아름다운 수학록
```

## 음악연습실 수학록 기타 연습

### 60분 루틴

**1. 비정규 박자 기초 (15분)**
   - 5/4박자 박수 치기 ("이게 뭔지 알겠어")
   - 7/8박자 박수 치기
   - 메트로놈과 함께 각 박자 확인

**2. 5/4 리프 연습 (15분)**
   - 5박자 기타 리프 만들기
   - 한 코드로 5박자 느낌 찾기
   - ♩= 80에서 반복

**3. 폴리리듬 기초 (15분)**
   - 상현 2분할 + 하현 3분할
   - 각각 독립적으로 먼저
   - 합쳐서 폴리리듬 확인

**4. 수학록 곡 분석 (15분)**
   - Animals as Leaders 또는 Polyphia 트랙 선택
   - 박자 구조 파악
   - 느리게 따라 연주

## 마무리

수학록 기타는 **논리와 감성이 만나는 지점**입니다. Tosin Abasi가 "수학적 구조 안에서도 감동이 있어야 한다"고 했듯, 복잡한 폴리리듬 안에서도 음악적 표현이 살아있어야 합니다. 5/4 박자 한 마디가 자연스럽게 느껴질 때, 수학록의 세계로 들어갑니다.

은평구 24시간 음악연습실에서 5/4박자 박수 치기부터 시작하세요. 이상한 박자가 자연스러워지는 순간, 수학록의 아름다움이 시작됩니다.
