## 상계·중계·하계·공릉에서 연신내 스튜디오 놀까지

노원구 동부 지역(상계·중계·하계·공릉)에서 지하철로 45~55분이면 연신내 스튜디오 놀에 도달합니다.

---

## 지역별 이동 경로

### 상계역 출발 (4호선)

### 상계역 출발 (4호선)

1. 상계역(4호선) 탑승 (당고개 방면이 아닌 노원 방면)
2. 노원역 → 계속 4호선 남하
3. 동대문역사문화공원역에서 6호선 환승
4. 6호선 → 연신내역

- **총 소요시간**: 약 40~50분

### 중계·하계역 출발 (7호선)

### 하계역·중계역 출발 (7호선)

1. 하계역 또는 중계역(7호선) 탑승
2. 태릉입구역 방면 이동
3. 태릉입구역에서 6호선 환승
4. 6호선 → 연신내역

- **총 소요시간**: 약 45~55분

### 공릉역 출발 (7호선)

### 공릉역 출발 (7호선)

1. 공릉역(7호선) 탑승
2. 태릉입구역에서 6호선 환승
3. 6호선 → 연신내역

- **총 소요시간**: 약 40~45분

---

## 노원구 동부 지역별 소요 시간

| 출발지 | 경로 | 소요 시간 |
|--------|------|---------|
| 상계역 (4호선) | 4호선 → 동대문역사문화공원 → 6호선 | 약 40~50분 |
| 중계역 (7호선) | 7호선 → 태릉입구 → 6호선 | 약 50~55분 |
| 하계역 (7호선) | 7호선 → 태릉입구 → 6호선 | 약 45~55분 |
| 공릉역 (7호선) | 7호선 → 태릉입구 → 6호선 | 약 40~45분 |
| 수락산역 (7호선) | 7호선 → 태릉입구 → 6호선 | 약 55~60분 |

**스튜디오 주소**: 서울특별시 은평구 연신내역 인근 (연신내역 3번 출구 도보 5분)

## 온라인 의뢰 서비스

| 서비스 | 내용 |
|--------|------|
| 파일 전달 | 드라이 보컬 WAV + MR 카카오톡 전송 |
| 믹싱·마스터링 | 전문 엔지니어 작업 후 완성 파일 납품 |
| 수정 | 2라운드 수정 포함 |
| 소요 시간 | 2~5일 (협의) |

## 마치며

상계·중계·하계·공릉에서 지하철 40~55분 방문 전 카카오톡으로 예약 시간을 먼저 잡아두시면 대기 없이 바로 세션에 들어갈 수 있습니다.
