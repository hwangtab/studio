# 포스트록 기타·빌드업·Explosions in the Sky·Mogwai 스타일 — 음악연습실 완전 가이드

포스트록 기타(Post-Rock Guitar)는 **가사 없이 기타의 음색과 다이나믹만으로 감동적인 이야기를 만드는 음악**입니다. Explosions in the Sky의 에픽 빌드업, Mogwai의 조용함에서 폭발로 가는 여정, Godspeed You! Black Emperor의 오케스트라 같은 기타 — 포스트록은 록 기타의 가장 시적인 형태입니다.

---

## 포스트록이란?

### 가사 없는 록의 감동

**포스트록의 특징:**
```

보컬 없음 (인스트루멘탈)
긴 곡 구조 (5~15분 이상)
조용함 → 폭발 → 다시 조용함 (빌드업)
앰비언트 이펙터 많이 사용

```

**포스트록 대표 밴드:**
```

Explosions in the Sky: 텍사스 에픽 포스트록
Mogwai: 스코틀랜드 다이나믹 포스트록
Godspeed You! Black Emperor: 캐나다 오케스트라 포스트록
Sigur Rós: 아이슬란드 앰비언트 포스트록

```

---

## 빌드업 구조

### 포스트록의 핵심 형식

**전형적인 빌드업:**
```

Intro (조용히): 클린 아르페지오, pp
Rising (점점): 레이어 추가, 드럼 시작
Climax (폭발): 풀 디스토션, ff
Outro (해소): 다시 조용히, pp
= 감정의 파도

```

**빌드업 요소:**
```

다이나믹: pp → ff → pp
레이어: 기타 1 → 기타 2 추가 → 베이스 → 드럼
이펙터: 클린 → 오버드라이브 → 디스토션

```

---

## Explosions in the Sky 스타일

### 텍사스 에픽 포스트록

Explosions in the Sky:
- **두 대의 기타:** 대화하듯 인터플레이
- **모달 코드:** Csus2, Amsus4 등 서스펜드 코드
- **긴 빌드업:** 10분 이상의 감정 여정

**"Your Hand in Mine" 스타일:**
```

시작: 클린 기타 아르페지오 (pp)
중간: 두 번째 기타 추가 (mp)
클라이맥스: 풀 디스토션 + 드럼 (ff)
= 10분의 감동적인 여정

```

**서스펜드 코드 활용:**
```

Csus2: C-D-G (3도 없음)
Amsus4: A-D-E (3도 없음)
= 장조도 단조도 아닌 모호한 아름다움

```

---

## Mogwai 스타일

### 조용함에서 폭발로

Mogwai:
- **극단적 다이나믹:** 거의 무음 → 귀청 찢을 듯 폭발
- **피드백 활용:** 앰프 피드백을 음악으로
- **미니멀 멜로디:** 단순하지만 감동적

**Mogwai 다이나믹 기법:**
```

볼륨 노브: 0으로 시작 → 갑자기 10
= 청중이 예상 못하는 폭발

```

**피드백 제어:**
```

기타를 앰프 앞에 세우기
피드백 음을 음악의 일부로
= 소음이 음악이 되는 순간

```

---

## 포스트록 기타 이펙터

### 레이어 쌓기

**필수 이펙터:**
```

딜레이: 반복음으로 공간 채우기
리버브: 큰 공간감 (홀, 플레이트)
디스토션/퍼즈: 클라이맥스 폭발
볼륨 페달: 볼륨 스웰

```

**포스트록 딜레이 세팅:**
```

딜레이 타임: 400~800ms
피드백: 60~80% (오래 반복)
믹스: 50% (원음 + 반복음 동등)

```

**루프 페달 활용:**
```

코드 1 루프 → 코드 2 루프 추가
= 두 기타 없이 혼자 레이어

```

---

## 클린 아르페지오 기초

### 포스트록의 시작

**모달 아르페지오:**
```

Am: A-C-E
Csus2: C-D-G
G: G-B-D
Fsus2: F-G-C
= 서스펜드 코드로 모호한 아름다움

```

**8분음표 아르페지오:**
```

낮은 현부터 높은 현까지 올라가기
= 맑고 선명한 포스트록 인트로

```

---

## 음악연습실 포스트록 기타 연습

### 60분 루틴

**1. 아르페지오 인트로 (15분)**
   - Csus2-Amsus4-Fsus2-G 진행
   - 클린 톤, 리버브 깊게
   - 볼륨 스웰 적용

**2. 레이어 빌드업 연습 (15분)**
   - 코드 1 루프 녹음
   - 그 위에 멜로디 추가
   - 점점 많은 레이어

**3. 클라이맥스 디스토션 (15분)**
   - 디스토션 파워 코드
   - 풀 볼륨으로 클라이맥스
   - 감정 최고조 표현

**4. 전체 빌드업 즉흥 (15분)**
   - pp에서 ff까지 자유롭게
   - 5~10분 포스트록 즉흥
   - 음악이 이야기를 만들게

## 마무리

포스트록 기타는 **말보다 더 많은 것을 말하는 음악**입니다. Explosions in the Sky가 "우리 음악은 가사 없이도 충분히 말한다"고 했듯, 올바른 다이나믹과 빌드업이 있으면 기타 하나가 소설 한 편을 쓸 수 있습니다. 조용히 시작해서 폭발하고 다시 사라지는 그 여정이 포스트록입니다.

은평구 24시간 음악연습실에서 Csus2 아르페지오부터 시작하세요. 볼륨 스웰이 공간을 채우는 순간, 포스트록의 세계가 펼쳐집니다.

---

일렉트릭 기타에서 피킹 각도와 깊이는 톤에 직접적인 영향을 미칩니다. 픽을 줄에 대해 약간 비스듬히 잡으면 마찰음이 줄고 부드러운 톤을 얻을 수 있습니다. 얼터네이트 피킹을 정확하게 구현하기 위해 느린 BPM에서 다운·업 스트로크를 교대하는 훈련이 필수적입니다. 이펙터 조합을 다양하게 실험해보면 오버드라이브, 딜레이, 리버브 등 각 이펙트가 사운드에 미치는 영향을 직접 파악할 수 있습니다. 앰프 볼륨과 이펙터 레벨의 적절한 조화를 찾는 과정이 자신만의 톤을 만들어갑니다. 음악 연습의 질을 높이는 데 있어 녹음은 매우 강력한 도구입니다. 스마트폰으로 간단히 녹음한 뒤 나중에 들어보면 연주 중에는 미처 인식하지 못했던 리듬 불안정, 음정 이탈, 다이나믹 부재 등을 객관적으로 파악할 수 있습니다. 자신의 연주를 비판적으로 분석하는 능력이 쌓일수록 효율적인 자기 교정이 가능해집니다. 연습실의 앰프나 모니터 스피커를 통해 자신의 소리를 명확하게 듣는 환경을 만드는 것도 중요합니다.
