# 기타 이코노미 피킹·스위핑 기초 — 음악연습실 완전 가이드

기타 속주 테크닉 중에서 이코노미 피킹(Economy Picking)과 스윕 피킹(Sweep Picking)은 동작의 효율성을 극대화하는 기법입니다. 얼터네이트 피킹이 현을 위아래로 번갈아 치는 것이라면, 이코노미 피킹은 "같은 방향으로 넘어가는 현은 계속 같은 방향으로 쓸어주는" 방식입니다. 이 원칙에서 나오는 스윕 피킹은 빠른 아르페지오 연주의 필수 테크닉입니다.

---

## 이코노미 피킹이란

### 기본 원리
얼터네이트 피킹에서는 6번 현에서 5번 현으로 이동할 때, 현행 피킹 방향과 관계없이 방향을 바꿔서 칩니다.

이코노미 피킹에서는 다른 현으로 넘어갈 때 **자연스러운 방향(같은 방향)**으로 넘어갑니다.

**예시:**
- 6번 현을 다운(↓)으로 치고, 5번 현으로 이동 → 자연스럽게 다운(↓)으로 이동하여 스윕
- 이 동작은 피크가 한 번의 쓸어내림으로 두 현을 차례로 치는 것

### 얼터네이트 피킹과의 차이
| 항목 | 얼터네이트 피킹 | 이코노미 피킹 |
|-----|-------------|------------|
| 현 이동 시 방향 | 반드시 반대 방향 | 같은 방향으로 스윕 |
| 균일성 | 완전 균일 | 스윕 구간 별도 처리 |
| 속도 한계 | 높음 | 더 높음 (스윕 구간) |
| 아르페지오 | 복잡 | 자연스러운 스윕 |

---

## 스윕 피킹이란

스윕 피킹(Sweep Picking)은 이코노미 피킹의 극단적인 형태로, 여러 현을 한 번의 "쓸어내림/올림" 동작으로 차례로 치는 것입니다.

**키 포인트:**
- 각 현이 동시에 울리지 않고 **순차적으로** 울려야 함
- 스윕하는 동안 왼손은 이미 친 현의 음을 뮤트하며 다음 현으로 이동
- 결과: 빠른 아르페지오 효과

### 왼손과 오른손의 동기화
스윕 피킹에서 가장 어려운 부분은 **왼손과 오른손의 완벽한 동기화**입니다.

오른손이 스윕하는 속도와 왼손이 프렛을 짚는 속도가 정확히 일치해야 합니다. 이보다 빠르거나 느리면 음이 뭉개지거나 소음이 납니다.

---

## 기초 스윕 피킹 연습

### 1단계: 3현 스윕
가장 기본적인 3현 스윕입니다. C 메이저 아르페지오 형태를 사용합니다.

```
3현 C 메이저 아르페지오 (낮은 포지션):
4번 현: 3프렛 (C)
3번 현: 2프렛 (E)
2번 현: 1프렛 (G)
```

다운 스윕: 4번 → 3번 → 2번 현을 아래 방향으로 쓸어내림
업 스윕: 2번 → 3번 → 4번 현을 위 방향으로 쓸어올림

**핵심 체크:**
- 각 음이 선명하게 독립적으로 들리는지
- 음이 뭉개지지 않는지
- 왼손이 직전 현을 뮤트하며 다음 현으로 이동하는지

### 2단계: 5현 스윕
5개 현으로 확장합니다. Am 아르페지오를 사용합니다.

```
Am 아르페지오 (개방 포지션):
6번 현: 0 (A)
5번 현: 0 (A)
4번 현: 2프렛 (E)
3번 현: 2프렛 (A)
2번 현: 1프렛 (C)
```

동일한 방향으로 쓸어내린 후 방향 전환하여 다시 올라옵니다.

---

## 이코노미 피킹 스케일 연습

스케일에서 이코노미 피킹을 적용하면 더 유동적인 연주가 가능합니다.

**E 마이너 펜타토닉 이코노미:**
```
6번 현: D(↓) E(↑)
5번 현: A(↓) B(↑) - 6번 현에서 5번 현 이동 시 다운(↓)으로 스윕
4번 현: D(↓) E(↑) - 5번 현에서 4번 현 이동 시 다운(↓)으로 스윕
```

현 이동 시 항상 방향 전환 없이 같은 방향으로 이어집니다.

## 스윕 피킹을 사용하는 기타리스트

### Yngwie Malmsteen
네오 클래식 메탈의 거장으로, 스윕 피킹을 클래식 아르페지오에 결합한 스타일을 완성했습니다.

### Frank Gambale
재즈 기타리스트로, 이코노미 피킹 이론을 체계화하고 교육 자료로 발전시켰습니다.

### Jason Becker
단명했지만 기술적으로 가장 정교한 스위퍼 중 한 명으로 평가받습니다.

## 단계별 연습 루틴

### 초급 (첫 달)
- 3현 스윕 BPM 60에서 정확성 훈련
- 왼손 뮤트 동작 집중 연습
- 단일 방향(다운만) 스윕 마스터

### 중급 (2~3개월)
- 5현 스윕 확장
- 업 스윕 추가
- 다운-업 연속 스윕

### 고급 (4개월 이후)
- 6현 전체 스윕
- 스케일에 이코노미 피킹 적용
- 실제 솔로에서 스윕 삽입
