## 수원 구도심에서 연신내 스튜디오 놀까지

경기도 수원시 장안구·팔달구·권선구(수원역 인근, 화서동, 정자동, 조원동) 지역에서 1호선을 이용하면 서울 연신내 스튜디오 놀까지 약 70~90분에 도달할 수 있습니다.

## 수원 장안·팔달·권선 → 연신내 이동 경로

### 1호선 + 경의중앙선 + 6호선 (추천)

### 수원역·화서역 출발 (1호선)

1. 수원역 또는 화서역(1호선) 탑승
2. 1호선 서울 방면 이동
   수원 → 화서(또는 역순)
  - 성균관대 → 의왕 → 군포
  - 금정 → 명학 → 안양 → 관악
  - 석수 → 금천구청 → 독산
  - 가산디지털단지 → 구로 → 신도림
  - 영등포역 하차
3. 영등포역에서 경의중앙선 환승
   (수색·DMC 방면)
4. 당산 → 가양 → 수색 → DMC역 하차
5. DMC역에서 6호선 환승
6. 수색 → 증산 → 새절 → 응암 → 역촌
  - 불광 → 연신내역 하차

**단순 경로 요약**
수원역(1호선) → 영등포역(경의중앙선 환승)
- DMC역(6호선 환승) → 연신내역
- **총 소요시간**: 약 75~90분
