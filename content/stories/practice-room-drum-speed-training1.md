# 드럼 스피드 트레이닝·빠른 싱글 스트로크 — 음악연습실 완전 가이드

드럼에서 속도는 단순히 빠르게 치는 것이 아닙니다. **효율적인 스트로크, 올바른 리바운드 활용, 근육 이완**이 조화를 이룰 때 자연스럽게 속도가 올라갑니다. 이 가이드에서는 과학적으로 검증된 스피드 향상 방법을 안내합니다.

---

## 속도의 기초 원리

### 왜 빠르게 치기 어려운가?

**속도를 방해하는 요소:**
1. **근육 긴장**: 힘을 쓸수록 느려짐
2. **비효율적 스트로크**: 에너지 낭비
3. **리바운드 미활용**: 스틱의 튕김을 억제
4. **잘못된 손목 각도**: 관절 효율 저하

**속도의 실제 원천:**
- 힘이 아닌 **이완(relaxation)**
- 스틱 리바운드의 **활용**
- 손가락 제어를 통한 **세밀한 스트로크**

---

## Moeller 방법론

### 모엘러 스트로크란?

Albert Moeller가 개발한 기법으로, **스틱의 관성과 채찍 동작**을 결합합니다.

**3단계 동작:**
1. **업 스트로크 준비**: 팔꿈치를 들어 스틱을 높이 올림
2. **채찍 모션**: 손목을 아래로 빠르게 채찍질
3. **리바운드 활용**: 스틱이 튕겨 올라오는 것을 활용

**결과:** 한 번의 팔 동작에서 2-3개의 음표 생성 가능

### 모엘러 연습

```
느린 동작부터:
팔 올리기 → 채찍 아래로 → 리바운드 → 손가락으로 추가 스트로크
```

---

## 핑거 기법 (Finger Control)

### 왜 손가락인가?

빠른 속도에서 손목보다 손가락이 더 효율적:
- 손목보다 질량이 작음 = 더 빠른 동작 가능
- 스틱 끝 제어가 정밀함
- 피로도 감소

### 핑거 기법 훈련

**기본 핑거 훈련:**
```
1. 스틱을 엄지-검지 사이에 가볍게
2. 중지-약지-소지로 스틱 끝을 밀어 내림
3. 리바운드로 스틱이 올라오면 손가락 받기
4. 반복 — 손목은 거의 움직이지 않음
```

**속도 한계 극복:**
손목으로 더 빠르게 치기 어려울 때 핑거 기법으로 전환

---

## 싱글 스트로크 롤 속도 향상

### 3단계 속도 향상법

**1단계: 편안한 속도 찾기**
```
현재 가장 편안한 최고 속도 확인
그 속도 -20 BPM에서 연습 시작
```

**2단계: 점진적 증가**
```
매주 2-3 BPM 증가
편안함을 유지하며 올리기
```

**3단계: 한계 돌파 훈련**
```
최고 속도 +10 BPM에서 10-15초 버티기
다시 편안한 속도로 내려오기
이 반복이 한계를 넓힘
```

---

## 핫 롤 기법

매우 빠른 롤을 위한 손목-손가락 조합:

**프리 스트로크 롤:**
```
처음엔 손목으로 시작
점점 빨라지면 자동으로 손가락으로 전환
손이 빨라지면 그 흐름에 맡기기
```

---

## 스틱 선택과 속도

### 무게와 속도의 관계

**가벼운 스틱 (5A, 7A):**
- 빠른 속도에 유리
- 음량 작음

**무거운 스틱 (2B, 5B):**
- 음량 크고 파워풀
- 빠른 속도에 더 많은 힘 필요

**연습:** 가볍고 → 무겁고 (무거운 스틱으로 연습하면 가벼운 스틱이 더 쉽게 느껴짐)

## 음악연습실 스피드 루틴

### 45분 루틴

**1. 손목 워밍업 (5분)**
- 천천히 리스트 롤
- BPM 60에서 싱글 스트로크

**2. 핑거 기법 훈련 (15분)**
- 기본 핑거 컨트롤 패드 연습
- 손목 없이 손가락만으로 롤

**3. 싱글 스트로크 롤 스피드 (20분)**
- BPM 80 → 100 → 120 점진
- 모엘러 스트로크 적용

**4. 쿨다운 (5분)**
- 매우 느리게 (BPM 40)
- 손목, 손가락 스트레칭

## 마무리

드럼 속도는 **노력이 아닌 이완에서 나옵니다**. 힘을 쓸수록 느려지고, 이완할수록 빨라지는 역설이 드럼 스피드의 핵심입니다.
