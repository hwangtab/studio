## 충주에서 KTX로 서울까지

충주는 충북 북부 도시로, 오송역 KTX를 통해 서울과 약 2시간대로 연결됩니다. 사과와 충주호, 탄금대로 유명한 충주에서 당일 서울 스튜디오 방문이 가능합니다.

---

## 충주 → 연신내 이동 경로

### KTX 오송역 경유 (권장)

```
① 충주 → 오송역 (버스 약 1시간)
② 오송역 KTX 탑승 (서울역 방면, 약 30~40분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 2시간~2시간 30분
```

### 충주역 기차 경유 (선택)

```
① 충주역 → 청량리역 (무궁화·ITX-새마을, 약 2시간~2시간 30분)
② 청량리역 → 지하철 → 연신내역 (약 40분)

총 소요시간: 약 2시간 40분~3시간 20분
```

## 당일 왕복 일정 예시 (충주 기준)

```
오전 7시 30분 충주 출발 → 오송역 이동
오전 8시 30분 오송역 KTX 출발
→ 오전 9시 10분 서울역 도착
→ 오전 9시 50분 연신내역 도착
→ 오전 10시 세션 시작 (2시간)
→ 오후 12시 세션 완료
→ 오후 2시 서울역 출발
→ 오후 2시 40분 오송역 도착
→ 오후 3시 40분 충주 도착
```

## 온라인 파일 의뢰 서비스

```
충주 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
