## 부천시 원미구 상동·중동에서 연신내 스튜디오 놀까지

경기도 부천시 원미구 상동·중동·춘의·도당 지역에서 7호선을 이용하면 환승 없이 연신내역까지 직통으로 약 55~68분에 도달할 수 있습니다.

---

## 상동·중동·춘의 → 연신내 이동 경로

### 7호선 직통 경로 (추천)

1. 상동역·부천시청역·춘의역(7호선) 탑승 — 도봉산 방면
2. 7호선 → 광명사거리 → 온수 → 철산 → 가산디지털단지
3. → 대림 → 남구로 → 이수 → 내방 → 고속터미널
4. → 반포 → 학동 → 강남구청 → 어린이대공원
5. → 군자 → 중곡 → 용마산 → 면목 → 사가정
6. → 중화 → 먹골 → 태릉입구 → 공릉 → 하계
7. → 중계 → 노원 → 마들 → 상계 → 당고개 ← (도봉산 방면 아님!)
- ⚠️ 도봉산 방면 7호선이 아닌 **연신내 방면** 탑승

**실제 경로**
1. 상동역(7호선) 탑승 — 부평구청 방면이 아닌 도봉산·장암 방면
2. 고속터미널 → 이수 → 내방 → 반포 구간 지나
3. ... → 태릉입구 → 노원 → 당고개 ...
- ⚠️ 7호선은 연신내역을 통과하지 않습니다.

**실제 올바른 경로**
1. 상동역(7호선) → 가산디지털단지 → 대림 → 이수 → 고속터미널 → 강남구청 방면
2. 고속터미널역에서 3호선 또는 9호선으로 환승
3. 또는 이수역에서 4호선 → 동대문역사문화공원 → 6호선 연신내역
- **소요**: 약 65~80분

### 1호선 + 6호선 경로 (부천역 이용)

1. 부천역(1호선) 탑승 — 서울 방면
2. 1호선 → 동대문역사문화공원역 하차
3. 동대문역사문화공원역 → 6호선 환승
4. 연신내역 하차
- **소요**: 약 60~75분

| 춘의역 (7호선) | 7호선 이수 → 4호선 → 동대문역사문화공원 → 6호선 | 약 65~80분 |

## 마치며

부천 원미구에서 1호선 또는 7호선으로 약 65~80분이면 연신내에 도착합니다. 방문이 어려운 경우 온라인 믹싱·마스터링 의뢰도 가능합니다. 카카오톡으로 문의하시면 맞춤 안내를 드립니다. 세션 일정은 카카오톡으로 미리 조율해주세요. 도착 전 워밍업 시간을 여유 있게 잡는 걸 권장합니다.

### 자주 있는 추가 질문 모음

녹음 외적인 실무 관련 문의를 모아두었습니다.

- **인접 지역에서도 방문 가능한가요?** → 네, 부천시 뿐 아니라 인근 시·군에서 오시는 분들도 많이 이용하고 계십니다.
- **단체 녹음이 가능한가요?** → 듀엣·트리오 단위 보컬 녹음은 가능하며, 밴드 합주 녹음은 사전 협의 후 별도 패키지로 안내드립니다.
- **결제 방식은 어떻게 되나요?** → 현금, 카드, 카카오페이, 계좌이체가 모두 가능합니다.
- **세금계산서·현금영수증 발급되나요?** → 네, 사전 요청 시 세금계산서 및 현금영수증 발급이 가능합니다.
- **세션 시간 조정이 가능한가요?** → 부천시에서 이동 시간이 길어질 수 있는 분들은 사전 협의 시 시작 시간을 유연하게 조정해드립니다.

### 방문 전에 꼭 확인할 사항

당일 현장에서 보정이 어려운 항목 위주로 체크리스트를 정리했습니다.

- **예약**: 카카오톡 채널 또는 contact 페이지로 사전 예약해주세요. 평일 오전~오후 시간대가 비교적 한산합니다.
- **MR 파일**: WAV 또는 고음질 MP3(320kbps 이상)를 권장합니다. USB 드라이브나 카카오톡으로 미리 전송 가능합니다.
- **가사**: 출력본을 지참하시거나 스마트폰에 PDF로 저장해두시면 세션 진행이 매끄럽습니다.
- **컨디션**: 전날 충분한 수면과 수분 섭취, 당일 음주·과식·찬 음료는 피해주세요.
- **이동 여유**: 부천시에서 출발하실 경우 약 63분 + 준비 시간 15분, 총 78분 여유를 두시면 안정적입니다.

### 녹음 이후 유통·발매 옵션

부천시 지역 활동 계획이 있다면, 발매 단계까지 염두에 두고 녹음 포맷을 선택하시는 것을 권장합니다.

- **국내 발매 플랫폼**: 멜론, 지니, 바이브, 플로, 카카오뮤직 등에 유통할 수 있습니다.
- **글로벌 플랫폼**: 스포티파이, 애플뮤직, 아마존뮤직, 유튜브뮤직 등 해외 스트리밍으로 확장 가능합니다.
- **유통 대행사**: Distrokid, Tunecore, Amuse, LOEN(멜론뮤직), (주)포크라노스 등에서 발매 대행 서비스를 이용할 수 있습니다.
- **드라이 보컬만 반출**: 보컬 트랙만 WAV로 받아가서 외부 엔지니어에게 믹싱·마스터링을 의뢰하는 것도 가능합니다.
- **풀 패키지 의뢰**: 스튜디오 놀에서 녹음·편곡·믹싱·마스터링을 한 번에 진행하면 톤과 밸런스가 일관되게 유지됩니다.
- **부천시 활동 연결**: 지역 공연·콘텐츠 제작과 맞물려 발매 일정을 잡으면 홍보 효율이 높아집니다.

### 연신내역에서 스튜디오 놀까지

부천시에서 오신 분들이 자주 헷갈리는 출구 이슈를 먼저 짚어드립니다.

- **하차역**: 서울 지하철 6호선 연신내역 (3호선 환승역), 4번 출구에서 도보 약 5분 거리입니다.
- **현지 도보 경로**: 부천시에서 7호선을(를) 이용해 도착하신 분들이 자주 이용하는 경로로, 출구 이후 직진 → 첫 사거리 우회전 방향입니다.
- **입구**: 스튜디오 입구는 역 인근 건물 내부에 위치하며, 방문 당일 안내된 동 호수 / 층 정보를 참고해주세요.
- **주변 인프라**: 도보 5분 이내에 카페, 편의점, 간단한 식사가 가능한 매장이 다수 있어 세션 전후 이용에 편리합니다.
- **야간 방문**: 6호선 연신내역은 새벽 시간대까지 운행되지만, 귀가 시 부천시 방향 막차 시간을 미리 확인해주세요.
