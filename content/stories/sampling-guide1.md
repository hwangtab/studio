## 샘플링 — 기존 소리로 새 음악 만들기

샘플링은 힙합·일렉트로닉·로파이의 핵심 제작 기법입니다. 저작권 안전하게 사용하는 방법부터 실전 편집 기법까지 정리합니다.

---

## 샘플 유형별 분류

| 샘플 유형 | 설명 | 활용 |
|-----------|------|------|
| 루프 (Loop) | 반복 가능한 4~8마디 패턴 | 비트 기반, 배경 레이어 |
| 원샷 (One-Shot) | 단발성 사운드 (킥, 스네어, 심벌) | 드럼 프로그래밍 |
| 보컬 초프 | 보컬 한 음절~단어 | 멜로디·리듬 샘플 |
| 텍스처 | 앰비언트·노이즈 레이어 | 분위기 형성 |

---

## 샘플링 저작권 가이드

소셜 미디어 전략은 릴리즈 최소 4주 전부터 준비하는 것이 효과적입니다.

### 합법적 샘플링 방법

1. 샘플 클리어런스 (Sample Clearance)
- 원저작자·음반사에 허가 취득
- 로열티 계약 체결
- 상업적 사용 가능

2. 로열티 프리 샘플팩 사용
- Splice, Looperman, Sample Magic
- 구매/구독 후 상업적 사용 가능
- 단, 샘플팩 자체 재판매 금지

3. 직접 녹음한 샘플
- 본인이 연주·녹음한 소리
- 저작권 문제 없음
- 가장 독창적인 사운드 가능

### 주의 사항

- 저작권 해제 표시 없는 음원 직접 샘플링 금지
- 유튜브 무료 다운로드 ≠ 저작권 해제
- 1~2초 샘플도 저작권 침해 가능

---

## 초퍼(Chopper) 기법 실전

플랫폼마다 정책이 다르므로 각 플랫폼의 최신 가이드라인을 직접 확인하세요.

### 기본 초퍼 워크플로우 (FL Studio 기준)

1. 샘플 임포트
- Edison 또는 Playlist에 오디오 드래그

2. 슬라이싱 (Slicing)
- Edison에서 비트·트랜지언트 마다 자르기
- Slice X 또는 DirectWave에 패드 매핑

3. 재배열 (Rearranging)
- 패드를 새 순서로 배치
- 피치 조정, 리버스 적용

4. 효과 적용
- 피치시프트, 타임스트레치
- 필터, 새추레이션으로 질감 변형
- 볼륨 오토메이션으로 그루브 형성

## DAW별 샘플 편집 도구

계약서의 세부 조항을 꼼꼼히 확인하는 습관이 장기적으로 큰 손실을 막아줍니다.

### Ableton Live

- **Simpler / Sampler**: 원샷·루프 편집
- **Drum Rack**: 드럼 패드 매핑
- **Warp**: 타임스트레치·피치시프트
- **Slice to MIDI**: 자동 슬라이싱

### FL Studio

- **Edison**: 오디오 편집
- **Slice X**: 패드 슬라이싱
- **Fruity Slicer**: 자동 비트 슬라이싱

### Logic Pro

- EXS24 / Quick Sampler
- **Flex Time**: 타임스트레치
- Drum Machine Designer

### MPC (하드웨어)

- 힙합 샘플링의 클래식 도구
- 16패드 + 내장 시퀀서

## 추천 샘플팩 소스

| 소스 | 가격 | 특징 |
|------|------|------|
| Splice | 월 구독 | 최대 라이브러리, 장르별 분류 |
| Looperman | 무료 | 커뮤니티 업로드, 로열티 프리 |
| Sample Magic | 유료 | 전문 스튜디오 품질 |
| LANDR Samples | 월 구독 | AI 추천 샘플 |
| Cymatics | 무료+유료 | 트랩·팝 특화 |

## 마치며

샘플링은 저작권을 지키며 창의적으로 활용하는 것이 핵심입니다. 로열티 프리 샘플팩을 기반으로 초퍼·루프 기법을 연습하면 독창적인 사운드를 빠르게 만들 수 있습니다.
