## 샘플링 — 기존 소리로 새 음악 만들기

샘플링은 힙합·일렉트로닉·로파이에서 자주 쓰이는 핵심 제작 기법입니다. 저작권을 안전하게 처리하는 방법부터 실전 편집 기법까지 정리합니다.

샘플링의 역사는 1970년대 브롱크스 DJ 문화에서 시작됩니다. DJ Kool Herc는 1973년 파티에서 두 레코드 플레이어로 동일한 바이닐을 번갈아 틀어 브레이크 비트를 무한 반복하는 "Merry-Go-Round" 기법을 개발했고, 이것이 힙합 샘플링의 원형입니다. 1980년대 MPC(MIDI Production Center)가 등장하면서 레코드에서 루프를 잘라 재배열하는 초퍼 기법이 체계화됐고, Pete Rock과 DJ Premier는 소울·재즈 레코드의 드럼 브레이크와 멜로디 훅을 정밀하게 편집해 1990년대 힙합 황금기를 만들었습니다. J Dilla는 MPC3000으로 완벽한 타이밍 정렬 대신 의도적인 타이밍 편차를 만들어 "살아 숨쉬는" 그루브를 구현했으며, 이 "루즈 그루브" 미학은 현재 로파이·네오소울 프로덕션의 표준이 됩니다. 저작권 측면에서는 Biz Markie의 1991년 패소(O'Sullivan 곡 무단 샘플링)를 계기로 미국 법원이 모든 상업 샘플링에 사전 클리어런스를 요구하는 기준을 세웠고, 이후 2013년 Splice 플랫폼의 등장으로 로열티 프리 샘플팩 시장이 민주화됐습니다.

## 샘플 유형별 분류

| 샘플 유형 | 설명 | 활용 |
|-----------|------|------|
| 루프 (Loop) | 반복 가능한 4~8마디 패턴 | 비트 기반, 배경 레이어 |
| 원샷 (One-Shot) | 단발성 사운드 (킥, 스네어, 심벌) | 드럼 프로그래밍 |
| 보컬 초프 | 보컬 한 음절~단어 | 멜로디·리듬 샘플 |
| 텍스처 | 앰비언트·노이즈 레이어 | 분위기 형성 |

## 샘플링 저작권 가이드

### 합법적 샘플링 방법

1. 샘플 클리어런스 (Sample Clearance)
- 원저작자·음반사에 허가 취득
- 로열티 계약 체결
- 상업적 사용 가능
2. 로열티 프리 샘플팩 사용
- Splice, Looperman, Sample Magic
- 구매/구독 후 상업적 사용 가능
- 단, 샘플팩 자체 재판매 금지
3. 직접 녹음한 샘플
- 본인이 연주·녹음한 소리
- 저작권 문제 없음
- 가장 독창적인 사운드 가능

### 주의 사항

- 저작권 해제 표시 없는 음원 직접 샘플링 금지
- 유튜브 무료 다운로드 ≠ 저작권 해제
- 1~2초 샘플도 저작권 침해 가능

---

## 초퍼(Chopper) 기법 실전

### 기본 초퍼 워크플로우 (FL Studio 기준)

1. 샘플 임포트
- Edison 또는 Playlist에 오디오 드래그
2. 슬라이싱 (Slicing)
- Edison에서 비트·트랜지언트 마다 자르기
- Slice X 또는 DirectWave에 패드 매핑
3. 재배열 (Rearranging)
- 패드를 새 순서로 배치
- 피치 조정, 리버스 적용
4. 효과 적용
- 피치시프트, 타임스트레치
- 필터, 새추레이션으로 질감 변형
- 볼륨 오토메이션으로 그루브 형성

## DAW별 샘플 편집 도구

### Ableton Live

- **Simpler / Sampler**: 원샷·루프 편집
- **Drum Rack**: 드럼 패드 매핑
- **Warp**: 타임스트레치·피치시프트
- **Slice to MIDI**: 자동 슬라이싱

### FL Studio

- **Edison**: 오디오 편집
- **Slice X**: 패드 슬라이싱
- **Fruity Slicer**: 자동 비트 슬라이싱

### Logic Pro

- EXS24 / Quick Sampler
- **Flex Time**: 타임스트레치
- Drum Machine Designer

### MPC (하드웨어)

- 힙합 샘플링의 클래식 도구
- 16패드 + 내장 시퀀서

## Studio NOL 보컬 녹음에서 보컬을 샘플 소스로 활용할 때 자주 보는 3가지

스튜디오 놀에서 녹음된 보컬을 샘플 소스로 활용·납품할 때 자주 점검하는 영역입니다.

**1. 클린 보컬 별도 녹음 — Wet 처리 없이 드라이 보존**

보컬을 샘플로 재활용하려면 리버브·딜레이가 적용되지 않은 클린 드라이 보컬을 별도 트랙으로 보존해야 합니다. 믹스에서 효과를 추가하기는 쉽지만, 한 번 들어간 효과를 제거하는 것은 불가능에 가깝습니다.

**2. 무지향성(omni) 마이크로 룸 톤 함께 캡처**

샘플 활용 시 보컬 외의 룸 톤(공간감)이 자연스럽게 섞이면 분위기가 풍부해집니다. 메인은 카디오이드로, 보조 마이크는 옴니로 같은 부스 안에서 동시 녹음해 두면 후처리 단계에서 룸 톤을 선택적으로 블렌드할 수 있습니다.

**3. 가사 없는 음절·허밍·리프 별도 녹음**

본 곡 가사 외에 "doo·wah·ahh" 같은 단순 음절·허밍·짧은 리프를 별도로 30~60초 녹음해 두면 향후 다른 곡에서 보컬 텍스처로 재활용할 수 있습니다. 발매 곡 가사를 다시 쓰는 것보다 라이선스가 깔끔합니다.

## 마치며

샘플링 제작에서 가장 실수하기 쉬운 지점은 로열티 프리 확인 없이 "무료 다운로드" 샘플을 상업적으로 사용하는 것입니다. 유튜브 무료 다운로드나 SoundCloud 무료 공개 파일은 저작권 해제가 아니며, Splice·Looperman처럼 명시적으로 "Royalty Free Commercial Use"가 표시된 플랫폼의 샘플만 상업 음원에 사용할 수 있습니다. 심지어 로열티 프리 샘플팩도 "샘플팩 자체의 재판매"나 "50% 이상 원본 유지"는 대부분 금지하므로, 초퍼로 충분히 변형하거나 다른 샘플과 레이어해 원본과 구별되도록 만드는 것이 안전합니다.

초퍼 기법의 핵심은 원본 리듬을 완전히 해체하는 데 있습니다. FL Studio Slice X나 Ableton Live의 Slice to MIDI 기능으로 트랜지언트마다 자동 슬라이싱한 뒤, 패드 순서를 재배열하고 각 슬라이스에 피치시프트·리버스·필터를 따로 적용하면 원본과 다른 리듬 패턴이 만들어집니다. 루프 BPM이 현재 프로젝트 템포와 다를 때는 타임스트레치 알고리즘(복잡한 소스에는 Complex 또는 Complex Pro, 단순 리듬에는 Beats 알고리즘)을 고르면 품질 손실 없이 템포를 맞출 수 있습니다.

## 샘플링은 "무료 다운로드"와 "저작권 해제"를 구분하는 데서 안전해져요

샘플링으로 사고가 나는 지점은 거의 하나예요. "무료로 받았으니 써도 되겠지" 하는 오해. 유튜브 무료 다운로드나 사운드클라우드 공개 파일은 저작권이 풀린 게 아닙니다. 상업 음원에 안심하고 쓰려면 Splice·Looperman처럼 "Royalty Free Commercial Use"가 명시된 플랫폼 샘플이거나, 원저작자에게 클리어런스를 받았거나, 본인이 직접 녹음한 소리여야 해요. 1~2초짜리도 침해가 될 수 있으니 여기서만큼은 보수적으로 가세요.

로열티 프리 샘플도 그냥 통째로 얹으면 안 돼요. 대부분 "샘플팩 재판매"나 "원본 50% 이상 유지"를 금지하거든요. 그래서 초퍼로 충분히 해체하는 게 안전하면서도 창작적으로도 이득이에요. FL Studio Slice X나 Ableton의 Slice to MIDI로 트랜지언트마다 자동으로 자른 다음, 패드 순서를 새로 짜고 각 조각에 피치시프트·리버스·필터를 따로 걸면 원본과 전혀 다른 리듬이 나옵니다. 피치나 템포만 살짝 바꿔서 "안 걸리겠지" 하는 건 통하지 않아요—원곡이 인식되면 그건 여전히 침해예요.

루프 템포가 프로젝트와 안 맞을 땐 타임스트레치 알고리즘을 소스에 맞게 고르세요. 복잡한 멜로디 소스엔 Complex나 Complex Pro, 단순한 드럼엔 Beats 계열이 품질 손실이 적어요. J Dilla가 그랬듯 일부러 타이밍을 완벽하게 안 맞추면 오히려 살아 숨쉬는 그루브가 나오기도 하고요. 이렇게 만든 조각을 비트로 엮는 흐름은 [비트 메이킹 가이드](/stories/beatmaking1)에서 이어집니다.
