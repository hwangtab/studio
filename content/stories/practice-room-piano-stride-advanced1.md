# 피아노 스트라이드 고급 테크닉 — 음악연습실 완전 가이드

스트라이드 피아노는 **왼손이 오케스트라**인 양식입니다. 낮은 베이스 음에서 높은 코드로 도약하는 왼손이 베이스·드럼·하모니를 동시에 담당하며, 오른손은 그 위에서 자유롭게 멜로디와 즉흥연주를 펼칩니다. Art Tatum, Fats Waller, James P. Johnson의 전설적 스타일을 분석합니다.

---

## 스트라이드 피아노의 기본 구조

### 왼손 패턴

**기본 스트라이드 패턴:**
```

박자: 1 2   3 4
왼손: Bass High Bass High
      (낮음)(높음)(낮음)(높음)

```

**C 장조 기본 스트라이드:**
```
1박: C2 (베이스 단음)
2박: E3-G3-C4 (코드, 중간 음역)
3박: G2 (베이스 단음)
4박: E3-G3-C4 (코드, 중간 음역)

```

### 도약 거리

스트라이드에서 왼손은 보통:
- **1옥타브 이상** 도약
- 빠른 템포에서 정확한 도착
- 베이스 음과 코드 위치를 완벽히 암기

---

## 왼손 고급 테크닉

### 텐스 보이싱 (Tenths)

10도 간격(2옥타브-단3도)의 왼손 — Art Tatum의 핵심 기법.

**C7 코드 텐스 보이싱:**
```

저음: C2
고음: Bb3 (C에서 10도 위 — 단10도)

```

**텐스 진행 예 (C7 → F7):**
```

C2-Bb3 → F2-Eb3 → Bb1-Ab3 → Eb2-Db4

```

**텐스 연습법:**
1. 먼저 각 음을 나눠서 연습
2. 천천히 도약 정확도 확인
3. 메트로놈으로 점진적 속도 증가

### 왼손 독립 훈련

오른손 없이 왼손만 가지고:
- C 장조로 2분 스트라이드
- F, Bb 등 플랫 조성에서 반복
- 12개 모든 조성 마스터

---

## Art Tatum 스타일

### Tatum의 특징

미국 재즈 역사상 가장 빠르고 복잡한 피아니스트.

**핵심 요소:**
- **초고속 런**: 16분음표·32분음표 스케일 패시지
- **재하모니제이션**: 단순 코드를 복잡한 대리코드로
- **템포 변화**: 루바토로 시간을 자유롭게

**Tatum 풍 재하모니제이션 예 (G7 → C):**
```

원래: G7 → C
Tatum: Db7 → C (트리톤 대리) 또는
       Db7 - G7 - C (두 코드를 겹쳐서)

```

### 스트라이드 즉흥연주

**오른손 패시지 구성:**
1. 스케일 런 (C 메이저 스케일을 4옥타브로)
2. 코드 아르페지오
3. 크로매틱 경과음 삽입
4. 옥타브 멜로디

---

## Fats Waller 스타일

### 유머와 스윙

Fats Waller는 스트라이드에 **유머·인간미**를 담았습니다.

**특징:**
- 풍부하고 명확한 스트라이드 왼손
- 멜로디를 노래처럼 우아하게
- 라그타임에서 발전한 리듬감

**Waller 스타일 코드 보이싱:**
```

오른손: 5th 상단 보이싱 (C7 → E3-Bb3-C4)
왼손: C1 + G2-Bb2-E3 (도약 코드)

```

### Honeysuckle Rose 스타일 분석

```
||: C maj7 | A7 | Dm7 | G7 :||
스트라이드:
- C: C1 / E3-G3-C4 / G1 / E3-G3-C4
- A7: A1 / C#3-E3-G3 / E1 / C#3-E3-G3
- Dm7: D1 / F3-A3-C4 / A1 / F3-A3-C4
- G7: G1 / B2-F3-G3 / D1 / B2-F3-G3

```

---

## James P. Johnson 스타일

### 할렘 스트라이드의 아버지

**특징:**
- 강렬한 왼손 비트
- 신나는 리듬감 — 춤을 위한 피아노
- 블루스 색채가 강함

**12마디 블루스 스트라이드 (C 블루스):**
```

C7 | C7 | C7 | C7
F7 | F7 | C7 | C7
G7 | F7 | C7 | G7

```

각 코드를 스트라이드 패턴으로:

```

C7: C1 + (Bb2-E3-G3) / G1 + (Bb2-E3-G3)
F7: F1 + (Eb3-A3-C4) / C1 + (Eb3-A3-C4)
G7: G1 + (F3-B3-D4) / D1 + (F3-B3-D4)

```

---

## 스트라이드 발전 단계

### 1단계: 기본 스트라이드

**목표:** C 장조에서 I-IV-V 진행

```

연습 패턴:
C: C1 / E3-G3-C4 (반복 4박)
F: F1 / A3-C4-F4 (반복 4박)
G7: G1 / B2-F3-G3 (반복 4박)
C: 해결

```

**속도:** 메트로놈 ♩=60에서 시작

### 2단계: 12조성 확장

- 12개 모든 조성에서 I-IV-V
- 각 조성의 베이스·코드 포지션 암기
- 조성 간 전조 연습

### 3단계: 재즈 스탠다드 적용

**Autumn Leaves 스트라이드:**
```

Cm7 → F7 → BbMaj7 → EbMaj7
Am7b5 → D7 → Gm (G단조)

```

### 4단계: 즉흥연주 추가

왼손 스트라이드가 자동화되면 오른손 즉흥 추가:
- 블루스 스케일로 시작
- 비밥 패턴 삽입
- 텐션·해결 구조

---

## 기술적 난관과 해결

### 왼손 도약 정확도

**문제:** 빠른 도약에서 코드를 놓침

**해결:**
1. 눈을 감고 포지션 감각 훈련
2. "도착 먼저" — 코드 위치에 집중
3. 느린 템포로 정확성 우선

### 왼손 지구력

**문제:** 스트라이드는 왼손이 매우 피로함

**해결:**
1. 10-15분 연습 후 휴식
2. 스트레칭 필수
3. 점진적으로 시간 증가

### 독립성 부족

**문제:** 오른손 멜로디와 왼손 스트라이드 분리 어려움

**해결:**
1. 왼손만 완전 자동화될 때까지 분리 연습
2. 오른손 멜로디를 먼저 완전히 외우기
3. 처음에는 오른손 단순화 (음표 줄이기)

---

## 음악연습실 스트라이드 연습

### 스튜디오 놀 피아노 연습

은평구 음악연습실의 어쿠스틱/디지털 피아노로:

**키 터치의 중요성:**
- 스트라이드는 건반 무게 감각이 핵심
- 어쿠스틱 피아노의 그랜드 액션이 이상적
- 디지털에서는 터치 민감도 최대로

**연습 루틴 (60분):**

1. **왼손 워밍업 (10분)**
   - 각 조성에서 스트라이드 패턴
   - 텐스 도약 연습

2. **스탠다드 스트라이드 (25분)**
   - 한 곡을 완전히 스트라이드로
   - 천천히 → 원래 템포

3. **즉흥연주 (25분)**
   - 왼손 스트라이드 + 오른손 자유
   - 녹음하여 분석

## 마무리

스트라이드 피아노는 **피아노로 오케스트라를 만드는 예술**입니다. 왼손 도약이 안정될수록 오른손이 자유로워지고, 그때부터 진정한 스트라이드 즉흥연주가 시작됩니다.

은평구 24시간 음악연습실에서 시간 제한 없이 왼손 도약을 훈련하세요. 스트라이드는 많은 반복이 필요한 스타일입니다—인내심을 갖고, 천천히, 정확하게.

## 고급 스트라이드는 왼손을 안 보고도 도약이 되느냐에서 갈려요

기본 스트라이드가 되는 분들이 다음 문을 여는 열쇠는 결국 시선이에요. 초급 때는 왼손 도약을 눈으로 확인하며 치지만, 고급 스트라이드는 시선을 왼손에서 완전히 떼어야 시작돼요. 눈이 왼손에 묶여 있으면 오른손 악보를 읽을 여유가 없어서 즉흥이 나올 수가 없거든요. BPM 60에서 왼손만 따로 떼어, 악보나 천장을 보면서도 12개 조성 전부에서 도약이 정확한 지점까지 밀어붙이세요. 손이 위치를 통째로 기억할 때 비로소 오른손이 자유로워집니다.

그다음이 왼손을 단음 베이스에서 텐스(10도) 보이싱으로 확장하는 단계예요. Art Tatum의 그 두툼한 왼손이 여기서 나오는데, C2와 그 위 10도인 E4를 한 손으로 벌려 잡는 거라 손이 크지 않으면 두 음을 살짝 굴려서라도 그 울림을 흉내 내야 해요. 텐스가 들어가면 왼손 하나가 베이스와 화성을 동시에 두툼하게 채워서 소리의 밀도가 확 달라집니다.

솔직히 이 단계의 어휘는 글로 설명하는 데 한계가 있어요. 가장 빠른 길은 거장 음원을 통째로 카피하는 거예요. Art Tatum이나 Fats Waller의 한 코러스를 골라 왼손 도약 패턴과 재하모니를 그대로 채보해 손에 넣어 보세요. 한 코러스만 제대로 떠도 스트라이드를 보는 눈이 달라져요. 참고로 스트라이드는 왼손 지구력을 엄청나게 쓰니 10~15분 치고 반드시 손목을 풀어 주세요. 기초 도약 감각을 다시 다지고 싶으면 [스트라이드 입문](/stories/practice-room-piano-stride-beginner1)으로 돌아가 점검해도 좋습니다.
