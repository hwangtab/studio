# 피아노 블루스 콤핑·블루스 피아노 반주 — 음악연습실 완전 가이드

블루스 피아노 콤핑(Comping)은 **블루스 밴드에서 피아니스트의 역할**입니다. 기타, 하모니카, 보컬을 지지하면서도 자신만의 그루브를 유지합니다. Otis Spann, Memphis Slim, Dr. John이 블루스 피아노의 황금기를 만들었습니다.

---

## 블루스 피아노의 기본

### 12마디 블루스 구조

블루스의 표준 형식:

```
마디 1-4: I 코드 (E7, G7, A7 등)
마디 5-6: IV 코드 (A7, C7, D7 등)
마디 7-8: I 코드
마디 9: V 코드 (B7, D7, E7 등)
마디 10: IV 코드
마디 11-12: I-V-I (턴어라운드)
```

**E 블루스 예:**
```
E7(4마디) - A7(2마디) - E7(2마디)
B7(1마디) - A7(1마디) - E7-B7(2마디)
```

### 블루스 음계

**블루스 스케일 (E):**
```
E-G-A-Bb-B-D (블루스 스케일)
= 마이너 펜타토닉 + b5 (블루 노트)
```

**블루스 피아노 오른손:**
```
이 스케일로 멜로디·솔로
장3음(G#)을 단3음(G)과 함께 사용
= 블루스의 독특한 긴장감
```

## Otis Spann 스타일

### 시카고 블루스 피아노

Otis Spann (Muddy Waters Band의 피아니스트):
- **규칙적인 왼손:** 안정적인 베이스 패턴
- **오른손 컬:** 블루스 리프를 반복적으로
- **경제적 사용:** 불필요한 음 없이

**Spann 스타일 콤핑:**
```
왼손: E2-E3 (옥타브) 또는 E2-G2-B2 (코드)
오른손: 블루스 리프 (E-G-Bb-B 중심)
```

### 블루스 왼손 패턴

**기본 왼손 (E7):**
```
패턴 1: E2 (1박) E2 (2박) E2 (3박) E2 (4박) — 루트 4회
패턴 2: E2 (1박) B2 (2박) E2 (3박) B2 (4박) — 루트+5도
패턴 3: E2-G2-B2 (1박 코드) 반복
```

**셔플 왼손:**
```
E2-B2 셔플: 1박→+박 (8분음표 셔플)
= 블루스 특유의 흔들리는 느낌
```

## Memphis Slim 스타일

### 부기우기 + 블루스 혼합

Memphis Slim의 특징:
- **부기우기 왼손:** 빠른 2-beat 패턴
- **오른손 솔로:** 다이나믹한 블루스 라인
- **멋진 글리산도:** 건반 훑어내리기

**Memphis Slim 왼손 (E7):**
```
E2-B2-E2-B2 (8분음표 빠르게)
또는
E2-G2-B2-D3 (블루스 코드 올라가기)
```

### 블루스 글리산도

```
오른손 손등·손가락 등으로 건반 위를 훑기
E4부터 E5까지 위로 (상행 글리산도)
또는 E5에서 E4로 아래로 (하행)
```

## Dr. John (Mac Rebennack) 스타일

### 뉴올리언즈 블루스 피아노

Dr. John (New Orleans):
- **루이지애나 그루브:** 폴카와 블루스 혼합
- **제2라인 리듬:** 뉴올리언즈 특유의 스윙
- **R&B 영향:** 단순하면서도 중독적

**Second Line 리듬:**
```
1-2-3-4: 기본 박자
제2라인: 1박에 약간 스윙, 2박을 뒤로
= 독특한 뉴올리언즈 리듬
```

**Dr. John 왼손:**
```
코드를 펼쳐서 (spread voicing)
E-G-B-D (넓게)
"텀벙" 느낌의 저음
```

## 블루스 콤핑 기법

### 콜-앤-리스폰스 (Call and Response)

블루스의 핵심 원리:

```
멜로디 악기(기타/하모니카): 질문
피아노: 응답
```

**피아노 콤핑 응답:**
```
기타 리프 후: 피아노가 짧게 리프
기타 쉬는 동안: 피아노가 채우기
= 대화처럼
```

### 앤티시페이션 (Anticipation)

코드 전환 직전에 먼저 새 코드로:
```
마디 4 (I 코드 끝): 박자 4+박에 IV 코드 미리
= 코드 전환이 자연스럽게
```

### 터닝 포인트 보이싱

12마디 마지막 2마디 (턴어라운드):

**E 블루스 턴어라운드:**
```
마디 11: E7 → E7/G# (인버전)
마디 12: A7 → B7 (V 코드)
= 다음 12마디로 연결
```

## 블루스 리프 라이브러리

### 기본 E 블루스 리프

**리프 1 (하행):**
```
E5-D5-C5-B4-Bb4-A4 (반음씩 하행)
블루 노트(Bb)가 핵심
```

**리프 2 (궁금증):**
```
G4-A4-Bb4-B4 (반음씩 상행)
B4 → 멈춤 → 해결
```

**리프 3 (셔플):**
```
E4-G4-E4-G4 (셔플 리듬으로)
= 블루스의 기본 셔플 피아노
```

### 응용 리프

**변화 리프:**
```
처음: E4-G4-Bb4-B4 (기본)
변형: E4-G4-Bb4-B4-D5 (위로 확장)
확장: E4-G4-Bb4-B4-D5-E5 (더 높이)
```

---

## 블루스 솔로 피아노

### 독주 블루스 피아노

솔로 피아노로 전체 블루스 밴드 표현:

**왼손:** 베이스 + 리듬
**오른손:** 멜로디 + 솔로 + 콤핑

**소나타 형식의 블루스:**
```
도입 (자유롭게) → 12마디 구조 → 임프로비제이션 → 아웃트로
```

### 왼손 워킹 + 오른손 솔로

```
왼손: E2-F#2-G2-A2 (워킹 업)
      A2-G2-F#2-E2 (워킹 다운)
오른손: E4-G4 리프 (동시에)
```

## 음악연습실 블루스 피아노 연습

### 60분 루틴

**1. 기본 12마디 (15분)**
   - E7-A7-B7 기본 진행
   - 왼손 패턴 3가지 연습
   - 오른손 블루스 스케일

**2. 블루스 리프 (15분)**
   - 기본 리프 3개 외우기
   - 리프 변형 연습
   - 12마디에서 리프 배치

**3. 스타일 연습 (15분)**
   - Otis Spann 시카고 스타일
   - Memphis Slim 부기우기 왼손
   - Dr. John 뉴올리언즈 그루브

**4. 즉흥 콤핑 (15분)**
   - 가상 기타 솔로에 응답
   - 공간 남기고 채우기
   - 턴어라운드 연습

## 마무리

블루스 피아노는 **감정의 직접적인 표현**입니다. Otis Spann이 한 음 한 음에 영혼을 담았듯이, 기술보다 느낌이 먼저입니다.
