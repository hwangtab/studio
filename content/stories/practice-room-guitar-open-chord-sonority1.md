# 기타 오픈 코드·소노리티 기법 — 음악연습실 완전 가이드

오픈 코드와 소노리티(Sonority)는 **기타만이 만들 수 있는 특별한 음향 세계**입니다. 열린 현이 울리며 만들어내는 배음, Add9와 Sus 코드의 개방적인 느낌, Joni Mitchell과 Nick Drake가 즐겨 쓰던 변형 튜닝—이것들이 어쿠스틱 기타의 고유한 소노리티를 만듭니다.

---

## 소노리티란?

### 개념

**소노리티(Sonority):** 음악적 소리의 질감, 풍부함, 울림의 특성.

기타의 소노리티는:
- **개방현의 울림:** 프렛 눌린 현 + 열린 현의 조합
- **배음(Overtone):** 각 현이 만들어내는 배음 구조
- **공명:** 악기 몸체의 울림

**좋은 소노리티:** 모든 음이 자연스럽게 어울리며 풍부한 울림.

---

## 오픈 코드의 마법

### 기본 오픈 코드

**C 메이저 오픈 코드:**
```
x-3-2-0-1-0
(6현 뮤트-5-4-3-2-1)
```
- 열린 현: 3번(G), 1번(E)
- 이 열린 현이 코드를 개방적으로 만듦

**G 메이저 오픈 코드:**
```
3-2-0-0-0-3
```
- 열린 현: 4번(D), 3번(G), 2번(B)
- 가장 울림이 풍부한 기타 코드 중 하나

### 오픈 코드의 풍부함

왜 오픈 코드는 특별한가:
- 열린 현의 배음이 프렛 현과 상호작용
- 더 많은 현이 울림
- 어쿠스틱 기타의 공명체가 충분히 활용됨

---

## Add9 코드

### Add9의 특성

**Cadd9:**
```
x-3-2-0-3-0
```
- 표준 C에 D음(9음) 추가
- 더 개방적이고 현대적인 느낌

**Gadd9:**
```
3-2-0-2-0-3 (또는 3-2-0-2-3-3)
```

**Add9의 음악적 효과:**
- 더 밝고 개방적
- 우울하지 않은 서정적 느낌
- 팝·포크에서 자주 사용

### Add9 진행 예

**포크 팝 진행:**
```
Cadd9 - G - Am - Fmaj7
```

각 코드를 열린 현과 함께 아르페지오로:
```
Cadd9: x-3-2-0-3-0
G: 3-2-0-0-0-3
Am: x-0-2-2-1-0
Fmaj7: x-x-3-2-1-0
```

## Sus 코드

### Sus4와 Sus2

**Sus4:** 3음 대신 4음
- Csus4: x-3-3-0-1-0 (G 대신 F)
- 해결을 기다리는 긴장감

**Sus2:** 3음 대신 2음
- Csus2: x-3-0-0-1-0 (E 대신 D)
- 더 개방적이고 모호한 느낌

### Sus 코드의 활용

**Dsus2 → D 해결:**
```
Dsus2: x-x-0-2-3-0
D: x-x-0-2-3-2
(2음이 3음으로 해결)
```

**팝에서 Sus 사용:**
```
Verse: Csus2 (모호함)
Chorus: C (명확한 해결)
대비 효과 극대화
```

## Joni Mitchell 스타일

### 변형 튜닝의 여왕

Joni Mitchell은 수십 가지 비표준 튜닝을 사용.

**Joni Mitchell 대표 튜닝:**
- Open G: D-G-D-G-B-D
- CGDGBE (low C)
- DADGBE (drop D의 변형)

**Joni의 코드:**
표준 튜닝과 다른 손가락 위치에서 더 풍부한 개방음.

**"Big Yellow Taxi" 스타일 (오픈 튜닝):**
```
오픈 E 기반
슬라이드 대신 일반 코드로 개방음 활용
```

### 소노리티 탐구법

**Joni Mitchell 접근법:**
1. 튜닝을 바꿔가며 소리 탐구
2. 코드 이름보다 소리가 먼저
3. 귀로 코드를 만들기

## Nick Drake 스타일

### 어쿠스틱 소노리티의 극치

Nick Drake는 **드롭 튜닝과 카포**로 독특한 소노리티를 만들었습니다.

**Nick Drake의 방법:**
- 다양한 카포 위치
- 오픈 코드와 카포 조합
- 저음현을 낮게 튜닝

**"Pink Moon" 스타일:**
```
카포 5프렛 + 열린 코드
가장 단순한 코드에서 가장 깊은 소리
```

### 깊은 어쿠스틱 소노리티

**비법:**
- 저음현을 C나 D로 낮게 튜닝
- 열린 현이 최대한 울리도록
- 카포로 원하는 음역 조정

---

## 소노리티 만들기 실습

### 소노리티 좋은 진행 만들기

**규칙:**
1. 가능하면 열린 현 포함한 코드 선택
2. 코드 간 공통 음 유지 (보이스 리딩)
3. 최고음부 멜로디 라인 의식

**예시 진행 (E 단조):**
```
Em7: 0-2-2-0-3-0
Cmaj9: x-3-2-0-3-0
G6: 3-2-0-0-0-0
D/F#: 2-0-0-2-3-2
```

각 코드에서 열린 현 유지 → 소노리티 연속성

### 폴리포닉 어쿠스틱 기타

멜로디 + 베이스 + 내성부를 동시에:

**기법:**
```
엄지: 베이스 라인 (저음현)
검지·중지: 코드 내성부 (중간현)
약지: 멜로디 (고음현)
```

## 음악연습실 소노리티 연습

### 연습 루틴 (50분)

**1. 오픈 코드 탐구 (15분)**
   - 기본 오픈 코드를 아르페지오로
   - 각 현이 완전히 울리도록

**2. Add9·Sus 코드 (15분)**
   - Cadd9, Gadd9, Dsus2, Asus2 연습
   - 해결 패턴 만들기

**3. 변형 튜닝 탐구 (10분)**
   - 6현을 D 또는 C로 낮추기
   - 소리 변화 느끼기

**4. 소노리티 진행 (10분)**
   - 위 기법으로 나만의 진행 만들기
