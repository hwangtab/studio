## 부천 소사·역곡에서 연신내 스튜디오 놀까지

경기도 부천시 소사구(역곡·소사·괴안)·원미구(중동·상동·심곡) 지역에서 지하철 1호선 또는 7호선을 이용하면 서울 연신내 스튜디오 놀까지 약 45~65분에 도달할 수 있습니다.

---

## 부천 소사·역곡 → 연신내 이동 경로

### 1호선 + 경의중앙선 (추천)

```
[역곡역·소사역 출발 (1호선)]
① 역곡역 또는 소사역(1호선) 탑승
② 1호선 서울역 방면 이동
   (온수 → 오류동 → 구일 → 구로역)
③ 구로역 → 영등포역 이동
④ 영등포역에서 경의중앙선 환승
   (능곡 방면)
⑤ 가좌역 → DMC역(디지털미디어시티) 하차
⑥ DMC역에서 6호선 환승 (봉화산 방면)
⑦ 수색 → 증산 → 새절 → 응암 → 역촌
   → 불광 → 연신내역 하차

총 소요시간:
역곡역 출발: 약 50~60분
소사역 출발: 약 45~55분
```

### 7호선 경로 (중동·상동 방면)

```
[부천시청역 출발 (7호선)]
① 부천시청역(7호선) 탑승
② 온수역에서 1호선 환승
③ 구로역 → 영등포역 이동
④ 영등포역 → 경의중앙선 → DMC역
⑤ DMC역 → 6호선 → 연신내역

총 소요시간: 약 55~70분
```
