## 부천 소사·역곡에서 연신내 스튜디오 놀까지

경기도 부천시 소사구(역곡·소사·괴안)·원미구(중동·상동·심곡) 지역에서 지하철 1호선 또는 7호선을 이용하면 서울 연신내 스튜디오 놀까지 약 45~65분에 도달할 수 있습니다.

---

## 부천 소사·역곡 → 연신내 이동 경로

### 1호선 + 경의중앙선 (추천)

팝 필터 하나로 파열음 문제의 상당 부분을 해결할 수 있습니다.

### 역곡역·소사역 출발 (1호선)

1. 역곡역 또는 소사역(1호선) 탑승
2. 1호선 서울역 방면 이동
   (온수 → 오류동 → 구일 → 구로역)
3. 구로역 → 영등포역 이동
4. 영등포역에서 경의중앙선 환승
   (능곡 방면)
5. 가좌역 → DMC역(디지털미디어시티) 하차
6. DMC역에서 6호선 환승 (봉화산 방면)
7. 수색 → 증산 → 새절 → 응암 → 역촌
  - 불광 → 연신내역 하차

**총 소요시간**
- **역곡역 출발**: 약 50~60분
- **소사역 출발**: 약 45~55분

### 7호선 경로 (중동·상동 방면)

### 부천시청역 출발 (7호선)

1. 부천시청역(7호선) 탑승
2. 온수역에서 1호선 환승
3. 구로역 → 영등포역 이동
4. 영등포역 → 경의중앙선 → DMC역
5. DMC역 → 6호선 → 연신내역

- **총 소요시간**: 약 55~70분

## 연신내까지 접근 경로

수도권에서 지하철·버스를 이용하면 45~90분 내에 도착할 수 있습니다. 위에 안내된 이동 경로를 참고해 출발 시간을 미리 계산해두세요.

## 부천 소사구 음악 씬과 서울 스튜디오

부천예고 인근. 클래식·K-pop 전공 입시생과 유튜버 음원 제작 수요. 서울 연신내 스튜디오 놀까지 1호선 → 7호선 이용 시 약 55분 소요됩니다.

소사역 1호선 → 부천역 7호선 환승 → 연신내 50분.

## 방문 전 세션 준비 가이드

수도권 이동 거리에 맞춰 준비를 체계화하면 세션 시간을 최대로 활용할 수 있습니다.

**출발 전 챙길 것:**
- [ ] 녹음할 곡의 가사·악보·MR 파일 (USB 또는 Google Drive)
- [ ] 원하는 사운드의 레퍼런스 트랙 2~3곡
- [ ] 예약 확인 메시지 캡처
- [ ] 보컬이라면 따뜻한 물·꿀차 보온병

**이동 중 활용법:**
- 이어폰으로 녹음할 곡 2~3회 예습
- 가사·감정 포인트 머릿속으로 정리
- 목·어깨 가볍게 스트레칭

**세션 팁:**
- 가장 중요한 구간을 세션 초반에 먼저 녹음
- 원하는 사운드를 엔지니어에게 레퍼런스 곡으로 구체적으로 설명
