# 기타 블루스 릭·스케일 완전 가이드 — 연신내 음악연습실 실전 연습

블루스 기타는 록·재즈·컨트리·팝의 뿌리입니다. 블루스 릭(Lick)과 스케일을 마스터하면 즉흥 연주 능력이 폭발적으로 성장하고, 다양한 장르에서 자유롭게 표현할 수 있게 됩니다. 연신내 음악연습실에서 블루스 기타의 본질을 체계적으로 익히는 방법을 소개합니다.

## 마이너 펜타토닉 스케일

블루스 릭의 90%는 마이너 펜타토닉 스케일 위에서 만들어집니다.

### A 마이너 펜타토닉 스케일 (5번 포지션)
```
e|--5--8------------|
B|--5--8------------|
G|--5--7------------|
D|--5--7------------|
A|--5--7------------|
E|--5--8------------|
```

이 포지션은 "블루스 박스(Blues Box)"라고도 불리며, 블루스 기타의 핵심 포지션입니다.

### 블루 노트(Blue Note) 추가
마이너 펜타토닉에 감5도(b5)를 추가하면 블루스 스케일이 됩니다.
- A 마이너 펜타토닉: A-C-D-E-G
- A 블루스 스케일: A-C-D-Eb-E-G

**Eb(감5도) 위치**: 6번 줄 7프렛 / 1번 줄 8프렛

## 핵심 블루스 릭

### 릭 1: 클래식 블루스 오프닝
```
e|--8-5-7-5---------|
B|------7-5-7-5-----|
G|---------------7--|
```
가장 많이 사용되는 블루스 오프닝 릭입니다. 천천히 시작해 속도를 올려보세요.

### 릭 2: 콜 앤 리스폰스 (Call & Response)
```
e|--8^--8-5-8-5------|
B|--5-8---------7-5--|
```
^는 벤딩 기호입니다. 고음에서 콜(Call)하고 저음에서 리스폰스(Response)하는 블루스 대화 구조입니다.

### 릭 3: 6음 블루스 릭
```
G|--7-5-7------|
D|--5---7-5-7--|
```
G·D 줄 사이를 오가는 유명한 블루스 프레이즈입니다.

## 벤딩(Bending): 블루스의 핵심 표현

벤딩은 음을 눌러 올려 피치를 높이는 기법으로, 블루스 보컬의 슬라이드 느낌을 기타로 표현합니다.

### 1음 벤딩 (Full Bend)
- 목표: 한 음 위의 피치까지 올리기 (장2도 상행)
- 방법: 7프렛 G줄을 눌러 올려 9프렛 음(A)이 나올 때까지 벤딩

**벤딩 주의사항**: 손목 회전이 아닌 팔뚝 전체 회전으로 힘을 전달해야 정확한 피치 컨트롤이 가능합니다.

### 반음 벤딩 (Half Bend)
반음(한 프렛) 위 피치까지만 올리는 섬세한 벤딩입니다. 블루스에서 가장 자주 사용하는 "블루지"한 표현입니다.

### 프리-벤딩 (Pre-Bend)
음을 내기 전에 먼저 피치를 올린 뒤 발음하는 기법입니다. 벤딩 해제(Release) 후 아래로 내려오는 움직임이 블루스 특유의 감성을 만듭니다.

## 블루스 비브라토

블루스 비브라토는 클래식 기타의 섬세한 비브라토가 아닌 넓고 강렬한 흔들림이 특징입니다.

### 블루스 비브라토 방법
1. 음을 누른 상태에서 손목과 팔뚝을 빠르게 회전
2. 피치가 올라갔다 내려갔다 반복 (폭: 약 반음 이상)
3. 속도는 장르와 감성에 따라 조절

**팁**: 비브라토는 항상 피치를 올리는 방향으로만 진행합니다. 음의 피치를 내리면 벤딩 후 릴리즈처럼 들려 의도가 달라집니다.

## 슬라이드(Slide) 기법

슬라이드는 한 프렛에서 다른 프렛으로 손가락이 미끄러지며 피치가 연속적으로 변하는 기법입니다.

### 업 슬라이드
5프렛에서 7프렛으로 슬라이드 업:
```
e|--5/7--|  (/ = 슬라이드 업)
```

### 다운 슬라이드
7프렛에서 5프렛으로 슬라이드 다운:
```
e|--7\5--|  (\ = 슬라이드 다운)
```

## 블루스 박스 위치 이동 (5 포지션)

마이너 펜타토닉은 5개의 포지션으로 기타 전체 지판을 커버합니다.

| 포지션 | A 마이너 기준 시작 프렛 |
|------|-----------------|
| 포지션 1 (박스) | 5프렛 |
| 포지션 2 | 8프렛 |
| 포지션 3 | 10프렛 |
| 포지션 4 | 12프렛 |
| 포지션 5 | 3프렛 |

**핵심**: 한 포지션을 완벽히 체득한 뒤 이웃 포지션을 연결하는 연습으로 지판 전체를 자유롭게 이동하는 능력을 키웁니다.

## 연신내 음악연습실에서 블루스 릭 연습 루틴

| 시간 | 내용 |
|-----|------|
| 0~10분 | A 마이너 펜타토닉 5번 포지션 스케일 웜업 |
| 10~20분 | 블루 노트 삽입 연습 |
| 20~35분 | 핵심 릭 1·2·3 습득 (BPM 60→90) |
| 35~45분 | 벤딩 정확도 훈련 (1음 벤딩·반음 벤딩) |
| 45~55분 | 슬라이드 + 비브라토 통합 적용 |
| 55~60분 | 12마디 블루스 진행 위에서 즉흥 연주 |

## 블루스 기타 흔한 실수

### 릭만 반복하는 문제
릭을 암기해 계속 반복하면 즉흥 연주가 아닌 "릭 재생기"가 됩니다. 릭을 리듬·시작 위치·음역을 바꾸어 변형하는 연습이 진짜 즉흥 연주 훈련입니다.

### 벤딩 피치가 정확하지 않은 문제
벤딩 목표 피치를 먼저 손가락으로 짚어보고 그 소리를 기억한 뒤 벤딩으로 도달하는 "가이드 피치 훈련"이 효과적입니다.

## 추천 레퍼런스

- **B.B. King**: 블루스 릭의 성경, 강렬한 비브라토의 교과서
- **Stevie Ray Vaughan**: 텍사스 블루스 — 파워풀한 벤딩과 리듬 기타
- **Eric Clapton**: 클래식 블루스 릭의 현대적 표현
- **Robert Johnson**: 델타 블루스의 원형 — 오픈 튜닝 슬라이드

## 마무리

블루스 기타는 기술이 아닌 감성입니다. 릭을 암기하는 것보다 블루스의 "느낌"을 체득하는 것이 더 중요합니다. 연신내 음악연습실에서 충분한 음량으로 벤딩하고, 슬라이드하고, 비브라토하며 기타가 노래하도록 만들어보세요.
