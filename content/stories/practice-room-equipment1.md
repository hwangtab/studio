## 좋은 음악연습실의 조건 — 장비와 시설 체크리스트

음악연습실을 고를 때 가장 중요한 것은 방음과 장비입니다. 가격이 저렴해도 장비가 부족하면 연습 효율이 떨어지고, 나쁜 습관이 생길 수 있습니다. 견학 전에 아래 체크리스트를 숙지하고, 현장에서 직접 확인하세요.

---

## 필수 장비 6가지

### 1. 방음 시스템 (최우선)

방음은 연습실 선택의 핵심 기준입니다. STC(음향 투과 손실) 등급이 높을수록 방음 성능이 좋습니다.

| STC 등급 | 방음 수준 | 연습 가능 활동 |
|---------|--------|--------------|
| STC 35~44 | 기본 차음 | 소프트 보컬, 헤드폰 연습 |
| STC 45~54 | 중급 차음 | 일반 보컬, 어쿠스틱 기타 |
| **STC 55 이상** | **전문 차음** | **풀 볼륨 보컬, 드럼, 앰프** |

방문 시 직접 풀 볼륨으로 소리를 내고 복도에서 소음이 어느 정도 새는지 확인하세요. 문이 닫혀 있을 때와 열렸을 때의 차이도 확인하는 것이 좋습니다.

### 2. 피아노 / 건반

| 종류 | 용도 | 특징 |
|------|------|------|
| 업라이트 피아노 | 음대 입시, 클래식 실기 | 터치감·음색 실제와 동일 |
| 디지털 피아노 (88건반, 해머 액션) | 실용음악, 보컬 반주, 미디 | 조용한 연습 가능, 유지보수 쉬움 |
| 61건반 미디 컨트롤러 | 미디 작업 전용 | 터치 연습 불가 |

피아노 견학 시 건반 상태(끊김·소음 없는지), 페달 작동, 조율 상태를 확인하세요.

### 3. PA 스피커 (모니터 시스템)

보컬 연습실에서 PA 스피커는 필수입니다. 자신의 목소리를 실시간으로 들으면서 음정·음색을 교정할 수 있어야 실력이 빠르게 향상됩니다.

- **액티브 스피커**: 앰프 내장으로 바로 연결 가능 (추천)
- **패시브 스피커**: 별도 앰프 필요 — 구형 연습실에 많음
- **블루투스 스피커**: 음질 불안정, 지연(레이턴시) 발생 — 피할 것

좋은 모니터 스피커는 볼륨을 높여도 음이 찌그러지지 않습니다. 현장에서 반드시 큰 볼륨으로 테스트하세요.

### 4. 마이크 스탠드

마이크 스탠드가 없으면 손으로 마이크를 잡고 연습하게 됩니다. 이는 **나쁜 마이크 테크닉과 자세 습관**으로 이어질 수 있습니다.

고정형 스탠드와 붐 스탠드 중 보컬 연습에는 붐 스탠드가 더 유연합니다.

### 5. 냉난방 시스템

음악 연습은 발성과 악기 연주로 체온이 올라가기 쉽습니다. 개별 제어 가능한 에어컨·히터가 없으면:
- 여름: 탈수와 성대 건조
- 겨울: 성대 경직으로 발성 저하
- 습도 불균형: 피아노·기타 손상

인버터 에어컨(소음이 적은 타입)이 설치된 연습실을 선택하세요.

### 6. 보안 시스템

24시간 운영 연습실이라면 보안이 중요합니다.

- **개인 디지털 도어록**: 입주자별 코드 발급 필수
- **CCTV**: 공용 공간 최소 설치
- **야간 조명**: 복도·입구 조명 충분한지 확인

---

## 연습실 견학 체크리스트

방문 전 온라인으로 확인:
- [ ] 방음 등급 또는 관련 리뷰
- [ ] 피아노 종류 및 상태
- [ ] PA 스피커 유무
- [ ] 24시간 운영 여부
- [ ] 월 요금 및 시간 대여 가격

현장에서 직접 확인:
- [ ] 풀 볼륨 소리 내고 복도에서 소음 확인
- [ ] 피아노/건반 음 이상 유무
- [ ] 스피커 볼륨 최대로 올렸을 때 왜곡 유무
- [ ] 에어컨·히터 작동 확인
- [ ] 도어록 코드 발급 방식 확인
- [ ] 결로·습기 흔적 없는지 확인

## 스튜디오 놀 음악연습실 장비 사양

스튜디오 놀은 연신내역 도보 5분 거리에 위치한 24시간 전문 음악연습실입니다.

| 항목 | 사양 |
|------|------|
| 방음 | STC 55 이상, 이중 벽체·이중 바닥 구조 |
| 피아노 | 업라이트 피아노 + Yamaha 디지털 피아노 (88건반) |
| 스피커 | 전문 PA 스피커, 마이크 스탠드 구비 |
| 냉난방 | 인버터 에어컨 개별 제어, 결로 방지 설계 |
| 보안 | 입주자별 디지털 도어록, 24시간 CCTV |
| 인터넷 | 기가비트 와이파이 |

견학은 별도 예약 없이 평일 오전·오후에 자유롭게 가능합니다. 방음 테스트와 장비 상태를 직접 확인하고 결정하세요.
