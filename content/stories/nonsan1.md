## 논산에서 KTX로 서울까지

논산은 충남 도시로, 대전역 KTX를 통해 서울과 약 1시간 40분대로 연결됩니다. 딸기로 유명한 논산에서 당일 서울 스튜디오 방문이 가장 편리한 충남 도시 중 하나입니다.

---

## 논산 → 연신내 이동 경로

### KTX 대전역 경유 (권장)

```
① 논산 → 대전역 (버스 약 30~40분)
② 대전역 KTX 탑승 (서울역 방면, 약 50분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 1시간 40분~2시간
```

---

## 당일 왕복 일정 예시 (논산 기준)

```
오전 8시 논산 출발 → 대전역 이동
오전 8시 45분 대전역 KTX 출발
→ 오전 9시 35분 서울역 도착
→ 오전 10시 15분 연신내역 도착
→ 오전 10시 30분 세션 시작 (3시간)
→ 오후 1시 30분 세션 완료
→ 오후 3시 서울역 출발
→ 오후 3시 50분 대전역 도착
→ 오후 4시 40분 논산 도착
```

---

## 온라인 파일 의뢰 서비스

```
논산 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
