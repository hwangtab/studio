  - q: 기타 코드 전환이 느린 문제를 어떻게 해결하나요?
    a: >-
      코드 전환 속도 향상: ① 한 번에 코드 하나씩 집중 — 두 코드 전환만 먼저 ② '공중 전환' 연습 — 줄에서 손가락 떼지 않고
      바로 다음 코드 형태 ③ 메트로놈 느리게 시작 — BPM 40부터 ④ 전환 직전 다음 코드 미리 생각하기 ⑤ 전환 후 첫 스트로크
      타이밍 정확하게. 코드 전환은 근육 기억이 필요하므로 매일 10분씩 꾸준한 반복이 유일한 해결책입니다.
  - q: 기타 코드를 처음 배울 때 어떤 코드부터 시작해야 하나요?
    a: >-
      입문 코드 순서: ① Em - 손가락 2개만 사용, 가장 쉬움 ② Am - Em과 비슷한 형태 ③ E - Am과 유사한 구조 ④
      Am-E-Am 전환 연습 ⑤ G, C, D - 팝 코드 3인방. 이 5개 코드면 한국 대중가요의 40~50%를 칠 수 있습니다. 한
      번에 너무 많이 외우려 하지 말고 2코드 전환부터 완성하세요.
  - q: 바레 코드(F코드)가 잘 안 눌리는 문제 해결법은?
    a: >-
      F코드(바레 코드) 극복: ① 먼저 5현 Am 형태로 연습 — 6현 바레 없이 ② 1번 줄만 바레하는 연습으로 시작 ③ 전체 바레는
      검지를 손가락 끝부분(딱딱한 부분)으로 ④ 엄지 위치 — 넥 뒤 중앙으로, 힘 분배 ⑤ 매일 1~2분만 — 손 근육 점진적 강화.
      F코드는 보통 1~3개월 걸립니다. 급하게 누르려 하면 오히려 더 힘듭니다.
  - q: 코드 자동화는 얼마나 연습해야 달성되나요?
    a: >-
      코드 자동화 기준: '코드 이름만 들으면 손이 먼저 가는 상태'. 일반적으로: ① 오픈 코드 6개 (Em·Am·E·A·G·D·C):
      2~4개월 ② F·B 바레 코드: 추가 1~2개월 ③ 전조·고급 코드: 6개월 이상. 매일 10~15분 × 3개월 = 기초 코드
      자동화. 방음 개인실에서 집중 연습하면 시간이 단축됩니다.

## 코드 자동화가 되면 노래에 집중할 수 있습니다

코드를 보면서 생각해야 한다면 음악이 끊깁니다. 코드를 손이 기억하게 되면 비로소 음악을 즐길 수 있습니다. 방음 개인실에서 꾸준히 코드를 익히세요.

코드 연습의 핵심:
- **한 쌍씩 집중**: 두 코드 전환 완성 후 다음으로
- **느린 메트로놈**: 빠르게 틀리느니 느리게 정확하게
- **공중 전환**: 손 떼기 전에 다음 코드 형태 준비
- **매일 조금**: 주 1회 1시간보다 매일 10분이 효과적

## 기타 입문 코드 순서

| 단계 | 코드 | 연습 목표 |
|-----|------|---------|
| 1단계 | Em → Am | 가장 기본 전환 |
| 2단계 | Am → E → Am | 3코드 사이클 |
| 3단계 | G, C, D | 팝 3코드 추가 |
| 4단계 | G→C, C→D, D→G | 3코드 순환 |
| 5단계 | F (바레) | 도전 코드 |

## 코드 전환 속도 향상 훈련

**2코드 집중 훈련 (10분/일)**
```

Am → E → Am → E (반복)
메트로놈 BPM 40
매 2박자에 코드 전환
틀려도 멈추지 말고 계속

```

**공중 전환 연습**
1. Am 자세에서 손가락 들기
2. 공중에서 E 형태로 손가락 위치 바꾸기
3. 내려놓기

## 기타 코드·코드 전환 훈련의 핵심 원칙 4가지

코드는 단순히 모양을 외우는 것이 아니라 **음악적 기능을 이해하면서 익히는** 것이 장기 기억에 훨씬 유리합니다.

1. **코드 기능 이해** — 각 코드가 I(토닉)·IV(서브도미넌트)·V(도미넌트) 중 어떤 기능인지 이해하며 연습. 기능을 알면 처음 보는 곡도 빠르게 코드를 파악할 수 있습니다.

2. **최소 이동 보이싱** — 코드 전환 시 손가락 이동을 최소화하는 보이싱 탐색. 공통 음을 중심으로 나머지 손가락만 이동하면 전환 속도가 빨라집니다.

3. **장르 맞춤 코드 색채** — 팝은 개방 코드의 따뜻함, 재즈는 7th·9th·13th 텐션, 클래식은 클로즈드 보이싱의 단단함을 각각 탐색하세요.

4. **코드톤 아르페지오** — 각 코드를 아르페지오로 분해하며 내성 음의 움직임을 귀로 인식. 코드와 선율의 관계가 명확해집니다.

### 기타 코드 연습에서 자주 하는 실수

1. **손가락을 눕혀서 인접 현을 뮤팅** — 각 손가락 끝을 세워서 프렛 바로 뒤를 누르기
2. **코드 전환 시 손 전체를 들어올림** — 기준 손가락(1지)을 최대한 이동하지 않고 전환
3. **스트로크 없이 코드 잡기만 연습** — 코드 전환 후 즉시 스트로크해서 '연주 흐름' 익히기
4. **바레 코드를 너무 일찍 시도** — 오픈 코드를 완전히 익힌 후 바레 코드로 진행

### 기타 코드 자가 진단

- [ ] 6개 현이 모두 깨끗하게 울리는가? (왼손 뮤팅 없이)
- [ ] G → C → Am → Em 코드 전환이 1박 안에 완성되는가?
- [ ] 코드 전환 후 첫 스트로크가 끊기지 않는가?

## 4주 기타 집중 연습 플랜

| 주차 | 목표 | 연습 항목 | 시간 |
|------|------|---------|------|
| 1주차 | 기초 코드 | Em·Am·G·C·D — 코드 전환 속도 향상 | 40분 |
| 2주차 | 스트로크·핑거 | 8비트 스트로크, 핑거피킹 기본 패턴 | 45분 |

**주간 체크포인트:** 1주차: 코드 전환 2초 이내 / 2주차: 박자 흔들림 없이 8마디 연속 / 3주차: 목표 곡 코드 전환 오류 없이 / 4주차: 노래·MR과 함께 완주

## Studio NOL이 기타 코드 전환 연습실 사용자에게 자주 권하는 3가지

스튜디오 놀(연신내, 서울 은평구) 음악연습실에서 기타 코드·코드 전환 연습 상담에서 반복적으로 드리는 조언입니다.

**1. 공통 손가락 활용 — 전환 속도 단축**

인접 코드 간 공통 손가락 위치를 유지하면 전환 속도가 빨라집니다. G → Em 전환 시 약지·새끼손가락 유지가 표준입니다.

**2. 메트로놈 BPM 60 — 정확성 우선**

빠른 BPM으로 시작하면 코드가 흐려집니다. BPM 60에서 정확성을 잡은 뒤 BPM을 올립니다.

**3. 곡 컨텍스트 — 단독 코드 전환 한계**

코드 전환만 단독 연습하면 곡 적용 시 흔들립니다. MR에 맞춰 곡 맥락에서 전환을 익힙니다.
