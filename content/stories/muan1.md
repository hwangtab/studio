## 무안에서 KTX로 서울까지

무안은 전남도청 소재지(남악)로 광주와 인접해 있습니다. 나주역 또는 광주송정역 KTX를 이용해 서울까지 약 2시간 20~40분대로 이동할 수 있습니다.

---

## 무안 → 연신내 이동 경로

### KTX 나주역 경유 (권장)

```
① 무안(남악) → 나주역 (버스 약 30~40분)
② 나주역 KTX 탑승 (서울역 방면, 약 1시간 40~50분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 2시간 40분~3시간
```

### KTX 광주송정역 경유

```
① 무안(남악) → 광주송정역 (버스 약 20~30분)
② 광주송정역 KTX 탑승 (서울역 방면, 약 1시간 40~50분)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 2시간 30~40분
```

## 당일 왕복 일정 예시 (무안 기준)

```
오전 7시 30분 무안 출발 → 광주송정역 이동
오전 8시 10분 광주송정역 KTX 출발
→ 오전 10시 서울역 도착
→ 오전 10시 40분 연신내역 도착
→ 오전 11시 세션 시작 (2시간)
→ 오후 1시 세션 완료
→ 오후 2시 30분 서울역 출발
→ 오후 4시 20분 광주송정역 도착
→ 오후 4시 50분 무안 도착
```

## 온라인 파일 의뢰 서비스

```
무안 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
