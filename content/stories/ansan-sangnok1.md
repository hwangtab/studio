## 안산 상록구에서 연신내 스튜디오 놀까지

경기도 안산시 상록구(사동·본오동·성포동·반월동) 지역에서 4호선을 이용하면 서울 연신내 스튜디오 놀까지 약 70~85분에 도달할 수 있습니다.

---

## 안산 상록구 → 연신내 이동 경로

### 4호선 + 1호선 + 경의중앙선 + 6호선 (추천)

반사음 문제는 후반 작업에서 제거하기 매우 어려우므로 녹음 환경 정비가 먼저입니다.

### 한대앞역·상록수역 출발 (4호선)

1. 한대앞역 또는 상록수역(4호선) 탑승
2. 4호선 서울 방면 이동
   한대앞 → (중앙 → 고잔 → 초지 → 안산
    - 상록수 → 반월 → 대야미 → 수리산
    - 산본 → 금정역)
   상록수역부터: 상록수 → 반월 → 대야미
    - 수리산 → 산본 → 금정역 하차
3. 금정역에서 1호선 환승
   (서울 방면 탑승)
4. 안양 → 석수 → 금천구청 → 독산
  - 가산디지털 → 구로 → 신도림
  - 영등포역 하차
5. 영등포역에서 경의중앙선 환승 → DMC역
6. DMC역에서 6호선 환승 → 연신내역 하차

**단순 경로 요약**
한대앞/상록수역(4호선) → 금정역(1호선 환승)
- 영등포역(경의중앙선 환승) → DMC역
- 6호선 → 연신내역
- **총 소요시간**: 약 70~85분
