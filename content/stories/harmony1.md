## 화음 하나로 노래가 풍성해집니다

메인 보컬만 있는 노래와 코러스 화음이 쌓인 노래의 차이는 큽니다. 혼자서도 레이어링으로 풍성한 코러스를 만들 수 있습니다.

보컬 화음의 역사는 중세 유럽의 오르가눔(Organum)에서 시작됩니다. 9세기 교회 음악에서 단선율 그레고리안 찬트에 5도·4도 간격의 화음을 추가하는 방식이 서양 다성 음악의 출발점이 됐습니다. 르네상스 마드리갈과 바로크 이후 4성부 합창(소프라노·알토·테너·베이스)이 서양 화음의 표준 구조로 자리 잡았고, 이 구조가 현대 팝 코러스 녹음의 레이어 개념으로 이어졌습니다. 1960년대 비치 보이스(Beach Boys)의 브라이언 윌슨은 스튜디오에서 수십 개의 보컬 레이어를 스태킹하는 방식으로 두꺼운 코러스 사운드를 만들었고, 이 기법이 현대 팝·K-POP 코러스 프로덕션의 직접적인 원형입니다. 국내에서는 1990년대 서태지와아이들·H.O.T의 그룹 코러스가 팝 화음 구조를 K-POP에 본격적으로 도입했으며, 현재는 DAW에서 1인이 여러 화음 레이어를 쌓는 보컬 스태킹이 인디 프로덕션의 표준 방법으로 자리 잡았습니다.

## 코러스 녹음 방식 비교

| 방식 | 설명 | 적합한 경우 |
|------|------|---------|
| 보컬 스태킹 | 혼자 같은 부분 여러 번 녹음 | 1인 음원, 두꺼운 사운드 |
| 3성부 화음 | 혼자 메인·중간·높은 화음 각 1트랙 | 클래식한 화음 구성 |
| 더블링 | 메인 멜로디를 동일하게 한 번 더 녹음 | 메인 볼륨감 강화 |
| 그룹 코러스 | 2명 이상 함께 녹음 | 합창·코러스 느낌 |

---

## 보컬 스태킹 (레이어링) 방법

혼자 풍성한 코러스를 만드는 기법:

1. 메인 보컬 녹음 완료
2. 메인 멜로디 + 3도 위 음정으로 1트랙 추가
3. 메인 멜로디 + 3도 아래 (또는 5도 위) 1트랙 추가
4. 원하면 메인 더블링 1트랙 추가

이렇게 트랙을 다 쌓았으면 믹싱에서 각 레이어의 볼륨을 조정해 메인과 화음의 균형을 잡습니다.

---

## 화음 구성 기초

| 화음 이름 | 음정 간격 | 예시 (C 기준) |
|---------|---------|-----------|
| 3도 위 | 장3도 (4반음) | C → E |
| 3도 아래 | 단3도 (3반음) | C → A |
| 5도 위 | 완전5도 (7반음) | C → G |
| 옥타브 위 | 12반음 | C → C (높게) |

**실전 팁**: 화성 이론을 몰라도 괜찮습니다. 코드 진행을 기반으로 각 음을 피아노 앱에서 확인하거나, 녹음하면서 귀로 어울리는 음정을 찾으세요.

---

## 코러스 녹음 시 주의사항

### 박자 일치

코러스 레이어는 메인과 정확히 같은 위치에서 시작해야 합니다.

- **방법**: 메인 보컬을 헤드폰으로 들으며 코러스 파트 녹음
- 눈을 감고 메인의 호흡·발성 시작을 느끼며 함께 부르기
- 박자가 맞지 않으면 편집 소프트웨어에서 미세 조정 가능

### 음량 균형

| 트랙 | 상대 볼륨 | 역할 |
|------|---------|------|
| 메인 보컬 | 기준 (0dB) | 주인공 |
| 더블링 | -3 ~ -6dB | 메인 보강 |
| 화음 (3도 위/아래) | -6 ~ -9dB | 화성 지지 |
| 배경 레이어 | -9 ~ -12dB | 앰비언스 |

### 다이나믹 통일

코러스 각 레이어의 다이나믹(강약)이 비슷해야 일체감이 생깁니다. 한 트랙만 너무 크거나 작으면 믹스에서 어색하게 들립니다.

## 스튜디오 놀에서 코러스 녹음

스튜디오 놀에서는:
- 메인 보컬 녹음 완료 후 코러스 파트 추가 녹음 가능
- 엔지니어가 각 레이어의 음정·박자·다이나믹 실시간 확인
- 믹싱에서 레이어 밸런스 최적화

## 마치며

코러스는 메인 보컬을 더 풍성하게 만드는 핵심 요소입니다. 혼자 레이어를 쌓는 보컬 스태킹부터 시작해보세요.

보컬 스태킹에서 각 레이어의 박자 위치가 맞지 않으면 두꺼운 사운드 대신 흐릿하고 번지는 사운드가 됩니다. 메인 보컬을 헤드폰으로 들으며 각 화음 레이어를 녹음할 때 메인의 자음 시작 위치에 정확히 맞추는 것이 핵심이며, 약간의 타이밍 오차는 DAW에서 파형 뷰로 확인하고 수동으로 맞춥니다. 화음 레이어의 볼륨 균형은 개별 트랙에서 설정하기보다 버스(Bus)로 묶어 메인 보컬과의 상대 레벨로 조절하는 방식이 편리합니다. 코러스에 리버브를 더 많이 걸어야 하는 이유는 공간적 층위(메인은 앞, 코러스는 뒤)를 만들기 위해서이며, 이 층위가 무너지면 메인 보컬의 존재감이 약해집니다.

## 혼자 화음을 쌓을 때, 제가 귀보다 먼저 보는 것

코러스를 혼자 쌓아보겠다고 찾아오시는 분들께 제가 늘 먼저 확인하는 건 음정이 아니라 '자음이 언제 시작되는가'입니다. 3도 위, 3도 아래 음을 아무리 정확히 불러도 각 레이어의 'ㅅ', 'ㅋ' 같은 자음이 메인 보컬과 몇 밀리초라도 어긋나면, 소리가 두꺼워지는 게 아니라 흐릿하게 번져버리거든요. 그래서 저는 스태킹을 녹음할 때 메인 보컬의 파형을 화면에 띄워두고, 각 화음 레이어의 첫 자음을 눈으로 맞춰가며 진행합니다. 귀로만 맞추는 것보다 이 방식이 훨씬 단단한 결과를 냅니다.

볼륨을 잡는 방식도 한 가지 당부드립니다. 3도 위 하나, 아래 하나, 더블링 하나… 이렇게 트랙마다 페이더를 따로 움직이면 균형이 계속 흔들려요. 저는 화음 레이어를 하나의 버스로 묶어놓고 메인 보컬과의 상대 레벨만 조절합니다. 이러면 화음 덩어리 전체가 메인 뒤에서 한 몸처럼 움직여서, 후렴에서 갑자기 코러스만 튀어나오는 사고가 안 생깁니다.

마지막으로 공간감입니다. 메인은 비교적 드라이하게 두고 코러스에만 리버브를 조금 더 길게 걸어주면, 메인이 앞으로 나오고 화음이 뒤에서 받쳐주는 층이 만들어집니다. 이 앞뒤 층위가 무너지면 아무리 화음을 많이 쌓아도 메인 보컬의 존재감이 오히려 약해져요. 혼자 녹음한 트랙이라도 이 세 가지만 지키면 여럿이 함께 부른 것 같은 두께가 납니다. 혼자서 감이 잘 안 잡히면 [녹음·믹싱 요금 안내](/pricing)를 참고해 스튜디오에서 레이어를 함께 잡아봐도 좋습니다.
