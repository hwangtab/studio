## 화음 하나로 노래가 풍성해집니다

메인 보컬만 있는 노래와 코러스 화음이 쌓인 노래의 차이는 큽니다. 혼자서도 레이어링으로 풍성한 코러스를 만들 수 있습니다.

---

## 코러스 녹음 방식 비교

| 방식 | 설명 | 적합한 경우 |
|------|------|---------|
| 보컬 스태킹 | 혼자 같은 부분 여러 번 녹음 | 1인 음원, 두꺼운 사운드 |
| 3성부 화음 | 혼자 메인·중간·높은 화음 각 1트랙 | 클래식한 화음 구성 |
| 더블링 | 메인 멜로디를 동일하게 한 번 더 녹음 | 메인 볼륨감 강화 |
| 그룹 코러스 | 2명 이상 함께 녹음 | 합창·코러스 느낌 |

---

## 보컬 스태킹 (레이어링) 방법

혼자 풍성한 코러스를 만드는 기법:

아래 설정은 일반적인 권장 사항이며 장비 특성과 공간에 따라 조정이 필요합니다.

1. 메인 보컬 녹음 완료
2. 메인 멜로디 + 3도 위 음정으로 1트랙 추가
3. 메인 멜로디 + 3도 아래 (또는 5도 위) 1트랙 추가
4. 원하면 메인 더블링 1트랙 추가
- 믹싱에서 각 레이어 볼륨 조정

---

## 화음 구성 기초

| 화음 이름 | 음정 간격 | 예시 (C 기준) |
|---------|---------|-----------|
| 3도 위 | 장3도 (4반음) | C → E |
| 3도 아래 | 단3도 (3반음) | C → A |
| 5도 위 | 완전5도 (7반음) | C → G |
| 옥타브 위 | 12반음 | C → C (높게) |

**실전 팁**: 화성 이론을 몰라도 괜찮습니다. 코드 진행을 기반으로 각 음을 피아노 앱에서 확인하거나, 녹음하면서 귀로 어울리는 음정을 찾으세요.

---

## 코러스 녹음 시 주의사항

### 박자 일치

코러스 레이어는 메인과 정확히 같은 위치에서 시작해야 합니다.

헤드룸을 충분히 확보해두면 이후 믹싱 단계에서 선택의 폭이 넓어집니다.

- **방법**: 메인 보컬을 헤드폰으로 들으며 코러스 파트 녹음
- 눈을 감고 메인의 호흡·발성 시작을 느끼며 함께 부르기
- 박자가 맞지 않으면 편집 소프트웨어에서 미세 조정 가능

### 음량 균형

| 트랙 | 상대 볼륨 | 역할 |
|------|---------|------|
| 메인 보컬 | 기준 (0dB) | 주인공 |
| 더블링 | -3 ~ -6dB | 메인 보강 |
| 화음 (3도 위/아래) | -6 ~ -9dB | 화성 지지 |
| 배경 레이어 | -9 ~ -12dB | 앰비언스 |

### 다이나믹 통일

코러스 각 레이어의 다이나믹(강약)이 비슷해야 일체감이 생깁니다. 한 트랙만 너무 크거나 작으면 믹스에서 어색하게 들립니다.

---

## 스튜디오 놀에서 코러스 녹음

스튜디오 놀에서는:
- 메인 보컬 녹음 완료 후 코러스 파트 추가 녹음 가능
- 엔지니어가 각 레이어의 음정·박자·다이나믹 실시간 확인
- 믹싱에서 레이어 밸런스 최적화
