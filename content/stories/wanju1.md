## 완주에서 전주역 KTX로 서울까지

완주는 전북 전주와 인접한 도시로 전주역 KTX를 이용해 서울과 약 2시간대로 연결됩니다. 전주역은 호남고속선 KTX와 전라선 KTX가 모두 정차하는 주요 역입니다.

---

## 완주 → 연신내 이동 경로

### KTX 전주역 경유 (권장)

```
① 완주 시내 → 전주역 (버스·택시 약 20~30분)
② 전주역 KTX 탑승 (서울역 방면, 약 1시간 50분~2시간)
③ 서울역 → 지하철 → 연신내역 (약 30~40분)

총 소요시간: 약 2시간 40~50분
```

---

## 당일 왕복 일정 예시 (완주 기준)

```
오전 7시 완주 출발 → 전주역 이동
오전 7시 30분 전주역 KTX 출발
→ 오전 9시 30분 서울역 도착
→ 오전 10시 10분 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 서울역 출발
→ 오후 4시 전주역 도착
→ 오후 4시 30분 완주 도착
```

---

## 온라인 파일 의뢰 서비스

```
완주 현지 녹음실에서 드라이 보컬 WAV 녹음
→ 구글 드라이브 또는 WeTransfer 업로드
→ 카카오톡으로 링크 전송
→ 믹싱·마스터링 (영업일 2~5일)
→ 완성 WAV + MP3 온라인 납품
```
