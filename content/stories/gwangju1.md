## 호남에서 KTX로 두 시간이면

광주는 KTX·SRT로 서울과 빠르게 연결됩니다. 전문 보컬 녹음과 음반 제작을 위해 연신내 스튜디오 놀을 당일 왕복으로 이용할 수 있습니다.

---

## 광주 → 연신내 이동 경로

### KTX 호남선 → 서울역

```
① 광주송정역에서 KTX 탑승 (서울역 방면)
② 서울역 도착 (약 1시간 30~40분)
③ 1호선 → 환승 → 연신내역

총 소요시간: 약 2시간 20분~3시간
```

### SRT → 수서역

```
① 광주송정역에서 SRT (수서역 방면)
② 수서역 도착
③ 3호선 → 을지로3가 → 5호선 → 광화문 → 3호선 → 불광 → 연신내

총 소요시간: 약 2시간 20분~3시간
```

## 당일 왕복 일정 예시 (광주 기준)

```
오전 7시 광주송정역 출발 (KTX)
→ 오전 9시 서울역 도착
→ 오전 9시 50분 연신내역 도착
→ 오전 10시 세션 시작 (2시간)
→ 오후 12시 세션 완료
→ 오후 1시 30분 서울역 출발 (KTX)
→ 오후 3시 10분 광주송정역 도착
```
