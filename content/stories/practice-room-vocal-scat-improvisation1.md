# 보컬 스캣 즉흥연주 — 재즈 보컬 음악연습실 완전 가이드

스캣(Scat)은 **목소리로 악기를 모방하는 재즈 즉흥연주**입니다. "ba-doo-bee-dah"처럼 의미 없는 음절로 멜로디와 리듬을 자유롭게 즉흥 창조합니다. Ella Fitzgerald, Sarah Vaughan, Louis Armstrong—재즈 역사를 빛낸 스캣 마스터들의 기법을 분석합니다.

---

## 스캣의 기본 요소

### 스캣 음절 (Scat Syllables)

**기본 음절 팔레트:**
- **짧고 강한 음:** "doo", "dit", "bah", "dat"
- **부드럽고 연결:** "dee", "dah", "wah", "ya"
- **리듬적 강조:** "bop", "skoo", "dwee"
- **롱 톤용:** "daaaah", "waaah"

**악기별 모방:**
- **트럼펫:** "dah-doot-doo-wah" (날카롭고 강함)
- **색소폰:** "skoo-wah-dee" (부드럽고 구불구불)
- **더블베이스:** "doom-boom" (낮고 묵직)
- **피아노 런:** "diddly-dah-doo" (빠르고 경쾌)

---

## 리듬 스캣

### 스윙 느낌

재즈의 핵심은 **스윙 리듬**입니다. 8분음표를 균등하게가 아니라 점8분+16분 느낌으로.

**스윙 스캣 연습:**
```
악보상: 1 & 2 & 3 & 4 &
실제:   doo-bah doo-bah doo-bah doo-bah
        (긴-짧 긴-짧 긴-짧 긴-짧)
```

**C 메이저 스케일로 스캣 스윙 연습:**
```
"Doo-bah doo-bah, dee-dah doo-bah"
C-D   E-F    G-A   B-C
```

### 비밥 리듬 패턴

**특징:**
- 8분음표를 빠르게 연속
- 싱코페이션 강조
- 약박(2·4박) 강조

**비밥 스캣 기본 패턴:**
```
"Doo-bah-diddly-dah, skoo-wee-doo-bah"
(8분음표 연속 + 싱코페이션)
```

## 코드 음 공략

### 코드 톤 우선 원칙

즉흥연주에서 가장 중요한 규칙: **코드의 핵심 음에 착지**

**C 장조 트라이어드 코드 톤:**
```
C (근음), E (3음), G (5음)
이 음들에서 스캣을 시작하거나 끝냄
```

**C7 코드 (도미넌트 7th):**
```
C (근음), E (3음), G (5음), Bb (7음)
특히 3음(E)과 7음(Bb)이 코드의 색깔
```

### ii-V-I 진행 스캣

재즈의 기본 진행 Dm7-G7-C에서:

**코드 톤 연결:**
```
Dm7: D-F-A-C
G7:  G-B-D-F (B와 F가 핵심 가이드 톤)
CMaj7: C-E-G-B
```

**스캣으로 표현:**
```
"Doo-dee-dah / bee-doo-wah / daaaaah"
Dm7 코드톤  / G7 가이드톤 / CMaj7 해결
```

## Ella Fitzgerald 스타일

### Ella의 특징

재즈 역사상 가장 위대한 스캣 싱어.

**핵심 요소:**
- **완벽한 인토네이션**: 어떤 음표도 정확하게
- **트럼펫 모방**: Dizzy Gillespie의 비밥 트럼펫을 목소리로
- **유머**: 흥겹고 장난기 있는 스캣

**Ella 풍 비밥 패턴:**
```
"Shoo-bee-doo-wah, doo-dat-doo-dee-dah"
(비밥 8분음표 연속, 싱코페이션)
```

### Ella의 "How High the Moon" 스캣

이 곡에서 Ella는 "La Bamba", "Air Mail Special" 등 다른 곡의 멜로디를 스캣으로 인용했습니다.

**인용 기법 연습:**
1. 잘 아는 멜로디를 스캣 음절로 노래
2. 화성 진행 위에 올리기
3. 리듬 변형

## Sarah Vaughan 스타일

### Sassy의 특징

**특징:**
- **광범위한 음역**: 여러 옥타브를 자유롭게
- **성악적 완성도**: 클래식 기법 + 재즈 즉흥
- **블루지한 표현**: 블루노트를 적극 활용

**Sarah 풍 스캣:**
```
"Waaah-dee-dah, skoo-wee-yah-doo"
(폭넓은 음역 도약 + 블루노트)
```

### 블루노트 스캣

C 장조에서 블루노트: **Eb (b3), Gb (b5), Bb (b7)**

**블루노트 스캣 연습:**
```
C-Eb-E-G (b3 스크레이프)
G-Gb-F-Eb (b5 하강)
Bb-B-C (b7에서 해결)
```

## 스캣 구조 만들기

### 4마디 스캣 문장

스캣은 **문장처럼** 구성합니다.

**기본 4마디 구조:**
```
마디 1: 주제 제시 (call)
마디 2: 발전
마디 3: 긴장 고조
마디 4: 해결 (response)
```

**예시 (C 블루스 12마디 중 첫 4마디):**
```
M1: "Doo-bah-dee-dah" (C7 코드톤)
M2: "Skoo-wee-doo-wah" (C7 크로매틱)
M3: "Dit-diddly-dah-dee" (F7로 이동 준비)
M4: "Doooooo-wah" (F7 해결)
```

### 콜-앤-리스폰스

솔로와 반응 — 스스로 묻고 답하기.

```
Call: "Bee-doo-wah?" (올라가는 느낌)
Response: "Skoo-dee-dah!" (내려오는 해결)
```

## 실전 스캣 즉흥연주 연습

### 1단계: 코드 음 스캣

반주 트랙 위에서:
- C 코드 동안 C-E-G만 사용
- F 코드 동안 F-A-C만 사용
- G7 코드 동안 G-B-D-F만 사용

### 2단계: 스케일 스캣

- 각 코드의 스케일로 확장
- C 장조: C-D-E-F-G-A-B
- F 장조: F-G-A-Bb-C-D-E

### 3단계: 비밥 패시지

**C에서 비밥 패시지:**
```
C-B-Bb-A-Ab-G-F#-F-E-Eb-D-Db-C
(크로매틱 하강)
```

### 4단계: 자유 즉흥

반주 트랙 위에서 자유롭게 — 실수를 두려워하지 않기.

---

## 음악연습실 스캣 연습

### 스튜디오 놀에서 스캣 연습

**마이크로 스캣 연습:**
- 마이크를 통해 자신의 스캣 소리를 모니터링
- 녹음하여 피치·리듬 분석
- 개인 연습실에서 큰 소리로 자유롭게

**연습 루틴 (50분):**

1. **음절 워밍업 (10분)**
   - 스캣 음절 팔레트를 스케일 위에서 연습

2. **코드 톤 스캣 (15분)**
   - ii-V-I 진행으로 코드 음 집중

3. **비밥 패턴 (15분)**
   - Ella 스타일 8분음표 연속

4. **자유 즉흥 (10분)**
   - 녹음하며 자유롭게
