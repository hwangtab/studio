## 방배·서초·내방·이수에서 연신내 스튜디오 놀까지

방배·서초·내방·이수에서 2호선 또는 4호선을 이용하면 연신내 스튜디오 놀까지 약 35~50분이면 도달할 수 있습니다.

---

## 지역별 이동 경로

### 방배역 출발 (2호선)

```
[방배역 출발 (2호선)]
① 방배역(2호선) 탑승 (합정 방면)
② 서초 → 교대 → 강남 → ... → 합정역
③ 합정역에서 6호선 환승 → 연신내역

총 소요시간: 약 35~45분
```

### 이수역 출발 (4호선)

```
[이수역 출발 (4호선)]
① 이수역(4호선) 탑승 (당고개 방면)
② 동작역 → 이촌역 → 신용산역 → 삼각지역 하차
③ 삼각지역 6호선 환승 → 합정 경유 → 연신내역

총 소요시간: 약 38~48분
```

## 서초구 동부 지역별 소요 시간

| 출발지 | 경로 | 소요 시간 |
|--------|------|---------|
| 방배역 (2호선) | 2호선 → 합정 → 6호선 | 약 35~45분 |
| 서초역 (2호선) | 2호선 → 합정 → 6호선 | 약 37~47분 |
| 교대역 (2호선·3호선) | 2호선 합정 방면 또는 3호선 연신내 방면 직통 | 약 30~40분 |
| 이수역 (4호선) | 4호선 삼각지 → 6호선 | 약 38~48분 |
| 내방역 (7호선) | 이수역 → 4호선 → 6호선 | 약 42~52분 |
| 사당역 (2호선·4호선) | 2호선 합정 또는 4호선 삼각지 → 6호선 | 약 40~50분 |

**스튜디오 주소**: 서울특별시 은평구 (연신내역 3번 출구 도보 5분)
