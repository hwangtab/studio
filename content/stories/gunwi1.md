## 군위에서 동대구역 경유 서울까지

대구광역시 군위구(구 경북 군위군)는 동대구역 KTX를 통해 서울과 약 2시간 50분~3시간으로 연결됩니다. 삼국유사 인각사·화본역으로 알려진 군위에서 서울 연신내 스튜디오 놀까지 당일 왕복이 가능합니다.

---

## 군위 → 연신내 이동 경로

### KTX 동대구역 경유 (권장)

주차 공간은 제한적이므로 대중교통 이용을 권장합니다.

1. 군위 → 동대구역 (시외버스 약 40~50분)
2. 동대구역 KTX 서울 방면 탑승
3. 서울역 하차 (약 1시간 40분)
4. 지하철 6호선 경유 연신내역 (약 25분)

- **총 소요시간**: 약 2시간 50분~3시간

### 중앙선 대안

1. 군위 → 의성역 (버스 약 30분)
2. 의성역 중앙선 무궁화/ITX 서울 방면
3. 청량리역 도착 → 지하철 연신내역

- **총 소요시간**: 약 4~5시간 (권장하지 않음)

## 당일 왕복 일정 예시 (군위 기준)

입구 위치나 주차 정보가 필요한 경우 예약 전 문의해주시면 안내드립니다.

오전 7시 군위 출발 → 동대구역
오전 8시 KTX 탑승 (동대구역)
- 오전 9시 40분 서울역 도착
- 오전 10시 연신내역
- 오전 10시 30분 세션 시작 (2시간)
- 오후 12시 30분 세션 완료
- 오후 3시 서울역 출발 KTX
- 오후 4시 40분 동대구역 도착
- 오후 5시 30분 군위 도착

---

온라인 파일 의뢰도 가능합니다. 현지에서 드라이 보컬 WAV를 녹음해 파일로 보내주시면 믹싱·마스터링 후 납품합니다. [자세한 안내](/stories/onlinemix1)

## 군위 음악 씬과 서울 스튜디오

군위는 대구 북부에 편입된 경북 군 지역입니다. 대구에 인접해 대구역·동대구역 KTX를 이용하면 서울까지 빠르게 도달할 수 있습니다.

## 방문 전 세션 준비 가이드

1시간 30분 이상 이동 후 최상의 컨디션으로 세션에 임하려면 철저한 사전 준비가 필요합니다.

**출발 전 챙길 것:**
- [ ] 녹음할 곡의 가사·악보·MR 파일 (USB 또는 Google Drive)
- [ ] 원하는 사운드의 레퍼런스 트랙 2~3곡
- [ ] 예약 확인 캡처 + 교통편 티켓
- [ ] 보컬: 따뜻한 차·꿀물 보온병, 간식
- [ ] 귀마개 또는 노이즈캔슬링 이어폰 (이동 중 성대 보호)

**이동 중 활용법:**
- 이어폰으로 녹음할 곡 2~3회 예습
- 가사·감정 포인트 집중 정리
- 목·어깨 스트레칭 (장시간 이동 피로 완화)
- 충분한 수분 섭취 (기차 이동 중 성대 건조 방지)

**세션 팁:**
- 도착 후 20~30분 워밍업 시간 확보 (일정 계획 시 반드시 포함)
- 가장 중요한 구간을 세션 초반(이동 피로 전)에 먼저 녹음
- 원하는 사운드를 레퍼런스 곡으로 구체적으로 설명
- 온라인 파일 의뢰 서비스 병행 시 재방문 부담 최소화 가능

## 세션 당일 체크리스트

**전날:**
- [ ] MR·가사·레퍼런스 트랙 파일 최종 확인
- [ ] 교통편 티켓 + 예약 확인 캡처
- [ ] 충분한 수면 + 성대 무리 금지

**출발 전:**
- [ ] 따뜻한 차·꿀물 지참
- [ ] 이동 중 성대 보호 (소리 지르기 금지, 수분 섭취)

**도착 후:**
- [ ] 20~30분 워밍업 확보 (일정에 미리 포함)
- [ ] 엔지니어에게 레퍼런스·사운드 방향 설명
- [ ] 가장 어려운 구간 최우선 녹음

**녹음 중:**
- [ ] 헤드폰 볼륨 확인
- [ ] 테이크마다 즉시 청취
- [ ] 막차 시간 미리 확인 (귀가 일정)
