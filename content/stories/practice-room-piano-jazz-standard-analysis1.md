# 피아노 재즈 스탠다드 분석·All the Things You Are — 음악연습실 완전 가이드

"All the Things You Are"는 **재즈 스탠다드의 교과서**입니다. Jerome Kern이 1939년에 작곡한 이 곡은 복잡한 전조(Modulation)와 풍부한 화성 언어로 인해 재즈 뮤지션들의 필수 학습 곡이 되었습니다. 이 곡을 피아노로 완전히 분석하고 연주하는 방법을 단계적으로 안내합니다.

---

## 곡의 구조 분석

### 기본 정보

- **제목**: All the Things You Are
- **작곡**: Jerome Kern (1939)
- **형식**: AABA' (32마디)
- **시작 조성**: F 단조 (Ab 장조 방향)
- **특징**: 4개 조성을 넘나드는 복잡한 전조

### 32마디 구조

```

A (8마디): Ab 장조 중심 (Am7b5→D7→G으로 시작)
A (8마디): 동일한 A섹션 반복 (끝 2마디 변형)
B (8마디): E 장조 (Bridge)
A' (8마디): A섹션 변형 (C 장조로 마무리)

```

---

## 섹션별 코드 분석

### A 섹션 (1-8마디)

```

Fm7 - Bbm7 - Eb7 - Abmaj7
Dbmaj7 - Dm7b5 - G7 - Cmaj7

```

**화성 분석:**
- Fm7 → Bbm7: 마이너 II-V
- Bbm7 → Eb7 → Abmaj7: Ab 장조의 II-V-I
- Dbmaj7 → Dm7b5 → G7: Db 장조에서 C 장조로 전조
- G7 → Cmaj7: C 장조의 V-I

**전조 포인트:** 3마디에서 Ab 장조 → 5마디에서 Db 장조 → 8마디에서 C 장조

### B 섹션 Bridge (17-24마디)

```

Am7b5 - D7 - Gmaj7
Am7b5 - D7 - Gmaj7
F#m7 - B7 - Emaj7
F7 - Bb7 - Eb7

```

**화성 분석:**
- Am7b5 - D7 - Gmaj7: G 장조의 II-V-I
- F#m7 - B7 - Emaj7: E 장조의 II-V-I
- F7 - Bb7 - Eb7: F 장조 → Bb 장조 전환 준비

**Bridge 핵심:** G 장조와 E 장조를 지나며 전혀 다른 화성 색채를 경험.

### A' 섹션 (25-32마디)

```

Fm7 - Bbm7 - Eb7 - Abmaj7
Dbmaj7 - Dbm7 - Cm7 - Bdim7
Bbm7 - Eb7 - Abmaj7

```

## 피아노 보이싱 접근법

### 기본 껍데기 보이싱 (Shell Voicing)

왼손에 루트-7도 또는 루트-3도만 잡는 미니멀 보이싱.

**Abmaj7 껍데기 보이싱:**
```

왼손: Ab - G (루트-7도)
오른손: Eb - C (5도-3도)

```

**Fm7 껍데기 보이싱:**
```

왼손: F - Eb (루트-7도)
오른손: C - Ab (5도-3도)

```

### 리치 보이싱 (Rootless Voicing)

베이스 없이 3, 5, 7, 9를 겹쳐서 풍부한 소리.

**Abmaj7 루트리스 보이싱:**
```

오른손만: C - Eb - G - Bb (3-5-7-9)
왼손: Ab 단독 루트

```

**Eb7 루트리스:**
```

오른손: G - Bb - Db - F (3-5-b7-9)
왼손: Eb 단독

```

---

## 멜로디 + 보이싱 조합

### 코드 블록 스타일

오른손으로 멜로디와 코드 보이싱을 동시에.

**1마디 예:**
```

멜로디: Ab4 (Fm7 위에서)
왼손 보이싱: F - Eb (Fm7 껍데기)
오른손: Ab + C + Eb (멜로디 + 코드 내음)

```

### 멜로디 하모나이제이션

각 멜로디 음에 어울리는 코드를 배치하는 기술.

**원칙:**
- 멜로디 음이 코드 톤이면 기본 코드
- 멜로디 음이 텐션이면 텐션 코드 선택
- 크로매틱 멜로디에는 패싱 코드 삽입

---

## 즉흥 연주 접근법

### 스케일 선택

각 코드에 어울리는 스케일:

| 코드 | 스케일 |
|-----|------|
| Fm7 | F 도리안 |
| Bbm7 | Bb 도리안 |
| Eb7 | Eb 믹소리디안 또는 Eb 얼터드 |
| Abmaj7 | Ab 리디안 또는 Ab 이오니안 |
| Cmaj7 | C 이오니안 또는 C 리디안 |

### 가이드 톤 멜로디 (Guide Tone Line)

3도와 7도만으로 만드는 즉흥 선율.

**A 섹션 가이드 톤:**
```

Fm7: Ab - Eb
Bbm7: Db - Ab
Eb7: G - Db
Abmaj7: C - G

```

이 음들만 사용해도 재즈의 진행이 명확하게 들립니다.

## 음악연습실 학습 루틴

### 기초 단계 (90분)

**1. 코드 외우기 (30분)**
- 32마디 코드 이름 외우기
- 각 전조 포인트 표시

**2. 왼손 껍데기 보이싱 (30분)**
- 모든 코드를 루트-7도 형태로 연주
- A→B→A'→A 순서로

**3. 멜로디 + 왼손 (30분)**
- 오른손 멜로디 + 왼손 보이싱
- 천천히 (BPM 60)부터

### 중급 단계

- 루트리스 보이싱 전체에 적용
- 가이드 톤 즉흥
- 스케일 기반 즉흥 추가

## 마무리

"All the Things You Are"를 완전히 이해하고 연주할 수 있게 되면, 재즈 피아노의 핵심 화성 언어가 손에 익습니다. 이 곡의 전조와 화성 논리가 이해되면 다른 재즈 스탠다드들이 훨씬 쉽게 느껴집니다.

은평구 24시간 음악연습실에서 충분한 시간을 갖고 단계적으로 접근하세요. 32마디의 코드를 외우는 것부터—그것이 모든 것의 시작입니다.

## Studio NOL이 재즈 스탠다드 분석 연습실 사용자에게 자주 권하는 3가지

스튜디오 놀(연신내, 서울 은평구) 음악연습실에서 피아노 재즈 스탠다드 분석·즉흥 연습 상담에서 반복적으로 드리는 조언입니다.

**1. iReal Pro 백킹 — 스탠다드 코드 진행 무한 반복**

스탠다드 분석은 백킹 트랙 없이는 즉흥이 늘지 않습니다. iReal Pro로 곡 BPM과 키를 자유롭게 조정하며 연주합니다.

**2. 헤드 멜로디 카피 — 즉흥 전 멜로디 마스터**

즉흥에 들어가기 전 헤드 멜로디를 완전히 익혀야 변형의 기준이 생깁니다. 멜로디 없이 솔로로 직행하면 곡 정체성이 흐려집니다.

**3. ii-V-I 단독 연습 — 스탠다드의 90% 진행**

재즈 스탠다드의 핵심 진행은 ii-V-I입니다. 12키 ii-V-I 위에서 즉흥하는 일일 훈련을 30분 배정합니다.

팝 피아노에서는 코드 반전형과 보이싱 선택이 사운드의 세련미를 결정합니다. 기본 반주형인 알베르티 베이스에서 벗어나 블록 코드, 아르페지오, 리듬 패턴을 상황에 맞게 섞어 쓰면 생동감 있는 반주가 완성됩니다. 오른손 선율을 살리면서 왼손 반주를 적절히 억제하는 다이나믹 감각이 팝 피아노의 완성도를 결정합니다. 좋아하는 팝 곡의 피아노 반주를 귀로 듣고 카피하는 훈련은 음악적 어휘를 빠르게 확장시켜 줍니다. 음악을 배우는 과정에서 이론과 실기를 함께 발전시키는 것이 이상적입니다. 화성학 기초를 이해하면 코드 진행을 귀로 파악하는 능력이 향상되고, 즉흥 연주나 작곡의 기반이 됩니다. 악보를 보고 연주하는 초견 능력은 꾸준히 새로운 악보를 접하는 훈련으로만 향상됩니다. 함께 연주할 동료를 찾아 앙상블 경험을 쌓는 것도 개인 연습에서는 얻기 어려운 실전 감각을 키워주는 중요한 방법입니다.
