## 양주 덕계·옥정에서 연신내 스튜디오 놀까지

경기도 양주시 덕계동·옥정동·고읍면·회천읍 지역에서 7호선 또는 1호선을 이용하면 서울 연신내 스튜디오 놀까지 약 1~1.5시간에 도달할 수 있습니다.

---

## 양주 덕계·옥정 → 연신내 이동 경로

### 7호선 + 1호선 경유

```
[덕계역 출발 (7호선)]
① 덕계역(7호선) 탑승
② 도봉산역 하차 (7호선 종착역)
③ 도봉산역에서 1호선 환승 (서울역 방면)
④ 창동역 → 방학역 → 도봉역 → 방향
   (도봉산 → 창동 → 광운대 → 석계 → 상봉)
   ※ 연신내 방면 직통 없음
⑤ 상봉역에서 버스 또는 환승으로 이동
   또는 창동에서 4호선 → 불광 → 연신내

권장:
① 덕계역(7호선) → 도봉산역(1호선 환승)
② 창동역 하차
③ 창동 → 4호선 탑승 → 불광역
④ 불광역에서 3호선 또는 버스 → 연신내역

총 소요시간: 약 55~70분
```

### 옥정 출발 버스 + 지하철 경유

```
[옥정신도시 출발]
① 옥정에서 버스 → 덕계역 또는 의정부역
② 의정부역(1호선) → 창동 → 4호선 환승
③ 불광역 → 연신내역

총 소요시간 (옥정 기준): 약 1시간~1시간 20분
```

| 옥정신도시 | 버스 → 의정부역 → 1호선 → 환승 | 약 1시간~1시간 20분 |
