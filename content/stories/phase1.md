## 위상 — 소리가 스스로 지워지는 현상

위상 문제는 뛰어난 녹음과 믹싱을 무색하게 만들 수 있는 보이지 않는 함정입니다.

오디오 위상 문제는 멀티트랙 레코딩이 등장하면서 처음 체계적으로 인식됐습니다. 1950~60년대 EMI Abbey Road와 RCA 스튜디오에서 두 마이크로 같은 악기를 동시에 녹음하기 시작하면서 마이크 간 거리 차이로 인한 위상 상쇄가 처음 문제로 보고됐습니다. 초기에는 '3:1 원칙'(마이크 간 거리 = 음원-마이크 거리 × 3)이 현장 경험으로 정립됐고, Phil Spector의 'Wall of Sound' 레코딩(1960년대)에서 다수 악기를 겹쳐 녹음하는 과정에서 위상 관리가 필수 기술이 됐습니다. 디지털 오디오 시대에는 플러그인 처리 지연(Plugin Latency)이 새로운 위상 오프셋 원인으로 등장했고, Pro Tools·Logic·Ableton의 자동 레이턴시 보상(ALC) 기능이 이를 대부분 해결합니다. 한국 홈 레코딩 환경에서는 더블 트래킹 후 두 트랙의 타이밍 불일치로 발생하는 위상 문제가 가장 흔한 케이스입니다.

## 위상 문제 원인과 증상

| 원인 | 발생 상황 | 증상 |
|------|-----------|------|
| 마이크 배치 | 두 마이크로 같은 소리 녹음 | 저역·중역 상쇄 |
| 더블 트래킹 | 타이밍 불일치 트랙 합산 | 모노 시 저역 얇아짐 |
| 플러그인 레이턴시 | 처리 지연 불일치 | 위상 차이 발생 |
| 케이블 연결 오류 | 역위상 케이블 | 전체 신호 상쇄 |
| MS 처리 오류 | Mid-Side 디코딩 오류 | 위상 반전 |

## 위상 확인 방법

### 모노 체크 (가장 중요)

1. DAW 마스터버스 모노 버튼 활성화
2. 믹스 전체 재생
3. 소리가 얇아지거나 베이스·보컬이 사라지면 위상 문제

### 위상 스코프 시각화

- SPAN(무료), TB ProAudio ISOL8, Waves InPhase 등 활용
- 리사쥬 패턴이 세로로 나타나면 모노 호환
- 가로로 나타나면 위상 문제 가능성

### A/B 테스트

1. 의심 트랙 Mute → 모노 소리 확인
2. 의심 트랙 Solo → 모노 소리 확인
3. 해당 트랙이 원인인지 파악

---

## 위상 문제 교정 방법

### 위상 반전 버튼(Ø) 활용

1. 문제 트랙에 위상 반전(Ø) 버튼 활성화
2. 모노 체크로 소리 개선 여부 확인
3. 개선되면 ← 해당 트랙이 반전 상태였던 것
- DAW 모든 오디오 트랙·채널 스트립에 내장

### 타이밍 교정

1. 두 트랙을 파형 뷰에서 확인
2. 시작점 불일치 확인
3. 한 트랙을 수동으로 당겨 파형 정렬
- 더블 트래킹에서 자주 발생

### 위상 정렬 플러그인

- Little Labs IBP: 연속적 위상 회전 가능
- Waves InPhase: 실시간 위상 정렬
- 마이크 복수 배치 시 특히 유용

---

## 마이크 배치와 위상

### 3:1 원칙

- 두 마이크 배치 시 마이크 간 거리 = 음원 거리 × 3
- 예: 음원에서 마이크까지 30cm → 마이크 간 거리 90cm 이상
- 이 원칙으로 위상 문제 대부분 예방 가능

### 스테레오 마이킹

- X-Y 방식: 두 마이크 교차 배치 → 위상 최소화
- ORTF 방식: 17cm 간격, 110도 각도 → 자연스러운 스테레오
- A-B 방식: 간격 넓음 → 위상 주의 필요

### 보컬 싱글 마이크

- 단일 마이크 사용 → 위상 문제 없음
- 방 반사음이 문제일 경우 방음 처리로 해결

---

## 더블 트래킹 위상 관리

### 예방

- 두 테이크 타이밍 최대한 일치시키기
- 반드시 같은 마이크, 같은 위치 사용
- 위상 반전 없이 자연스러운 코러스 효과 목표

### 교정

1. 두 트랙 파형 시작점 수동 정렬
2. 모노 체크로 저역 풍성함 확인
3. 한 트랙의 Ø 버튼 토글로 소리 비교
4. 더 풍성하게 들리는 쪽 선택

### 팬으로 분리

- L/R로 패닝하면 위상 상쇄 감소
- 모노 시에는 여전히 위상 영향 있음

## Studio NOL 믹싱 세션에서 위상 문제를 확인하는 3가지 시점

스튜디오 놀 믹싱 의뢰에서 자주 발견되는 위상 문제 패턴입니다.

**1. 보컬 더블 트래킹 정렬 확인**

두 테이크를 합산했을 때 저역이 얇아지는 현상이 가장 자주 보입니다. 파형 뷰에서 두 트랙의 시작점을 맞추고 모노 체크를 하면 대부분 해결됩니다. 타이밍 차이가 2ms 이내라도 저역 상쇄가 느껴질 수 있어 샘플 단위 정렬이 필요한 경우가 있습니다.

**2. 마이크 2개 사용 보컬 스템 수신**

룸 마이크와 클로즈 마이크를 동시에 사용한 스템이 들어올 때 위상 문제가 포함된 경우가 있습니다. 두 트랙을 합산한 뒤 모노로 전환해 클로즈 마이크 단독보다 얇아지면 위상 반전 버튼(Ø)으로 먼저 체크합니다.

**3. 플러그인 체인 내 위상 반전 누적**

EQ나 다이나믹 플러그인이 여러 개 직렬로 연결된 보컬 체인에서 특정 대역이 모노 전환 시 얇아지는 경우, 각 플러그인의 위상 특성이 누적된 것일 수 있습니다. 플러그인을 하나씩 바이패스하며 원인 구간을 좁히는 방법이 가장 빠릅니다.

## 마치며

위상 문제는 모노 체크 하나로 대부분 발견하고 교정할 수 있습니다. 믹싱의 모든 단계에서 주기적으로 모노 버튼을 눌러 중요 악기(보컬·킥·베이스)가 얇아지거나 사라지지 않는지 확인하는 습관이 위상 문제를 예방하는 가장 효과적인 방법입니다. 마이크 2개를 사용할 때는 3:1 원칙을 지켜 마이크 간 거리를 음원-마이크 거리의 3배 이상으로 설정하면 위상 문제의 대부분을 사전에 예방할 수 있습니다.

더블 트래킹 위상 교정은 두 트랙을 파형 뷰에서 확인해 시작점을 정렬하는 것이 첫 단계입니다. 한 트랙의 위상 반전 버튼(Ø)을 토글하면서 모노로 더 풍성하게 들리는 상태를 선택합니다. 위상 문제가 의심되는데 육안으로 정렬이 안 될 때는 Little Labs IBP나 Waves InPhase 같은 위상 정렬 플러그인이 샘플 단위의 미세 조정을 가능하게 합니다.
