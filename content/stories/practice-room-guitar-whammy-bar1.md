# 기타 왐미바·트레몰로 암 기법 — 음악연습실 완전 가이드

왐미바(Whammy Bar), 정식 명칭 트레몰로 암(Tremolo Arm)은 기타의 음정을 올리거나 낮추는 장치입니다. 지미 헨드릭스, 에디 반 헤일런, 잉위 맘스틴이 대중화한 이 기법은 기타에서만 가능한 독특한 표현을 만들어냅니다.

---

## 트레몰로 시스템 이해

### 트레몰로 종류

**빈티지 싱크로나이즈드 트레몰로 (Fender 스타일):**
- 다이브만 가능 (음정을 낮추는 방향)
- 더블 록킹 없음
- 세팅 간단

**플로이드 로즈 (Floyd Rose):**
- 양방향 (다이브 + 암 업)
- 더블 락킹 시스템으로 튜닝 안정적
- 복잡한 세팅, 하지만 익스트림 트레몰로 가능

**카일러 트레몰로 (Kahler):**
- 플로이드 로즈와 비슷하지만 구조 다름

## 기본 왐미바 기법

### 다이브밤 (Dive Bomb)

음정을 급격히 낮추는 기법:

```
높은 음 → 암을 아래로 밀며 → 음정 급격히 하강
사용 예: 솔로 마무리, 드라마틱 효과
```

**연습:**
```
1. G 현 15프렛(D)을 픽킹
2. 암을 천천히 아래로
3. 암을 빠르게 아래로 (다이브밤)
```

### 스쿠프 & 다이브 (Scoop & Dive)

음정을 먼저 올렸다가 내리는 기법:

```
낮은 음 → 암 올리며 → 음정 상승 → 이후 하강
```

### 암 트릴 (Arm Trill)

빠르게 암을 위아래로 흔들어 비브라토 효과:

```
고정 음에서 암을 빠르게 앞뒤로:
결과: 음정이 미세하게 오르내리는 비브라토
```

### 암 업 (Arm Up)

플로이드 로즈에서만 가능 — 음정을 올리는 기법:

```
음을 픽킹한 채 암을 위로 당기기
음정이 반음~온음 이상 올라감
```

---

## 트레몰로 비브라토

### 클래식 비브라토

지미 헨드릭스 스타일:

```
음 픽킹 → 암을 천천히 아래로 → 다시 올리기 → 반복
마치 손가락 비브라토처럼 자연스러운 흔들림
```

**다이나믹 비브라토:**
- 시작: 좁은 비브라토
- 클라이맥스: 넓은 비브라토
- 페이드: 다시 좁은 비브라토

---

## 음표를 왐미바로 변형

### 헤드 슬라이드 (Head Slide)

코드를 픽킹한 후 암으로 내렸다가 다시 올리기:

```
코드 스트럼 → 암 다운 → 암 업 (원래 음정으로)
```

헤드 메탈의 대표적 효과

### 서핑 노이즈

암을 완전히 내린 채 픽킹하면 다이브밤:

```
암 최대 다운 → 픽킹 → 서서히 올리기
→ 노이즈에서 음이 "솟아오르는" 효과
```

---

## 플로이드 로즈 세팅

### 스프링 밸런싱

트레몰로가 수평을 유지해야 튜닝 안정:

```
너무 앞으로 기울면: 스프링 추가 또는 조여주기
너무 뒤로 기울면: 스프링 줄이거나 느슨하게
목표: 바디와 평행
```

### 락킹 너트 활용

픽킹 전 락킹 너트로 고정:
- 트레몰로 사용 후 자동으로 복귀
- 미세 튜닝은 브리지 파인 튜너로

---

## 음악연습실 왐미바 루틴

### 기초 단계 (45분)

**1. 암 컨트롤 감각 (10분)**
- 암 없이 음 픽킹
- 암으로 반음 다운, 정확히 원래 음으로 복귀

**2. 다이브밤 연습 (15분)**
- G 현 12프렛에서 다이브밤
- 느리게 → 빠르게 변형

**3. 트레몰로 비브라토 (10분)**
- 한 음에서 비브라토 지속 유지
- 다이나믹 변화 연습

**4. 음원 카피 (10분)**
- 지미 헨드릭스 "Star Spangled Banner" 왐미 구간
