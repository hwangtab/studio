## 내 음악을 법적으로 보호하는 방법

자작곡을 발매했다고 해서 저작권이 자동으로 보호되는 것은 아닙니다. 방송·스트리밍·공연 수익을 실제로 받으려면 **KOMCA(한국음악저작권협회)** 등록이 필요합니다.

한국에서 음악 저작권 개념이 법적으로 정립된 것은 1986년 전면 개정된 저작권법이 시행되면서부터입니다. 이전에는 작사·작곡가가 방송사에서 곡이 방영되어도 별도 저작권료를 받기 어려운 관행이 일반적이었습니다. 한국음악저작권협회(KOMCA)는 1964년 설립됐지만 실질적인 저작권료 분배 체계가 작동하기 시작한 것은 1987년 이후입니다. 스트리밍 시대에 KOMCA 등록의 중요성은 더 커졌습니다. 멜론·스포티파이에서 한 곡이 100만 스트리밍을 기록할 때 KOMCA 미등록 아티스트는 작곡권 분배(스트리밍 수익의 약 10~12%)를 수령할 수 없고, 이 금액은 KOMCA 미분배 pool로 남아 다른 등록 아티스트들에게 재분배됩니다. 즉 내 곡이 스트리밍되어도 내가 받지 못하는 저작권료가 다른 사람에게 가는 구조입니다. 음원 유통사(카카오·원스토어·멜론)는 KOMCA 등록 여부와 무관하게 마스터 수익을 정산하지만, KOMCA에 별도 등록해야만 작곡권·작사권 수익이 추가로 수령됩니다. 인디 뮤지션이 연간 수백만 원 이상의 저작권료 손실을 방치하는 가장 흔한 이유가 바로 이 등록 누락입니다.

## 음악 저작권의 종류

### 저작권 (Copyright)

작사자·작곡자가 가지는 권리. 음악의 창작 행위 자체에서 발생합니다.

| 저작권 유형 | 권리자 | 관리 기관 |
|-----------|--------|---------|
| 작사 저작권 | 작사가 | KOMCA |
| 작곡 저작권 | 작곡가 | KOMCA |
| 편곡 저작권 | 편곡가 | KOMCA (별도 등록) |

### 저작인접권

- **음반 제작자**: 음반에 고정된 음원에 대한 권리
- **실연자**: 연주·노래 행위에 대한 권리 (한국음악실연자연합회 관리)

## KOMCA 저작권 등록 방법

### 1단계: KOMCA 회원 가입

1. [KOMCA 홈페이지](https://www.komca.or.kr) 접속
2. 회원 가입 (개인 또는 법인)
3. 신청서 작성 — 본인 확인 서류 제출

**가입 조건:**
- 스트리밍 발매 완료 곡 또는 방송·공연 사용 이력 있는 곡이 1곡 이상 있을 것

### 2단계: 저작물 등록

- 곡명, 작사가, 작곡가, 편곡가 정보 입력
- 악보 파일 (PDF) 또는 가사 파일 제출
- 스트리밍 발매 링크 첨부

### 3단계: 저작권료 수령

등록 후 KOMCA가 각 플랫폼·방송사에서 저작권료를 수거해 분기별로 정산합니다.

## 저작권료가 발생하는 경로

| 경로 | 발생 조건 | 수령 기관 |
|------|--------|---------|
| 스트리밍 | 멜론·스포티파이 등 재생 | KOMCA |
| 방송 (TV·라디오) | 방송 사용 | KOMCA |
| 유튜브 | Content ID 등록 시 | YouTube → KOMCA 또는 직접 |
| 공연 | 공연장 사용 신청 시 | KOMCA |
| 영화·광고 동기화 | 계약에 의해 | 직접 협상 또는 KOMCA |

---

## 커버곡 저작권 처리

### 유튜브에서 커버곡 게시 시

- Content ID 시스템이 원저작자에게 광고 수익 자동 분배
- 채널 삭제·저작권 경고는 대부분 발생하지 않음 (단, 원저작자가 차단 설정 시 예외)

### 스트리밍 플랫폼 커버곡 발매 시

커버곡을 멜론·스포티파이에 발매하려면 **기계적 저작권 라이선스(Mechanical License)** 취득이 필요합니다.

| 방법 | 설명 |
|------|------|
| DistroKid Cover Song 라이선스 | 미국 곡 한정, 곡당 $12 |
| 음원 유통사 통해 요청 | 국내 곡 포함 처리 가능 |
| KOMCA 직접 신청 | 국내 곡 기계적 이용 허락 |

## 자작곡 저작권 보호 체크리스트

- [ ] KOMCA 회원 가입
- [ ] 발매 곡 KOMCA 저작물 등록
- [ ] 유튜브 아티스트 채널 인증 (Content ID 직접 관리 옵션)
- [ ] 음원 유통사와 저작권 분배 조건 확인
- [ ] 음반 제작자 저작인접권 등록 (음반 발매 후)

## 마치며

저작권 등록은 내 음악이 돈을 벌기 시작하는 기반입니다. 발매와 동시에 KOMCA 등록을 챙기세요. KOMCA 등록에서 가장 많이 실수하는 부분은 공동 창작물의 지분 분배 입력입니다. 작사와 작곡을 각각 다른 사람이 맡았다면 작사권과 작곡권의 기여자를 별도로 입력해야 하며, 초기에 잘못 입력한 지분은 수정이 번거롭기 때문에 공동 창작자와 사전에 지분 비율을 합의하고 문서화한 뒤 등록하는 것이 중요합니다.

음원 발매 전 KOMCA 등록을 완료해두면 발매 직후부터 스트리밍 저작권료가 집계되기 시작합니다. 발매 후 등록해도 소급 적용이 가능하지만 등록 이전의 스트리밍 저작권료는 회수가 어렵습니다. 가수이자 연주자라면 KOMCA(작사·작곡권) 외에 한국음악실연자연합회(실연자권)에도 별도 등록해 두 기관에서 이중으로 수익을 수령하는 구조를 만드는 것이 인디 아티스트의 최적 저작권 관리 방식입니다.

## Studio NOL이 음악 저작권 관리자에게 자주 권하는 3가지

스튜디오 놀(연신내, 서울 은평구)에서 음악 저작권 상담에서 반복적으로 드리는 조언입니다.

**1. KOMCA 사전 등록 — 발매 전 완료**

발매 전 KOMCA 등록 완료. 발매 후 등록은 소급 회수 어려움.

**2. 가수 + 연주자 — 두 기관 이중 등록**

작사·작곡권은 KOMCA, 실연자권은 한국음악실연자연합회 별도 등록.

**3. 정산 주기 — 분기·반기 별 확인**

저작권료는 분기·반기 별 정산. 본인 작품 정산 확인 습관.
