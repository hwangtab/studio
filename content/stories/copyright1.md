## 내 음악을 법적으로 보호하는 방법

자작곡을 발매했다고 해서 저작권이 자동으로 보호되는 것은 아닙니다. 방송·스트리밍·공연 수익을 실제로 받으려면 **KOMCA(한국음악저작권협회)** 등록이 필요합니다.

---

## 음악 저작권의 종류

### 저작권 (Copyright)

작사자·작곡자가 가지는 권리. 음악의 창작 행위 자체에서 발생합니다.

| 저작권 유형 | 권리자 | 관리 기관 |
|-----------|--------|---------|
| 작사 저작권 | 작사가 | KOMCA |
| 작곡 저작권 | 작곡가 | KOMCA |
| 편곡 저작권 | 편곡가 | KOMCA (별도 등록) |

### 저작인접권

- **음반 제작자**: 음반에 고정된 음원에 대한 권리
- **실연자**: 연주·노래 행위에 대한 권리 (한국음악실연자연합회 관리)

---

## KOMCA 저작권 등록 방법

### 1단계: KOMCA 회원 가입

1. [KOMCA 홈페이지](https://www.komca.or.kr) 접속
2. 회원 가입 (개인 또는 법인)
3. 신청서 작성 — 본인 확인 서류 제출

**가입 조건:**
- 스트리밍 발매 완료 곡 또는 방송·공연 사용 이력 있는 곡이 1곡 이상 있을 것

### 2단계: 저작물 등록

- 곡명, 작사가, 작곡가, 편곡가 정보 입력
- 악보 파일 (PDF) 또는 가사 파일 제출
- 스트리밍 발매 링크 첨부

### 3단계: 저작권료 수령

등록 후 KOMCA가 각 플랫폼·방송사에서 저작권료를 수거해 분기별로 정산합니다.

---

## 저작권료가 발생하는 경로

| 경로 | 발생 조건 | 수령 기관 |
|------|--------|---------|
| 스트리밍 | 멜론·스포티파이 등 재생 | KOMCA |
| 방송 (TV·라디오) | 방송 사용 | KOMCA |
| 유튜브 | Content ID 등록 시 | YouTube → KOMCA 또는 직접 |
| 공연 | 공연장 사용 신청 시 | KOMCA |
| 영화·광고 동기화 | 계약에 의해 | 직접 협상 또는 KOMCA |

---

## 커버곡 저작권 처리

### 유튜브에서 커버곡 게시 시

- Content ID 시스템이 원저작자에게 광고 수익 자동 분배
- 채널 삭제·저작권 경고는 대부분 발생하지 않음 (단, 원저작자가 차단 설정 시 예외)

### 스트리밍 플랫폼 커버곡 발매 시

커버곡을 멜론·스포티파이에 발매하려면 **기계적 저작권 라이선스(Mechanical License)** 취득이 필요합니다.

| 방법 | 설명 |
|------|------|
| DistroKid Cover Song 라이선스 | 미국 곡 한정, 곡당 $12 |
| 음원 유통사 통해 요청 | 국내 곡 포함 처리 가능 |
| KOMCA 직접 신청 | 국내 곡 기계적 이용 허락 |

- [ ] KOMCA 회원 가입

- [ ] 음원 유통사와 저작권 분배 조건 확인
- [ ] 음반 제작자 저작인접권 등록 (음반 발매 후)
