# 드럼 비밥·재즈 비밥 드러밍·Max Roach — 음악연습실 완전 가이드

비밥(Bebop)은 **1940년대 탄생한 모던 재즈의 혁명**입니다. Charlie Parker, Dizzy Gillespie의 빠른 멜로딕 라인을 지지하기 위해 드럼도 혁명적으로 변했습니다. Kenny Clarke, Max Roach, Art Blakey가 비밥 드러밍을 정의했습니다.

---

## 비밥 드러밍의 혁명

### 스윙에서 비밥으로의 전환

| 요소 | 스윙 | 비밥 |
|-----|------|------|
| 리듬의 중심 | 스네어·킥이 강박 유지 | 라이드 심벌로 이동 |
| 템포 | 중간 | 매우 빠름 (♩=200-300+) |
| 킥 드럼 | 규칙적 4박 | 자유로운 "bomb dropping" |
| 스네어 | 2·4박 고정 | 자유로운 악센트 |
| 라이드 | 보조적 | 리듬의 주역 |

### "Dropping Bombs"

비밥의 대표적 기법:

**킥 드럼으로 "폭탄 투하":**
```
예상치 못한 위치에 강한 킥 드럼
리듬의 긴장감 생성
주로 솔로이스트의 구절 끝에 맞춰
```

## Kenny Clarke — 비밥 드러밍의 창시자

### 라이드 심벌로 리듬 이동

Kenny Clarke의 혁신:
- **라이드 심벌**이 주 리듬 도구가 됨
- 스네어·킥 = 자유로운 대위선율
- 하이햇 = 2박, 4박 클로즈

**Clarke 스타일 기본 비밥 패턴:**
```
라이드: 딩-딩-딩-딩-딩-딩 (스윙 8분음표 3연음)
하이햇: . . x . . . x . (2, 4박 발로 클로즈)
스네어: 자유롭게 (2, 4박 기본 + 즉흥 악센트)
킥: 자유롭게 (bomb dropping)
```

### 라이드 패턴 상세

**비밥 라이드 심벌 패턴:**
```
ding-ding-da-ding: 기본 비밥 리듬
(8분-8분-16분-8분 = 스윙 3연음 변형)

표기:
1  +  2  +  3  +  4  +
ding    ding da ding    (스윙 느낌)
```

## Max Roach — 비밥 드러밍의 완성

### "We Insist!" 스타일

Max Roach (Clifford Brown Quintet)의 특징:
- **완벽한 박자감:** 흔들림 없는 템포
- **음악적 표현:** 드럼이 멜로디처럼
- **독주 능력:** 솔로 드럼 작품 다수

**Roach 스타일 악센트:**
```
라이드 심벌 패턴 유지하면서
예상치 못한 위치에 스네어 악센트
청중을 의외성으로 이끌기
```

### 드럼 솔로 구성

Max Roach는 드럼 솔로를 **음악적 작품**으로:

```
솔로 구조:
1. 테마 제시 (라이드로 리듬 테마)
2. 변형 (다른 드럼으로 이동)
3. 빌드업 (점점 복잡하게)
4. 클라이맥스
5. 해결 (처음 리듬으로 돌아옴)
```

## Art Blakey — 하드밥의 불꽃

### Jazz Messengers 스타일

Art Blakey (Jazz Messengers)의 특징:
- **파워풀한 스네어:** 강한 2·4박 백비트
- **심벌 워시:** 크래시 심벌 자유롭게 사용
- **훵키한 느낌:** 블루스·가스펠 영향

**Blakey 스타일 백비트:**
```
스네어 2·4박 = 강하게! (큰 소리)
라이드: 비밥 패턴
킥: 1박 + 폭탄 투하
결과: 하드밥의 에너지
```

### 밴드 드라이빙

Blakey는 "밴드를 몰아붙이는 드러머":
```
크레센도: 점점 크게 연주하여 밴드를 밀어붙임
심벌 워시: 밴드 전체를 감싸는 심벌 사운드
킥: 밴드의 약점에 강한 액센트
```

## 비밥 드러밍 기법 상세

### 라이드 심벌 그립

**트래디셔널 그립(Traditional Grip):**
```
왼손: 엄지·검지 사이에 스틱 끼우기
      손바닥이 위로 향하지 않음
오른손: 매치드 그립
비밥 드러머 대부분 사용
```

### 하이햇 발 기법

**비밥 하이햇:**
```
2박, 4박에 발로 하이햇 클로즈
소리 내지 않고 (뮤트)
또는 약하게 "치크" 소리
= 박자감의 기준점
```

**하이햇 변형:**
```
기본: 2, 4박
변형: 1, 3박 (반전)
빌드업: 매 박 (모든 8분음표)
```

### 킥 드럼 비밥 패턴

**비밥 킥 어프로치:**
```
일반 재즈: 킥을 최소화
비밥: 솔로이스트와 대화
       구절 끝에 강한 킥 (bomb)
       솔로이스트 피크에 킥 호응
```

## 빠른 템포 트레이닝

### 비밥 템포 기준

```
슬로우 비밥: ♩= 160-200
미디엄 비밥: ♩= 200-240
패스트 비밥: ♩= 240-300+
```

### 템포 올리기 방법

**단계적 접근:**
```
1단계: ♩= 120 (스윙 패턴 완벽히)
2단계: ♩= 144
3단계: ♩= 160
4단계: ♩= 180
5단계: ♩= 200 (비밥 영역)
각 단계에서 1주일 이상 연습
```

**주의사항:**
```
빠른 템포에서 라이드 패턴 무너지지 않게
하이햇 2·4박 일관성 유지
킥 드럼 자유롭게 사용 (조심스럽게)
```

## 음악연습실 비밥 드러밍 연습

### 60분 루틴

**1. 라이드 심벌 (15분)**
   - 기본 비밥 라이드 패턴
   - ♩= 120부터 시작
   - 하이햇 2·4박 동시
   - 점차 템포 올리기

**2. 4-way Coordination (15분)**
   - 라이드 + 하이햇 + 스네어 + 킥
   - 각각 독립적으로 움직이기
   - 비밥 패턴에서 킥 자유롭게

**3. 폭탄 투하 연습 (15분)**
   - 라이드 유지하면서 예상치 못한 킥
   - 솔로이스트 시뮬레이션 (메트로놈)에 반응
   - Blakey 스타일 백비트 강하게

**4. 곡 적용 (15분)**
   - "Autumn Leaves" 비밥 템포
   - 드럼 솔로 4마디 즉흥
   - 전체 팀 사운드 느끼기

## 마무리
