## 정읍에서 KTX로 1시간 40분

정읍역은 KTX 호남선의 주요 정차역으로 서울역까지 약 1시간 30~40분에 연결됩니다. 전북 남부 지역에서 서울 스튜디오 접근성이 우수한 도시입니다.

---

## 정읍 → 연신내 이동 경로

### KTX 정읍역 이용 (권장)

```
① 정읍역에서 KTX 탑승 (서울역 방면)
② 서울역 도착 (약 1시간 30~40분)
③ 1호선 또는 6호선 환승 → 연신내역 (약 30~40분)

총 소요시간: 약 2시간 10~20분
```

### 김제에서 출발 (정읍역 환승)

```
① 김제 시내 → 정읍역 (버스·택시 약 20~30분)
② 정읍역 KTX → 서울역 (약 1시간 30~40분)
③ 서울역 → 연신내역 (약 30~40분)

총 소요시간: 약 2시간 30~40분
```

## 당일 왕복 일정 예시 (정읍 기준)

```
오전 7시 30분 정읍역 출발 (KTX)
→ 오전 9시 20분 서울역 도착
→ 오전 10시 연신내역 도착
→ 오전 10시 30분 세션 시작 (2시간)
→ 오후 12시 30분 세션 완료
→ 오후 2시 서울역 출발
→ 오후 3시 40분 정읍역 도착
```
