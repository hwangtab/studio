# 기타 켈틱·아이리쉬 핑거피킹·전통 멜로디 — 음악연습실 완전 가이드

켈틱 기타(Celtic Guitar)는 **아일랜드, 스코틀랜드, 웨일즈 등 켈트족 음악 전통을 기타로 표현**하는 장르입니다. Davy Graham, Martin Simpson, Tony McManus가 켈틱 기타를 세계적으로 알렸습니다. DADGAD 튜닝, 드론 현, 오르나멘테이션이 켈틱 기타의 핵심입니다.

---

## 켈틱 기타의 특징

### 핵심 요소

| 요소 | 내용 |
|-----|------|
| 튜닝 | DADGAD (가장 일반적) |
| 조성 | D 메이저, G 메이저, A 마이너 중심 |
| 리듬 | 릴(Reel), 지그(Jig), 혼파이프(Hornpipe) |
| 기법 | 드론 현, 핑거피킹, 오르나멘테이션 |
| 악기 | 피들(바이올린), 틴 휘슬, 보드란의 기타 버전 |

### 켈틱 모드

켈틱 음악은 **교회 모드** 기반:
```
D 믹솔리디안: D-E-F#-G-A-B-C (b7)
D 도리안: D-E-F-G-A-B-C (b3, b7)
A 에올리안: A-B-C-D-E-F-G (단조)
```

**켈틱의 특징:** 반음 없는 스케일 (주로 펜타토닉+α)

---

## DADGAD 튜닝 켈틱

### DADGAD 기본 복습

```
6번: D2
5번: A2
4번: D3
3번: G3
2번: A3
1번: D4
```

**오픈 코드:** Dsus4 (D-A-D-G-A-D)

### 켈틱 DADGAD 기본 코드

**D 코드 (오픈):**
```
6-1번 모두 오픈 = Dsus4
5번 2프렛 = F#: D 메이저
```

**G 코드:**
```
5번 2프렛, 4번 0, 3번 0, 2번 0, 1번 3프렛
= G 코드
```

**Am 코드:**
```
5번 0, 4번 2프렛, 3번 2프렛, 2번 0, 1번 0
= Am (DADGAD에서)
```

---

## 드론 현 (Drone)

### 드론의 역할

켈틱 음악에서 드론 = **백파이프의 저음 지속음 모방**

**DADGAD 드론:**
```
6번 줄(D2) + 5번 줄(A2) = 항상 울리게
멜로디는 나머지 줄에서
= 드론 위의 멜로디
```

### 드론 핑거피킹

**엄지로 드론:**
```
엄지: 6번, 5번 줄 번갈아가며 계속
손가락: 1-4번 줄에서 멜로디
동시에 드론+멜로디 연주
```

**기본 드론 패턴:**
```
엄지: D2(6번) - A2(5번) - D2 - A2...
손가락: 멜로디 위에서 자유롭게
```

---

## 릴 (Reel) 리듬

### 릴이란?

아이리쉬 전통 댄스 음악:

**릴 박자:**
```
4/4 박자 (또는 Cut Time 2/2)
빠른 템포: ♩= 160-200
8분음표를 스윙하지 않고 균등하게
```

**릴 리듬 패턴:**
```
1박: 강 - 약 - 강 - 약
16분음표: 균등하게 (스윙 없음)
```

### 릴 멜로디 예: "The Morning Dew"

```
D 믹솔리디안으로:
D4-E4-F#4-G4-A4 (8분음표 상행)
A4-G4-F#4-E4-D4 (하행)
```

**DADGAD에서 연주:**
```
D4: 2번 줄 오픈
E4: 2번 줄 2프렛
F#4: 1번 줄 3프렛
G4: 1번 줄 5프렛
A4: 1번 줄 7프렛
```

---

## 지그 (Jig) 리듬

### 지그란?

**지그 박자:**
```
6/8 박자 (또는 9/8, 12/8)
세 가지 8분음표가 그룹 = "쿵-강-강"
빠른 템포: ♩= 100-120
```

**지그 리듬 패턴:**
```
1-2-3: 쿵-강-강 (강-약-약)
4-5-6: 쿵-강-강
= 두 그룹의 3연음
```

### 지그 멜로디 예: "The Irish Washerwoman"

```
6/8에서:
G4-A4-B4 (1-2-3)
G4-F#4-E4 (4-5-6)
D4-E4-F#4 (1-2-3)
G4 (4박 강조)
```

---

## 켈틱 오르나멘테이션

### 크런(Crun)

**크런:** 2-3음의 빠른 장식음

**피들 크런을 기타로:**
```
E4를 연주하기 전: D4-E4-D4-E4 (빠르게)
= 앞꾸밈음 효과
```

### 컷(Cut)

**컷:** 음 위의 반음 또는 온음으로 빠르게 장식

```
A4를 연주할 때:
B4(빠르게) → A4 (실제 음)
= 위에서 내려오는 장식
```

### 롤(Roll)

**롤:** 5음 장식음 패턴

```
A4 롤:
A4-B4-A4-G4-A4 (매우 빠르게)
= 5음이 하나의 음처럼 들림
```

## 켈틱 핑거피킹 스타일

### Tony McManus 스타일

현대 켈틱 기타의 대가 Tony McManus:
- **풍부한 화음:** 단순한 드론 이상의 보이싱
- **오르나멘테이션:** 피들 스타일 장식음
- **빠른 릴:** 빠른 템포에서도 명확한 아티큘레이션

**McManus 핑거피킹:**
```
엄지: 베이스 + 드론 (6번, 5번 줄)
검지: 4번, 3번 줄 (중간 화음)
중지: 2번 줄 (내부 멜로디)
약지: 1번 줄 (상단 멜로디)
```

---

## 전통 켈틱 멜로디 기타 편곡

### 편곡 방법

**피들 멜로디를 기타로:**
1. 멜로디를 1번·2번 줄로 연주
2. 드론(D, A)을 낮은 줄에 추가
3. 화음 일부를 중간 줄에 추가
4. 오르나멘테이션 추가

**단순 편곡 예:**
```
피들: G4-A4-B4-A4-G4
기타: G4(1줄)+D3(4줄드론) / A4+A2 / B4+D3 / A4+A2 / G4+D3
```

## 음악연습실 켈틱 기타 연습

### 60분 루틴

**1. DADGAD 튜닝·코드 (15분)**
   - DADGAD 정확한 튜닝
   - 기본 켈틱 코드 (D, G, Am, Em)
   - 드론 현 연습

**2. 릴 리듬 (15분)**
   - 기본 8분음표 릴 리듬
   - 간단한 D 믹솔리디안 멜로디
   - 드론+멜로디 동시

**3. 오르나멘테이션 (15분)**
   - 크런 연습 (느리게)
   - 컷 연습
   - 실제 멜로디에 장식음 추가

**4. 전통 곡 연습 (15분)**
   - "Scarborough Fair" 또는 켈틱 곡
   - 핑거피킹으로 편곡
   - 드론 유지하면서

## 마무리

켈틱 기타는 **전통과 현대의 만남**입니다. 수백 년 된 아이리쉬 멜로디가 DADGAD 기타 위에서 새롭게 태어납니다. Tony McManus, Davy Graham이 보여준 것처럼, 켈틱 음악은 기타에서 무한한 가능성을 가집니다.

은평구 24시간 음악연습실에서 DADGAD를 튜닝하고, 드론 현을 울리고, 릴 리듬을 익히세요. 켈틱의 심장이 뛰는 소리를 들을 것입니다.
