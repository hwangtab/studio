## 음악연습실, 처음이라 막막한 분들을 위한 가이드

음악연습실을 처음 방문하는 분들이 공통으로 궁금해하는 것들을 단계별로 정리했습니다.

---

## STEP 1 — 예약하기

### 시간제 이용 예약

1. **연습실 검색**: 지역명 + "음악연습실" 검색 → 위치·방음·가격 비교
2. **예약 채널**: 네이버 예약, 카카오채널, 전화, 직접 방문
3. **날짜·시간 선택**: 원하는 시간대 확인 (주말·저녁은 조기 마감)
4. **요금 확인**: 시간당 가격 × 이용 시간 계산

### 월세 입주 신청

1. 연습실 방문 또는 카카오채널 상담
2. 공실 확인 및 견학 일정 조율
3. 계약서 작성 + 첫 달 월세 선납
4. 개인 도어록 코드 발급 → 즉시 24시간 이용 가능

---

## STEP 2 — 준비물 챙기기

### 필수 지참물

- **신분증**: 본인 확인용 (무인 연습실은 도어록 코드로 대체)
- **이용료**: 현금 또는 카드 (연습실마다 다름)
- **음악 파일**: MR(반주 파일)이 담긴 스마트폰·노트북

### 선택 지참물 (있으면 좋음)

- **개인 마이크**: 다이나믹 또는 콘덴서 마이크
- **이어폰·헤드폰**: 조용한 환경에서의 모니터링
- **악보·노트**: 연습 내용 기록

---

## STEP 3 — 입실하기

### 무인 연습실 입실 절차 (스튜디오 놀 기준)

1. 예약 확정 후 카카오채널로 도어록 코드 수신
2. 연신내역 4번 출구 도착 → 도보 5분
3. 건물 입구 공동 도어록 → 해당 방 도어록 입력
4. 입실 완료 → 냉난방 켜기 → 연습 시작

### 입실 후 기본 세팅

- **냉난방**: 개별 리모컨으로 원하는 온도 설정
- **PA 스피커**: 전원 ON → 블루투스 또는 케이블로 스마트폰 연결
- **마이크**: 스탠드에 장착 → PA 스피커 마이크 입력 연결
- **조명**: 스위치 ON (전부 최대 밝기 또는 조절 가능)

---

## STEP 4 — 연습하기

### 보컬 연습 기본 세팅

```

스마트폰(MR 재생) → PA 스피커 (보조 입력)
마이크 → PA 스피커 (마이크 입력)
볼륨: MR 볼륨 : 마이크 볼륨 = 약 6:4 비율

```

### 건반·피아노 연습

- 피아노: 건반 덮개 열기 → 그대로 연주 (별도 연결 불필요)
- 디지털 건반: 전원 ON → 헤드폰 또는 PA 스피커 연결

### 기타·베이스 연습

- 개인 앰프 없을 경우: 오디오 인터페이스 → 노트북 → 스피커
- 어쿠스틱 기타: 앰프 없이 바로 연주 가능

---

## STEP 5 — 퇴실하기

1. **정리**: 마이크 스탠드 원위치, 의자 정렬
2. **전원 OFF**: PA 스피커, 냉난방 전원 끄기
3. **문 잠금**: 퇴실 후 도어록이 자동 잠김 확인
4. **분실물 확인**: 개인 소지품·악기 챙기기

---

## 음악연습실 이용 시 흔한 실수

| 실수 | 해결법 |
|-----|------|
| PA 스피커 볼륨을 너무 크게 설정 | 처음에는 낮게 시작, 서서히 올리기 |
| 냉난방 끄지 않고 퇴실 | 퇴실 체크리스트 사용 |
| 마이크 에코 효과 켜 놓음 | 드라이 신호로 연습하는 것이 발성에 유리 |
| 이용 시간 초과 | 예약 종료 15분 전 알람 설정 |

---

## 스튜디오 놀 첫 이용 안내

| 항목 | 내용 |
|-----|-----|
| 예약 방법 | 카카오채널 상담 또는 전화 |
| 입실 방법 | 무인 도어록 코드 (카카오로 발송) |
| 시간 대여 | 운영하지 않음 (월세 입주 전용) |
| 월세 입주 | 36만원~, 6개월 계약 시 첫 달 50% 할인 |
| 위치 | 연신내역 4번 출구 도보 5분 |
| 문의 | 카카오채널 '스튜디오 놀' |

---

### 효율적인 연습 원칙

- **목표 설정 → 연습 → 검증 루틴** — 목표를 정하고, 집중 연습하고, 녹음으로 개선을 확인하는 3단계를 매 세션에 적용
- **분리 연습 원칙** — 전체 반복보다 문제 구간만 2~4마디 앞부터 분리해서 집중하는 것이 훨씬 효과적
- **완성된 느낌의 함정 경계** — 잘 된다고 느끼는 순간이 실제로 완성된 순간과 다를 수 있음. 녹음으로 객관적 확인 필수

### 연습 중 자주 하는 실수

1. **목표 없는 반복 — 시간만 소비** — 무엇을 개선할지 모르는 반복은 잘못된 패턴만 강화. 매 세션 전 "오늘 이것만은 해결한다" 목표 1개를 설정
2. **어려운 구간 회피 — 약점 지속** — 잘 되는 부분만 반복하면 약점이 영원히 남음. 불편하고 어려운 구간이 실력 향상의 핵심 포인트
3. **자기 연주의 객관적 청취 불가** — 연주 중에는 자신의 소리를 객관적으로 듣기 어려움. 녹음 후 청취로 문제를 발견하고 수정하는 루틴이 필요

### 연습 자가 진단

- [ ] 오늘 연습의 구체적인 목표를 시작 전에 정했는가?
- [ ] 어려운 구간을 분리해서 집중적으로 반복했는가?
- [ ] 연습 후 무엇이 개선되었는지 구체적으로 인식하는가?

## Studio NOL이 연습실 처음 방문하는 분에게 자주 권하는 3가지

스튜디오 놀(연신내, 서울 은평구) 음악연습실에서 처음 이용 상담 때 자주 드리는 조언입니다.

**1. 무료 견학 — 결정 전 직접 확인**

월세 입주 전 무료 견학 필수. 방음·시설 직접 확인 후 결정.

**2. 카카오톡 오픈채팅 — 빠른 응답**

전화·이메일보다 카카오톡 오픈채팅(open.kakao.com/me/nol)이 가장 빠른 응답.

**3. 6개월 계약 — 첫 달 50% 할인**

6개월 계약 시 첫 달 50% 할인. 단기 1개월도 가능하지만 6개월이 가성비.
