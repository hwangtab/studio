## 홈 레코딩의 가능성과 한계

홈 레코딩은 언제든 편하게 녹음할 수 있다는 큰 장점이 있습니다. 환경을 잘 구축하면 드라이 보컬 수준의 높은 품질도 가능합니다.

---

## 홈 레코딩 필수 장비

| 장비 | 역할 | 예산별 추천 |
|------|------|-----------|
| 오디오 인터페이스 | XLR 연결·저레이턴시 | 10~30만원: Scarlett Solo / 30~50만원: UA Volt |
| 콘덴서 마이크 | 보컬 메인 녹음 | 10~20만원: AT2020 / 20~50만원: Rode NT1 |
| 팝 필터 | 파열음 제거 | 1~3만원 |
| 마이크 스탠드 | 안정적 위치 고정 | 3~10만원 |
| 모니터 헤드폰 | 녹음 중 모니터링 | 10~30만원: Sony MDR-7506 |
| DAW | 녹음·편집 소프트웨어 | 무료: Garageband / 유료: Logic Pro, Ableton |

## 공간 어쿠스틱 처리

레이턴시 설정은 녹음과 믹싱 단계에서 각각 다르게 최적화하는 것이 좋습니다.

### 가장 간단한 방법 — 이불·옷장 활용

- 옷장 안(옷이 가득 걸린)에서 녹음
- 이불이나 담요로 마이크 주변 둘러싸기
- 침실이 거실보다 어쿠스틱이 좋은 경우 많음

### 예산형 흡음재 설치

- 코너 베이스 트랩 (저음 흡수)
- 벽면 흡음 패널 (반사음 제거)
- 천장 반사판 흡음 처리

### 피해야 할 환경

- 콘크리트·타일 바닥이 모두 노출된 공간 (반향 심함)
- 큰 유리창이 많은 공간
- 환기 팬·냉장고 소음이 있는 공간

### 테스트 방법

- 박수를 치고 echo/reverb 느껴보기
- 팔짝팔짝 빠르게 사라지면 양호한 어쿠스틱

## 홈 보컬 녹음 세팅

불필요한 배경 소음을 차단하는 것이 노이즈 제거 플러그인보다 효과적입니다.

### 마이크 위치

- 입에서 약 20~30cm 거리
- 마이크를 입 높이나 약간 위로 — 코 방향으로 지향
- 팝 필터는 마이크와 5~10cm 거리

### DAW 기본 세팅

- **샘플레이트**: 44.1kHz
- **비트뎁스**: 24bit
- **모니터 레이턴시**: 5ms 이하 목표
- **입력 게인**: -18dBFS ~ -12dBFS (피킹 방지)

### 모니터링

- 헤드폰으로 MR + 자신의 목소리 동시에 모니터
- Direct Monitoring 기능 활성화 (오디오 인터페이스)
- 자신의 목소리 레벨: MR보다 약간 크게 설정

---

## 홈 녹음 후 스튜디오 믹싱 의뢰

마이크 위치를 조금만 바꿔도 음색이 크게 달라지므로 충분한 테스트가 필요합니다.

### 온라인 의뢰 절차

드라이 보컬 WAV 녹음 (홈)
- 파일 클리닝 (무음 구간, 잡음 제거)
- 구글 드라이브 / WeTransfer 업로드
- 카카오톡으로 링크 전송
- 스튜디오 놀 믹싱·마스터링 (영업일 2~5일)
- 완성 WAV + MP3 납품

### 홈 녹음 품질을 높이는 핵심

- 드라이 보컬 (리버브 없이 녹음)
- 클리핑(과부하) 없는 게인 레벨
- 배경 소음 최소화 (조용한 심야 녹음)

### 녹음 세션 공통 체크리스트

**준비 단계**
- [ ] 세션 목표 명확히 설정 (완성할 구간·트랙 수)
- [ ] 모든 파일·장비 사전 점검 완료
- [ ] 아티스트 컨디션 확인 (보컬: 목 상태, 악기: 튜닝)

**세션 중**
- [ ] 테이크별 메모 (베스트/리테이크 표시)
- [ ] 문제 구간 즉시 인식하고 재녹음 결정
- [ ] 세션 종료 30분 전 마무리 시작

**후반 작업**
- [ ] 원본 파일 즉시 백업
- [ ] 믹싱 전 24시간 이상 청취 공백 유지

### 세션 효율을 높이는 팁

1. **가장 어려운 구간을 세션 초반에** — 에너지가 최고일 때 어려운 것 먼저
2. **구간 분리 녹음** — 전체 통으로 반복보다 구간별 완성 후 연결
3. **즉각 피드백** — 녹음 직후 헤드폰으로 바로 모니터링

## 마치며

홈 레코딩은 아이디어 캡처와 드라이 보컬 수집에 매우 유용합니다. 하지만 최종 완성도를 위해서는 스튜디오 놀의 전문 믹싱·마스터링을 활용하면 훨씬 높은 품질의 결과물을 얻을 수 있습니다.
