# 기타 재즈 리듬·콤핑 기법 — 음악연습실 완전 가이드

재즈 리듬 기타는 솔로 기타와 완전히 다릅니다. **콤핑(Comping)**은 솔리스트를 지지하고 대화하면서도 자신의 음악적 발언을 하는 기술입니다. 피아노가 없는 재즈 트리오나 쿼텟에서 기타 리듬은 하모니·리듬·대위를 동시에 담당합니다.

---

## 콤핑이란?

### 콤핑의 정의

**Comping = Accompanying**의 줄임말:
- 솔리스트의 연주에 리스펀스(반응)하기
- 하모니 지지
- 리듬적 서포트
- 공간 채우기와 비우기

### 콤핑의 핵심 원칙

1. **솔리스트에게 공간 주기**: 솔로 구간에서 과하게 치지 않기
2. **코드 변화 예측**: 다음 코드로 자연스럽게 이동
3. **다이나믹 반응**: 솔리스트의 강약에 맞추기
4. **음악적 대화**: 솔리스트의 프레이즈에 반응하는 리스펀스

## 재즈 리듬 기타 기초

### 4비트 리듬 (Freddie Green 스타일)

Basie 밴드의 전설적 기타리스트 Freddie Green의 스타일:

**4박자 전부에 가벼운 코드 스트로크:**
```
박 1: ♩ (코드)
박 2: ♩ (코드)
박 3: ♩ (코드)
박 4: ♩ (코드)
```

**보이싱 특징:**
- 루트 없는 3-음 코드 (보통 3도, 5도, 7도)
- 3번 현 아래 영역에서 연주 (저음 현 뮤트)
- 가볍고 절제된 다운 스트로크

### 프레디 그린 보이싱 예시

**G7:**
```
3번 현: B(오픈)
4번 현: F(3프렛)
5번 현: D(오픈)
6번 현: 뮤트
```

**Cmaj7:**
```
3번 현: G(오픈)
4번 현: E(2프렛)
5번 현: 뮤트
```

## 싱코페이션 콤핑

### 업비트 콤핑 패턴

4비트 대신 업비트(and)에 코드:

```
박 1-and: 코드
박 2-and: 코드
박 3-and: 코드
박 4-and: 코드
```

이 패턴이 더 모던하고 스윙감이 있습니다.

### 블록 코드 콤핑

특정 박에만 강한 코드 타격:

```
박 2: 강한 코드
박 4: 강한 코드
(2, 4박 백비트와 함께)
```

## 리스펀스 콤핑

### 솔리스트와의 대화

가장 고급 콤핑 기술:

**솔리스트 프레이즈 A:**
```
C-E-G-B (짧은 리프)
```

**기타 리스펀스:**
```
다음 박자에 간단한 코드 스트로크로 반응
→ 음악적 대화처럼
```

### 공간 남기기

솔리스트가 연주하는 동안 콤핑 줄이기:
- 솔리스트 롱 노트: 기타는 쉬기
- 솔리스트 쉬는 구간: 기타 짧은 필

---

## 재즈 코드 연결

### 가이드 톤 (Guide Tone) 진행

코드 변화에서 3도와 7도를 부드럽게 연결:

**G7 → Cmaj7:**
```
G7의 7도(F) → Cmaj7의 7도(B)로 반음 이동
G7의 3도(B) → Cmaj7의 3도(E)로 4도 하강
```

이 최소 이동이 재즈 코드 진행의 부드러움을 만듭니다.

### 크로매틱 접근 보이싱

코드 변화 직전에 반음 위 또는 아래에서 접근:

**C로 가기 전:**
```
B7 보이싱 (반음 아래) → Cmaj7로 해결
```

## 음악연습실 재즈 리듬 기타 연습 루틴

### 기초 (30분)

1. **4비트 Freddie Green**: G 블루스 진행에서 (10분)
2. **3음 보이싱 암기**: G7, Cmaj7, Dm7, Am7 (10분)
3. **업비트 콤핑**: 기본 업비트 패턴 (10분)

### 중급 (30분)

1. **II-V-I 콤핑**: Dm7-G7-Cmaj7 부드러운 연결 (10분)
2. **가이드 톤 진행**: 3도, 7도 목소리 이끌기 (10분)
3. **Blues 콤핑**: 12마디 블루스 전체 (10분)

### 리스펀스 훈련 (30분)

1. 재즈 트리오 음원 위에서 콤핑
2. 솔리스트 공간 존중하며 반응
3. 녹음 후 콤핑 밀도 체크
