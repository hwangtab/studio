## 계룡에서 KTX로 서울까지

계룡시는 충남의 도시로, 계룡역 KTX를 통해 서울과 약 1시간 10분~1시간 30분으로 빠르게 연결됩니다. 충청권에서 서울 스튜디오 방문이 가장 편리한 도시 중 하나로, 당일 왕복이 충분히 가능합니다.

---

## 계룡 → 연신내 이동 경로

### KTX + 6호선 경로 (추천)

1. 계룡역 KTX 탑승 (서울역 방면, 약 1시간 10분~1시간 30분)
2. 서울역 하차
3. 서울역 → 6호선 환승 → 연신내역 하차 (약 25~30분)
4. 3번 출구 → 도보 5분

- **총 소요시간**: 약 1시간 40분~2시간 10분

## 당일 왕복 일정 예시

| 시간 | 일정 |
|------|------|
| 오전 8:30 | 계룡역 KTX 출발 |
| 오전 10:00 | 서울역 도착 |
| 오전 10:40 | 연신내역 도착 |
| 오전 11:00 | 세션 시작 (3시간) |
| 오후 2:00 | 세션 완료 |
| 오후 4:00 | 서울역 KTX 출발 |
| 오후 5:30 | 계룡역 도착 |

KTX 배차 간격을 고려해 세션 시작/종료 시간을 조율하면 됩니다. 예약 시 KTX 시간에 맞춰 안내해 드립니다.

## 스튜디오 놀 소개

스튜디오 놀은 서울 은평구 연신내역 도보 5분 거리에 위치한 전문 음악 레코딩 스튜디오입니다. 동명여고 정문 바로 옆 건물 3층에 위치해 있어 찾기 쉽습니다. (건물 1층에 카센터가 있습니다.)

### 주요 장비

- **메인 마이크**: Neumann U87AI 콘덴서 마이크 (방송·음반사 표준 장비)
- **아날로그 프로세싱**: 따뜻하고 감칠맛 있는 아날로그 사운드
- **방음 부스**: 외부 소음 완전 차단, 드라이 보컬 녹음에 최적화된 환경

### 서비스 및 요금

| 서비스 | 요금 |
|--------|------|
| 합주실 대여 | 시간당 2만원 |
| 셀프 보컬 녹음 축가 패키지 | 15만원~ |
| 성우·오디오북 녹음 | 시간당 3만원 |
| 믹싱·마스터링 | 카카오톡 견적 문의 |
| 1:1 음악 레슨 | 월 35만원 정액 |

## 계룡 뮤지션에게 스튜디오 놀을 추천하는 이유

**1. 가성비 높은 전문 장비**
Neumann U87AI는 국내 방송사와 메이저 음반사에서도 쓰는 표준 콘덴서 마이크입니다. 충남 지역에서 이 수준의 장비를 갖춘 스튜디오를 합리적인 요금으로 이용할 수 있습니다.

**2. 엔지니어 주도 세션**
10년 이상 경력의 엔지니어가 직접 세션을 이끕니다. 마이크 포지셔닝, 프리앰프 게인, 모니터 레벨까지 최적 세팅을 잡아주기 때문에 처음 녹음하는 분도 좋은 결과물을 낼 수 있습니다.

**3. KTX 직통으로 2시간 이내**
계룡역에서 KTX 한 번이면 서울역까지. 서울역에서 6호선 환승으로 연신내까지 총 2시간 내외입니다. 충청권에서 가장 빠르게 접근할 수 있는 경로입니다.

**4. 원스톱 음악 제작**
보컬 녹음 → 믹싱 → 마스터링 → 음원 유통 상담까지 한 곳에서 진행할 수 있습니다. 방문 한 번으로 전체 작업을 시작할 수 있어 지방에서 오는 분에게 효율적입니다.

**5. 온라인 파일 의뢰 가능**
방문하지 않아도 드라이 보컬 WAV 파일을 카카오톡으로 전송하면 믹싱·마스터링 후 납품합니다. 녹음만 스튜디오에서 하고 이후 믹싱은 온라인으로 진행하는 방식도 가능합니다.

## 방문 당일 체크리스트

- [ ] 녹음할 곡의 MR 파일 (WAV 또는 MP3) — USB나 스마트폰에 저장
- [ ] 예약 확인 (카카오톡)
- [ ] KTX 왕복 승차권 예매
- [ ] 세션 시작 30분 전 도착 (워밍업 권장)
- [ ] 도착 전 성대 워밍업 시작 (허밍, 립 트릴 등)

주차: 스튜디오 자체 주차 공간은 협소합니다. 대중교통(연신내역 3번 출구 도보 5분) 이용을 권장합니다.
