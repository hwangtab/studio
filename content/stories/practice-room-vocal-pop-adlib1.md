# 보컬 팝 애드립·스타일링 기법 — 음악연습실 완전 가이드

팝 보컬 애드립(Ad lib)은 **악보에 없는 즉흥적인 보컬 장식**입니다. 멜로디 끝에 작은 필인, 고음 절정에서의 감탄사, 가사 사이의 "oh", "yeah"—이 작은 스타일링이 보컬을 살아있게 만들고 개성을 만들어냅니다. Beyoncé, Ariana Grande, Bruno Mars의 애드립 기법을 분석합니다.

---

## 팝 애드립의 종류

### 1. 멜로디 필인 (Melodic Fill)

**멜로디 사이 빈 공간을 채우는 짧은 패시지.**

**예:**
- 메인 멜로디: "I love you [  빈 공간  ] baby"
- 애드립: "I love you [oh-oh-oh] baby"

**필인 음절:**
- "oh", "yeah", "mm-mm"
- 짧은 멜리즈마 런

### 2. 감정 감탄사

가사나 멜로디에 감정을 더하는 외침.

**예:**
- 구절 시작 전: "Oh, I..."
- 구절 끝 후: "...love you, yeah"
- 절정에서: "Ooooh!"

### 3. 배킹 보컬 스타일 필인

자신의 메인 위에 자신이 배킹 보컬처럼 추가.

**예:**
- 메인: "Take me there"
- 애드립 위에: "mmm-hmm" (낮게)

### 4. 아웃트로 애드립

곡 끝부분에서의 자유로운 애드립 섹션.

**예:** Whitney Houston "I Will Always Love You" 아웃트로

## Beyoncé 스타일 애드립

### "Big Big" 기법

Beyoncé가 절정에서 자주 사용하는 패턴.

**특징:**
- 날카롭고 높은 고음에서 시작
- 빠르게 하강하는 멜리즈마
- 매우 개인적이고 파워풀

**Beyoncé 식 애드립 구조:**
```
고음 시작 → 빠른 하강 → 다시 상행 → 해결
```

**"Crazy in Love" 애드립:**
```
구절 끝: "Yeah, yeah, yeah-yeah-yeah" (반음씩 강조)
```

### 리듬 애드립

Beyoncé는 멜로디뿐 아니라 **리듬**으로도 애드립.

**싱코페이션 애드립:**
- 박자 뒤에 살짝 늦게 필인
- 리듬의 여유로움 표현

## Ariana Grande 스타일

### 위스퍼-투-벨팅

Ariana의 시그니처: **조용한 위스퍼에서 폭발적인 벨팅으로**

**기법:**
```
구절: 부드럽고 낮은 목소리 (위스퍼)
코러스: 폭발적인 고음 벨팅
중간: 애드립으로 연결
```

### 고음 애드립

Ariana의 가장 유명한 기법: **C6 이상의 고음 애드립**

**특징:**
- 플래지올렛(Flageolet) 음역 사용
- 매우 맑고 투명한 소리
- 코러스 끝에서 위로 뻗어나감

**연습법:**
1. 편한 음역에서 "wee" 발음으로 고음 탐구
2. 압박 없이 자연스럽게 공기압으로
3. 부드럽게 시작, 점점 높여가기

## Bruno Mars 스타일

### 레트로 팝 스타일링

Bruno Mars는 **60-70년대 소울의 애드립**을 현대 팝에 적용.

**특징:**
- 재미있고 그루비한 필인
- "huh", "uh", "woo" 등 퍼커시브한 음절
- 댄스와 연결된 보컬 리듬

**"Uptown Funk" 스타일:**
```
구절 사이: "Uh!" (짧고 강한 타격)
코러스 전: "Stop, wait a minute—"
```

### 팝-소울 애드립

**"When I Was Your Man" 아웃트로 스타일:**
```
발라드 끝에서 점점 감정 고조
"I should have bought you flowers" →
"oh-oh-oh, I should have..."
```

## 애드립 만드는 원칙

### 1. 코드 음 중심

애드립도 화성을 따름.

**C 코드 위 애드립:**
```
C-E-G-C-E (코드 톤 위아래)
경과음 추가: D, F, B 등
```

### 2. 공간 활용

**애드립의 황금률:** 공간이 있는 곳에만.

멜로디가 쉬는 곳, 가사가 끝난 곳에 필인.

**나쁜 예:** 멜로디 위에 겹쳐서 → 혼잡
**좋은 예:** 멜로디 후 빈 공간에 → 아름다움

### 3. 감정 일치

애드립의 감정이 곡의 감정과 일치해야 함.

- 슬픈 발라드: 부드럽고 섬세한 애드립
- 파워 발라드: 강력하고 드라마틱
- 팝 댄스: 그루비하고 리드미컬

## 실전 애드립 연습

### 1단계: 코러스 끝 애드립

가장 쉬운 애드립 위치: **코러스 마지막 구절 끝**

**연습 방법:**
1. 코러스 멜로디를 정확히 노래
2. 마지막 단어 후 공간에 "oh" 또는 "yeah" 추가
3. 점점 멜로디 라인으로 확장

### 2단계: 구절 사이 필인

**중간 빈 공간 채우기:**
```
구절 1: "[멜로디]"
빈 공간: 짧은 "mm" 또는 "ooh"
구절 2: "[멜로디]"
```

### 3단계: 아웃트로 자유 애드립

곡의 마지막에서 가장 자유롭게.

**준비:**
1. 코드 진행 외우기
2. 코드 음 확인
3. 감정 흘려보내기

## 음악연습실 애드립 연습

### 스튜디오 놀에서 보컬 연습

**마이크 연습의 장점:**
- 작은 애드립도 명확하게 들림
- 녹음으로 자신의 스타일 분석
- 방음으로 큰 소리로 실험 가능

**연습 루틴 (50분):**

**1. 기본 스케일 + 애드립 음절 (10분)**
   - 스케일을 "ooh", "ah"로 노래

**2. 공간 채우기 (15분)**
   - 좋아하는 곡 틀고 빈 공간에 필인

**3. 고음 탐구 (15분)**
   - 편한 음역에서 점점 위로
   - 애드립 고음 찾기

**4. 자유 애드립 (10분)**
   - 반주 트랙에서 자유롭게
