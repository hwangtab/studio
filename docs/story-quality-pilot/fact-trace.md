# 게이트 4 — 사실 출처 대조표 (2026-07-28)

## 0. 범위 조정 — 왜 이 문서가 "매핑 표"가 아닌가

Task 9 브리프 원안은 "심화로 새로 들어간 사실 주장을 인터뷰 답변에 매핑"하는 표를
요구한다. 그러나 `docs/story-quality-pilot/interview.md`를 확인한 결과 **Q1~Q7의
`**답변:**` 줄이 전부 공백이다** — 인터뷰 답변이 한 건도 도착하지 않았다. 사실을
추가하는 단계(Task 5·6 Step 1)가 보류됐고, Task 5~8은 스타일 전용(구조 정리·윤문)으로
진행됐다. "사실을 추가하지 않는다"가 하드 룰이었다.

따라서 이 게이트는 **역방향으로 검증한다**: "새 주장마다 출처가 있는가"가 아니라
"새 사실 주장이 애초에 하나도 없는가"를 증명한다. 아래는 그 증거다.

## 1. 검증 방법

- 대상 커밋 범위: `cffde43c43`(파일럿 착수 전 베이스라인) → `HEAD`
- 대상 파일: `content/stories/practice-room-startup1.md`, `content/stories/plugins1.md`
- 명령: `git diff cffde43c43..HEAD -- content/stories/<file>.md` (경로 필터링 —
  같은 기간 다른 사람이 커밋한 `db/`·`next.config.mjs`·`pages/api/contracts/` 등은
  대상 범위 밖)
- 방법: 각 파일의 diff hunk를 전부(누락 없이) 읽고, **추가된 줄**에 숫자·고유명사·
  사건·인용 등 사실 주장이 새로 등장하는지, **삭제된 줄**에 있던 주장이 본문 다른
  곳에 그대로 남아 있는지 hunk 단위로 대조했다. 표로 만들 "새 주장"이 하나도
  나오지 않았으므로, 브리프의 표 형식(`# | 주장 | 줄 | 출처 | 판정`) 대신 diff
  hunk 단위 감사 로그로 기록한다.
- **hunk·줄 수 집계 방식**: 아래 "hunk 수"는 `git diff`의 기본 컨텍스트(±3줄,
  `-U0` 아님)로 생성한 diff에서 `grep -c '^@@'`로 센 값이다. insertions/
  deletions는 `git diff --numstat`의 원시 값이다. 두 수치 모두 아래 명령으로
  직접 재현 가능:
  ```bash
  git diff --numstat cffde43c43..HEAD -- content/stories/<file>.md
  git diff cffde43c43..HEAD -- content/stories/<file>.md | grep -c '^@@'
  ```

   바뀌면서, "비교 가능하다"는 능력 서술이 "비교하면 (당연히) 기준이 생긴다"는
   전제 서술로 옮겨갔다. Task 7 자체 리포트가 이 자리를 SEG:018로 미리
   포착해 "가능성 → 과정 서술, 큰 차이는 아님"이라고 판단하고 되돌림 대상에서
   제외한 것과 일치하는 지점이다. 순수 서술 강도로 보면 경계선상이라 재검토
   가치가 있다고 판단해 여기 다시 기록한다.
2. **L183** — 베이스라인 "실패 패턴을 **미리 학습할 수 있습니다**." → HEAD
   "실패 패턴을 **미리 배웁니다**." 가능 표현이 완전히 제거되고 단정으로
   바뀐, 앞서 되돌려진 6곳과 형태상 동일한 패턴이다. Task 7 리포트의
   "되돌리지 않은 것(Strengths로 명시)" 목록에 "183줄 배웁니다"로 명시돼
   있어 **인지되고 검토된 뒤 의도적으로 유지된 것**이지 놓친 것은 아니다.
   다만 이 문장이 등장하는 문단 전체("사용자 불편 포인트가 보입니다" 등)가
   이미 원문에서부터 단정형이었고, 되돌려진 6곳은 전부 "리스크·수익이
   체계적으로 과장되는 방향"이라는 코디네이터 기준에 해당했던 반면 이 문장은
   "6개월 입주로 배우는 것" — 창업자에게 유리한 학습 효과 주장으로, 과장
   방향이 리스크/수익 축과 다르다. 판단 기준에서 벗어난 항목이라 반드시
   틀렸다고 말할 수는 없지만, **동일 클래스의 처리 일관성이 완전하지는
   않다**는 점은 사실대로 기록한다.

이 두 건 모두 **숫자·고유명사·사실관계는 변경되지 않았다** — 순전히
가능성-단정 축의 서술 강도 문제이며, 게이트 4가 요구하는 "새 사실 주장"에는
해당하지 않는다. 다만 브리프가 "잔존 인스턴스가 있으면 그대로 보고하라"고
명시했으므로 파기하지 않고 있는 그대로 남긴다.
