# 실험 — 의뢰 의도 글에 카카오 직링크 부착 (2026-07-30 시작)

## 배경

의뢰 의도 검색어("믹싱 비용", "연습실 한달 대여 가격" 등)로 6~7위에 들어오는
정보 글들이 리드를 거의 못 낸다. 본문에 "카카오톡으로 문의하세요"라고 써 있으나
**평문이라 클릭할 수 없다** — 사이트 전체 530편이 같은 상태.

530편 일괄 수정 전에 소규모로 검증한다. 앞선 가설 3개가 모두 데이터에 부정당한
이력이 있어(오퍼 부재설·오퍼 종류설·카카오 버튼 부재설), 이번에도 효과를 전제하지 않는다.

## 반증 데이터 (실험 설계 시 인지)

`seoul1`은 평문 카카오뿐인데 88세션에 리드 3건, `recording-price1`은 같은 조건에서
151세션에 리드 2건이다. 링크 유무가 결정적이라면 이 순서가 나올 수 없다.
→ 효과가 없을 가능성이 상당하다. 없으면 530편을 건드리지 않는 근거가 된다.

## 처치

3편 5곳의 평문 "카카오톡" → `[카카오톡](https://open.kakao.com/me/nol)` 직링크.
FAQ 프론트매터는 제외(JSON-LD·UI 렌더 경로가 달라 링크가 안 먹을 수 있음).

| 글 | 수정 위치 |
|---|---|
| practice-room-price1 | 110행 |
| recording-price1 | 73·150·172행 |
| practice-room-monthly1 | 130행 |

## 판정

- **판정 지표는 리드가 아니라 클릭률.** 주당 리드 7.5건·포아송 노이즈 ±2.7건 규모에서
  리드로 개선을 증명하려면 1년이 걸린다(근거: 리드 지표 무결성 메모).
- 2~4주 후 `node --env-file=.env.local scripts/ga4-fetch.mjs` 재실행 →
  세션 대비 `lead_click_kakao` 비율을 처치군·대조군 비교.
- 처치군 비율이 대조군 대비 뚜렷이 오르지 않으면 **530편 확대를 하지 않는다.**

## 유의

카카오 URL을 본문에 하드코딩했다(기존 26편 관행). 전화번호와 달리 `%%kakao%%` 토큰이
없어, URL이 바뀌면 전수 스윕이 필요하다. 확대 결정 시 토큰화를 먼저 검토할 것.
