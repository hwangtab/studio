# GEO 가시성 추적 — 월 1회 수동 체크

> 근거: `docs/proposals/seo-geo-aeo-inquiry-growth-2026-09-04.md` P0-3.
> ChatGPT·Gemini·Perplexity는 GA4·GSC에 인용 여부가 안 잡힌다(리드는 잡혀도 "왜 인용됐는지"는
> 안 잡힘). 그래서 고정 쿼리를 매달 손으로 넣어 인용 여부·인용 URL·함께 언급된 경쟁사·톤을
> 직접 기록한다. 코드도 자동화도 없다 — 30분짜리 수작업 루틴이다. 자동화는 3회차(3개월치
> 데이터가 쌓인 뒤) 판단한다.

## 무엇을 하는가

고정 쿼리 20개(`queries.md`)를 매달 ChatGPT·Gemini·Perplexity 세 엔진에 그대로 넣고,
각 답변에서 "스튜디오 놀이 인용/추천됐는가"만 본다. 60건(20쿼리 × 3엔진)을
`YYYY-MM.csv`에 한 줄씩 남긴다.

## 실행 절차

1. **로그인 상태로 실행한다.** 비로그인 상태는 개인화가 꺼진 답변만 나와 실제 사용자가
   보는 결과와 다르다.
2. **매 쿼리마다 새 대화로 시작한다.** 같은 대화 안에서 이어 물으면 이전 질문의 맥락이
   다음 답변의 인용에 영향을 준다 — 20개 쿼리는 서로 독립적으로 측정돼야 한다.
3. **기억·개인화 기능은 끈다.** ChatGPT는 설정에서 "메모리 참조"·저장된 맞춤 지침을 끄고,
   Gemini는 계정 활동 기반 개인화를, Perplexity는 개인화 설정을 끈 상태로 실행한다.
   목적은 "이 계정만 받는 답"이 아니라 "일반 사용자가 받을 답"을 재는 것이다.
4. **모바일 앱이 아니라 웹 브라우저로 실행한다.** 앱은 인용 링크 표시 방식이 웹과 달라
   `cited_url`을 못 뽑는 경우가 있다. 데스크톱/모바일 웹 어느 쪽이든 좋다.

각 쿼리를 넣고 답변에서 다음을 그대로 옮겨 적는다:

- 스튜디오 놀(또는 studionol.co.kr)이 언급/인용됐는가 (`cited`)
- 인용됐다면 어떤 URL을 근거로 들었는가 (`cited_url`) — 각주·링크 카드·본문 URL 어디든
- 답변 안에서 몇 번째 순서로 등장했는가 (`position_in_answer`) — 1이면 가장 먼저 언급
- 함께 언급된 경쟁 업체·서비스 이름 (`competitors_named`) — 답변에 실제로 나온 이름만,
  나오지 않은 이름을 추측해서 채우지 않는다
- 언급의 톤 (`tone`) — 긍정적으로 추천됐는지, 그냥 목록에 끼었는지(중립), 부정적으로
  비교됐는지, 아예 언급이 없었는지(absent)

## 파일

- `queries.md` — 고정 쿼리 20개(보컬톤 상담형 8·믹싱 의뢰형 6·녹음실/연습실 추천형 6),
  각각 id와 "우리가 인용되길 기대하는 페이지"를 붙였다. 쿼리 자체는 원칙적으로 바꾸지
  않는다 — 매달 같은 쿼리를 넣어야 추세 비교가 된다. 실제 답변이 특정 서비스를 새로
  다루게 되는 등 명백한 사유가 있을 때만, 바꾼 이유를 커밋 메시지에 남기고 바꾼다.
- `template.csv` — 매달 이 파일을 복사해 `YYYY-MM.csv`로 이름 붙이고 채운다.
  헤더: `month,query_id,engine,cited(yes/no),cited_url,position_in_answer,competitors_named,tone(positive/neutral/negative/absent),notes`

## 집계 방법

**인용률 = `cited` = yes인 행 수 ÷ 60** (20쿼리 × 3엔진). 원하면 엔진별(÷20)이나
그룹별(보컬톤 상담형 ÷24, 믹싱 의뢰형 ÷18, 녹음실·연습실 추천형 ÷18)로도 나눠 본다.

## 판독 주의

- **같은 쿼리도 답이 매번 다르다.** LLM 응답은 결정적이지 않으므로 한 달 숫자를 보고
  "인용이 늘었다/줄었다"고 결론 내리지 않는다. 최소 3개월치가 쌓인 뒤 추세로만 본다.
- **경쟁사 이름은 답변에 실제로 등장한 그대로 적는다.** 등장하지 않았는데 "아마 여기가
  나왔을 것"이라고 추측해서 채우지 않는다. 모르면 비워 둔다.
- **인용 없음(absent)이 그 자체로 실패는 아니다.** 이 루틴은 방향을 보는 관측이지,
  이번 달부터 달성해야 할 목표치가 있는 KPI가 아니다.
- 실행자·실행 시각이 달라져도 괜찮다. 다만 절차(로그인·새 대화·기억 끄기·웹)는 매달
  동일하게 지켜야 월 간 비교가 의미를 가진다.
