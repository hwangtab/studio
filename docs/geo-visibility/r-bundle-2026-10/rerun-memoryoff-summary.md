# R묶음 재측정 — Memory 끈 뒤 (2026-10-16 16:09~16:53 UTC)

운영자가 ChatGPT 설정에서 Memory를 직접 껐다고 확인한 뒤, 같은 시나리오A·B를 각 5회씩
다시 측정했다. 목적은 둘: (1) Memory가 실제로 꺼졌는지 확인, (2) 켜져 있던 상태의 결과가
오염된 것이었는지 가른다.

## 1. Memory는 실제로 꺼졌다

10회 전부 1차 메시지 전·3차 답변 후 두 시점에서 "소스" 패널을 열어 확인했고, **어느
회차에도 "메모리 N개" 섹션이 뜨지 않았다.** 이전 회차(2026-10-16 낮, memory 켜진 상태)에
시나리오A 3회차에서 떴던 "메모리 6"과 대조된다. 조치가 실제로 적용됐다.

## 2. 결과 — 시나리오A는 그대로, 시나리오B는 떨어졌다

| | Memory 켜짐(최초 측정) | Memory 꺼짐(재측정) |
|---|---|---|
| 시나리오A(믹싱 탐색) | 1/5 (20%) | **1/5 (20%)** — 불변 |
| 시나리오B(녹음 탐색) | 5/5 (100%) | **3/5 (60%)** — 하락 |

**시나리오B의 "100% 인용"은 부분적으로 메모리 오염이었다.** Memory를 끈 뒤 같은 질문을
다시 하자 비율이 100%에서 60%로 떨어졌다. 2회는 본문에 실제로 들어갔고(2회차는 소스
패널로 "웹 검색으로 studionol.co.kr 블로그 글이 걸려 인용됨"을 직접 확인 — 메모리가
아니라 진짜 웹 크롤링), 2회는 본문에는 없었지만 소스 패널의 "더보기" 웹 출처 목록에는
studionol.co.kr 글이 떠 있었다(크롤링은 됐지만 최종 추천엔 안 들어감).

**시나리오A의 "20%"는 메모리와 무관한 진짜 신호다.** Memory를 꺼도 똑같이 1/5이 나왔다.

## 3. 경쟁 풀 구조도 다시 봐야 한다 — "녹음이 좁고 믹싱이 넓다"가 아니라 반대였다

Memory를 끈 뒤 집계한 경쟁 업체 목록:

- **시나리오A(믹싱)**: 821Sound·그루브앤밸런스·Black Key·살폿 4곳이 5회 중 4회에 반복
  등장(정확히는 1·3·4·5회차가 이 4곳 중 3~4곳씩 겹친다). 2회차만 완전히 다른 구성
  (R!ccio·이메이진뮤직)이었고 이때 스튜디오 놀이 1순위로 들어갔다 — **고정 상위 4곳의
  구성이 그대로 나올 때는 못 끼고, 그 4곳이 안 나올 때만 끼어든다는 뜻**으로 읽힌다.
- **시나리오B(녹음)**: 노이즈 스튜디오·그루브앤밸런스·이메이진뮤직·에이블·스노우핑거·
  블루포닉·오디오가이·벨벳·MUUX·웨이브먼트·서서울 레코딩·오르카 레코딩 — **5회에서
  고유 이름이 12개**. 믹싱보다 오히려 더 파편화돼 있다.

이전 결론("녹음=지리적 필터로 좁은 풀, 믹싱=원격이라 전국 단위로 넓은 풀")은 Memory
오염이 섞인 데이터 위에서 나온 것이고, 깨끗한 데이터는 **반대 방향**을 보여준다 — 믹싱
쪽이 오히려 더 고정된 소수 업체(4곳)가 자리를 지키고, 녹음 쪽은 매번 다른 업체가 나온다.

## 4. 수정된 판단

- 믹싱 탐색형 질문에서 안 뜨는 이유는 "경쟁이 전국 단위라 구조적으로 어쩔 수 없다"가
  아니라, **821Sound·그루브앤밸런스·Black Key·살폿 이 4곳이 이 질문 프레임("허스키한
  보컬 톤 살리는 믹싱")에서 구체적으로 우리보다 먼저 떠오른다**는 더 좁고 구체적인 문제다.
  — 답할 수 있는 질문("저 4곳 지도 평점·소개 문구가 왜 이 프레임에 더 잘 맞는가")이지,
  손 놓을 구조적 상한이 아니다. PR #722(VAT·신뢰신호·증상형 FAQ 보강)는 방향 자체는
  맞았지만 "구조 문제라 효과가 작을 것"이라는 전제는 다시 봐야 한다.
- 녹음 탐색형 질문의 실제 인용률은 100%가 아니라 **60%**다. 여전히 믹싱(20%)보다 훨씬
  높지만, 이전에 생각했던 "거의 보장된 인용"은 아니다.
- 표본은 여전히 각 5회뿐이다. 이번에도 시나리오당 n=5 수준이라 정밀한 비율로 확정할
  단계는 아니고, 방향(믹싱 << 녹음, 믹싱 쪽 경쟁자 4곳이 고정적으로 앞섬)만 신뢰한다.

## 5. 다음에 할 일 (제안, 아직 미실행)

  문구·지도 평점을 실제로 열어 보고, 우리 믹싱 LP·llms.txt와 무엇이 다른지 구체적으로
