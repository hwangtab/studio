# kosmart.co.kr 스튜디오 페이지 리다이렉트 실행 계획 (2026-09-21)

> **결정**: 301 리다이렉트. 운영자(황경하)가 kosmart 직원이므로 내부에서 직접 실행한다.
> 조합원 할인은 **운영하지 않는다**(2026-09-21 확인) — 그 페이지는 없는 혜택까지 광고하고 있었다.

## 왜 하는가

`kosmart.co.kr`에 스튜디오 놀을 소개하는 페이지가 둘 있고, 둘 다 **현재 사실과 다르다.**

| | `/recording` | `/practice` |
|---|---|---|
| 제목 | 레코딩 스튜디오 \| 한국스마트협동조합 | 음악 연습실 \| 한국스마트협동조합 |
| 소개 | "한국스마트협동조합 레코딩 스튜디오 '스튜디오 놀'" | "한국스마트협동조합이 자랑하는 음악연습실, 스튜디오 놀" |
| 주소 | 은평구 통일로71길 2-1 3층 (일치) | 같음 |
| **전화** | **02-764-3114** | **02-764-3114** |
| **이메일** | **contact@kosmart.org** | **kosmart.org** |
| **가격** | 녹음 20만(조합원 15만) · 보컬튠 20만(조합원 15만) · 믹싱 20만(조합원 15만) · 마스터링 15만 | — |
| studionol.co.kr 링크 | **0개** | **0개** |

세 가지가 동시에 틀렸다.

1. **소유 표현** — 스튜디오 놀은 황경하 소유·운영이다. kosmart는 설립 기원일 뿐 모조직이 아니다
   (단 황경하는 현재도 kosmart 직원 — 인적 관계는 있다).
2. **연락처** — 그 번호·주소로 오는 문의는 GA4·GSC 어디에도 안 잡힌다.
   (2026-09-26 정정: 02-764-3114는 운영자도 받는 번호라 문의 자체는 닿는다. 남는 문제는 측정이
   안 되는 것과, 연락처가 달라 AI·검색이 두 업체로 볼 여지다.)
3. **가격** — 옛 가격표다. 현재 정본은 보컬 녹음 25만원(3시간)·믹싱 20만원(10트랙 이하)·
   마스터링 10만원이고, **조합원 할인은 운영하지 않는다.** 없는 혜택을 광고하는 상태다.

실측 근거: 2026-09-18 GEO 2회차에서 ChatGPT에 "온라인으로 보컬 믹싱 맡길 만한 곳 추천해줘"를
물었더니 우리를 1순위로 인용하면서 경쟁자 목록에 **"한국스마트협동조합 레코딩 스튜디오"**를
함께 올렸다. AI가 같은 주소의 같은 스튜디오를 두 업체로 본다.

## 왜 삭제가 아니라 리다이렉트인가

두 페이지 모두 우리 사이트로 가는 링크가 0개라, 지금은 혼동만 만들고 아무 도움도 주지 않는다.
그냥 지우면 혼동은 사라지지만 그 페이지가 쌓아 온 검색 신호도 함께 버려진다. 301은 그 신호를
우리 쪽으로 넘기고, 그 페이지로 오던 사람도 우리 사이트에 도착한다. AI가 다시 크롤할 때도
출처가 사라지는 대신 우리 페이지를 가리키게 된다.

## 실행 (Wix)

kosmart.co.kr은 Wix다(`X-Wix` 헤더 확인). Wix 대시보드에 URL 리디렉션 관리자가 있다.

**경로**: Wix 대시보드 → 마케팅 및 SEO → SEO 도구 → **URL 리디렉션 관리자**
(영문: Marketing & SEO → SEO Tools → URL Redirect Manager)

**설정할 매핑 2건** — 유형은 `301 (영구 이동)`:

| Old URL | New URL |
|---|---|
| `/recording` | `https://studionol.co.kr/ko/recording` |
| `/practice` | `https://studionol.co.kr/ko/practice-room` |

**메뉴 정리도 함께**: 리다이렉트만 걸면 조합 사이트 메뉴("예술창작 인프라 구축" 아래
"레코딩 스튜디오"·"음악 연습실")가 외부로 나가는 링크가 된다. 메뉴에서 두 항목을 빼거나,
남긴다면 라벨을 "스튜디오 놀(협력)"처럼 외부임이 드러나게 바꾼다.

**외부 URL 리다이렉트가 막혀 있다면**(플랜에 따라 다를 수 있다) 대안:
페이지를 남기되 본문을 한 줄로 줄이고 — "스튜디오 놀은 황경하가 운영하는 독립 스튜디오입니다.
문의·요금: studionol.co.kr" — 잘못된 연락처·가격·소유 표현을 전부 지운다. 백링크는 그대로 얻는다.

## 실행 후 확인

```bash
# 301이 걸렸는지 (Location 헤더 확인)
curl -sI -m 15 https://www.kosmart.co.kr/recording | grep -iE '^(HTTP|location)'
curl -sI -m 15 https://www.kosmart.co.kr/practice  | grep -iE '^(HTTP|location)'

# 리다이렉트를 따라갔을 때 우리 페이지에 도착하는지
curl -s -o /dev/null -L -w '%{http_code} %{url_effective}\n' https://www.kosmart.co.kr/recording
```

- [ ] 두 URL이 301로 우리 페이지에 도착한다
- [ ] kosmart 메뉴에서 두 항목이 정리됐다
- [ ] **2~4주 뒤 GEO 재측정** — Q09("온라인으로 보컬 믹싱 맡길 만한 곳 추천해줘")에서
      "한국스마트협동조합 레코딩 스튜디오"가 경쟁자 목록에서 빠지는지 확인.
      빠지지 않으면 AI 학습 데이터에 이미 들어간 것이므로 시간이 더 필요하다고 보고 재측정한다
      (리다이렉트 자체가 실패한 것으로 읽지 말 것).
- [ ] 결과를 날짜와 함께 이 파일 하단에 기록
