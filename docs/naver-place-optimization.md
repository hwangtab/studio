# 네이버 스마트플레이스 최적화 정보안 — 스튜디오 놀

> **왜 이 작업이 1순위인가**: GA4 90일 분석 결과 네이버 유입은 구글 대비 **전환율 2~2.5배**(네이버 모바일 1.28% / 네이버 0.88% vs 구글 0.52%), 이탈률도 절반(0.20 vs 0.36). 그런데 네이버 트래픽은 구글의 1/10이고 **네이버 플레이스 유입은 90일 12세션**에 불과 — 한국 1위 검색·지역검색 채널이 거의 비어 있음. "음악연습실 월세 / 연신내(불광) 녹음실" 같은 지역검색은 네이버 점유율이 구글보다 압도적이므로, 플레이스 최적화가 최고 ROI.

아래 내용을 [네이버 스마트플레이스](https://smartplace.naver.com)에 그대로 입력/보강하면 됩니다.

## 1. 업종(카테고리) — 복수 등록

네이버는 대표 1개 + 추가 카테고리를 허용합니다. 두 매출축을 모두 잡으려면:

- **대표 카테고리**: `녹음실` (또는 `녹음스튜디오`)
- **추가 카테고리**: `음악연습실`, `음악학원`(레슨), `예술기획·제작`

> 음악연습실 카테고리를 반드시 추가하세요 — "음악연습실 월세"는 네이버 지역검색 수요가 크고 전환이 가장 좋은 상품입니다.

```
보컬 녹음 1곡 25만원, 마스터링 10만원. 세션 전 가격 확정, 숨은 비용 없음.
```

## 8. 리뷰 전략 (플레이스 상위노출의 최대 변수)

네이버 플레이스 순위는 **방문자 리뷰 + 블로그 리뷰의 수·최신성**이 결정적.

1. **방문자 리뷰**: 녹음/연습실 이용 후 카톡으로 리뷰 요청 메시지 발송(영수증 리뷰 유도). 키워드가 자연 포함된 리뷰가 노출에 유리("연습실 방음 좋아요", "보컬 녹음 디렉팅 친절").
2. **블로그 리뷰**: 이용 고객/지인 블로그 후기 1~2건/월. "연신내 녹음실", "은평구 음악연습실 월세" 등 지역+업종 키워드 제목.
3. **답글**: 모든 리뷰에 답글 — 활동성 신호.
