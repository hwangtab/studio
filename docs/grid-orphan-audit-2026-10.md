# 그리드 빈칸 전수 점검 (2026-10-11)

운영자 질문: "2열인데 1개만 왼쪽에 있다든지… 이런 문제들 전수체크". 프로덕션 ko 75페이지(사이트맵 전체 + 스토리·예약·견적 표본)를
1280px·900px으로 열고, 끝까지 스크롤해 늦게 붙는 절까지 띄운 뒤 **마지막 줄이 덜 찬 카드 그리드**를 기계로 뽑았다
(세션 스크래치 `grid.cjs`). 이미지·글 2단 배치처럼 원래 칸이 비는 배치와 지역 링크 목록은 걸러 냈다.

## 1. 칸 수보다 카드가 적다 — 가장 눈에 띈다

| 페이지 | 절 | 칸 | 카드 | 보이는 모습 |
|---|---|---|---|---|
| 믹싱·마스터링, 축가 | 후기("아티스트와 함께 만드는 감동의 기록") | 2 | 1 | 운영자 스크린샷 — 카드 하나가 왼쪽 절반, 별점·제목과 정렬도 어긋남 |
| 예약(/booking) | 성우·축가·커버·연습실 시간제·공연 티켓 | 2 | 1 | 서비스마다 카드 하나가 왼쪽 절반, 오른쪽 "부가세 별도"만 떠 있음 |
| 가이드 5종 | 추천 패키지 | 2 | 1 | 같은 모양 |
| 오디오북 가이드 | 실제 작업 결과물 | 3 | 1 | 카드 하나가 왼쪽 ⅓ |
| 가격 | 부가 서비스 | 4 | 2 | 오른쪽 절반이 빔 |

## 2. 마지막 줄에 하나·둘만 남는다

| 페이지 | 절 | 칸×카드 (1280 / 900) |
|---|---|---|
| 가이드 6종·성우·발매·커버·레슨 | 관련 가이드(스토리 카드) | 3×7 → 끝줄 1 / 2×7 → 끝줄 1 (5개인 곳은 3+2) |
| 녹음·가격·믹싱 | FAQ 요약 | 3×4 → 끝줄 1 |
| 녹음 | 녹음실 대여 가격 | 3×4 → 끝줄 1 (900에서도) |
| 가격 | 스페셜 패키지 | 3×7 → 끝줄 1 |
| 가격·작곡편곡 | 작곡·편곡·MR | 3×5 → 3+2 / 2×5 → 끝줄 1 |
| 레슨 | 레슨 한눈에 | 3×5 → 3+2 |
| 연습실 | 이런 고민 있으신가요 | 3×5 → 3+2 / 2×5 |
| 발매 | 함께 만들고 있는 음반 | 3×5 → 3+2 / 2×5 |
| 장비 | 장비 목록 | 3×8 → 3+3+2 |

## 3. 고치는 규칙(제안)

1. **카드가 칸보다 적으면 칸을 카드 수로 줄이고 가운데로** — 후기 1개는 한 장을 가운데(폭 제한), 예약·추천 패키지 1개도 같음.
   공용 컴포넌트(ReviewSection·예약 그룹·BuyerIntentHubPage 패키지 절)에서 개수로 판정하므로 데이터가 늘면 저절로 2열이 된다.
2. **고정 개수 카드는 나누어떨어지는 칸 수로** — 4개 → 2×2 또는 4칸, 8개 → 4칸, 2개 → 2칸.
3. **나누어떨어지지 않는 개수(5·7)는 마지막 줄을 가운데로** — 카드 폭은 그대로 두고 줄만 가운데 정렬(공용 `CenteredGrid` 하나로).
4. **관련 가이드(스토리 카드)는 6개로 맞춘다** — 3칸·2칸 모두 나누어떨어진다(지금 5·7·8·9개).
5. 지역 링크 목록(연습실 동네별)처럼 **목록**인 것은 그대로 둔다 — 왼쪽 정렬이 읽는 순서다.
6. 가드: 공용 그리드에 카드 수 → 칸 수 판정을 두고, 이번 크롤 스크립트를 테스트로 옮기진 않는다(프로덕션 렌더 기준이라 CI에서 못 돈다).
