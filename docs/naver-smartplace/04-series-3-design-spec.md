## 기획 의도

시리즈 1·2가 정보·기술 톤이었다면, 시리즈 3은 **페르소나 자기 동일시 효과**로 클릭률 상승.

### 차별 포인트
- **컨셉**: "이 페르소나는 나야" 효과 — 4가지 대표 입주자 유형 시각화
- **컬러**: 시리즈 1과 동일 베이지+차콜 (음악연습실 카테고리 일관성)
- **레이아웃**: 좌/우 사진 위치 교차 (L → R → L → 중앙박스) — 시각 리듬
- **카피**: 사용자 직접 인용 톤 ("낮엔 회사, 밤엔 음악") — 공감 유도
- **비중 기여**: 음악연습실 카테고리 (시리즈 1·3 = 80% 비중)
