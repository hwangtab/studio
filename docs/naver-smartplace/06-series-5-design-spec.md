## 다이어그램 디자인

### 카드 1 — 두 역 카드 (호선 마크)
- **연신내역 (primary)**: 차콜 배경 + 골드 보더 + 3·6호선 마크
  - 3호선 녹색 원 (`#558B41`) + "3"
  - 6호선 갈색 원 (`#8E764E`) + "6"
  - "도보 5분" 골드 명조 강조
- **불광역 (secondary)**: 베이지 카드 + 6호선 마크만 + "도보 7분"

### 카드 2 — 건물 층 다이어그램
- 3F STUDIO NOL (highlight, 차콜+골드)
- 2F 일반 사무실 (베이지)
- 1F 카센터 (베이지) + "한눈에 보이는 간판"
- → 시각적으로 "위에서 아래로 찾기 쉬움" 흐름

### 카드 3 — 4가지 도착 정보
- P 아이콘: KT은평빌딩 주차장
- 🚇 아이콘: 대중교통 권장
- 🍴 아이콘: 인근 식당·편의점
- 💬 아이콘: 톡톡으로 길안내
