## 0. 요약

**핵심 명제: 페이지 수의 시대는 끝났다. 이제 페이지당 권위에 투자한다.**

- 스토리 1,757편 중 95%(1,499편)가 2026-04-06~09 나흘간 생성된 pSEO 자산. 감사 대상 1,562편 중 **44%(688편)가 NOINDEX_CANDIDATE**, 트래픽은 소수 KEEP 페이지(517편, 실질적으로는 그중 상위 수십 편)에 집중.
- 91%(1,428편)가 동일 저자 박스 템플릿, 354편이 AUTO-EXPAND-V1 보일러플레이트 공유 — 구글 "scaled content abuse" 정책의 정확한 타깃 프로필. 방어적 탈템플릿화가 시급하다.
- 전략은 3축: **고도화**(역피라미드 재배분 — 승자에 투자, 중위는 CTR 수술, 꼬리는 정리), **전문화**(황경하 실명 저자성 기반 E-E-A-T 해자 + 성우·발매 클러스터 심화), **강화**(내부링크 허브 구조 + 네이버 채널 개통 + 측정 루프).
- 순서 논리: ① 이미 순위 있는 곳에서 클릭을 이긴다(가장 싼 승리) → ② 클릭을 이긴 곳에서 신뢰를 이긴다(전문화) → ③ 신뢰가 생긴 곳에서 최고 전환 채널(네이버)과 매출 직결 클러스터(발매·성우)로 확장한다.

**탈템플릿화(방어적 고도화)**: 색인 노출 페이지부터 ① 91% 동일 저자 박스를 페이지별 맞춤 문단 또는 실명 저자 카드로 교체, ② AUTO-EXPAND-V1 보일러플레이트를 페이지 고유 내용으로 대체. noindex 페이지는 후순위(이미 색인 제외라 위험 낮음).

### 축 2 — 전문화: E-E-A-T 해자

pSEO 시대의 익명성("스튜디오 놀" 일괄 저자)을 버리고, 이 사이트만 가진 자산 — **15년차 인디 프로듀서 황경하와 실제 스튜디오 운영 데이터** — 를 전면화한다. 이는 발매 프로젝트 재포지셔닝(Path B: "프로듀서 + 네트워크가 상품")과 같은 방향이다.

1. **실명 저자성 인프라**: 저자 소개 페이지 신설 + `Person` JSON-LD(현재 BlogPosting 저자가 조직명) + 플래그십부터 실명 바이라인. sameAs로 외부 프로필 연결.
2. **경험 우선 콘텐츠**: "실제 세션에서 있었던 일" 단락, 실제 견적·소요시간·수정 횟수 등 스튜디오 로그 기반 서술을 플래그십에 주입. 경쟁사가 복제할 수 없는 유일 콘텐츠.
3. **원본 데이터 시리즈**: "스튜디오 놀 데이터로 본 첫 녹음 평균 소요시간", "믹싱 수정 횟수 분포" 등 — GEO(AI 검색 인용)에서 통계·정의형 콘텐츠가 인용 우위. 신규 발행 쿼터(월 2~4편)의 일부를 여기 배정.
4. **클러스터 전문화 (분기 신규 주제 배분 — 기결정 우선순위 준용)**:
   - ① **성우 클러스터 심화**: 섭외 견적, 오디오북 단가 구조 등 buyer-intent 주제. pos 34.8 → 10위권 목표. 공식가 10만원/시간 준수.
   - ② **발매 프로젝트 연계**: 첫 EP 비용, 세션 연주자 섭외 → `indie-release-guide` 허브로 수렴. 콘텐츠가 플래그십 상품(발매 3티어)의 세일즈 퍼널이 되게 한다.
   - ③ **연습실 롱테일**: 신규 지역 페이지가 아니라 기존 21개 dedicated LP 강화.
5. **GEO 정합성**: FAQ·정의형 구조는 이미 100% — llms.txt/robots AI 봇 허용도 완비. 남는 과제는 인용할 가치가 있는 '원본 사실'의 밀도.

### 축 3 — 강화: 유통·전환·측정

1. **내부링크 허브 구조**: 모든 Cluster → Pillar 링크 규칙 준수 감사(자동 스크립트로 위반 검출). 관련글 스코어링(`storyRelatedScoring.ts`)에 "동일 클러스터 우선" 가중치 검토. 308 통합 시 내부링크 홉 제거 원칙 유지.
2. **네이버 채널 개통 (최대 미개통 레버)**: 이미 완성된 자산 실행 — 플레이스 가이드 11섹션 등록, 블로그 초안 23편을 발행순서 문서(`p3-external-channels-runbook.md`)대로 발행. 사이트 스토리 승자를 네이버 블로그용으로 재가공(중복 아닌 요약+링크형)하는 파이프라인 정례화. 4~8주 내 네이버 유입 3배 목표(기존 목표 준용).
3. **전환 경로**: 스토리 CTA는 카카오 우선(데이터 근거). 플래그십·성우·발매 콘텐츠에 해당 Pillar/상담 CTA 매핑 점검(`storyCtaPolicy.ts`). `micro_click_service/contact`를 key event로 올리지 않는다(오염 경고 상존).
4. **측정 루프**: GSC 감사 크론(`pages/api/cron/gsc-audit.ts`) 분기 리포트 → 티어 재배정 → 다음 분기 CTR 수술·플래그십 후보 자동 추출. 리라이트 페이지는 변경일 기록 후 4주 뒤 CTR 전후 비교.

## 6. 가드레일 (하지 말 것)

1. 신규 지역 페이지·대량 생성·자동 번역 확장 금지 (기결정).
2. 승자 페이지의 URL·canonical 변경 금지 — 리라이트는 메타·본문만.
3. 꼬리 정리에서 물리적 삭제 금지 — noindex/308만 (내부링크 홉·색인 신호 보존).
4. 가격·사실은 SSOT 상수만 인용 (성우 10만원/시간, 연습실 월 36만원~, 레슨 월 35만원 등). 사실 가드 테스트 우회 금지.
5. `micro_click_service/contact`를 GA4 key event로 승격 금지 (리드 오염 재발 경고).
6. 한날 대량 발행·일괄 date 수정 금지 (발행 지문 악화).
