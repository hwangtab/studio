# 3-1. 네이버 플레이스 최적화 ⭐ 최우선

전환율 2.75% 채널을 여는 작업. 이번 주 안에 1)~6) 완료 목표.

### 1) 업종 카테고리

- **대표**: `녹음실` (또는 `녹음스튜디오`)
- **추가**: `음악연습실`, `음악학원`(레슨), `예술기획·제작`

> "음악연습실"은 네이버 지역검색 수요가 높고 전환 최상 — **반드시 추가**.

### 2) 가격 탭 — 아래 7항목 그대로 등록

| 항목 | 가격 |
|---|---|
| 보컬 녹음 1곡 (3시간 기준 · 전담 엔지니어·디렉팅·기본 편집 포함, 튠·믹싱 별도) | 250,000원 |
| 시간당 레코딩 | 100,000원 / 시간 |
| 6시간 패키지 (Day Lock) | 500,000원 |
| 싱글 마스터링 | 100,000원 |
| 성우·나레이션 녹음 | 100,000원~ |
| 축가 / 이벤트 녹음 | 350,000원 |
| **음악연습실 월세** | **360,000원~** |

> 모두 VAT 별도. "보컬 녹음 1곡(25만)"과 "축가/이벤트(35만)"는 **별개 상품** — 축가 패키지만 2시간 녹음 + 보컬 튠 + 믹싱·마스터링 올인원이다(`data/pricing.ts` VOCAL_PACKAGE_PRICE 주석 "1곡·3시간" 참조). 2026-09-04 정정: 이전 표는 25만원 상품을 축가 구성으로 오설명하고 있었다(7/28 네이버 블로그 정정과 같은 오류).

### 3) 사진 — 최소 10장, 아래 순서로

대표 4장(첫 화면)은 **텍스트 0% 감성 실사**. 알고리즘이 실사를 우대합니다. AI 생성 이미지 금지.

1. 메인 녹음룸 전경 (밝고 장비 노출) — 클릭률 좌우
2. 컨트롤 데스크 / 아웃보드 (U87Ai, 콘솔) — 전문성
3. 방음 부스 내부
4. 음악연습실 (보컬 / 피아노 / 건반) — "월세" 검색자용
5. 라운지 / 휴게 공간
6. 외관 + 동명여고 옆 / 불광역 동선
7~10. 작업 장면 · 발매 음원 커버 · 장비 디테일

> 활용 가능한 저장소 이미지: `public/images/` 의 `studio2~5`, `hardware8`, `room1·3·6` 등.

### 4) 예약·톡톡 연결 (전환 단축 + 노출 점수)

- [ ] 네이버 톡톡 연결 → 카카오 오픈채팅(`open.kakao.com/me/nol`) 안내
- [ ] 네이버 예약 도입 (예약 버튼 클릭이 노출 점수 + 전환을 동시에 올림 — P4 온라인예약 파일럿과 연결)

### 5) 리뷰 전략

- [ ] **방문자 리뷰**: 이용 후 카톡으로 리뷰 요청(영수증 리뷰). "연신내 녹음실", "은평구 음악연습실 월세" 등 키워드 포함 리뷰가 유리
- [ ] **블로그 리뷰**: 이용 고객·지인 1~2건/월. 제목에 지역 키워드 포함
- [ ] **답글 100%**: 모든 리뷰에 답글 = 활동성 신호
- 6개월 목표: 네이버 플레이스 후기 **30개+**

**리뷰 답글은 100% 단다, 답글에 서비스명을 자연스럽게 넣는다** — 답글은 검색엔진·AI가 함께
읽는 텍스트라, "스튜디오 놀에서 보컬 녹음 진행해 주셔서 감사합니다" 식으로 어떤 작업이었는지
한 번 더 언급하면 리뷰 본문이 짧아도 답글이 맥락을 보강한다.

**리뷰 요청 카톡 템플릿 3종** — 링크는 플레이스홀더(`{네이버 플레이스 리뷰 링크}`·
`{구글 리뷰 링크}`)를 실제 링크로 바꿔서 보낸다. 세 개 모두 존댓말, 60~120자, "어떤 작업이었는지
한 줄"만 부탁하고 거절해도 부담 없게 끝맺는다. **키워드를 넣어달라고 유도하지 않고, 대가를
제공하지 않고, 별점을 지정해 요청하지 않는다** — 플랫폼 제재와 표시광고법 대상이다.

| 시점 | 템플릿 |
|---|---|
| 녹음 세션 종료 후 | 오늘 세션 마무리하셨습니다. 혹시 괜찮으시면 어떤 작업이었는지 한 줄만 남겨주실 수 있을까요? {네이버 플레이스 리뷰 링크} 부담되시면 그냥 넘어가셔도 괜찮습니다, 감사했습니다. |
| 온라인 믹싱 납품 후 | 믹싱 파일 잘 받으셨을까요? 시간 되실 때 어떤 곡 작업이었는지 한 줄 후기 남겨주시면 감사하겠습니다. {구글 리뷰 링크} 바쁘시면 넘어가셔도 전혀 상관없습니다. |
| 연습실 입주 1개월 후 | 입주하신 지 한 달 되셨네요. 지내시면서 느끼신 점 한 줄만 남겨주시면 다음 분들께 도움이 될 것 같습니다. {네이버 플레이스 리뷰 링크} 편하실 때 부탁드려요, 부담 갖지 않으셔도 됩니다. |

### 6) 소식(이벤트) — 월 1~2회

- 연습실 1년 계약 시 첫 달 50% 할인 안내
- 무료 견적 상담 안내
- 신규 장비 도입 소식
