# 2026년 기준 대체 대상 리서치

조사일: 2026-06-20 KST  
목적: 2019년 매뉴얼에서 사라졌거나 낡은 플랫폼, 지원사업, 홍보 루트를 2026년에 실제로 쓸 만한 대상으로 대체하기.

## 먼저 바꿀 관점

2019년식 매뉴얼은 "한 플랫폼에 올리면 발견되고, 지원사업도 따라온다"는 구조가 강했다. 2026년에는 그 방식이 잘 맞지 않는다. 지금은 역할을 나누는 편이 안전하다.

| 예전 역할 | 2026년 대체 구조 |
| --- | --- |
| 네이버 뮤지션리그 하나로 데모 공개, 팬 소통, 판매, 지원사업 연결 | 데모 공개는 SoundCloud/Bandcamp/YouTube, 정식 발매는 유통사/애그리게이터, 팬 유입은 Shorts/Reels/TikTok, 지원사업은 KOCCA/CJ/지자체 공고로 분리 |
| 네이버 온스테이지 같은 단일 라이브 노출 창구 | YouTube 라이브 세션, 지원사업 쇼케이스, 지역 음악창작소 공연, 큐레이션 채널, 숏폼 클립으로 분산 |
| 그라폴리오에서 작가 찾기 | Notefolio/Behance/ArtStation/Instagram/X/크몽/숨고에서 포트폴리오 확인 후 계약 |
| 오투잡 기사 송출 | 공식 보도자료, 라이브 리뷰, 플레이리스트 피칭, 인터뷰, 뉴스레터, 광고 표시가 명확한 PR로 전환 |
| 2019년 공모전 리스트 | 매년 공식 공고를 갱신하는 지원사업 캘린더로 전환 |

## 음원 공개와 유통 대체 스택

### 데모와 팬 반응 테스트

| 대상 | 용도 | 넣을 문장 방향 |
| --- | --- | --- |
| [SoundCloud](https://soundcloud.com/) | 데모, 미발매곡, 스케치, 해외 청취자 반응 | "정식 발매 전에는 SoundCloud 등 공개 플랫폼으로 곡의 반응과 협업 가능성을 테스트할 수 있다." |
| [Bandcamp](https://bandcamp.com/artists) | 팬 직접 판매, 디지털 앨범, 굿즈, 후원형 구매 | "팬에게 직접 판매하거나 소장형 앨범 경험을 만들고 싶다면 Bandcamp를 검토한다." |
| [YouTube](https://artists.youtube/) | 리릭비디오, 라이브 클립, Shorts, MV | "YouTube는 포트폴리오이자 검색 엔진이므로 공식 아티스트 채널을 정리한다." |
| [TikTok for Artists](https://artists.tiktok.com/) | 훅/챌린지/숏폼 발견 | "신곡의 훅은 TikTok과 Reels/Shorts에서 짧은 클립으로 테스트한다." |
| [Bugs Connect](https://music.bugs.co.kr/connect/connectall) | 국내 오픈형 음악 등록 후보 | "국내 플랫폼 중 직접 음악을 등록할 수 있는 창구가 남아 있는지 Bugs Connect 같은 현재 페이지를 확인한다." |

### 정식 발매용 애그리게이터

해외 애그리게이터는 가입형으로 빠르지만, 국내 DSP 커버리지와 정산/세금 조건은 서비스마다 다르다. "멜론/지니/벅스/FLO/VIBE까지 전부 자동 유통된다"고 단정하면 안 된다.

| 대상 | 성격 | 장점 | 확인할 것 |
| --- | --- | --- | --- |
| [DistroKid](https://distrokid.com/) | 구독형 글로벌 유통 | 빠른 업로드, 독립 뮤지션 친화 | 국내 DSP 포함 여부, 유튜브 Content ID, 해지 후 유지 조건. 공식 도움말의 [서비스/스토어 목록](https://support.distrokid.com/hc/en-us/articles/360013649093-Which-Services-and-Stores-Does-DistroKid-Send-Music-To), [요금 안내](https://support.distrokid.com/hc/en-us/articles/360013648973-How-Much-Does-DistroKid-Cost) 확인 |
| [TuneCore](https://www.tunecore.com/) | 글로벌 유통/퍼블리싱 서비스 | 옵션이 많고 분석/퍼블리싱 기능이 있음 | 가격 모델, 국가별 세금, 한국 DSP |
| [CD Baby](https://cdbaby.com/) | 글로벌 유통/물리/퍼블리싱 연계 | 오래된 독립 유통사, 원스톱형 | 수수료, 발매 단위 비용, 권리 설정 |
| [RouteNote](https://routenote.com/kr/) | 무료/프리미엄 선택형 유통 | 비용 부담이 낮은 선택지 | 무료 플랜 수익 배분, 심사 기간 |
| [Amuse](https://www.amuse.io/en/) | 유통+아티스트 서비스 | 모바일/글로벌 중심 | 플랜별 제공 DSP와 정산 조건 |
| [Ditto Music](https://dittomusic.com/en) | 글로벌 유통/레이블 서비스 | 독립 레이블형 기능 | 가격, 국내 DSP, 저작권 관리 범위 |

### 국내 유통 문의 후보

아래는 "가입하면 바로 올릴 수 있다"기보다, 국내 DSP와 홍보/레이블 네트워크까지 고려할 때 문의 후보로 넣을 만한 곳이다.

## 원고에 바로 넣을 수 있는 대체 문단 초안

### 오픈 플랫폼 대체 문단

네이버 뮤지션리그처럼 하나의 국내 플랫폼에 데모 공개, 팬 소통, 판매, 지원사업이 모여 있던 시대는 지났다. 지금은 목적별로 채널을 나누는 편이 좋다. 데모와 미발매곡은 SoundCloud나 Bandcamp에 올려 반응을 보고, 영상과 라이브 클립은 YouTube와 Shorts/Reels/TikTok에 맞춰 편집한다. 정식 발매는 유통사나 애그리게이터를 통해 진행하고, 발매 후에는 Spotify for Artists, Apple Music for Artists, YouTube for Artists 같은 공식 아티스트 도구에서 프로필과 통계를 관리한다.

### 지원사업 대체 문단

지원사업은 매년 예산과 주관기관의 방향에 따라 바뀐다. 따라서 특정 사업을 "항상 열리는 프로그램"처럼 소개하기보다, 매년 확인해야 할 공고처를 안내하는 것이 안전하다. 현재 확인할 만한 대상은 KOCCA, MUSE ON, MU:CON, CJ문화재단 튠업, 유재하 음악경연대회, 경기콘텐츠진흥원 인디스땅스, 서울문화재단, 서울거리공연 구석구석라이브, 지역 음악창작소 등이다.

### 앨범 아트 대체 문단

그라폴리오 대신 현재는 Notefolio, Behance, ArtStation, Instagram, X, 크몽, 숨고 등에서 작가를 찾는 편이 현실적이다. 작가에게 의뢰할 때는 단순히 이미지 파일을 받는 것에서 끝내지 말고, 상업 이용 범위, 2차 편집 가능 여부, 원본 파일 제공 여부, 크레딧 표기, 독점 사용 여부를 메일이나 계약서로 남겨야 한다.

### 보도자료/큐레이션 대체 문단

검색 결과를 만들기 위해 저가 홍보성 기사를 대량 송출하는 방식은 신뢰를 해칠 수 있다. 대신 공연, 발매, 수상, 지원사업 선정처럼 실제 뉴스 가치가 있는 사건을 보도자료로 정리하고, 공식 홈페이지/EPK와 함께 관리한다. 음악 발견을 노릴 때는 Spotify for Artists의 플레이리스트 피칭, YouTube/Shorts, TikTok, 장르별 큐레이션 채널, 뉴스레터, 블로그, 플레이리스트 운영자에게 맞춤형으로 제안하는 편이 낫다.

## 링크 검증 메모

보고서 작성 시 본문 링크 77개를 자동 접속 점검했다. 이후 자동 접속에서 401/403 또는 타임아웃이 난 링크는 `https://r.jina.ai/http://...` reader 경유로 다시 확인했다.

reader로 추가 확인된 항목:

- Canva: 일반 첫 화면은 방어 페이지가 나왔지만, [앨범커버 제작 페이지](https://www.canva.com/create/album-covers/)와 [콘텐츠 라이선스 계약](https://www.canva.com/policies/content-license-agreement/)은 확인 가능했다. 앨범커버 제작 도구로는 유효하되, Free/Pro/AI 생성 콘텐츠별 라이선스를 확인해야 한다.
- Pexels: [메인](https://www.pexels.com/)과 [라이선스](https://www.pexels.com/license/) 확인 가능. 무료 사용, 출처 표기 불필요, 수정 가능. 단, 무수정 재판매, 보증/추천 오인, 스톡 플랫폼 재배포, 상표 사용은 제한된다.
- Pixabay: [메인](https://pixabay.com/) 확인 가능. 이미지, 영상, 음악, 효과음, 3D 모델 등을 제공한다. 라이선스 요약은 브라우저 수동 확인 권장.
- Adobe Express: [영문](https://www.adobe.com/express/)과 [한국어](https://www.adobe.com/kr/express/) 페이지 확인 가능. 무료/프리미엄 플랜과 SNS 이미지/비디오/홍보물 제작 용도로 유효하다.
- Unsplash: 메인/라이선스 원문은 계속 봇 차단이 있었지만, [공식 도움말의 라이선스 문서](https://help.unsplash.com/en/articles/2612315-unsplash-license)는 확인 가능했다. 대부분의 개인/상업/에디토리얼 프로젝트에 무료 사용 가능하나 금지 사용은 약관 확인 필요.
- CD Baby: 메인/가격 페이지는 reader가 빈 결과를 냈지만, [공식 Help Center](https://support.cdbaby.com/hc/en-us)에서 distribution, payment, legal/policy 카테고리를 확인했다.
- ArtStation: marketplace는 CAPTCHA가 있었지만 [prints 페이지](https://www.artstation.com/prints)와 Find an Artist/Marketplace 링크 구조는 확인됐다. 작가 포트폴리오 탐색 후보로 유지 가능하다.
