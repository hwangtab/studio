# 아티스트 상점 계획 — 2026-10-14

상점(`/ko/shop`, `lib/shop/CLAUDE.md`)을 아티스트별 공식 상점으로 넓힌다. 새 주문 흐름을 만들지 않고, 상점의 결제·재고·배송과
펀딩의 아티스트 계정·정산 계산을 이어 붙인다.

## 1. 결정 (운영자 2026-10-14)

| 항목 | 결정 |
|---|---|
| 판매자 | 스튜디오. 아티스트에게는 정산한다(펀딩과 같은 구조) |
| 재고·발송 | 아티스트가 재고를 맡기고 스튜디오가 발송한다 — 처리방침의 배송지 제공 대상이 늘지 않는다 |
| 수수료 | 스튜디오 45% · 아티스트 55%(음반 매장 위탁 수준). 상품 판매가(VAT 포함) 기준, 배송비는 스튜디오 몫 |
| 시범 | 자이(Jai) |

정산식은 `lib/shop/artistPayout.ts`. 개인 아티스트는 세금계산서가 없어 부가세 상당액(10/110)과 원천징수 3.3%를 뺀다 —
두 유형 모두 스튜디오에 남는 금액이 같다(20,000원 CD 1장: 사업자 11,000원 / 개인 9,670원 이체, 스튜디오 8,182원).

## 2. 단계

**1단계 — 위탁 상품 + 수동 정산 (구현됨)**
- 상품에 `artist` 하나를 붙인다. 아티스트 페이지 `/ko/artists/<slug>`에 상품이 모이고, 상품 화면이 아티스트로 링크한다.
- 아티스트 등재는 후원 멤버십과 같은 `data/artists` 목록(멤버십 없이 상점만이면 `supportActive: false`).
- `/admin/shop`의 "아티스트 정산 예정"이 그 달에 발송한 주문으로 이체액을 계산한다. 이체는 운영자가 한다.
- 실물이면 종류를 가리지 않는다: CD·카세트·바이닐·티셔츠·포스터·가사집·과정집·악보집. 한정판은 총 재고 수로 된다.

**2단계 — 정산 기록 (아티스트가 2~3팀을 넘으면)**
- 정산 표(아티스트 × 월)·확정·정산 메일. 펀딩 정산 화면을 본뜬다. 이미 정산한 달의 반품을 다음 달에 자동으로 차감한다.
- 제작 대행비 공제(펀딩 설계비 공제와 같은 구조).

**3단계 — 특수 상품 (구현됨)**
- 디지털 앨범·공연 실황 음원·악보 PDF (구현됨): 배송지 없는 주문 경로(디지털만 담으면 배송지·배송비 없음)와 R2 내려받기 게이트
  (첫 내려받기 기록 → 고객 취소 제한, 운영자 환불은 가능). 큰 파일은 운영자가 R2에 `shop/` 접두사로 올리고 관리자 상품 화면에서 키를 넣는다.
  정산 예정 표는 배송 없는 주문을 결제 승인 월로 세고, 내려받기 전 주문은 "철회 가능 N건"으로만 알린다(정산 기록은 2단계).
- 예약 판매 (구현됨): SKU에 발송 예정일. 결제·재고는 그대로.
- 넘버링 (구현됨): 결제 확정 때 SKU별 일련번호를 주문 줄에 남긴다.
- 공동 제작: 상점이 아니라 펀딩으로 연다. 아티스트 페이지에서 진행 중인 펀딩을 잇는다.

**4단계 — 아티스트 직접 등록 (구현됨) + 상점 이용료 (아직)**
- 직접 등록: 상품 정본이 파일과 DB 둘이고(`shop_products`·`shop_product_skus`), 개설자 콘솔 상점 탭에서 등록·심사 신청한다.
  관리자 `/admin/shop/products`가 승인·보완 요청·반려를 한다. 승인 때 SKU가 잠겨 가격·옵션명·id를 못 바꾼다(가격 변경은 새 옵션).
  승인 뒤 부제·소개·사진·공개 여부·새 옵션·판매 종료는 아티스트가 고치고, 고치면 운영자에게 메일이 간다. 판매 현황 표가 콘솔에 있다.
  규칙은 `lib/shop/CLAUDE.md`, 설계는 `docs/shop-artist-platform-design-2026-10.md`.
- 월 이용료는 정기결제(`subscriptions`)로 — 아직 없다.

## 3. 자이 시범 판매 전에 필요한 것

1. **상점 판매 개시 체크리스트**(`lib/shop/CLAUDE.md`) — 마이그레이션 0052, 처리방침 개정·판본, 이용약관 청약철회 조항.
3. **자이 등재 정보**(`data/artists`): 소개 문안, 권리 확인된 사진(`/images/artists/`), 링크, 세금 유형(사업자/개인), 등재 동의.
4. **위탁 판매 계약** — 재고 소유권(판매 전까지 아티스트), 보관 중 분실·파손 책임, 정산 주기·방법, 반품·불량 처리, 재고 회수.
5. **세무 확인** — 개인 아티스트가 자기 음반·굿즈를 위탁해 받는 돈을 사업소득 원천징수로 처리해도 되는지(첫 정산 전).
6. 상품 정보: 품목·옵션·가격·사진(`/images/shop/<이름>-YYYYMMDD.webp`)·맡길 수량.
