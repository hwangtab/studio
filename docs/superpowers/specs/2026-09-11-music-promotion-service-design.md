# 음원 발매 홍보 서비스 설계

작성일 2026-09-11 · 상태: 설계 확정, 구현 대기

## 1. 배경

스튜디오 놀은 이미 음원 발매 홍보를 실제로 수행하고 있다. 전용 CLI 파이프라인
`~/music-promo`(별도 저장소)로 5개 캠페인에서 **1,444통을 실발송**했다.

| 캠페인 | 성공 발송 | 기간 | 성격 |
|---|---:|---|---|
| namsan-tower (마리코 & 유키에 정규 1집) | 1,218 | 2026-08-25 ~ 09-09 | 우리가 믹싱·기획·제작 |
| hwa (그라인드코어 EP) | 125 | 2026-09-01 ~ 09-08 | 외부 밴드 |
| ohyoon-opening (판화전 개막식) | 65 | 2026-09-09 ~ 09-10 | 미술 |
| ksfp-press / ksfp-orgs (연대 공연) | 36 | 2026-09-09 ~ 09-10 | 공연·시민단체 |

확보된 자산:

- 국내외 매체·기자·평론가 연락처 (고유 이메일 약 1,884개, 44개 CSV, 파일별 출처·수집일·오염 사례 문서화). 해외 60개국+, 세그먼트 5종(desk/radio/critic/shop/live)
- `campaign.ts` 한 파일만 채우면 재사용되는 파이프라인 — 앨범·EP·공연·전시 4종으로 실증
- 다국어 보도자료 자동 조립 (남산타워 기준 ko/ja/en + es/pt/de/fr/zh)
- 매체 형태별 원고 변환(기사 원고 / 제보 폼 / 라디오 멘트 / 매장 소개)
- 프레스킷 웹페이지 + ZIP + 고해상 아트워크
- 전곡 이어듣기 영상 파이프라인 (Whisper 강제정렬 + ffmpeg)
- 안전장치: 근거 없는 개인화 차단, 도입부/본문 언어 불일치 차단, 하루 발송 상한, `"보내기"` 타이핑 확인

**이 설계는 이 역량을 외부 아티스트에게 파는 단독 상품을 정의한다.**

## 2. 현황의 약점 (상품화 전에 인정하고 시작하는 것들)

1. **게재 실적 기록이 0건.** `registry.json` 기준 회신 3건, 게재 확인 0건. 열람·클릭 추적을
   도달률을 위해 의도적으로 껐고, 회신·게재는 `log` 명령으로 사람이 수동 기록인데 그게
   거의 이뤄지지 않았다. "성과가 없었다"가 아니라 **"측정 체계가 없다"**이며, 판매 시점에
   내놓을 실적 근거가 없다는 뜻이다.
2. **남산타워 반송률 9.1%** (111/1,218). `music-promo/README.md`가 스스로 적어둔
   "5% 초과 시 도메인 평판 훼손" 기준의 두 배다.
3. **발신 도메인이 매번 다르다.** 남산타워 `press@alf.seoul.kr`, HWA `contact@ggac.kr`.
   Studio NOL 상품이 되면 발신 주체가 통일돼야 하는데, 위 반송률로 주력 도메인을
   쓰면 고객 응대 메일까지 함께 죽는다.

2주 샘플러 $595(83만) · 4주 스타터 $995(139만) · 6주 Buzz Builder $1,995(279만) ·
6주 Critical Mass $2,495(349만). 업계 일반은 월 $2,000~5,000(280~700만원).

### 업계가 정직성을 지키는 방식

SubmitHub·Groover·Musosoup 모두 **"응답은 보장하되 게재는 보장하지 않고, 응답이 없으면
환불"** 구조다. 반대로 신뢰를 무너뜨리는 건 세 가지 조합이었다 — 절대 숫자를 못박는 약속,
종료 후 증빙 리포트 부재, 선불 후 과정 불투명.

## 4. 상품 정의

### 4.1 개요

**음원 발매 홍보** — 정가 **120만원**, 한정 기간 도입가 **30만원** (모두 부가세 별도)
· 1회 실행 · 월 3팀 한정

단일 티어다. 규모·기간별 티어를 두지 않는다. 해외식 기간제·월 리테이너도 쓰지 않는다.
**의뢰가 들어오면 한 번, 며칠에 걸쳐 집중 실행하고 리포트로 끝낸다.**

**정가는 120만원**이다. 근거는 둘이다 — 집중 작업 5일 × 8시간 × 시간당 3만원, 그리고
해외 동급(Music With Depth 4주 스타터 $995 ≈ 139만원)과 같은 자리다.

**도입가 30만원은 한정 기간 할인이다.** 게재 실적 기록이 0건인 상태에서 정가를 받을 근거가
아직 없기 때문이다. 30만원은 돈을 버는 가격이 아니라 **실적과 사례를 사는 가격**이다.

> **할인 표시 준수 사항 (필수)**
>
> 정가를 한 번도 판매하지 않은 채 할인가만 운영하면 표시광고법상 부당한 표시·광고에
> 해당한다. 두 가지를 반드시 지킨다.
>
> 1. **할인 종료 조건을 페이지에 명시하고 실제로 지킨다.** 기간이 무기한 연장되는 것이
>    전형적인 제재 사유다. **종료일은 2026년 12월 31일**이며, 페이지·계약서·가격 상수
>    주석에 같은 날짜를 박는다. 월 3팀 한도와 맞물려 도입가 적용은 최대 10팀 안팎이 된다.
> 2. **종료 후 실제로 120만원에 판매한다.** 정가가 실판매가가 아니면 할인 표시 자체가
>    성립하지 않는다.

### 4.2 포함 산출물 (전부 포함, 추가금 없음)

| 산출물 | 내용 |
|---|---|
| 보도자료 | 한국어 + 영어 + 권역 맞춤 3개 언어(총 5개 언어). **어느 언어를 쓸지는 음악·아티스트에 맞춰 우리가 선정하고 심사 통과 시 알려준다** |
| 프레스킷 페이지 | studionol.co.kr 내 전용 페이지 — 전곡 인라인 재생, 가사, 크레딧, 고해상 아트워크, 프레스킷 ZIP |
| 매체 발송 | 국내 음악매체·기자·평론가 + 해외 매체·라디오·레코드숍·페스티벌. 매체 성격별로 다른 본문. **발송 대상 수는 장르·언어 적합성에 따라 선별하며, 심사 통과 시 예상 규모를 확정해 알려준다**(§4.5) |
| 파생 원고 | 라디오 DJ 멘트 · 매장 소개문 · 언론사 제보 폼용 축약본 |
| 전곡 이어듣기 영상 | 곡별 챕터. **가사 텍스트를 주면 자막 정렬, 없으면 챕터만**(Whisper 받아쓰기는 오타가 나므로 자막을 붙이지 않는다). 곡수 상한 없음 |
| 리포트 | 발송 명세 + 회신 + 게재 확인분 (§6) |

### 4.3 약속하지 않는 것 (페이지에 그대로 게시)

- **기사 게재를 보장하지 않는다.** 보장하는 업체가 있다면 광고를 사서 기사처럼 보이게 하는 것이다.
- **플레이리스트 등재·스트리밍 수치를 보장하지 않는다.** 조회수·구독자·재생수를 판매하는 서비스와 다른 일을 한다.
- **특정 매체 노출을 약속하지 않는다.** 통제하는 범위는 "누구에게 어떤 형태로 닿는가"까지다.

대신 **실행량을 약속한다.** "이런 자료를 만들어 이런 성격의 매체 N곳에 보낸다"를 숫자로
쓰고 리포트로 증빙한다.

### 4.4 실행 형태

```
집중 작업 5일 (명단 준비 · 보도자료 5개 언어 · 도입부 · 프레스킷 · 영상)
  → 고객 확인
  → 발송 1~3주 (자동 배치, 하루 몇 분의 명령 실행)
  → 리포트
```

**발송을 하루에 끝내지 않는 이유를 고객에게 먼저 설명한다.** 1,200통을 몰아 쏘면 발신
도메인이 스팸으로 분류되고, 그러면 그 캠페인 전체가 무의미해진다. 이 사실을 숨기지 않고
먼저 말하는 것이 신뢰 신호가 된다 — 하루에 다 쏘는 업체가 왜 효과가 없는지를 함께
설명하는 자리이기도 하다.

**고객 확인 단계는 생략할 수 없다.** 남산타워에서 일본 매체 22곳에 한국어 도입부 +
일본어 본문이 붙은 채 나간 사고가 있었고, 근거 없는 개인화를 잡는 검사기가 있어도
사실 오류는 아티스트만 안다.

### 4.5 발송 규모를 약속하는 방식

**모든 캠페인에 동일한 숫자를 약속하지 않는다.** 장르에 따라 적합한 매체 수가 크게 다르기
때문이다 — 남산타워(시티팝·월드뮤직)는 전 권역이 열려 1,218곳이었지만, 장르가 좁으면
그 안에서만 유효하다. 고정 숫자를 내걸면 **맞지 않는 매체에 억지로 보내거나 약속을 어기거나**
둘 중 하나가 되고, 전자는 §5.2의 명단 소모로 직결된다.

대신 이렇게 한다.

| 단계 | 숫자를 말하는 방식 |
|---|---|
| 페이지 히어로 | 숫자 없이 범위로 — "국내 음악 기자·평론가와 해외 60개국 매체에 보냅니다" |
| 페이지 사례 섹션 | **실측값**으로 — "남산타워 1,218곳 / 60개국 / 8개 언어 / 12일" |
| 심사 통과 통보 | **이 캠페인의 예상 발송 규모와 언어 구성을 확정해 전달** |
| 계약·리포트 | 확정 숫자 기준으로 약속하고 증빙 |

막연한 "1,200곳"보다 "이 앨범은 실제로 1,218곳에 보냈다"가 설득력이 강하고, 지킬 수 있는
약속만 하게 된다.

## 5. 심사

### 5.1 원칙 — 심사는 음악을 듣는 일이다

> 우리는 좋은 음악만 홍보합니다. 정확히 말하면 — 우리가 아는 기자와 평론가에게 보냈을 때,
> 그들이 끝까지 들을 음악인지를 봅니다. 프로듀서가 전곡을 듣고 직접 판단합니다.

판단 기준 셋:

1. **이 음악을 받아 들을 기자가 우리가 닿는 범위 안에 있는가.** 강한 영역은
   인디·얼터너티브·월드뮤직·시티팝·메탈·포크다. 좋은 음악이어도 접점이 없으면 보낼 곳이 없다.
2. **음악 안에서 이야기가 나오는가.** 보도자료는 소개문이 아니라 기자가 기사로 만들 재료다.
3. **우리가 이 작업을 좋아하는가.** 좋아하지 않는 음악을 남에게 권할 수 없고, 그 메일은 티가 난다.

**거절 시 이유를 적어 보낸다.** 대부분은 "음악이 나쁘다"가 아니라 "우리가 닿는 매체에서
이 음악을 받을 곳을 찾지 못했다"이며, 그 경우 어디에 보내야 할지를 아는 만큼 적어 준다.

심사 결과는 **3영업일 내 통보**한다.

### 5.2 왜 심사하는가

두 가지다. 첫째, 매번 보내는 대상이 같은 사람들이라 함량 미달 자료를 반복해 보내면
**연락처 자산 자체가 소모된다** — 한 번 태우면 복구되지 않는다. 둘째, 30만원이라는
가격에서 심사는 거절 장치가 아니라 **"싸서 대충 하는 게 아니다"라는 신호**다. 심사 통과
자체가 아티스트에게는 받을 만한 평가가 된다.

### 5.3 진행 요건 (심사와 별개)

| 요건 | 이유 |
|---|---|
| 발매일 확정 + 유통 등록(스트리밍 링크) | 링크 없이 해외 발송하면 파이프라인이 자동 차단한다 |

**이미 발매된 음원도 받는다.** 해외 PR사는 대부분 "발매 6~8주 전"을 요구하지만, 국내
인디는 발매하고 나서야 홍보를 생각한다. 그쪽이 더 큰 시장이며, 발매 시점에 따라 보도자료
프레이밍만 달라진다.

아트워크(2000px+)·프로필 사진·크레딧·가사는 요건이 아니라 "주시면 좋은 것"이다.
저작권·샘플·커버 허가는 심사·진행 요건이 아니며, 신청 확인란에서 아티스트 책임임을
확인받는 선에서 처리한다.

## 6. 리포트

게재를 보장하지 않으므로 **리포트가 이 비용이 어디에 쓰였는지를 증명하는 유일한 물건**이다.

| 항목 | 표기 방식 |
|---|---|
| 법인·단체 매체 | **매체명 공개** (법인 정보) |
| 개인 기자·평론가·1인 매체 | **집계만** — "국내 음악 평론가 42명", "일본 음악 매체 기고자 14명" |
| 발송 집계 | 국가별·성격별(기자/평론/라디오/레코드숍/페스티벌)·언어별 |
| 보낸 것 | 보도자료 전문(언어별), 프레스킷 페이지 주소, 영상 링크 |
| 회신 | 원문 제공하되 **발신자 이름·소속·주소 제거** |
| 게재 | 확인된 기사·리뷰·선곡 링크 |
| 반송·수신거부 | 숨기지 않고 그대로. 명단 품질 지표다 |
| 이메일 주소 | **전면 비공개** |

개인 기자를 집계로만 표기하는 이유는 §8에서 다룬다.

## 7. 페이지 설계

### 7.1 라우트

게재 실적 기록이 0건이므로 **실행량으로 증명한다.** 남산타워 1,218통·60개국·8개 언어·
12일 배치 발송, HWA 125통(메탈 전문 매체 수직 수집). 그리고 실제로 만든 프레스킷 페이지를
링크로 걸어 결과물을 직접 보게 한다.

첫 유료 캠페인부터는 회신·게재를 반드시 기록한다(§9).

1. **SEO** — 스토리 1,000편이 가장 큰 자산이다. `music-pr1`(발매 홍보를 정면으로 다루는
   유일한 글)을 필두로 발매·유통 관련 글에서 내부 링크를 건다. `buyerIntentHubs`의
   `indie-release-guide` 허브에도 연결한다.
2. **프레스킷 페이지가 곧 포트폴리오** — 캠페인마다 만드는 프레스킷 페이지가 사례 카탈로그가

3. **AI 검색(GEO)** — 믹싱 리드가 ChatGPT 추천에서 온 전례가 있다. `pages/api/llms.ts`에
   등재해 "인디 음원 홍보 어디에 맡기나" 류 질문에 잡히게 한다.

## 8. 법적 고려

### 8.1 보내는 행위

**개인정보보호법** — 기자가 기사 하단·매체 소개란에 스스로 공개한 업무용 이메일은, 대법원이
"정보주체가 공개한 범위 내에서는 별도 동의 없이 처리 가능"하다는 취지로 판단해 온 영역이다.
다만 **수집 출처 고지**(요구 시 답변)와 **수신거부 처리** 의무가 따른다. 둘 다 이미 갖춰져
있다 — `contacts/sources/` CSV에 출처 URL 컬럼, `registry.json`에 수신거부 영구 기록,
발송에 `List-Unsubscribe` 헤더.

**정보통신망법 제50조(영리목적 광고성 정보)** 가 더 미묘하다. 보도자료는 전통적으로 취재
자료로 취급돼 왔으나, **유료 대행이 되는 순간 성격이 회색지대로 들어간다.** 방어선은 본문에
"이 메일은 ○○의 발매 보도자료입니다. 수신을 원치 않으시면 [수신거부]"를 **명시적으로**
넣는 것이다. 현재는 헤더에만 있고 본문 안내가 약하다.

**변호사 확인이 필요하다.** 위는 일반적 법리 정리이지 법률 자문이 아니며, 특히 "유료 대행이
광고성 정보 전송에 해당하는가"는 단정할 수 없다.

### 8.2 리포트 공개 범위

개인 기자·평론가·1인 매체는 **매체명이 곧 개인 식별 정보**다. 이를 고객에게 제공하면
**개인정보 제3자 제공**이 되어 동의 없이는 불가하다. 따라서 §6의 구분(법인은 실명, 개인은
집계)을 지킨다. 이 분류는 **자동화해야 한다** — 손으로 하면 언젠가 샌다.

### 8.3 페이지 표기

"60개국", "국내외 음악 매체·기자·평론가", 실측 사례의 "1,218곳" 같은 **집계 표현은
문제없다.**
반대로 "기자 개인 이메일 1,884개를 확보하고 있습니다" 류로 **명단 보유를 자산처럼 자랑하는
카피는 쓰지 않는다.** 사실이어도 대외 문서에서 스스로 분쟁 소재를 만드는 문장이다.
"닿는 범위"로 말하고 "보유한 명단"으로 말하지 않는다.

### 8.4 조치 목록

1. 발송 본문에 명시적 수신거부 안내 추가 (`music-promo` 렌더러)
2. 리포트 생성 시 개인 식별 수신자 자동 집계 처리
3. 사이트 개인정보처리방침에 "언론 홍보 대행 업무를 위한 매체 연락처 처리" 항목 추가
4. 수집 출처 고지 요청 대응을 위한 출처 URL 보관 유지 (이미 충족)

## 9. 선행 작업 (`music-promo` 저장소, 별도)

**아래 다섯은 첫 유료 캠페인보다 먼저다.** 특히 도메인 워밍업은 시간이 걸려 페이지 공개
전에 시작해야 한다.

| 작업 | 이유 |
|---|---|
| `press.studionol.co.kr` 발신 도메인 + SPF/DKIM/DMARC 분리 | 반송률 9.1% 명단으로 주력 도메인을 태우면 고객 응대 메일까지 스팸함으로 간다. 새 도메인은 워밍업이 필요해 첫 1~2건은 발송이 더 느리다 |
| 명단 약 1,884개 MX 재검증·죽은 도메인 제거 | 반송률을 5% 미만으로. 죽은 도메인은 이미 `contacts/README.md`에 문서화돼 있다(`chol.com`, `kdaily.com` 폐간, `rollingstonekorea.co.kr` 등) |
| 발송 본문 수신거부 안내 | §8.1 |
| `report` 명령 신설 | 리포트가 상품의 결과물이다. 개인 식별 수신자 집계를 자동 처리한다 |
| 고객 데이터 커밋 분리 규칙 | `music-promo`는 "비공개 전제로 명단·발송기록을 통째로 커밋"한다고 README에 명시돼 있다. 유료 고객의 음원·자료·연락처가 들어오면 이 전제가 바뀐다 |

## 10. 코드 배선 (`studio` 저장소)

### 10.1 `data/pricing.ts`

- `RELEASE_PRESS_PRICE = 1200000` (정가) 및 `RELEASE_PRESS_INTRO_PRICE = 300000`
  (한정 도입가) 추가. 두 값이 함께 움직이므로 오퍼는 도입가를 표시하되 정가를
  `originalPrice`로 병기한다
- `RELEASE_PRESS_INTRO_ENDS_ON = '2026-12-31'` 추가. 기간이 지났는데 상수가 그대로면
  부당 표시가 되므로, `practiceRoomAvailability` 패턴처럼 **테스트가 만료를 CI에서
  잡게 한다**. 페이지·계약서·상수가 같은 날짜를 보게 배선한다
- 300,000은 제거 대상인 `service-promo`가 쓰던 값이라 충돌하지 않는다. 1,200,000은 신규 값이다
- `service-release-press` 오퍼 신설 (`additionalServices`)
- **`service-promo`(30만원) 제거** — 같은 일을 5만원 싸게 판다고 적혀 있어 공존 불가
- **`service-epk`(50만원) 제거** — 이 상품에 EPK가 포함되어 중복이고, 도입가 기간에는
  단품(50만)이 전체 패키지(30만)보다 비싼 가격 역전이 생긴다
- **번들 3종 features 수정** — "발매 홍보 — 국내 기자·평론가 + 해외 매체·라디오·
  플레이리스트 피칭"을 "발매 홍보 포함 (단독 구매 시 120만원)"으로. **정가로 표기한다** —
  할인은 한시적이고, 번들의 체감 가치도 정가 기준이어야 맞다
- 번들 고객도 **심사를 거치고 월 3팀 한도에 포함된다.** 다만 제작 단계에서 이미 함께
  판단했으므로 심사는 형식이다. 한도에 포함하지 않으면 한도가 무의미해진다

## 11. 리스크

| 리스크 | 대응 |
|---|---|
| 도입가에 문의가 몰려 월 3팀을 못 지킨다 | 페이지에 월 한도 명시, 차면 다음 달 대기 접수 |
| 발신 도메인 평판 훼손이 본업 메일로 번진다 | 서브도메인 분리 + 명단 재정제 선행 (§9) |
| 실적이 쌓여도 가격을 못 올린다 | 정가 120만원을 함께 표시해 인상이 아니라 할인 종료가 되게 한다 |
| **정가를 판 적이 없어 부당 할인 표시가 된다** | 종료 조건 명시·준수 + 종료 후 실제 정가 판매 (§4.1) |
| 도입가 기간 중 시간당 단가가 낮다 | 한시적 손실 리더로 수용. 실적 축적과 제작 상품 유입이 회수 경로이며, 종료 후 정가로 회복한다 |
| 개인정보 제3자 제공 사고 | 리포트 집계 처리 자동화 (§8.2) |
| 장르가 좁아 발송 규모가 기대에 못 미친다 | 고정 숫자를 약속하지 않고 심사 통과 시 확정 통보 (§4.5) |
| 고객 데이터가 개인 저장소에 섞인다 | 커밋 분리 규칙 (§9) |

## 12. 비목표

- 기간제 캠페인·월 리테이너 — 의뢰 단위 1회 실행만 한다
- 발매 전/후 2라운드 발송 — 1회 실행 원칙에 어긋난다
- 규모별 티어 — 단일 티어를 유지한다
- 게재 건수 보장·성공 보수 — 추적 체계가 서기 전에는 정산 근거가 없다
- 조회수·스트리밍·팔로워 판매 — 영구 비목표
- 전용 신청 폼 신설 — 1차는 카카오 문의로 받고, 물량이 검증되면 검토한다
- 모든 캠페인에 동일한 발송 건수를 약속하는 것 (§4.5)
