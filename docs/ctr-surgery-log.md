## 변경 상세 (2026-07-18)

### audioformat1
- **타이틀**: `WAV MP3 차이·MP3 WAV 차이 — 음질·용량·발매 납품 형식 비교` → `WAV MP3 차이 완전 정리 — 음질·용량 비교, 발매·납품엔 어떤 형식?`
- **근거**: 6/9 재제목이 두 어순을 병기했으나 CTR 0.54% 정체. 구글은 어순 정규화 매칭하므로 병기 이득 없음, SERP 가독성만 훼손. 고볼륨 어순("wav mp3 차이" 409노출)은 유지.
- **summary**: 어순 병기 제거, 사용 상황(발매·납품·데모)별 선택 프레임으로 재작성.

### seoul-metro-guide1
- **타이틀**: `수도권 지하철로 연신내 녹음실 방문 가이드 — 서울·경기·인천에서 스튜디오 놀까지` → `연신내 녹음실 가는 법 — 서울·경기·인천 지하철 노선별 소요시간 총정리`
- **근거**: 핵심 상업 키워드("연신내 녹음실") 전진 배치 + 구체 효용(노선별 소요시간). 기존 랭킹 쿼리("서울 당일치기 여행")는 의도 미스매치라 클릭 가치 없음 — 재조준이 맞음.
- **summary**: "연신내에서 연신내" 템플릿 치환 버그 수정. 본문 검증 사실만 사용(4번 출구 도보 5분, 서울 40~60분, 경기·인천 1시간~1시간 30분).

- **summary**: 1문장 → 본문 표 검증 수치(대전 1:25·동대구 2:15·부산 3:05, 연신내 환승 35분 포함) 기반 확장.
