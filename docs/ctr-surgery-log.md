   **착수하지 않는다.** 하려면 먼저 "패자와 승자 중 어느 쪽이 그 쿼리의 더 나은 답인가"를

## 실험 결과 판정 (2026-08-14)

> 리뷰일이 지났거나 오늘 도래한 3편(copyright-cover1·songstructure1·falsetto1)을 확정 판정하고,
> 나머지 4편(session-musician1·audioformat1·seoul-metro-guide1·ktx-gyeongbu-guide1)은 리뷰일 미도래로
> 잠정 관찰치만 기록한다. 원본 데이터는 2026-08-14 수집된 `docs/gsc-raw/page-query.csv`,
> `docs/gsc-raw/page-all.csv`.

### 분류 규칙 (재현 가능)

**정의형 쿼리** = `query` 문자열에 `뜻|의미|차이|무엇` 중 하나라도 포함된 행. 그 외는 전부 **그 외(거래형
포함)**로 분류한다. `page-all.csv`·`page-query.csv` 모두 목차 앵커(FAQ 섹션 등)가 `#...`이 붙은 별도
"페이지"로 잡히므로(예: `.../copyright-cover1#커버곡-유튜브-수익화...`), **`#`이 포함된 행은 제외**하고
정규 URL 행만 사용한다(제외하지 않으면 노출 총합이 실제보다 20%가량 부풀려짐 — 앵커 행에 중복 노출이
잡히기 때문).

```bash
python3 - <<'EOF'
import csv, re
pattern = re.compile(r'뜻|의미|차이|무엇')
def_imp=def_click=other_imp=other_click=0
with open("docs/gsc-raw/page-query.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        if '#' in row['page']:
            continue
        imp, clk = int(row['impressions']), int(row['clicks'])
        if pattern.search(row['query']):
            def_imp += imp; def_click += clk
        else:
            other_imp += imp; other_click += clk
print(f"정의형: 노출 {def_imp} 클릭 {def_click} CTR {100*def_click/def_imp:.2f}%")
print(f"그 외: 노출 {other_imp} 클릭 {other_click} CTR {100*other_click/other_imp:.2f}%")
EOF
```

```
정의형: 노출 17835 클릭 38 CTR 0.21%
그 외: 노출 127738 클릭 2373 CTR 1.86%
```

**약 8.7배 격차**(1.86 / 0.21). 페이지별 정의형 비중은 같은 필터(`#` 제외) + `slug`로 그룹핑해 구했다
