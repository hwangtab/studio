# 코드 리뷰 및 개선 보고서

**날짜:** 2026년 2월 4일
**검토자:** Gemini CLI Agent

## 1. 요약
전체적인 프로젝트 구조를 검토한 결과, Next.js의 정적 내보내기(Static Export) 방식을 사용하는 웹사이트로 확인되었습니다. 자동화된 린트(Lint) 및 타입 검사 결과는 대체로 양호하였으나, **아키텍처 변경으로 인한 "죽은 코드(Dead Code)"와 테스트 코드의 불일치**가 가장 큰 문제점으로 발견되었습니다. 또한 이미지 최적화 등 성능 개선이 필요한 부분이 일부 확인되었습니다.

## 2. 주요 발견 사항 (Bugs & Code Conflicts)

### 2.1. `pages_api_backup` 및 테스트 코드의 불일치 (Code Conflict)
*   **현상:** `pages_api_backup/contact.ts` 파일이 존재하며, `__tests__/contact-api.test.ts`는 이 파일을 테스트하고 있습니다.
*   **문제점:** 현재 프론트엔드(`pages/contact.tsx`)는 `EmailJS` 서비스를 사용하여 클라이언트 사이드에서 직접 이메일을 전송하도록 구현되어 있습니다. 즉, **백업된 API 코드는 실제 서비스에서 전혀 사용되지 않는 "죽은 코드"**입니다.
*   **상태:** 발견 당시 테스트 코드가 실패하고 있어(전화번호 유효성 검사 로직 불일치), 이를 수정하여 테스트를 통과시켰습니다. 하지만 **이 테스트가 통과한다고 해서 실제 문의하기 기능이 정상 작동함을 보장하지 않습니다.**
*   **권고:** 혼란을 방지하기 위해 `pages_api_backup` 디렉토리와 관련 테스트 파일(`__tests__/contact-api.test.ts`)을 삭제하거나, 프론트엔드 컴포넌트(`Contact.tsx`)를 테스트하는 방식으로 변경할 것을 강력히 권장합니다.

### 2.2. 이미지 최적화 미흡 (`<img>` 태그 사용)
*   **위치:**
    *   `components/AudioPlayer/Playlist.tsx`
    *   `components/MarkdownRenderer.tsx`
*   **문제점:** Next.js의 `next/image` 컴포넌트 대신 표준 HTML `<img>` 태그를 사용하고 있습니다. 이는 이미지 자동 리사이징, 포맷 최적화(WebP 등), Lazy Loading 등의 이점을 누리지 못하게 하여 페이지 로딩 속도(LCP)에 부정적인 영향을 줄 수 있습니다.
*   **권고:** 가능한 경우 `next/image`로 교체하여 성능을 최적화하세요. (Markdown 렌더러의 경우 외부 이미지를 다루므로 `loader` 설정이 필요할 수 있습니다.)

### 2.3. 하드코딩된 문자열
*   **위치:** `pages/contact.tsx` 등 다수
*   **문제점:** 유효성 검사 메시지, UI 텍스트 등이 컴포넌트 내부에 하드코딩되어 있습니다. `data/siteConfig.ts`가 존재하지만 모든 텍스트가 중앙화되어 있지 않습니다.
*   **권고:** 유지보수와 다국어 확장성을 위해 문자열 상수를 분리하는 것이 좋습니다.

## 3. 서브페이지 검토 결과
*   **포트폴리오 (`pages/portfolio.tsx`):** 정적 데이터(`data/portfolio.ts`)를 기반으로 렌더링되며 특별한 논리적 결함은 발견되지 않았습니다.
*   **스토리 (`pages/stories/`):** Markdown 파일을 기반으로 생성되며 구조적으로 안정적입니다. 다만 앞서 언급한 `MarkdownRenderer`의 이미지 태그 개선이 필요합니다.

## 4. 조치 내역
*   **테스트 수정:** `__tests__/contact-api.test.ts`의 테스트 데이터(전화번호)가 유효성 검사 규칙(`8~20자`)을 만족하지 못해 실패하던 문제를 수정했습니다. (`010` -> `010-1234-5678`)

## 5. 결론
프로젝트는 전반적으로 안정적이나, 과거의 백엔드 로직(API Route)이 정리되지 않은 채 남아있어 유지보수에 혼선을 줄 수 있습니다. **백업 폴더 정리**가 최우선 과제이며, 이후 이미지 최적화를 진행하면 완성도가 더욱 높아질 것입니다.
