## 운영 규칙

1. **F15 업그레이드 ≠ 타이틀 변경.** 타이틀은 [ctr-surgery-log.md](ctr-surgery-log.md)의 측정 상태를 따른다. `content/ctrTargets.test.ts`에 고정된 키워드(songstructure1·audioformat1·falsetto1·noise-reduction1·mastering1 등 9편)는 임의 제거 금지.
2. 업그레이드 체크리스트: 실사례/실데이터 1개 이상 주입 → 최신성 확인 → Pillar 링크 확인 → 관련 스토리 링크 2~3개 → 카카오 CTA 경로 확인 → `npm run content-check` + factGuards 통과.
3. 저자 박스 탈템플릿화는 F15부터 시작 (91% 공통 템플릿 → 페이지 맞춤 or 실명 저자 카드).
4. 티어 재산정: 분기 1회 GSC 감사 크론 결과로 갱신. 다음 재산정 2026-10.
