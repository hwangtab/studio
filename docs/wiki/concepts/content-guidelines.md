# 콘텐츠 작성 가이드라인

스튜디오 놀 사이트(`content/stories/`)에 콘텐츠를 작성할 때 준수해야 할 규칙.
소스: [../content-guidelines.md](../content-guidelines.md) (2025-02-03)

---

## 1. 이미지 사용 규칙

- 기본 원칙: `public/images/` 폴더 내 기존 파일 재활용 우선. 완벽하게 내용과 일치하지 않아도 됨.
- 참조 방식: 마크다운 내 `/images/파일명.jpg` 형태
- 주요 에셋: `studio1~5.jpg`, `hardware1~8.jpg`, `console.jpg`, `recording1~17.png`, `service1~8.jpg`
- 선택 기준: 내용 일치보다 **전반적인 분위기(Mood)**와의 조화 우선

**히어로 이미지 처리**: 본문의 첫 번째 이미지는 자동으로 Hero Section 배경으로 사용되고 본문에서 자동 숨김 처리됨. 별도 캡션 텍스트 불필요.

---

## 2. 글쓰기 톤 & 매너 — 휴머나이징 전략

### 페르소나: 친절한 멘토 선배

- 권위적인 선생님이 아닌, 먼저 경험해 본 선배가 옆에서 조곤조곤 설명하는 느낌
- 독자의 어려움에 공감: "처음엔 다들 어려워해요", "저도 실수했던 기억이 나네요"

### 어투

| 금지 | 권장 |
|---|---|
| ~합니다, ~것입니다, ~살펴보겠습니다 (딱딱한 개조식/번역투) | ~해요, ~거든요, ~일까요?, ~해볼까요? (구어체) |

### 비유 활용

전문 용어는 반드시 일상적 개념에 빗댐:
- 헤드룸 → "천장 높이"
- 오디오 인터페이스 → "통역사"
- 룸 모드 → "방의 거짓말"

---

## 3. 콘텐츠 구조 원칙

### 분량과 깊이

- 피상적인 요약 금지. 최소 100줄 이상 권장.
- "A는 B입니다" 식 사전적 정의 지양.
- 하나의 개념도 '왜(Why)' 중요한지, 현장에서 어떻게 쓰이는지 충분히 설명.

### 글 구성 순서

1. **공감과 문제 제기**: 초보자들이 겪는 어려움으로 시작
2. **비유를 통한 개념화**: 기술 용어 → 일상 비유
3. **핵심 원리 심화**: 파라미터 상호작용 등 깊이 있게
4. **실전 적용 및 팁**: 즉시 써먹을 수 있는 내용
5. **철학적 마무리**: 기술을 넘어 음악을 대하는 태도

### 실전성

- 구체적인 액션 아이템 포함: "지금 바로 모노 버튼을 눌러보세요"
- 열악한 홈레코딩 환경·저가 장비에서의 현실적 대처법 다루기

---

## 4. 날짜 설정 규칙

- 시리즈물 정렬: 이전 편의 날짜보다 **하루 뒤**로 설정
- 미래 날짜 허용(시리즈 정렬 목적)
- Frontmatter `date` 필드: `YYYY-MM-DD` 형식

---

## 5. 작업 프로세스 (믹싱 강좌 계열)

1. **소스 문서**: `/docs/오디오 믹싱 메뉴얼.md` — 원본 교과서
2. **가공**: 챕터 핵심 내용 요약 → 멘토 페르소나로 리라이팅
3. **파일 생성**: `content/stories/mixing{N}.md` 형식

---

## 6. 기술 아키텍처 (Data Flow)

```
content/stories/*.md
  → lib/stories.ts (gray-matter 파싱, remark HTML 변환, 첫 이미지 stripping)
    → pages/[locale]/stories/[id].tsx getStaticProps (JSON 직렬화)
      → MarkdownRenderer 컴포넌트 (클라이언트 렌더)
```

- 이미지: Sharp 자동 최적화, 원본 화질 유지
- 캡션: `MarkdownRenderer`에서 자동 처리, 마크다운 내 텍스트로 별도 작성 불필요

---

## 7. SEO 연계 기준

신규 스토리 발행 시 체크리스트:
- [ ] 분량 5,000자 이상
- [ ] H2 소제목, 표, FAQ 3개 이상
- [ ] 내부 링크: 관련 스토리 2~3개 + 서비스 Pillar 페이지 1개
- [ ] thin content 게이트: 1,500자 미만 시 noindex 자동 적용
- [ ] 키워드 클러스터 커버 여부: [[concepts/keyword-clusters]] 확인
