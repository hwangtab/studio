# 가격 및 오퍼 구조

스튜디오 놀의 공식 서비스 가격 및 패키지 정보. 모든 가격은 VAT 별도.
소스: [../studio-nol-complete-guide.md](../studio-nol-complete-guide.md) 제4·6장

> **전화번호**: 010-4255-7893 (0507 안심번호는 폐기됨 — 표기 금지)

| 항목 | 가격 | 비고 |
|---|---|---|
| 시간당 레코딩 | 100,000원/시간 | 최소 2시간 예약 필수, 전문 엔지니어 포함 |

포함: 전문 엔지니어링, 보컬 디렉팅 지원, 실시간 모니터링, 녹음 파일 제공

## 2. 믹싱

트랙 수 기준 3단계 요금:

| 상품명 | 트랙 수 | 가격 |
|---|---|---|
| 10트랙 이하 | 보컬+MR·소편성 | 200,000원/곡 |
| 11~30트랙 | 일반 밴드·팝 편곡 | 350,000원/곡 |
| 31트랙 이상 | 대편성·복잡한 일렉트로닉 | 500,000원/곡 |

> 사이트 상품명은 트랙 수 그 자체다(2026-09-02 변경). 예전 내부 축약인
> "Level 1~3"은 더 이상 고객 대면 어디에도 쓰지 않는다 — 이 표기로 답하면
> 사이트에 없는 이름을 안내하게 된다. 오퍼 id(`mixing-level1~3`)만 그대로다.

포함: 기본 2회 수정, 스테레오 마스터 파일

---

## 3. 마스터링

| 항목 | 가격 |
|---|---|
| 싱글 마스터링 | 100,000원/곡 (기본 1회 수정 포함) |
| EP/앨범 패키지 | 80,000원/곡 (4곡 이상 시 적용) |

포함: 스트리밍 플랫폼 규격 준수, 고해상도 음원 제공 (WAV/FLAC)

**믹싱+마스터링을 한 번에 주문할 수 있다**(온라인 주문 전용, 2026-10-03 운영자 결정). **가격은 믹싱과 마스터링의 합산 그대로이고
번들 할인은 없다.** 마스터링 단가는 곡 수가 정한다 — 1~3곡은 싱글(100,000원/곡), 4곡 이상은 패키지(80,000원/곡). 예) 믹싱 10트랙 이하
3곡 = (200,000 + 100,000) × 3 = 900,000원, 4곡 = (200,000 + 80,000) × 4 = 1,120,000원(VAT 별도). 수정은 믹싱 2회·마스터링 1회.
이 통합 상품은 요금 페이지 오퍼가 아니라 `/ko/booking/mixing-mastering` 주문 화면 전용이다(`lib/booking/mixing-products.ts`).

## 4-1. 작곡 · 편곡 · MR 제작 (2026-10-05 신설, 곡당 · 부가세 별도 · 수정 2회)

| 상품 | 가격 | 구성 |
|---|---|---|
| 작곡 | 500,000원/곡 | 멜로디(탑라인)·코드·곡 구조 + 피아노/기타 가이드 데모. 공동 작곡 크레딧·지분은 작업 전 서면 합의 |
| 소편성 편곡 (10트랙 이하) | 500,000원/곡 | 피아노·기타 중심 + 리듬, 가상악기. MR WAV 24bit/48kHz + 악기별 스템 |
| 풀밴드 편곡 (11~30트랙) | 1,000,000원/곡 | 드럼·베이스·기타·건반, 가상악기 기준 (추천) |
| 대편성 편곡 (31트랙 이상) | 2,000,000원/곡 | 스트링·브라스·합창 오케스트레이션, 파트 악보 포함 |
| 맞춤 MR 제작 | 200,000원/곡 | 기존 곡을 키·템포·길이 맞춤(축가·행사·커버·리하모니), 4분 초과는 상담 |

- **등급은 믹싱과 같은 트랙 수**다 — 편곡 등급이 곧 믹싱 등급이라 고객이 두 번 세지 않는다.
- 풀밴드 +50만·대편성 +150만은 발매 싱글 페이지의 "편곡 깊이 +50~150만원"과 같은 증분. 소편성·작곡 50만원은 싱글 번들가, 맞춤 MR 20만원은 10트랙 이하 믹싱가와 같은 값 — 사이트 안 숫자에서 끌어냈다(2026-10-05, 운영자 "사이트 데이터를 종합해 정가를 둔다").
- 세션 연주비는 어느 등급에도 없다(연주자 실비만, 섭외 수수료 없음). 납기 정본 없음 — 상담에서 1차 데모·최종 납품일을 정한다.
- 정본: `data/pricing.ts`의 `COMPOSITION_PRICE`·`ARRANGEMENT_SMALL/BAND/LARGE_PRICE`·`CUSTOM_MR_PRICE`, 오퍼 `arrangementOffers`. LP `/ko/composition-arrangement`, `/ko/pricing#arrangement`.

## 폐지된 오퍼 (2026-09-11)

`기본 홍보 패키지`(300,000원)와 `EPK 웹사이트`(500,000원)는 **음원 발매 홍보로 흡수돼
더 이상 팔지 않는다.** 전자는 같은 일을 다른 이름으로 팔고 있었고, 후자는 EPK가 발매
홍보에 포함되면서 도입가 기간에 단품이 전체 패키지보다 비싼 가격 역전이 생겼다.
문의가 오면 음원 발매 홍보로 안내할 것.
