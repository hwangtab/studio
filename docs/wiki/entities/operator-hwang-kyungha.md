# 운영자 황경하

Studio NOL 운영자. 사이트 전체에서 Person entity `#person-hwang`으로 통일되며,
프로필 페이지는 `/[locale]/author`다.

## 코드 SSOT

이 페이지는 **대조본**이고, 실제 사이트에 나가는 값의 단일 소스는 코드다.

| 대상 | 위치 |
|------|------|
| 수상·작업 연보·언론 보도·인물 사진 | `data/siteConfig.ts` → `studioOperator` |
| 프로필 페이지 표현(라벨·문구) | `data/authorProfile.ts` |
| Person JSON-LD | `utils/schema/person.ts` (`getOperatorAwards`가 award 배열 단일 변환 지점) |

새 이력을 추가할 때는 코드와 이 페이지를 함께 갱신한다. 한쪽만 고치면 대조가 무의미해진다.

## 표기 방침 (2026-08-14 결정)

- **홈에서는 수상을 언급하지 않는다.** 첫 화면 태그라인은 "무슨 일을 하는 사람인가"만 말한다.
  하나뿐이던 수상을 일곱 군데서 돌려쓰던 것이 자랑처럼 읽힌 원인이었다.
- **목록 형식을 쓴다.** 같은 수상을 문장으로 늘여 쓰면 자랑이 되고, 연도별로 늘어놓으면
  이력이 된다. `/author`의 수상 섹션과 작업 연보가 모두 목록인 이유다.
- **기계가 읽는 곳은 유지한다.** Person JSON-LD `award`(6건), `llms.ts`는 자기자랑이 아니라
  엔티티 검증 데이터다. 사람 눈에 보이는 마케팅 문구와 구분해서 다룬다.
- **음반을 앞, 기획·전시·축제를 뒤에 둔다.** 녹음 의뢰하러 온 방문자는 앞부분만 보고
  판단하고, 더 궁금한 사람이 아래까지 읽는다.
- **스토리 본문·포트폴리오 작품 설명에도 수상을 넣지 않는다**(2026-08-14 2차 정리).
  스토리에서는 "15년째 이 일을 했다" 같은 경험 근거만 남기고 수상은 뺐다 — 어느 문단도
  수상 없이 논지가 성립했고, 오히려 선명해진 곳이 있었다. 수상 이력의 제자리는 `/author` 목록이다.
