# Studio NOL 서비스 목록

스튜디오 놀이 실제로 제공하는 서비스의 정식 목록.
소스: [../studio-nol-complete-guide.md](../studio-nol-complete-guide.md)

> **서비스 범위 가드**: 보컬·악기 레슨 없음. 드럼 녹음은 의뢰 시 가능(제외 단정 금지). 영어 전담 엔지니어 없음 — 영어 제공은 예약 응대 + 원격 믹싱에 한함.

| 항목 | 내용 |
|---|---|
| 메인 마이크 | Neumann U87AI, AKG C414 XLS, SM58/57 등 |
| 프리앰프 | Vintech X73i (Neve 1073 스타일), Focusrite Octopre |
| 인터페이스 | Prism Sound Lyra 2 |
| 요금 | 100,000원/시간 (최소 2시간), 500,000원/Day Lock(6시간) |

장르별 지원: 보컬, 어쿠스틱·일렉트릭 악기, 피아노(Yamaha U3/U1), 성우·나레이션

## 2. 믹싱

| 레벨 | 트랙 수 | 가격 |
|---|---|---|
| Level 1 | 10트랙 이하 | 200,000원/곡 |
| Level 2 | 11~30트랙 | 350,000원/곡 |
| Level 3 | 31트랙 이상 | 500,000원/곡 |

포함: 기본 2회 수정, 밸런스·톤 보정, 이펙팅·공간감, 스테레오 마스터 파일.
원격 믹싱 의뢰 가능 (`/ko/pricing` 참조).

## 6. 연습실 입주

| 항목 | 내용 |
|---|---|
| 월 이용료 | 360,000원~ |
| 1년 계약 | 첫 달 50% 할인, 보증금 0원 |
| 운영 | 24시간, 개별 디지털 도어록 |
| 방음 | 국제표준 STC, 이중 벽체, 방진 시공 |

입주 혜택 8가지: 녹음실 할인, 무료 음원 유통(오디오가이·순이익 70%), 보도자료 지원, 버스킹 장비 대여, 전문가 피드백, 펀딩 컨설팅, 예술지원사업 안내, 공구 대여.

## 8. 부가·기획 서비스

- 기획/컨설팅: 50,000원/시간
- 펀딩 설계 대행: 400,000원 선불 + 성공 시 10%
- 기본 홍보 패키지 (보도자료 + 미디어 배포): 300,000원
- EPK 웹사이트 제작: 500,000원
- 유튜브/방송 촬영 대관: 100,000원/시간
- 라이브 공연 기획·운영 지원: 가격 미정 (2026-08-20 본인 확인. `data/services.ts`의 음반 제작
  8단계 중 '공연 기획' 카드가 이 서비스다. 정본 미등재 상태로 사이트에만 노출돼 있어 등재)
