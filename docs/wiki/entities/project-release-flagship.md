# 발매 프로젝트 — Path B 플래그십

> 소스: [../2026-05-28-발매프로젝트-재포지셔닝-기획.md](../2026-05-28-발매프로젝트-재포지셔닝-기획.md) (read-only)
> 상태: 기획 확정 / 실행 진행 중 (Open items §10 미결)

---

## 목적 — 왜 이 프로젝트인가

현재 사이트는 세 마케팅 원칙(타겟 좁히기·결과 중심·가치 기준 가격)에 모두 실패하고 있다.
"은평구 최저가"(커머디티)와 "최고급 세계적 장비"(프리미엄)를 동시에 노출해 서로를 깎아먹고,
어느 고객에게도 "여긴 나를 위한 곳"이라는 신호를 주지 못한다.

**핵심 재발견:** 실제 고가 상품은 "시간당 녹음실"이 아니라
**프로듀서 황경하 + 그의 네트워크** — 기획·녹음·세션 연결·믹싱·유통·평단 PR까지
인디 아티스트를 발매시키는 전 과정 — 이다.
그런데 이 상품이 현재 사이트에는 사실상 보이지 않는다.

---

## 포지셔닝 방향 — Path B (플래그십 추가 / 위계 뒤집기)

- **브랜드 구조:** 스튜디오 놀 = 우산 브랜드(사이트·연습실·단건 서비스·SEO 자산 전체 포괄).
  황경하 = 발매 프로젝트 랜딩·소개에서만 전면에 내세우는 프로듀서 얼굴 ("프로듀서 추천형").
  이중 브랜드가 아니다 — 황경하 이름의 신뢰를 플래그십에서만 집중 활용해 신생 브랜드를 부트스트랩.
- **타겟 (스파인):** 인디 싱어송라이터 — 본업 수입이 있고 자기 곡이 있으며, 멜론/스포티파이 발매·세션 연결·인디씬 인지도·평론가 리뷰를 원하는 사람.
  (기존 입시생·축가·유튜버 타겟은 서포팅 페이지에 잔존)
- **의도한 결과:** 발매·홍보·인디씬 진입에서 막힌 인디 싱어송라이터가 사이트에 들어와
  "여기가 나를 발매 아티스트로 세워줄 곳"이라고 즉시 느끼고, 무료 발매 상담을 신청한다.

## 진짜 상품 정의

**앨범 판매가 아니라 "프로듀서 + 네트워크"가 진짜 상품이다.**

| 범주 | 내용 |
|------|------|
| 인하우스 직접 제공 | 보컬 녹음, 믹싱, 마스터링, 연습실 ([[entities/services]] 참조) |
| 황경하 오케스트레이션 | 기획, 프로듀싱, 발매 디렉팅, 평단 PR 동선 |
| 네트워크 연결 | 세션 연주자(기획안 명시: 정수민·권낙주·더밀리웨이스 등), 유통 파트너(포크라노스·미러볼 류), 지원사업·펀딩 노하우 |
| 해자(Moat) | 평론가·매체 네트워크, 15년 누적 디스코그래피, 세션맨 풀 |

> **인하우스 밴드 트래킹 약속 아님.** 악기 트래킹은 네트워크 연결로 충당한다.

## 상품 형태 (플래그십 3티어)

티어는 기능 게이트가 아니라 **실제 발매 규모**로 구분한다.

| 형태 | 호흡 | 베이스 단가 (보컬 녹음·믹싱 기준; 세션·편곡·유통·평단 PR 풀스코프는 가산) |
|------|------|------|
| 싱글 발매 | 6~12주 | 약 50만~ (1곡 기준) |
| EP 발매 | 3~6개월 | 규모·편성에 따라 맞춤 견적 |
| 정규 발매 | 6~12개월 | 약 400만~ (8곡 기준) |

전환 경로: **"무료 발매 상담 신청 (30분 기획 상담)"** → 맞춤 견적. 기존 카카오톡 상담 동선 재사용.

## 메시지 원칙 (카피 가드레일)

- 헤드라인 후보: "혼자선 못 가는 발매, 끝까지 함께 갑니다" / "곡은 다 썼는데, 그 다음을 모르는 당신에게" / "당신의 첫 발매, 처음부터 끝까지 동행합니다" (실행 시 1개 확정 필요)
- 부제 방향: "기획부터 녹음·세션·믹싱·유통, 그리고 평론가에게 닿는 일까지 — 15년차 프로듀서 황경하가 이끄는 발매 프로젝트"
- **금지:** "최저가·할인"과 "최고급 장비"의 동시 노출. 보장형 단정("평단이 인정합니다") — 반드시 동행·과정 약속("평론가에게 닿는 길을 함께 연다")으로 표현.

## 고객 vs 프로듀서 이력 구분 주의 사항

이 기획안에는 **고객/아티스트의 페르소나 정보**가 포함되어 있다.
예를 들어 "두루두루AMC 매니저 경력"은 고객 sickbaby의 페르소나 설계 과정에서 나온 정보이며,
황경하(스튜디오 운영자·프로듀서) 본인의 이력이 아니다.
프로듀서 소개·사이트 카피 작성 시 절대 혼용하지 않는다.

황경하 본인 이력 = "15년째 인디씬에서 여러 의미 있는 음반들을 작업해온 기획자·프로듀서"
(구체적 디스코그래피는 `data/portfolio/items.ts` 참조)
