# 이용안내(Pricing) 페이지 구현 계획

## 1. 개요
`docs/price.md`에 정의된 고정 단가표를 바탕으로, 사용자에게 신뢰감을 주고 정보를 명확하게 전달할 수 있는 '이용안내' 페이지를 신규 제작합니다.

## 2. 디자인 컨셉
- **키워드:** 신뢰, 투명성, 전문성, 모던함
- **스타일:**
    - 기존 웹사이트의 디자인 언어(그라디언트, 폰트, 카드 UI)를 계승
    - `framer-motion`과 `utils/animationUtils`의 공통 애니메이션 상수(`PAGE_TITLE_ANIMATION` 등)를 사용하여 일관성 유지
    - 중요한 정보(가격, 추천 패키지)를 시각적으로 강조
    - **다크 모드 지원:** `dark:` 클래스를 적극 활용하여 라이트/다크 모드 모두에서 최적의 가독성 제공 (기존 컴포넌트 스타일 준수)

## 3. 페이지 구조 (`pages/pricing.js`)

### 3.1. Hero 섹션
- **메인 카피:** "합리적인 가격, 투명한 서비스"
- **서브 카피:** 프로젝트 스튜디오 운영에 필요한 핵심 서비스에 대한 고정 단가 제시 및 예산 계획 지원 메시지
- **필수 표기:** "모든 가격은 VAT 별도입니다" 문구를 명시하여 가격 정책의 투명성 확보 (Global Notice)
- **디자인:** 그라디언트 텍스트와 은은한 배경으로 주목도 향상

### 3.2. 레코딩 (Recording) 섹션
- **구성:** 2개의 카드 (시간당 / 일당)
- **카드 1: 시간당 레코딩**
    - 가격: 70,000원 / 시간
    - 특징: 최소 2시간, 성우/간단한 녹음용
- **카드 2: 일당 레코딩 (Day Lock)**
    - 가격: 600,000원 / 일 (10시간)
    - 특징: **RECOMMENDED** 배지 적용, 장시간 앨범 작업용, 식사 시간 포함

### 3.3. 믹싱 (Mixing) 섹션
- **구성:** 3개의 카드 (Level 1 / 2 / 3)
- **카드 1: Level 1**
    - 가격: 200,000원 / 곡
    - 대상: 10 트랙 이하 (보컬+MR, 소편성)
    - **포함 사항:** 기본 2회 수정 포함
- **카드 2: Level 2**
    - 가격: 350,000원 / 곡
    - 대상: 11~30 트랙 (풀 밴드, 팝) - **RECOMMENDED**
    - **포함 사항:** 기본 2회 수정 포함
- **카드 3: Level 3**
    - 가격: 500,000원 / 곡
    - 대상: 31 트랙 이상 (대편성, 복잡한 곡)
    - **포함 사항:** 기본 2회 수정 포함
- **추가 정보:** 보컬 튠/에딧 별도 (곡당 150,000원) 안내 박스

### 3.4. 마스터링 (Mastering) 섹션
- **구성:** 2개의 카드 (싱글 / 앨범)
- **카드 1: 싱글 마스터링**
    - 가격: 100,000원 / 곡
    - 특징: 디지털 싱글용, 기본 1회 수정 포함
- **카드 2: EP/앨범 패키지**
    - 가격: 80,000원 / 곡
    - 특징: 4곡 이상 시 할인 적용, 기본 1회 수정 포함 - **RECOMMENDED**

### 3.5. 부가 서비스 섹션
- **구성:** 4개의 그리드 아이템
- **항목:**
    1.  기획/컨설팅: 50,000원/시간
    2.  펀딩 설계 대행:
        - 설계 대행료: 400,000원 (선불)
        - 성공 수수료: 최종 펀딩 성공액의 10% (후불)
        - *카드 내에서 선불/후불 항목을 명확히 구분하여 표기*
    3.  기본 홍보 패키지: 300,000원
    4.  EPK 웹사이트 제작: 500,000원

### 3.6. 하단 CTA (Call to Action)
- **메시지:** "당신의 음악을 위한 최고의 파트너"
- **버튼:** "무료 상담 신청하기" (-> `/contact` 페이지로 이동)
