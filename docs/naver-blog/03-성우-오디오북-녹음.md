## 왜 전문 스튜디오인가 — 후보정으로 안 되는 것

AI 노이즈 제거 도구가 좋아졌지만, **말소리에서 룸 잔향과 배경 소음을 강하게 빼면 목소리가 인공적으로 변합니다.** 특히 오디오북 플랫폼(윌라·밀리·ACX 등)은 **노이즈 플로어 기준이 까다로워서**, 홈레코딩 소스로는 심사 통과가 어려운 경우가 많습니다.

처음부터 **드라이하고 깨끗한 소스**를 확보하면, 이후 편집·마스터링이 훨씬 수월하고 결과물 퀄리티가 확 올라갑니다.

**녹음 환경**
- 🔇 외부 소음과 룸 울림을 줄인 방음 부스
- 🎙️ 원고와 목소리에 맞춰 마이크 세팅
- 🎚️ 전담 엔지니어 1:1 진행

[📷 사진: 마이크 / 팝필터 셋업]

## 녹음 진행 방식

음악 보컬 녹음과 달리, 성우·낭독 녹음은 **단락 단위 + 딕션·호흡 관리**가 핵심입니다.

1. **사전 상담** — 원고 분량·용도·납품 형식(파일 규격) 확인
2. **마이크 세팅** — 입과 마이크 15~20cm, 팝필터
3. **단락 단위 녹음** — 실수 구간은 표시음 내고 다시 읽기 (편집 용이)
4. **편집** — 호흡음·입술 소리·노이즈 정리, 챕터 분할
5. **마스터링** — 플랫폼 기준(라우드니스) 최적화
6. **납품** — 플랫폼 규격에 맞춰 전달
