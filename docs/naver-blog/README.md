# 네이버 블로그 발행용 글 모음

> 작성 2026-05-31. GSC 검색 수요 데이터 기반 7편. 네이버 블로그 전용 — **자사 사이트(studionol.co.kr)에는 올리지 말 것**(유사문서 패널티).

## 발행 원칙

1. **사이트 스토리와 제목·문장이 달라야 함** — 같은 주제라도 각도·표현을 바꿈. 이 글들은 모두 네이버 톤(1인칭·대중 친화·추천/비교형)으로 사이트 객관 가이드와 차별화됨.
2. **사진 5장 이상** — 네이버 C-rank는 직접 찍은 사진이 많은 글을 우대. 각 글의 `[사진]` 표시 위치에 실제 사진 삽입.
3. **플레이스 장소 첨부** — 본문에 "스튜디오 놀" 네이버 플레이스를 첨부해 블로그↔플레이스 연결(지역 검색 강화).
4. **글 끝 링크** — 플레이스 + 필요 시 사이트 링크로 3자 연결.
5. **주 1편 페이스** — 한 번에 몰아 올리지 말 것(어뷰징 의심).
6. **발행 순서 정본은 [PUBLISH_WITH_LOCAL_IMAGES.md](PUBLISH_WITH_LOCAL_IMAGES.md)** — 아래 "글 목록"의
   `7 → 2 → 1` 순서는 2026-05-31 영문 7편 초안 시절 것이라 낡았다. 그 순서는 2·1번이 순수 정보성 글
   (마이크 추천·고음 안 올라가는 이유)이라 첫 분기 회수를 스스로 깎는다. 전환 의도가 강한
   `01-음악연습실-월세-입주` → `02-연신내-녹음실-보컬녹음` → `03-성우-오디오북-녹음` 순서를 쓸 것.

## 계측 규칙 (발행 전 필수)

**이 채널은 아직 미검증이다.** GA4 `source.csv` 기준 `blog.naver.com` 1세션 / `m.blog.naver.com` 1세션 —
편당 세션 실측치가 저장소에 없다. 반면 `m.search.naver.com`(네이버 검색)은 860세션에 리드 24건
(2.79%)으로 구글 오가닉(0.81%)의 3.4배다. 블로그가 그 검색 유입에 기여하는지를 **재는 것**이
파일럿의 목적이므로, 계측 없이 발행하면 90일 뒤에도 판정이 불가능하다.

1. **UTM** — 글에서 사이트로 보내는 링크에 반드시 붙인다:
   `https://studionol.co.kr/ko/practice-room?utm_source=naverblog&utm_medium=referral&utm_content=<파일명>`
   `utm_content`는 확장자 뺀 파일명(예: `01-음악연습실-월세-입주`). 글마다 달라야 어느 글이 먹혔는지 갈린다.
2. **카카오 진입 문구를 글마다 다르게** — 카카오 오픈채팅 전환은 오프사이트라 GA4에 안 잡힌다.
   글별로 첫 인사 문구를 구분해 두면 채팅방에서 유입 글을 역추적할 수 있다.
3. **발행 즉시 아래 발행 대장에 날짜 기록 후 커밋** — 현재 저장소에는 발행 여부를 알 방법이 전혀 없다
   (관련 커밋 13건이 전부 집필·사실정정이고 발행 기록이 없음).
4. **발행 전후 GA4 스냅샷** — `scripts/ga4-fetch.mjs` 출력에는 날짜 차원이 없어 그냥 두면 전후 비교가
   구조적으로 불가능하다. 발행일에 `docs/ga4-raw/`를 커밋해 시점을 남길 것.

스토리가 1,764편 있고 구글에서 무료로 돌고 있다.
