# 본문

녹음은 잘 끝냈는데, 그다음이 막막하신가요? "믹싱은 뭐고 마스터링은 또 뭔지", "비용은 얼마인지", "지방에 사는데 꼭 스튜디오까지 가야 하는지"… 음원 발매를 앞두고 가장 많이 막히는 단계가 바로 후반 작업입니다.

오늘은 서울 연신내·불광 **스튜디오 놀**의 **믹싱·마스터링 의뢰**를 — 비용부터 온라인 의뢰 방법까지 정리해 드릴게요.

## 믹싱 vs 마스터링, 한 줄 정리

- **믹싱**: 보컬·악기 등 여러 트랙의 볼륨·음색·공간감을 다듬어 **하나의 완성된 스테레오 곡**으로 만드는 작업
- **마스터링**: 완성된 믹스를 스트리밍·발매 기준(LUFS)에 맞춰 **음량·음색을 최종 최적화**하는 마무리

순서는 항상 **믹싱 → 마스터링**입니다. 믹싱이 요리라면, 마스터링은 플레이팅이라고 보시면 돼요.

[📷 사진: 아웃보드 장비 / 컴프레서·EQ]

## 지방에 계셔도 됩니다 — 온라인 믹싱 의뢰

녹음은 직접 와야 하지만, **믹싱·마스터링은 파일만 보내주시면 됩니다.** 이미 녹음된 트랙(스템)이 있다면, 굳이 서울까지 오실 필요 없이 온라인으로 의뢰하실 수 있어요. 부산이든 광주든 제주든, 파일 전송으로 같은 퀄리티의 후반 작업이 가능합니다.

**온라인 의뢰 시 보내실 것**
- 트랙별 드라이 WAV 파일(스템) — 24bit / 44.1kHz 이상
- 참고곡(레퍼런스) 링크 — "이런 느낌으로 가고 싶다"
- 곡 정보 한 줄 — "보컬 1곡 + 트랙 약 15개 / 발매용"
