`[사진 1: DAW 파일 내보내기 화면 또는 파형 비교]`

안녕하세요, 연신내에서 보컬 녹음·믹싱하는 스튜디오 놀입니다.

"믹싱 맡기려는데 파일 WAV로 보내요 MP3로 보내요?", "음원 사이트에 올릴 때 뭐로 내보내요?" — 작업 의뢰하시는 분들이 진짜 자주 헷갈려 하세요. 한 번 정리해두면 평생 안 헷갈리니, 결론부터 갑니다.

### ⚡ 3초 결론

- **녹음·믹싱·마스터링 등 "작업 단계" → 무조건 WAV**
- **다 끝나고 친구한테 들려주거나 미리듣기 → MP3 OK**
- **멜론·스포티파이 등 발매 → 유통사가 요구하는 WAV 규격**

이게 전부예요. 이유가 궁금하면 아래로.

`[사진 2: WAV vs MP3 개념 비교 일러스트]`

### 🎵 WAV와 MP3, 뭐가 다른가

- **WAV**: 소리를 **손실 없이** 그대로 담은 파일. 용량이 큼(곡당 30~50MB).
- **MP3**: 사람이 잘 못 듣는 정보를 **버려서 압축**한 파일. 용량이 작음(곡당 3~5MB). 한 번 버린 정보는 못 되살림.

핵심은 **"MP3는 한 번 압축하면 되돌릴 수 없다"**는 점이에요. MP3를 다시 WAV로 바꿔도 버려진 음질은 안 돌아옵니다.

### 🚫 그래서 작업 파일을 MP3로 주면 생기는 일

믹싱을 의뢰하면서 보컬을 MP3로 보내시는 분이 가끔 계세요. 그러면 — 이미 음질이 깎인 상태에서 작업을 시작하는 거라, 아무리 잘 믹싱해도 **천장이 낮아집니다.** EQ로 고음을 올리면 MP3 압축 때문에 생긴 "찌글거림"까지 같이 커지거든요.

저희가 녹음·믹싱 의뢰받을 때 **드라이 보컬을 꼭 WAV(24bit)로 받는 이유**가 이겁니다. 시작 재료가 좋아야 끝이 좋아요.

`[사진 3: 스튜디오 작업 장면 / 24bit 설정 화면]`

### 📤 단계별 정리

| 단계 | 형식 | 이유 |
|---|---|---|
| 녹음 (DAW 저장) | **WAV 24bit / 48kHz** | 작업 여유(헤드룸) 확보 |
| 믹싱·마스터링 의뢰 | **WAV** | 음질 손실 없이 작업 |
| 발매(멜론·스포티파이) | **WAV 16bit / 44.1kHz** | 유통사 표준 규격 |
| 미리듣기·공유 | MP3 320kbps | 용량 작고 충분히 들을 만함 |

### 🎚 자주 묻는 것

**Q. MP3 320kbps면 거의 WAV급 아닌가요?**
듣기엔 비슷할 수 있어요. 하지만 그 위에 **추가 작업(믹싱·마스터링)**을 하면 차이가 드러납니다. "완성해서 듣기"는 MP3 OK, "작업 재료"는 WAV.

**Q. 유튜브 올릴 땐요?**
유튜브가 어차피 재압축하지만, **올릴 때는 WAV나 고음질로** 올리세요. 압축은 한 번이라도 적게 거치는 게 좋습니다.

**Q. 발매용 규격을 모르겠어요.**
유통사마다 조금씩 달라요. 보통 WAV 16bit/44.1kHz를 요구합니다. 헷갈리면 믹싱·마스터링 맡길 때 "발매용으로 내보내 주세요"라고 하면 규격 맞춰 드려요.

### 정리

외우기 귀찮으면 딱 하나 — **"작업할 거면 WAV, 그냥 들을 거면 MP3."**

녹음·믹싱 의뢰하실 때 파일 형식이 헷갈리면 그냥 물어보세요. 연신내에서 보컬 녹음·믹싱 하고 있고, 발매용 규격까지 맞춰서 내보내 드립니다. 톡톡으로 편하게 문의 주세요 🎧
