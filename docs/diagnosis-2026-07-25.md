## 1. 이번 진단의 5대 핵심 발견

### 발견 1 — 🔴 핵심 서비스 "녹음실"이 검색에서 사실상 부재

사이트 대표 서비스(녹음 100,000원/시간)를 사는 사람이 칠 쿼리에서 노출이 없다:

| 쿼리 | 사이트 노출 | 랭킹 페이지 |
|---|---|---|
| "녹음실 대여" | **0** | 없음 |
| "녹음실 가격" | **0** | 없음 |
| "마포/망원 녹음실" | 0 | (상권 밖이라 자연스러움) |
| "녹음실" | 89 imp | `studio-compare1` pos 10.6 (스토리) |
| "녹음 스튜디오" | 94 imp | `studio-compare1` pos 8.1 / **홈은 pos 42** |
| "보컬 녹음" | 27 imp | `selfrecord1` pos 6.1 (정보성 스토리) |

원인: `pages/[locale]/`에 practice-room·voice-acting·wedding-song·lesson·cover-video는 있는데 **녹음(recording) 서비스 LP가 없다.** 1,576편 스토리가 정보성 쿼리를 다 먹는 동안, 정작 돈이 되는 상업 쿼리는 받아줄 페이지가 없었다.

대조: 연습실은 전용 LP(`/ko/practice-room`)가 있고 → "음악작업실 월세" 클러스터 pos 3~7 → 90일 295클릭 → **32 카카오 리드(CR 6.1%)**. 상업 LP 하나가 사이트 전체 리드의 26%를 만든다. 이 공식을 녹음에 복제하지 않은 상태.

### 발견 2 — 🔴 GA4 주요 이벤트(전환) 오염

Admin API로 실측한 현재 key events (14개):

```
purchase, page_view, form_start, lead_click_kakao, session_start,
user_engagement, lead_submit_error, lead_form_start, lead_click_phone,
click, first_visit, lead_form_field_error, scroll, lead_form_abandon
```

- `page_view`·`session_start`·`scroll`·`click`·`first_visit`·`user_engagement`가 전환으로 등록 → **GA4 conversions 수치가 무의미** (사실상 모든 방문이 전환으로 집계)
- 오류 이벤트(`lead_submit_error`·`lead_form_field_error`·`lead_form_abandon`)까지 전환 등록 → 실패가 전환으로 잡힘
- 정작 불변식 5종 중 **`lead_submit_success`·`lead_click_naver_map`·`lead_click_email` 누락**

`utils/analytics.ts`의 이벤트 설계는 성숙한데 GA4 콘솔 설정이 이를 배반하는 상태. 향후 Google Ads 연동·자동 입찰·탐색 퍼널까지 전부 오염되므로 **모든 개선 판단의 전제로 즉시 정화 필요**.

### 발견 3 — 채널별 전환율 격차 20배: 트래픽의 質 문제

- 구글 오가닉이 세션의 86%를 차지하지만 CR은 네이버의 1/4, ChatGPT의 1/5.
- **네이버는 CR이 검증됐는데 유입 규모가 방치됨** (플레이스 유입 11세션은 사실상 0). 은평구 로컬 고객의 기본 행동(네이버 검색→플레이스→예약)이 퍼널에 없음.
- **AI 검색(LLM) 합계 ~450세션이 CR 3%+** — 이미 구글 오가닉보다 質 좋은 채널로 성장. `/en/contact`로 ChatGPT가 58세션을 직접 보내고 있고 폼 제출 성공 2건 발생(주한 외국인 수요 실존).

### 발견 4 — 트래픽의 95.6%(스토리)가 리드의 절반밖에 못 만든다

- 스토리 1,749개: 클릭 9,979 (95.6%) → 유효 리드 ~57건 (스토리 세션당 CR ~0.5%)
- 서비스·정적 101개: 클릭 457 (4.4%) → 유효 리드 ~65건 (**10~20배 효율**)
- 세션 상위 정보성 스토리는 참여도가 높은데(체류 2~4분, 이탈 4~14%) 리드 0: `copyright-cover1`(261세션), `daw-choice1`(254), `eq1`(227), `song-key1`(217), `revenue1`(171), `loudness1`(154), `vst-guide1`(135)…
- 이 독자들은 이탈자가 아니라 **아직 오퍼를 못 받은 잠재고객**(음악인)이다. 직접 "문의하기" CTA로는 정보 탐색 단계와 미스매치 → 중간 퍼널(리드 마그넷, 채널 추가) 설계가 빈 자리.

### 발견 5 — 예약 시스템 부재 + 계측 사각

- "100% 예약제"(FAQ)인데 예약 수단이 카카오 오픈채팅 단 하나. 네이버 예약 없음, 온라인 결제 없음. 카톡 응답 속도/시간대가 곧 매출 상한.
- 전화 리드가 90일 6건뿐 — 로컬 서비스업 치고 비정상적으로 낮음 (전화번호 노출·클릭 유도 약함).
- 푸터 네이버지도·mailto 클릭 미추적 → 방문 의도 리드 GA4 누락.

## 3. 획기적 개선 설계 — 5개 레버

> 설계 원칙: "트래픽 +x%"가 아니라 **리드 월 40건 → 100건+ (3개월)**, 그리고 리드 믹스를
> 고단가·확장가능 서비스(녹음·믹싱·발매 0.5~4M)로 이동시키는 것을 목표로 한다.
> 연습실(월 360k)은 정원이 유한해 리드가 늘어도 매출 상한이 빠르게 온다.

### 레버 1 — 녹음 서비스 LP 신설 + 로컬 검색 장악 (예상 기여 최대)

**왜**: 발견 1. 상업 LP 1개(연습실)가 리드 26%를 만드는 공식이 검증됐는데, 더 큰 시장(녹음)에 LP가 없다.

**설계**:
1. `/ko/recording` LP 신설 — 타깃 쿼리 클러스터: "녹음실 대여", "녹음실 가격/비용", "보컬 녹음 스튜디오", "서울/은평구/연신내 녹음실", "일반인 녹음실". 구성: 가격 인라인(250k 1곡 패키지 선두) + 장비/부스 사진 + 포트폴리오 + 이용 흐름 + 후기 + FAQ + LocalBusiness·Service·Offer schema.
2. 기존 랭킹 자산의 링크 집중: "녹음실"류 쿼리를 이미 받는 `studio-compare1`(pos 8~10)·`seoul1`·지역 스토리들 → 본문 상단에서 LP로 내부링크. 스토리가 받은 노출을 LP 랭킹 신호로 전환.
3. `/ko/voice-acting` 강화 — "성우 녹음실" pos 16.4, "성우 녹음 섭외 전문가/업체/견적/외주"(B2B, 건당 단가 높음) pos 8~28에서 클릭 0. 섭외 프로세스·견적 예시·납품 스펙을 페이지에 명시해 1페이지 진입.
4. `/ko/pricing` 재타기팅 — 현재 브랜드 쿼리 외 노출 없음. title/H1을 "녹음실·믹싱·마스터링 가격표"로, 상단에 가격 요약표 즉답 배치(ChatGPT bounce 86% 대응 겸용).
5. 연습실 클러스터 마무리 — "음악작업실 월세" 계열 pos 3~7 → 1~3위로: `practice-room-monthly1`(pos 5~7)과의 카니벌라이제이션을 LP 우선으로 정리(스토리는 LP로 canonical 신호 집중).

**목표**: 3개월 내 녹음 클러스터에서 월 100클릭+ / CR 4%+ → **월 +15~30 리드** (연습실 공식 복제).

### 레버 2 — 네이버 채널 본격 가동 (CR 검증 완료, 유입만 없음)

**왜**: 발견 3. 네이버 모바일 CR 2.33%(구글 4배)인데 세션 729뿐, 플레이스는 11세션.

**설계**:
1. **네이버 예약 도입** — 스마트플레이스에 예약 상품 등록(녹음 1곡 패키지 250k, 시간대여 100k, 성우/나레이션 100k). "100% 예약제 + 예약 시스템 부재" 모순 해소. 예약 도입은 플레이스 노출 순위에도 기여.
2. 스마트플레이스 최적화 실행 — `docs/naver-place-optimization.md` 이미 작성돼 있음(카드뉴스 5종 포함). 실행만 남음.
3. **리뷰 생성 루프** — 세션 종료 시 카톡으로 영수증 리뷰 요청 메시지 자동화(템플릿). 로컬 검색에서 리뷰 수 = 순위.
4. 네이버 블로그 개시 — 초안 23편 자산(`entities/channel-naver-blog`) 순차 발행, 각 편에서 플레이스·사이트 LP로 링크.
5. 사이트 내 전화 CTA 강화 — 모바일에서 전화 버튼 가시성 상향(현재 90일 6건은 비정상). 네이버 고객층은 전화 선호.

**목표**: 네이버발 세션 3배(월 ~250 → 750) + 플레이스 예약/전화 직전환 → **월 +15~25 리드** (사이트 계측 밖 전화·예약 포함).

### 레버 3 — GA4 전환 측정 정화 (즉시, 모든 판단의 전제)

**왜**: 발견 2. 지금 상태로는 어떤 개선의 효과도 신뢰 있게 측정 불가.

**설계**:
1. key events를 불변식 5종만 남기고 정리: `lead_click_kakao`·`lead_click_phone`·`lead_click_email`·`lead_click_naver_map`·`lead_submit_success` — 나머지 9개(특히 page_view·scroll·click·오류 3종) 해제. `scripts/ga4-set-key-events.mjs` 확장(삭제 로직 추가, edit 토큰 1회 발급 필요).
2. 계측 사각 부착: 푸터 네이버지도(`Footer.tsx`)·`ContactInfoCard` 네이버지도/mailto에 `lead_click_naver_map`/`lead_click_email`.
3. `StoryCTA`의 구형 GTM `select_content` → 통합 `trackLeadEvent` 체계로 이관.
4. 주간 리포트에 "채널별 유효 리드 CR" 고정 지표화(이미 `ga4-fetch.mjs`가 산출).

### 레버 4 — 정보 트래픽 13k 세션의 중간 퍼널 설계 (전환율 0.93% → 1.5%+)

**왜**: 발견 4. 최대 자산(참여도 높은 정보성 독자)이 오퍼 미스매치로 전량 이탈.

**설계**:
1. **의도 매칭 오퍼 맵** — 카테고리별 CTA를 "문의하기"가 아니라 구체 오퍼로:
   - `eq1`·`loudness1`·`mixing*`·`vst-guide1` → "믹싱 데모 무료 피드백" (파일 보내면 코멘트 1회)
   - `copyright-cover1`·`coverrecording1` → 커버 녹음+발매 패키지 (저작권 처리 포함 강조)
   - `revenue1`·`distribution1`·`music-marketing1`·`indie-label1` → 발매 프로젝트 (0.5~4M 고단가)
   - `daw-choice1`·`plugins1`·`producer1` → 프로듀싱 레슨 (월 350k)
2. **리드 마그넷 → 카카오 채널 추가** — "발매 전 체크리스트"·"믹싱 전 셀프 점검 10항목" 등 PDF/노션을 채널 추가 조건으로 제공. 직접 문의 CR 한계(정보 단계 독자)를 우회해 **재접촉 가능한 자산**(채널 친구)으로 축적.
3. 오퍼 노출 위치는 기존 인라인 콜아웃 시스템(`lib/storyAutoFallback.ts`) 재사용 — 매핑 테이블만 교체라 구현 비용 낮음.
4. quick-win 병행: `noise-reduction1`(imp 3,389, pos 12.1 — 1페이지 진입 시 월 +60클릭), `seoul1`(pos 10.2)·`preamp1`(14.3)·`vocal-solo-recording1`(10.4).

**목표**: 사이트 전환율 0.93% → 1.5% (**월 +25 리드 상당**) + 채널 친구 DB(재마케팅 자산) 신설.

### 레버 5 — AI 검색(GEO) 가속 (이미 CR 3%+, 선점 구간)

**왜**: 발견 3. LLM 유입 ~450세션/90d에 CR 3~4.4%. 경쟁자가 아직 없는 구간.

**설계**:
